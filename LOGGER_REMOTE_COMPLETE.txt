  Development (NODE_ENV !== 'production'):
    User Code Error/Warning
        ↓
    logger.error/warn(message, context, error)
        ↓
    ├─→ Console (formatted with emoji + timestamp)
    └─→ Log History (in-memory, 100 max)
    
    ❌ NOT sent to Sentry
    ❌ NOT stored in localStorage

  Production (NODE_ENV === 'production'):
    User Code Error/Warning
        ↓
    logger.error/warn(message, context, error)
        ↓
    ├─→ Console (formatted with emoji + timestamp)
    ├─→ Log History (in-memory, 100 max)
    ├─→ Sentry (with full context, tags, user info)
    └─→ localStorage (backup, 50 max)

  Info/Debug Logs (Both Environments):
    ├─→ Console only
    └─→ Log History (in-memory)
    ❌ NOT sent to Sentry (reduce noise)

🎯 SENTRY INTEGRATION DETAILS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  What Gets Sent to Sentry:
  
  For Errors (with exception):
    • Exception object with full stack trace
    • Log message
    • Full context (component, action, etc.)
    • Timestamp
    • Tags: component, action

  For Warnings:
    • Message
    • Full context
    • Timestamp
    • Tags: component, action
    • Level: 'warning'

  User Context (when set):
    • User ID
    • Email
    • Username
    • Attached to all subsequent errors

  Not Sent to Sentry:
    • Info logs (reduce noise)
    • Debug logs (development only)
    • Development environment errors

    logger.clearHistory();     // Clear in-memory

  Download Logs for Support:
    const logs = logger.getStoredLogs();
    const blob = new Blob([JSON.stringify(logs, null, 2)], { type: 'application/json' });
    const url = URL.createObjectURL(blob);

    a.href = url;
    a.download = `error-logs-${new Date().toISOString()}.json`;
    a.click();
