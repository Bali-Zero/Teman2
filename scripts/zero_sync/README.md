# zero_sync — canonical main -> FastLabsNet/zero main

One-way mirror, run every 30 min by launchd on Mini (`com.nuzantara.zero-sync`, wrapper
`infra/launchagents/wrappers/mini-zero-sync.sh`, organ `mini.zero_sync`).

## What it does
Keeps a bare partial clone in the state dir (`~/.nuzantara-pilots/zero-sync/repo.git`), fetches canonical
(depth 1, blob:none) and zero main, then builds zero's new tree with git plumbing only:
canonical entries under `.slim/keep_paths.txt`, minus `cut_paths.txt`, with zero-owned paths
(`.github/`, `.slim/`, `local_paths.txt`) taken exclusively from zero; root `package.json` pruned to
the workspaces present, root `package-lock.json` regenerated by npm (cached in `lock_cache/`).
Different from zero's tree: one fast-forward commit `sync: canonical <sha>` with trailer
`Zero-Sync-Canonical: <sha>`, pushed plain (never forced). Zero's root commit is treated as the import baseline.

## Exit codes
0 synced / no-op / already running · 1 error · 2 equal URLs · 3 divergence refused · 4 push rejected (retry next tick).

## Divergence refusal (exit 3)
The sync refuses when a commit made directly on zero (after the last sync commit) changed a non-zero-owned path
that the rebuilt tree would revert. Heartbeat status `error` lists up to 10 paths. Fix on the canonical side:
land the same change in canonical (then the next tick passes), or add the path to `cut_paths.txt`/`local_paths.txt`
in zero if it is meant to be zero-only. Nothing is pushed while refused.

## Operating
- Dry run: `python3 scripts/zero_sync/zero_sync.py --dry-run --no-ci-check --state-dir <dir>` (no push, no heartbeat; exit 3 if it would refuse).
- Stop: `MINI_ZERO_SYNC_ENABLED=false` in the job env, or `launchctl bootout gui/$(id -u)/com.nuzantara.zero-sync`.
- A keep path missing from canonical is a hard error naming the path: edit zero's `.slim/keep_paths.txt`.
- Log: `~/logs/mini-zero_sync/run.log`; heartbeat: `~/.organism/last_seen/mini.zero_sync.json`.
- Needs on Mini: git, gh (CI check), npm, push access to zero. Tests: `python -m pytest scripts/zero_sync/tests`.
