---

## Cara Setup (Sekali Saja)

### 1. Buka Terminal

- Tekan **Cmd + Space** di keyboard
- Ketik `Terminal`
- Tekan **Enter**

### 2. Ketik perintah ini, lalu Enter:

```
bash ~/Desktop/nuzantara/scripts/krisna-node/install.sh
```

Tunggu sampai selesai (5-10 menit). Kalau minta password, masukkan password Mac kamu.

### 3. Login

Setelah selesai, ketik ini lalu Enter:

```
gemini auth login
```

Browser akan terbuka — pilih **krisna@balizero.com** dan klik Izinkan.

---

## Cara Pakai Setiap Hari

Buka Terminal, ketik ini lalu Enter:

```
cd ~/Desktop/nuzantara && gemini
```

Lalu tanya apa saja, contoh:

- _"tampilkan klien terbaru"_
- _"apa langkah selanjutnya untuk klien [nama]?"_
- _"pratik mana yang sedang berjalan?"_
- _"buat klien baru [nama], email [email]"_
