## Налаштування (один раз)

### 1. Відкрий Terminal

- Натисни **Cmd + Space**
- Введи `Terminal`
- Натисни **Enter**

### 2. Введи цю команду та натисни Enter:

```
bash ~/Desktop/nuzantara/scripts/ruslana-node/install.sh
```

Зачекай 5-10 хвилин. Якщо запитає пароль — введи пароль свого Mac.

### 3. Увійди в систему

Після завершення введи:

```
gemini auth login
```

Відкриється браузер — вибери **ruslana@balizero.com** та натисни Дозволити.
