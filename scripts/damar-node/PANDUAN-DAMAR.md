## Apa ini?

Ini adalah **asisten AI pribadimu** yang tahu semua data klien dan visa di Bali Zero.
Kamu bisa tanya apa saja pakai Bahasa Indonesia, dan dia akan jawab dengan data nyata.

---

## Cara Setup (Sekali Saja)

### 1. Buka Terminal

- Tekan **Cmd + Space** di keyboard
- Ketik `Terminal`
- Tekan **Enter**

### 2. Ketik perintah ini, lalu Enter:

```
bash ~/Desktop/nuzantara/scripts/damar-node/install.sh
```

Tunggu sampai selesai (5-10 menit). Kalau minta password, masukkan password Mac kamu.

### 3. Login

Setelah selesai, ketik ini lalu Enter:

```
gemini auth login
```

Browser akan terbuka — pilih **damar@balizero.com** dan klik Izinkan.

---

## Cara Pakai Setiap Hari

Buka Terminal, ketik ini lalu Enter:

```
cd ~/Desktop/nuzantara && gemini
```

Lalu tanya apa saja, contoh:

- _"tampilkan pratik yang aktif sekarang"_
- _"visa siapa yang habis bulan ini?"_
- _"info klien [nama]"_
- _"ada alert kepatuhan hari ini?"_
