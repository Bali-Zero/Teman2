📋 QUICK DEPLOYMENT STEPS (Manual Path)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. Create Sentry Project
     • Go to: https://sentry.io
     • Create project → "Next.js" → Name: "mouth"
     • Copy DSN

  2. Get Credentials
     • DSN: Settings → Projects → mouth → Client Keys
     • Org: Settings → General Settings → Org Slug
     • Token: Settings → Developer Settings → Auth Tokens
       (Permissions: Project R/W + Release Admin)

  3. Add to Vercel
     • Dashboard: https://vercel.com/dashboard
     • Project: "mouth" → Settings → Environment Variables
     • Add 5 variables (Production + Preview + Development):
       - NEXT_PUBLIC_SENTRY_DSN
       - SENTRY_DSN
       - SENTRY_ORG
       - SENTRY_PROJECT (value: "mouth")
       - SENTRY_AUTH_TOKEN

  4. Deploy
     • Push to main: git push origin main
     • Or manual: vercel --prod

  5. Verify
     • Visit: https://balizero.com
     • DevTools → Console: throw new Error('[TEST]');
     • Check Sentry dashboard (5-10 sec)
