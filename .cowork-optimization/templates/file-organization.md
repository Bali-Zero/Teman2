# File Organization Template

## Task Description

Organize files in [FOLDER_PATH] by:

- Type (documents, images, code, etc.)
- Date (last 7 days, last month, older)
- Project (nuzantara, KB, personal, etc.)

## Instructions

1. Scan [FOLDER_PATH] recursively
2. Identify file types and categories
3. Create organized folder structure:
   ```
   [FOLDER_PATH]/
   ├── Documents/
   ├── Images/
   ├── Code/
   ├── Archives/
   └── Other/
   ```
4. Move files to appropriate folders
5. Create summary report of actions taken

## Safety Rules

- Do NOT delete any files
- Create backup before moving files
- Log all actions
- Ask before moving files larger than 10MB

## Output

Provide:

- Total files processed: [N]
- Files moved by category
- Any errors or warnings
- Recommended next actions
