# Project Report Template

## Task Description

Generate comprehensive project report from codebase and documentation

## Instructions

1. Analyze project structure in [PROJECT_PATH]
2. Extract key information:
   - Project overview and purpose
   - Technology stack
   - File/folder structure
   - Dependencies
   - Key features
   - Recent changes (git log)
   - Open issues/TODOs

3. Generate markdown report

## Analysis Areas

### 1. Project Overview

- Name and description
- Main purpose/goals
- Target users
- Current status

### 2. Technical Architecture

- Frontend: frameworks, libraries
- Backend: languages, frameworks
- Database: type, schema
- APIs and integrations
- Infrastructure: hosting, deployment

### 3. Codebase Metrics

- Total files: [N]
- Lines of code: [N]
- Languages breakdown:
  - Python: [%]
  - TypeScript: [%]
  - etc.
- Test coverage: [%]

### 4. Dependencies

- npm packages: [N]
- Python packages: [N]
- Critical dependencies
- Security vulnerabilities

### 5. Recent Activity

- Last commit: [DATE]
- Recent changes (last 7 days)
- Active branches
- Contributors

### 6. Documentation Quality

- README completeness: [SCORE]
- API docs: Yes/No
- Code comments: [%]
- Examples: [N]

### 7. Issues & TODOs

- Open GitHub issues: [N]
- TODO comments in code: [N]
- Technical debt items
- Security concerns

## Output Format

```markdown
# [PROJECT_NAME] - Project Report

Generated: [DATE]

## Executive Summary

[2-3 paragraphs overview]

## Technical Stack

- Frontend: [TECH]
- Backend: [TECH]
- Database: [TECH]
- Infrastructure: [TECH]

## Project Structure

[FOLDER TREE]

## Key Metrics

- Files: [N]
- LOC: [N]
- Dependencies: [N]
- Test Coverage: [%]

## Recent Activity

[GIT LOG SUMMARY]

## Recommendations

1. [RECOMMENDATION 1]
2. [RECOMMENDATION 2]
3. [RECOMMENDATION 3]

## Next Steps

- [ ] Action item 1
- [ ] Action item 2
- [ ] Action item 3
```
