## Adversarial Review

**2 — MAJOR**
```ts
if (e.slug) return isPublicSlug(e.slug);
```
An entry carrying **both** `slug` and `nameOverride` short-circuits on the slug and never inspects `nameOverride`. `{ slug: "kadek", nameOverride: "Faisha" }` passes the filter; a consumer that renders `nameOverride` when present republishes the excluded person. The type `T extends { slug?: string; nameOverride?: string }` permits this combination.
**Fix:** When `nameOverride` is present, check it against `EXCLUDED_NAMES` regardless of whether `slug` is set.

**3 — MINOR**
```ts
if (EXCLUDED.has(slug)) return false;
```
`Set.has` is case-sensitive. `isPublicSlug("Faisha")` → not in `EXCLUDED` → `rosterBySlug("Faisha")` → `undefined` → **returns `true`**. Any call-site that passes a slug without lowercasing it first bypasses the check. Same applies to `EXCLUDED.has(member.slug)` in `isPubliclyListed` if a roster entry ever carries a non-lowercase slug.
**Fix:** Normalise: `const s = slug.toLowerCase()` before every `EXCLUDED.has` / `rosterBySlug` call, or build the Set from lowercased slugs.

**4 — MINOR**
```ts
const name = e.nameOverride?.trim().toLowerCase();
return !name || !EXCLUDED_NAMES.has(name);
```
`trim`+`toLowerCase` does not handle Unicode confusables or diacritics (`"Faïsha"`, fullwidth `"Ｆａｉｓｈａ"`, or `"FAİSHA"` with Turkish İ whose `toLowerCase()` is `"faisha"` in some locales but not others). Unlikely in practice for an internal editorial CMS, but the guard is presented as exhaustive.
**Fix:** At minimum, add `.normalize("NFKC")` before comparison; document that only the exact roster spelling is caught.

**5 — NIT (drift question answered)**
```ts
const EXCLUDED_NAMES: ReadonlySet<string> = new Set(
  <REDACTED>((slug) => {
    const member = rosterBySlug(slug);
    return member ? [slug, member.name.toLowerCase()] : [slug];
  }),
);
```
This is **derived, not a second list**, so it cannot drift from `PUBLIC_EXCLUDED_SLUGS` at runtime. The fallback `[slug]` when `rosterBySlug` returns `undefined` is the only lossy path, and the "pins" test catches it. No action needed; the design is sound.
