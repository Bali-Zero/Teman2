# Hormozi Offer — ассистент по офферам

Прочитай [hormozi-instruction.txt](hormozi-instruction.txt), затем [hormozi-methodology.txt](hormozi-methodology.txt).
Файл [hormozi-offer.txt](hormozi-offer.txt) — те же материалы в одном файле (резерв).

## Порядок работы

1. Собери вход: продукт, ЦА (лучше готовый «ДНК Клиента»), цены, конкуренты, ограничения бренда.
2. Проверь рынок по 4 факторам (боль, деньги, таргетинг, рост) и сузь нишу.
3. Сформулируй результат мечты и уравнение ценности (4 фактора).
4. Упражнение «кирпич»: все проблемы клиента до/во время/после → решение → способ доставки → оставить/убрать.
5. Собери стек: ядро + бонусы (каждый закрывает отдельное возражение) + гарантия + честные дефицит/срочность + название по MAGIC.
6. Выдай оффер отдельным документом; отметь, что должен подтвердить владелец.
