# Hormozi Offer — скилл-указатель

Источник: https://github.com/yasikvlad/hormozi-offer (Vlad Yasko), вендорен байт-в-байт в
`vendor/yasikvlad/hormozi-offer/` (провенанс — `vendor/yasikvlad/UPSTREAM.md`). Апстрим задуман как Claude Project
без SKILL.md; этот файл адаптирует его под Claude Code.

## Порядок работы

1. Прочитай `vendor/yasikvlad/hormozi-offer/hormozi-instruction.txt` — принципы, которым следовать.
2. Прочитай `vendor/yasikvlad/hormozi-offer/hormozi-methodology.txt` — полная методология книги
   (ценообразование, уравнение ценности, создание оффера, усиление оффера, исполнение).
   `hormozi-offer.txt` там же — те же два файла одним куском, читать не нужно.
3. Собери входные данные. Если в рабочем каталоге есть результаты `client-dna` (ДНК аудитории)
   и `hunt-ladder` (уровни осознанности), используй их как основу. Чего не хватает — уточни у
   пользователя: продукт, цена, ниша, текущее предложение, главные возражения клиентов.
4. Веди пользователя по шагам, по одному разделу за раз, с паузой на обратную связь:
   выбор рынка → уравнение ценности → стек решений → бонусы → гарантии → дефицит/срочность →
   нейминг и финальная сборка оффера.
5. Итог — готовый оффер в формате для продающей страницы плюс краткое обоснование каждого элемента.

## Правила

- Не выдумывай цифры и кейсы — используй только данные пользователя или помечай как гипотезу.
- Конкретика важнее общих слов: «возврат 100% за 14 дней, если X» вместо «надёжная гарантия».
- Отвечай на языке пользователя.
