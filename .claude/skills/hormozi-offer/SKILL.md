# Hormozi Offer — создание оффера по $100M Offers

Источник: https://github.com/yasikvlad/hormozi-offer (Vlad Yasko). Апстрим задуман как Claude Project;
этот SKILL.md адаптирует его под Claude Code.

## Порядок работы

1. Прочитай `hormozi-instruction.txt` — основные принципы, которым следовать при создании оффера.
2. Прочитай `hormozi-methodology.txt` — полная методология книги (5 разделов: ценообразование,
   уравнение ценности, создание оффера, усиление оффера, исполнение).
3. Собери входные данные. Если в проекте есть результаты скиллов `client-dna` (ДНК аудитории)
   и `hunt-ladder` (уровни осознанности), используй их как основу — не спрашивай заново то, что
   там уже есть. Чего не хватает — уточни у пользователя: продукт, цена, ниша, текущее
   предложение, главные возражения клиентов.
4. Проведи пользователя по шагам методологии, по одному разделу за раз, с паузой на обратную связь:
   выбор рынка и ценности → уравнение ценности → стек решений → бонусы → гарантии →
   дефицит/срочность → нейминг и финальная сборка оффера.
5. Итог — готовый оффер в формате, пригодном для продающей страницы, плюс краткое обоснование
   каждого элемента.

## Правила

- Не выдумывай цифры и кейсы — используй только данные пользователя или помечай как гипотезу.
- Конкретика важнее общих слов: «гарантия возврата 100% за 14 дней, если X» вместо «надёжная гарантия».
- Отвечай на языке пользователя.
