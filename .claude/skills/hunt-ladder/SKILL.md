# Лестница Ханта — скилл-указатель

Источник: https://github.com/yasikvlad/hunt-ladder (Vlad Yasko), вендорен байт-в-байт в
`vendor/yasikvlad/hunt-ladder/` (провенанс — `vendor/yasikvlad/UPSTREAM.md`). Апстрим не имеет YAML-шапки,
поэтому шапка живёт здесь.

## Как выполнять

1. Прочитай `vendor/yasikvlad/hunt-ladder/SKILL.md` — полная инструкция анализа (всё в одном файле).
   Методология отдельно — `methodology.md`, шаблоны и примеры прогрева — `templates.md`
   в том же каталоге.
2. Если в рабочем каталоге пользователя есть результат скилла `client-dna` (ДНК аудитории),
   используй его как исходные данные об аудитории — не спрашивай заново то, что там уже есть.
3. Результат (карта аудитории по уровням + стратегия контента) сохраняй в рабочий каталог
   пользователя — следующий шаг цепочки, `hormozi-offer`, берёт его как вход.
4. Отвечай на языке пользователя.
