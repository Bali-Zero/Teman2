## 1. Apa yang harus kamu lakukan?

3. **Submit laporan** di website OSS
4. **Tandai "Submitted"** di workspace

## 2. Di mana semua datanya?

### Halaman utama LKPM: `kita.balizero.com/lkpm`

Di sini kamu lihat **semua 59 perusahaan** dalam satu tabel.

| Kolom | Artinya |
|---|---|
| **Company** | Nama PT |
| **Status** | Draft = belum dikerjain, Submitted = sudah selesai |
| **Assigned to** | Siapa yang ngerjain. Kalau kosong = belum ada yang ambil |
| **OSS** | Klik "Show" untuk lihat username + password OSS |
| **Alerts** | Merah = ada masalah. Kuning = perlu dicek. Hijau = aman |

### Cara ambil laporan (assign ke diri sendiri)

1. Buka `kita.balizero.com/lkpm`
2. Cari baris yang kolom "Assigned to" masih kosong
3. Klik dropdown di kolom itu
4. Pilih nama kamu
5. Sekarang itu tanggung jawab kamu

### Cara lihat OSS credentials

1. Di baris perusahaan yang kamu mau
2. Klik tombol **"Show"** di kolom OSS
3. Muncul username + password
4. Klik icon 📋 untuk copy

---

## 3. Cara submit laporan ke OSS

### Step 1: Buka halaman detail

Klik nama perusahaan di tabel → masuk ke halaman detail.
Di sini ada **Ready Pack** — semua angka yang perlu kamu masukkan ke OSS.

### Step 2: Login ke OSS

1. Buka `oss.go.id`
2. Masukkan username + password (dari workspace, tombol "Show")
3. Login

### Step 3: Isi data di OSS

Copy-paste angka dari Ready Pack ke form OSS:
- Realisasi Investasi (per kategori)
- Data Tenaga Kerja (TKI/TKA)
- Pendapatan

### Step 4: Submit di OSS

Klik submit di website OSS. **Catat nomor receipt** yang keluar.

### Step 5: Tandai di workspace

1. Balik ke `kita.balizero.com/lkpm`
2. Klik **"Mark Submitted"** di baris perusahaan itu
3. Masukkan nomor receipt
4. Selesai ✅
