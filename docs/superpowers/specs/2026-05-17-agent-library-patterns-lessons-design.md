`_generate-inventory.py`, ~27KB) is the catalog entry point. The 2026-05-14
inventory spec explicitly references `02-patterns.md` and `03-lessons.md` as

generated inventory as curated companions: the inventory tells you WHAT
agents/crons/skills exist; patterns and lessons tell you HOW to use them and
WHY some approaches work better than others.

### 5 Meta-patterns (emergent cross-source synthesis)

| Meta-pattern                               | Lessons that support it | Insight                                                                                                                                                                                      |

Each meta-pattern: 1 paragraph (~80 words) describing the cross-cutting
insight, explicitly flagged as "synthesis" (NOT a quote from any single

## Sourcing & verification protocol (anti-hallucination)

### Hard rule

Every `file:line` citation in 02 and every `path` in 03 MUST be Read in
THIS turn (writing-time). Context buffer is NOT authoritative.
Reference: `~/.claude/projects/-Users-nuzantara/memory/lessons_hallucinating_tool_output_is_diabolical.md`.

### Protocol for 02-patterns.md (9 schede)

| Step                           | Tool                                 | Verification                  |
| ------------------------------ | ------------------------------------ | ----------------------------- |
| 1. Open primary source         | `Read <path>`                        | line range visible in output  |
| 2. Extract example line        | `Grep -n` or Read with offset        | exact line number confirmed   |
| 3. Cross-check correlated scar | `Grep "<keyword>" cicatrix-scars.md` | entry exists                  |
| 4. Write the schede            | `Edit` on `02-patterns.md`           | —                             |
| 5. Post-write verify           | `ls -la` + `wc -l`                   | bytes/lines match expectation |

### Protocol for 03-lessons.md (20 entries)

| Step                                  | Tool                    | Verification            |
| ------------------------------------- | ----------------------- | ----------------------- |
| 1. Per memory file                    | `Read` (limit 30 righe) | first paragraph visible |
| 2. Extract 2-line synthesis + trigger | mental synthesis        | —                       |
| 3. Verify path exists                 | `ls memory/<file>`      | exists                  |
| 4. Cross-link pattern correlato       | mental map              | —                       |

### Protocol for 5 meta-patterns

NOT in any single source → I write synthesis from 2+ entries.
Citation = list of supporting entries (e.g. "supported by #7, #13, #8").
Explicitly flagged as "synthesis" in each meta-pattern paragraph.

### What I do NOT do

- Cite `file:line` "remembered" without Read in this turn
- Invent pattern names not documented (e.g. no "Reflexion-Voyager hybrid"
  unless 2+ written references found)
- Mix cicatrix with lessons memory (separate sources, cite what was opened)
