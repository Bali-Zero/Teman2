## Context

Part of the "agent-library" initiative: build a curated, queryable personal
library of agents, patterns, and lessons. `01-inventory.md` is the catalog
entry point — a machine-generated operational snapshot of every agent in the
stack.

## Decisions locked

| Decision | Choice | Rationale |
|---|---|---|
| Location | `~/Desktop/nuzantara/agent-library/` top-level | Curated library separate from raw research (`research/agent-craft/`) |
| Audience | Claude as operational catalog | Fast lookup, not linear reading |
| Scope | 16 Claude subagents + 3 cross-tool + cron-agents (agentic/infra split) + skills | Full stack snapshot |
| Freshness | Artifact generated by script, never hand-edited | Hand-editing drifts immediately; regeneration is ~5s |
| Cron depth | LaunchD metadata + script path only | No script content analysis (YAGNI, privacy) |
| Format | Approach A: flat sectioned markdown | Single file with Quick index + 4 sections + Drift warnings |

## Script logic (_generate-inventory.py)

6-step flow, no network/LLM/secrets required:

1. **SCAN subagents** — glob `~/.claude/agents/*.yaml` (Claude Code subagents)
   and `~/.claude/projects/*/agents/*.yaml` (project-scoped), parse YAML
   frontmatter defensively (unknown fields ignored, malformed = skip + warn)

2. **SCAN cross-tool** — glob `.cursor/rules/**/*.mdc`, `.gemini/skills/**/*.md`

3. **SCAN crons** — `launchctl list | grep com.balizero` → get labels,
   then per label: `plutil -convert json -o - ~/Library/LaunchAgents/<label>.plist`
   → extract `StartInterval`/`StartCalendarInterval`, `Program`/`ProgramArguments[0]`.
   Classify agentic/infra via keyword regex on script content header comment
   (`claude`, `gemini`, `nlm`, `codex`, `deepseek`, `ollama` → agentic; else infra).
   `not-loaded` state = neutral, not error.

4. **SCAN skills** — glob `~/.claude/skills/**/*.md`, extract `name`/`description`
   from frontmatter

5. **DRIFT checks**:
   - YAML missing → warn
   - Plist `ProgramArguments[0]` path not on disk → orphaned
   - Agent file `mtime` > 90d + no git activity → stale

6. **RENDER** — write `agent-library/01-inventory.md` with timestamp header

---

## YAGNI exclusions

- No `--json` output flag (not needed now)
- No script content analysis beyond header comment (privacy, complexity)
- No git history traversal (mtime heuristic sufficient)
- No diffing against previous inventory (out of scope)
- No network calls, no LLM, no secrets

## Testing

```bash
# Smoke: script runs without errors
python3 agent-library/_generate-inventory.py --dry-run

# Output check: file written with content
python3 agent-library/_generate-inventory.py && wc -l agent-library/01-inventory.md

# Drift section present
grep -c "Drift" agent-library/01-inventory.md
```

No separate unit tests — the script is pure I/O; smoke covers the contract.

## Regen trigger

- `make inventory` (Makefile alias, ~5s)
- Optional: pre-commit hook when `~/.claude/agents/*.yaml` or
  `Library/LaunchAgents/com.balizero.*.plist` are staged

No autonomous cron — avoids commit noise. Human decides when to regen.
