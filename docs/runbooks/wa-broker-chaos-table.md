# WA broker — chaos table (spec §7 deliverable)

> BOT-V4 S2 PR-6. Spec: `research/operations/2026-08-19-bot-chatgpt-provider-broker-spec.md`
> §7: _"S2's deliverable is the full per-case table — initial state, fault point, expected
> final state, max time-to-converge for every row."_ This file is that table.
>
> **How to read "pinned by":** a row is either TEST-pinned (the named suite drives the fault
> and asserts the final state) or DESIGN-argued (the convergence follows from an additive
> schema / protocol property; no single test drives it end-to-end — declared, not hidden).
> Timing constants referenced by name, one SSOT in
> `backend/services/integrations/wa_broker.py`: `DEFAULT_DEADLINE_S=45` (env
> `WA_BROKER_DEADLINE_S`, widened 2026-08-28 from 15 — see the constant's own comment for
> the measured incident), `lease_ttl_seconds()=DEFAULT_DEADLINE_S+LEASE_TTL_MARGIN_S=50` at
> default (DERIVED from the deadline as of the same fix — never a bare constant, so raising
> the deadline can no longer invert the deadline/lease ordering), `DEFAULT_ABSENT_AFTER_S=45`
> (env `WA_BROKER_ABSENT_AFTER_S`).

## Invariants every row must preserve (spec §7)

- **≤1 accepted generation per job** — the fence token + completion-key replay path.
- **The worker INITIATES ≤1 send per row** — the pre-existing Graph ack window stays
  outside this spec's claim (§2).
- **Fail-off within SLO** — a codex-lane fault ends in a Gemini regeneration or a typed
  parked retry, never a silent stall.

## Residual, declared

- Rows 1 and 9 carry design-argued halves (machine reboot, dual-version run) — nothing in CI
  boots a Mac or runs two deploy images concurrently. Their server-side halves are the same
  reaper/CAS paths rows 3-5 pin with tests.
- Row 5's "orphaned grandchildren of a SIGKILLed daemon" (not of a timeout) die on their own
  schedule; nothing waits on them. The group-kill + bounded reap covers every path where OUR
  code survives to clean up.
- The §4.3 canary/persistence SWEEP (enumerated-paths property) is S3a's pass set, not this
  table — this table proves lease/exec/completion convergence only.
