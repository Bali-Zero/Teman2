## Method

- **Classify:** 35 shards of ≤20 rows, one read-only auditor each (cloud container: shallow clone, no Mac/Fly/prod reach), every verdict backed by a command run in that turn.
- **Verify (generator ≠ grader):** every CURED/OBSOLETE claim (166) was re-derived by two independent adversarial reviewers on a different model — _reproduce_ (re-run the proof, look for what it misses) and _W81-scope_ (is any part of the arming live/machine/prod state that repo evidence cannot prove?). A row is closed only when **both** confirm; a refuted claim takes the refuter's verdict.
- **Close:** confirmed rows are flipped in place `- opened` → `- closed` with the refuters' proof appended (the ledger's own convention; `check-ledger-no-silent-loss` will list them as intentional closures).
