`MANDATE_BUDGET_OFF=1` disables the added reservation gate for operator recovery; it does not disable sandbox enforcement or the child depth rule. Existing Claude kill switches remain honored. Codex `needs_attention` never reopens normal tools after a context boundary.

## Installation boundary

Codex installs three source files per CODEX_HOME and eight trusted native hook definitions. Existing hooks and credentials stay in place. Each profile has an update backup and a source-hash manifest.

Claude installs `child_workflow.py` and the exact shared `mandate_budget.py` beside the current hooks. Only the existing PreToolUse context handler and SubagentStop handler are routed through this wrapper; SubagentStart adds the child contract. The wrapper invokes the exact installed context guard for the parent. The original context guard, stop guard and orchestrate gate remain byte-identical, verified before/after installation. Their existing per-host differences are not overwritten with this worktree's older repo copies. No SessionStart contract injection is added.

A profile with no previous context/stop hook receives these specific handlers pointing at the shared primary hook directory. Settings symlinks remain symlinks. The installer validates all target commands and source syntax before writes; rollback restores that profile's backed-up settings and the two adapter files, without replacing any legacy guard.

## Review and tests

The first Fable implementation review rejected installation and identified fail-open context recovery, session-lifetime budget coupling and false UNKNOWN stop blocks. These were corrected before the canary. Followup accounting, nested delegation, an owned-process EOF race, checkpoint initialization and resumed-child stop markers were also corrected. The final wrapper design avoids changing the legacy guard files.

Regression checks cover first native fork metadata, inherited-history exclusion, parent/child state isolation, repeated denials, bounded stop reminders, exact continuation acknowledgement, zero-tool readers, shell/MCP mutation classification, expired unstarted reservations, strict total budgets, same-child resume accounting, deadline/cancel/EOF cleanup and narrow settings routing. Native probes independently read the fixture after a real child returns. Secondary profiles require separate configuration/hash validation; a primary-profile model probe does not prove a secondary credential works.
