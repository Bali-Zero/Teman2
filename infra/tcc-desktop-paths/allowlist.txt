# infra/tcc-desktop-paths/allowlist.txt

# Declared exceptions to the W84 TCC-Desktop-path sweep/lint (scar #1 HOME-fork,
# superscar family). Consumed by BOTH:
#   scripts/tcc_migrate_desktop_paths.py --git-scope --exclude-file  (one-time sweep,
#     never touches these)
#   scripts/lint_tcc_desktop_paths.py --check                        (permanent CI
#     guard, never flags these as violations)
#
# Every entry here is a DELIBERATE decision, not an oversight (scar #3 discipline:
# an exception list makes exclusions declared, not implicit). Two classes:
#
#   1. HISTORICAL RECORD — research/, docs/superpowers/, docs/audits/, dated
#      plan/session/audit/report files elsewhere, and .claude/rules/cicatrix-*.md.
#      These describe what WAS true at a point in time (a scar, a dated research
#      capture, a post-mortem, a FROZEN snapshot). Rewriting the path inside them
#      would falsify the historical record they exist to preserve. Per CLAUDE.md
#      §15, research/ is explicitly ad-hoc/never-promoted — the entire tree is
#      historical by convention, not just the .md reports.
#
#   2. GUARD-TEST CORPUS — infra/claude-hooks/test_tilde_target_resolver.py and
#      test_w84_strip_noise_cross_line.py. The worktree-isolation hook (superscar
#      #3, 6 prior over/under-match recidives — W83/W84/W85/W91/W92/W94) has its
#      OWN guilt/innocence tests keyed on recognizing `~/Desktop/nuzantara` /
#      `$HOME/Desktop/nuzantara` shell notations as equivalent to the main
#      checkout. That recognition remains load-bearing AFTER the repo move: the
#      compat symlink `~/Desktop/nuzantara -> ~/nuzantara` still exists (COMPAT
#      ONLY per the migration brief — reading it still traverses Desktop), so a
#      session can still type the old notation and the hook must still catch it.
#      Rewriting these fixtures would silently narrow coverage of a real,
#      still-live attack surface. test_w84_strip_noise_cross_line.py additionally
#      reproduces the EXACT historical trigger string from the 2026-06-16
#      incident — changing it would blur what is being regression-tested.
#
# All OTHER test files with a Desktop/nuzantara literal were inspected by hand
# (2026-07-16 TCC repo-paths PR) and found to use it as incidental placeholder/
# example data disconnected from the guard logic under test (verified against
# each guard's actual matching code) — those were swept normally, not excluded.
#
# infra/home-fork/declared-pairs.json is class 1 despite not living under
# research/docs/superpowers/audits: its ONLY hit is a free-text "_note" field
# narrating a 2026-07-14 fix ("...fixed to REPO_ROOT-aware ($HOME/Desktop/
# nuzantara default)...") — a historical description of what the default WAS
# on that date, not a live "live"/"repo" pair value the lint compares against.
# Sweeping it would misattribute today's (2026-07-16) path convention to a
# fix that landed two days earlier.
#
#   3. THE TOOLS' OWN SOURCE/TESTS — scripts/tcc_migrate_desktop_paths.py,
#      scripts/lint_tcc_desktop_paths.py, and their test files
#      (scripts/tests/test_tcc_migrate_desktop_paths.py,
#      scripts/tests/test_lint_tcc_desktop_paths.py). These reference
#      `Desktop/nuzantara` as SUBJECT MATTER — the regex pattern source, its
#      docstring rationale/examples, and guilt-case test fixtures literally
#      constructing that string to prove detection works — never as a path
#      the tool itself depends on. Self-referential by construction: any tool
#      whose job is detecting a literal string will contain that literal in
#      its own source. Sweeping these would either corrupt the regex (turning
#      the detector into a no-op) or invert the guilt tests (making them
#      assert on the wrong string). Same reasoning extends to this file
#      itself (this documentation talks ABOUT the pattern) and to
#      .github/workflows/immune-enforcement.yml's step name/comments for the
#      lint step this PR adds.
#
