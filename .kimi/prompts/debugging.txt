KIMI DEBUGGING PROMPT
=====================

You are debugging an issue in the Nuzantara system. Follow systematic debugging.

DEBUGGING FRAMEWORK
-------------------

### 1. INFORMATION GATHERING
- [ ] What is the exact error message?
- [ ] When did it start occurring?
- [ ] What changed recently?
- [ ] Which component is affected?
- [ ] Can you reproduce it?

### 2. SYSTEM STATE CHECK
Run these diagnostics:
- [ ] `check_system_health()` - Overall health
- [ ] `get_collection_stats()` - Qdrant status
- [ ] `get_fly_logs(lines=100, filter_str="ERROR")` - Recent errors
- [ ] `check_deployment_readiness()` - Pre-deploy checks

### 3. CODE ANALYSIS
- [ ] Search for error in codebase: `search_codebase("error_pattern")`
- [ ] Check recent changes: `git log --oneline -10`
- [ ] Review related test files
- [ ] Verify imports not removed (rogue AI check)

### 4. COMMON ISSUES CHECKLIST

#### Import Errors
```bash
# Error: ImportError: attempted relative import
# Fix: Activate venv + PYTHONPATH
cd apps/backend-rag && source .venv/bin/activate
PYTHONPATH=. python -m backend.scripts.script_name
```

#### Embedding Model Mismatch
```bash
curl -s https://nuzantara-rag.fly.dev/health | jq '.embeddings.model'
# Must be: "text-embedding-3-small"
```

#### Database Connection Issues
```bash
# Check fly logs
fly logs -a nuzantara-rag | grep -i "database\|postgres"
```

#### Rogue AI Changes
```bash
# Check for removed imports (common: Any, Optional)
git diff HEAD~5 -- apps/backend-rag/backend/ | grep "^-from typing"
```

### 5. ISOLATION TESTING
- [ ] Does it work locally?
- [ ] Does it work in staging?
- [ ] Is it environment-specific?
- [ ] Is it data-specific?

### 6. RESOLUTION
Once root cause identified:
1. Fix the issue
2. Add test to prevent regression
3. Verify fix with tests
4. Document if needed

DEBUGGING OUTPUT FORMAT
-----------------------
```markdown
## Debugging Report: [Issue Title]

### Symptoms
[What happened]

### Investigation
1. [Step taken]
2. [Finding]

### Root Cause
[Why it happened]

### Fix Applied
[What was changed]

### Verification
[How confirmed fixed]

### Prevention
[Test/doc added]
```

Remember: "Given enough eyeballs, all bugs are shallow." But first, gather the eyeballs. 👁️
