### Base E33 requirements — VERIFIED

Confirmed live on the E33 index page: USD 130,000 deposit in the applicant's own name at a
state-owned (BUMN) Indonesian bank, **or** USD 1,000,000 in qualifying property; no
sponsor; a 90-day window to place the guarantee after landing; first grant up to 5 years.
Independently corroborated this run by a public slide deck reproducing Permenkumham
22/2023's operative text, which states the same deposit/property figures and the
Rp13,000,000 fee verbatim (slideshare.net/.../permen-22-tahun-2023-pdf).

### E33E / E33F / E33G requirements — VERIFIED

- **E33E**: age 55+ as stated live ("orang asing berusia 55 tahun atau lebih"), USD 50,000
  BUMN deposit + USD 3,000/month passive income, 5-year validity, Rp13,000,000 PNBP.
- **E33F**: no age line stated on the E33F index page itself; USD 3,000/month income only
  (no deposit); a sponsor/guarantor account required on evisa.imigrasi.go.id; 1-year
  validity; Rp7,000,000 PNBP.
- **E33G**: minimum USD 60,000/year in foreign-sourced income (from a company established
  outside Indonesia); 1-year validity; Rp7,000,000 PNBP; online renewal.

## Axis 3 — SOTA UX for visa/eligibility funnels

- **Progressive disclosure** is the dominant pattern for high-consideration wizards: one
  decision per step, advanced/edge-case content held back until it's relevant, chosen via
  research (card sorting/task analysis) rather than guesswork
  (uxpin.com/studio/blog/what-is-progressive-disclosure/ — surfaced via search this run
  with substantive quoted content).
- **Quiz-style funnels outconvert static collection/requirement pages** specifically
  because they pre-resolve the "which product is right for me" question before the visitor
  has to self-diagnose — the same mechanism that makes a band-verdict wizard outperform a
  bare requirements list (fudge.ai/blog/shopify-product-recommendation-quiz/). This is
  direct support for keeping Studio's quiz-first entry rather than reverting to a static
  FAQ-style landing.
- **Band verdicts over numeric scores** is consistent with what the accessibility and
  conversion literature recommends for legal/financial high-stakes contexts: a score
  implies false precision the underlying rules can't support; a band (strong_fit /
  likely_fit / edge_case / not_eligible) is legible and matches how immigration officers
  themselves reason. Bali Zero's Studio already does this — this research confirms it as
  the SOTA choice, not a compromise.
- **Consent/PII deferral**: Boundless.com (fetched this run) front-loads account creation
  ("Choose your path → Create an account → Relax and let us guide you") before any
  qualification signal is shown — this is the pattern Bali Zero's Studio deliberately
  avoids (localStorage-only state, no email until the WhatsApp handoff, no plan URL sent
  server-side). Worth stating this contrast explicitly in marketing copy: "check your
  fit — no account, no email."
- **Accessibility of radio-group wizards**: WCAG 2.2 requires touch targets ≥24×24 CSS
  pixels (Success Criterion 2.5.8) and every related-options group needs
  `fieldset`+`legend` semantic grouping — reported as the single most common failure class
  across audited sites
  (testparty.ai/blog/accessible-radio-groups-html-fast-remediation-large-sites, fetched via
  search this run). This is a concrete, checkable audit item for Studio's existing
  256-test vitest suite, not a redesign.
- **Handoff to a human**: the dominant, higher-consideration-appropriate pattern is a
  short, branch-aware summary handed to a live human channel (WhatsApp/chat) rather than a
  ticket queue or async email — matching Studio's existing ≤6-bullet WhatsApp-handoff
  design.

## Reconciliation against live Bali Zero pricing (2026-08-23)

This table was produced this run by comparing the VERIFIED official PNBP figures above
(each Ditjen Imigrasi index page's own **Biaya** field) against Bali Zero's live production

only.

|---|---|---|---|
| E33 base, 5y | Rp 13,000,000 | Rp 35,000,000 | +22,000,000 |
| E33E senior, 5y offshore | Rp 13,000,000 | Rp 14,000,000 | +1,000,000 |
| E33E senior, 5y onshore | Rp 13,000,000 | Rp 16,000,000 | +3,000,000 |
| E33F senior, 1y offshore | Rp 7,000,000 | Rp 14,000,000 | +7,000,000 |
| E33F senior, 1y onshore | Rp 7,000,000 | Rp 16,000,000 | +9,000,000 |

| E33G remote worker, 1y onshore | Rp 7,000,000 | Rp 14,000,000 | +7,000,000 |

The standing internal composition rule is PNBP + Rp 3,000,000. Measured against that rule,
as a finding and not a recommendation:

- **E33E onshore** (+3,000,000) matches the rule exactly.
- **E33E offshore** (+1,000,000) falls Rp 2,000,000 BELOW the rule.
- **E33F and E33G** sit well above the rule, from +6,000,000 to +9,000,000.
- **E33E (5 years) and E33F (1 year) are sold at the same price** — 14,000,000 offshore /
  16,000,000 onshore — although E33E's own PNBP (Rp13,000,000) is nearly double E33F's
  (Rp7,000,000): the longer, better product carries the thinner margin.
- **Base E33 at Rp 35,000,000** is a deliberate owner ruling of 2026-08-19 (match the
  competitor's public 35M SKU; win on product, not price) and is therefore NOT a deviation
  from the composition rule — it was never intended to follow it.

Any price change is the owner's decision (Legge 5) — this document records the arithmetic,
it does not propose a new price.
