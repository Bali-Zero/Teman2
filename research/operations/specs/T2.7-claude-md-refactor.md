## Problem

## Selected approach (v3, post 3-LLM panel)

**NOT** sub-CLAUDE.md move (Codex+DeepSeek convergent: sub-CLAUDE is cwd-conditional, NOT system prompt auto-injected — same failure mode as "See X.md" pointer pattern that was rejected in v1).

**NOT** pure pointer pattern (panel REJECT v1: extracted instructions become invisible because LLM won't proactively read referenced docs).

**YES**: **Binary split** within root CLAUDE.md:

- **Part A — Agent Directives**: instruction-critical, every session (§1-7)
- **Part B — Project Invariants**: code/data correctness (§8-15)

Compress verbose blocks to 1-liners, delete derivable inventory tables, route hyper-local detail (ASCII trees, code patterns) to `apps/backend-rag/CLAUDE.md` (which auto-loads when cwd in subtree — load-bearing for backend work), keep cross-stack invariants verbatim in root.
