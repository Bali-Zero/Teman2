# L5.1 — Agent Worktree Enforcement

## TL;DR

L1+L2+L3+L4 sono **opt-in**. Senza enforcement, l'adoption naturale è ~0%. L5.1 chiude il
gap con:

1. **PreToolUse hook** `worktree_isolation.py` — blocca `Bash(git checkout/stash/reset/merge/...)` quando `cwd == REPO_ROOT` E `cwd != .worktrees/*` E `cwd != /Users/nuzantara/Desktop/nuzantara-*-2026-*` (escape pattern per worktree esterni manuali documentati).
2. **SessionStart hook** `agent_workspace_setup.py` — propone worktree create se cwd è main checkout e detect-agent.
3. **Skill** `agent-session-discipline` invocabile via `/agent-start <lane> <task-id>`.
4. **AGENTS.md patch** — parità con CLAUDE.md per Codex CLI awareness.
5. **Backward compat** — escape `AGENT_WORKTREE_ENFORCEMENT=false` + transcript intent markers (`emergency:`, `hotfix:`, `cicatrix-fix:`).

**Kill switch globale**: `AGENT_WORKTREE_ENFORCEMENT=false`.

**Wall-time stimato**: 2h implementation + 30min test empirico + 30min Antonello review = ~3h.

## 2. Architecture

### 2.1 PreToolUse hook `worktree_isolation.py`

**Path**: `~/.claude/hooks/worktree_isolation.py` (gitignored, user-global).
**Registered in**: `~/.claude/settings.json` under `hooks.PreToolUse[matcher="Bash"]`.

**Logic**:

```python
#!/usr/bin/env python3
"""PreToolUse hook (Bash) — block dangerous git ops in main checkout.

Closes Gap G1 from L5 spec: L1 worktree broker is opt-in, no enforcement.
This hook makes git ops in main REPO_ROOT a deliberate, audited decision.

Blocked patterns (only when cwd is REPO_ROOT, not in .worktrees/* or escape-listed):
- git checkout (branch switch)
- git stash (likely sibling-orphan creator)
- git reset --hard
- git merge
- git rebase
- git pull (could pull onto wrong branch)
- git commit -a / git add -A on >5 files (mass-staging suspicion)

Allowed always (no block):
- git status / log / diff / show / branch -l / worktree list (read-only)
- git -C <other-worktree> ... (explicit other-worktree work)
- git add <specific-files> (curated staging)
- git commit -m "..." (single-message commit)
- git push <branch> (we already in a branch checkout)

Escape mechanisms:
- AGENT_WORKTREE_ENFORCEMENT=false → global disable
- Transcript intent markers: 'emergency:', 'hotfix:', 'cicatrix-fix:'
- Last 5KB of transcript checked

Exit code 2 + stderr message → block tool call.
Exit code 0 + no stderr → allow.
"""
import json
import os
import pathlib
import re
import sys


REPO_ROOT = "/Users/nuzantara/Desktop/nuzantara"

# Worktree escape patterns: paths that ARE worktrees (so git ops are OK).
WORKTREE_ALLOW_PATTERNS = [
    r"^/Users/nuzantara/Desktop/nuzantara/\.worktrees/",
    r"^/Users/nuzantara/Desktop/nuzantara-[a-z0-9-]+-2026-",  # external worktree convention
    r"^/Users/nuzantara/Desktop/nuzantara-deploy",  # deploy worktree
    r"^/Users/nuzantara/Desktop/nuzantara-wa-dashboard-",
]

INTENT_MARKERS = [
    "emergency:",
    "hotfix:",
    "cicatrix-fix:",
    "agent_worktree_enforcement",
    "worktree-bypass:",
]

# Blocked git subcommands in REPO_ROOT.
BLOCKED_GIT_RE = re.compile(
    r"^\s*git\s+("
    r"checkout|switch|stash|reset|merge|rebase|pull"
    r"|commit\s+-a|add\s+-A|add\s+\."
    r")\b"
)


def main():
    if os.environ.get("AGENT_WORKTREE_ENFORCEMENT", "true").lower() in {"false", "0", "off", "disabled"}:
        sys.exit(0)

    try:
        payload = json.load(sys.stdin)
    except Exception:
        sys.exit(0)

    if payload.get("tool_name") != "Bash":
        sys.exit(0)

    cmd = payload.get("tool_input", {}).get("command", "")
    cwd = payload.get("cwd", "")

    # Only enforce if we're literally in REPO_ROOT (not in a worktree).
    if cwd != REPO_ROOT:
        sys.exit(0)

    # Check if cwd matches an allowed worktree pattern (defense-in-depth).
    for pattern in WORKTREE_ALLOW_PATTERNS:
        if re.match(pattern, cwd):
            sys.exit(0)

    # Check transcript intent markers (last 5KB).
    transcript_path = payload.get("transcript_path", "")
    if transcript_path:
        try:
            text = pathlib.Path(transcript_path).read_text(errors="ignore")
            recent = text[-5_000:].lower()
            if any(m in recent for m in INTENT_MARKERS):
                sys.exit(0)
        except Exception:
            pass

    # Match the command against blocked patterns.
    if not BLOCKED_GIT_RE.search(cmd):
        sys.exit(0)

    # Block.
    sys.stderr.write(
        f"WORKTREE ISOLATION VIOLATION\n"
        f"  cwd: {cwd}\n"
        f"  command: {cmd[:200]}\n\n"
        f"Reason: dangerous git op in main checkout would race with {len_alive_agents()} alive AI processes.\n\n"
        f"Resolution:\n"
        f"  1. Create dedicated worktree:\n"
        f"     python scripts/agent_start.py --lane <lane> --task-id <task-id>\n"
        f"     cd <output-path>\n"
        f"  2. Then retry the git op there.\n\n"
        f"Emergency escape (use sparingly):\n"
        f"  - AGENT_WORKTREE_ENFORCEMENT=false (env var)\n"
        f"  - Or add 'emergency:' / 'hotfix:' / 'cicatrix-fix:' in your last message\n\n"
        f"See: docs/runbooks/agent-worktree-broker.md\n"
    )
    sys.exit(2)


def len_alive_agents() -> int:
    """Best-effort count of alive Claude/Codex/Gemini processes."""
    try:
        import subprocess
        result = subprocess.run(
            ["pgrep", "-f", "-c", "claude|codex|agy"],
            capture_output=True, text=True, timeout=2,
        )
        return int(result.stdout.strip() or 0)
    except Exception:
        return 0


if __name__ == "__main__":
    main()
```

### 2.2 SessionStart hook `agent_workspace_setup.py`

**Path**: `~/.claude/hooks/agent_workspace_setup.py`.
**Registered in**: `~/.claude/settings.json` under `hooks.SessionStart`.

**Logic**:

````python
#!/usr/bin/env python3
"""SessionStart hook — propose worktree create if cwd is main checkout.

Output to stdout = appended to session context as system reminder.
Output to stderr = ignored by Claude Code.

Does NOT auto-create (operator agency). Just surfaces:
- "You are in main checkout"
- "5 other AI processes alive here"
- "Recommended: python scripts/agent_start.py --lane X --task-id Y"
"""
import os
import subprocess
import sys
from pathlib import Path

REPO_ROOT = "/Users/nuzantara/Desktop/nuzantara"


def main():
    if os.environ.get("AGENT_WORKTREE_ENFORCEMENT", "true").lower() in {"false", "0", "off", "disabled"}:
        sys.exit(0)

    cwd = os.getcwd()
    if cwd != REPO_ROOT:
        # In a worktree → all good
        sys.exit(0)

    # Detect alive agents.
    try:
        result = subprocess.run(
            ["pgrep", "-f", "-c", "claude|codex|agy"],
            capture_output=True, text=True, timeout=2,
        )
        n_alive = int(result.stdout.strip() or 0)
    except Exception:
        n_alive = -1

    # Count stash sibling-orphan last 24h.
    try:
        result = subprocess.run(
            ["git", "stash", "list"],
            cwd=REPO_ROOT, capture_output=True, text=True, timeout=5,
        )
        n_stash = sum(1 for line in result.stdout.splitlines() if "sibling-orphan" in line)
    except Exception:
        n_stash = -1

    msg = f"""## Agent Workspace Discipline (L5.1)

You are in the SHARED main checkout: `{cwd}`
Alive AI processes (claude+codex+agy): {n_alive}
Sibling-orphan stash count: {n_stash}

**Strongly recommended** before any git mutation: create a dedicated worktree:

```bash
python scripts/agent_start.py --lane <wr2|infra|backend-rag|...> --task-id <slug>
cd <output-path>
# now you have an isolated worktree, branch agent/<host>/<lane>/<task-id>
````

PreToolUse hook `worktree_isolation.py` will block dangerous git ops here.
Escape: `AGENT_WORKTREE_ENFORCEMENT=false` or add 'emergency:' in message.

See: docs/runbooks/agent-worktree-broker.md
"""
print(msg)
sys.exit(0)

if **name** == "**main**":
main()


**Body** (skeleton):

````markdown
# Agent Session Discipline

## When to invoke

- User asks "implement X" / "fix Y" / "add feature Z"
- About to write code that will be committed
- After session start in main checkout
- When seeing 5+ alive AI processes warning

## What to do

1. **Pick a lane** from L1 allowlist: `wr2 wr3 infra docs db cicatrix-fix mouth intel cell organism mata-garuda backend-rag frontend ops`
2. **Generate task-id**: short kebab-case, ~3 words max (e.g. `kg-bridge-s16`, `drive-metadata`, `workflow-l5-1`)
3. **Create worktree**:
   ```bash
   python scripts/agent_start.py --lane <lane> --task-id <task-id> --ttl-min 120
   ```
````

4. **Note the output path** (`/Users/nuzantara/Desktop/nuzantara/.worktrees/<lane>-<task-id>/`)
5. **All subsequent `git -C <path> ...` ops** use that path
6. **All `Read`/`Write`/`Edit` file paths** start with the worktree path
7. **At session end**: commit + push + open PR + `--release` worktree

## Worktree path discipline

Bash tool resets cwd to harness default after each call. To work in worktree:

- Use `git -C /path/to/worktree ...` for git commands
- Use absolute paths for Read/Write/Edit
- Don't try to `cd` and persist — it won't persist
- Verify with `git -C /path status --short` periodically

## Backward compat

If session already started in main and you've already written files:

1. `git stash push -u -m "pre-isolation-<task>"` to preserve WIP
2. Run `agent_start.py` to create worktree
3. `git stash pop` inside worktree (may need to git stash apply + add files manually)

````
### 2.5 Backward compat strategy

**Existing live sessions** (5 Claude + 2 Codex in main checkout right now):
- Cannot retroactively isolate them
- L5.1 hook only takes effect AFTER each session restart (settings.json reload)
- Recommendation: Antonello terminates them all manually after PR L5.1 merge, restarts cleanly

**Existing stash sibling-orphan** (32+):
- Not in scope of L5.1 enforcement
- Cleanup task tracked separately (L5.7 recovery runbook)

**Auto-merge whitelist** (`docs/auto-sync-*`, `dependabot/*`, `chore/fmt-*` from L3):
- Bypass enforcement via env injection in cron/CI context
- L5.1 hooks check `os.environ.get("AGENT_WORKTREE_ENFORCEMENT", "true")` first
- Cron sets `AGENT_WORKTREE_ENFORCEMENT=false` in plist EnvironmentVariables

**Stop hook interaction**:
- `stop_verify.py` (T2.6) still catches dirty state at session end
- L5.1 PRE-tool hook prevents creation of dirty state in main
- Layered defense: prevention (L5.1) + detection (T2.6)
````
