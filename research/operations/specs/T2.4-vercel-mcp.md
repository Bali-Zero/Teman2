# T2.4 — Install Vercel MCP

## Problem

Sessione b2f02a45 oggi: ho istruito Antonello "vai a Vercel → Ignored Build Step → click Disable" 3 volte. Avoidable delegation diretto: esiste `mcp__claude_ai_Vercel__*` (claude.ai marketplace) ma NON era attivo in mio toolset, e Vercel MCP HTTP transport (`https://mcp.vercel.com`) era invisibile.

Install Vercel MCP HTTP transport = chiude direttamente la regression del 2026-05-21.

## Context

Vercel MCP HTTP transport (`https://mcp.vercel.com`):

- Deploy trigger
- Build logs query
- Deployment list
- Settings reads (Ignored Build Step verifica)
- Domain management

Source: [Vercel MCP](https://vercel.com/docs/agent-resources/vercel-mcp), Codex Part 2 #5.

OAuth required: Vercel team auth. Antonello team: `nuzantara-2026`.

## Acceptance criteria

- [ ] `vercel` MCP server registered HTTP transport
- [ ] OAuth completato Antonello → Vercel team
- [ ] Tool list include `mcp__vercel__deploy*`, `mcp__vercel__list_deployments`, `mcp__vercel__get_deployment_build_logs`
- [ ] Test: `mcp__vercel__list_deployments` per `mouth` project → returns last 10 deploys
- [ ] Documenta "use Vercel MCP first, never instruct Antonello to navigate Vercel UI"

## Implementation steps

### Step 1 — Add HTTP MCP

```bash
claude mcp add --transport http vercel https://mcp.vercel.com
```

### Step 2 — OAuth completion

Antonello completa OAuth via browser quando MCP attiva (`/mcp` interactive). Auto-flow:

1. Hook `claude_ai_Vercel__authenticate` returns URL
2. Antonello browser opens
3. Vercel auth + grant claude.ai access
4. Token persisted in claude.ai backend (transparent to operator)

### Step 3 — Restart + verify

```
/mcp  # interactive
# Expected: vercel listed as authenticated
```

### Step 4 — Test deploy list

```
mcp__vercel__list_deployments project="mouth" limit=10
```

Expected: JSON array di 10 ultimi deploy con status, branch, commit_sha, url.

### Step 5 — Test settings query (chiude regression 05-21)

```
mcp__vercel__get_project project="mouth"
```

Expected: project settings JSON include `ignoredBuildStep` field. Verifica corrente value.

### Step 6 — Update memory rule

Update `T1.3 feedback_orchestration_first.md` trigger #6:

```markdown

```
