# T2.2 — Install Playwright MCP

## Problem

Diagnosi 2026-05-21: avoidable delegation cluster su Vercel/GA4 UI flow (8/23 hit). Avevo istruito Antonello "vai a Vercel → Settings → Ignored Build Step → click Disable" 3 volte invece di usare browser automation. Vercel MCP esiste ma non espone tutti i settings; Playwright MCP è browser-generic e chiude lo stesso gap.

## Context

Playwright MCP (`@playwright/mcp@latest`):

- Browser automation (Chromium/Firefox/WebKit)
- Click, fill, screenshot, navigate
- Supporta OAuth flows persistenti via storage state
- Already used by Nuzantara via local Playwright (apps/wa-mirror, apps/nuzantara-mcp-browser)

Source: [Playwright MCP](https://playwright.dev/docs/getting-started-mcp), Nimbalyz #5, Codex arming Part 2 #3.

**Decision**: Playwright MCP è additivo a `nuzantara-mcp-browser` (custom MCP esistente). Nuzantara-mcp-browser usa stealth patches (webdriver, chrome.runtime, navigator). Playwright MCP è "stock" — utile per task non-stealth (dashboard di proprietà nostra, no anti-bot).

## Acceptance criteria

- [ ] `@playwright/mcp` registrato in `.mcp.json` o `~/.claude.json`
- [ ] Tool list include `mcp__playwright__*` (browser_navigate, browser_click, browser_snapshot, ecc.)
- [ ] Test: navigate to `https://kita.balizero.com` e screenshot OK
- [ ] Documenta scope d'uso vs `nuzantara-mcp-browser` (stealth) in CLAUDE.md o memory

```json
}
```

```bash
# Browser MCP — 2 server attivi, scope distinto

## `mcp__playwright__*` (stock @playwright/mcp)

Use per:
- Dashboard PROPRIETARI Bali Zero (kita.balizero.com, my.balizero.com, prime.balizero.com, ecc.)
- Vercel/GA4/Stripe/GitHub Actions/Cloudflare admin UI (auth interactive OK)
- Screenshot QA after deploy
- Test E2E delle nostre app
- OAuth flow Drive/Workspace (persistente con storage state)

Tool prefix: `mcp__playwright__browser_*`

## `mcp__nuzantara-browser__*` (custom stealth)

Use per:
- Scraping anti-bot (Instagram, LinkedIn pubblico, FB pubblico)
- Competitor monitoring (Lets Move Indonesia, Emerhub, Flado)
- OSINT browsing where stealth patches needed
- Cross-domain auth chains (avoid detection)

Tool prefix: `mcp__nuzantara-browser__*`

## Tie-breaker

Sito di proprietà Bali Zero → Playwright stock (più semplice)
Sito esterno con anti-bot → nuzantara-browser stealth
Sito esterno senza anti-bot → Playwright stock

**Anti-pattern**: usare nuzantara-browser per kita.balizero.com (overkill, stealth non serve).
EOF
```
