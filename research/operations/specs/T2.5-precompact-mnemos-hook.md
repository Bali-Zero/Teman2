# T2.5 — PreCompact "Mnemos" hook

## Problem

Auto-compact (Claude Code interna) interviene quando context approaches 95%. Senza preparazione strutturata, comprime in modo lossy: detail crucial scartato (regulatory citations, file path specifici, command verbatim).

Nuzantara ha `precompact-transcript-backup.sh` esistente (tars JSONL transcript for archeology) ma NON pattern "Mnemos" = structured handoff dei fatti load-bearing.

Source NB-AGENTS [28,29]:

> _"When context hits ~95%, compaction fires. To prevent Claude from losing critical facts (amnesia), a PreCompact hook writes a task-state checkpoint to disk. A PostCompact (or PreToolUse) hook re-injects that exact checkpoint into the fresh context."_

## Context

Schema "Mnemos" checkpoint:

- **objective**: cosa stiamo cercando di fare (1-2 sentences)
- **changed**: file path modificati this session
- **verified**: comandi che hanno PASSED (verbatim)
- **risks**: dirty worktree, secrets exposed, partial deploys, ecc.
- **next**: action immediate post-compact (1-2 step)

Output file: `~/.claude/state/precompact-handoff-{session_id}.json`. Letto da SessionStart hook (re-injection) o PreToolUse next session.

## Design

Hook in Python (più strutturato di Bash per JSON). Strategy:

1. Parse last 20KB transcript per detect: file paths edited, commands run, errors, pending TODOs
2. Genera structured handoff JSON
3. Write to disk

Re-injection separato (T3.5 SessionStart o T1.1 dispatch_nudge extension).

## Acceptance criteria

- [ ] `~/.claude/hooks/precompact_mnemos.py` exists
- [ ] Wire in `settings.json` `PreCompact` (additivo, no rimozione `precompact-transcript-backup.sh`)
- [ ] Test: trigger compaction mock, verifica file written con schema valido
- [ ] `~/.claude/state/` directory creata se non esiste
- [ ] Handoff JSON ≤ 4KB per session

### Step 2 — Crea hook file

Path: `~/.claude/hooks/precompact_mnemos.py`

```python
#!/usr/bin/env python3
"""PreCompact hook — structured handoff before context loss.

Parses recent transcript, extracts:
- objective (best-effort from user prompts)
- changed files (Edit/Write tool calls)
- verified commands (Bash exit=0)
- risks (dirty git, exposed secrets, partial deploys)
- next action (TODO from TaskUpdate or end-of-msg)

Writes JSON to ~/.claude/state/precompact-handoff-{session_id}.json
Reference: research/operations/specs/T2.5-precompact-mnemos-hook.md
"""
import json
import pathlib
import re
import sys
import datetime

STATE_DIR = pathlib.Path.home() / ".claude" / "state"
STATE_DIR.mkdir(parents=True, exist_ok=True)

def parse_transcript_jsonl(path):
    """Parse JSONL transcript line-by-line, pairing tool_use with tool_result.

    GPT-5.5 panel B5 fix: structured parsing instead of regex over text blob.
    Distinguishes:
    - attempted_commands: all Bash commands attempted (including failed)
    - successful_commands: ONLY those with exit_code=0 in tool_result
    - changed_files: file_paths in Edit/Write tool_use, paired with success
    """
    attempted = []
    successful = []
    changed_attempted = []
    changed_successful = []
    user_prompts_last = []
    in_progress_subjects = []
    risks = set()

    # Pending tool_uses indexed by id
    pending = {}

    try:
        for line in path.read_text(errors="ignore").splitlines()[-2000:]:  # last 2000 events
            try:
                evt = json.loads(line)
            except json.JSONDecodeError:
                continue

            content = evt.get("content") or evt.get("message", {}).get("content")
            role = evt.get("role") or evt.get("message", {}).get("role", "")

            # User prompt → objective
            if role == "user" and isinstance(content, str):
                if 20 < len(content) < 500:
                    user_prompts_last.append(content)

            # Walk content array if structured
            if isinstance(content, list):
                for item in content:
                    if not isinstance(item, dict):
                        continue
                    itype = item.get("type")

                    if itype == "tool_use":
                        tid = item.get("id", "")
                        tname = item.get("name", "")
                        tinput = item.get("input", {})
                        pending[tid] = {"name": tname, "input": tinput}

                        # Track attempted commands
                        if tname == "Bash":
                            cmd = tinput.get("command", "")
                            if cmd:
                                attempted.append(cmd[:200])

                        # Track attempted file changes
                        if tname in ("Edit", "Write", "MultiEdit", "NotebookEdit"):
                            fp = tinput.get("file_path", "")
                            if fp:
                                changed_attempted.append(fp)

                    elif itype == "tool_result":
                        tid = item.get("tool_use_id", "")
                        is_error = item.get("is_error", False)
                        result_content = item.get("content", "")

                        if tid in pending:
                            tool_use = pending.pop(tid)
                            # Success criteria: not is_error AND content doesn't contain "exit code 1" etc
                            result_str = str(result_content)[:500]
                            failed = (
                                is_error or
                                "exit code 1" in result_str.lower() or
                                "exit code 2" in result_str.lower() or
                                "error:" in result_str.lower()[:100] or
                                "traceback" in result_str.lower()
                            )

                            if not failed:
                                if tool_use["name"] == "Bash":
                                    successful.append(tool_use["input"].get("command", "")[:200])
                                elif tool_use["name"] in ("Edit", "Write", "MultiEdit", "NotebookEdit"):
                                    changed_successful.append(tool_use["input"].get("file_path", ""))

            # TaskUpdate in_progress
            if isinstance(content, list):
                for item in content:
                    if isinstance(item, dict) and item.get("type") == "tool_use" and item.get("name") == "TaskUpdate":
                        if item.get("input", {}).get("status") == "in_progress":
                            subj = item.get("input", {}).get("subject", "")
                            if subj:
                                in_progress_subjects.append(subj)
    except Exception as e:
        return {"parse_error": str(e), "attempted_commands": [], "successful_commands": []}

    # Risks heuristics (still text-based, on actual transcript content)
    text_blob = path.read_text(errors="ignore")[-50_000:]
    if "dirty worktree" in text_blob.lower():
        risks.add("Dirty worktree detected")
    if re.search(r'sk-ant-[a-z0-9]{20,}|sk-[a-zA-Z0-9]{40,}', text_blob):
        risks.add("Potential secret exposure")
    if "fly deploy" in text_blob.lower() and "failed" in text_blob.lower():
        risks.add("Failed Fly deploy mentioned")

    next_action = in_progress_subjects[-1] if in_progress_subjects else "(deduce from objective)"

    return {
        "objective": user_prompts_last[-3:],
        # GPT-5.5 B5 fix: separate attempted vs successful
        "attempted_commands": attempted[-30:],  # All bash attempts (including failed)
        "successful_commands": successful[-30:],  # ONLY exit_code=0
        "attempted_file_changes": changed_attempted[-20:],
        "successful_file_changes": list(set(changed_successful))[-20:],
        "risks": sorted(risks),
        "next_action": next_action,
    }

def main():
    try:
        payload = json.load(sys.stdin)
    except Exception:
        sys.exit(0)

    transcript_path = payload.get("transcript_path", "")
    session_id = payload.get("session_id", "unknown")

    if not transcript_path:
        sys.exit(0)

    p = pathlib.Path(transcript_path)
    if not p.exists():
        sys.exit(0)

    # GPT-5.5 B5 fix: use structured JSONL parser, not regex over blob
    parsed = parse_transcript_jsonl(p)

    handoff = {
        "session_id": session_id,
        "timestamp": datetime.datetime.now().isoformat(),
        "transcript_path": transcript_path,
        **parsed,
    }

    out = STATE_DIR / f"precompact-handoff-{session_id}.json"
    out.write_text(json.dumps(handoff, indent=2))

    # Don't print anything — PreCompact hook output isn't injected (Anthropic spec)
    sys.exit(0)

if __name__ == "__main__":
    main()
```

## Open questions

1. **Re-injection mechanism**: hook scrive JSON ma chi lo legge a SessionStart? Opzioni:
   - (a) SessionStart hook (T3.5) cerca handoff file più recente + carica se session-resume
   - (b) PreToolUse hook (T1.1) variant che inietta handoff in primo user prompt
   - (c) Manual `/resume` slash command (T3.4)
     Default = combinazione (a) + (c).

2. **State file retention**: cleanup auto? Default = mantieni ultimo 7gg, deleta più vecchi via cron weekly.

3. **Secrets detection regex**: pattern `sk-ant-` può match anche `sk-ant-public-test-key`. False positive accettabile (segnala risk = better than miss).

4. **Sensitivity of risks**: lista pubblica = OK. Ma JSON contiene `verified_commands` che può avere secret in env vars assignment? Verifica empirico, eventualmente filter.
