# T0.1 — Orphan memory file triage

## Problem

La compaction 2026-05-19 di MEMORY.md (60.6KB → 13.8KB) ha lasciato **22+ orphaned `.md` file** in `~/.claude/projects/-Users-nuzantara-Desktop-nuzantara/memory/` che esistono su disk ma NON sono referenziati nell'indice compactato.

## Context

Empirical evidence (regression-fix-19 digest):

- `alzheimer-diagnose-20260521.md` segnala 22+ "Orphaned memory file" warnings
- File noti orphan (sample): `mcp-bridge-openclaw.md`, `graphrag-v6-deployed.md`, `api-keys.md`, `rogue-ai-refactors.md`, `team-contacts.md`, `nlm-source-preparation-decisions.md`, `p2_19_langgraph_federation_orchestrator_2026_05_20.md`
- Side-effect mai indirizzato dal piano 2026-05-19 (Item 2 era "split in overflow file" ma non triage dei post-cut residui)

Rischio:

- File con contenuti possibly load-bearing (es. `api-keys.md`) **invisibili** a SessionStart
- Storage cosmetic accumulo + alzheimer-diagnose noise ogni giorno

## Design

Triage trifoglia: KEEP (re-link in MEMORY) / ARCHIVE (move to `MEMORY_ARCHIVE.md` entry pointer) / DELETE (obsolete duplicate). Decision criteria:

| Criterion                                                          | Action                                       |
| ------------------------------------------------------------------ | -------------------------------------------- |
| File contiene segreti/credenziali attive (es. `api-keys.md`)       | KEEP + re-link sotto `## Facts (infra core)` |
| File contiene decisione strutturale (architecture, infrastructure) | KEEP + re-link                               |
| File documenta evento storico chiuso (>30gg, no follow-up)         | ARCHIVE → `MEMORY_ARCHIVE.md` pointer        |
| File duplica contenuto già in `MEMORY.md` o sotto-indice           | DELETE                                       |
| File appartiene a project specifico (es. `p2_19_*`) chiuso         | ARCHIVE                                      |
| File è cron-output noise (`alzheimer-diagnose-YYYYMMDD.md`)        | DELETE (mantengo solo ultimo 7gg)            |

## Acceptance criteria

- [ ] Zero "Orphaned memory file" warnings in `alzheimer-diagnose-20260522.md` (next cron run)
- [ ] `MEMORY.md` cresce di max 5 entry (≤700 byte aggiunti) — re-link compatti
- [ ] `MEMORY_ARCHIVE.md` cresce con N pointer ARCHIVE entries
- [ ] `~/backups/orphan-triage-20260521.tar.gz` backup completo creato prima di DELETE
- [ ] Step 4.5 dry-run report `/tmp/orphan-delete-dryrun-report.txt` reviewed by Antonello (DS panel medium concern fix)
- [ ] User explicit Y confirmation captured before any rm
- [ ] `git diff` di settings.json o altri config = 0 (solo memory dir touched)

## Implementation steps

```bash
# Step 1 — Backup completo
cd ~/.claude/projects/-Users-nuzantara-Desktop-nuzantara/memory
tar -czf ~/backups/orphan-triage-20260521.tar.gz .
ls -la ~/backups/orphan-triage-20260521.tar.gz  # verify >0 bytes

# Step 2 — Lista completa orphan
cat ~/.claude/projects/-Users-nuzantara-Desktop-nuzantara/memory/alzheimer-diagnose-20260521.md | grep "Orphaned" > /tmp/orphan-list.txt
wc -l /tmp/orphan-list.txt

# Step 3 — Per ogni orphan: classify (manual review or grep heuristic)
# Bash script di assistenza:
for f in $(grep -oE 'Orphaned memory file: [a-z0-9_.-]+\.md' /tmp/orphan-list.txt | awk '{print $4}'); do
  echo "=== $f ==="
  size=$(stat -f "%z" "$f" 2>/dev/null || echo 0)
  mtime=$(stat -f "%Sm" -t "%Y-%m-%d" "$f" 2>/dev/null || echo NA)
  head -5 "$f" 2>/dev/null | head -3
  echo "size=$size mtime=$mtime"
  echo ""
done > /tmp/orphan-classification.txt

# Step 4 — Manual triage. Per ogni file decidi KEEP/ARCHIVE/DELETE
# Strumenti: hexdump per sospetti binari, grep -l per duplicate detection

# Step 4.5 — DRY-RUN gate (DS panel medium concern fix)
# BEFORE any DELETE, show full list of files to be deleted to Antonello for per-file approval
echo "=== DRY-RUN: files marked for DELETE ==="
echo "Total: $(wc -l < /tmp/orphan-delete-list.txt) files"
echo ""
cat /tmp/orphan-delete-list.txt | while read f; do
    echo "--- $f ---"
    echo "Size: $(wc -c < "$f") bytes"
    echo "Last modified: $(stat -f "%Sm" "$f")"
    echo "First 5 lines:"
    head -5 "$f"
    echo ""
done > /tmp/orphan-delete-dryrun-report.txt

cat /tmp/orphan-delete-dryrun-report.txt
echo ""
echo "REVIEW ABOVE. Press Y to proceed with DELETE, N to abort."
read -r confirm
if [ "$confirm" != "Y" ]; then
    echo "ABORTED by user — no files deleted."
    exit 1
fi

# Step 5 — Esegui DELETE su file marcati (only after Step 4.5 approval)
for f in $(cat /tmp/orphan-delete-list.txt); do
    rm "$f" && echo "DELETED: $f" || echo "FAILED: $f"
done

# Step 6 — Esegui ARCHIVE: appendi 1-line pointer in MEMORY_ARCHIVE.md poi delete file
# Format: - YYYY-MM-DD <slug>: <one-line summary>

# Step 7 — Esegui KEEP: appendi 1-line pointer in MEMORY.md sezione appropriata
# Format: - `<filename>` — <one-line summary>

# Step 8 — Verify post-state
~/.claude/scripts/mos-maintenance.sh 2>&1 | grep -i orphan  # should be 0
wc -l ~/.claude/projects/-Users-nuzantara-Desktop-nuzantara/memory/MEMORY.md  # should be ≤200
```
