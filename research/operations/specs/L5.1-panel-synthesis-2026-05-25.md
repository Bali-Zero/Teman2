**A3. `git -C <path>` effective target parsing**

```python
GIT_C_PATTERN = re.compile(r"\bgit\s+(?:-c\s+\S+\s+)*-C\s+(\S+)")
GIT_CD_PATTERN = re.compile(r"\bcd\s+(\S+)\s*(?:&&|;)\s*git\b")

def _effective_git_target(cmd: str) -> str | None:
    """Return effective working dir for the git op, or None if no override."""
    m = GIT_C_PATTERN.search(cmd)
    if m: return m.group(1)
    m = GIT_CD_PATTERN.search(cmd)
    if m: return m.group(1)
    return None
```

Then in main():

