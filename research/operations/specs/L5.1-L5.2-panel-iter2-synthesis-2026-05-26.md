## L5.1 iter-2 — 7 difetti residui (post-amendments A1-A9)

| #   | Difetto                                                                    | Severity    | Found by                       | Patch necessaria (iter-3)                                                                                                                                                           |
| --- | -------------------------------------------------------------------------- | ----------- | ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| R1  | MultiEdit bypass — `edits[*]` array non iterato                            | Critical    | DeepSeek                       | `worktree_file_write_check.py` skip se top-level `file_path` mancante. MultiEdit ha `edits[*]` con `file_path` per edit. Iterare l'array e bloccare se any in zone restricted.      |
| R2  | `git -C` multi-arg bug                                                     | High        | Gemini + DeepSeek              | Regex prende primo `-C`, git applica ultimo. `git -C /allowed -C /main checkout` bypass. Scan tutti `-C` occurrences, return last.                                                  |
| R3  | Hardlink bypass via `/tmp`                                                 | Medium-High | DeepSeek                       | Hardlink in `/tmp` pointing into REPO_ROOT inode passa il check (file_path outside repo). Mitigation: stat+inode compare OR documented limitation + L5.1.1 audit cron.              |
| R4  | Hook coverage non-Bash tools (`Delete`/`Replace`/`Rename` + `rm -rf` Bash) | High        | Gemini + DeepSeek              | Matcher attuale `Edit\|Write\|MultiEdit` non copre tool destructive alternativi. Anche Bash `rm -rf REPO_ROOT/...` non scopre.                                                      |
| R5  | Hook crash fail-open vs fail-closed undocumented                           | High        | DeepSeek                       | Se hook crash con exit non-zero, harness behavior non documentato. Se fail-open, transient errors = bypass silenzioso. Test empirico obbligatorio + try/except wrap.                |
| R6  | Sub-agent inheritance NOT verified (iter-1 Q4 unsolved)                    | Critical    | Gemini + DeepSeek re-emphasize | Phase 1 probe pre-requisite STRINGENT. Se sub-agent non eredita parent hooks, L2 Redis lease NON è backstop sufficient (DeepSeek: L2 anch'esso client-side). Solo L5.2 server-side. |
| R7  | `git --git-dir/--work-tree` flag bypass                                    | High        | Gemini                         | Equivalente funzionale di `-C`, NOT captured da regex. `git --work-tree=/main --git-dir=/main/.git checkout` bypassa.                                                               |

**Conseguenza**: L5.1 iter-2 status → `pending-iter-3`. Monitor-mode rollout (probe-only, no block) acceptable interim.
