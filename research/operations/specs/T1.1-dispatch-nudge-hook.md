# T1.1 — `dispatch_nudge.py` hook

## Problem

Within-session orchestration decay: subagent dispatch passa 8→0 dopo ~500 righe di transcript, mentre Bash engagement resta 57-81%. Empirical evidence sessione `d955ac4b`:

| Lines bucket | Asst msgs          | Tool calls | Tool ratio | Subagent dispatches |
| ------------ | ------------------ | ---------- | ---------- | ------------------- |
| 0-500        | 112                | 75         | 67%        | **8**               |
| 500-7500     | (continua stabile) | ~60%       | ~60%       | **0**               |

Causa probabile: arsenale awareness pushed out of attention dopo SessionStart, ma tool engagement Bash resta perché triggerato dal prompt utente immediato.

## Context

Tutti i 3 LLM panel convergono sulla necessità di un hook che intercetti questa decay e iniettì reminder:

- **Codex**: Python variant minimale, scan transcript file ultimo 40KB
- **DeepSeek**: Bash variant con state-dir tracking + ricco match pattern (`grep|find|ls -lR|wc`)
- **NB-AGENTS**: pattern PreToolUse `{"permissionDecision": "defer"}` per pause/resume

Decisione orchestratore: Python primary (semplicità), Bash come `_alternative.sh` documentato.

## Design

Hook tipo `UserPromptSubmit` (fires BEFORE Claude vede il prompt utente).

Flow:

1. Legge `transcript_path` da JSON stdin (Claude env)
2. Conta last 40KB del transcript: occorrenze di `Task(` + `subagent` + line count
3. Condizione trigger: `line_count > 500` AND `subagent_dispatch_count == 0`
4. Inietta system message: "Long session, zero subagent dispatch — dichiara direct / skill / subagent / MCP prima di rispondere"

Architettura: single-file Python, no daemon, no external state. Stateless = simple.

## Acceptance criteria

- [ ] Hook eseguito senza errori in <500ms su transcript da 8KB
- [ ] In fresh session: hook NON inietta nulla (line_count < 500)
- [ ] In sessione mock con >500 righe + Task() entries: hook NON inietta (subagent presenti)
- [ ] In sessione mock con >500 righe + zero Task(): hook inietta reminder
- [ ] settings.json `UserPromptSubmit` array aggiornato senza rompere hook esistenti

## Implementation steps

### Step 1 — Crea hook file

Path: `~/.claude/hooks/dispatch_nudge.py`

```python
#!/usr/bin/env python3
"""UserPromptSubmit hook — counter orchestration regression.

Reads transcript file from Claude env, if long session + zero subagent
dispatch in recent history, injects system reminder.

Reference: research/operations/specs/T1.1-dispatch-nudge-hook.md
"""
import json
import pathlib
import sys

# Defaults — tunable
LINE_THRESHOLD = 500          # trigger if transcript > N lines
RECENT_BYTES = 40_000         # last N bytes scanned
DISPATCH_KEYWORDS = ("Task(", '"subagent_type"', "Agent(")

def main():
    try:
        payload = json.load(sys.stdin)
    except Exception:
        # Malformed input — fail silent, don't block Claude
        sys.exit(0)

    transcript_path = payload.get("transcript_path", "")
    if not transcript_path:
        sys.exit(0)

    p = pathlib.Path(transcript_path)
    if not p.exists():
        sys.exit(0)

    try:
        full_text = p.read_text(errors="ignore")
    except Exception:
        sys.exit(0)

    total_lines = full_text.count("\n")
    if total_lines <= LINE_THRESHOLD:
        sys.exit(0)  # short session — no nudge

    recent = full_text[-RECENT_BYTES:]
    dispatch_count = sum(recent.count(kw) for kw in DISPATCH_KEYWORDS)

    if dispatch_count == 0:
        reminder = (
            "ORCHESTRATION REMINDER — session is {} lines but no subagent "
            "has been dispatched recently. Before answering, choose one: "
            "(a) direct Bash, (b) load skill, (c) spawn subagent, (d) call MCP — "
            "and state why this choice fits the task."
        ).format(total_lines)
        print(json.dumps({"systemMessage": reminder}))

    sys.exit(0)

if __name__ == "__main__":
    main()
```

## Open questions

1. **Threshold 500 righe**: empirical da `d955ac4b`. In sessioni più corte/code-heavy potrebbe essere troppo basso. Considera dinamico: `min(500, file_size_kb)`.
2. **40KB scan window**: equivale a ~5-8 minuti di recent activity. Se sessione molto attiva può perdere segnale. Iterazione futura: contare _N most recent assistant turns_ invece di bytes.
3. **`Agent(` keyword**: include tutti i tipi di subagent dispatch. Verifica empirica che match Claude Code output reale.
4. **Conflict con altri UserPromptSubmit hook**: settings.json ha già 3 commands attivi. Eseguono in serie, output combinato? Verificare race condition possibile.
