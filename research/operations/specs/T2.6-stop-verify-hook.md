# T2.6 — `stop_verify.py` Stop hook

## Problem

Claude Code stop event = fine sessione. Senza verifica: posso fermarmi con worktree sporco (file modificati non committed) → next session ripartono "da capo" + perdita di state.

Combina con T0.1 lesson (orphan files post-compaction) e T2.5 (Mnemos handoff): se forziamo verbatim verification PRIMA di Stop, hook può blocking + chiedere "ricapitola cosa hai cambiato".

## Context

Stop hook in Anthropic spec:

- Exit code 2 + stderr = "block stop" + feedback to Claude
- Exit code 0 = allow stop

NB-AGENTS [31] mostra pattern Stop-hook-exit-2 = "native Ralph TDD loop":

> _"If the script exits with code 2, Claude is prevented from stopping, the stderr is fed back, and Claude must fix the code."_

## Design

Hook Python: check `git status --short` su working tree. Se dirty AND no `commit` o `git stash` in last 20 turn → block. Allow se Claude conferma "incomplete on purpose, leave dirty".

## Implementation steps

### Step 1 — Crea hook file

Path: `~/.claude/hooks/stop_verify.py`

```python
#!/usr/bin/env python3
"""Stop hook — block if dirty worktree without explicit commit intent.

Exit code 2 + stderr = block stop, force Claude to address dirty state.
Override via env var STOP_VERIFY_ALLOW_DIRTY=1.

Reference: research/operations/specs/T2.6-stop-verify-hook.md
"""
import json
import os
import pathlib
import subprocess
import sys

def main():
    # Allow override
    if os.environ.get("STOP_VERIFY_ALLOW_DIRTY", "0") == "1":
        sys.exit(0)

    try:
        payload = json.load(sys.stdin)
    except Exception:
        sys.exit(0)

    cwd = payload.get("cwd", os.getcwd())

    # Check git status
    try:
        result = subprocess.run(
            ["git", "-C", cwd, "status", "--short"],
            capture_output=True, text=True, timeout=5
        )
    except Exception:
        sys.exit(0)  # not in git repo or git unavailable

    if result.returncode != 0:
        sys.exit(0)  # not a git repo

    dirty = result.stdout.strip()
    if not dirty:
        sys.exit(0)  # clean, allow stop

    # Dirty — check if Claude explicitly noted intent to leave dirty
    transcript_path = payload.get("transcript_path", "")
    if transcript_path:
        try:
            text = pathlib.Path(transcript_path).read_text(errors="ignore")
            # Look for intent markers in last 10KB
            recent = text[-10_000:]
            intent_markers = [
                "wip:", "checkpoint", "leave dirty", "non commit",
                "incomplete on purpose", "pause here", "salvare per dopo",
            ]
            if any(m in recent.lower() for m in intent_markers):
                sys.exit(0)  # explicit intent, allow
        except Exception:
            pass

    # Block
    sys.stderr.write(
        "STOP BLOCKED: dirty worktree detected.\n"
        f"Working dir: {cwd}\n"
        f"Changes:\n{dirty[:1000]}\n\n"
        "Action required:\n"
        "1. Commit changes (`git add -A && git commit -m 'WIP: ...'`)\n"
        "2. Stash with `-u` (`git stash push -u -m 'session-stop'`)\n"
        "3. Discard via explicit `git restore` (after confirmation)\n"
        "4. Or set env: STOP_VERIFY_ALLOW_DIRTY=1 and retry stop\n"
    )
    sys.exit(2)

if __name__ == "__main__":
    main()
```
