# T3.1 — Fix nuzantara-mcp DNS

## Problem

Sessione 2026-05-21 SessionStart output:

```
nuzantara-mcp: configured=yes reachable=no
DNS resolution failed: nuzantara-rag.fly.dev
```

L'MCP server primario di Nuzantara (115 tools: CRM, KBLI, pricing, intel, ecc.) è IRRAGGIUNGIBILE. Tutti i `mcp__nuzantara-mcp__*` tools loadati nel deferred list ma chiamate failirebbero al primo invocation.

Questo è il P0 numero uno della session: arsenal "armed" ma scollegato dal corpo.

## Context

Empirical SessionStart output ha mostrato:

- DNS hostname: `nuzantara-rag.fly.dev` (correct production URL)
- DNS fail → MCP transport (HTTP?) non si stabilisce
- Local proxy potrebbe essere giù

Possibili cause:

1. **Fly.io app auto-stop**: nuzantara-rag ha `auto_stop=off` ma se machine in restart loop, DNS Fly può rispondere NXDOMAIN
2. **DNS cache stale**: macOS DNS cache (`mDNSResponder`) può holdare risposta vecchia
3. **MCP server config**: `.mcp.json` o `~/.claude.json` punta a hostname errato
4. **Tailscale routing**: se MCP usa hostname via Tailscale, NordVPN può dirottare (vedi `lessons_nordvpn_tailscale_block`)
5. **OAuth token scaduto**: se MCP usa OAuth login flow, token expired → DNS effort è fallback symptom

## Acceptance criteria

- [ ] `mcp__nuzantara-mcp__check_health` returns 200 OK
- [ ] `mcp__nuzantara-mcp__check_health_detailed` returns full service status
- [ ] SessionStart MCP readiness shows: `nuzantara-mcp: configured=yes reachable=yes`
- [ ] Test concreto: `mcp__nuzantara-mcp__list_clients` returns N clients
- [ ] Memory scar updated con root cause + fix

### Step 1 — Diagnose empirical


### Step 2 — Diagnose by hypothesis

**H1 — Fly app down**:

```bash
fly status -a nuzantara-rag --json | jq '.Status'
# Se "stopped" o restart loop → fly machine restart
```

**H2 — DNS cache**:

```bash
sudo dscacheutil -flushcache
sudo killall -HUP mDNSResponder
dig +short nuzantara-rag.fly.dev  # retry
```

**H3 — MCP config error**:

```bash
# Verifica URL in config
cat .mcp.json | jq '.mcpServers["nuzantara-mcp"].url'
# Expected: https://nuzantara-rag.fly.dev/mcp or similar
# Compare con app actual hostname:
fly apps list | grep nuzantara
```

**H4 — VPN block**:

```bash
# Check VPN status
nordvpn status 2>/dev/null
# If connected → disconnect, retry
nordvpn disconnect 2>/dev/null
```

**H5 — OAuth expired**:

```bash
# Check if MCP uses OAuth (some MCPs)
# Look for token in keychain
security find-internet-password -s "nuzantara-rag.fly.dev"
# se trovato + age > 30d → renew
```

### Step 6 — Add MCP health to SessionStart check

```bash

#!/bin/bash
# Test critical MCP servers reachability at SessionStart
for url in "https://nuzantara-rag.fly.dev/health"; do
  status=$(curl -s -o /dev/null -w "%{http_code}" -m 5 "$url")
  if [ "$status" != "200" ]; then
    echo "⚠️ MCP UNREACHABLE: $url (HTTP $status)" >&2
  fi
done
EOF
chmod +x ~/.claude/scripts/mcp-health-check.sh
```
