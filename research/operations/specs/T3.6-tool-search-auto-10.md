# T3.6 — Tool Search ENABLE_TOOL_SEARCH=auto:10

## Problem

DeepSeek diagnosi 2026-05-21 hypothesis:

> _"Tool Search auto:5 deferral threshold prunes subagent tool schemas after 5+ tool calls per session. Result: subagent options become invisible after a few tool turns, hence orchestration decay."_

NOT empirically verified. Spec serve a:

1. Verify hypothesis (compare auto:5 vs auto:10 vs auto:none)
2. If validated, raise threshold

## Context

Tool Search auto-deferral:

- `ENABLE_TOOL_SEARCH=auto:N` env var
- N = max non-deferred tools available simultaneously
- N+ tools moved to deferred list (need ToolSearch to load schema)

Current setting: probably auto:5 (default) — Anthropic docs unclear.

## Acceptance criteria

- [ ] Empirical measurement: `auto:5` vs `auto:10` subagent dispatch ratio
- [ ] If auto:10 ≥10% increase in subagent dispatches → adopt
- [ ] Env var documented in `~/.zshenv` or Claude Code config
- [ ] Memory entry comparing thresholds

## Implementation steps

### Step 1 — Verify current setting

```bash
env | grep ENABLE_TOOL_SEARCH
echo $ENABLE_TOOL_SEARCH
# Check ~/.zshenv, ~/.zshrc, Claude Code launch script

# Also check default behavior (no env var = default)
grep -r "ENABLE_TOOL_SEARCH\|auto:" ~/.claude/ 2>/dev/null | head
```

### Step 2 — A/B baseline measurement

Session A (current setting):

- Run a complex task for 30 min
- Count subagent dispatches via `/dispatch-stat`

Session B (`auto:10`):

- `export ENABLE_TOOL_SEARCH=auto:10`
- Restart Claude Code
- Run equivalent task
- Count subagent dispatches

Session C (`auto:none` = no deferral):

- `export ENABLE_TOOL_SEARCH=none`
- Restart
- Run equivalent task

### Step 3 — Compare metrics

```
Setting    | Dispatches | Time | Tool tokens
auto:5     | X          | Tx   | Yx
auto:10    | Y          | Ty   | Yy
auto:none  | Z          | Tz   | Yz
```

Hypothesis validated if:

- Y >> X (auto:10 increase dispatch)
- Z >> Y (auto:none even more)
- BUT tool tokens Yz >> Yy >> Yx (cost trade-off)

### Step 4 — Decision matrix

| auto:N      | Dispatch | Token cost | Latency | Recommendation                  |
| ----------- | -------- | ---------- | ------- | ------------------------------- |
| 5 (default) | low      | best       | best    | use if dispatch acceptable      |
| 10          | medium   | medium     | medium  | sweet spot if hypothesis valida |
| none        | high     | high       | high    | use only se critical workflow   |

### Step 5 — Apply

If auto:10 validated:

```bash

echo 'export ENABLE_TOOL_SEARCH=auto:10' >> ~/.zshenv
# Restart Claude Code
```
