  ## 5. Beyond-SOTA recommendations

  Ranked by (impact × confidence) / cost. All extend existing doors — the shape the 2026-08-26 refuter round measured as the only kind that survives.

  **R1 — The TRIAGE receipt: make pre-build triage a CI-consumed artifact.** *What:* extend `evidence/brief.yml` schema with a `triage:` block — provisional gear + reason, the falsifiable acceptance criteria as authored BEFORE the first build commit (timestamped), and `criteria_shape:` — and add a pack-linter rule: for floor ≥2 PRs, the pack's receipts must map onto the brief's acceptance criteria one-to-one (each criterion cited by a receipt or declared waived-with-reason). *Why beyond SOTA:* Spec Kit, Kiro and Anthropic all say "write criteria first"; **no system verifies the criteria were written before the build and closes them against receipts** — it composes three things only this organism has: the required harness-floor check, the pack linter, and the receipts convention. *Cost:* ~150 lint lines + schema; flat-sub tokens negligible. *Gear:* 2. *Risk:* superscar #2 (exists ≠ armed) — mitigated by wiring into the existing required check, not a new workflow; #9 (schema drift) if the brief schema mutates without the linter. *Metric:* % of floor≥2 PRs with 100% criterion→receipt closure (baseline: unmeasurable today → target 100% instrumented; method: lint exit codes over 30 days). *Kill criterion:* if >20% of PRs carry vacuous criteria that lint can't catch, add the shape lint (R4) or drop the rule. *First PR below.*

  **R2 — The assumption ledger: close the infer-don't-ask protocol with a measured error rate.** *What:* brief schema gains `assumptions:` (each inference made under the language protocol, one line each, as CLAUDE.md §4 already demands in chat); the Gear-3 gate verdict must mark each CONFIRMED/REFUTED; refuted assumptions on hot-zone work get a scar-line count. *Why beyond SOTA:* every surveyed culture either interrogates (Anthropic interview, Amazon FAQ) or infers silently (vibe coding); nobody *measures* the false-inference rate of an infer-first protocol — the organism's solo-owner asymmetry makes it the only place this measurement matters, and its gate structure makes it free. *Cost:* schema + verdict template + one lint rule; ~100 lines. *Gear:* 2. *Risk:* #3 (guard-over-match: verdict-templating gamed with "CONFIRMED" boilerplate) — the gate is Opus xhigh, judgment stays there; the lint only enforces presence. *Metric:* refuted-assumption rate per 100 floor≥2 mandates (baseline unknown; W100/W113 imply non-trivial; method: quarterly grep of verdicts). *Kill:* if rate <2% after 50 mandates, the ledger is ceremony — demote to optional.

  **R3 — Scar-cited grounding for floor-3 packs.** *What:* when `compute_floor()=3`, the pack must carry `scars_cited:` — the superscar/W-numbers whose antidotes the brief claims to honor (modus GROUND already says "quote the applicable scar ANTIDOTE lines"; SKILL.md:76). Lint enforces non-empty + well-formed; relevance stays the gate's judgment. *Why beyond SOTA:* pre-mortems (Klein) use hypothetical failures; EARS constrains syntax; **nobody conditions the entry gate on citing measured prior failures of the same class** — the scar corpus is the asymmetry (296 KB + 397 KB of versioned, measured trauma). *Cost:* one lint rule; the discipline already exists in prose. *Gear:* 2. *Risk:* #3 again — citation without reading; mitigated because the antidote text must be quoted, and the gate reads. *Metric:* recurrence of scar families in floor-3 PRs (baseline: W86/W89 recurrences documented in AMENDMENTS lines 28–29; method: scar-ID grep over merged hot-zone PRs, before/after quarter). *Kill:* if citations become rot (same scar cited on >60% of packs regardless of domain), narrow to domain-matched citations.

  **R4 — EARS-or-executable shape lint for acceptance criteria.** *What:* each `acceptance:` entry must match an EARS keyword shape (While/When/Where/If…Then + shall) or contain an executable token (`pytest`, `grep`, `curl`, `exit`, a status code). Warn-tier first in the pack linter, promote later (needs-ruling, §7). *Why beyond SOTA:* Kiro *writes* EARS requirements; nothing *lints* them in CI against drift into prose — and Nuzantara's criteria must be machine-checkable anyway because sessions, not humans, verify them. *Cost:* ~60 lines regex + fixtures. *Gear:* 1–2. *Risk:* #3 (substring trapping — the corpus must include innocences, per the scars' own GOTCHA discipline). *Metric:* % criteria machine-shaped (baseline ~low; the on-disk brief.yml passes on executable tokens, fails EARS shape — it's the calibration fixture). *Kill:* false-positive rate >10% on a 30-PR calibration window.

  **R5 — State-space check for the migration/state-machine class (TLA-lite).** *What:* for briefs whose floor-3 cause is `migrations_v2/**` or a state machine, require a property test that enumerates reader×policy combinations (the visa-retention failure was a combination — 4 readers × new scope — invisible to instance tests), hypothesis-style, not TLA+ proper. *Why behind-then-beyond:* AWS's TLA+ catches this class with a model checker; the beyond-SOTA move is **LLM-generated property suites reviewed cross-family against the live catalog** — cheaper than teaching the fleet PlusCal, stronger than instance tests, and the refuter-refutes-the-suite structure already exists. *Cost:* 2–4h per migration brief + Sonnet/GLM tokens. *Gear:* 3 only (P0 data class). *Risk:* #6 (phantom properties — suite must be run red-first against the pre-fix state, stadio-zero discipline). *Metric:* combination-class defects escaping to prod (baseline: 1 measured, 2026-08-26; method: incident count). *Kill:* if 3 consecutive migration briefs produce suites that never go red on the pre-fix state, the generator is writing tautologies — back to manual.

  **R6 — Appetite receipts for Gear 1–2.** *What:* extend the stop-loss declaration (today Gear-3-only, SKILL.md:61) downward as a one-line `budget_shape:` in the brief, reconciled by `session_budget.py` (already on disk) at session end; report variance in the pack. *Why beyond SOTA:* Shape Up's appetite bounds *human-weeks*; nothing bounds *agent-token-spend vs declared shape* with receipts — the 2026-08-22 trauma (44h/8.6M tokens on a misgeared meta-mandate) is the measured cost of the gap. *Cost:* hook wiring + pack field. *Gear:* 2. *Risk:* #2 again. *Metric:* declared-vs-actual token variance per gear (method: session_budget report over 30 days). *Kill:* variance unusable because budgets are declared as jokes (>10×) on >30% of mandates.

  ## 8. §Meta-pattern

  Across every finding in this lane — stadio-zero warn-only, premise_gate warn-only, rule 8 written *after* #4547 burned 6h, the misgeared 44h meta-mandate, the kill-criterion check with no checker, `harness/fable-gate` published-not-required, the acceptance criterion that was unobtainable by construction (AMENDMENTS 2026-08-23) — one defective belief repeats: **"a rule whose text is correct is a rule that runs."** The organism's intake doctrine is genuinely excellent prose; its failure mode is never wrong doctrine, it is the absence of a counter on the doctrine. Superscar #2 (esiste ≠ armato) is usually aimed at daemons and gates; this lane shows it operates one level up, at the *epistemic* layer: entry gates, sizing rules, and acceptance criteria exist as text while their execution rate is zero-instrumented. The malattia-delle-malattie for intake is therefore not under-specification or over-ceremony — it is **unmeasured specification**: every improvement that survived (the floor, the ceiling, the required harness check) shares exactly one property the failures lack — a deterministic door that recomputes the claim instead of trusting it. All six recommendations are that shape, deliberately.
