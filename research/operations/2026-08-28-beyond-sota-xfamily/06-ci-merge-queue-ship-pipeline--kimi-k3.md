  ## 8. §Meta-pattern

  One defective belief generates this lane's entire scar topology: **"the platform's reported state is the system state."** GitHub reports `completed` (W124: on a subset), `mergeable: false` (on a `merge=union` file every git client merges cleanly), `autoMergeRequest: null` (on a perfectly armed PR mid-queue), a rerun's green (on a stale merge-ref, W111), a check-suite count "39" (remembered; measured 55). Every trap, every watcher, every Contract rule in this lane is the same antibody: *never read one field; never trust a gesture; cross-check the count against the requirement; prove the gate on every ref that must satisfy it.* The organism has metabolized this belief-defect better than any surveyed system — its watchers exist precisely because the belief is false. The remaining gap (R1/R2/R4) is the same pattern one level down: sessions still treat *conflicts* as opaque platform verdicts when the organism's own conflicts are 90% mechanical registries whose merge semantics it fully owns. The beyond-SOTA move is not more verification of GitHub's state — it is **withdrawing classes of work from GitHub's state model entirely** (namespaced paths, schema-aware resolution), so there is less state to distrust.
