## 5. Beyond-SOTA recommendations

Ranked by (impact × confidence) / cost. All exploit organism asymmetries (always-on local machines, scar corpus, PENDING-ARMS ledger, full-lifecycle session ownership, hooks-as-backstop).

**R1 — Two-plane merge-gate integrity: close the CANNOT-VERIFY hole.**
- *What:* Keep `merge-gate-integrity-watch.yml` as the in-CI detector, but (a) add a local probe on Pro/Mini (launchd, admin-scope token) that runs `scripts/probe_merge_gate_integrity.py` with live `branches/main/protection` reads after every main push it observes; (b) add a required check `required-context-drift` that fails when `infra/required.d/contexts.json` diverges from live protection (compare local-probe fetch vs snapshot; regen in-PR is already the documented cure).
- *Why it beats SOTA:* no surveyed system continuously proves that required checks *actually computed* before each landed commit; Google/Chromium trust their presubmit infra implicitly. This composes the organism's existing detector with its always-on-machine + admin-token asymmetry.
- *Cost:* flat-sub tokens, ~2 sessions; Gear 2.
- *Risk:* superscar #9 (probe becomes a proxy that lies if local git state lags) — mitigate by probing via API only, never local refs. Scar family #2 if the launchd agent dies silently — register in the existing watcher-coverage regime (prepush-guards cites `scripts/check_watcher_coverage.py`).
- *Metric:* CANNOT-VERIFY share of main merges 100%→<2% (exempt: GitHub incidents); drift-time-to-detection <15 min. Measurement: probe verdict ledger appended per run.
- *Kill criterion:* if >5% of probes false-alarm over 2 weeks, revert to detector-only.
- *First PR:* `scripts/ci/check_required_context_drift.py` + workflow job, ≤400 lines, acceptance: hand-edit contexts.json in test → job fails with named diff.
