## Discovery critica: **CODEOWNERS-orphan**

Esiste su main:

- `.github/CODEOWNERS` (87 righe, mtime 26 mag 09:22, scope perfetto: workflows / fly.toml / migrations / app/auth / services/auth / services/invoicing / services/pricing / services/billing / launchagents)
- `auto-merge-whitelist.yml` enforce paths protetti via regex pattern match BEFORE auto-merge

MANCA su main:

- `required_pull_request_reviews` su branch protection main → **NULL**
- `require_code_owner_reviews=true` → impossibile da settare se `required_pull_request_reviews` è null
- → **CODEOWNERS è documentazione semantica, non hard gate**

Conseguenza: nessuna PR è bloccata da CODEOWNERS. Auto-merge whitelist blocca solo PR Dependabot/bot/Antonello su path protetti — ma una PR umana da Subhi (`SubBZ2026`) può mergiare su `services/auth/` se Antonello la mergia manualmente senza guardarla, perché GitHub non chiederà CODEOWNERS review.

**Real gap chiuso da L5.2**: configurare branch protection per leggere CODEOWNERS.
