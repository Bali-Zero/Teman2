# Review packet

Start with [REPORT.md](REPORT.md): the accepted, adjudicated report.

- `provenance.json`: actual models, invocations, completion states and limitations.
- `source-manifest.json`, `source-packet.txt`: exact code input.
- `home-baseline-desktop.png`, `visual-evidence.json`: loaded desktop image before approved team compaction.
- `claude-final-review.md`: real final Opus visual review; not every suggestion accepted.
- `adjudication.md`: corrected or rejected model assertions.
- `verified-web-sources.md`: primary pages independently opened by orchestrator.
- `*-raw.json`, `*-events.jsonl`, `*-execution.json`: raw invocation evidence, not accepted business facts.

The initial Gemini report is prominently REJECTED. A model tool event in state DONE is not proof of a successful source read when the final result reports permission denial. No automatic edits or production actions follow this review.
