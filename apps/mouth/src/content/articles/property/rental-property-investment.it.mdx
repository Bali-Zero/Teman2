## Aspettative di Rendimento

### Rendimenti Tipici

| Tipo di Proprietà          | Rendimento Lordo | Rendimento Netto |
| -------------------------- | ---------------- | ---------------- |
| Villa Bali (breve termine) | 8-15%            | 5-10%            |
| Villa Bali (lungo termine) | 5-8%             | 4-6%             |
| Appartamento Giacarta      | 5-7%             | 4-5%             |
| Appartamento servito       | 6-10%            | 4-7%             |

<InfoCard variant="warning" title="Aspettative Realistiche">
**Sii realistico:**

- I rendimenti lordi ignorano le spese
- I rendimenti netti contano di più
- L'occupazione varia (60-80% tipica per il breve termine)
- I costi di manutenzione si accumulano
- Commissioni di gestione 15-25%
- Le tasse riducono ulteriormente i rendimenti

Punta a un rendimento netto del 5-8% per una pianificazione realistica.

</InfoCard>

### Calcolatore di Rendimento

<Calculator
  title="Stima del Rendimento da Locazione"
  description="Calcola i potenziali rendimenti"
  fields={[
    {
      id: "purchase",
      label: "Valore Proprietà (IDR)",
      type: "number",
      defaultValue: 3000000000,
      min: 0
    },
    {
      id: "monthlyRate",
      label: "Tariffa Mensile Affitto (IDR)",
      type: "number",
      defaultValue: 25000000,
      min: 0
    },
    {
      id: "occupancy",
      label: "Occupazione Prevista (%)",
      type: "number",
      defaultValue: 70,
      min: 0,
      max: 100
    },
    {
      id: "managed",
      label: "Gestione Immobiliare?",
      type: "select",
      options: [
        { value: "yes", label: "Sì (20% del fatturato)" },
        { value: "no", label: "No (gestione autonoma)" }
      ],
      defaultValue: "yes"
    }
  ]}
  calculateResult={(values) => {
    const annualGross = values.monthlyRate * 12 * (values.occupancy / 100);
    const managementFee = values.managed === "yes" ? annualGross * 0.20 : 0;
    const maintenance = annualGross * 0.10; // 10% per manutenzione
    const utilities = values.monthlyRate * 0.1 * 12; // Stima approssimativa utenze
    const tax = annualGross * 0.10; // 10% tassa sul reddito da locazione

    const totalExpenses = managementFee + maintenance + utilities + tax;
    const netIncome = annualGross - totalExpenses;

    const grossYield = (annualGross / values.purchase) * 100;
    const netYield = (netIncome / values.purchase) * 100;

    return {
      total: Math.round(netIncome),
      breakdown: [
        { label: "Affitto lordo annuo", amount: Math.round(annualGross) },
        { label: "Gestione immobiliare", amount: -Math.round(managementFee) },
        { label: "Manutenzione (10%)", amount: -Math.round(maintenance) },
        { label: "Stima utenze", amount: -Math.round(utilities) },
        { label: "Tasse locazione (10%)", amount: -Math.round(tax) },
        { label: "REDDITO ANNUO NETTO", amount: Math.round(netIncome) },
        { label: "Rendimento lordo", amount: `${grossYield.toFixed(1)}%` },
        { label: "Rendimento netto", amount: `${netYield.toFixed(1)}%` }
      ],
      currency: "IDR",
      note: `Rendimento netto: ${netYield.toFixed(1)}% (~USD ${Math.round(netIncome / 16000).toLocaleString()}/anno)`
    };

}}

## Obblighi Fiscali

### Imposta sul Reddito da Locazione

<InfoCard variant="note" title="Imposta Finale 10%">
Il reddito da locazione immobiliare è soggetto a:

**Imposta Finale 10%** sul reddito lordo da locazione

- Nessuna deduzione per le spese
- Finale (non si cumula ad altri redditi)
- Trattenuta dagli inquilini societari
- Autoliquidata per inquilini individuali
  </InfoCard>

### Tramite PT PMA

| Voce              | Trattamento        |
| ----------------- | ------------------ |
| Reddito locazione | Reddito societario |
| Spese             | Deducibili         |
| Ammortamento      | Edificio: 5%/anno  |
| Imposta utile     | 22% CIT            |
| Dividendo         | 10% WHT            |
