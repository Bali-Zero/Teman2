# Membeli Apartemen di Indonesia 2026: Panduan untuk Orang Asing

Apartemen (kondominium) menawarkan jalur hukum yang paling jelas bagi orang asing untuk memiliki properti di Indonesia. Berikut adalah panduan lengkap Anda.

## Apakah Orang Asing Boleh Membeli Apartemen?

<InfoCard variant="note" title="Ya, Dengan Persyaratan">
  Orang asing dapat memiliki apartemen di Indonesia dengan kondisi tertentu: - Harus memiliki
  **KITAS atau KITAP** yang berlaku - Properti harus memenuhi **persyaratan harga minimum** - Harus
  berada di bangunan **hak milik strata** yang disetujui untuk kepemilikan asing - Kepemilikan
  dilakukan melalui **Hak Milik Satuan Rumah Susun** (HMSRS) atau **Hak Pakai** strata
</InfoCard>

---

## Kepemilikan Hak Milik Strata

Saat Anda membeli apartemen, Anda mendapatkan:

### Apa yang Anda Miliki

- **Unit**: Ruang apartemen spesifik Anda
- **Saham properti bersama**: Kepemilikan proporsional atas fasilitas bersama
- **Hak keanggotaan**: Dalam manajemen bangunan (P3SRS)

### Properti Bersama Termasuk

- Lahan tempat bangunan berada
- Struktur dan atap
- Koridor dan lobi
- Kolam renang dan pusat kebugaran
- Struktur parkir
- Taman dan area bersama

<Calculator

    const notary = price * 0.01; // Biaya notaris (perkiraan)
    const registration = 1000000; // Pendaftaran BPN

    const pph = price * 0.025; // Pajak penghasilan penjual

    const totalBuyerCosts = price + bphtb + notary + registration;

    return {
      total: totalBuyerCosts,
      breakdown: [
        { label: "Harga Pembelian", amount: price },
        { label: "BPHTB (pajak transfer 5%)", amount: bphtb },

      ],
      currency: "IDR",
      note: `Penjual juga membayar PPh ${(pph / 1000000).toFixed(0)}M (2.5%)`

## Hal yang Perlu Diperiksa

### Uji Tuntas Bangunan

- Rekam jejak pengembang
- Status penyelesaian bangunan
- Hak milik strata diterbitkan/tertunda
- Kualitas perusahaan manajemen
- Kepemilikan asing diizinkan

### Uji Tuntas Unit

- Status hak milik (SHMSRS diterbitkan)
- Beban apapun
- Kondisi serah terima
- Termasuk (perabot, dll.)

<InfoCard variant="tip" title="Baru vs Bekas">
  **Baru dari pengembang**: Mungkin mendapatkan hak milik strata nanti (PPJB dulu) **Bekas**:
  Seharusnya memiliki hak milik strata yang siap untuk transfer
</InfoCard>

## Biaya Berkelanjutan

### Biaya Bulanan/Tahunan

| Biaya                | Kisaran Tipikal       | Catatan                  |
| -------------------- | --------------------- | ------------------------ |
| Biaya layanan        | IDR 50-100k/sqm/bulan | Pemeliharaan bangunan    |
| Dana cadangan        | IDR 10-30k/sqm/bulan  | Cadangan perbaikan besar |
| PBB (pajak properti) | 0.1-0.3% per tahun    | Pajak tahunan            |
| Asuransi             | Bervariasi            | Isi pribadi              |

### Jika Disewakan

- Pajak penghasilan sewa: 10% dari bruto sewa
- Biaya manajemen: 10-20% dari sewa
