# Impôt sur les revenus locatifs en Indonesia 2026 : Guide du propriétaire

Si vous louez une propriété en Indonesia, vous devez comprendre comment les revenus locatifs sont imposés. Voici ce que les propriétaires immobiliers doivent savoir.

## Aperçu de l'impôt sur les revenus locatifs

<InfoCard variant="note" title="Impôt final de 10%">
Les revenus locatifs provenant de terrains et de bâtiments en Indonesia sont soumis à un **impôt final de 10% (PPh Final)** sur le montant brut du loyer.

"Final" signifie qu'il s'agit de l'impôt complet - vous ne l'ajoutez pas à vos autres revenus pour les taux progressifs.

</InfoCard>

---

## Comment ça marche

### Taux d'imposition et base

| Élément           | Détail                   |
| ----------------- | ------------------------ |
| Taux d'imposition | 10%                      |
| Base d'imposition | Loyer brut perçu         |
| Type d'impôt      | PPh Final (Article 4(2)) |
| Déductions        | Aucune autorisée         |

### Points importants

- Calculé sur le **loyer brut** (aucune déduction de dépenses)
- Impôt **final** - non combiné avec d'autres revenus
- S'applique à tous les types de location (résidentielle, commerciale)
- Même taux pour les particuliers et les entreprises

## Qui perçoit l'impôt ?

### Locataires entreprises (retenue à la source)

Si votre locataire est une entreprise (sujet fiscal) :

1. Le locataire retient 10% du paiement du loyer
2. Le locataire paie l'impôt au gouvernement
3. Le locataire vous remet un **Bukti Potong** (reçu fiscal)
4. Vous recevez le loyer net (90%)

<InfoCard variant="note" title="Le Bukti Potong est votre preuve">
  Le Bukti Potong prouve que votre impôt a été payé. Gardez-le pour vos dossiers
  et incluez-le dans votre déclaration de revenus annuelle.
</InfoCard>

### Locataires individuels (auto-paiement)

Si votre locataire est un particulier :

1. Vous recevez l'intégralité du loyer (100%)
2. **Vous** devez payer 10% d'impôt
3. Payez via la banque ou le bureau des impôts
4. Déclarez dans la déclaration de revenus annuelle

## Imposition de la location de villa

Pour les locations à court terme/de vacances :

### L'impôt s'applique à chaque location

- 10% sur chaque paiement de loyer
- S'applique même aux tarifs à la nuitée
- La société de gestion peut collecter et payer

### Si vous utilisez une société de gestion

De nombreux propriétaires de villa utilisent des sociétés de gestion qui :

1. Collectent les loyers auprès des clients
2. Retiennent et paient 10% d'impôt
3. Vous fournissent les documents
4. Gèrent la déclaration

<InfoCard variant="tip" title="Clarifier la gestion fiscale">
  Lorsque vous engagez une société de gestion de villa, clarifiez : - Qui paie
  l'impôt locatif de 10% ? - Fourniront-ils un Bukti Potong ? - L'impôt est-il
  inclus dans leur structure de frais ?
</InfoCard>

## Autres taxes foncières

Outre l'impôt sur les revenus locatifs, les propriétaires immobiliers paient également :

### PBB (Impôt foncier et immobilier)

| Aspect    | Détail              |
| --------- | ------------------- |
| Taux      | 0.1% - 0.3% de NJOP |
| Fréquence | Annuel              |
| Paiement  | Avant le 31 août    |
| Qui paie  | Propriétaire        |

**NJOP** = Nilai Jual Objek Pajak (valeur imposable, souvent inférieure au marché)

### BPHTB (Taxe de transfert)

- 5% lors de l'achat d'une propriété
- Payé par l'acheteur
- Une seule fois à l'achat

## Considérations pour les propriétaires étrangers

### Si vous êtes résident fiscal

Déclarez les revenus locatifs sur votre SPT annuel (Formulaire 1770) :

- Incluez-les dans la section revenus
- Déclarez l'impôt déjà payé
- Pas d'impôt supplémentaire (il est final)

### Si vous êtes non-résident

- L'impôt final de 10% s'applique toujours
- Peut avoir des implications conventionnelles
- Envisagez d'obtenir un formulaire DGT pour une retenue à la source réduite sur d'autres revenus

<InfoCard variant="warning" title="N'ignorez pas l'impôt locatif">
  Le non-paiement de l'impôt sur les revenus locatifs peut entraîner : - Des
  rappels d'impôts avec intérêts - Des pénalités allant jusqu'à 200% - Des
  problèmes lors de futures transactions immobilières - Des problèmes avec le
  renouvellement du visa (le cas échéant)
</InfoCard>
