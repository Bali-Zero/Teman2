# Acheter une villa à Bali en 2026 : Guide pour les étrangers

Posséder une villa à Bali est un rêve pour beaucoup. Voici tout ce que vous devez savoir pour le concrétiser.

## Les étrangers peuvent-ils acheter ?

<InfoCard variant="warning" title="La réponse courte">
**Les étrangers ne peuvent pas posséder de terres en pleine propriété en Indonesia.**

Mais il existe des moyens légaux d'acquérir une propriété :

- **Leasehold** (bail à long terme)
- **Hak Pakai** (droit d'usage - pour résidence personnelle)
- **PT PMA** (propriété d'entreprise)

Chacune a ses avantages et ses inconvénients - choisissez en fonction de votre situation.

</InfoCard>

## Calculateur de coûts

<Calculator
  title="Budget d'achat de villa"
  description="Estimer les coûts totaux"
  fields={[
    {
      id: "price",
      label: "Prix de la villa (IDR)",
      type: "number",
      defaultValue: 5000000000,
      min: 0
    },
    {
      id: "structure",
      label: "Structure de propriété",
      type: "select",
      options: [
        { value: "leasehold", label: "Leasehold" },
        { value: "hakpakai", label: "Hak Pakai" },
        { value: "ptpma", label: "PT PMA + HGB" }
      ],
      defaultValue: "leasehold"
    }
  ]}
  calculateResult={(values) => {
    const price = values.price;
    let structureCost = 0;
    let transferTax = 0;
    let notary = price * 0.01;
    let legal = 0;

    if (values.structure === "leasehold") {
      structureCost = 0;
      transferTax = 0; // No BPHTB on lease
      legal = 30000000;
    } else if (values.structure === "hakpakai") {
      transferTax = price * 0.05; // BPHTB
      legal = 50000000;
    } else {
      structureCost = 150000000; // PT PMA setup
      transferTax = price * 0.05; // BPHTB
      legal = 75000000;
    }

    const agent = price * 0.05; // If using agent
    const misc = 20000000;

    const total = price + structureCost + transferTax + notary + legal + agent + misc;

    return {
      total: total,
      breakdown: [
        { label: "Prix de la villa", amount: price },
        { label: "Coût de la structure (si PT PMA)", amount: structureCost },
        { label: "Taxe de transfert (BPHTB)", amount: transferTax },
        { label: "Frais de notaire", amount: Math.round(notary) },
        { label: "Frais juridiques", amount: legal },
        { label: "Commission d'agent (5%)", amount: Math.round(agent) },
        { label: "Divers", amount: misc }
      ],
      currency: "IDR",
      note: `~USD ${Math.round(total / 16000).toLocaleString()} total`
    };

}}

## Erreurs courantes

<InfoCard variant="warning" title="Évitez-les">
**Erreurs courantes des acheteurs :**

1.  **Ne pas faire la diligence raisonnable** - Les problèmes de titre sont courants
2.  **Utiliser un prête-nom** - Risqué, non recommandé
3.  **Ignorer l'examen juridique** - Toujours utiliser un avocat
4.  **Payer trop vite** - Retenir jusqu'à ce que tout soit clair
5.  **Mauvaise structure** - Adapter à vos besoins
6.  **Ignorer le zonage** - Pourrait ne pas pouvoir louer
7.  **Accords verbaux** - Tout mettre par écrit
8.  **Ne pas budgétiser les extras** - 10-15% en plus du prix
    </InfoCard>
