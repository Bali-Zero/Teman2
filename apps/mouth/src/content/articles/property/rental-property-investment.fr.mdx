## Attentes de rendement

### Rendements typiques

| Type de propriété          | Rendement brut | Rendement net |
| -------------------------- | -------------- | ------------- |
| Villa à Bali (court terme) | 8-15%          | 5-10%         |
| Villa à Bali (long terme)  | 5-8%           | 4-6%          |
| Appartement à Jakarta      | 5-7%           | 4-5%          |
| Appartement avec services  | 6-10%          | 4-7%          |

<InfoCard variant="warning" title="Attentes réalistes">
**Soyez réaliste :**

- Les rendements bruts ignorent les dépenses
- Les rendements nets sont plus importants
- Le taux d'occupation varie (60-80% typique pour le court terme)
- Les coûts d'entretien s'additionnent
- Frais de gestion 15-25%
- La taxe réduit davantage les rendements

Visez un rendement net de 5-8% pour une planification réaliste.

</InfoCard>

### Calculateur de rendement

<Calculator
  title="Estimation du rendement locatif"
  description="Calculez les rendements potentiels"
  fields={[
    {
      id: "purchase",
      label: "Valeur de la propriété (IDR)",
      type: "number",
      defaultValue: 3000000000,
      min: 0
    },
    {
      id: "monthlyRate",
      label: "Loyer mensuel (IDR)",
      type: "number",
      defaultValue: 25000000,
      min: 0
    },
    {
      id: "occupancy",
      label: "Taux d'occupation prévu (%)",
      type: "number",
      defaultValue: 70,
      min: 0,
      max: 100
    },
    {
      id: "managed",
      label: "Gestion immobilière ?",
      type: "select",
      options: [
        { value: "yes", label: "Oui (20% des revenus)" },
        { value: "no", label: "Non (autogestion)" }
      ],
      defaultValue: "yes"
    }
  ]}
  calculateResult={(values) => {
    const annualGross = values.monthlyRate * 12 * (values.occupancy / 100);
    const managementFee = values.managed === "yes" ? annualGross * 0.20 : 0;
    const maintenance = annualGross * 0.10; // 10% for maintenance
    const utilities = values.monthlyRate * 0.1 * 12; // Rough utility estimate
    const tax = annualGross * 0.10; // 10% rental income tax

    const totalExpenses = managementFee + maintenance + utilities + tax;
    const netIncome = annualGross - totalExpenses;

    const grossYield = (annualGross / values.purchase) * 100;
    const netYield = (netIncome / values.purchase) * 100;

    return {
      total: Math.round(netIncome),
      breakdown: [
        { label: "Revenu locatif annuel brut", amount: Math.round(annualGross) },
        { label: "Gestion immobilière", amount: -Math.round(managementFee) },
        { label: "Maintenance (10%)", amount: -Math.round(maintenance) },
        { label: "Estimation des services publics", amount: -Math.round(utilities) },
        { label: "Taxe locative (10%)", amount: -Math.round(tax) },
        { label: "REVENU ANNUEL NET", amount: Math.round(netIncome) },
        { label: "Rendement brut", amount: `${grossYield.toFixed(1)}%` },
        { label: "Rendement net", amount: `${netYield.toFixed(1)}%` }
      ],
      currency: "IDR",
      note: `Rendement net : ${netYield.toFixed(1)}% (~USD ${Math.round(netIncome / 16000).toLocaleString()}/an)`
    };

}}
/>

## Obligations fiscales

### Taxe sur les revenus locatifs

<InfoCard variant="note" title="Taxe finale de 10%">
Les revenus locatifs immobiliers sont soumis à :

**10% de taxe finale** sur le revenu locatif brut

- Aucune déduction pour les dépenses
- Finale (non ajoutée à d'autres revenus)
- Retenue par les locataires corporatifs
- Auto-évaluée pour les locataires individuels
  </InfoCard>

### Via PT PMA

| Article                   | Traitement              |
| ------------------------- | ----------------------- |
| Revenu locatif            | Revenu de la société    |
| Dépenses                  | Déductibles             |
| Amortissement             | Bâtiment : 5%/an        |
| Impôt sur le bénéfice net | 22% IS                  |
| Dividende                 | 10% Retenue à la source |
