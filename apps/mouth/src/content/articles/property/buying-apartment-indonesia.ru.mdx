# Покупка квартиры в Индонезии 2026: Руководство для иностранцев

Квартиры (кондоминиумы) предлагают один из самых четких юридических путей для иностранцев к владению недвижимостью в Индонезии. Вот ваше полное руководство.

## Могут ли иностранцы покупать квартиры?

<InfoCard variant="note" title="Yes, With Requirements">
  Иностранцы могут владеть квартирами в Индонезии при определенных условиях: - Должны иметь
  действующий **KITAS или KITAP** - Недвижимость должна соответствовать требованиям **минимальной
  цены** - Должна находиться в здании с **правом собственности на квартиру (strata title)**,
  одобренном для владения иностранцами - Владение осуществляется через **Hak Milik Satuan Rumah
  Susun** (HMSRS) или **Hak Pakai** strata
</InfoCard>

---

## Право собственности на квартиру (Strata Title)

Когда вы покупаете квартиру, вы получаете:

### Что вы владеете

- **Единица**: Ваше конкретное жилое пространство
- **Доля общей собственности**: Пропорциональное владение общими объектами
- **Права членства**: В управлении зданием (P3SRS)

### Общая собственность включает

- Земля, на которой стоит здание
- Конструкция и крыша
- Коридоры и вестибюли
- Бассейны и тренажерные залы
- Парковочные сооружения
- Сады и общие зоны

## Расчет затрат

<Calculator
  title="Apartment Purchase Costs"
  description="Рассчитайте общие затраты на покупку"
  fields={[
    {
      id: "price",
      label: "Цена покупки (IDR)",
      type: "number",
      defaultValue: 3000000000,

      step: 100000000,
      suffix: "IDR"

  ]}
  calculateResult={(values) => {
    const price = Number(values.price);

    // Transfer costs
    const bphtb = price * 0.05; // Buyer transfer tax
    const notary = price * 0.01; // Notary fees (approx)
    const registration = 1000000; // BPN registration

    // Seller pays, but affects negotiation
    const pph = price * 0.025; // Seller income tax

    const totalBuyerCosts = price + bphtb + notary + registration;

    return {
      total: totalBuyerCosts,
      breakdown: [
        { label: "Цена покупки", amount: price },
        { label: "BPHTB (5% налог на передачу)", amount: bphtb },
        { label: "Нотариальные сборы (~1%)", amount: notary },
        { label: "Регистрация BPN", amount: registration },
        { label: "Общая стоимость", amount: totalBuyerCosts }
      ],
      currency: "IDR",
      note: `Продавец также платит PPh ${(pph / 1000000).toFixed(0)}M (2.5%)`
    };

}}

## Что проверить

### Надлежащая проверка здания

- Репутация застройщика
- Статус завершения строительства
- Выданное/ожидающее право собственности на квартиру
- Качество управляющей компании
- Разрешено ли владение иностранцам

### Надлежащая проверка объекта

- Статус права собственности (выдан HMSRS)
- Любые обременения
- Состояние при передаче
- Включения (мебель и т.д.)

<InfoCard variant="tip" title="New vs Resale">
  **Новое от застройщика**: Право собственности на квартиру может быть получено позже (сначала PPJB)
  **Перепродажа**: Право собственности на квартиру должно быть готово к передаче
</InfoCard>

## Текущие расходы

### Ежемесячные/ежегодные сборы

| Стоимость                   | Типичный диапазон         | Примечания                   |
| --------------------------- | ------------------------- | ---------------------------- |
| Плата за обслуживание       | IDR 50-100k/кв.м/месяц    | Обслуживание здания          |
| Амортизационный фонд        | IDR 10-30k/кв.м/месяц     | Резерв на капитальный ремонт |
| PBB (налог на недвижимость) | 0.1-0.3% от стоимости/год | Ежегодный налог              |
| Страхование                 | Варьируется               | Личное имущество             |

### При сдаче в аренду

- Налог на доход от аренды: 10% от валовой арендной платы
- Комиссия за управление: 10-20% от арендной платы
