## Calcolatore di Investimento

<Calculator
  title="Analisi dell'Investimento in Villa"
  description="Stima i costi di investimento e i rendimenti"
  fields={[
    {
      id: "purchasePrice",
      label: "Prezzo di acquisto/leasing (IDR)",
      type: "number",
      defaultValue: 5000000000,
      min: 1000000000,
      step: 500000000,
      suffix: "IDR"
    },
    {
      id: "bedrooms",
      label: "Camere da letto",
      type: "select",
      options: [
        { value: "2", label: "2 Camere da letto" },
        { value: "3", label: "3 Camere da letto" },
        { value: "4", label: "4 Camere da letto" },
        { value: "5", label: "5+ Camere da letto" }
      ],
      defaultValue: "3"
    },
    {
      id: "location",
      label: "Posizione",
      type: "select",
      options: [
        { value: "premium", label: "Premium (Seminyak, centro Canggu)" },
        { value: "good", label: "Buona (Pererenan, Umalas)" },
        { value: "developing", label: "In via di sviluppo (Tabanan, Nord)" }
      ],
      defaultValue: "good"
    },
    {
      id: "occupancy",
      label: "Occupazione prevista %",
      type: "number",
      defaultValue: 60,
      min: 20,
      max: 90
    }
  ]}
  calculateResult={(values) => {
    const purchase = Number(values.purchasePrice);
    const bedrooms = Number(values.bedrooms);
    const occupancy = Number(values.occupancy) / 100;

    // Nightly rates by location and bedrooms
    const rateMap = {
      "premium-2": 3000000, "premium-3": 4500000, "premium-4": 6000000, "premium-5": 8000000,
      "good-2": 2000000, "good-3": 3000000, "good-4": 4000000, "good-5": 5500000,
      "developing-2": 1200000, "developing-3": 1800000, "developing-4": 2500000, "developing-5": 3500000
    };

    const nightlyRate = rateMap[`${values.location}-${values.bedrooms}`] || 2500000;
    const annualGross = nightlyRate * 365 * occupancy;

    // Operating costs
    const management = annualGross * 0.20; // 20% management
    const maintenance = 60000000; // General maintenance
    const utilities = 36000000; // Utilities avg
    const marketing = 24000000; // OTA fees, marketing
    const insurance = 12000000;
    const tax = annualGross * 0.10; // Rental income tax

    const totalCosts = management + maintenance + utilities + marketing + insurance + tax;
    const netIncome = annualGross - totalCosts;
    const grossYield = (annualGross / purchase) * 100;
    const netYield = (netIncome / purchase) * 100;

    return {
      total: netIncome,
      breakdown: [
        { label: "Ricavo Annuo Lordo", amount: annualGross },
        { label: "Gestione (20%)", amount: -management },
        { label: "Manutenzione", amount: -maintenance },
        { label: "Utenze", amount: -utilities },
        { label: "Marketing/OTA", amount: -marketing },
        { label: "Assicurazione", amount: -insurance },
        { label: "Tasse sull'affitto (10%)", amount: -tax },
        { label: "Reddito Annuo Netto", amount: netIncome }
      ],
      currency: "IDR",
      note: `Rendimento lordo: ${grossYield.toFixed(1)}% | Rendimento netto: ${netYield.toFixed(1)}%`
    };

}}
/>

## Licenze per l'Affitto

<InfoCard variant="warning" title="Licenza di affitto richiesta">
Gestire una villa in affitto richiede:
- Licenza **Pondok Wisata** per piccole strutture
- **TDUP** per operazioni più grandi
- Registrazione turistica
- Vari permessi locali

Operare senza licenze comporta il rischio di multe, chiusura e problemi con il visto.

</InfoCard>

### Requisiti per le Licenze

| Licenza       | Per                   | Emessa da          |
| ------------- | --------------------- | ------------------ |
| Pondok Wisata | Piccole guesthouse    | Governo locale     |
| TDUP          | Strutture turistiche  | Dip. del Turismo   |
| NIB           | Registrazione aziend. | OSS                |
| Ambientale    | Impatto operativo     | Dip. dell'Ambiente |

## Rischi Comuni

### Rischi di Mercato

- Sovraofferta nelle zone popolari
- Fluttuazioni del turismo
- Concorrenza degli hotel
- Cambiamenti normativi

### Rischi Operativi

- Problemi gestionali
- Problemi di manutenzione
- Danni causati dagli ospiti
- Sfide con il personale

### Rischi Legali

- Controversie sui titoli
- Problemi con le licenze
- Scadenza del leasing
- Complicazioni fiscali
