## Tassa Annuale sulla Proprietà (PBB)

### Cos'è la PBB?

<InfoCard variant="note" title="Pajak Bumi dan Bangunan">
La **PBB** (Tassa su Terreni e Fabbricati) è:
- Tassa annuale sulla proprietà di immobili
- Basata sul valore valutato dal governo (NJOP)
- Pagata dal proprietario dell'immobile
- Scadenza entro agosto di ogni anno

Tutti i proprietari di terreni e fabbricati devono pagare la PBB.

</InfoCard>

### Calcolo della PBB

| Componente        | Spiegazione                           |
| ----------------- | ------------------------------------- |
| NJOP              | Valore valutato dal governo           |
| NJOPTKP           | Soglia esente (varia per regione)     |
| Valore imponibile | NJOP meno NJOPTKP                     |
| Aliquota          | 0,1-0,5% (varia per regione e valore) |

### Calcolatore PBB

<Calculator
  title="Stima PBB"
  description="Stima la tua tassa annuale sulla proprietà"
  fields={[
    {
      id: "njop",
      label: "Valore NJOP (IDR)",
      type: "number",
      defaultValue: 500000000,
      min: 0
    },
    {
      id: "region",
      label: "Regione",
      type: "select",
      options: [
        { value: "jakarta", label: "Giacarta" },
        { value: "bali", label: "Bali" },
        { value: "other", label: "Altro" }
      ],
      defaultValue: "bali"
    }
  ]}
  calculateResult={(values) => {
    // Il NJOPTKP varia in base alla regione
    const njoptkp = {
      jakarta: 60000000,
      bali: 50000000,
      other: 30000000
    };

    const threshold = njoptkp[values.region];
    const taxable = Math.max(0, values.njop - threshold);

    // Aliquota semplificata (quella effettiva varia per scaglioni)
    let rate;
    if (values.njop < 1000000000) {
      rate = 0.001; // 0.1%
    } else if (values.njop < 2000000000) {
      rate = 0.002; // 0.2%
    } else {
      rate = 0.003; // 0.3%
    }

    const tax = taxable * rate;

    return {
      total: Math.round(tax),
      breakdown: [
        { label: "Valore NJOP", amount: values.njop },
        { label: "NJOPTKP (soglia)", amount: threshold },
        { label: "Valore imponibile", amount: taxable },
        { label: "Aliquota effettiva", amount: `${(rate * 100).toFixed(2)}%` },
        { label: "PBB Annuale", amount: Math.round(tax) }
      ],
      currency: "IDR",
      note: "La tassa effettiva può variare in base alle normative locali"
    };

}}
/>

## Tassa di Trasferimento/Acquisizione (BPHTB)

### Cosa Pagano gli Acquirenti

<InfoCard variant="warning" title="BPHTB - Tassa di Trasferimento del 5%">
La **BPHTB** si applica quando si acquisisce una proprietà tramite:
- Acquisto
- Donazione
- Eredità
- Permuta

**Aliquota:** 5% del valore di trasferimento meno il NJOPTKP
**Pagata da:** Acquirente/destinatario
**Quando:** Prima del trasferimento del titolo

</InfoCard>

### Calcolo della BPHTB

| Elemento           | Calcolo                       |
| ------------------ | ----------------------------- |
| Valore transazione | Il maggiore tra prezzo o NJOP |
| Meno NJOPTKP       | Soglia esente da imposte      |
| Base imponibile    | Risultato                     |
| BPHTB              | 5% della base imponibile      |

### Esempio

| Voce              | Importo            |
| ----------------- | ------------------ |
| Prezzo d'acquisto | 2.000.000.000 IDR  |
| NJOP              | 1.500.000.000 IDR  |
| Valore maggiore   | 2.000.000.000 IDR  |
| NJOPTKP           | 60.000.000 IDR     |
| Base imponibile   | 1.940.000.000 IDR  |
| **BPHTB (5%)**    | **97.000.000 IDR** |

## Tassa del Venditore (PPh Final)

### Cosa Pagano i Venditori

| Transazione      | Aliquota Fiscale            |
| ---------------- | --------------------------- |
| Vendita immobile | 2,5% del valore transazione |
| Vendita terreno  | 2,5% del valore transazione |

<InfoCard variant="note" title="Tassa del Venditore">
  **La PPh Final del 2,5%** è: - Pagata dal venditore - Basata sul valore della transazione (o NJOP
  se superiore) - Scade prima del trasferimento del titolo - Finale (nessuna ulteriore imposta sul
  reddito sulla plusvalenza)
</InfoCard>

## Tassa sul Reddito da Locazione

### Tassa sull'Affitto Ricevuto

<InfoCard variant="note" title="Imposta Finale del 10%">
Il reddito da locazione di immobili è soggetto a:

**PPh Finale del 10%** sul reddito lordo da locazione

- Si applica a terreni e fabbricati
- Nessuna deduzione per le spese
- Finale (non aggiunto ad altri redditi)
- Deve essere trattenuto dagli inquilini aziendali
  </InfoCard>

### Chi Trattiene?

| Tipo di Inquilino   | Trattamento Fiscale      |
| ------------------- | ------------------------ |
| Inquilino aziendale | Deve trattenere il 10%   |
| Inquilino privato   | Il proprietario dichiara |

### Reporting

| Situazione          | Azione                           |
| ------------------- | -------------------------------- |
| Inquilino aziendale | Rilasciano la bukti potong       |
| Inquilino privato   | Tu dichiari e paghi              |
| Misto               | Dichiarare tutto nel SPT annuale |

## Spiegazione del NJOP

### Cos'è il NJOP?

<InfoCard variant="note" title="Valore Valutato dal Governo">
Il **NJOP** (Nilai Jual Objek Pajak) è:
- Valore della proprietà valutato dal governo
- Utilizzato per i calcoli fiscali
- Di solito inferiore al valore di mercato
- Aggiornato periodicamente

Trova il tuo NJOP sul tuo SPPT (avviso fiscale) o verifica presso l'ufficio fiscale locale.

</InfoCard>

### NJOP vs Valore di Mercato

| Aspetto             | NJOP               | Valore di Mercato |
| ------------------- | ------------------ | ----------------- |
| Stabilito da        | Governo            | Mercato           |
| Livello tipico      | 50-80% del mercato | 100%              |
| Freq. aggiornamento | Periodica          | In tempo reale    |
| Utilizzato per      | Tasse              | Transazioni       |

## Consigli per la Pianificazione Fiscale

### Modi Legali per Minimizzare

| Strategia             | Come Funziona                                   |
| --------------------- | ----------------------------------------------- |
| Tempismo acquisizione | La fine dell'anno può permettere pianificazione |
| Struttura proprietà   | PT PMA vs personale                             |
| Utilizzare NJOPTKP    | Assicurarsi che venga applicata la soglia       |
| Pagare PBB in tempo   | Evitare sanzioni                                |
| Documentare spese     | Per la base di vendita futura                   |

<InfoCard variant="warning" title="Conformità Fiscale">
**Cosa NON fare:**
- Sottodichiarare i valori delle transazioni
- Nascondere la proprietà di immobili
- Non pagare la PBB
- Ignorare il reddito da locazione

Le autorità fiscali incrociano i dati con i registri del BPN e dei notai. La non conformità crea problemi quando si desidera vendere.

</InfoCard>
