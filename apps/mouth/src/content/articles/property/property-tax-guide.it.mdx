## Imposta Annuale sugli Immobili (PBB)

### Cos'è il PBB?

<InfoCard variant="note" title="Imposta su Terreni e Edifici">
**PBB** (Imposta su Terreni e Edifici) è:
- Imposta annuale sulla proprietà immobiliare
- Basata sul valore determinato dal governo (NJOP)
- Pagata dal proprietario dell'immobile
- Dovuta entro agosto di ogni anno

Tutti i proprietari di terreni e edifici devono pagare il PBB.

</InfoCard>

### Calcolo del PBB

| Componente     | Spiegazione                           |
| --------------- | ------------------------------------- |
| NJOP            | Valore determinato dal governo        |
| NJOPTKP         | Soglia esente da tasse (varia per regione) |
| Valore imponibile | NJOP meno NJOPTKP                    |
| Aliquota fiscale | 0.1-0.5% (varia per regione e valore) |

### Calcolatore PBB

<Calculator
  title="Stima PBB"
  description="Stima la tua imposta annuale sugli immobili"
  fields={[
    {
      id: "njop",
      label: "Valore NJOP (IDR)",
      type: "number",
      defaultValue: 500000000,
      min: 0
    },
    {
      id: "region",
      label: "Regione",
      type: "select",
      options: [
        { value: "jakarta", label: "Jakarta" },
        { value: "bali", label: "Bali" },
        { value: "other", label: "Altro" }
      ],
      defaultValue: "bali"
    }
  ]}
  calculateResult={(values) => {
    // NJOPTKP varies by region
    const njoptkp = {
      jakarta: 60000000,
      bali: 50000000,
      other: 30000000
    };

    const threshold = njoptkp[values.region];
    const taxable = Math.max(0, values.njop - threshold);

    // Simplified rate (actual varies by bracket)
    let rate;
    if (values.njop < 1000000000) {
      rate = 0.001; // 0.1%
    } else if (values.njop < 2000000000) {
      rate = 0.002; // 0.2%
    } else {
      rate = 0.003; // 0.3%
    }

    const tax = taxable * rate;

    return {
      total: Math.round(tax),
      breakdown: [
        { label: "Valore NJOP", amount: values.njop },
        { label: "NJOPTKP (soglia)", amount: threshold },
        { label: "Valore imponibile", amount: taxable },
        { label: "Aliquota effettiva", amount: `${(rate * 100).toFixed(2)}%` },
        { label: "PBB Annuale", amount: Math.round(tax) }
      ],
      currency: "IDR",
      note: "L'imposta reale può variare in base alle normative locali"
    };

}}
/>

## Imposta su Trasferimento/Acquisizione (BPHTB)

### Cosa Pagano gli Acquirenti

<InfoCard variant="warning" title="BPHTB - Imposta sul Trasferimento 5%">
**BPHTB** si applica quando acquisti un immobile:
- Acquisto
- Donazione
- Eredità
- Scambio

**Aliquota:** 5% del valore di trasferimento meno NJOPTKP
**Pagato da:** Acquirente/beneficiario
**Quando:** Prima del trasferimento del titolo

</InfoCard>

### Calcolo del BPHTB

| Elemento           | Calcolo             |
| ------------------- | -------------------- |
| Valore della transazione | Maggiore tra prezzo o NJOP |
| Meno NJOPTKP        | Soglia esente da tasse |
| Base imponibile     | Risultato           |
| BPHTB               | 5% della base imponibile |

### Esempio

| Voce             | Importo             |
| ----------------- | -------------------- |
| Prezzo di acquisto   | IDR 2.000.000.000    |
| NJOP              | IDR 1.500.000.000    |
| Usa il valore maggiore | IDR 2.000.000.000    |
| NJOPTKP           | IDR 60.000.000       |
| Base imponibile   | IDR 1.940.000.000    |
| **BPHTB (5%)**     | **IDR 97.000.000**   |

## Imposta sul Venditore (PPh Final)

### Cosa Pagano i Venditori

| Transazione       | Aliquota Fiscale                  |
| ------------------ | ---------------------------------- |
| Vendita immobiliare | 2.5% del valore della transazione |
| Vendita di terreni   | 2.5% del valore della transazione |

<InfoCard variant="note" title="Imposta sul Venditore">

  **PPh Final 2.5%** è: - Pagata dal venditore - Basata sul valore della transazione (o NJOP se più alto) - Dovuta prima del trasferimento del titolo - Finale (nessuna ulteriore imposta sul reddito sul guadagno)
</InfoCard>

## Imposta sul Reddito da Affitto

### Imposta sugli Affitti Ricevuti

<InfoCard variant="note" title="Imposta Finale 10%">
Il reddito da affitto derivante da immobili è soggetto a:

**PPh Finale al 10%** sul reddito lordo da affitto

- Si applica a terreni e edifici
- Nessuna deduzione per spese
- Finale (non aggiunta ad altri redditi)
- Dovrebbe essere trattenuta dai locatari aziendali
</InfoCard>

### Chi Trattiene?

| Tipo di Locatario       | Trattamento Fiscale          |
| ------------------------ | ---------------------------- |
| Locatario aziendale      | Deve trattenere il 10%       |
| Locatario privato        | Il locatore si autodeclara   |

### Segnalazione

| Situazione         | Azione                    |
| ------------------- | -------------------------- |
| Locatario aziendale | Emettono *bukti potong*    |
| Locatario privato   | Tu devi dichiarare e pagare |
| Misto               | Dichiarare tutto nell'SPT annuale |

## NJOP Spiegato

### Cos'è il NJOP?

<InfoCard variant="note" title="Valore Determinato dal Governo">
**NJOP** (Nilai Jual Objek Pajak) è:
- Valore dell'immobile determinato dal governo
- Utilizzato per i calcoli fiscali
- Di solito inferiore al valore di mercato
- Aggiornato periodicamente

Trova il tuo NJOP sulla tua SPPT (avviso fiscale) o verifica presso l'ufficio tributario locale.

</InfoCard>

### NJOP vs Valore di Mercato

| Aspetto           | NJOP             | Valore di Mercato |
| ------------------ | ----------------- | ------------------ |
| Determinato da    | Governo           | Mercato            |
| Livello tipico    | 50-80% del mercato | 100%               |
| Frequenza aggiornamento | Periodico        | In tempo reale     |
| Utilizzato per    | Tasse             | Transazioni        |

## Consigli per la Pianificazione Fiscale

### Modi Legali per Ridurre le Tasse

| Strategia            | Come Funziona                |
| --------------------- | ----------------------------- |
| Tempistica acquisto  | La fine dell'anno può permettere pianificazione |
| Struttura proprietà   | PT PMA vs personale          |
| Usa NJOPTKP          | Assicurati che la soglia sia applicata    |
| Salda PBB in tempo   | Evita sanzioni                |
| Documenta spese      | Per la base di futura vendita       |

<InfoCard variant="warning" title="Conformità Fiscale">
**Non:**
- Sotto-dichiarare i valori delle transazioni
- Nascondere la proprietà immobiliare
- Non pagare il PBB
- Ignorare il reddito da affitto

Le autorità fiscali incrociano i dati con i registri BPN e notarili. La non conformità crea problemi quando vuoi vendere.

</InfoCard>
