## Tassa Annuale sugli Immobili (PBB)

### Cos'è il PBB?

<InfoCard variant="note" title="Tasse su Terreni e Edifici">
**PBB** (Tasse su Terreni e Edifici) è:
- Tassa annuale sulla proprietà immobiliare
- Basata sul valore stimato dal governo (NJOP)
- Pagata dal proprietario dell'immobile
- Dovuta entro agosto di ogni anno

Tutti i proprietari di terreni e edifici devono pagare il PBB.

</InfoCard>

### Calcolo del PBB

| Componente     | Spiegazione                           |
| ------------- | ------------------------------------- |
| NJOP          | Valore stimato dal governo             |
| NJOPTKP       | Soglia esente da tasse (varia per regione) |
| Valore imponibile | NJOP meno NJOPTKP                    |
| Aliquota      | 0.1-0.5% (varia per regione e valore) |

### Calcolatore PBB

<Calculator
  title="Stima PBB"
  description="Stima la tua tassa annuale sugli immobili"
  fields={[
    {
      id: "njop",
      label: "Valore NJOP (IDR)",
      type: "number",
      defaultValue: 500000000,
      min: 0
    },
    {
      id: "region",
      label: "Regione",
      type: "select",
      options: [
        { value: "jakarta", label: "Jakarta" },
        { value: "bali", label: "Bali" },
        { value: "other", label: "Altro" }
      ],
      defaultValue: "bali"
    }
  ]}
  calculateResult={(values) => {
    // NJOPTKP varies by region
    const njoptkp = {
      jakarta: 60000000,
      bali: 50000000,
      other: 30000000
    };

    const threshold = njoptkp[values.region];
    const taxable = Math.max(0, values.njop - threshold);

    // Simplified rate (actual varies by bracket)
    let rate;
    if (values.njop < 1000000000) {
      rate = 0.001; // 0.1%
    } else if (values.njop < 2000000000) {
      rate = 0.002; // 0.2%
    } else {
      rate = 0.003; // 0.3%
    }

    const tax = taxable * rate;

    return {
      total: Math.round(tax),
      breakdown: [
        { label: "Valore NJOP", amount: values.njop },
        { label: "NJOPTKP (soglia)", amount: threshold },
        { label: "Valore imponibile", amount: taxable },
        { label: "Aliquota effettiva", amount: `${(rate * 100).toFixed(2)}%` },
        { label: "PBB Annuale", amount: Math.round(tax) }
      ],
      currency: "IDR",
      note: "La tassa reale può variare in base alle normative locali"
    };

}}
/>

## Tassa su Trasferimento/Acquisizione (BPHTB)

### Cosa Pagano gli Acquirenti

<InfoCard variant="warning" title="BPHTB - Tassa sul Trasferimento 5%">
Il **BPHTB** si applica quando acquisti un immobile:
- Acquisto
- Donazione
- Eredità
- Scambio

**Aliquota:** 5% del valore di trasferimento meno NJOPTKP
**Pagato da:** Acquirente/beneficiario
**Quando:** Prima del trasferimento del titolo

</InfoCard>

### Calcolo del BPHTB

| Elemento           | Calcolo             |
| ----------------- | ----------------------- |
| Valore dell'operazione | Prezzo più alto o NJOP |
| Minus NJOPTKP     | Soglia esente da tasse      |
| Base imponibile          | Risultato                  |
| BPHTB             | 5% della base imponibile          |

### Esempio

| Voce             | Importo             |
| ---------------- | ------------------ |
| Prezzo di acquisto   | IDR 2.000.000.000  |
| NJOP             | IDR 1.500.000.000  |
| Usa il valore più alto | IDR 2.000.000.000  |
| NJOPTKP          | IDR 60.000.000     |
| Base imponibile         | IDR 1.940.000.000  |
| **BPHTB (5%)**   | **IDR 97.000.000** |

## Tassa del Venditore (PPh Final)

### Cosa Pagano i Venditori

| Operazione   | Aliquota                  |
| ------------- | ------------------------- |
| Vendita immobile | 2.5% del valore dell'operazione |
| Vendita terreno     | 2.5% del valore dell'operazione |

<InfoCard variant="note" title="Tassa sul Venditore">

  **PPh Final 2.5%** è: - Pagata dal venditore - Basata sul valore dell'operazione (o NJOP se più alto) - Dovuta prima del trasferimento del titolo - Finale (nessuna ulteriore tassa sul reddito per la plusvalenza)
</InfoCard>

## Tassa sul Reddito da Affitto

### Tassa sui Canoni Ricevuti

<InfoCard variant="note" title="Tassa Finale 10%">
Il reddito da affitto derivante da immobili è soggetto a:

**PPh Finale 10%** sul canone lordo da affitto

- Si applica a terreni e edifici
- Nessuna deduzione per spese
- Finale (non aggiunta ad altri redditi)
- Dovrebbe essere trattenuta dai tenant aziendali
</InfoCard>

### Chi Trattiene?

| Tipo di Tenant       | Trattamento Fiscale          |
| ----------------- | ---------------------- |
| Tenant aziendale  | Deve trattenere il 10%      |
| Tenant privato    | Il locatore si autotassa     |

### Segnalazione

| Situazione         | Azione                    |
| ----------------- | ------------------------- |
| Tenant aziendale  | Emettono *bukti potong*   |
| Tenant privato    | Tu segnali e paghi        |
| Misto             | Dichiarare tutto nella SPT annuale |

## NJOP Spiegato

### Cos'è il NJOP?

<InfoCard variant="note" title="Valore Stimato dal Governo">
**NJOP** (Nilai Jual Objek Pajak) è:
- Valore dell'immobile stimato dal governo
- Utilizzato per i calcoli fiscali
- Solitamente inferiore al valore di mercato
- Aggiornato periodicamente

Trova il tuo NJOP sulla tua SPPT (avviso di tassa) o verifica presso l'ufficio delle tasse locale.

</InfoCard>

### NJOP vs Valore di Mercato

| Aspetto           | NJOP             | Valore di Mercato |
| ---------------- | ---------------- | ------------ |
| Stabilizzato da   | Governo       | Mercato       |
| Livello tipico    | 50-80% del mercato | 100%         |
| Frequenza aggiornamento | Periodico         | In tempo reale    |
| Utilizzato per         | Tasse            | Transazioni |

## Consigli di Pianificazione Fiscale

### Modi Legali per Ridurre

| Strategia            | Come Funziona                |
| ------------------- | --------------------------- |
| Tempistica acquisto    | La fine dell'anno può permettere la pianificazione |
| Struttura della proprietà | PT PMA vs personale          |
| Usa NJOPTKP         | Assicurati che la soglia venga applicata    |
| Salda PBB in tempo   | Evita sanzioni             |
| Documenta le spese   | Per la base futura di vendita       |

<InfoCard variant="warning" title="Conformità Fiscale">
**Non:**
- Sottostimare i valori delle operazioni
- Nascondere la proprietà immobiliare
- Non pagare il PBB
- Ignorare il reddito da affitto

Le autorità fiscali incrociano i dati con i registri del BPN e degli uffici notarili. La non conformità crea problemi quando vuoi vendere.

</InfoCard>
