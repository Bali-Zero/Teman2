# Правила землевладения в Индонезии 2026: Руководство для иностранцев

Иностранцы не могут напрямую владеть землей в Индонезии по праву полной собственности. Однако существуют законные способы обеспечить права собственности на недвижимость. Вот ваше полное руководство.

## Основное правило

<InfoCard variant="warning" title="Фундаментальное ограничение">
**Законодательство Индонезии (Аграрный закон 1960 года):**

- Только граждане Индонезии могут владеть **Hak Milik** (полная собственность)
- Иностранцы могут владеть определенными **правами пользования**
- Земля автоматически переходит государству, если иностранец владеет Hak Milik

Это конституционный закон — его нельзя обойти легальным путем.

</InfoCard>

## Структура PT PMA

### Как это работает

1. **Учреждение PT PMA** - Иностранная инвестиционная компания
2. **Регистрация вида деятельности по недвижимости** - В бизнес-лицензии
3. **Приобретение титула HGB** - Компания владеет титулом
4. **Вы контролируете компанию** - Косвенное владение

### Преимущества

| Преимущество                    | Детали                              |
| ------------------------------- | ----------------------------------- |
| Коммерческое использование      | Можно сдавать недвижимость в аренду |
| Несколько объектов недвижимости | Нет ограничения на один объект      |
| Бизнес-операции                 | Полная коммерческая деятельность    |
| Передаваемость                  | Продажа акций, а не недвижимости    |
| Банковское финансирование       | Легче получить                      |

### Недостатки

| Проблема                         | Детали                               |
| -------------------------------- | ------------------------------------ |
| Стоимость создания               | 100-200 млн IDR+                     |
| Постоянное соблюдение нормативов | Отчетность, налоги                   |
| Требования к капиталу            | Минимальные инвестиции               |
| Сложность                        | Юридическое и административное бремя |
| Эксплуатационные расходы         | Бухгалтерия, лицензии                |

## Арендные соглашения

### Долгосрочная аренда

<InfoCard variant="tip" title="Более простая альтернатива">
**Аренда (Hak Sewa)** часто проще:

- Аренда земли у индонезийского владельца
- Типичные сроки: 25-30 лет
- Можно строить с разрешения
- Меньшая сложность, чем PT PMA
- Нет требований к минимальной стоимости

Многие экспаты предпочитают этот вариант из-за простоты.

</InfoCard>

| Права на строительство | Обычно включены                           |
| Улучшения              | Возвращаются владельцу или компенсируются |

## Что насчет номинальных владельцев?

<InfoCard variant="warning" title="Соглашения о номинальных владельцах">
**Номинальный владелец = индонезиец владеет титулом от имени иностранца**

**Правда:**

- Распространено, но **юридически рискованно**
- Земельное законодательство не признает номинальных владельцев
- Номинальный владелец может заявить о подлинном владении
- Суды могут не защитить иностранца
- Может быть аннулировано при оспаривании

**Если вы используете номинального владельца:**

- Используйте всеобъемлющие юридические соглашения
- Понимайте, что у вас ОГРАНИЧЕННАЯ защита
- Рассмотрите PT PMA вместо этого для безопасности
  </InfoCard>

### Риски номинального владения

| Риск                                                | Последствие                       |
| --------------------------------------------------- | --------------------------------- |
| Номинальный владелец заявляет о праве собственности | Можно потерять имущество          |
| Номинальный владелец умирает                        | Осложнения с наследством          |
| Долги номинального владельца                        | Имущество может быть конфисковано |
| Развод номинального владельца                       | Супруг может претендовать         |
| Юридическое оспаривание                             | Соглашение аннулируется           |

## Право собственности на квартиру/многоквартирный дом

### Лучший вариант для иностранцев

<InfoCard variant="note" title="Право собственности на квартиру (Hak Milik Sarusun)">
**Квартиры — это другое!**

Иностранцы могут напрямую владеть правом собственности на квартиру (HMSRS):

- Не требуется PT PMA
- Не требуется KITAS (проверьте конкретный проект)
- Требования к минимальной стоимости все еще применяются
- Более простой процесс сделки

Многие иностранцы выбирают квартиры из-за простоты.

</InfoCard>

### Требования

| Требование            | Детали                               |
| --------------------- | ------------------------------------ |
| Минимальная стоимость | Варьируется по регионам              |
| Тип здания            | Только квартиры/многоквартирные дома |
| Документация          | Паспорт, договор купли-продажи       |
| Регистрация           | Через застройщика/BPN                |
