## Ekspektasi Imbal Hasil

### Yield Tipikal

| Tipe Properti              | Yield Kotor | Yield Bersih |
| -------------------------- | ----------- | ------------ |
| Vila Bali (jangka pendek)  | 8-15%       | 5-10%        |
| Vila Bali (jangka panjang) | 5-8%        | 4-6%         |
| Apartemen Jakarta          | 5-7%        | 4-5%         |
| Serviced apartment         | 6-10%       | 4-7%         |

<InfoCard variant="warning" title="Ekspektasi Realistis">
**Bersikaplah realistis:**

- Yield kotor mengabaikan pengeluaran
- Yield bersih lebih penting
- Okupansi bervariasi (tipikal 60-80% untuk jangka pendek)
- Biaya pemeliharaan bertambah
- Biaya manajemen 15-25%
- Pajak mengurangi imbal hasil lebih lanjut

Targetkan pengembalian bersih 5-8% untuk perencanaan yang realistis.

</InfoCard>

### Kalkulator Imbal Hasil

<Calculator
  title="Estimasi Pengembalian Sewa"
  description="Hitung potensi imbal hasil"
  fields={[
    {
      id: "purchase",
      label: "Nilai Properti (IDR)",
      type: "number",
      defaultValue: 3000000000,
      min: 0
    },
    {
      id: "monthlyRate",
      label: "Tarif Sewa Bulanan (IDR)",
      type: "number",
      defaultValue: 25000000,
      min: 0
    },
    {
      id: "occupancy",
      label: "Okupansi yang Diharapkan (%)",
      type: "number",
      defaultValue: 70,
      min: 0,
      max: 100
    },
    {
      id: "managed",
      label: "Manajemen Properti?",
      type: "select",
      options: [
        { value: "yes", label: "Ya (20% dari pendapatan)" },
        { value: "no", label: "Tidak (kelola sendiri)" }
      ],
      defaultValue: "yes"
    }
  ]}
  calculateResult={(values) => {
    const annualGross = values.monthlyRate * 12 * (values.occupancy / 100);
    const managementFee = values.managed === "yes" ? annualGross * 0.20 : 0;
    const maintenance = annualGross * 0.10; // 10% for maintenance
    const utilities = values.monthlyRate * 0.1 * 12; // Rough utility estimate
    const tax = annualGross * 0.10; // 10% rental income tax

    const totalExpenses = managementFee + maintenance + utilities + tax;
    const netIncome = annualGross - totalExpenses;

    const grossYield = (annualGross / values.purchase) * 100;
    const netYield = (netIncome / values.purchase) * 100;

    return {
      total: Math.round(netIncome),
      breakdown: [
        { label: "Sewa kotor tahunan", amount: Math.round(annualGross) },
        { label: "Manajemen properti", amount: -Math.round(managementFee) },
        { label: "Pemeliharaan (10%)", amount: -Math.round(maintenance) },
        { label: "Estimasi utilitas", amount: -Math.round(utilities) },
        { label: "Pajak sewa (10%)", amount: -Math.round(tax) },
        { label: "PENDAPATAN BERSIH TAHUNAN", amount: Math.round(netIncome) },
        { label: "Yield kotor", amount: `${grossYield.toFixed(1)}%` },
        { label: "Yield bersih", amount: `${netYield.toFixed(1)}%` }
      ],
      currency: "IDR",
      note: `Yield bersih: ${netYield.toFixed(1)}% (~USD ${Math.round(netIncome / 16000).toLocaleString()}/tahun)`
    };

}}
/>

**Pajak Final 10%** dari pendapatan sewa kotor
