# Aturan Kepemilikan Tanah Indonesia 2026: Panduan untuk Warga Asing

Warga asing tidak dapat secara langsung memiliki tanah dengan hak milik di Indonesia. Namun, ada cara legal untuk mengamankan hak atas properti. Berikut panduan lengkap Anda.

## Aturan Dasar

<InfoCard variant="warning" title="Batasan Fundamental">
**Hukum Indonesia (Undang-Undang Agraria 1960):**

- Hanya warga negara Indonesia yang dapat memegang **Hak Milik** (hak milik penuh)
- Warga asing dapat memegang hak-hak **penggunaan tertentu**
- Tanah akan otomatis kembali ke negara jika warga asing memegang Hak Milik

Ini adalah hukum konstitusional - tidak dapat dielakkan secara legal.

</InfoCard>

## Struktur PT PMA

### Cara Kerjanya

1. **Bentuk PT PMA** - Perusahaan investasi asing
2. **Daftarkan aktivitas properti** - Dalam izin usaha
3. **Dapatkan sertifikat HGB** - Perusahaan memegang sertifikat
4. **Anda mengendalikan perusahaan** - Kepemilikan tidak langsung

### Keuntungan

| Manfaat             | Detail                    |
| ------------------- | -------------------------- |
| Penggunaan komersial | Dapat menyewa properti     |
| Banyak properti     | Tidak ada batas satu properti |
| Operasi bisnis      | Aktivitas komersial penuh |
| Dapat dialihkan      | Jual saham, bukan properti |
| Pembiayaan bank     | Lebih mudah didapat        |

### Kekurangan

| Tantangan            | Detail                |
| -------------------- | ---------------------- |
| Biaya setup          | IDR 100-200M+         |
| Kepatuhan berkelanjutan | Pelaporan, pajak      |
| Persyaratan modal    | Investasi minimum      |
| Kompleksitas         | Beban hukum dan admin  |
| Biaya operasional    | Akuntansi, lisensi     |

## Perjanjian Sewa

### Sewa Jangka Panjang

<InfoCard variant="tip" title="Alternatif Lebih Sederhana">
**Leasehold (Hak Sewa)** sering kali lebih sederhana:

- Sewa tanah dari pemilik Indonesia
- Periode tipikal: 25-30 tahun
- Dapat membangun dengan izin
- Kompleksitas lebih rendah daripada PT PMA
- Tidak ada persyaratan nilai minimum

Banyak expat lebih memilih ini untuk kesederhanaan.

</InfoCard>

### Struktur Sewa

| Elemen         | Periode Tipikal                  |
| --------------- | ------------------------------ |
| Durasi        | 25-30 tahun                    |
| Perpanjangan       | Sering dapat dinegosiasikan               |
| Pendaftaran    | Perjanjian notaris            |
| Hak bangunan | Biasanya termasuk               |
| Peningkatan    | Kembali ke pemilik atau dikompensasi |

## Bagaimana dengan Nominee?

<InfoCard variant="warning" title="Perjanjian Nominee">
**Nominee = Orang Indonesia memegang sertifikat untuk warga asing**

**Kenyataannya:**

- Umum tetapi **berisiko secara legal**
- Hukum tanah tidak mengakui nominee
- Nominee dapat mengklaim kepemilikan sebenarnya
- Pengadilan mungkin tidak melindungi warga asing
- Dapat dibatalkan jika ditantang

**Jika Anda menggunakan nominee:**

- Gunakan perjanjian legal yang komprehensif
- Pahami bahwa Anda memiliki perlindungan TERBATAS
- Pertimbangkan PT PMA sebagai alternatif untuk keamanan
</InfoCard>

### Risiko Nominee

| Risiko                     | Konsekuensi               |
| ------------------------ | ------------------------- |
| Nominee mengklaim kepemilikan | Mungkin kehilangan properti         |
| Nominee meninggal          | Masalah pewarisan        |
| Hutang nominee          | Properti dapat disita    |
| Perceraian nominee          | Pasangan mungkin mengklaim          |
| Tantangan legal          | Perjanjian batal          |

## Sertifikat Apartemen/Hak Milik Bersama

### Opsi Lebih Baik untuk Warga Asing

<InfoCard variant="note" title="Sertifikat Hak Milik Bersama (HMSRS)">
**Apartemen berbeda!**

Warga asing dapat memegang sertifikat hak milik bersama (HMSRS) secara langsung:

- Tidak perlu PT PMA
- Tidak perlu KITAS (periksa pengembangan spesifik)
- Persyaratan nilai minimum tetap berlaku
- Proses transaksi lebih mudah

Banyak warga asing memilih apartemen untuk kesederhanaan.

</InfoCard>

### Syarat-Syarat

| Syarat   | Detail                      |
| ------------- | ---------------------------- |
| Nilai minimum | Berbeda-beda per wilayah             |
| Jenis bangunan | Apartemen/hak milik bersama saja       |
| Dokumentasi | Paspor, perjanjian pembelian |
| Pendaftaran  | Melalui pengembang/BPN        |
