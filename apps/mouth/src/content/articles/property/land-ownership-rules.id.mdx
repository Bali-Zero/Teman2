# Aturan Kepemilikan Tanah Indonesia 2026: Panduan untuk Warga Asing

Warga asing tidak dapat secara langsung memiliki tanah hak milik di Indonesia. Namun, ada cara legal untuk mengamankan hak atas properti. Berikut panduan lengkap Anda.

## Aturan Dasar

<InfoCard variant="warning" title="Pembatasan Fundamental">
**Hukum Indonesia (Undang-Undang Agraria 1960):**

- Hanya warga negara Indonesia yang dapat memegang **Hak Milik** (hak milik)
- Warga asing dapat memegang hak-hak **penggunaan tertentu**
- Tanah akan otomatis kembali ke negara jika warga asing memegang Hak Milik

Ini adalah hukum konstitusional - tidak dapat dilangkahi secara legal.

</InfoCard>

## Struktur PT PMA

### Cara Kerjanya

1. **Bentuk PT PMA** - Perusahaan investasi asing
2. **Daftarkan aktivitas properti** - Dalam izin usaha
3. **Dapatkan sertifikat HGB** - Perusahaan memegang sertifikat
4. **Anda mengendalikan perusahaan** - Kepemilikan tidak langsung

### Keuntungan

| Manfaat             | Detail                    |
| ------------------- | -------------------------- |
| Penggunaan komersial | Dapat menyewakan properti      |
| Properti multiple   | Tidak ada batasan satu properti   |
| Operasi bisnis      | Aktivitas komersial penuh |
| Dapat ditransfer    | Jual saham, bukan properti  |
| Pembiayaan bank     | Lebih mudah diperoleh           |

### Kekurangan

| Tantangan            | Detail                |
| -------------------- | ---------------------- |
| Biaya setup          | IDR 100-200M+          |
| Kepatuhan berkelanjutan   | Pelaporan, pajak         |
| Persyaratan modal    | Investasi minimum     |
| Kompleksitas         | Beban hukum dan admin |
| Biaya operasional    | Akuntansi, lisensi   |

## Perjanjian Sewa

### Sewa Jangka Panjang

<InfoCard variant="tip" title="Alternatif Lebih Sederhana">
**Leasehold (Hak Sewa)** sering kali lebih sederhana:

- Sewa tanah dari pemilik Indonesia
- Periode tipikal: 25-30 tahun
- Dapat membangun dengan izin
- Kompleksitas lebih rendah daripada PT PMA
- Tidak ada persyaratan nilai minimum

Banyak ekspatriat lebih memilih ini untuk kesederhanaan.

</InfoCard>

### Struktur Sewa

| Elemen         | Periode Tipikal                  |
| --------------- | ------------------------------ |
| Durasi        | 25-30 tahun                    |
| Perpanjangan       | Sering dapat dinegosiasikan               |
| Pendaftaran    | Perjanjian notaris            |
| Hak bangunan | Biasanya termasuk               |
| Peningkatan    | Kembali ke pemilik atau dikompensasi |

## Bagaimana dengan Nomine?

<InfoCard variant="warning" title="Perjanjian Nomine">
**Nomine = Orang Indonesia memegang sertifikat untuk warga asing**

**Kenyataan:**

- Umum tetapi **berisiko secara legal**
- Hukum tanah tidak mengakui nomine
- Nomine dapat mengklaim kepemilikan sejati
- Pengadilan mungkin tidak melindungi warga asing
- Dapat dibatalkan jika ditantang

**Jika Anda menggunakan nominee:**

- Gunakan perjanjian hukum yang komprehensif
- Pahami Anda memiliki perlindungan TERBATAS
- Pertimbangkan PT PMA sebagai alternatif untuk keamanan
</InfoCard>

### Risiko Nomine

| Risiko                     | Konsekuensi               |
| ------------------------ | ------------------------- |
| Nomine mengklaim kepemilikan | Mungkin kehilangan properti         |
| Nomine meninggal          | Komplikasi warisan        |
| Hutang nomine            | Properti dapat disita    |
| Perceraian nomine        | Pasangan mungkin mengklaim          |
| Tantangan hukum          | Perjanjian batal          |

## Sertifikat Apartemen/Situs Bersama

### Opsi Lebih Baik untuk Warga Asing

<InfoCard variant="note" title="Situs Bersama (Hak Milik Sarusun)">
**Apartemen berbeda!**

Warga asing dapat memegang situs bersama (HMSRS) secara langsung:

- Tidak perlu PT PMA
- Tidak perlu KITAS (periksa pengembangan spesifik)
- Persyaratan nilai minimum tetap berlaku
- Proses transaksi lebih mudah

Banyak warga asing memilih apartemen untuk kesederhanaan.

</InfoCard>

### Persyaratan

| Persyaratan   | Detail                      |
| ------------- | ---------------------------- |
| Nilai minimum | Bervariasi per daerah             |
| Jenis bangunan | Apartemen/situs bersama saja       |
| Dokumentasi | Paspor, perjanjian pembelian |
| Pendaftaran  | Melalui pengembang/BPN        |
