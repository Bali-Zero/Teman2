# Aturan Kepemilikan Tanah Indonesia 2026: Panduan Orang Asing

Orang asing tidak dapat secara langsung memiliki tanah hak milik di Indonesia. Namun, ada cara legal untuk mengamankan hak properti. Inilah panduan lengkap Anda.

## Aturan Dasar

<InfoCard variant="warning" title="Batasan Fundamental">
**Hukum Indonesia (Undang-Undang Agraria 1960):**

- Hanya warga negara Indonesia yang dapat memegang **Hak Milik** (freehold)
- Orang asing dapat memegang **hak pakai** tertentu
- Tanah secara otomatis kembali ke negara jika orang asing memegang Hak Milik

Ini adalah hukum konstitusional - tidak dapat dilewati secara legal.

</InfoCard>

## Struktur PT PMA

### Cara Kerjanya

1. **Mendirikan PT PMA** - Perusahaan investasi asing
2. **Mendaftarkan aktivitas properti** - Dalam izin usaha
3. **Mendapatkan gelar HGB** - Perusahaan memegang gelar
4. **Anda mengendalikan perusahaan** - Kepemilikan tidak langsung

### Keuntungan

| Keuntungan           | Detail                          |
| -------------------- | ------------------------------- |
| Penggunaan komersial | Dapat menyewakan properti       |
| Banyak properti      | Tidak ada batasan satu properti |
| Operasi bisnis       | Aktivitas komersial penuh       |
| Dapat dialihkan      | Jual saham, bukan properti      |
| Pembiayaan bank      | Lebih mudah didapatkan          |

### Kerugian

| Tantangan               | Detail                |
| ----------------------- | --------------------- |
| Biaya pendirian         | Rp 100-200 jt+        |
| Kepatuhan berkelanjutan | Pelaporan, pajak      |
| Persyaratan modal       | Investasi minimum     |
| Kompleksitas            | Beban legal dan admin |
| Biaya operasional       | Akuntansi, lisensi    |

## Pengaturan Hak Sewa

### Sewa Jangka Panjang

<InfoCard variant="tip" title="Alternatif Lebih Sederhana">
**Hak Sewa (Leasehold)** seringkali lebih sederhana:

- Sewa tanah dari pemilik WNI
- Jangka waktu umum: 25-30 tahun
- Dapat membangun dengan izin
- Kompleksitas lebih rendah daripada PT PMA
- Tidak ada persyaratan nilai minimum

Banyak ekspatriat lebih menyukai ini karena kesederhanaannya.

</InfoCard>

### Struktur Sewa

| Elemen        | Jangka Waktu Umum                  |
| ------------- | ---------------------------------- |
| Durasi        | 25-30 tahun                        |
| Perpanjangan  | Seringkali dapat dinegosiasikan    |
| Pendaftaran   | Perjanjian yang dinotariskan       |
| Hak membangun | Biasanya termasuk                  |
| Perbaikan     | Kembali ke pemilik atau kompensasi |

## Bagaimana dengan Nominee?

<InfoCard variant="warning" title="Pengaturan Nominee">
**Nominee = WNI memegang gelar untuk orang asing**

**Kenyataannya:**

- Umum tetapi **berisiko secara legal**
- Hukum pertanahan tidak mengakui nominee
- Nominee dapat mengklaim kepemilikan sebenarnya
- Pengadilan mungkin tidak melindungi orang asing
- Dapat dibatalkan jika ditentang

**Jika Anda menggunakan nominee:**

- Gunakan perjanjian hukum yang komprehensif
- Pahami bahwa Anda memiliki perlindungan TERBATAS
- Pertimbangkan PT PMA sebagai gantinya untuk keamanan
  </InfoCard>

### Risiko Nominee

| Risiko                    | Konsekuensi               |
| ------------------------- | ------------------------- |
| Nominee klaim kepemilikan | Dapat kehilangan properti |
| Nominee meninggal         | Komplikasi warisan        |
| Utang nominee             | Properti dapat disita     |
| Perceraian nominee        | Pasangan dapat mengklaim  |
| Tantangan legal           | Pengaturan batal          |

## Apartemen/Strata Title

### Opsi Lebih Baik untuk Orang Asing

<InfoCard variant="note" title="Strata Title (Hak Milik Sarusun)">
**Apartemen berbeda!**

Orang asing dapat memegang strata title (HMSRS) secara langsung:

- Tidak butuh PT PMA
- Tidak butuh KITAS (cek pengembangan spesifik)
- Persyaratan nilai minimum tetap berlaku
- Proses transaksi lebih mudah

Banyak orang asing memilih apartemen karena kesederhanaannya.

</InfoCard>

### Persyaratan

| Persyaratan    | Detail                       |
| -------------- | ---------------------------- |
| Nilai minimum  | Bervariasi per wilayah       |
| Jenis bangunan | Apartemen/strata saja        |
| Dokumentasi    | Paspor, perjanjian pembelian |
| Pendaftaran    | Melalui pengembang/BPN       |
