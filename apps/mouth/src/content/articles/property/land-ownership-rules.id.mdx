# Aturan Kepemilikan Tanah Indonesia 2026: Panduan untuk W asing

W asing tidak dapat secara langsung memiliki tanah hak milik di Indonesia. Namun, ada cara legal untuk mengamankan hak properti. Berikut panduan lengkap Anda.

## Aturan Dasar

<InfoCard variant="warning" title="Pembatasan Fundamental">
**Hukum Indonesia (Undang-Undang Pokok Agraria 1960):**

- Hanya warga negara Indonesia yang dapat memegang **Hak Milik** (hak milik)
- W asing dapat memegang hak-hak **penggunaan tertentu**
- Tanah akan otomatis kembali ke negara jika w asing memegang Hak Milik

Ini adalah hukum konstitusional - tidak dapat dilangkahi secara legal.

</InfoCard>

## Struktur PT PMA

### Cara Kerjanya

1. **Bentuk PT PMA** - Perusahaan investasi asing
2. **Daftarkan aktivitas properti** - Dalam izin usaha
3. **Dapatkan sertifikat HGB** - Perusahaan memegang sertifikat
4. **Anda kendalikan perusahaan** - Kepemilikan tidak langsung

### Keunggulan

| Manfaat             | Detail                    |
| ------------------- | -------------------------- |
| Penggunaan komersial | Dapat menyewakan properti  |
| Banyak properti     | Tidak ada batas satu properti |
| Operasi bisnis      | Aktivitas komersial penuh |
| Dapat dialihkan      | Jual saham, bukan properti |
| Pembiayaan bank     | Lebih mudah diperoleh      |

### Kekurangan

| Tantangan            | Detail                |
| -------------------- | ---------------------- |
| Biaya setup          | IDR 100-200M+         |
| Kepatuhan berkelanjutan | Pelaporan, pajak       |
| Kebutuhan modal      | Investasi minimum      |
| Kompleksitas         | Beban legal dan admin  |
| Biaya operasional    | Akuntansi, lisensi     |

## Perjanjian Sewa

### Sewa Jangka Panjang

<InfoCard variant="tip" title="Alternatif Lebih Sederhana">
**Leasehold (Hak Sewa)** sering lebih sederhana:

- Sewa tanah dari pemilik WNI
- Periode tipikal: 25-30 tahun
- Dapat membangun dengan izin
- Kompleksitas lebih rendah daripada PT PMA
- Tidak ada persyaratan nilai minimum

Banyak expat lebih memilih ini untuk kesederhanaan.

</InfoCard>

### Struktur Sewa

| Elemen         | Periode Tipikal                  |
| --------------- | ------------------------------ |
| Durasi        | 25-30 tahun                    |
| Perpanjangan       | Sering dapat dinegosiasikan               |
| Pendaftaran    | Perjanjian notaris            |
| Hak bangunan | Biasanya termasuk               |
| Peningkatan    | Kembali ke pemilik atau dikompensasi |

## Bagaimana dengan Nominee?

<InfoCard variant="warning" title="Perjanjian Nominee">
**Nominee = WNI memegang sertifikat untuk w asing**

**Kenyataan:**

- Umum tetapi **berisiko secara legal**
- Hukum tanah tidak mengakui nominee
- Nominee dapat mengklaim kepemilikan sejati
- Pengadilan mungkin tidak melindungi w asing
- Dapat dibatalkan jika ditantang

**Jika Anda menggunakan nominee:**

- Gunakan perjanjian legal yang komprehensif
- Pahami bahwa Anda memiliki perlindungan TERBATAS
- Pertimbangkan PT PMA sebagai alternatif yang lebih aman
</InfoCard>

### Risiko Nominee

| Risiko                     | Konsekuensi               |
| ------------------------ | ------------------------- |
| Nominee mengklaim kepemilikan | Mungkin kehilangan properti         |
| Nominee meninggal        | Komplikasi warisan        |
| Hutang nominee           | Properti dapat disita     |
| Perceraian nominee       | Pasangan mungkin mengklaim          |
| Tantangan legal          | Perjanjian batal          |

## Sertifikat Apartemen/Strata

### Opsi Lebih Baik untuk W Asing

<InfoCard variant="note" title="Sertifikat Strata (Hak Milik Sarusun)">
**Apartemen berbeda!**

W asing dapat memegang sertifikat strata (HMSRS) secara langsung:

- Tidak perlu PT PMA
- Tidak perlu KITAS (periksa pengembangan spesifik)
- Persyaratan nilai minimum tetap berlaku
- Proses transaksi lebih mudah

Banyak w asing memilih apartemen untuk kesederhanaan.

</InfoCard>

### Persyaratan

| Persyaratan   | Detail                      |
| ------------- | ---------------------------- |
| Nilai minimum | Bervariasi per daerah             |
| Jenis bangunan | Apartemen/strata saja       |
| Dokumen        | Paspor, perjanjian pembelian |
| Pendaftaran    | Melalui pengembang/BPN        |
