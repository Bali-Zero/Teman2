# Membeli Villa di Bali 2026: Panduan untuk Orang Asing

Memiliki villa di Bali adalah impian bagi banyak orang. Berikut adalah semua yang perlu Anda ketahui untuk mewujudkannya.

## Bisakah Orang Asing Membeli?

<InfoCard variant="warning" title="Jawaban Singkatnya">
**Orang asing tidak dapat memiliki tanah dengan hak milik (freehold) di Indonesia.**

Tetapi ada cara legal untuk mengamankan properti:

- **Sewa Jangka Panjang (Leasehold)**
- **Hak Pakai** (untuk tempat tinggal pribadi)
- **PT PMA** (kepemilikan perusahaan)

Masing-masing memiliki kelebihan dan kekurangan - pilih berdasarkan situasi Anda.

</InfoCard>

## Kalkulator Biaya

<Calculator
  title="Anggaran Pembelian Villa"
  description="Perkirakan total biaya"
  fields={[
    {
      id: "price",
      label: "Harga Villa (IDR)",
      type: "number",
      defaultValue: 5000000000,
      min: 0
    },
    {
      id: "structure",
      label: "Struktur Kepemilikan",
      type: "select",
      options: [
        { value: "leasehold", label: "Sewa (Leasehold)" },
        { value: "hakpakai", label: "Hak Pakai" },
        { value: "ptpma", label: "PT PMA + HGB" }
      ],
      defaultValue: "leasehold"
    }
  ]}
  calculateResult={(values) => {
    const price = values.price;
    let structureCost = 0;
    let transferTax = 0;
    let notary = price * 0.01;
    let legal = 0;

    if (values.structure === "leasehold") {
      structureCost = 0;
      transferTax = 0; // Tidak ada BPHTB untuk sewa
      legal = 30000000;
    } else if (values.structure === "hakpakai") {
      transferTax = price * 0.05; // BPHTB
      legal = 50000000;
    } else {
      structureCost = 150000000; // Persiapan PT PMA
      transferTax = price * 0.05; // BPHTB
      legal = 75000000;
    }

    const agent = price * 0.05; // Jika menggunakan agen
    const misc = 20000000;

    const total = price + structureCost + transferTax + notary + legal + agent + misc;

    return {
      total: total,
      breakdown: [
        { label: "Harga Villa", amount: price },
        { label: "Persiapan struktur (jika PT PMA)", amount: structureCost },
        { label: "Pajak pengalihan (BPHTB)", amount: transferTax },
        { label: "Biaya notaris", amount: Math.round(notary) },
        { label: "Biaya hukum", amount: legal },
        { label: "Komisi agen (5%)", amount: Math.round(agent) },
        { label: "Lain-lain", amount: misc }
      ],
      currency: "IDR",
      note: `Total sekitar ~USD ${Math.round(total / 16000).toLocaleString()}`
    };

}}

## Kesalahan Umum

<InfoCard variant="warning" title="Hindari Ini">
**Kesalahan umum pembeli:**

1. **Tidak melakukan uji tuntas** - Masalah hak milik sangat umum
2. **Menggunakan nominee** - Berisiko, tidak disarankan
3. **Melewatkan tinjauan hukum** - Selalu gunakan pengacara
4. **Membayar terlalu cepat** - Tahan sampai semuanya bersih
5. **Struktur yang salah** - Sesuaikan dengan kebutuhan Anda
6. **Mengabaikan zonasi** - Mungkin tidak bisa disewakan
7. **Perjanjian lisan** - Pastikan semuanya tertulis
8. **Tidak menganggarkan biaya ekstra** - 10-15% di atas harga
   </InfoCard>
