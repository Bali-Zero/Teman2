# Leasehold vs Freehold di Indonesia 2026: Yang Perlu Diketahui Orang Asing

Di banyak negara, \"freehold\" berarti kepemilikan abadi. Di Indonesia, padanan terdekatnya (Hak Milik) tertutup bagi orang asing. Inilah yang perlu Anda pahami.

## Apa itu Freehold (Hak Milik)?

<InfoCard variant="note" title="Freehold Indonesia">
  **Hak Milik** adalah hak properti terkuat di Indonesia: - Kepemilikan abadi -
  Dapat diwariskan tanpa batas - Hak pembuangan penuh - Hanya untuk warga negara
  Indonesia (individu atau badan hukum tertentu)
</InfoCard>

### Siapa yang Bisa Memegang Hak Milik?

- Warga negara Indonesia
- Badan hukum Indonesia tertentu
- Organisasi keagamaan (untuk tempat ibadah)

### TIDAK Tersedia Untuk:

- Orang asing (kebangsaan apa pun)
- Perusahaan asing (termasuk PT PMA)
- Warga negara ganda (harus memilih kewarganegaraan)

---

## Apa itu Leasehold?

Leasehold adalah hak kontraktual untuk menggunakan properti selama periode tertentu:

### Cara Kerjanya

1. Pemilik WNI tetap memegang **Hak Milik** (freehold)
2. Penyewa mendapatkan hak pakai eksklusif melalui perjanjian **Sewa** (lease)
3. Sewa dapat didaftarkan di BPN (kantor pertanahan)
4. Pada akhir masa sewa, properti kembali ke pemilik

### Ketentuan Umum

- **Durasi**: Umumnya 25-30 tahun, dimungkinkan hingga 99 tahun
- **Perpanjangan**: Seringkali dinegosiasikan di muka
- **Hak membangun**: Biasanya sudah termasuk
- **Pengalihan**: Mungkin memerlukan persetujuan pemilik

  description="Estimasi nilai sisa dari masa sewa"

  calculateResult={(values) => {
    const original = Number(values.original);
    const total = Number(values.totalYears);
    const remaining = Number(values.yearsRemaining);

    // Simple linear depreciation
    const ratio = remaining / total;
    const currentValue = original * ratio;
    const depreciation = original - currentValue;
    const annualDepreciation = original / total;

    return {
      total: currentValue,
      breakdown: [
        { label: "Nilai Awal", amount: original },
        { label: "Total Depresiasi", amount: -depreciation },
        { label: "Estimasi Nilai Saat Ini", amount: currentValue },
        { label: "Depresiasi Tahunan", amount: annualDepreciation }
      ],

      note: `Sewa telah menyusut sebesar ${Math.round((1 - ratio) * 100)}% dari nilai awal`

## Risiko Leasehold

### Masalah Umum

1. **Sengketa pemilik tanah** - Ahli waris mungkin menantang masa sewa
2. **Penolakan perpanjangan** - Pemilik mungkin tidak mau memperpanjang
3. **Masalah gelar tanah** - Masalah gelar dasar (underlying title)
4. **Kenaikan harga** - Perpanjangan dengan harga pasar yang tinggi
5. **Kesulitan pembiayaan** - Bank tidak menyukai leasehold
6. **Tantangan saat keluar** - Sulit menjual sisa sewa yang pendek

### Strategi Mitigasi

- **Jangka waktu awal yang lama** - Minimum 25-30 tahun
- **Perpanjangan yang disetujui di muka** - Kunci ketentuan pembaruan
- **Uji tuntas (Due diligence)** - Verifikasi gelar tanah dasar
- **Tinjauan hukum** - Penyusunan kontrak sewa secara profesional
- **Notarisasi** - Akta yang dinotariskan
- **Pendaftaran** - Pendaftaran di BPN

## Realitas Pasar

### Di Bali

- **Sebagian besar penjualan kepada orang asing adalah leasehold**
- Umum: Jangka waktu awal 25-30 tahun
- Perpanjangan biasanya dinegosiasikan di awal
- Harga dikutip sebagai \"nilai leasehold\"
- Daftar \"Freehold\" biasanya menggunakan nominee (ilegal)

### Perbedaan Harga

Perbandingan perkiraan untuk properti serupa:

- **Tanah Freehold**: Rp 100 jt per are
- **Leasehold (25 tahun)**: Rp 50-60 jt per are (50-60% dari harga freehold)

<InfoCard variant="note" title="Lokasi Sangat Penting">
  Di area wisata utama, leasehold masih dapat meminta harga premium karena
  pasokan yang terbatas dan permintaan yang tinggi. Nilainya ada pada lokasi dan
  potensi sewa, bukan hanya pada jenis kepemilikan.
</InfoCard>

## Strategi Keluar (Exit Strategy)

Ketika Anda ingin mengakhiri kepemilikan leasehold:

### Opsi

1. **Jual masa sewa** - Jika pengalihan diizinkan
2. **Tunggu hingga habis** - Dapatkan kembali deposit (jika ada)
3. **Negosiasi pembelian kembali (buyout)** - Dengan pemilik tanah
4. **Sublease** - Jika diizinkan

### Tantangan

- Sisa masa sewa pendek = nilai rendah
- Mungkin butuh persetujuan pemilik tanah
- Menemukan pembeli bisa jadi sulit
- Tidak ada kenaikan nilai modal (capital appreciation)
