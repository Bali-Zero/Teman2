## Kalkulator Investasi

<Calculator
  title="Analisis Investasi Villa"
  description="Perkirakan biaya investasi dan imbal hasil"
  fields={[
    {
      id: "purchasePrice",
      label: "Harga Beli/Sewa (IDR)",
      type: "number",
      defaultValue: 5000000000,
      min: 1000000000,
      step: 500000000,
      suffix: "IDR"
    },
    {
      id: "bedrooms",
      label: "Kamar Tidur",
      type: "select",
      options: [
        { value: "2", label: "2 Kamar Tidur" },
        { value: "3", label: "3 Kamar Tidur" },
        { value: "4", label: "4 Kamar Tidur" },
        { value: "5", label: "5+ Kamar Tidur" }
      ],
      defaultValue: "3"
    },
    {
      id: "location",
      label: "Lokasi",
      type: "select",
      options: [
        { value: "premium", label: "Premium (Seminyak, pusat Canggu)" },
        { value: "good", label: "Bagus (Pererenan, Umalas)" },
        { value: "developing", label: "Berkembang (Tabanan, Utara)" }
      ],
      defaultValue: "good"
    },
    {
      id: "occupancy",
      label: "Ekspektasi Okupansi %",
      type: "number",
      defaultValue: 60,
      min: 20,
      max: 90
    }
  ]}
  calculateResult={(values) => {
    const purchase = Number(values.purchasePrice);
    const bedrooms = Number(values.bedrooms);
    const occupancy = Number(values.occupancy) / 100;

    // Nightly rates by location and bedrooms
    const rateMap = {
      "premium-2": 3000000, "premium-3": 4500000, "premium-4": 6000000, "premium-5": 8000000,
      "good-2": 2000000, "good-3": 3000000, "good-4": 4000000, "good-5": 5500000,
      "developing-2": 1200000, "developing-3": 1800000, "developing-4": 2500000, "developing-5": 3500000
    };

    const nightlyRate = rateMap[`${values.location}-${values.bedrooms}`] || 2500000;
    const annualGross = nightlyRate * 365 * occupancy;

    // Operating costs
    const management = annualGross * 0.20; // 20% management
    const maintenance = 60000000; // General maintenance
    const utilities = 36000000; // Utilities avg
    const marketing = 24000000; // OTA fees, marketing
    const insurance = 12000000;
    const tax = annualGross * 0.10; // Rental income tax

    const totalCosts = management + maintenance + utilities + marketing + insurance + tax;
    const netIncome = annualGross - totalCosts;
    const grossYield = (annualGross / purchase) * 100;
    const netYield = (netIncome / purchase) * 100;

    return {
      total: netIncome,
      breakdown: [
        { label: "Pendapatan Kotor Tahunan", amount: annualGross },
        { label: "Manajemen (20%)", amount: -management },
        { label: "Pemeliharaan", amount: -maintenance },
        { label: "Utilitas", amount: -utilities },
        { label: "Pemasaran/OTA", amount: -marketing },
        { label: "Asuransi", amount: -insurance },
        { label: "Pajak Sewa (10%)", amount: -tax },
        { label: "Pendapatan Bersih Tahunan", amount: netIncome }
      ],
      currency: "IDR",
      note: `Imbal hasil kotor: ${grossYield.toFixed(1)}% | Imbal hasil bersih: ${netYield.toFixed(1)}%`
    };

}}
/>

## Perizinan Sewa

<InfoCard variant="warning" title="Izin Sewa Diperlukan">
Mengoperasikan villa sewa memerlukan:
- Izin **Pondok Wisata** untuk akomodasi kecil
- **TDUP** untuk operasional yang lebih besar
- Registrasi pariwisata
- Berbagai izin lokal lainnya

Mengoperasikan tanpa izin berisiko denda, penutupan, dan masalah visa.

</InfoCard>

### Persyaratan Izin

| Izin          | Untuk                | Dikeluarkan Oleh |
| ------------- | -------------------- | ---------------- |
| Pondok Wisata | Guesthouse kecil     | Pemerintah lokal |
| TDUP          | Akomodasi pariwisata | Dinas Pariwisata |
| NIB           | Registrasi bisnis    | OSS              |
| Lingkungan    | Dampak operasional   | Dinas Lingkungan |

## Biaya Operasional

### Anggaran Operasional Bulanan

| Biaya                  | Rentang (IDR/bulan) | Catatan                     |
| ---------------------- | ------------------- | --------------------------- |
| Staf                   | 8-20 Juta           | Manager villa, pembersih    |
| Kolam/taman            | 3-5 Juta            | Pemeliharaan                |
| Utilitas               | 2-5 Juta            | Listrik, air, internet      |
| Perbaikan/pemeliharaan | 3-8 Juta            | Rata-rata                   |
| Manajemen              | 15-25% pendapatan   | Jika menggunakan perusahaan |

### Biaya Tetap Tahunan

| Biaya      | Jumlah (IDR/tahun) | Catatan               |
| ---------- | ------------------ | --------------------- |
| PBB        | 5-15 Juta          | Tergantung ukuran     |
| Asuransi   | 10-20 Juta         | Bangunan + liabilitas |
| Komisi OTA | 15-20% pemesanan   | Airbnb, Booking.com   |
| Pemasaran  | 12-24 Juta         | Foto, konten, iklan   |

## Risiko Umum

### Risiko Pasar

- Kelebihan pasokan di area populer
- Fluktuasi pariwisata
- Persaingan dari hotel
- Perubahan regulasi

### Risiko Operasional

- Masalah manajemen
- Masalah pemeliharaan
- Kerusakan oleh tamu
- Tantangan staf

### Risiko Hukum

- Sengketa hak milik
- Masalah izin
- Berakhirnya masa sewa
- Komplikasi pajak
