# Investissement en villa à Bali 2026 : Guide complet pour les étrangers

Les villas à Bali attirent les investisseurs du monde entier. Voici un aperçu honnête de ce que cela implique, des rendements et des risques pour les investisseurs étrangers.

<InfoCard variant="danger" title="Alerte réglementaire 2026 : Terres durables et zones vertes">
  Avant d'acheter ou de construire une villa à Bali, il est essentiel de vérifier le **statut LP2B**
  du terrain. Conformément à la **Perda 4/2026 de Bali**, la conversion de rizières protégées en
  villas est désormais une infraction pénale. De nombreuses propriétés en "Zone Verte" sont vendues
  avec des promesses illégales. Protégez votre investissement en comprenant la nouvelle
  criminalisation de la conversion des rizières. [Lire la mise à jour de la loi foncière de Bali
  2026 →](/business/bali-rice-field-conversion-criminalization-perda-4-2026)
</InfoCard>

<Calculator
  title="Analyse de l'investissement en villa"
  description="Estimez les coûts et les rendements de l'investissement"
  fields={[
    {

        { value: "4", label: "4 Chambres" },
        { value: "5", label: "5+ Chambres" }
      ],
      defaultValue: "3"
    },
    {
      id: "location",
      label: "Emplacement",
      type: "select",
      options: [
        { value: "premium", label: "Premium (Seminyak, centre de Canggu)" },
        { value: "good", label: "Bon (Pererenan, Umalas)" },
        { value: "developing", label: "En développement (Tabanan, Nord)" }
      ],
      defaultValue: "good"
    },
    {
      id: "occupancy",
      label: "Taux d'occupation prévu %",
      type: "number",
      defaultValue: 60,
      min: 20,
      max: 90
    }
  ]}
  calculateResult={(values) => {
    const purchase = Number(values.purchasePrice);
    const bedrooms = Number(values.bedrooms);
    const occupancy = Number(values.occupancy) / 100;

    // Nightly rates by location and bedrooms
    const rateMap = {
      "premium-2": 3000000, "premium-3": 4500000, "premium-4": 6000000, "premium-5": 8000000,
      "good-2": 2000000, "good-3": 3000000, "good-4": 4000000, "good-5": 5500000,
      "developing-2": 1200000, "developing-3": 1800000, "developing-4": 2500000, "developing-5": 3500000
    };

    const nightlyRate = rateMap[`${values.location}-${values.bedrooms}`] || 2500000;
    const annualGross = nightlyRate * 365 * occupancy;

    // Operating costs
    const management = annualGross * 0.20; // 20% management
    const maintenance = 60000000; // General maintenance
    const utilities = 36000000; // Utilities avg
    const marketing = 24000000; // OTA fees, marketing
    const insurance = 12000000;
    const tax = annualGross * 0.10; // Rental income tax

    const totalCosts = management + maintenance + utilities + marketing + insurance + tax;
    const netIncome = annualGross - totalCosts;
    const grossYield = (annualGross / purchase) * 100;
    const netYield = (netIncome / purchase) * 100;

    return {
      total: netIncome,
      breakdown: [
        { label: "Revenus annuels bruts", amount: annualGross },
        { label: "Gestion (20%)", amount: -management },
        { label: "Maintenance", amount: -maintenance },
        { label: "Charges", amount: -utilities },
        { label: "Marketing/OTA", amount: -marketing },
        { label: "Assurance", amount: -insurance },
        { label: "Taxe locative (10%)", amount: -tax },
        { label: "Revenu annuel net", amount: netIncome }
      ],
      currency: "IDR",
      note: `Rendement brut : ${grossYield.toFixed(1)}% | Rendement net : ${netYield.toFixed(1)}%`
    };

}}

## Licences de location

<InfoCard variant="warning" title="Licence de location requise">
L'exploitation d'une villa locative nécessite :
- Une licence **Pondok Wisata** pour les petits hébergements
- Un **TDUP** pour les opérations plus importantes
- L'enregistrement touristique
- Divers permis locaux

Opérer sans licence risque des amendes, la fermeture et des problèmes de visa.

</InfoCard>

### Exigences de licence

| Licence       | Pour                        | Délivré par                    |
| ------------- | --------------------------- | ------------------------------ |
| Pondok Wisata | Petites maisons d'hôtes     | Gouvernement local             |
| TDUP          | Hébergement touristique     | Département du tourisme        |
| NIB           | Enregistrement d'entreprise | OSS                            |
| Environmental | Impact des opérations       | Département de l'environnement |
