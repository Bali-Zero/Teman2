## Impôt foncier annuel (PBB)

### Qu'est-ce que le PBB ?

<InfoCard variant="note" title="Pajak Bumi dan Bangunan">
**PBB** (Impôt sur la Terre et les Bâtiments) est :
- Un impôt annuel sur la propriété immobilière
- Basé sur la valeur évaluée par le gouvernement (NJOP)
- Payé par le propriétaire
- Dû chaque année avant fin août

Tous les propriétaires de terrains et de bâtiments doivent payer le PBB.

</InfoCard>

### Calcul du PBB

| Composante        | Explication                                         |
| ----------------- | --------------------------------------------------- |
| NJOP              | Valeur évaluée par le gouvernement                  |
| NJOPTKP           | Seuil d'exonération fiscale (varie selon la région) |
| Valeur imposable  | NJOP moins NJOPTKP                                  |
| Taux d'imposition | 0.1-0.5% (varie selon la région et la valeur)       |

### Calculateur PBB

<Calculator
  title="Estimation PBB"
  description="Estimez votre impôt foncier annuel"
  fields={[
    {
      id: "njop",
      label: "Valeur NJOP (IDR)",
      type: "number",
      defaultValue: 500000000,
      min: 0
    },
    {
      id: "region",
      label: "Région",
      type: "select",
      options: [
        { value: "jakarta", label: "Jakarta" },
        { value: "bali", label: "Bali" },
        { value: "other", label: "Autre" }
      ],
      defaultValue: "bali"
    }
  ]}
  calculateResult={(values) => {
    // NJOPTKP varies by region
    const njoptkp = {
      jakarta: 60000000,
      bali: 50000000,
      other: 30000000
    };

    const threshold = njoptkp[values.region];
    const taxable = Math.max(0, values.njop - threshold);

    // Simplified rate (actual varies by bracket)
    let rate;
    if (values.njop < 1000000000) {
      rate = 0.001; // 0.1%
    } else if (values.njop < 2000000000) {
      rate = 0.002; // 0.2%
    } else {
      rate = 0.003; // 0.3%
    }

    const tax = taxable * rate;

    return {
      total: Math.round(tax),
      breakdown: [
        { label: "Valeur NJOP", amount: values.njop },
        { label: "NJOPTKP (seuil)", amount: threshold },
        { label: "Valeur imposable", amount: taxable },
        { label: "Taux effectif", amount: `${(rate * 100).toFixed(2)}%` },
        { label: "PBB annuel", amount: Math.round(tax) }
      ],
      currency: "IDR",
      note: "L'impôt réel peut varier en fonction de la réglementation locale"
    };

}}
/>

## Taxe de transfert/acquisition (BPHTB)

### Ce que les acheteurs paient

<InfoCard variant="warning" title="BPHTB - Taxe de transfert de 5%">
**BPHTB** s'applique lorsque vous acquérez une propriété :
- Achat
- Don
- Héritage
- Échange

**Taux :** 5% de la valeur de transfert moins le NJOPTKP
**Payé par :** Acheteur/bénéficiaire
**Quand :** Avant le transfert de titre

</InfoCard>

### Calcul du BPHTB

| Élément               | Calcul                                 |
| --------------------- | -------------------------------------- |
| Valeur de transaction | Le plus élevé entre le prix ou le NJOP |
| Moins NJOPTKP         | Seuil d'exonération fiscale            |
| Base d'imposition     | Résultat                               |
| BPHTB                 | 5% de la base d'imposition             |

### Exemple

| Article                           | Montant            |
| --------------------------------- | ------------------ |
| Prix d'achat                      | IDR 2,000,000,000  |
| NJOP                              | IDR 1,500,000,000  |
| Utiliser la valeur la plus élevée | IDR 2,000,000,000  |
| NJOPTKP                           | IDR 60,000,000     |
| Base d'imposition                 | IDR 1,940,000,000  |
| **BPHTB (5%)**                    | **IDR 97,000,000** |

## Impôt du vendeur (PPh Final)

### Ce que les vendeurs paient

| Transaction       | Taux d'imposition                |
| ----------------- | -------------------------------- |
| Vente immobilière | 2.5% de la valeur de transaction |
| Vente de terrain  | 2.5% de la valeur de transaction |

<InfoCard variant="note" title="Impôt du vendeur">
  **PPh Final 2.5%** est : - Payé par le vendeur - Basé sur la valeur de la
  transaction (ou le NJOP si plus élevé) - Dû avant le transfert de titre -
  Final (pas d'impôt sur le revenu supplémentaire sur le gain)
</InfoCard>

## Impôt sur les revenus locatifs

### Impôt sur les loyers perçus

<InfoCard variant="note" title="Impôt final de 10%">
Les revenus locatifs immobiliers sont soumis à :

**10% de PPh Final** sur le revenu locatif brut

- S'applique aux terrains et aux bâtiments
- Pas de déduction pour les dépenses
- Final (non ajouté aux autres revenus)
- Doit être retenu par les locataires corporatifs
  </InfoCard>

### Qui retient l'impôt ?

| Type de locataire    | Traitement fiscal             |
| -------------------- | ----------------------------- |
| Locataire corporatif | Doit retenir 10%              |
| Locataire individuel | Le propriétaire s'auto-évalue |

### Déclaration

| Situation            | Action                           |
| -------------------- | -------------------------------- |
| Locataire corporatif | Ils délivrent un bukti potong    |
| Locataire individuel | Vous déclarez et payez           |
| Mixte                | Déclarez tout dans le SPT annuel |

## Explication du NJOP

### Qu'est-ce que le NJOP ?

<InfoCard variant="note" title="Valeur évaluée par le gouvernement">
**NJOP** (Nilai Jual Objek Pajak) est :
- La valeur immobilière évaluée par le gouvernement
- Utilisée pour les calculs fiscaux
- Généralement inférieure à la valeur marchande
- Mise à jour périodiquement

Trouvez votre NJOP sur votre SPPT (avis d'imposition) ou vérifiez au bureau des impôts local.

</InfoCard>

### NJOP vs Valeur marchande

| Aspect                   | NJOP             | Valeur marchande |
| ------------------------ | ---------------- | ---------------- |
| Établi par               | Gouvernement     | Marché           |
| Niveau typique           | 50-80% du marché | 100%             |
| Fréquence de mise à jour | Périodique       | En temps réel    |
| Utilisé pour             | Impôts           | Transactions     |

## Conseils de planification fiscale

### Moyens légaux de minimiser

| Stratégie               | Comment ça marche                               |
| ----------------------- | ----------------------------------------------- |
| Acquisition temporaire  | La fin d'année peut permettre une planification |
| Structure de propriété  | PT PMA vs personnel                             |
| Utiliser le NJOPTKP     | S'assurer que le seuil est appliqué             |
| Régler le PBB à temps   | Éviter les pénalités                            |
| Documenter les dépenses | Pour une base de vente future                   |

<InfoCard variant="warning" title="Conformité fiscale">
**Ne pas :**
- Sous-déclarer les valeurs de transaction
- Cacher la propriété immobilière
- Ne pas payer le PBB
- Ignorer les revenus locatifs

Les autorités fiscales recoupent les informations avec le BPN et les registres notariés. La non-conformité crée des problèmes lorsque vous souhaitez vendre.

</InfoCard>
