# Acheter un appartement en Indonesia en 2026 : Guide pour les étrangers

Les appartements (condos) offrent l'une des voies légales les plus claires pour les étrangers souhaitant posséder une propriété en Indonesia. Voici votre guide complet.

## Les étrangers peuvent-ils acheter des appartements ?

<InfoCard variant="note" title="Oui, avec des exigences">
  Les étrangers peuvent posséder des appartements en Indonesia sous certaines
  conditions : - Doivent avoir un **KITAS ou KITAP** valide - La propriété doit
  respecter les exigences de **prix minimum** - Doit se trouver dans un immeuble
  en **strata title** approuvé pour la propriété étrangère - La propriété est
  détenue via **Hak Milik Satuan Rumah Susun** (HMSRS) ou Hak Pakai en strata
</InfoCard>

---

## Propriété en Strata Title

Lorsque vous achetez un appartement, vous obtenez :

### Ce que vous possédez

- **L'unité** : Votre espace d'appartement spécifique
- **Partie de la propriété commune** : Propriété proportionnelle des installations partagées
- **Droits de membre** : Au sein de la gestion de l'immeuble (P3SRS)

### La propriété commune comprend

- Le terrain sur lequel est construit l'immeuble
- La structure et le toit
- Les couloirs et les halls
- Les piscines et les salles de sport
- Les structures de stationnement
- Les jardins et les espaces communs

## Répartition des coûts

<Calculator

    const bphtb = price * 0.05; // Buyer transfer tax
    const notary = price * 0.01; // Notary fees (approx)
    const registration = 1000000; // BPN registration

    // Seller pays, but affects negotiation
    const pph = price * 0.025; // Seller income tax

    const totalBuyerCosts = price + bphtb + notary + registration;

    return {
      total: totalBuyerCosts,
      breakdown: [
        { label: "Prix d'achat", amount: price },
        { label: "BPHTB (taxe de transfert de 5 %)", amount: bphtb },

      ],

      note: `Le vendeur paie également le PPh ${(pph / 1000000).toFixed(0)}M (2.5%)`

## Ce qu'il faut vérifier

### Due diligence de l'immeuble

- Historique du promoteur
- État d'achèvement de l'immeuble
- Strata title émis/en attente
- Qualité de la société de gestion
- Propriété étrangère autorisée

### Due diligence de l'unité

- Statut du titre (SHMSRS émis)
- Toute charge
- État de la livraison
- Inclusions (meubles, etc.)

<InfoCard variant="tip" title="Neuf vs Revente">
  **Neuf du promoteur** : Le strata title peut être obtenu plus tard (PPJB en
  premier) **Revente** : Le strata title devrait être prêt pour le transfert
</InfoCard>

## Coûts récurrents

### Frais mensuels/annuels

| Coût                | Fourchette typique       | Notes                            |
| ------------------- | ------------------------ | -------------------------------- |
| Frais de service    | IDR 50-100k/m²/mois      | Entretien de l'immeuble          |
| Fonds de prévoyance | IDR 10-30k/m²/mois       | Réserve pour grosses réparations |
| PBB (taxe foncière) | 0.1-0.3% de la valeur/an | Taxe annuelle                    |
| Assurance           | Varie                    | Contenu personnel                |

### En cas de location

- Impôt sur le revenu locatif : 10% du loyer brut
- Frais de gestion : 10-20% du loyer
