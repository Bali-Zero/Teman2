## Pajak Properti Tahunan (PBB)

### Apa itu PBB?

<InfoCard variant="note" title="Pajak Bumi dan Bangunan">
**PBB** (Land and Building Tax) adalah:
- Pajak tahunan atas kepemilikan properti
- Berdasarkan nilai yang dinilai pemerintah (NJOP)
- Dibayar oleh pemilik properti
- Jatuh tempo pada akhir setiap tahun

Semua pemilik tanah dan bangunan wajib membayar PBB.

</InfoCard>

### Perhitungan PBB

| Komponen     | Penjelasan                           |
| ------------- | ------------------------------------- |
| NJOP          | Nilai yang dinilai pemerintah         |
| NJOPTKP       | Batas bebas pajak (berbeda per daerah) |
| Nilai kena pajak | NJOP dikurangi NJOPTKP              |
| Tarif pajak   | 0.1-0.5% (berbeda per daerah dan nilai) |

### Kalkulator PBB

<Calculator
  title="Estimasi PBB"
  description="Estimasi pajak properti tahunan Anda"
  fields={[
    {
      id: "njop",
      label: "Nilai NJOP (IDR)",
      type: "number",
      defaultValue: 500000000,
      min: 0
    },
    {
      id: "region",
      label: "Daerah",
      type: "select",
      options: [
        { value: "jakarta", label: "Jakarta" },
        { value: "bali", label: "Bali" },
        { value: "other", label: "Lainnya" }
      ],
      defaultValue: "bali"
    }
  ]}
  calculateResult={(values) => {
    // NJOPTKP varies by region
    const njoptkp = {
      jakarta: 60000000,
      bali: 50000000,
      other: 30000000
    };

    const threshold = njoptkp[values.region];
    const taxable = Math.max(0, values.njop - threshold);

    // Simplified rate (actual varies by bracket)
    let rate;
    if (values.njop < 1000000000) {
      rate = 0.001; // 0.1%
    } else if (values.njop < 2000000000) {
      rate = 0.002; // 0.2%
    } else {
      rate = 0.003; // 0.3%
    }

    const tax = taxable * rate;

    return {
      total: Math.round(tax),
      breakdown: [
        { label: "Nilai NJOP", amount: values.njop },
        { label: "NJOPTKP (batas)", amount: threshold },
        { label: "Nilai kena pajak", amount: taxable },
        { label: "Tarif efektif", amount: `${(rate * 100).toFixed(2)}%` },
        { label: "PBB Tahunan", amount: Math.round(tax) }
      ],
      currency: "IDR",
      note: "Pajak aktual dapat bervariasi berdasarkan peraturan daerah"
    };

}}

## Pajak Peralihan/Perolehan (BPHTB)

### Apa yang Dibayar Pembeli

<InfoCard variant="warning" title="BPHTB - Pajak Transfer 5%">
**BPHTB** berlaku saat Anda memperoleh properti:
- Pembelian
- Hadiah
- Warisan
- Tukar menukar

**Tarif:** 5% dari nilai transfer dikurangi NJOPTKP
**Dibayar oleh:** Pembeli/penerima
**Kapan:** Sebelum transfer sertifikat

</InfoCard>

### Perhitungan BPHTB

| Elemen           | Perhitungan             |
| ----------------- | ----------------------- |
| Nilai transaksi   | Yang lebih tinggi antara harga atau NJOP |
| Kurangi NJOPTKP   | Batas bebas pajak       |
| Dasar pajak       | Hasil                   |
| BPHTB             | 5% dari dasar pajak      |

### Contoh

| Item             | Jumlah             |
| ---------------- | ------------------ |
| Harga pembelian  | IDR 2,000,000,000  |
| NJOP             | IDR 1,500,000,000  |
| Gunakan nilai yang lebih tinggi | IDR 2,000,000,000  |
| NJOPTKP          | IDR 60,000,000     |
| Dasar pajak      | IDR 1,940,000,000  |
| **BPHTB (5%)**   | **IDR 97,000,000** |

## Pajak Penjual (PPh Final)

### Apa yang Dibayar Penjual

| Transaksi       | Tarif Pajak                  |
| ------------- | ------------------------- |
| Penjualan properti | 2.5% dari nilai transaksi |
| Penjualan tanah     | 2.5% dari nilai transaksi |

<InfoCard variant="note" title="Pajak Penjual">

  **PPh Final 2.5%** adalah: - Dibayar oleh penjual - Berdasarkan nilai transaksi (atau NJOP jika lebih tinggi) - Jatuh tempo sebelum transfer sertifikat - Final (tidak ada pajak penghasilan tambahan atas keuntungan)
</InfoCard>

## Pajak Pendapatan Sewa

### Pajak atas Sewa yang Diterima

<InfoCard variant="note" title="Pajak Final 10%">
Pendapatan sewa dari properti dikenakan:

**PPh Final 10%** atas pendapatan sewa kotor

- Berlaku untuk tanah dan bangunan
- Tidak ada pengurangan biaya
- Final (tidak ditambahkan ke penghasilan lain)
- Seharusnya dipotong oleh penyewa korporasi
</InfoCard>

### Siapa yang Memotong?

| Tipe Penyewa       | Perlakuan Pajak          |
| ----------------- | ---------------------- |
| Penyewa korporasi  | Wajib memotong 10%      |
| Penyewa perorangan | Pemilik properti menghitung sendiri |

### Pelaporan

| Situasi         | Tindakan                    |
| ----------------- | ------------------------- |
| Penyewa korporasi  | Mereka menerbitkan bukti potong   |
| Penyewa perorangan | Anda melaporkan dan membayar        |
| Campuran             | Deklarasikan semua dalam SPT tahunan |

## NJOP Dijelaskan

### Apa itu NJOP?

<InfoCard variant="note" title="Nilai yang Dinilai Pemerintah">
**NJOP** (Nilai Jual Objek Pajak) adalah:
- Nilai properti yang dinilai pemerintah
- Digunakan untuk perhitungan pajak
- Biasanya lebih rendah dari nilai pasar
- Diperbarui secara berkala

Cari NJOP Anda pada SPPT (surat ketetapan pajak) atau cek di kantor pajak setempat.

</InfoCard>

### NJOP vs Nilai Pasar

| Aspek           | NJOP             | Nilai Pasar |
| ---------------- | ---------------- | ------------ |
| Ditetapkan oleh  | Pemerintah       | Pasar        |
| Tingkat tipikal  | 50-80% dari pasar | 100%         |
| Frekuensi update | Berkala          | Real-time    |
| Digunakan untuk   | Pajak            | Transaksi    |

## Tips Perencanaan Pajak

### Cara Legal untuk Mengurangi

| Strategi            | Cara Kerjanya                |
| ------------------- | --------------------------- |
| Waktu perolehan     | Akhir tahun mungkin memungkinkan perencanaan |
| Struktur kepemilikan | PT PMA vs pribadi          |
| Gunakan NJOPTKP         | Pastikan batas diterapkan    |
| Lunasi PBB tepat waktu   | Hindari denda             |
| Dokumentasikan biaya   | Untuk dasar penjualan masa depan       |

<InfoCard variant="warning" title="Kepatuhan Pajak">
**Jangan:**
- Melaporkan nilai transaksi lebih rendah
- Menyembunyikan kepemilikan properti
- Gagal membayar PBB
- Mengabaikan pendapatan sewa

Otoritas pajak membandingkan data dengan catatan BPN dan notaris. Ketidakpatuhan menciptakan masalah saat Anda ingin menjual.

</InfoCard>

### Perlakuan Berbeda

| Aspek        | Pribadi   | PT PMA             |
| ------------- | ---------- | ------------------ |
| PBB           | Sama       | Sama               |

| Pendapatan sewa | 10% final  | Pajak penghasilan perusahaan |
| Penyusutan    | Tidak ada   | Ya, untuk bangunan |
