## Pajak Bumi dan Bangunan (PBB)

### Apa itu PBB?

<InfoCard variant="note" title="Pajak Bumi dan Bangunan">
**PBB** adalah:
- Pajak tahunan atas kepemilikan properti
- Berdasarkan nilai taksiran pemerintah (NJOP)
- Dibayar oleh pemilik properti
- Jatuh tempo pada bulan Agustus setiap tahun

Semua pemilik tanah dan bangunan wajib membayar PBB.

</InfoCard>

### Perhitungan PBB

| Komponen         | Penjelasan                                   |
| ---------------- | -------------------------------------------- |
| NJOP             | Nilai Jual Objek Pajak (taksiran pemerintah) |
| NJOPTKP          | Ambang batas tidak kena pajak (bervariasi)   |
| Nilai kena pajak | NJOP dikurangi NJOPTKP                       |
| Tarif pajak      | 0,1-0,5% (bervariasi menurut wilayah)        |

### Kalkulator PBB

<Calculator
  title="Estimasi PBB"
  description="Estimasi pajak properti tahunan Anda"
  fields={[
    {
      id: "njop",
      label: "Nilai NJOP (IDR)",
      type: "number",
      defaultValue: 500000000,
      min: 0
    },
    {
      id: "region",
      label: "Wilayah",
      type: "select",
      options: [
        { value: "jakarta", label: "Jakarta" },
        { value: "bali", label: "Bali" },
        { value: "other", label: "Lainnya" }
      ],
      defaultValue: "bali"
    }
  ]}
  calculateResult={(values) => {
    // NJOPTKP bervariasi menurut wilayah
    const njoptkp = {
      jakarta: 60000000,
      bali: 50000000,
      other: 30000000
    };

    const threshold = njoptkp[values.region];
    const taxable = Math.max(0, values.njop - threshold);

    // Tarif yang disederhanakan (aktual bervariasi menurut bracket)
    let rate;
    if (values.njop < 1000000000) {
      rate = 0.001; // 0.1%
    } else if (values.njop < 2000000000) {
      rate = 0.002; // 0.2%
    } else {
      rate = 0.003; // 0.3%
    }

    const tax = taxable * rate;

    return {
      total: Math.round(tax),
      breakdown: [
        { label: "Nilai NJOP", amount: values.njop },
        { label: "NJOPTKP (ambang batas)", amount: threshold },
        { label: "Nilai kena pajak", amount: taxable },
        { label: "Tarif efektif", amount: `${(rate * 100).toFixed(2)}%` },
        { label: "PBB Tahunan", amount: Math.round(tax) }
      ],
      currency: "IDR",
      note: "Pajak sebenarnya mungkin berbeda berdasarkan peraturan daerah"
    };

}}
/>

## Bea Perolehan Hak atas Tanah dan Bangunan (BPHTB)

### Apa yang Dibayar Pembeli

<InfoCard variant="warning" title="BPHTB - Pajak Balik Nama 5%">
**BPHTB** berlaku saat Anda memperoleh properti melalui:
- Pembelian
- Hibah
- Warisan
- Tukar menukar

**Tarif:** 5% dari nilai perolehan dikurangi NPOPTKP
**Dibayar oleh:** Pembeli/penerima
**Kapan:** Sebelum balik nama sertifikat

</InfoCard>

### Perhitungan BPHTB

| Elemen            | Perhitungan                                   |
| ----------------- | --------------------------------------------- |
| Nilai transaksi   | Mana yang lebih tinggi antara harga atau NJOP |
| Dikurangi NPOPTKP | Ambang batas tidak kena pajak                 |
| Dasar pajak       | Hasil pengurangan                             |
| BPHTB             | 5% dari dasar pajak                           |

### Contoh

| Item                    | Jumlah             |
| ----------------------- | ------------------ |
| Harga pembelian         | IDR 2.000.000.000  |
| NJOP                    | IDR 1.500.000.000  |
| Gunakan nilai tertinggi | IDR 2.000.000.000  |
| NPOPTKP                 | IDR 60.000.000     |
| Dasar pajak             | IDR 1.940.000,000  |
| **BPHTB (5%)**          | **IDR 97.000.000** |

## Pajak Penjual (PPh Final)

### Apa yang Dibayar Penjual

| Transaksi     | Tarif Pajak               |
| ------------- | ------------------------- |
| Jual properti | 2,5% dari nilai transaksi |
| Jual tanah    | 2,5% dari nilai transaksi |

<InfoCard variant="note" title="Pajak Penjual">
  **PPh Final 2,5%** adalah: - Dibayar oleh penjual - Berdasarkan nilai
  transaksi (atau NJOP jika lebih tinggi) - Jatuh tempo sebelum balik nama -
  Final (tidak ada pajak penghasilan tambahan atas keuntungan)
</InfoCard>

## Pajak Penghasilan Sewa

### Pajak atas Sewa yang Diterima

<InfoCard variant="note" title="Pajak Final 10%">
Penghasilan sewa dari properti dikenakan:

**PPh Final 10%** dari total penghasilan sewa bruto

- Berlaku untuk tanah dan bangunan
- Tidak ada pengurangan biaya-biaya
- Final (tidak ditambahkan ke penghasilan lain)
- Harus dipotong oleh penyewa perusahaan
  </InfoCard>

### Siapa yang Memotong?

| Tipe Penyewa       | Perlakuan Pajak       |
| ------------------ | --------------------- |
| Penyewa perusahaan | Wajib memotong 10%    |
| Penyewa individu   | Pemilik lapor sendiri |

### Pelaporan

| Situasi            | Tindakan                          |
| ------------------ | --------------------------------- |
| Penyewa perusahaan | Mereka menerbitkan bukti potong   |
| Penyewa individu   | Anda melapor dan membayar         |
| Campuran           | Deklarasikan semua di SPT tahunan |

## Penjelasan NJOP

### Apa itu NJOP?

<InfoCard variant="note" title="Nilai Jual Objek Pajak">
**NJOP** adalah:
- Nilai properti yang ditaksir pemerintah
- Digunakan untuk perhitungan pajak
- Biasanya lebih rendah dari nilai pasar
- Diperbarui secara berkala

Temukan NJOP Anda di SPPT (surat pajak) atau cek di kantor pajak setempat.

</InfoCard>

### NJOP vs Nilai Pasar

| Aspek               | NJOP              | Nilai Pasar |
| ------------------- | ----------------- | ----------- |
| Ditetapkan oleh     | Pemerintah        | Pasar       |
| Tingkat tipikal     | 50-80% dari pasar | 100%        |
| Frekuensi pembaruan | Berkala           | Real-time   |
| Digunakan untuk     | Pajak             | Transaksi   |

## Tips Perencanaan Pajak

### Cara Legal untuk Meminimalkan

| Strategi              | Cara Kerjanya                        |
| --------------------- | ------------------------------------ |
| Waktu akuisisi        | Akhir tahun memungkinkan perencanaan |
| Struktur kepemilikan  | PT PMA vs pribadi                    |
| Gunakan NJOPTKP       | Pastikan ambang batas diterapkan     |
| Bayar PBB tepat waktu | Hindari denda                        |
| Dokumentasi biaya     | Untuk dasar penjualan masa depan     |

<InfoCard variant="warning" title="Kepatuhan Pajak">
**Jangan:**
- Melaporkan nilai transaksi di bawah harga sebenarnya
- Menyembunyikan kepemilikan properti
- Lalai membayar PBB
- Mengabaikan pajak penghasilan sewa

Otoritas pajak melakukan verifikasi silang dengan catatan BPN dan notaris. Ketidakpatuhan akan menimbulkan masalah saat Anda ingin menjual properti.

</InfoCard>
