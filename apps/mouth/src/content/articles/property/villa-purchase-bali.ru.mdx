# Покупка виллы на Bali 2026: Руководство для иностранцев

Владение виллой на Bali – мечта многих. Вот все, что вам нужно знать, чтобы воплотить ее в реальность.

## Могут ли иностранцы покупать?

<InfoCard variant="warning" title="Краткий ответ">
**Иностранцы не могут владеть землей в полную собственность (freehold) в Indonesia.**

Но есть законные способы обеспечить себе недвижимость:

- **Leasehold** (долгосрочная аренда)
- **Hak Pakai** (право пользования - для личного проживания)
- **PT PMA** (владение компанией)

Каждый вариант имеет свои плюсы и минусы – выбирайте исходя из вашей ситуации.

</InfoCard>

## Калькулятор стоимости

<Calculator
  title="Бюджет покупки виллы"
  description="Оцените общие затраты"
  fields={[
    {
      id: "price",
      label: "Стоимость виллы (IDR)",
      type: "number",
      defaultValue: 5000000000,
      min: 0
    },
    {
      id: "structure",
      label: "Структура владения",
      type: "select",
      options: [
        { value: "leasehold", label: "Leasehold" },
        { value: "hakpakai", label: "Hak Pakai" },
        { value: "ptpma", label: "PT PMA + HGB" }
      ],
      defaultValue: "leasehold"
    }
  ]}
  calculateResult={(values) => {
    const price = values.price;
    let structureCost = 0;
    let transferTax = 0;
    let notary = price * 0.01;
    let legal = 0;

    if (values.structure === "leasehold") {
      structureCost = 0;
      transferTax = 0; // No BPHTB on lease
      legal = 30000000;
    } else if (values.structure === "hakpakai") {
      transferTax = price * 0.05; // BPHTB
      legal = 50000000;
    } else {
      structureCost = 150000000; // PT PMA setup
      transferTax = price * 0.05; // BPHTB
      legal = 75000000;
    }

    const agent = price * 0.05; // If using agent
    const misc = 20000000;

    const total = price + structureCost + transferTax + notary + legal + agent + misc;

    return {
      total: total,
      breakdown: [
        { label: "Стоимость виллы", amount: price },
        { label: "Создание структуры (если PT PMA)", amount: structureCost },
        { label: "Налог на передачу (BPHTB)", amount: transferTax },
        { label: "Нотариальные сборы", amount: Math.round(notary) },
        { label: "Юридические сборы", amount: legal },
        { label: "Комиссия агента (5%)", amount: Math.round(agent) },
        { label: "Прочее", amount: misc }
      ],
      currency: "IDR",
      note: `~USD ${Math.round(total / 16000).toLocaleString()} всего`
    };

}}

## Распространенные ошибки

<InfoCard variant="warning" title="Избегайте этих ошибок">
**Распространенные ошибки покупателей:**

1.  **Не проводить должную осмотрительность** - Проблемы с титулом распространены
2.  **Использование номинального владельца** - Рискованно, не рекомендуется
3.  **Пропуск юридической проверки** - Всегда используйте юриста
4.  **Слишком быстрая оплата** - Придержите деньги до полного оформления
5.  **Неправильная структура** - Должна соответствовать вашим потребностям
6.  **Игнорирование зонирования** - Возможно, не сможете сдавать в аренду
7.  **Устные соглашения** - Все оформляйте письменно
8.  **Не учитывать дополнительные расходы** - 10-15% сверх цены
