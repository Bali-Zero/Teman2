## Ежегодный налог на недвижимость (PBB)

### Что такое PBB?

<InfoCard variant="note" title="Pajak Bumi dan Bangunan">
**PBB** (Налог на землю и строения) это:
- Ежегодный налог на владение недвижимостью
- Основан на оценочной стоимости правительства (NJOP)
- Оплачивается владельцем недвижимости
- Срок уплаты - до августа каждого года

Все владельцы земли и строений должны платить PBB.

</InfoCard>

### Расчет PBB

| Компонент                  | Объяснение                                    |
| -------------------------- | --------------------------------------------- |
| NJOP                       | Оценочная стоимость правительства             |
| NJOPTKP                    | Необлагаемый порог (варьируется по региону)   |
| Налогооблагаемая стоимость | NJOP минус NJOPTKP                            |
| Налоговая ставка           | 0.1-0.5% (варьируется по региону и стоимости) |

### Калькулятор PBB

<Calculator
  title="Оценка PBB"
  description="Оцените свой ежегодный налог на недвижимость"
  fields={[
    {
      id: "njop",
      label: "Стоимость NJOP (IDR)",
      type: "number",
      defaultValue: 500000000,
      min: 0
    },
    {
      id: "region",
      label: "Регион",
      type: "select",
      options: [
        { value: "jakarta", label: "Jakarta" },
        { value: "bali", label: "Bali" },
        { value: "other", label: "Другое" }
      ],
      defaultValue: "bali"
    }
  ]}
  calculateResult={(values) => {
    // NJOPTKP varies by region
    const njoptkp = {
      jakarta: 60000000,
      bali: 50000000,
      other: 30000000
    };

    const threshold = njoptkp[values.region];
    const taxable = Math.max(0, values.njop - threshold);

    // Simplified rate (actual varies by bracket)
    let rate;
    if (values.njop < 1000000000) {
      rate = 0.001; // 0.1%
    } else if (values.njop < 2000000000) {
      rate = 0.002; // 0.2%
    } else {
      rate = 0.003; // 0.3%
    }

    const tax = taxable * rate;

    return {
      total: Math.round(tax),
      breakdown: [
        { label: "Стоимость NJOP", amount: values.njop },
        { label: "NJOPTKP (порог)", amount: threshold },
        { label: "Налогооблагаемая стоимость", amount: taxable },
        { label: "Эффективная ставка", amount: `${(rate * 100).toFixed(2)}%` },
        { label: "Ежегодный PBB", amount: Math.round(tax) }
      ],
      currency: "IDR",
      note: "Фактический налог может варьироваться в зависимости от местных правил"
    };

}}
/>

## Налог на передачу/приобретение (BPHTB)

### Что платят покупатели

<InfoCard variant="warning" title="BPHTB - 5% налог на передачу">
**BPHTB** применяется при приобретении недвижимости:
- Покупка
- Дарение
- Наследование
- Обмен

**Ставка:** 5% от стоимости передачи минус NJOPTKP
**Оплачивается:** Покупателем/получателем
**Когда:** До передачи титула

</InfoCard>

### Расчет BPHTB

| Элемент          | Расчет                   |
| ---------------- | ------------------------ |
| Стоимость сделки | Большее из цены или NJOP |
| Минус NJOPTKP    | Необлагаемый порог       |
| Налоговая база   | Результат                |
| BPHTB            | 5% от налоговой базы     |

### Пример

| Пункт                          | Сумма              |
| ------------------------------ | ------------------ |
| Цена покупки                   | IDR 2,000,000,000  |
| NJOP                           | IDR 1,500,000,000  |
| Использовать большую стоимость | IDR 2,000,000,000  |
| NJOPTKP                        | IDR 60,000,000     |
| Налоговая база                 | IDR 1,940,000,000  |
| **BPHTB (5%)**                 | **IDR 97,000,000** |

## Налог продавца (PPh Final)

### Что платят продавцы

| Сделка               | Налоговая ставка         |
| -------------------- | ------------------------ |
| Продажа недвижимости | 2.5% от стоимости сделки |
| Продажа земли        | 2.5% от стоимости сделки |

<InfoCard variant="note" title="Налог продавца">
  **PPh Final 2.5%** это: - Оплачивается продавцом - Основан на стоимости сделки
  (или NJOP, если выше) - Срок уплаты до передачи титула - Окончательный
  (дальнейший подоходный налог на прибыль не взимается)
</InfoCard>

## Налог на доход от аренды

### Налог на полученный доход от аренды

<InfoCard variant="note" title="10% окончательный налог">
Доход от аренды недвижимости облагается:

**10% PPh Final** с валового дохода от аренды

- Применяется к земле и строениям
- Нет вычетов за расходы
- Окончательный (не добавляется к другим доходам)
- Должен удерживаться корпоративными арендаторами
  </InfoCard>

### Кто удерживает?

| Тип арендатора           | Налоговый режим                                       |
| ------------------------ | ----------------------------------------------------- |
| Корпоративный арендатор  | Должен удерживать 10%                                 |
| Индивидуальный арендатор | Арендодатель самостоятельно рассчитывает и уплачивает |

### Отчетность

| Ситуация                 | Действие                         |
| ------------------------ | -------------------------------- |
| Корпоративный арендатор  | Они выдают bukti potong          |
| Индивидуальный арендатор | Вы отчитываетесь и платите       |
| Смешанный                | Задекларируйте все в годовом SPT |

## Что такое NJOP?

### Что такое NJOP?

<InfoCard variant="note" title="Оценочная стоимость правительства">
**NJOP** (Nilai Jual Objek Pajak) это:
- Оценочная стоимость недвижимости правительством
- Используется для налоговых расчетов
- Обычно ниже рыночной стоимости
- Периодически обновляется

Найдите свой NJOP в SPPT (налоговом уведомлении) или проверьте в местной налоговой инспекции.

</InfoCard>

### NJOP против рыночной стоимости

| Аспект             | NJOP            | Рыночная стоимость |
| ------------------ | --------------- | ------------------ |
| Устанавливается    | Правительством  | Рынком             |
| Типичный уровень   | 50-80% от рынка | 100%               |
| Частота обновлений | Периодическая   | В реальном времени |
| Используется для   | Налогов         | Сделок             |

## Советы по налоговому планированию

### Законные способы минимизации

| Стратегия                  | Как это работает                        |
| -------------------------- | --------------------------------------- |
| Выбор времени приобретения | Конец года может позволить планирование |
| Структура владения         | PT PMA против личного                   |
| Использование NJOPTKP      | Убедитесь, что порог применен           |
| Своевременная уплата PBB   | Избегайте штрафов                       |
| Документирование расходов  | Для будущей базы продажи                |

<InfoCard variant="warning" title="Налоговое соответствие">
**Не делайте:**
- Занижать стоимость сделок
- Скрывать владение недвижимостью
- Не платить PBB
- Игнорировать доход от аренды

Налоговые органы перекрестно сверяют данные с BPN и нотариальными записями. Несоблюдение требований создает проблемы, когда вы захотите продать.

</InfoCard>
