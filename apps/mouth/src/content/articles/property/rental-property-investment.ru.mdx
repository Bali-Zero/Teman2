## Ожидаемая доходность

### Типичная доходность

| Тип недвижимости           | Валовая доходность | Чистая доходность |
| -------------------------- | ------------------ | ----------------- |
| Вилла Bali (краткосрочная) | 8-15%              | 5-10%             |
| Вилла Bali (долгосрочная)  | 5-8%               | 4-6%              |
| Квартира Jakarta           | 5-7%               | 4-5%              |
| Обслуживаемые апартаменты  | 6-10%              | 4-7%              |

<InfoCard variant="warning" title="Реалистичные ожидания">
**Будьте реалистами:**

- Валовая доходность не учитывает расходы
- Чистая доходность важнее
- Заполняемость варьируется (60-80% типично для краткосрочной аренды)
- Расходы на обслуживание растут
- Комиссии за управление 15-25%
- Налог еще больше снижает доходность

Для реалистичного планирования цельтесь в 5-8% чистой прибыли.

</InfoCard>

### Калькулятор доходности

<Calculator
  title="Оценка доходности от аренды"
  description="Рассчитайте потенциальную доходность"
  fields={[
    {
      id: "purchase",
      label: "Стоимость недвижимости (IDR)",
      type: "number",
      defaultValue: 3000000000,
      min: 0
    },
    {
      id: "monthlyRate",
      label: "Месячная ставка аренды (IDR)",
      type: "number",
      defaultValue: 25000000,
      min: 0
    },
    {
      id: "occupancy",
      label: "Ожидаемая заполняемость (%)",
      type: "number",
      defaultValue: 70,
      min: 0,
      max: 100
    },
    {
      id: "managed",
      label: "Управление недвижимостью?",
      type: "select",
      options: [
        { value: "yes", label: "Да (20% от дохода)" },
        { value: "no", label: "Нет (самостоятельное управление)" }
      ],
      defaultValue: "yes"
    }
  ]}
  calculateResult={(values) => {
    const annualGross = values.monthlyRate * 12 * (values.occupancy / 100);
    const managementFee = values.managed === "yes" ? annualGross * 0.20 : 0;
    const maintenance = annualGross * 0.10; // 10% for maintenance
    const utilities = values.monthlyRate * 0.1 * 12; // Rough utility estimate
    const tax = annualGross * 0.10; // 10% rental income tax

    const totalExpenses = managementFee + maintenance + utilities + tax;
    const netIncome = annualGross - totalExpenses;

    const grossYield = (annualGross / values.purchase) * 100;
    const netYield = (netIncome / values.purchase) * 100;

    return {
      total: Math.round(netIncome),
      breakdown: [
        { label: "Годовой валовой доход от аренды", amount: Math.round(annualGross) },
        { label: "Управление недвижимостью", amount: -Math.round(managementFee) },
        { label: "Обслуживание (10%)", amount: -Math.round(maintenance) },
        { label: "Приблизительные коммунальные услуги", amount: -Math.round(utilities) },
        { label: "Налог на аренду (10%)", amount: -Math.round(tax) },
        { label: "ЧИСТЫЙ ГОДОВОЙ ДОХОД", amount: Math.round(netIncome) },
        { label: "Валовая доходность", amount: `${grossYield.toFixed(1)}%` },
        { label: "Чистая доходность", amount: `${netYield.toFixed(1)}%` }
      ],
      currency: "IDR",
      note: `Чистая доходность: ${netYield.toFixed(1)}% (~USD ${Math.round(netIncome / 16000).toLocaleString()}/год)`
    };

}}

## Сегменты рынка

### Краткосрочная аренда (Airbnb/VRBO)

| Плюсы                                 | Минусы                        |
| ------------------------------------- | ----------------------------- |
| Более высокий потенциальный доход     | Больше управления             |
| Гибкость в использовании недвижимости | Сезонные колебания            |
| Возможность регулировать цены         | Проблемы с гостями            |
| Растущий туристический рынок          | Регуляторная неопределенность |

### Долгосрочная аренда

| Плюсы                        | Минусы                           |
| ---------------------------- | -------------------------------- |
| Стабильный доход             | Более низкая доходность          |
| Меньше управления            | Меньше гибкости                  |
| Предсказуемый денежный поток | Возможны проблемы с арендаторами |
| Меньший износ                | Более длительные простои         |

## Налоговые обязательства

### Налог на доход от аренды

<InfoCard variant="note" title="10% Окончательный налог">
Доход от аренды недвижимости облагается:

**10% Окончательным налогом** на валовой доход от аренды

- Без вычетов за расходы
- Окончательный (не добавляется к другим доходам)
- Удерживается корпоративными арендаторами
- Самостоятельно рассчитывается для индивидуальных арендаторов
  </InfoCard>
