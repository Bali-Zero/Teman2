# Regole sulla Proprietà Terreni in Indonesia 2026: Guida per l'Estero

Gli stranieri non possono possedere direttamente terreni a titolo di piena proprietà in Indonesia. Tuttavia, esistono modi legali per garantire diritti sulla proprietà. Ecco la tua guida completa.

## La Regola Fondamentale

<InfoCard variant="warning" title="Restrizione Fondamentale">
**Legge indonesiana (Legge Agraria 1960):**

- Solo i cittadini indonesiani possono detenere **Hak Milik** (piena proprietà)
- Gli stranieri possono detenere determinati **diritti di uso**
- Il terreno torna automaticamente allo stato se uno straniero detiene Hak Milik

Si tratta di una legge costituzionale - non può essere aggirata legalmente.

</InfoCard>

## Struttura PT PMA

### Come Funziona

1. **Istituire PT PMA** - Società di investimento estera
2. **Registrare attività immobiliare** - Nella licenza commerciale
3. **Acquisire titolo HGB** - La società detiene il titolo
4. **Tu controlli la società** - Proprietà indiretta

### Vantaggi

| Beneficio             | Dettagli                    |
| ------------------- | -------------------------- |
| Uso commerciale      | Possibilità di affittare la proprietà      |
| Multiple proprietà | Nessun limite di singola proprietà   |
| Operazioni aziendali | Piena attività commerciale |
| Trasferibile        | Vendita di quote, non proprietà  |
| Finanziamento bancario      | Più facile da ottenere           |

### Svantaggi

| Sfida            | Dettagli                |
| -------------------- | ---------------------- |
| Costo di setup           | IDR 100-200M+          |
   Compliance continuativa   | Reporting, tasse         |
| Requisiti di capitale | Investimento minimo     |
| Complessità           | Onere legale e amministrativo |
| Costi operativi        | Contabilità, licenze   |

## Accordi di Locazione

### Locazione a Lungo Termine

<InfoCard variant="tip" title="Alternativa Più Semplice">
**La locazione (Hak Sewa)** è spesso più semplice:

- Locare il terreno dal proprietario indonesiano
- Termini tipici: 25-30 anni
- Possibilità di costruire con autorizzazione
- Minore complessità rispetto alla PT PMA
- Nessun requisito di valore minimo

Molti espatri preferiscono questa opzione per la semplicità.

</InfoCard>

### Struttura di Locazione

| Elemento         | Termini Tipici                  |
| --------------- | ------------------------------ |
| Durata        | 25-30 anni                    |
| Prolungamento       | Spesso negoziabile               |
| Registrazione    | Accordo notarile            |
| Diritti di costruzione | Di solito inclusi               |
| Miglioramenti    | Torno al proprietario o compensati |

## E i Nominativi?

<InfoCard variant="warning" title="Accordi con Nominativi">
**Nominativo = Un indonesiano detiene il titolo per uno straniero**

**La verità:**

- Comune ma **legalmente rischioso**
- La legge sui terreni non riconosce il nominativo
- Il nominativo può rivendicare la vera proprietà
- I tribunali potrebbero non proteggere lo straniero
- Può essere nullo se contestato

**Se usi un nominativo:**

- Utilizzare accordi legali completi
- Comprendere di avere una PROTEZIONE LIMITATA
- Considerare la PT PMA invece per la sicurezza
</InfoCard>

### Rischi del Nominativo

| Rischio                     | Conseguenza               |
| ------------------------ | ------------------------- |
| Il nominativo rivendica la proprietà | Potresti perdere la proprietà         |
| Il nominativo muore             | Complicazioni ereditarie |
| Debiti del nominativo          | La proprietà può essere sequestrata    |
| Divorzio del nominativo          | Il coniuge potrebbe rivendicare          |
| Contestazione legale          | L'accordo è nullo          |

## Titolo di Condominio/Strata

### Opzione Migliore per gli Stranieri

<InfoCard variant="note" title="Titolo di Strata (Hak Milik Sarusun)">
**Gli appartamenti sono diversi!**

Gli stranieri possono detenere direttamente il titolo di strata (HMSRS):

- Non serve PT PMA
- Non serve KITAS (verificare lo sviluppo specifico)
- Si applicano ancora i requisiti di valore minimo
- Processo transazionale più semplice

Molti stranieri scelgono gli appartamenti per la semplicità.

</InfoCard>

### Requisiti

| Requisito   | Dettagli                      |
| ------------- | ---------------------------- |
| Valore minimo | Varia per regione             |
| Tipo di edificio | Appartamenti/strata solo       |
| Documentazione | Passaporto, accordo di acquisto |
| Registrazione  | Attraverso sviluppatore/BPN        |
