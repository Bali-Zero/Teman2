# Regole sulla Proprietà Terreni in Indonesia 2026: Guida per Esterni

Gli stranieri non possono possedere direttamente terreni a titolo di piena proprietà (freehold) in Indonesia. Tuttavia, esistono modi legali per garantire diritti sulla proprietà. Ecco la vostra guida completa.

## La Regola Fondamentale

<InfoCard variant="warning" title="Restrizione Fondamentale">
**Legge indonesiana (Legge Agraria 1960):**

- Solo i cittadini indonesiani possono detenere il **Hak Milik** (piena proprietà)
- Gli stranieri possono detenere determinati **diritti di uso**
- Il terreno torna automaticamente allo Stato se uno straniero detiene Hak Milik

Si tratta di diritto costituzionale - non può essere aggirato legalmente.

</InfoCard>

## Struttura PT PMA

### Come Funziona

1. **Istituire PT PMA** - Società di investimento straniera
2. **Registrare attività immobiliare** - Nella licenza commerciale
3. **Acquisire titolo HGB** - La società detiene il titolo
4. **Voi controllate la società** - Proprietà indiretta

### Vantaggi

| Beneficio             | Dettagli                    |
| ------------------- | -------------------------- |
| Uso commerciale      | Possibilità di affittare la proprietà      |
| Molteplici proprietà | Nessun limite di singola proprietà   |
| Operazioni aziendali | Piena attività commerciale |
| Trasferibile        | Vendita delle quote, non della proprietà  |
| Finanziamento bancario      | Più facile da ottenere           |

### Svantaggi

| Sfida            | Dettagli                |
| -------------------- | ---------------------- |
| Costo di setup           | IDR 100-200M+          |
   Conformità continuativa   | Rendicontazione, tasse         |
   Requisiti di capitale | Investimento minimo     |
   Complessità           | Onere legale e amministrativo |
   Costi operativi        | Contabilità, licenze   |

## Accordi di Locazione

### Locazione a Lungo Termine

<InfoCard variant="tip" title="Alternativa più Semplice">
**Diritto di locazione (Hak Sewa)** è spesso più semplice:

- Locare il terreno dal proprietario indonesiano
- Scadenze tipiche: 25-30 anni
- Possibilità di costruire con autorizzazione
- Complessità inferiore rispetto a PT PMA
- Nessun requisito di valore minimo

Molti espatri preferiscono questa opzione per la semplicità.

</InfoCard>

### Struttura di Locazione

| Elemento         | Scadenze Tipiche                  |
| --------------- | ------------------------------ |
| Durata        | 25-30 anni                    |
| Proroga       | Spesso negoziabile               |
| Registrazione    | Accordo notarile            |
   Diritti di costruzione | Generalmente inclusi               |
   Migliorie    | Torna al proprietario o compensate |

## Che Cosa dei Nominee?

<InfoCard variant="warning" title="Accordi con Nominee">
**Nominee = Indonesiano detiene il titolo per lo straniero**

**La verità:**

- Comune ma **legalmente rischioso**
- La legge sui terreni non riconosce il nominee
- Il nominee può rivendicare la vera proprietà
   I tribunali potrebbero non proteggere lo straniero
   Può essere nullo se contestato

**Se usate un nominee:**

- Utilizzate accordi legali completi
- Capite di avere una PROTEZIONE LIMITATA
   Considerate PT PMA invece per sicurezza
</InfoCard>

### Rischi del Nominee

| Rischio                     | Conseguenza               |
| ------------------------ | ------------------------- |
| Il nominee rivendica la proprietà | Potete perdere la proprietà         |
| Il nominee muore             | Complicazioni ereditarie |
| Debiti del nominee          | La proprietà può essere sequestrata    |
| Divorzio del nominee          | Il coniuge può rivendicare          |
   Contestazione legale          | L'accordo è nullo          |

## Titolo di Condominio/Strata Title

### Opzione Migliore per Stranieri

<InfoCard variant="note" title="Titolo di Strata (Hak Milik Sarusun)">
**Gli appartamenti sono diversi!**

Gli stranieri possono detenere direttamente il titolo di strata (HMSRS):

- Non serve PT PMA
- Non serve KITAS (verificare lo sviluppo specifico)
   I requisiti di valore minimo si applicano ancora
   Processo transazionale più semplice

Molti stranieri scelgono gli appartamenti per la semplicità.

</InfoCard>

### Requisiti

| Requisito   | Dettagli                      |
| ------------- | ---------------------------- |
   Valore minimo | Varia per regione             |
   Tipo di edificio | Appartamenti/strata solo       |
   Documentazione | Passaporto, accordo di acquisto |
   Registrazione  | Attraverso sviluppatore/BPN        |
