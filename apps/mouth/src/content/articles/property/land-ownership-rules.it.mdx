# Regole Proprietà Fondiaria Indonesia 2026: Guida per Stranieri

Gli stranieri non possono possedere direttamente terreni in piena proprietà (freehold) in Indonesia. Tuttavia, esistono modi legali per garantire i diritti di proprietà. Ecco la tua guida completa.

## La Regola di Base

<InfoCard variant="warning" title="Restrizione Fondamentale">
**Legge indonesiana (Legge Agraria 1960):**

- Solo i cittadini indonesiani possono detenere l'**Hak Milik** (proprietà piena)
- Gli stranieri possono detenere determinati **diritti d'uso**
- Il terreno torna automaticamente allo Stato se uno straniero detiene l'Hak Milik

Questa è una legge costituzionale - non può essere aggirata legalmente.

</InfoCard>

## Struttura PT PMA

### Come Funziona

1. **Costituzione PT PMA** - Società a investimento estero
2. **Registrazione attività immobiliare** - Nella licenza commerciale
3. **Acquisizione titolo HGB** - La società detiene il titolo
4. **Controllo della società** - Proprietà indiretta

### Vantaggi

| Beneficio              | Dettagli                         |
| ---------------------- | -------------------------------- |
| Uso commerciale        | Può affittare la proprietà       |
| Proprietà multiple     | Nessun limite di una proprietà   |
| Operazioni aziendali   | Piena attività commerciale       |
| Trasferibile           | Si vendono le quote, non il bene |
| Finanziamento bancario | Più facile da ottenere           |

### Svantaggi

| Sfida                 | Dettagli                      |
| --------------------- | ----------------------------- |
| Costi di setup        | IDR 100-200M+                 |
| Compliance continua   | Reporting, tasse              |
| Requisiti di capitale | Investimento minimo           |
| Complessità           | Oneri legali e amministrativi |
| Costi di gestione     | Contabilità, licenze          |

## Accordi di Locazione (Leasehold)

### Leasing a Lungo Termine

<InfoCard variant="tip" title="Alternativa più semplice">
La **Locazione (Hak Sewa)** è spesso più semplice:

- Affitto del terreno da un proprietario indonesiano
- Termini tipici: 25-30 anni
- Possibilità di costruire con permesso
- Minore complessità rispetto alla PT PMA
- Nessun requisito di valore minimo

Molti espatriati preferiscono questa opzione per la sua semplicità.

</InfoCard>

### Struttura del Leasing

| Elemento            | Termini Tipici                   |
| ------------------- | -------------------------------- |
| Durata              | 25-30 anni                       |
| Estensione          | Spesso negoziabile               |
| Registrazione       | Accordo notarile                 |
| Diritti costruzione | Solitamente inclusi              |
| Migliorie           | Tornano al proprietario o pagate |

## E per quanto riguarda i prestanome (Nominee)?

<InfoCard variant="warning" title="Accordi Nominee">
**Nominee = un indonesiano detiene il titolo per lo straniero**

**La verità:**

- Comune ma **legalmente rischioso**
- La legge fondiaria non riconosce i prestanome
- Il prestanome può rivendicare la vera proprietà
- I tribunali potrebbero non proteggere lo straniero
- Può essere annullato se contestato

**Se usi un prestanome:**

- Usa accordi legali completi
- Comprendi di avere una protezione LIMITATA
- Considera la PT PMA per una maggiore sicurezza
  </InfoCard>

### Rischi del Nominee

| Rischio                              | Conseguenza                       |
| ------------------------------------ | --------------------------------- |
| Il prestanome rivendica la proprietà | Perdita della proprietà           |
| Decesso del prestanome               | Complicazioni ereditarie          |
| Debiti del prestanome                | La proprietà può essere pignorata |
| Divorzio del prestanome              | Il coniuge può avanzare pretese   |
| Sfida legale                         | Accordo nullo                     |

## Titolo Strata / Appartamenti

### Opzione Migliore per gli Stranieri

<InfoCard variant="note" title="Titolo Strata (Hak Milik Sarusun)">
**Gli appartamenti sono diversi!**

Gli stranieri possono detenere direttamente il titolo strata (HMSRS):

- Nessuna PT PMA necessaria
- Nessun KITAS necessario (controllare lo sviluppo specifico)
- Si applicano comunque i requisiti di valore minimo
- Processo di transazione più semplice

Molti stranieri scelgono gli appartamenti per la loro semplicità.

</InfoCard>

### Requisiti

| Requisito        | Dettagli                         |
| ---------------- | -------------------------------- |
| Valore minimo    | Varia per regione                |
| Tipo di edificio | Solo appartamenti/strata         |
| Documentazione   | Passaporto, contratto d'acquisto |
| Registrazione    | Tramite sviluppatore/BPN         |
