# Règles de Propriété Foncière en Indonesia 2026 : Guide pour les Étrangers

Les étrangers ne peuvent pas posséder directement de terrain en pleine propriété en Indonesia. Cependant, il existe des moyens légaux de garantir des droits de propriété. Voici votre guide complet.

## La Règle de Base

<InfoCard variant="warning" title="Restriction Fondamentale">
**Loi agraire indonésienne (Loi agraire de 1960) :**

- Seuls les citoyens indonésiens peuvent détenir le **Hak Milik** (pleine propriété)
- Les étrangers peuvent détenir certains **droits d'usage**
- La terre revient automatiquement à l'État si un étranger détient le Hak Milik

Il s'agit d'une loi constitutionnelle - elle ne peut être contournée légalement.

</InfoCard>

## Structure PT PMA

### Comment ça Marche

1. **Établir une PT PMA** - Société d'investissement étrangère
2. **Enregistrer l'activité immobilière** - Dans la licence commerciale
3. **Acquérir le titre HGB** - La société détient le titre
4. **Vous contrôlez la société** - Propriété indirecte

### Avantages

| Avantage                | Détails                              |
| ----------------------- | ------------------------------------ |
| Usage commercial        | Peut louer la propriété              |
| Propriétés multiples    | Aucune limite de propriété unique    |
| Opérations commerciales | Activités commerciales complètes     |
| Transférable            | Vendre des actions, pas la propriété |
| Financement bancaire    | Plus facile à obtenir                |

### Désavantages

| Défi                    | Détails                        |
| ----------------------- | ------------------------------ |
| Coût de création        | 100-200 millions d'IDR et plus |
| Conformité continue     | Rapports, taxes                |
| Exigences de capital    | Investissement minimum         |
| Complexité              | Fardeau légal et administratif |
| Coûts de fonctionnement | Comptabilité, licences         |

## Accords de Bail Emphytéotique

### Bail à Long Terme

<InfoCard variant="tip" title="Alternative Plus Simple">
Le **bail emphytéotique (Hak Sewa)** est souvent plus simple :

- Louer un terrain à un propriétaire indonésien
- Durées typiques : 25-30 ans
- Possibilité de construire avec permission
- Moins complexe qu'une PT PMA
- Aucune exigence de valeur minimale

De nombreux expatriés préfèrent cette option pour sa simplicité.

</InfoCard>

### Structure du Bail

| Élément              | Conditions Typiques                      |
| -------------------- | ---------------------------------------- |
| Durée                | 25-30 ans                                |
| Extension            | Souvent négociable                       |
| Enregistrement       | Accord notarié                           |
| Droits de construire | Généralement inclus                      |
| Améliorations        | Retournent au propriétaire ou compensées |

## Qu'en est-il des Nominees ?

<InfoCard variant="warning" title="Arrangements de Nominee">
**Nominee = un Indonésien détient le titre pour un étranger**

**La vérité :**

- Courant mais **juridiquement risqué**
- La loi foncière ne reconnaît pas les nominees
- Le nominee peut revendiquer la vraie propriété
- Les tribunaux peuvent ne pas protéger l'étranger
- Peut être annulé si contesté

**Si vous utilisez un nominee :**

- Utilisez des accords légaux complets
- Comprenez que vous avez une protection LIMITÉE
- Envisagez une PT PMA à la place pour la sécurité
  </InfoCard>

### Risques liés aux Nominees

| Risque                             | Conséquence                   |
| ---------------------------------- | ----------------------------- |
| Le nominee revendique la propriété | Peut perdre la propriété      |
| Le nominee décède                  | Complications successorales   |
| Les dettes du nominee              | La propriété peut être saisie |
| Divorce du nominee                 | Le conjoint peut revendiquer  |
| Contestation légale                | Arrangement annulé            |

## Appartement/Titre de Strata

### Meilleure Option pour les Étrangers

<InfoCard variant="note" title="Titre de Strata (Hak Milik Sarusun)">
**Les appartements sont différents !**

Les étrangers peuvent détenir directement un titre de strata (HMSRS) :

- Aucune PT PMA nécessaire
- Aucun KITAS nécessaire (vérifier le développement spécifique)
- Les exigences de valeur minimale s'appliquent toujours
- Processus de transaction plus facile

De nombreux étrangers choisissent les appartements pour leur simplicité.

</InfoCard>

### Exigences

| Exigence         | Détails                        |
| ---------------- | ------------------------------ |
| Valeur minimale  | Varie selon la région          |
| Type de bâtiment | Appartements/strata uniquement |
| Documentation    | Passeport, contrat d'achat     |
| Enregistrement   | Par le promoteur/BPN           |
