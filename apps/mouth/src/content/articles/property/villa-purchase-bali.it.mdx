# Comprare una Villa a Bali 2026: Guida per Stranieri

Possedere una villa a Bali è un sogno per molti. Ecco tutto quello che devi sapere per renderlo realtà.

## Gli Stranieri Possono Comprare?

<InfoCard variant="warning" title="La risposta in breve">
**Gli stranieri non possono possedere terreni in proprietà esclusiva (freehold) in Indonesia.**

Ma esistono modi legali per assicurarsi una proprietà:

- **Leasehold** (locazione a lungo termine)
- **Hak Pakai** (diritto d'uso - per residenza personale)
- **PT PMA** (proprietà aziendale)

Ognuno ha pro e contro: scegli in base alla tua situazione.

</InfoCard>

## Calcolatore dei Costi

<Calculator
  title="Budget per l'Acquisto della Villa"
  description="Stima i costi totali"
  fields={[
    {
      id: "price",
      label: "Prezzo della Villa (IDR)",
      type: "number",
      defaultValue: 5000000000,
      min: 0
    },
    {
      id: "structure",
      label: "Struttura di Proprietà",
      type: "select",
      options: [
        { value: "leasehold", label: "Leasehold (Leasing)" },
        { value: "hakpakai", label: "Hak Pakai" },
        { value: "ptpma", label: "PT PMA + HGB" }
      ],
      defaultValue: "leasehold"
    }
  ]}
  calculateResult={(values) => {
    const price = values.price;
    let structureCost = 0;
    let transferTax = 0;
    let notary = price * 0.01;
    let legal = 0;

    if (values.structure === "leasehold") {
      structureCost = 0;
      transferTax = 0; // Nessun BPHTB sul leasing
      legal = 30000000;
    } else if (values.structure === "hakpakai") {
      transferTax = price * 0.05; // BPHTB
      legal = 50000000;
    } else {
      structureCost = 150000000; // Costo avvio PT PMA
      transferTax = price * 0.05; // BPHTB
      legal = 75000000;
    }

    const agent = price * 0.05; // Se si usa un agente
    const misc = 20000000;

    const total = price + structureCost + transferTax + notary + legal + agent + misc;

    return {
      total: total,
      breakdown: [
        { label: "Prezzo villa", amount: price },
        { label: "Avvio struttura (se PT PMA)", amount: structureCost },
        { label: "Tassa trasferimento (BPHTB)", amount: transferTax },
        { label: "Spese notarili", amount: Math.round(notary) },
        { label: "Spese legali", amount: legal },
        { label: "Commissione agente (5%)", amount: Math.round(agent) },
        { label: "Varie", amount: misc }
      ],
      currency: "IDR",
      note: `Totale circa ~${Math.round(total / 16000).toLocaleString()} USD`
    };

}}

## Processo di Acquisto

### Passo dopo Passo

| Passo | Azione                      | Durata         |
| ----- | --------------------------- | -------------- |
| 1     | Trova la proprietà          | Settimane-mesi |
| 2     | Negozia prezzo/termini      | 1-2 settimane  |
| 3     | Due diligence               | 2-4 settimane  |
| 4     | Avvio struttura (se PT PMA) | 4-8 settimane  |
| 5     | Bozza dei contratti         | 1-2 settimane  |
| 6     | Firma e pagamento deposito  | 1 giorno       |
| 7     | Completamento trasferimento | 2-4 settimane  |
| 8     | Consegna                    | 1 giorno       |

## Errori Comuni

<InfoCard variant="warning" title="Evita questi errori">
**Errori comuni degli acquirenti:**

1. **Non fare la due diligence** - I problemi di titolo sono comuni
2. **Usare un prestanome** - Rischioso, non raccomandato
3. **Saltare la revisione legale** - Usa sempre un avvocato
4. **Pagare troppo velocemente** - Trattieni il saldo fino alla chiarezza
5. **Struttura sbagliata** - Adattala alle tue esigenze
6. **Ignorare la zonizzazione** - Potresti non essere in grado di affittare
7. **Accordi verbali** - Metti tutto per iscritto
8. **Non prevedere extra a budget** - Calcola un 10-15% in più sul prezzo
   </InfoCard>
