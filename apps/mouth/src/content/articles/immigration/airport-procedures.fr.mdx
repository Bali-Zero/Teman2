## Paiement VOA

### Au comptoir VOA

<InfoCard variant="note" title="Visa à l'arrivée">
**Avant l'immigration, payez le VOA :**

- Coût : IDR 500,000
- Paiement : Espèces (IDR, USD) ou carte
- Reçu : À conserver pour l'immigration
- Durée : 30 jours, prolongeable

Cherchez le comptoir "Visa on Arrival" avant les files d'attente de l'immigration.

</InfoCard>

### Options de paiement

| Méthode               | Accepté                        |
| --------------------- | ------------------------------ |
| Roupie indonésienne   | Oui                            |
| Dollars américains    | Oui                            |
| Carte de crédit/débit | Oui (la plupart des aéroports) |
| Autres devises        | Certaines acceptées            |

## Douanes

### Que déclarer

| Déclarer                                       | Franchise                      |
| ---------------------------------------------- | ------------------------------ |
| Argent liquide de plus de IDR 100M / USD 10K   | Doit être déclaré              |
| Cigarettes de plus de 200                      | Doit être déclaré              |
| Alcool de plus de 1 litre                      | Doit être déclaré              |
| Marchandises d'une valeur supérieure à USD 500 | Peut être soumise à des droits |

### Articles interdits

<InfoCard variant="warning" title="Ne pas apporter">
**Strictement interdit :**
- Stupéfiants/drogues (peine de mort !)
- Armes
- Pornographie
- Produits contrefaits
- Certains produits alimentaires
- Articles offensants pour la religion

Les drogues sont passibles de la **peine de mort** en Indonesia !

</InfoCard>

### Canaux

| Canal | Utiliser quand      |
| ----- | ------------------- |
| Vert  | Rien à déclarer     |
| Rouge | Articles à déclarer |

Vous pouvez toujours être contrôlé aléatoirement dans le canal vert.

## Vérification du dépassement de séjour

<InfoCard variant="warning" title="Vérifier avant le départ">
**Avant de vous rendre à l'immigration :**

- Comptez vos jours en Indonesia
- Vérifiez la date d'expiration de votre visa
- Dépassement de séjour = amende de IDR 1,000,000 par jour
- Les amendes sont payées à l'immigration de l'aéroport
- Peut retarder votre départ

Calculez attentivement pour éviter les surprises !

</InfoCard>
