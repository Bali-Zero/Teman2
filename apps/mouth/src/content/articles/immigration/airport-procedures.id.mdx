## Pembayaran VOA

### Di Kounter VOA

<InfoCard variant="note" title="Visa on Arrival">
**Sebelum imigrasi, bayar VOA:**

- Biaya: IDR 500.000
- Pembayaran: Tunai (IDR, USD) atau kartu
- Bukti: Simpan untuk imigrasi
- Masa berlaku: 30 hari, dapat diperpanjang

Cari kounter "Visa on Arrival" sebelum antrian imigrasi.

</InfoCard>

### Opsi Pembayaran

| Metode            | Diterima            |
| ----------------- | ------------------- |
| Rupiah Indonesia | Ya                 |
| Dolar AS         | Ya                 |
| Kartu Kredit/Debit | Ya (di sebagian besar bandara) |
| Mata uang lain   | Beberapa diterima  |

## Imigrasi

### Apa yang Diharapkan

| Item       | Apa yang Terjadi                       |
| ---------- | ---------------------------------- |
| Dokumen    | Tunjukkan paspor + bukti VOA/visa    |
| Pertanyaan | Mungkin ditanya tujuan, durasi, alamat |
| Biometrik  | Foto dan sidik jari                    |
| Cap        | Cap masuk di paspor                    |
| Durasi     | Bervariasi (bisa cepat atau lambat)    |

### Pertanyaan Umum yang Diajukan

| Pertanyaan          | Jawaban yang Baik                                   |
| ----------------- | --------------------------------------------- |
| Tujuan kunjungan? | Wisata / Pertemuan bisnis / Membesuk keluarga     |
| Berapa lama tinggal? | [Durasi yang direncanakan]                        |
| Tempat tinggal?   | [Nama hotel dan area]                             |
| Tiket pulang?     | [Tanggal dan maskapai]                            |
| Pekerjaan?        | [Pekerjaan/profesi Anda]                          |

<InfoCard variant="tip" title="Tips Imigrasi">
**Untuk kelancaran:**

- Bersikap sopan dan sabar
- Jawab jujur
- Siapkan alamat akomodasi
- Tahu tanggal keberangkatan
- Jangan bercanda tentang hal ilegal
- Berpakaian wajar
</InfoCard>

## Bea Cukai

### Apa yang Harus Dilaporkan

| Laporkan                      | Batas       |
| ---------------------------- | ----------- |
| Uang tunai > IDR 100M / USD 10K | Harus dilaporkan    |
| Rokok > 200 batang           | Harus dilaporkan    |
| Alkohol > 1 liter            | Harus dilaporkan    |
| Barang > USD 500 nilai       | Mungkin dikenai bea |

### Barang Dilarang

<InfoCard variant="warning" title="Jangan Membawa">
**Dilarang keras:**
- Narkotika/obat-obatan (hukuman mati!)
- Senjata
- Porno
- Barang palsu
- Produk makanan tertentu
- Barang yang menyinggung agama

Narkotika membawa **hukuman mati** di Indonesia!

</InfoCard>

### Saluran

| Saluran | Gunakan Saat           |
| ------- | ------------------ |
| Hijau   | Tidak ada yang dilaporkan |
| Merah   | Ada barang yang dilaporkan   |

Anda masih bisa diperiksa secara acak di saluran hijau.

## Pemeriksaan Keterlambatan

<InfoCard variant="warning" title="Periksa Sebelum Keberangkatan">
**Sebelum ke imigrasi:**

- Hitung hari Anda di Indonesia
- Periksa tanggal kedaluwarsa visa
- Keterlambatan = denda IDR 1.000.000 per hari
- Denda dibayar di imigrasi bandara
- Dapat menghambat keberangkatan Anda

Hitung dengan cermat untuk menghindari kejutan!

</InfoCard>
