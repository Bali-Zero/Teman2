## Pembayaran VOA

### Di Kasir VOA

<InfoCard variant="note" title="Visa on Arrival">
**Sebelum imigrasi, bayar untuk VOA:**

- Biaya: IDR 500.000
- Pembayaran: Tunai (IDR, USD) atau kartu
- Kwitansi: Simpan untuk imigrasi
- Durasi: 30 hari, dapat diperpanjang

Cari kasir "Visa on Arrival" sebelum antrian imigrasi.

</InfoCard>

### Opsi Pembayaran

| Metode            | Diterima            |
| ----------------- | ------------------- |
| Rupiah Indonesia  | Ya                  |
| Dolar Amerika     | Ya                  |
| Kartu Kredit/Debit | Ya (di sebagian besar bandara) |
| Mata uang lain    | Sebagian diterima   |

## Imigrasi

### Yang Perlu Diharapkan

| Item       | Yang Terjadi                       |
| ---------- | ---------------------------------- |
| Dokumen    | Tunjukkan paspor + bukti/visa VOA  |
| Pertanyaan | Mungkin ditanyakan tujuan, durasi, alamat |
| Biometrik  | Foto dan sidik jari               |
| Stempel    | Stempel masuk di paspor           |
| Durasi     | Bervariasi (bisa cepat atau lambat)      |

### Pertanyaan Umum yang Ditanyakan

| Pertanyaan          | Jawaban Baik                                   |
| ----------------- | --------------------------------------------- |
| Tujuan kunjungan? | Wisata / Rapat bisnis / Mengunjungi keluarga |
| Berapa lama tinggal? | [Durasi rencana Anda]                |
| Di mana menginap?    | [Nama hotel dan area]                         |
| Penerbangan pulang?    | [Tanggal dan maskapai]                            |
| Pekerjaan?       | [Pekerjaan/profesi Anda]                         |

<InfoCard variant="tip" title="Tips Imigrasi">
**Untuk perjalanan yang lancar:**

- Bersikap sopan dan sabar
- Jawab dengan jujur
- Siapkan alamat akomodasi
- Tahu tanggal penerbangan pulang Anda
- Jangan bercanda tentang hal-hal ilegal
- Berpakaian wajar
</InfoCard>

## Pabean

### Yang Perlu Dideklarasikan

| Dideklarasikan                      | Kuota       |
| ---------------------------- | --------------- |
| Tunai di atas IDR 100M / USD 10K | Harus dideklarasikan    |
| Rokok di atas 200             | Harus dideklarasikan    |
| Alkohol di atas 1 liter         | Harus dideklarasikan    |
| Barang dengan nilai di atas USD 500     | Mungkin kena bea   |

### Barang Terlarang

<InfoCard variant="warning" title="Jangan Dibawa">
**Dilarang keras:**
- Narkotika/obat-obatan (hukuman mati!)
- Senjata
- Pornografi
- Barang palsu
- Produk makanan tertentu
- Barang yang menyinggung agama

Narkoba membawa **hukuman mati** di Indonesia!

</InfoCard>

### Saluran

| Saluran | Gunakan Saat           |
| ------- | ------------------ |
| Hijau   | Tidak ada barang untuk dideklarasikan |
| Merah   | Ada barang untuk dideklarasikan   |

Anda masih mungkin diperiksa secara acak di saluran hijau.

## Cek Keterlambatan Visa

<InfoCard variant="warning" title="Cek Sebelum Keberangkatan">
**Sebelum pergi ke imigrasi:**

- Hitung hari Anda di Indonesia
- Cek tanggal kedaluwarsa visa
- Keterlambatan = denda IDR 1.000.000 per hari
- Denda dibayar di imigrasi bandara
- Dapat menunda keberangkatan Anda

Hitung dengan hati-hati untuk menghindari kejutan!

</InfoCard>

### Dari Bandara Bali
