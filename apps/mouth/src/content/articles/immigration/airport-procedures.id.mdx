## Pembayaran VOA

### Di Konter VOA

<InfoCard variant="note" title="Visa Kedatangan">
**Sebelum imigrasi, bayar untuk VOA:**

- Biaya: IDR 500.000
- Pembayaran: Tunai (IDR, USD) atau kartu
- Struk: Simpan untuk imigrasi
- Durasi: 30 hari, dapat diperpanjang

Cari "Visa on Arrival" sebelum antrean imigrasi.

</InfoCard>

### Pilihan Pembayaran

| Metode             | Diterima                       |
| ------------------ | ------------------------------ |
| Rupiah Indonesia   | Ya                             |
| Dolar AS           | Ya                             |
| Kartu Kredit/Debit | Ya (di sebagian besar bandara) |
| Mata uang lain     | Beberapa diterima              |

## Imigrasi

### Apa yang Diharapkan

| Item       | Apa yang Terjadi                       |
| ---------- | -------------------------------------- |
| Dokumen    | Tunjukkan paspor + struk VOA/visa      |
| Pertanyaan | Mungkin ditanya tujuan, durasi, alamat |
| Biometrik  | Foto dan sidik jari                    |
| Stempel    | Stempel masuk di paspor                |
| Durasi     | Bervariasi (bisa cepat atau lambat)    |

### Pertanyaan yang Sering Diajukan

| Pertanyaan            | Jawaban yang Baik                                 |
| --------------------- | ------------------------------------------------- |
| Apa tujuan kunjungan? | Turisme / Pertemuan bisnis / Mengunjungi keluarga |
| Berapa lama tinggal?  | [Durasi rencana Anda yang sebenarnya]             |
| Di mana menginap?     | [Nama hotel dan area]                             |
| Tiket kembali?        | [Tanggal dan maskapai penerbangan]                |
| Pekerjaan?            | [Pekerjaan/profesi Anda]                          |

<InfoCard variant="tip" title="Tips Imigrasi">
**Untuk kelancaran perjalanan:**

- Bersikap sopan dan sabar
- Jawab dengan jujur
- Siapkan alamat akomodasi
- Ketahui tanggal kembali
- Jangan bercanda tentang hal-hal ilegal
- Berpakaian sopan

## Bea Cukai

### Apa yang Harus Dilaporkan

| Laporkan                                        | Batas                 |
| ----------------------------------------------- | --------------------- |
| Uang tunai lebih dari IDR 100 juta / USD 10.000 | Harus dilaporkan      |
| Rokok lebih dari 200                            | Harus dilaporkan      |
| Alkohol lebih dari 1 liter                      | Harus dilaporkan      |
| Barang dengan nilai lebih dari USD 500          | Mungkin dikenakan bea |

### Barang yang Dilarang

<InfoCard variant="warning" title="Jangan Dibawa">
**Sangat dilarang:**
- Narkotika/obat-obatan (hukuman mati!)
- Senjata
- Pornografi
- Barang palsu
- Produk makanan tertentu
- Barang yang menyinggung agama

Narkoba dapat membawa **hukuman mati** di Indonesia!

</InfoCard>

### Jalur

| Jalur | Gunakan Jika                    |
| ----- | ------------------------------- |
| Hijau | Tidak ada yang perlu dilaporkan |
| Merah | Barang perlu dilaporkan         |

Anda mungkin masih diperiksa secara acak di jalur hijau.

## Pengecekan Overstay

<InfoCard variant="warning" title="Periksa Sebelum Keberangkatan">
**Sebelum menuju imigrasi:**

- Hitung hari Anda di Indonesia
- Periksa tanggal kedaluwarsa visa
- Overstay = denda IDR 1.000.000 per hari
- Denda dibayarkan di imigrasi bandara
- Dapat menunda keberangkatan Anda

Hitung dengan cermat untuk menghindari kejutan!

</InfoCard>
