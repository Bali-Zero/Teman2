## MERP (Permis de Sortie-Réentrée Multiples)

### Qu'est-ce que le MERP ?

<InfoCard variant="note" title="Choix le plus courant">
**Le MERP permet :**

- Sorties et entrées illimitées
- Valide pour la durée du KITAS
- Pas besoin de demander à chaque voyage
- Le plus pratique pour les voyageurs d'affaires

La plupart des détenteurs de KITAS obtiennent le MERP dès le début.

</InfoCard>

### Détails du MERP

| Caractéristique   | Détails                                  |
| ----------------- | ---------------------------------------- |
| Validité          | Identique à la validité du KITAS         |
| Voyages autorisés | Illimités                                |
| Demande           | Généralement avec le traitement du KITAS |
| Coût              | 1 à 1,5 million IDR généralement         |
| Traitement        | 3 à 5 jours ouvrables                    |

## SERP (Permis de Sortie-Réentrée Unique)

### Quand l'utiliser ?

| Cas d'utilisation  | Le SERP est pertinent                     |
| ------------------ | ----------------------------------------- |
| Un voyage prévu    | Validité KITAS courte                     |
| Soucieux du budget | Économise de l'argent par rapport au MERP |
| Voyages rares      | Ne voyage pas souvent                     |

### Limitations du SERP

<InfoCard variant="warning" title="Un seul voyage">
**Le SERP n'autorise qu'UNE SEULE sortie et réentrée :**

- Utilisé après un seul voyage
- Doit être demandé à nouveau pour le prochain voyage
- Moins pratique que le MERP
- Envisagez le MERP si vous êtes susceptible de voyager davantage

Si vous êtes susceptible de voyager plusieurs fois, le MERP offre un meilleur rapport qualité-prix.

</InfoCard>

---

## EPO (Permis de Sortie Uniquement)

### Qu'est-ce que l'EPO ?

| Objectif         | Détails                                |
| ---------------- | -------------------------------------- |
| Départ définitif | Quitter Indonesia de façon permanente  |
| Annulation KITAS | Accompagne généralement l'annulation   |
| Pas de retour    | Ne peut pas rentrer avec le même KITAS |

### Quand l'EPO est requis

<InfoCard variant="warning" title="Sortie permanente">
**L'EPO est nécessaire lorsque :**

- Vous mettez fin à votre emploi en Indonesia
- Vous ne renouvelez pas votre KITAS
- Vous changez de type de visa
- Vous quittez Indonesia de façon permanente

L'EPO annule effectivement votre KITAS.

</InfoCard>

### Processus EPO

| Étape | Action                             |
| ----- | ---------------------------------- |
| 1     | Soumettre le KITAS pour annulation |
| 2     | Demander un EPO                    |
| 3     | Payer les frais                    |
| 4     | Recevoir l'EPO                     |
| 5     | Doit partir dans les 7 jours       |

## Considérations pratiques

### Avant de voyager

| Vérifier                         | Action                                |
| -------------------------------- | ------------------------------------- |
| Validité MERP                    | S'assurer qu'il est toujours valide   |
| Validité KITAS                   | Doit couvrir la période de voyage     |
| Validité passeport               | Généralement 6 mois et plus           |
| Retour dans les délais du permis | Ne pas dépasser la durée à l'étranger |

### À l'immigration

| Départ                  | Retour                 |
| ----------------------- | ---------------------- |
| Montrer le passeport    | Montrer le passeport   |
| KITAS scanné            | KITAS scanné           |
| MERP vérifié            | MERP vérifié           |
| Tampon de sortie apposé | Tampon d'entrée apposé |

### Problèmes courants

| Problème                  | Solution                            |
| ------------------------- | ----------------------------------- |

| KITAS perdu à l'étranger  | Contacter l'ambassade immédiatement |
| KITAS expiré à l'étranger | Contacter l'immigration/l'agent     |

## Détenteurs de KITAP

<InfoCard variant="note" title="KITAP différent">
**Détenteurs de KITAP :**

- Le MERP est généralement inclus automatiquement
- Validité plus longue (5 ans)
- Moins de démarches administratives
- Même liberté de voyager

Le KITAP est plus pratique pour les voyageurs fréquents.

</InfoCard>

## Conseils de voyage

### Pour les détenteurs de KITAS

| Astuce                  | Pourquoi                        |
| ----------------------- | ------------------------------- |
| Obtenir le MERP tôt     | Ne pas attendre le voyage       |
| Garder des copies       | Passeport, KITAS, MERP          |
| Suivre la validité      | Définir des rappels calendaires |
| Utiliser un agent       | Pour les renouvellements        |
| Connaître votre sponsor | Peut nécessiter son approbation |

### Situations d'urgence

| Situation                    | Action                                   |
| ---------------------------- | ---------------------------------------- |
| Passeport perdu à l'étranger | Ambassade d'Indonesia                    |
| KITAS expiré à l'étranger    | Contacter le sponsor/l'agent             |
| Urgence médicale             | Assistance de l'ambassade                |
| Urgence familiale            | Peut voyager, régler le permis plus tard |
