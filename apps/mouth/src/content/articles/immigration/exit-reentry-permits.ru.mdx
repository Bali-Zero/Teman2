## MERP (Разрешение на многократный выезд и повторный въезд)

### Что такое MERP?

<InfoCard variant="note" title="Самый частый выбор">
**MERP позволяет:**

- Неограниченное количество выездов и въездов
- Действителен в течение срока действия KITAS
- Не нужно подавать заявление для каждой поездки
- Наиболее удобен для деловых путешественников

Большинство владельцев KITAS получают MERP с самого начала.

</InfoCard>

### Детали MERP

| Характеристика                | Детали                            |
| ----------------------------- | --------------------------------- |
| Срок действия                 | Такой же, как срок действия KITAS |
| Допустимое количество поездок | Неограниченно                     |
| Подача заявления              | Обычно вместе с оформлением KITAS |
| Стоимость                     | Обычно 1-1.5 млн IDR              |
| Обработка                     | 3-5 рабочих дней                  |

## SERP (Разрешение на однократный выезд и повторный въезд)

### Когда использовать

| Случай использования         | SERP имеет смысл                   |
| ---------------------------- | ---------------------------------- |
| Одна запланированная поездка | Короткий срок действия KITAS       |
| Ограниченный бюджет          | Экономия денег по сравнению с MERP |
| Редкие поездки               | Не часто путешествуете             |

### Ограничения SERP

<InfoCard variant="warning" title="Только одна поездка">
**SERP разрешает только ОДИН выезд и повторный въезд:**

- Используется после одной поездки
- Необходимо подавать заявление снова для следующей поездки
- Менее удобно, чем MERP
- Рассмотрите MERP, если вы можете путешествовать чаще

Если вы, вероятно, будете путешествовать несколько раз, MERP является более выгодным.

</InfoCard>

---

## EPO (Разрешение только на выезд)

### Что такое EPO?

| Цель                 | Детали                                       |
| -------------------- | -------------------------------------------- |
| Окончательный отъезд | Окончательный отъезд из Indonesia            |
| Аннулирование KITAS  | Обычно сопутствует аннулированию             |
| Без возвращения      | Невозможно повторно въехать по тому же KITAS |

### Когда требуется EPO

<InfoCard variant="warning" title="Постоянный отъезд">
**EPO требуется, когда:**

- Завершается трудоустройство в Indonesia
- Не продлевается KITAS
- Меняется тип визы
- Окончательно покидается Indonesia

EPO фактически аннулирует ваш KITAS.

</InfoCard>

### Процесс EPO

| Шаг | Действие                        |
| --- | ------------------------------- |
| 1   | Подать KITAS на аннулирование   |
| 2   | Подать заявление на EPO         |
| 3   | Оплатить сборы                  |
| 4   | Получить EPO                    |
| 5   | Должен выехать в течение 7 дней |

## Практические соображения

### Перед поездкой

| Проверка                        | Действие                                  |
| ------------------------------- | ----------------------------------------- |
| Срок действия MERP              | Убедитесь, что он еще действителен        |
| Срок действия KITAS             | Должен покрывать период поездки           |
| Срок действия паспорта          | Обычно 6+ месяцев                         |
| Возвращение в рамках разрешения | Не превышайте срок пребывания за границей |

### На иммиграционном контроле

| Выезд                   | Возвращение             |
| ----------------------- | ----------------------- |
| Предъявите паспорт      | Предъявите паспорт      |
| KITAS сканируется       | KITAS сканируется       |
| MERP проверяется        | MERP проверяется        |
| Ставится штамп о выезде | Ставится штамп о въезде |

### Распространенные проблемы

| Проблема                                      | Решение                                    |
| --------------------------------------------- | ------------------------------------------ |
| Нет MERP                                      | Подайте заявление до поездки               |
| Срок действия MERP истек                      | Продлите или получите SERP                 |
| KITAS утерян за границей                      | Немедленно свяжитесь с посольством         |
| Превышен срок пребывания по KITAS за границей | Свяжитесь с иммиграционной службой/агентом |

## Владельцы KITAP

<InfoCard variant="note" title="KITAP отличается">
**Владельцы KITAP:**

- MERP обычно включается автоматически
- Более длительный срок действия (5 лет)
- Меньше административной нагрузки
- Та же свобода передвижения

KITAP более удобен для часто путешествующих.

</InfoCard>
