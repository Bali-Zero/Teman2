# Guichets d'Immigration dans les Malls de Bali : La Fin des Files d'Attente ?

---

## ⚡ LE BREF DE 30 SECONDES

> **Dois-je m'inquiéter ?** Non, c'est une bonne nouvelle

- 🎯 **Quoi :** Guichets d'immigration dans les centres commerciaux pour les renouvellements et services de base
- 👤 **Qui est concerné :** Titulaires de KITAS/KITAP, voyageurs fréquents
- 📅 **Quand :** Prévu pour le S2 2026
- ⚠️ **Opportunité :** ÉLEVÉE — Horaires étendus, plus de matinées perdues

---

## 📋 LES FAITS

Le gouvernement provincial de Bali a annoncé l'ouverture de **Immigration Lounge** dans les centres commerciaux dans le cadre du programme de modernisation des services.

**Services confirmés :**

| Service                             | Disponibilité |
| ----------------------------------- | ------------- |
| Renouvellement KITAS/KITAP          | ✅ Confirmé   |
| Permis de sortie-rentrée (EPO/MERP) | ✅ Confirmé   |
| Capture biométrique                 | ✅ Confirmé   |
| Retrait de documents                | ✅ Confirmé   |
| Informations générales              | ✅ Confirmé   |

**NON disponibles (probablement) :**

| Service                                  | Raison                             |
| ---------------------------------------- | ---------------------------------- |
| Nouvelles demandes de visa               | Nécessite le bureau principal      |
| Cas de déportation/dépassement de séjour | Nécessite des officiers supérieurs |
| Cas complexes                            | Compétence du siège central        |
| Recours                                  | Procédure formelle                 |

**Lieux probables :**

| Centre Commercial | Zone     | Probabilité                   |
| ----------------- | -------- | ----------------------------- |
| Beachwalk         | Kuta     | Élevée (trafic touristique)   |
| Mall Bali Galeria | Kuta     | Élevée (structure consolidée) |
| Lippo Mall Kuta   | Tuban    | Élevée (près de l'aéroport)   |
| Trans Studio Mall | Denpasar | Moyenne                       |
| Level 21          | Denpasar | Moyenne                       |

**Horaires prévus :**

- Centre commercial : 10:00 - 20:00 (vs Kantor Imigrasi : 08:00 - 15:00)
- Jours : Lun-Sam (certains pourraient inclure Dim)

---

## 🧠 L'ANALYSE DE BALI ZERO

**Ce que les journaux ne disent pas :**

Cette initiative est née de la nécessité, pas de la générosité. Avec environ 200 000 titulaires de KITAS/KITAP actifs et des millions d'arrivées touristiques, les bureaux d'immigration traditionnels sont au bord de l'effondrement.

Le modèle a déjà été testé à Jakarta (Mal Kelapa Gading, Grand Indonesia) avec des résultats positifs. Bali ne fait que le reproduire.

**Notre conseil :**

Ne modifiez pas vos plans de renouvellement en attendant cette nouveauté. Le lancement est prévu pour le second semestre 2026, et les premiers mois seront probablement chaotiques (voir : chaque lancement informatique indonésien jamais réalisé).

Chez Bali Zero, nous testerons le service dès qu'il sera disponible et mettrons à jour ce guide.

## 🚀 PROCHAINES ÉTAPES

### Si vous avez un renouvellement de KITAS imminent :

1. ✅ Procédez normalement — n'attendez pas les centres commerciaux
2. 📋 Les délais ne changent pas, seule la commodité changera
3. 🔔 Surveillez les annonces officielles pour les dates exactes

### Si vous voyagez fréquemment :

1. ✅ L'EPO/MERP dans les centres commerciaux sera pratique
2. 📋 Système de réservation en ligne prévu (probablement M-Paspor)
3. 🔔 Suivez les mises à jour pour comprendre comment réserver

### Pour tous :

1. ✅ Aucune action requise pour le moment
