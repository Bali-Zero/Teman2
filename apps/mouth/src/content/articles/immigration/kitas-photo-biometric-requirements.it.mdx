## Perché le specifiche delle foto per il KITAS sono importanti

I requisiti fotografici per l'immigrazione in Indonesia non sono semplici formalità burocratiche. Servono a due scopi fondamentali:

1. **Abbinamento biometrico** - La tua foto viene confrontata con i database di riconoscimento facciale ai posti di blocco dell'immigrazione, negli aeroporti e durante i controlli casuali.
2. **Integrità dei documenti** - La tua tessera KITAS, i registri dell'immigrazione e i file dello sponsor utilizzano tutti la stessa foto per la verifica dell'identità.

L'invio di foto che non soddisfano le specifiche è uno dei motivi più comuni di ritardo nelle domande di KITAS. Farlo bene la prima volta fa risparmiare giorni o settimane di tempo di elaborazione.

## Specifiche fisiche della foto

### Dimensioni richieste

L'immigrazione indonesiana richiede foto in più formati per scopi diversi:

| Formato | Scopo                                  | Quantità solitamente necessaria |
| ------- | -------------------------------------- | ------------------------------- |
| 4x6 cm  | Tessera KITAS, domande di immigrazione | 8-12 stampe                     |
| 3x4 cm  | Documenti di supporto, Wajib Lapor     | 4-6 stampe                      |
| 2x3 cm  | Moduli aggiuntivi (meno comuni)        | 2-4 stampe                      |

**Prepara sempre più foto di quante pensi te ne servano.** Gli uffici immigrazione, il Dukcapil, la polizia e le banche richiedono foto in vari momenti. Avere una scorta di oltre 20 foto per ogni formato evita viaggi ripetuti allo studio fotografico.

### Requisiti del colore di sfondo

| Sfondo             | Utilizzato per                                                                           |
| ------------------ | ---------------------------------------------------------------------------------------- |
| **Rosso (merah)**  | Tessera KITAS, domanda di ITAS, Wajib Lapor, la maggior parte dei moduli di immigrazione |
| **Blu (biru)**     | Alcuni moduli di immigrazione, domande in stile passaporto, alcuni documenti consolari   |
| **Bianco (putih)** | Alcune domande di passaporto presso le ambasciate (specifico per paese)                  |

**Raccomandazione:** Scatta foto con sfondo sia rosso che blu. La maggior parte degli studi fotografici in Indonesia può cambiare lo sfondo digitalmente, quindi chiedi entrambe le versioni.

### Requisiti del viso e della composizione

| Specifica                   | Requisito                               |
| --------------------------- | --------------------------------------- |
| Copertura del viso          | 70-80% dell'altezza dell'inquadratura   |
| Posizione della testa       | Diritta, rivolta verso la fotocamera    |
| Espressione                 | Neutra (non sorridere, non accigliarsi) |
| Occhi                       | Aperti, guardando la fotocamera         |
| Bocca                       | Chiusa                                  |
| Orecchie                    | Visibili (entrambe, se possibile)       |
| Capelli                     | Non devono coprire il viso o gli occhi  |
| Dal mento alla sommità capo | Completamente visibile nel fotogramma   |

### Cosa indossare

| Articolo                                      | Ammesso?    | Note                                                  |
| --------------------------------------------- | ----------- | ----------------------------------------------------- |
| Abbigliamento formale/smart casual            | Sì          | Preferibile camicia con colletto                      |
| T-shirt                                       | Accettabile | Non ideale ma non rifiutata                           |
| Copricapo religioso (hijab, turbante, kippah) | Sì          | Il viso deve rimanere completamente visibile          |
| Cappello o berretto                           | No          | Salvo requisiti religiosi                             |
| Occhiali (da vista o da sole)                 | No          | Devono essere rimossi per la foto                     |
| Gioielli vistosi                              | Evitare     | Possono causare riflessi o ostruire il viso           |
| Uniforme                                      | Accettabile | Alcuni preferiscono evitare uniformi militari/polizia |

### Standard di qualità tecnica

| Parametro         | Requisito                                    |
| ----------------- | -------------------------------------------- |
| Messa a fuoco     | Nitida, chiara sul viso                      |
| Illuminazione     | Uniforme, senza ombre forti sul viso         |
| Esposizione       | Corretta (né troppo chiara né troppo scura)  |
| Colore            | Toni della pelle naturali, nessuna dominante |
| Qualità di stampa | Alta risoluzione su carta fotografica        |
| Tipo di carta     | Carta fotografica lucida o semilucida        |
| Bordi             | Taglio netto, senza pieghe o curvature       |

## Specifiche per il caricamento digitale della foto

Per le domande online tramite il sistema dell'immigrazione (app M-Paspor, domande KITAS online), le foto digitali devono soddisfare requisiti tecnici specifici:

### Specifiche del file digitale

| Parametro           | Requisito                                        |
| ------------------- | ------------------------------------------------ |
| Formato file        | JPEG (.jpg)                                      |
| Dimensione file     | 100 KB - 500 KB (varia in base alla piattaforma) |
| Risoluzione         | Minimo 300 DPI                                   |
| Dimensioni in pixel | 400 x 600 pixel (minimo)                         |
| Spazio colore       | sRGB                                             |
| Sfondo              | Rosso o blu a tinta unita (senza sfumature)      |

### Errori comuni nel caricamento digitale

| Errore                   | Causa                                      | Soluzione                                    |
| ------------------------ | ------------------------------------------ | -------------------------------------------- |
| "File too large"         | La foto supera i KB massimi                | Comprimi senza perdere qualità               |
| "File too small"         | Foto a bassa risoluzione                   | Riscansiona o riscattala ad alta risoluzione |
| "Invalid format"         | Tipo di file errato (PNG, PDF)             | Converti in JPEG                             |
| "Face not detected"      | Scarsa illuminazione o viso troppo piccolo | Riscattala con l'inquadratura corretta       |
| "Background not uniform" | Ombre o sfumature nello sfondo             | Usa uno sfondo a tinta unita                 |

### Consigli per le foto digitali

1. **Scansiona le foto fisiche** a 300+ DPI se non hai il file digitale.
2. **Usa uno scanner fotografico dedicato** invece della fotocamera del telefono per scansionare le stampe.
3. **Controlla la dimensione del file** prima del caricamento - regola la compressione se necessario.
4. **Mantieni le proporzioni** - non allungare o schiacciare l'immagine.
5. **Fai un caricamento di prova** prima dell'invio finale per individuare tempestivamente eventuali errori.

## Registrazione biometrica presso l'ufficio immigrazione

Oltre alle foto, i richiedenti del KITAS devono sottoporsi alla registrazione biometrica presso l'ufficio immigrazione. Si tratta di un processo obbligatorio da svolgere di persona.

### Cosa succede durante la registrazione biometrica

| Passo | Procedura                                            | Durata      |
| ----- | ---------------------------------------------------- | ----------- |
| 1     | Verifica dell'identità (passaporto + domanda)        | 5 minuti    |
| 2     | Acquisizione foto del viso (fotocamera immigrazione) | 2 minuti    |
| 3     | Scansione impronte digitali (tutte le 10 dita)       | 5-10 minuti |
| 4     | Acquisizione firma (pad digitale)                    | 1 minuto    |
| 5     | Verifica e conferma                                  | 2 minuti    |

**Tempo totale:** 15-25 minuti a persona

### Consigli per la registrazione biometrica

- **Le dita devono essere pulite e asciutte** - lavati e asciugati bene le mani prima di arrivare.
- **Nessun taglio o benda sui polpastrelli** - possono impedire una scansione accurata.
- **Rimuovi gli anelli** prima della scansione delle impronte.
- **Segui precisamente le istruzioni dell'ufficiale** per il posizionamento delle dita.
- **Se un dito non viene scansionato** (cicatrice, pelle secca), l'ufficiale potrebbe usare della crema idratante o riprovare più volte.

### Quando è richiesta la registrazione biometrica

| Situazione                           | Registrazione biometrica richiesta? |
| ------------------------------------ | ----------------------------------- |
| Nuova domanda di KITAS               | Sì (registrazione completa)         |
| Rinnovo/Estensione KITAS             | Sì (nuova foto + impronte)          |
| Trasferimento KITAS (cambio sponsor) | Sì                                  |
| Conversione KITAS (cambio tipo)      | Sì                                  |
| Solo cambio di indirizzo             | No (solo aggiornamento sistema)     |
| Sostituzione tessera KITAS persa     | Sì                                  |

## Requisiti della nuova foto al rinnovo del KITAS

Ogni volta che rinnovi il tuo KITAS, sono richieste nuove foto. Ecco cosa cambia al rinnovo:

### Nuove foto necessarie

- Nuovo set di foto 4x6 cm (sfondo rosso)
- Nuovo set di foto 3x4 cm
- Le foto devono essere scattate entro 6 mesi dalla domanda di rinnovo
- Nuovo file digitale per l'invio online (se applicabile)

### Nuova acquisizione biometrica

- Nuova foto del viso presso l'ufficio immigrazione
- Nuova scansione delle impronte digitali (tutte le 10 dita)
- Questo avviene durante l'appuntamento per la registrazione biometrica

### Perché sono richieste nuove foto

1. **Cambiamenti estetici** - Il tuo aspetto può cambiare nell'arco di 1-2 anni.
2. **Aggiornamento del database biometrico** - L'immigrazione aggiorna il proprio database di riconoscimento facciale.
3. **Prevenzione delle frodi** - Le foto recenti impediscono l'uso di immagini obsolete o alterate.
4. **Produzione della tessera** - La nuova tessera KITAS viene stampata con la nuova foto.

## Motivi comuni di rifiuto della foto

In base ai frequenti feedback degli uffici immigrazione, questi sono i motivi più comuni di rifiuto delle foto:

### I 10 principali motivi di rifiuto

| Pos. | Motivo                                                 | Frequenza    |
| ---- | ------------------------------------------------------ | ------------ |
| 1    | Uso di occhiali                                        | Molto comune |
| 2    | Colore dello sfondo errato                             | Comune       |
| 3    | Foto troppo vecchia (più di 6 mesi)                    | Comune       |
| 4    | Sorriso o cambio di espressione                        | Comune       |
| 5    | Viso troppo piccolo nell'inquadratura                  | Moderata     |
| 6    | Ombre sul viso                                         | Moderata     |
| 7    | Testa inclinata o girata                               | Moderata     |
| 8    | Capelli che coprono gli occhi o il viso                | Occasionale  |
| 9    | Scarsa qualità di stampa (inkjet invece di carta foto) | Occasionale  |
| 10   | Formato errato (3x4 invece di 4x6 o viceversa)         | Occasionale  |

### Come evitare i rifiuti

1. **Rivolgiti a uno studio fotografico professionale** - Non un selfie col telefono o una stampante domestica.
2. **Dì al fotografo "foto per immigrazione"** (foto per imigrasi) - Conoscono le specifiche.
3. **Rimuovi gli occhiali prima dello scatto** - Anche quelli da vista con lenti trasparenti.
4. **Indossa una camicia con colletto** se hai un abbigliamento casual.
5. **Richiedi sfondi sia rossi che blu** in un'unica sessione.
6. **Chiedi i file digitali** oltre alle stampe.
7. **Ordina stampe extra** (almeno 20 per formato).
8. **Controlla tu stesso le foto** prima di lasciare lo studio.

## Dove scattare le foto per il KITAS a Bali

### Studi fotografici professionali

La maggior parte degli studi fotografici vicino agli uffici immigrazione è esperta nelle specifiche per il KITAS:

- Diversi studi lungo Jalan Bypass Ngurah Rai
- Studi all'interno dell'area dell'aeroporto Ngurah Rai

### Checklist per lo studio fotografico

Prima di lasciare lo studio, verifica che:

- [ ] Le foto siano del formato corretto (4x6 cm)
- [ ] Lo sfondo sia del colore giusto (rosso per il KITAS)
- [ ] Non siano visibili occhiali
- [ ] Il viso sia correttamente centrato e delle dimensioni giuste
- [ ] L'espressione sia neutra
- [ ] La qualità di stampa sia nitida e chiara
- [ ] Siano stati ricevuti i file digitali (formato JPEG)
- [ ] La quantità ordinata sia sufficiente

## Conservazione e gestione delle foto per l'immigrazione

### Conservazione fisica

- Conserva le foto in una busta pulita e asciutta.
- Tienile lontane da calore e umidità (importante nel clima di Bali).
- Etichetta la busta con la data dello scatto.
- Non piegare, spillare o usare graffette sulle foto.

### Conservazione digitale

- Salva i file digitali in una cartella dedicata.
- Fai il backup su cloud (Google Drive, iCloud, Dropbox).
- Nomina i file chiaramente: `KITAS_foto_rosso_4x6_2026-02.jpg`.
- Conserva più copie su diversi dispositivi.
- Questi file digitali possono essere ristampati se necessario.
