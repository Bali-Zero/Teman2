# Стоимость разрешения на работу в Индонезии 2026: Полный анализ сборов

Получение разрешения на работу в Индонезии включает в себя множество сборов. Вот точная сумма, которую вы (или ваш работодатель) заплатите.

## Калькулятор стоимости

<Calculator
  title="Оценка стоимости разрешения на работу"
  description="Рассчитать общую стоимость разрешения на работу"
  fields={[
    {
      id: "duration",
      label: "Срок действия разрешения",
      type: "select",
      options: [
        { value: "6", label: "6 месяцев" },
        { value: "12", label: "12 месяцев (1 год)" },
        { value: "24", label: "24 месяца (2 года)" }
      ],
      defaultValue: "12"
    },
    {
      id: "useAgent",
      label: "Используете иммиграционного агента?",
      type: "checkbox",
      defaultValue: true
    },
    {
      id: "newCompany",
      label: "Новая компания (первый иностранный работник)?",
      type: "checkbox",
      defaultValue: false
    }
  ]}
  calculateResult={(values) => {
    const months = Number(values.duration);

    // Government fees
    const dkpTka = months * 100; // USD 100/month
    const kitasFee = 2000000; // IDR
    const vitasFee = 1500000; // IDR
    const stm = 200000; // IDR
    const biometrics = 100000; // IDR

    // Agent fees (typical range)
    const agentBase = values.useAgent ? 15000000 : 0; // IDR
    const agentPremium = values.newCompany ? 5000000 : 0; // IDR

    // Convert to IDR (approx rate)
    const dkpTkaIdr = dkpTka * 16000;

    // Totals
    const govtTotal = kitasFee + vitasFee + stm + biometrics + dkpTkaIdr;
    const agentTotal = agentBase + agentPremium;
    const grandTotal = govtTotal + agentTotal;

    return {
      total: grandTotal,
      breakdown: [
        { label: `DKP-TKA (${months} месяцев)`, amount: dkpTkaIdr },
        { label: "Плата за KITAS", amount: kitasFee },
        { label: "Плата за VITAS", amount: vitasFee },
        { label: "STM + Биометрия", amount: stm + biometrics },
        { label: "Плата за услуги агента", amount: agentBase },
        { label: "Надбавка для новой компании", amount: agentPremium }
      ],
      currency: "IDR",
      note: `Эквивалент в USD: ~${Math.round(grandTotal / 16000)}$`
    };

}}

### 2. Сборы агентов/за обработку

Большинство компаний пользуются услугами иммиграционных агентов. Типичные сборы:

| Услуга                 | Диапазон стоимости (IDR) | Примечания                           |
| ---------------------- | ------------------------ | ------------------------------------ |
| Полная обработка KITAS | 15-25 миллионов          | Все включено                         |
| Только RPTKA           | 5-8 миллионов            | Если оформляете KITAS самостоятельно |
| Обработка продления    | 8-15 миллионов           | Проще, чем новое заявление           |
| Срочная обработка      | +30-50%                  | Не всегда возможно                   |

<InfoCard variant="tip" title="Выбор агента">
  Выбирайте агентов, которые: - Имеют четкие расценки (без скрытых платежей) - Предоставляют
  письменное соглашение об услугах - Имеют проверенную репутацию - Оперативно отвечают на вопросы
</InfoCard>

## Кто платит?

Юридически **работодатель** несет ответственность за большинство расходов на разрешение на работу. На практике:

### Обычно платит работодатель

- DKP-TKA (обязательство работодателя)
- Обработка RPTKA
- Сборы агентов

### Часто обсуждается

- Сборы за KITAS
- Расходы на продление
- Подготовка документов

<InfoCard variant="warning" title="Проверьте свой контракт">
Перед тем как принять предложение о работе, уточните:
- Кто платит за первоначальное разрешение на работу?
- Кто платит за продление?
- Что произойдет, если вы уйдете раньше?
- Будут ли расходы вычтены из зарплаты?

Получите это в письменном виде в вашем трудовом договоре.

</InfoCard>

## Экономия денег

Советы по снижению затрат:

1.  **Используйте внутренние ресурсы компании** - У некоторых крупных компаний есть свои иммиграционные специалисты
2.  **Многолетние разрешения** - 2-летние разрешения стоят меньше в год, чем 1-летние
3.  **Объединяйте с другими** - Агенты могут предоставить скидку для нескольких работников
4.  **Сравните агентов** - Цены значительно различаются
5.  **Правильно подготовьте документы** - Избегайте повторных сборов за обработку
