## MERP (Multiple Exit Re-Entry Permit)

### Apa itu MERP?

<InfoCard variant="note" title="Pilihan Paling Umum">
**MERP memungkinkan:**

- Keluar dan masuk tanpa batas
- Berlaku selama masa berlaku KITAS
- Tidak perlu mendaftar setiap kali perjalanan
- Paling nyaman untuk pelancong bisnis

Sebagian besar pemegang KITAS mendapatkan MERP sejak awal.

</InfoCard>

### Detail MERP

| Fitur       | Detail                       |
| ------------- | ----------------------------- |
| Berlaku      | Sama dengan masa berlaku KITAS        |
| Perjalanan diizinkan | Tak Terbatas                     |
| Pendaftaran   | Biasanya bersamaan dengan pemrosesan KITAS |
| Biaya          | IDR 1-1.5M biasanya          |
| Pemrosesan    | 3-5 hari kerja              |

## SERP (Single Exit Re-Entry Permit)

### Kapan Digunakan

| Kasus Penggunaan         | SERP Masuk Akal     |
| ---------------- | -------------------- |
| Satu perjalanan yang direncanakan | Masa berlaku KITAS pendek |
| Hemat anggaran | Lebih hemat dibanding MERP  |
| Perjalanan jarang      | Tidak sering bepergian   |

### Keterbatasan SERP

<InfoCard variant="warning" title="Satu Perjalanan Saja">
**SERP hanya mengizinkan SATU kali keluar dan masuk kembali:**

- Terpakai setelah satu perjalanan
- Harus mendaftar lagi untuk perjalanan berikutnya
- Kurang nyaman dibanding MERP
- Pertimbangkan MERP jika Anda mungkin akan bepergian lebih sering

Jika Anda kemungkinan akan bepergian beberapa kali, MERP lebih bernilai.

</InfoCard>

---

## EPO (Exit Permit Only)

### Apa itu EPO?

| Tujuan           | Detail                         |
| ----------------- | ------------------------------- |
| Keberangkatan akhir   | Meninggalkan Indonesia secara permanen   |
| Pembatalan KITAS | Biasanya menyertai pembatalan |
| Tidak kembali         | Tidak dapat masuk kembali dengan KITAS yang sama   |

### Kapan EPO Diperlukan

<InfoCard variant="warning" title="Keluar Permanen">
**EPO diperlukan ketika:**

- Mengakhiri pekerjaan di Indonesia
- Tidak memperpanjang KITAS
- Beralih ke jenis visa berbeda
- Meninggalkan Indonesia secara permanen

EPO secara efektif membatalkan KITAS Anda.

</InfoCard>

### Proses EPO

| Langkah | Tindakan                       |
| ---- | ---------------------------- |
| 1    | Ajukan pembatalan KITAS |
| 2    | Ajukan EPO                |
| 3    | Bayar biaya                     |
| 4    | Menerima EPO                  |
| 5    | Harus berangkat dalam 7 hari    |

## Pertimbangan Praktis

### Sebelum Berpergian

| Periksa                | Tindakan                   |
| -------------------- | ------------------------ |
| Berlaku MERP        | Pastikan masih berlaku       |
| Berlaku KITAS       | Harus mencakup periode perjalanan |
| Berlaku paspor    | Biasanya 6+ bulan        |
| Kembali dalam izin   | Jangan melebihi waktu di luar negeri    |

### Di Imigrasi

| Keberangkatan        | Masuk Kembali            |
| ---------------- | ----------------- |
| Tampilkan paspor    | Tampilkan paspor     |
| KITAS discan    | KITAS discan     |
| MERP diverifikasi    | MERP diverifikasi     |
| Stempel keluar diberikan | Stempel masuk diberikan |

### Masalah Umum

| Masalah                   | Solusi                    |
| ----------------------- | --------------------------- |
| Tidak ada MERP                 | Daftar sebelum bepergian         |
| MERP kadaluarsa            | Perbarui atau dapatkan SERP           |
| KITAS hilang di luar negeri       | Hubungi kedutaan segera |
| Kelebihan waktu KITAS di luar negeri | Hubungi imigrasi/agen   |

## Pemegang KITAP

<InfoCard variant="note" title="KITAP Berbeda">
**Pemegang KITAP:**

- MERP biasanya sudah termasuk secara otomatis
- Berlaku lebih lama (5 tahun)
- Beban administratif lebih sedikit
- Kebebasan perjalanan sama

KITAP lebih nyaman untuk pelancong yang sering bepergian.

</InfoCard>

## Tips Perjalanan

### Untuk Pemegang KITAS

| Tips               | Mengapa                     |
| ----------------- | ----------------------- |
| Dapatkan MERP lebih awal    | Jangan tunggu sampai perjalanan   |
| Simpan salinan       | Paspor, KITAS, MERP   |
| Pantau berlakunya    | Atur pengingat kalender  |
| Gunakan agen         | Untuk perbaruan            |
| Kenali sponsor Anda | Mungkin perlu persetujuan mereka |

### Situasi Darurat

| Situasi                  | Tindakan                        |
| -------------------------- | ----------------------------- |
| Paspor hilang di luar negeri       | Kedutaan Indonesia            |
| KITAS kadaluarsa saat di luar negeri | Hubungi sponsor/agen         |
| Darurat medis          | Bantuan kedutaan            |
| Darurat keluarga           | Dapat bepergian, atur izin nanti |
