# Coûts du permis de travail en Indonesia 2026 : Répartition complète des frais

Obtenir un permis de travail en Indonesia implique plusieurs frais. Voici exactement ce que vous (ou votre employeur) paierez.

## Calculateur de Coûts

<Calculator
  title="Estimateur de Coûts de Permis de Travail"
  description="Calculer le total des coûts de permis de travail"
  fields={[
    {
      id: "duration",

    const months = Number(values.duration);

    // Government fees
    const dkpTka = months * 100; // USD 100/month

    const vitasFee = 1500000; // IDR
    const stm = 200000; // IDR
    const biometrics = 100000; // IDR

    // Agent fees (typical range)
    const agentBase = values.useAgent ? 15000000 : 0; // IDR
    const agentPremium = values.newCompany ? 5000000 : 0; // IDR

    const dkpTkaIdr = dkpTka * 16000;

    // Totals

    const agentTotal = agentBase + agentPremium;
    const grandTotal = govtTotal + agentTotal;

    return {
      total: grandTotal,

### 2. Frais d'Agent/de Traitement

La plupart des entreprises utilisent des agents d'immigration. Frais typiques :

| Service                    | Fourchette de Coûts (IDR) | Notes                               |
| -------------------------- | ------------------------- | ----------------------------------- |
| Traitement complet KITAS   | 15-25 millions            | Tout compris                        |
| RPTKA seulement            | 5-8 millions              | Si vous gérez le KITAS vous-même    |
| Traitement de prolongation | 8-15 millions             | Plus simple qu'une nouvelle demande |
| Traitement express         | +30-50%                   | Pas toujours possible               |

<InfoCard variant="tip" title="Sélection de l'Agent">
  Choisissez des agents qui : - Ont des prix clairs (pas de frais cachés) -
  Fournissent un accord de service écrit - Ont un historique vérifiable - Sont
  réactifs aux questions
</InfoCard>

## Qui paie ?

Légalement, l'**employeur** est responsable de la plupart des coûts de permis de travail. En pratique :

### L'employeur paie généralement

- DKP-TKA (obligation employeur obligatoire)
- Traitement RPTKA
- Frais d'agent

### Souvent Négocié

- Frais KITAS
- Coûts de prolongation
- Préparation de documents

<InfoCard variant="warning" title="Vérifiez Votre Contrat">
Avant d'accepter un emploi, clarifiez :
- Qui paie pour le permis de travail initial ?
- Qui paie pour les prolongations ?
- Que se passe-t-il si vous partez tôt ?
- Les coûts sont-ils déduits du salaire ?

Obtenez-le par écrit dans votre contrat de travail.

</InfoCard>

## Économiser de l'argent

Conseils pour réduire les coûts :

1.  **Utiliser le service interne de l'entreprise** - Certaines grandes entreprises ont du personnel d'immigration
2.  **Permis pluriannuels** - Les permis de 2 ans coûtent moins cher par an que ceux de 1 an
3.  **Regrouper avec d'autres** - Les agents peuvent accorder des réductions pour plusieurs travailleurs
4.  **Comparer les agents** - Les prix varient considérablement
5.  **Préparer correctement les documents** - Éviter les frais de re-traitement
