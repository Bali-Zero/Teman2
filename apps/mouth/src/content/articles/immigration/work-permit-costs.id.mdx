# Biaya Izin Kerja di Indonesia 2026: Rincian Biaya Lengkap

Mendapatkan izin kerja di Indonesia melibatkan beberapa biaya. Berikut adalah rincian tepat dari apa yang akan Anda (atau pemberi kerja Anda) bayar.

## Kalkulator Biaya

<Calculator
  title="Estimasi Biaya Izin Kerja"
  description="Hitung total biaya izin kerja"
  fields={[
    {
      id: "duration",
      label: "Durasi Izin",
      type: "select",
      options: [
        { value: "6", label: "6 bulan" },
        { value: "12", label: "12 bulan (1 tahun)" },
        { value: "24", label: "24 bulan (2 tahun)" }

      label: "Menggunakan Agen Imigrasi?",

      id: "newCompany",
      label: "Perusahaan baru (pekerja asing pertama)?",
      type: "checkbox",
      defaultValue: false
    }
  ]}
  calculateResult={(values) => {
    const months = Number(values.duration);

    // Government fees
    const dkpTka = months * 100; // USD 100/month
    const kitasFee = 2000000; // IDR
    const vitasFee = 1500000; // IDR
    const stm = 200000; // IDR
    const biometrics = 100000; // IDR

    // Agent fees (typical range)
    const agentBase = values.useAgent ? 15000000 : 0; // IDR
    const agentPremium = values.newCompany ? 5000000 : 0; // IDR

    // Convert to IDR (approx rate)
    const dkpTkaIdr = dkpTka * 16000;

    // Totals
    const govtTotal = kitasFee + vitasFee + stm + biometrics + dkpTkaIdr;
    const agentTotal = agentBase + agentPremium;
    const grandTotal = govtTotal + agentTotal;

    return {
      total: grandTotal,
      breakdown: [
        { label: `DKP-TKA (${months} bulan)`, amount: dkpTkaIdr },
        { label: "Biaya KITAS", amount: kitasFee },
        { label: "Biaya VITAS", amount: vitasFee },
        { label: "STM + Biometrik", amount: stm + biometrics },
        { label: "Biaya Jasa Agen", amount: agentBase },
        { label: "Premi Perusahaan Baru", amount: agentPremium }
      ],
      currency: "IDR",
      note: `Setara USD: ~$${Math.round(grandTotal / 16000)}`
    };

}}

### 2. Biaya Agen/Pemrosesan

Kebanyakan perusahaan menggunakan agen imigrasi. Biaya tipikal:

| Layanan                  | Rentang Biaya (Rp) | Catatan                            |
| ------------------------ | ------------------ | ---------------------------------- |
| Pemrosesan KITAS lengkap | 15-25 juta         | All-inclusive                      |
| RPTKA saja               | 5-8 juta           | Jika mengurus KITAS sendiri        |
| Pemrosesan perpanjangan  | 8-15 juta          | Lebih sederhana dari aplikasi baru |
| Pemrosesan kilat         | +30-50%            | Tidak selalu memungkinkan          |

---

| Foto                  | Rp 50-100rb       | Persyaratan khusus                        |

| Perjalanan biometrik  | Bervariasi        | Mungkin perlu mengunjungi kantor tertentu |

## Siapa yang Membayar?

Secara hukum, **pemberi kerja** bertanggung jawab atas sebagian besar biaya izin kerja. Dalam praktiknya:

### Pemberi Kerja Biasanya Membayar

- DKP-TKA (kewajiban wajib pemberi kerja)
- Pemrosesan RPTKA
- Biaya agen

### Sering Dinegosiasikan

- Biaya KITAS
- Biaya perpanjangan
- Penyiapan dokumen

<InfoCard variant="warning" title="Periksa Kontrak Anda">
Sebelum menerima pekerjaan, klarifikasi:
- Siapa yang membayar izin kerja awal?
- Siapa yang membayar perpanjangan?
- Apa yang terjadi jika Anda berhenti lebih awal?
- Apakah biaya dipotong dari gaji?

Dapatkan secara tertulis dalam kontrak kerja Anda.
