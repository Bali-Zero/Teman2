## MERP (Multiple Exit Re-Entry Permit)

### Cos'è il MERP?

<InfoCard variant="note" title="Scelta Più Comune">
**Il MERP permette:**

- Uscite e rientri illimitati
- Validità pari a quella del KITAS
- Necessità di richiedere solo una volta
- Molto comodo per i viaggiatori d'affari

La maggior parte dei titolari di KITAS ottiene il MERP fin dall'inizio.

</InfoCard>

### Dettagli sul MERP

| Caratteristica       | Dettagli                       |
| ------------- | ----------------------------- |
| Validità      | Identica a quella del KITAS   |
| Viaggi consentiti | Illimitati                     |
| Richiesta     | Solitamente insieme al KITAS  |
| Costo          | IDR 1-1.5M in media           |
| Elaborazione   | 3-5 giorni lavorativi         |

## SERP (Single Exit Re-Entry Permit)

### Quando Utilizzarlo

| Caso d'uso         | Il SERP ha senso          |
| ---------------- | -------------------- |
| Un viaggio pianificato | Validità KITAS breve |
| Attenzione al budget | Risparmia rispetto al MERP |
| Viaggi rari      | Non viaggi spesso        |

### Limitazioni del SERP

<InfoCard variant="warning" title="Solo Un Viaggio">
**Il SERP permette solo UNA uscita e un rientro:**

- Si esaurisce dopo un viaggio
- Bisogna richiederlo di nuovo per il prossimo viaggio
- Meno comodo rispetto al MERP
- Considera il MERP se prevedi di viaggiare spesso

Se è probabile che tu debba viaggiare più volte, il MERP offre un miglior rapporto qualità-prezzo.

</InfoCard>

---

## EPO (Exit Permit Only)

### Cos'è l'EPO?

| Scopo           | Dettagli                         |
| ----------------- | ------------------------------- |
| Partenza finale   | Uscita definitiva dall'Indonesia |
| Cancellazione KITAS | Accompagna solitamente la cancellazione |
| Nessun ritorno         | Impossibile rientrare con lo stesso KITAS   |

### Quando è Richiesto l'EPO

<InfoCard variant="warning" title="Uscita Definitiva">
**L'EPO è necessario quando:**

- Si conclude il rapporto lavorativo in Indonesia
- Non si rinnova il KITAS
- Si passa a un altro tipo di visto
- Si lascia l'Indonesia definitivamente

L'EPO cancella efficacemente il tuo KITAS.

</InfoCard>

### Processo EPO

| Passo | Azione                       |
| ---- | ---------------------------- |
| 1    | Sottomettere la richiesta di cancellazione del KITAS |
| 2    | Richiedere l'EPO                |
| 3    | Pagare le tasse                     |
| 4    | Ricevere l'EPO                  |
| 5    | Essere obbligati a partire entro 7 giorni    |

## Considerazioni Pratiche

### Prima di Viaggiare

| Verifica                | Azione                   |
| -------------------- | ------------------------ |
| Validità MERP        | Assicurarsi che sia ancora valido       |
| Validità KITAS       | Deve coprire il periodo di viaggio |
| Validità passaporto    | Solitamente 6+ mesi        |
| Rientro entro il permesso | Non trascorrere troppo tempo all'estero    |

### All'Ufficio Immigrazione

| Uscita        | Rientro            |
| ---------------- | ----------------- |
| Mostrare passaporto    | Mostrare passaporto     |
| KITAS scansionato    | KITAS scansionato     |
| MERP verificato    | MERP verificato     |
| Timbro di uscita dato | Timbro di ingresso dato |

### Problemi Comuni

| Problema                   | Soluzione                    |
| ----------------------- | --------------------------- |
| Nessun MERP                 | Richiederlo prima del viaggio         |
| MERP scaduto            | Rinnovarlo o ottenere un SERP           |
| KITAS perso all'estero       | Contattare immediatamente l'ambasciata |
| KITAS scaduto all'estero    | Contattare immigrazione/agente   |

## Titolari di KITAP

<InfoCard variant="note" title="KITAP Diverso">
**I titolari di KITAP:**

- Solitamente ottengono il MERP automaticamente
- Validità più lunga (5 anni)
- Meno oneri amministrativi
- Stessa libertà di viaggio

Il KITAP è più comodo per i viaggiatori frequenti.

</InfoCard>

## Consigli per Viaggiare

### Per Titolari di KITAS

| Consiglio               | Perché                     |
| ----------------- | ----------------------- |
| Ottieni il MERP presto    | Non aspettare fino al viaggio   |
| Conserva copie       | Passaporto, KITAS, MERP   |
| Monitora la validità    | Imposta promemoria sul calendario  |
| Usa un agente         | Per i rinnovi            |
| Conosci il tuo sponsor | Potrebbe essere necessaria la loro approvazione |

### Situazioni di Emergenza

| Situazione                  | Azione                        |
| -------------------------- | ----------------------------- |
| Passaporto perso all'estero       | Ambasciata indonesiana            |
| KITAS scaduto mentre si è all'estero | Contattare sponsor/agente         |
| Emergenza medica          | Assistenza dell'ambasciata            |
| Emergenza familiare           | Si può viaggiare, regolarizzare il permesso dopo |
