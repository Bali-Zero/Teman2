## Pagamento VOA

### Al Conto VOA

<InfoCard variant="note" title="Visa on Arrival">
**Prima dell'immigrazione, paga il VOA:**

- Costo: IDR 500.000
- Pagamento: Contanti (IDR, USD) o carta
- Ricevuta: Tienila per l'immigrazione
- Durata: 30 giorni, estendibile

Cerca il conto "Visa on Arrival" prima delle code per l'immigrazione.

</InfoCard>

### Opzioni di Pagamento

| Metodo            | Accettato            |
| ----------------- | ------------------- |
| Rupiah Indonesiana | Sì                 |
| Dollari USA        | Sì                 |
| Carta di Credito/Prepagata | Sì (nella maggior parte degli aeroporti) |
| Altre valute       | Alcune accettate   |

## Immigrazione

### Cosa Aspettarsi

| Elemento       | Cosa Succede                       |
| ---------- | ---------------------------------- |
| Documenti  | Mostra passaporto + ricevuta/viso VOA |
| Domande  | Possono chiedere scopo, durata e indirizzo di soggiorno |
| Biometria | Foto e impronte digitali             |
| Timbro      | Timbro di ingresso nel passaporto            |
| Durata   | Variabile (può essere veloce o lenta)      |

### Domande Comuni Poste

| Domanda          | Buona Risposta                                   |
| ----------------- | --------------------------------------------- |
| Scopo della visita? | Turismo / Riunioni d'affari / Visita a familiari |

<InfoCard variant="tip" title="Consigli per l'Immigrazione">
**Per un passaggio fluido:**

- Sii educato e paziente

- Tieni pronto l'indirizzo dell'alloggio

- Non scherzare su cose illegali

## Dogana

### Cosa Dichiarare

| Dichiarare                      | Autorizzazione       |
| ---------------------------- | --------------- |
| Contanti superiori a IDR 100M / USD 10K | Va dichiarato    |
| Sigarette oltre 200          | Va dichiarato    |
| Alcol oltre 1 litro          | Va dichiarato    |
| Merci con valore superiore a USD 500     | Potrebbe essere tassabile |

### Oggetti Proibiti

<InfoCard variant="warning" title="Non Portare">
**Strettamente proibito:**
- Narcotici/droghe (pena di morte!)
- Armi
- Pornografia
- Merci contraffatte
- Alcuni prodotti alimentari
- Oggetti offensivi per la religione

Le droghe comportano **pena di morte** in Indonesia!

</InfoCard>

### Canali

| Canale | Usare Quando           |
| ------- | ------------------ |
| Verde   | Nulla da dichiarare |
| Rosso     | Oggetti da dichiarare   |

Potresti comunque essere controllato a caso anche nel canale verde.

## Controllo Soggiorno Eccessivo

<InfoCard variant="warning" title="Verifica Prima della Partenza">
**Prima di andare all'immigrazione:**

- Conta i giorni trascorsi in Indonesia
- Controlla la data di scadenza del visto
- Soggiorno eccessivo = multa di IDR 1.000.000 al giorno
- Le multe si pagano all'immigrazione dell'aeroporto
- Può ritardare la tua partenza

Calcola con cura per evitare sorprese!

</InfoCard>

## Strutture Aeroportuali

### Bali (DPS) - Ngurah Rai

| Struttura       | Posizione                 |
| -------------- | ------------------------ |
| Bancomat           | Sala arrivi, partenza  |

| Struttura        | Posizione          |
| --------------- | ----------------- |
| Bancomat            | In tutto l'aeroporto        |
| Cambio valuta  | Più contatori       |
| Carte SIM       | Sale arrivi     |
| Treno (Railink) | Verso il centro città    |
| Taxi            | Contatori ufficiali |

## Opzioni di Trasporto

### Dall'Aeroporto di Bali

| Opzione         | Costo                | Note                     |
| -------------- | ------------------- | ------------------------- |
| Taxi ufficiale  | Prezzo fisso per zona | Sicuro, alternativa con tassametro |
| Grab/Gojek     | Variabile            | Area di prelievo esterna       |
| Prendi in hotel   | Spesso gratuito          | Organizza in anticipo        |
| Autista privato | IDR 200-400K        | Prenotato                |

### Dall'Aeroporto di Jakarta

| Opzione           | Costo     | Note                |
| ---------------- | -------- | -------------------- |
| Treno aeroportuale    | IDR 70K  | Verso Sudirman, 45 min  |
| Taxi (Blue Bird) | Con tassametro  | IDR 200-400K verso la città |
| Grab             | Variabile | Potrebbe essere più economico       |
| Prendi in hotel     | Varia   | Organizza in anticipo   |
