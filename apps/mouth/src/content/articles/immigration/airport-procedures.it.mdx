## Pagamento VOA

### Al Contatto VOA

<InfoCard variant="note" title="Visa on Arrival">
**Prima dell'immigrazione, paga il VOA:**

- Costo: IDR 500.000
- Pagamento: Contanti (IDR, USD) o carta
- Ricevuta: Tienila per l'immigrazione
- Durata: 30 giorni, estendibile

Cerca il banco "Visa on Arrival" prima delle code per l'immigrazione.

</InfoCard>

### Opzioni di Pagamento

| Metodo            | Accettato            |
| ----------------- | ------------------- |
| Rupiah Indonesiano | Sì                 |
| Dollari USA       | Sì                 |
| Carta di Credito/Prepagata | Sì (nella maggior parte degli aeroporti) |
| Altre valute      | Alcune accettate   |

## Immigrazione

### Cosa Aspettarsi

| Elemento         | Cosa Succede                       |
| ---------------- | ---------------------------------- |
| Documenti        | Mostra passaporto + ricevuta/visto VOA |
| Domande          | Potrebbero chiedere scopo, durata e indirizzo di soggiorno |
| Biometria        | Foto e impronte digitali           |
| Timbro           | Timbro di ingresso nel passaporto  |
| Durata           | Variabile (può essere veloce o lenta) |

### Domande Comuni Poste

| Domanda          | Buona Risposta                                   |
| ---------------- | ------------------------------------------------- |
| Scopo della visita? | Turismo / Riunioni d'affari / Visita a familiari |
| Quanto tempo rimarrai? | [La tua durata pianificata reale]                 |
| Dove starai?     | [Nome dell'hotel e zona]                         |
| Volo di ritorno? | [Data e compagnia aerea]                        |
| Occupazione?     | [Il tuo lavoro/professione]                      |

<InfoCard variant="tip" title="Consigli per l'Immigrazione">
**Per un passaggio fluido:**

- Sii cortese e paziente
- Rispondi con verità
- Tieni pronto l'indirizzo del luogo di soggiorno
- Conosci la data del tuo volo di ritorno
- Non scherzare su cose illegali
- Vestiti in modo appropriato
</InfoCard>

## Dogana

### Cosa Dichiarare

| Dichiarare                      | Permessi           |
| ------------------------------- | ------------------ |
| Contanti oltre IDR 100M / USD 10K | Deve essere dichiarato    |
| Sigarette oltre 200             | Deve essere dichiarato    |
| Alcol oltre 1 litro             | Deve essere dichiarato    |
| Merci oltre valore di USD 500   | Potrebbe essere tassabile |

### Oggetti Proibiti

<InfoCard variant="warning" title="Non Portare">
**Strettamente proibito:**
- Narcotici/droghe (pena di morte!)
- Armi
- Pornografia
- Merci contraffatte
- Alcuni prodotti alimentari
- Oggetti offensivi per la religione

Le droghe comportano **pena di morte** in Indonesia!

</InfoCard>

### Canali

| Canale | Utilizzare Quando           |
| ------ | --------------------------- |
| Verde  | Nulla da dichiarare         |
| Rosso  | Oggetti da dichiarare       |

Potresti comunque essere controllato a caso anche nel canale verde.

## Controllo Sovraresidenza

<InfoCard variant="warning" title="Controlla Prima della Partenza">
**Prima di andare all'immigrazione:**

- Conta i tuoi giorni in Indonesia
- Controlla la data di scadenza del visto
- Sovraresidenza = multa di IDR 1.000.000 al giorno
- Le multe si pagano all'immigrazione dell'aeroporto
- Può ritardare la tua partenza

Calcola attentamente per evitare sorprese!

</InfoCard>
