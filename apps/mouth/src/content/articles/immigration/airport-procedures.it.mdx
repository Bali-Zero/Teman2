## Pagamento VOA

### Al Contatore VOA

<InfoCard variant="note" title="Visto all'Arrivo">
**Prima dell'immigrazione, paga per il VOA:**

- Costo: IDR 500.000
- Pagamento: Contanti (IDR, USD) o carta
- Ricevuta: Conservala per l'immigrazione
- Durata: 30 giorni, prorogabili

Cerca il contatore "Visa on Arrival" prima delle file dell'immigrazione.

</InfoCard>

### Opzioni di Pagamento

| Metodo                  | Accettato                                |
| ----------------------- | ---------------------------------------- |
| Rupia Indonesiana       | Sì                                       |
| Dollari USA             | Sì                                       |
| Carta di Credito/Debito | Sì (nella maggior parte degli aeroporti) |
| Altre valute            | Alcune accettate                         |

## Dogana

### Cosa Dichiarare

| Dichiarare                          | Limite                           |
| ----------------------------------- | -------------------------------- |
| Contanti oltre IDR 100M / USD 10K   | Deve essere dichiarato           |
| Sigarette oltre 200                 | Deve essere dichiarato           |
| Alcol oltre 1 litro                 | Deve essere dichiarato           |
| Merci di valore superiore a USD 500 | Potrebbe essere soggetta a dazio |

### Articoli Proibiti

<InfoCard variant="warning" title="Non Portare">
**Rigorosamente proibiti:**
- Narcotici/droghe (pena di morte!)
- Armi
- Pornografia
- Merci contraffatte
- Alcuni prodotti alimentari
- Articoli offensivi per la religione

Il traffico di **droghe** comporta la **pena di morte** in Indonesia!

</InfoCard>

### Canali

| Canale | Usare quando           |
| ------ | ---------------------- |
| Verde  | Nulla da dichiarare    |
| Rosso  | Articoli da dichiarare |

Potresti comunque essere controllato a campione nel canale verde.

## Controllo del Superamento della Durata del Soggiorno

<InfoCard variant="warning" title="Controlla Prima della Partenza">
**Prima di recarti all'immigrazione:**

- Conta i tuoi giorni in Indonesia
- Controlla la data di scadenza del visto
- Superamento della durata del soggiorno = multa di IDR 1.000.000 al giorno
- Le multe vengono pagate all'immigrazione aeroportuale
- Può ritardare la tua partenza

Calcola attentamente per evitare sorprese!

</InfoCard>
