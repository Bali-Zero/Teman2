## Pagamento VOA

### Allo sportello VOA

<InfoCard variant="note" title="Visto all'arrivo">
**Prima dell'immigrazione, paga il VOA:**

- Costo: IDR 500.000
- Pagamento: Contanti (IDR, USD) o carta
- Ricevuta: Conservala per l'immigrazione
- Durata: 30 giorni, estendibile

Cerca lo sportello "Visa on Arrival" prima delle code per l'immigrazione.

</InfoCard>

### Opzioni di pagamento

| Metodo            | Accettato            |
| ----------------- | ------------------- |
| Rupiah Indonesiana | Sì                 |
| Dollari USA        | Sì                 |
| Carta di credito/debito | Sì (la maggior parte degli aeroporti) |
| Altre valute       | Alcune accettate     |

## Immigrazione

### Cosa aspettarsi

| Elemento       | Cosa succede                       |
| -------------- | ---------------------------------- |
| Documenti      | Mostra passaporto + ricevuta VOA/visto   |
| Domande        | Potrebbero chiedere lo scopo, la durata, l'indirizzo |
| Biometria      | Foto e impronte digitali             |
| Timbro         | Timbro d'ingresso sul passaporto            |
| Durata         | Varia (può essere veloce o lenta)      |

### Domande comuni

| Domanda          | Buona risposta                                   |
| ----------------- | --------------------------------------------- |
| Scopo della visita? | Turismo / Riunioni d'affari / Visita a parenti |
| Per quanto tempo? | [Durata pianificata effettiva]                |
| Dove si alloggia?    | [Nome dell'hotel e area]                         |
| Volto di ritorno?    | [Data e compagnia aerea]                            |
| Occupazione?       | [Lavoro/professione]                         |

<InfoCard variant="tip" title="Consigli per l'immigrazione">
**Per un passaggio fluido:**

- Sii cortese e paziente
- Rispondi sinceramente
- Avere pronto l'indirizzo dell'alloggio
- Conoscere la data del volo di ritorno
- Non scherzare su cose illegali
- Vestire in modo decente
</InfoCard>

## Dogana

### Cosa dichiarare

| Dichiarare                      | Limite       |
| ---------------------------- | --------------- |
| Denaro oltre IDR 100M / USD 10K | Deve essere dichiarato    |
| Sigarette oltre 200          | Deve essere dichiarato    |
| Alcol oltre 1 litro         | Deve essere dichiarato    |
| Merci oltre USD 500 di valore     | Potrebbero essere tassate |

### Oggetti proibiti

<InfoCard variant="warning" title="Non portare">
**Strettamente proibito:**
- Narcotici/ droghe (pena capitale!)
- Armi
- Pornografia
- Merci contraffatte
- Certi prodotti alimentari
- Oggetti offensivi per la religione

Le droghe comportano **pena capitale** in Indonesia!

</InfoCard>

### Canali

| Canale | Usare quando           |
| ------- | ------------------ |
| Verde   | Niente da dichiarare |
| Rosso     | Oggetti da dichiarare   |

Puoi comunque essere controllato a caso nel canale verde.

## Controllo di sovra-stanza

<InfoCard variant="warning" title="Controlla prima della partenza">
**Prima di andare all'immigrazione:**

- Conta i giorni trascorsi in Indonesia
- Controlla la data di scadenza del visto
- Sovra-stanza = multa di IDR 1.000.000 al giorno
- Le multe vengono pagate all'immigrazione dell'aeroporto
- Possono ritardare la tua partenza

Calcola con attenzione per evitare sorprese!

</InfoCard>
