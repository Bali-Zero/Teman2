# IVA (PPN) in Indonesia nel 2026: Guida Completa per le Imprese

Il Pajak Pertambahan Nilai (PPN) è l’IVA indonesiana. Comprendere il suo funzionamento è fondamentale per la conformità aziendale.

<InfoCard variant="warning" title="Aggiornamento IVA 2026 (Fonte: pajak.go.id)">
**IVA al 12% in vigore dal 1 gennaio 2025:**

L’IVA indonesiana è ufficialmente al **12%** dal 1 gennaio 2025. Tuttavia, grazie al meccanismo **DPP Nilai Lain** (Base Imponibile Altra), l'aliquota effettiva per la maggior parte dei beni e servizi rimane all'**11%**.

- **Beni normali**: 12% × (11/12) = **11% effettivo**
- **Beni di lusso**: **12% pieno** (senza DPP Nilai Lain)
- **Tutte le fatture (Faktur Pajak)** devono essere emesse tramite **Coretax/e-Faktur**

**Nota Importante**: Questa struttura è stata implementata per minimizzare l'impatto sui consumatori mantenendo formalmente l'aliquota del 12% prevista dalla legge.

</InfoCard>

## Registrazione IVA

### Chi deve registrarsi?

<InfoCard variant="note" title="Soglia di Registrazione PKP">
Devi registrarti come **PKP (Pengusaha Kena Pajak)** se:

- Il fatturato lordo supera le **IDR 4.8 miliardi/anno**
- Oppure ti registri **volontariamente**

Come PKP, devi:

- Applicare l’IVA sulle vendite
- Emettere fatture fiscali (Faktur Pajak)
- Presentare dichiarazioni IVA mensili
- Poter richiedere crediti IVA a debito
  </InfoCard>

## Calcolo dell’IVA

<Calculator
  title="Calcolatore IVA"
  description="Calcola l’IVA sulle transazioni"
  fields={[
    {
      id: "amount",
      label: "Importo della Transazione (IDR)",
      type: "number",
      defaultValue: 100000000,
      min: 0,
      step: 1000000,
      suffix: "IDR"
    },
    {
      id: "type",
      label: "Tipo di Transazione",
      type: "select",
      options: [
        { value: "exclusive", label: "Aggiungere IVA al prezzo" },
        { value: "inclusive", label: "IVA inclusa nel prezzo" }
      ],
      defaultValue: "exclusive"
    }
  ]}
  calculateResult={(values) => {
    const amount = Number(values.amount);
    const rate = 0.11; // 11%

    let baseAmount, vatAmount, totalAmount;

    if (values.type === "exclusive") {
      baseAmount = amount;
      vatAmount = amount * rate;
      totalAmount = amount + vatAmount;
    } else {
      totalAmount = amount;
      baseAmount = amount / (1 + rate);
      vatAmount = totalAmount - baseAmount;
    }

    return {
      total: vatAmount,
      breakdown: [
        { label: "Base Amount (DPP)", amount: Math.round(baseAmount) },
        { label: "VAT (11%)", amount: Math.round(vatAmount) },
        { label: "Total with VAT", amount: Math.round(totalAmount) }
      ],
      currency: "IDR",
      note: "Rate: 11% (standard)"
    };

}}

## Fatture Fiscali (Faktur Pajak)

### Sistema E-Faktur

<InfoCard variant="warning" title="E-Faktur Obbligatorio">
Tutte le imprese registrate per l’IVA devono utilizzare il sistema di fatturazione elettronica **e-Faktur**:

- Scaricare l'applicazione e-Faktur
- Registrare il certificato digitale
- Emettere tutte le fatture elettronicamente
- Caricare nel sistema DJP
- Inserire i crediti IVA elettronicamente
  </InfoCard>

### Contenuti di Faktur Pajak

| Campo Obbligatorio     | Descrizione                                   |
| ---------------------- | --------------------------------------------- |
| NPWP del venditore     | Il tuo numero di identificazione fiscale      |
| NPWP dell'acquirente   | Numero di identificazione fiscale del cliente |
| Numero della fattura   | Sequenziale, generato dal sistema             |
| Data della transazione | Data di fornitura                             |
| Descrizione            | Dettaglio di beni/servizi                     |
| DPP                    | Base imponibile (prezzo prima dell’IVA)       |
| PPN                    | Importo dell’IVA                              |
| Firma digitale         | Verifica elettronica                          |

## IVA a Debito vs IVA a Credito

### Come Funzionano i Crediti IVA

| Transazione           | Tipo di IVA   | Trattamento                     |
| --------------------- | ------------- | ------------------------------- |
| Vendite ai clienti    | IVA a debito  | Raccogliere e versare           |
| Acquisti da fornitori | IVA a credito | Richiedere come credito         |
| Posizione netta       | Differenza    | Pagare se a debito > a credito  |
| Credito netto         | Differenza    | Trasferire in avanti o rimborso |

### Esempio di Calcolo Mensile

| Descrizione              | Importo  |
| ------------------------ | -------- |
| IVA a debito (vendite)   | IDR 110M |
| IVA a credito (acquisti) | IDR 55M  |
| IVA netta da versare     | IDR 55M  |

### Articoli Esenti IVA

Alcuni beni e servizi sono esenti IVA:

- Prodotti di prima necessità (alcuni articoli alimentari)
- Servizi sanitari

## Problemi Comuni

### Problemi IVA da Evitare

| Problema                 | Conseguenza                         |
| ------------------------ | ----------------------------------- |
| Presentazione in ritardo | Penalità di IDR 500K                |
| Fatture errate           | Crediti non ammessi                 |
| Fatture mancanti         | Impossibilità di richiedere crediti |
| NPWP errato              | Fattura respinta                    |
| Pagamento in ritardo     | Penalità di interessi               |

### Regole per i Crediti IVA

<InfoCard variant="warning" title="Crediti IVA Richiedibili">
Non tutti i crediti IVA sono richiedibili. I crediti sono **negati** per:

- Spese di intrattenimento
- Acquisti non aziendali
- Acquisti senza fattura fiscale valida
- Acquisti da fornitori non PKP
- Beni di lusso (auto, ecc.)
  </InfoCard>

## Rimborso IVA

### Quando è Disponibile il Rimborso

- L’IVA a debito è costantemente inferiore all’IVA a credito
- Imprese esportatrici (vendite zero-rated)
- Nuovi investimenti con grande IVA a debito

### Processo di Rimborso

1. Presentare una richiesta di rimborso annuale o speciale
2. Solitamente è richiesto un controllo fiscale
3. Tempo di elaborazione: 1-12 mesi
4. È richiesta una documentazione completa
