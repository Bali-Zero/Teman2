# Panduan Surat Pemberitahuan Tahunan (SPT) untuk Ekspatriat di Indonesia 2026

Jika Anda adalah penduduk pajak Indonesia, Anda wajib melaporkan SPT Tahunan paling lambat **31 Maret** setiap tahun. Berikut caranya.

## Tanggal Penting

| Tenggat Waktu  | Apa                                           |
| -------------- | --------------------------------------------- |
| **31 Januari** | Pemberi kerja memberikan Bukti Potong 1721-A1 |
| **31 Maret**   | Tenggat waktu SPT Individu                    |
| **30 April**   | Tenggat waktu SPT Badan                       |

<InfoCard variant="warning" title="Jangan Lewatkan Tenggat Waktu">
Denda keterlambatan lapor: **Rp 100.000** untuk individu

Keterlambatan bayar: **2% per bulan** dari pajak yang belum dibayar

Tetap lapor meskipun Anda tidak memiliki pajak terutang - ini wajib bagi penduduk pajak.

</InfoCard>

## Kesalahan Umum

<InfoCard variant="error" title="Hindari Kesalahan Ini">
  1. **Melewatkan tenggat waktu** - Lapor paling lambat 31 Maret 2. **Salah formulir** - Gunakan
  1770 jika Anda memiliki penghasilan luar negeri 3. **Melupakan penghasilan luar negeri** -
  Penduduk wajib melaporkan penghasilan seluruh dunia 4. **Tidak mengklaim kredit pajak luar
  negeri** - Hindari pajak berganda 5. **Melapor tanpa EFIN** - Dapatkan EFIN terlebih dahulu 6.
  **Tidak menyimpan catatan** - Simpan BPE dan dokumen pendukung
</InfoCard>
