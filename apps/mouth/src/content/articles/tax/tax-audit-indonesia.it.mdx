## Fattori Scatenanti Comuni

<InfoCard variant="warning" title="Cosa Scatena gli Audit">
**Indicatori di alto rischio:**

- Grandi richieste di rimborso IVA (PPN)
- Perdite significative dichiarate
- Questioni legate ai prezzi di trasferimento (Transfer Pricing)
- Campagne di audit a livello di settore
- Selezione casuale
- Segnalazioni di whistleblower
- Discrepanze negli incroci dei dati
- Dichiarazioni tardive o errate

Più sono i campanelli d'allarme, maggiore è il rischio di audit.

</InfoCard>

### Fattori Specifici

| Fattore Scatenante          | Livello di Rischio |
| --------------------------- | ------------------ |
| Richiesta rimborso IVA      | Alto               |
| Perdite costanti            | Alto               |
| Transazioni parti correlate | Alto               |
| Deduzioni con ratio elevato | Medio              |
| Campagna di settore         | Medio              |
| Selezione casuale           | Basso              |
| Routine (ogni pochi anni)   | Basso              |

## Aree di Focus dell'Audit

### Punti di Esame Comuni

| Area            | Cosa Controllano                  |
| --------------- | --------------------------------- |
| Ricavi          | Completezza, tempistica, classif. |
| Spese           | Deducibilità, documentazione      |
| IVA (PPN)       | Incrocio acquisti/vendite, tempi  |
| Ritenute        | Aliquote corrette, versamenti     |
| Parti correlate | Prezzi di libera concorrenza      |
| Asset           | Ammortamenti, alienazioni         |
| Payroll         | Calcoli, rendicontazione          |

### Focus sul Transfer Pricing

<InfoCard variant="warning" title="Scrutinio sui Prezzi di Trasferimento">
Le transazioni con parti correlate sono oggetto di severi controlli:

**Cosa esaminano gli auditor:**

- Metodologia di determinazione dei prezzi infragruppo
- Studi di benchmarking
- Documentazione (TP Doc)
- Giustificazione delle management fees
- Pagamenti di royalty
- Tassi di interesse sui prestiti

**Se hai transazioni con parti correlate:**

- Prepara in anticipo la documentazione TP
- Assicurati che i prezzi siano \"arm's length\"
- Documenta tutto meticolosamente
  </InfoCard>

## I Tuoi Diritti Durante l'Audit

### Diritti del Contribuente

| Diritto                  | Descrizione                            |
| ------------------------ | -------------------------------------- |
| Conoscere l'ambito       | L'audit deve restare nell'ambito dich. |
| Ricevere la notifica     | Preavviso adeguato prima dell'audit    |
| Assistenza professionale | Incaricare un consulente fiscale       |
| Tempo per rispondere     | Periodi minimi previsti per legge      |
| Riservatezza             | Gli auditor devono proteggere i dati   |
| Ricorso                  | Possibilità di contestare i risultati  |

### Scadenze dell'Audit

| Fase                  | Scadenza                             |
| --------------------- | ------------------------------------ |
| Consegna documenti    | Come richiesto (solitamente 7-14 gg) |
| Risposta all'SPHP     | 7 giorni lavorativi                  |
| Completamento audit   | Massimo 12 mesi                      |
| Pagamento dopo SKP    | 1 mese                               |
| Presentazione reclamo | 3 mesi dall'SKP                      |

## Gestione dei Risultati dell'Audit

### Strategie di Risposta

| Situazione         | Approccio                         |
| ------------------ | --------------------------------- |
| Accordo sui risul. | Accettazione e pagamento          |
| Accordo parziale   | Negoziare, accettare punti validi |
| Disaccordo totale  | Risposta formale con prove        |
| Carenza doc.       | Raccolta di supporto aggiuntivo   |

<InfoCard variant="tip" title="Consigli per la Negoziazione">
**Durante il processo di audit:**

1. **Sii cooperativo** - L'ostilità è controproducente
2. **Documenta tutto** - Tieni traccia di tutte le interazioni
3. **Rispondi prontamente** - Non mancare le scadenze
4. **Coinvolgi esperti** - I consulenti conoscono il processo
5. **Fornisci il contesto** - Aiuta gli auditor a capire il tuo business
6. **Sii organizzato** - Una documentazione chiara aiuta
7. **Conosci i tuoi diritti** - Ma esercitali con diplomazia
   </InfoCard>

## Contestazione degli Accertamenti

### Processo di Reclamo (Objection)

| Passaggio        | Tempistica             |
| ---------------- | ---------------------- |
| Invio reclamo    | Entro 3 mesi dall'SKP  |
| Revisione DJP    | Fino a 12 mesi         |
| Decisione emessa | Accettazione o ricorso |

### Opzioni di Ricorso

| Livello         | Sede                             |
| --------------- | -------------------------------- |
| Reclamo         | Kanwil DJP                       |
| Ricorso         | Corte Fiscale (Pengadilan Pajak) |
| Revisione Giud. | Corte Suprema                    |

<InfoCard variant="note" title="Pagamento in Pendenza di Ricorso">
**Importante:** Potrebbe essere necessario pagare l'imposta accertata anche durante il ricorso.

Tuttavia, se presenti un reclamo:

- Puoi richiedere il pagamento rateale
- Le sanzioni possono essere annullate se il ricorso ha successo
- Gli interessi maturano durante il periodo di ricorso
  </InfoCard>

## Penali e Sanzioni

### Sanzioni Amministrative

| Violazione                  | Sanzione                       |
| --------------------------- | ------------------------------ |
| Sotto-pagam. (autocorretto) | 2% mensile (max 24 mesi)       |
| Sotto-pagam. (da audit)     | 50% o 100% dell'imposta dovuta |
| Ritardo pagamento           | 2% mensile                     |
| Ritardata dichiarazione     | Sanzioni fisse + interessi     |

### Sanzioni Penali

| Reato            | Sanzione                      |
| ---------------- | ----------------------------- |
| Negligenza       | Sanzioni amministrative       |
| Evasione fiscale | Possibile procedimento penale |
| Frode            | Reclusione + multe            |
| Documenti falsi  | Sanzioni severe               |
