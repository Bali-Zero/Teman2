## PPh 21: Tasse sul Lavoro

### Cos'è il PPh 21?

<InfoCard variant="note" title="Ritenuta sui Dipendenti">
**PPh 21** è l'imposta sul reddito trattenuta dai compensi dei dipendenti:

- Stipendi e salari
- Bonus e indennità
- Indennità di licenziamento
- Compensi ai direttori
- Compensi a consulenti (persone fisiche)

L'azienda detiene e versa all'ufficio delle imposte.

</InfoCard>

### Aliquote PPh 21 (Progressive)

| Reddito Imponibile (IDR/anno) | Aliquota |
| ------------------------------ | -------- |
| 0 - 60 milioni                 | 5%       |
| 60M - 250 milioni              | 15%      |
| 250M - 500 milioni             | 25%      |
| 500M - 5 miliardi              | 30%      |
| Oltre 5 miliardi                | 35%      |

  title="Stima Mensile PPh 21"

      "tk0": 54000000,
      "k0": 58500000,
      "k1": 63000000,
      "k2": 67500000,
      "k3": 72000000
    };

    // Biaya Jabatan (max 5% fino a 6M/anno)
    const biayaJabatan = Math.min(annual * 0.05, 6000000);

    // Reddito imponibile
    const taxable = Math.max(0, annual - biayaJabatan - ptkp[values.status]);

    // Calcolo progressivo delle tasse
    let tax = 0;
    let remaining = taxable;

    if (remaining > 0) {
      const bracket1 = Math.min(remaining, 60000000);
      tax += bracket1 * 0.05;
      remaining -= bracket1;
    }
    if (remaining > 0) {
      const bracket2 = Math.min(remaining, 190000000);
      tax += bracket2 * 0.15;
      remaining -= bracket2;
    }
    if (remaining > 0) {
      const bracket3 = Math.min(remaining, 250000000);
      tax += bracket3 * 0.25;
      remaining -= bracket3;
    }
    if (remaining > 0) {
      const bracket4 = Math.min(remaining, 4500000000);
      tax += bracket4 * 0.30;
      remaining -= bracket4;
    }
    if (remaining > 0) {
      tax += remaining * 0.35;
    }

    const monthlyTax = tax / 12;

    return {
      total: Math.round(monthlyTax),
      breakdown: [
        { label: "Lordo Annuale", amount: annual },
        { label: "Biaya Jabatan", amount: biayaJabatan },
        { label: "PTKP", amount: ptkp[values.status] },
        { label: "Reddito Imponibile", amount: Math.max(0, taxable) },

## PPh 26: Tasse sui Non-Residenti

### Cos'è il PPh 26?

<InfoCard variant="warning" title="Pagamenti a Stranieri">
**PPh 26** si applica ai pagamenti effettuati a **non residenti** (persone o entità estere):

- Tasso standard: **20%**
- Può essere ridotto da **convenzione fiscale**
- Si applica a: servizi, dividendi, interessi, royalties
- Trattenuta dal pagatore indonesiano

</InfoCard>

### Tassi Convenzionali Comuni

| Paese      | Servizi   | Dividendi | Interessi | Royalties |
| ---------- | --------- | --------- | --------- | --------- |
| Singapore  | 15%       | 10/15%    | 10%       | 15%       |
| USA        | 15%       | 10/15%    | 10%       | 10%       |
| UK         | 15%       | 10/15%    | 10%       | 15%       |
| Australia  | 15%       | 15%       | 10%       | 15%       |
| Giappone   | 15%       | 10/15%    | 10%       | 10%       |
| Nessun trattato | 20%      | 20%       | 20%       | 20%       |

### Certificato di Domicilio (SKD)

Per applicare i tassi convenzionali, il beneficiario estero deve fornire:

- **Form DGT-1** (Certificato di Domicilio)
- Compilato dal beneficiario
- Certificato dall'autorità fiscale
- Valido per 12 mesi

## Certificati di Ritenuta

### Fornitura ai Beneficiari

Quando trattenete una tassa, dovete fornire un **Bukti Potong** (certificato di ritenuta):

| Tipo di Tassa | Certificato             |
| ------------- | ----------------------- |
| PPh 21        | Bukti Potong 1721-A1/A2 |
| PPh 23        | Bukti Potong PPh 23     |
| PPh 26        | Bukti Potong PPh 26     |
| PPh 4(2)      | Bukti Potong PPh 4(2)   |

I beneficiari utilizzano questi per:

- Richiedere crediti fiscali
- Presentare le proprie dichiarazioni dei redditi
- Supportare deduzioni di spese

## Errori Comuni

| Errore                    | Impatto                             |
| ------------------------- | ----------------------------------- |
| Mancata ritenuta          | Sanzioni per ritardo + interessi    |
| Aliquota errata applicata | Sottopagamento/soprapagamento       |
| Mancata fornitura certificati | Problemi per i beneficiari        |
| Formalità convenzionali mancanti | Si applica il 20% invece del tasso convenzionale |
| NPWP errato               | Problemi con i certificati          |

## Sanzioni

| Violazione                | Sanzione                |
| ------------------------- | ----------------------- |

| Dichiarazione in ritardo  | 100K-1M IDR per dichiarazione |
| Mancata ritenuta          | Tassa + sanzione del 100% |
| Rilascio certificato in ritardo | Sanzione amministrativa |
