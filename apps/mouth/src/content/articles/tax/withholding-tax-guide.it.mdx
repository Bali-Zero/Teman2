## PPh 21: Imposta sul Lavoro

### Cos'è il PPh 21?

<InfoCard variant="note" title="Trattenuta per Dipendenti">
Il **PPh 21** è l'imposta sul reddito trattenuta dalla retribuzione dei dipendenti:

- Stipendi e salari
- Bonus e indennità
- Indennità di fine rapporto
- Compenso di amministratori
- Compenso di consulenti (individuali)

Il datore di lavoro trattiene e versa all'ufficio delle imposte.

</InfoCard>

### Aliquote PPh 21 (Progressive)

| Reddito Imponibile (IDR/anno) | Aliquota |
| ----------------------------- | -------- |
| 0 - 60 milioni                | 5%       |
| 60M - 250 milioni             | 15%      |
| 250M - 500 milioni            | 25%      |
| 500M - 5 miliardi             | 30%      |
| Oltre 5 miliardi              | 35%      |

<Calculator
  title="Stima Mensile PPh 21"
  description="Stima la ritenuta mensile per i dipendenti"
  fields={[
    {
      id: "gross",
      label: "Stipendio Lordo Mensile (IDR)",
      type: "number",
      defaultValue: 25000000,
      min: 0,
      step: 1000000,

    {
      id: "status",

      type: "select",
      options: [

        { value: "k1", label: "Sposato, 1 figlio (K/1)" },
        { value: "k2", label: "Sposato, 2 figli (K/2)" },

      ],
      defaultValue: "tk0"

  calculateResult={(values) => {
    const monthly = Number(values.gross);
    const annual = monthly * 12;

    // PTKP (Reddito non imponibile) per il 2024
    const ptkp = {
      "tk0": 54000000,
      "k0": 58500000,
      "k1": 63000000,
      "k2": 67500000,
      "k3": 72000000
    };

    // Biaya Jabatan (5% max 6M/anno)
    const biayaJabatan = Math.min(annual * 0.05, 6000000);

    // Reddito imponibile
    const taxable = Math.max(0, annual - biayaJabatan - ptkp[values.status]);

    // Calcolo progressivo dell'imposta
    let tax = 0;
    let remaining = taxable;

    if (remaining > 0) {
      const bracket1 = Math.min(remaining, 60000000);
      tax += bracket1 * 0.05;
      remaining -= bracket1;
    }
    if (remaining > 0) {
      const bracket2 = Math.min(remaining, 190000000);
      tax += bracket2 * 0.15;
      remaining -= bracket2;
    }
    if (remaining > 0) {
      const bracket3 = Math.min(remaining, 250000000);
      tax += bracket3 * 0.25;
      remaining -= bracket3;
    }
    if (remaining > 0) {
      const bracket4 = Math.min(remaining, 4500000000);
      tax += bracket4 * 0.30;
      remaining -= bracket4;
    }
    if (remaining > 0) {
      tax += remaining * 0.35;
    }

    const monthlyTax = tax / 12;

    return {
      total: Math.round(monthlyTax),
      breakdown: [
        { label: "Annuale Lordo", amount: annual },
        { label: "Biaya Jabatan", amount: biayaJabatan },
        { label: "PTKP", amount: ptkp[values.status] },
        { label: "Reddito Imponibile", amount: Math.max(0, taxable) },
        { label: "PPh 21 Annuale", amount: Math.round(tax) },
        { label: "PPh 21 Mensile", amount: Math.round(monthlyTax) }
      ],
      currency: "IDR",
      note: "Calcolo approssimativo"
    };

}}

## PPh 26: Imposta per Non Residenti

### Cos'è il PPh 26?

<InfoCard variant="warning" title="Pagamenti a Stranieri">
Il **PPh 26** si applica ai pagamenti effettuati a **non residenti** (persone o entità straniere):

- Aliquota standard: **20%**
- Può essere ridotta da **trattato fiscale**
- Si applica a: servizi, dividendi, interessi, royalty
- Trattenuto da un pagatore indonesiano
  </InfoCard>

| --------------- | ------- | --------- | --------- | ------- |

| USA             | 15%     | 10/15%    | 10%       | 10%     |

| Australia       | 15%     | 15%       | 10%       | 15%     |
| Giappone        | 15%     | 10/15%    | 10%       | 10%     |
| Nessun trattato | 20%     | 20%       | 20%       | 20%     |

### Certificato di Domicilio (SKD)

Per applicare le aliquote del trattato, il beneficiario straniero deve fornire:

- **Modulo DGT-1** (Certificato di Domicilio)
- Compilato dal beneficiario
- Certificato dall'autorità fiscale
- Valido per 12 mesi

## Certificati di Ritenuta

### Fornire ai Beneficiari

Quando si trattiene l'imposta, è necessario fornire un **Bukti Potong** (certificato di ritenuta):

| Tipo di Tassa | Certificato             |
| ------------- | ----------------------- |
| PPh 21        | Bukti Potong 1721-A1/A2 |
| PPh 23        | Bukti Potong PPh 23     |
| PPh 26        | Bukti Potong PPh 26     |
| PPh 4(2)      | Bukti Potong PPh 4(2)   |

I beneficiari utilizzano questi per:

- Richiedere crediti d'imposta
- Presentare le proprie dichiarazioni dei redditi
- Supportare le detrazioni delle spese

## Errori Comuni

| Errore                        | Impatto                                           |
| ----------------------------- | ------------------------------------------------- |
| Ritenuta mancante             | Penalità per ritardo + interessi                  |
| Aliquota errata applicata     | Pagamento insufficiente/eccessivo                 |
| Mancanza di certificati       | Problemi per i beneficiari                        |
| Formalità del trattato errate | Si applica l'aliquota del 20% invece del trattato |
| NPWP errato                   | Problemi con il certificato                       |

## Sanzioni

| Violazione                             | Sanzione                      |
| -------------------------------------- | ----------------------------- |
| Ritardo nel pagamento                  | 2% per mese                   |
| Ritardo nella presentazione            | IDR 100K-1M per dichiarazione |
| Mancata ritenuta                       | Imposta + 100% di penale      |
| Ritardo nell'emissione del certificato | Sanzione amministrativa       |
