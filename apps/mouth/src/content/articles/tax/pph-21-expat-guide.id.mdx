# Pajak Penghasilan (PPh 21) untuk Ekspatriat di Indonesia 2026

PPh 21 adalah pajak penghasilan yang dipotong dari gaji Anda oleh pemberi kerja. Jika Anda bekerja di Indonesia, ini adalah kewajiban pajak utama Anda.

    const bonus = Number(values.bonus) * Number(values.monthly);
    const annual = (monthly * 12) + bonus;

    const ptkpMap = { 'TK0': 54000000, 'K0': 58500000, 'K1': 63000000, 'K2': 67500000, 'K3': 72000000 };
    const ptkp = ptkpMap[values.status];

      remaining -= b1;

## PTKP (Penghasilan Tidak Kena Pajak)

PTKP adalah jumlah penghasilan yang dibebaskan dari pajak:

| Status              | Kode | PTKP Tahunan  |
| ------------------- | ---- | ------------- |
| Lajang              | TK/0 | Rp 54.000.000 |
| Menikah, tanpa anak | K/0  | Rp 58.500.000 |
| Menikah + 1 anak    | K/1  | Rp 63.000.000 |
| Menikah + 2 anak    | K/2  | Rp 67.500.000 |
| Menikah + 3 anak    | K/3  | Rp 72.000.000 |

<InfoCard variant="tip" title="Maksimalkan PTKP Anda">
  - Daftarkan tanggungan dengan benar ke HR - Maksimal 3 tanggungan (anak) - Tanggungan harus
  tinggal bersama Anda - Pasangan hanya dihitung jika tidak bekerja
</InfoCard>

## Apa Saja yang Kena Pajak?

### Termasuk dalam PPh 21:

- Gaji pokok
- Tunjangan (perumahan, transport, makan)
- Bonus dan THR
- Imbalan dalam bentuk natura (beberapa jenis)
- Opsi saham (saat dieksekusi)

### Dikecualikan:

- Iuran BPJS yang dibayar pemberi kerja
- Peralatan kerja tertentu
- Reimbursement perjalanan bisnis tertentu

---

## Tidak Ada NPWP = Pajak Lebih Tinggi

<InfoCard variant="warning" title="Penalti 20% Tanpa NPWP">
Jika Anda tidak memiliki NPWP, pemberi kerja akan memotong pajak **20% lebih banyak**. Ini bisa berjumlah besar dengan cepat:

- Dengan NPWP: Pajak Rp 50 Juta
- Tanpa NPWP: Pajak Rp 60 Juta

Dapatkan NPWP Anda untuk menghindari penalti ini.

</InfoCard>
