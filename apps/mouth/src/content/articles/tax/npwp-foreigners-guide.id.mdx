# NPWP: Nomor Pajak Indonesia untuk Orang Asing 2026

NPWP (Nomor Pokok Wajib Pajak) adalah nomor identitas pajak Indonesia Anda. NPWP sangat penting untuk kepatuhan pajak dan banyak urusan praktis lainnya di Indonesia.

## Mengapa Anda Membutuhkan NPWP

### Diperlukan Untuk:

- **Pelaporan pajak** - Tidak bisa lapor SPT tanpanya
- **Tarif pajak lebih rendah** - Penalti 20% tanpa NPWP
- **Rekening bank** - Sebagian besar bank mewajibkan untuk rekening di atas ambang batas tertentu
- **Transaksi properti** - Diperlukan untuk membeli properti
- **Proses visa tertentu** - Beberapa visa memintanya

<InfoCard variant="warning" title="Penalti Pajak 20%">
  Tanpa NPWP, pemotongan pajak penghasilan Anda **20% lebih tinggi**. Jika pajak
  tahunan Anda Rp 50 juta, itu berarti tambahan Rp 10 juta. Dapatkan NPWP untuk
  menghindari hal ini.
</InfoCard>

## Format NPWP

NPWP Anda adalah **nomor 15 digit** dengan format berikut:

```
XX.XXX.XXX.X-XXX.XXX
```

Contoh: `01.234.567.8-901.000`

| Bagian          | Arti                          |
| --------------- | ----------------------------- |
| 9 digit pertama | ID wajib pajak unik           |
| Digit 10        | Digit verifikasi              |
| Digit 11-13     | Kode KPP (kantor pajak)       |
| Digit 14-15     | Kode cabang (000 untuk pusat) |

## Pendaftaran Online (E-Registration)

Anda juga dapat mendaftar secara online di **ereg.pajak.go.id**:

1. Buat akun
2. Isi formulir online
3. Unggah dokumen
4. Kirim
5. Kunjungi KPP untuk verifikasi (mungkin diperlukan)

<InfoCard variant="tip" title="Online vs Datang Langsung">
  Pendaftaran online memang nyaman, namun orang asing sering kali masih perlu
  mengunjungi KPP untuk verifikasi. Datang langsung ke KPP bisa lebih cepat bagi
  orang asing.
</InfoCard>

---

## Setelah Mendapatkan NPWP

### Langkah Berikutnya:

1. **Daftar DJP Online** - Untuk e-filing
2. **Dapatkan EFIN** - ID pelaporan elektronik
3. **Update pemberi kerja** - Berikan NPWP ke bagian HR
4. **Update bank** - Tambahkan ke rekening Anda
