## Pemicu Audit yang Umum

<InfoCard variant="warning" title="Apa yang Memicu Audit">
**Indikator risiko tinggi:**

- Klaim restitusi PPN yang besar
- Melaporkan kerugian signifikan
- Masalah transfer pricing
- Kampanye audit seluruh industri
- Pemilihan acak
- Laporan whistleblower
- Ketidaksesuaian data (cross-matching)
- Pelaporan telat atau salah

Semakin banyak bendera merah, semakin tinggi risiko audit.

</InfoCard>

### Pemicu Spesifik

| Pemicu                    | Tingkat Risiko |
| ------------------------- | -------------- |
| Permintaan restitusi PPN  | Tinggi         |
| Kerugian konsisten        | Tinggi         |
| Transaksi pihak afiliasi  | Tinggi         |
| Deduksi rasio tinggi      | Sedang         |
| Kampanye industri         | Sedang         |
| Pemilihan acak            | Rendah         |
| Rutin (tiap beberapa thn) | Rendah         |

## Area Fokus Audit

### Poin Pemeriksaan Umum

| Area              | Apa yang Mereka Cek                  |
| ----------------- | ------------------------------------ |
| Pendapatan        | Kelengkapan, waktu, klasifikasi      |
| Biaya             | Pengurang pajak, dokumentasi         |
| PPN               | Kecocokan masukan/keluaran, waktu    |
| Pemotongan        | Tarif yang benar, penyetoran tepat   |
| Pihak terafiliasi | Penentuan harga wajar (arm's length) |
| Aset              | Penyusutan, pelepasan                |
| Payroll           | Perhitungan, pelaporan               |

### Fokus Transfer Pricing

<InfoCard variant="warning" title="Pemeriksaan Transfer Pricing">
Transaksi pihak terafiliasi mendapat pemeriksaan ketat:

**Apa yang diperiksa pemeriksa:**

- Metodologi penentuan harga antarperusahaan
- Studi benchmarking
- Dokumentasi (TP Doc)
- Justifikasi biaya manajemen
- Pembayaran royalti
- Suku bunga pinjaman

**Jika Anda punya transaksi pihak terafiliasi:**

- Siapkan dokumentasi TP di muka
- Pastikan harga wajar (arm's length)
- Dokumentasikan semuanya secara menyeluruh
  </InfoCard>

## Hak Anda Selama Audit

### Hak Wajib Pajak

| Hak                  | Deskripsi                         |
| -------------------- | --------------------------------- |
| Mengetahui cakupan   | Audit harus sesuai cakupan awal   |
| Menerima notifikasi  | Pemberitahuan layak sebelum audit |
| Bantuan profesional  | Gunakan jasa konsultan pajak      |
| Waktu untuk menjawab | Periode minimum yang diamanatkan  |
| Kerahasiaan          | Pemeriksa harus melindungi data   |
| Banding              | Bisa menyanggah temuan            |

### Batas Waktu Audit

| Tahap               | Batas Waktu                            |
| ------------------- | -------------------------------------- |
| Penyerahan dokumen  | Sesuai permintaan (biasanya 7-14 hari) |
| Tanggapan SPHP      | 7 hari kerja                           |
| Penyelesaian audit  | Maksimal 12 bulan                      |
| Pembayaran usai SKP | 1 bulan                                |
| Ajukan keberatan    | 3 bulan dari SKP                       |

## Menangani Temuan Audit

### Strategi Tanggapan

| Situasi            | Pendekatan                   |
| ------------------ | ---------------------------- |
| Setuju temuan      | Terima dan bayar             |
| Setuju sebagian    | Negosiasi, terima poin valid |
| Tidak setuju total | Tanggapi resmi dengan bukti  |
| Celah dokumentasi  | Kumpulkan dukungan tambahan  |

<InfoCard variant="tip" title="Tips Negosiasi">
**Selama proses audit:**

1. **Kooperatif** - Sikap bermusuhan merugikan diri sendiri
2. **Dokumentasikan semuanya** - Catat semua interaksi
3. **Tanggapi segera** - Jangan lewatkan batas waktu
4. **Gunakan tenaga ahli** - Konsultan pajak tahu prosedurnya
5. **Berikan konteks** - Bantu pemeriksa paham bisnis Anda
6. **Terorganisir** - Dokumentasi yang jelas sangat membantu
7. **Tahu hak Anda** - Tapi gunakan secara diplomatis
   </InfoCard>

## Menyanggah Ketetapan

### Proses Keberatan

| Langkah          | Linimasa                 |
| ---------------- | ------------------------ |
| Ajukan keberatan | Dalam 3 bulan sejak SKP  |
| Peninjauan DJP   | Hingga 12 bulan          |
| Keputusan terbit | Terima atau banding lagi |

### Opsi Banding

| Tingkat            | Forum            |
| ------------------ | ---------------- |
| Keberatan          | Kanwil DJP       |
| Banding            | Pengadilan Pajak |
| Peninjauan Kembali | Mahkamah Agung   |

<InfoCard variant="note" title="Pembayaran Selama Banding">
**Penting:** Anda mungkin perlu membayar pajak ketetapan meskipun sedang banding.

Namun, jika Anda mengajukan keberatan:

- Bisa minta pembayaran angsuran
- Denda bisa dihapus jika banding menang
- Bunga berjalan selama periode banding
  </InfoCard>

## Denda dan Sanksi

### Sanksi Administratif

| Pelanggaran               | Denda                                 |
| ------------------------- | ------------------------------------- |
| Kurang bayar (pembetulan) | 2% per bulan (maks 24 bulan)          |
| Kurang bayar (dari audit) | 50% atau 100% dari pajak kurang bayar |
| Terlambat bayar           | 2% per bulan                          |
| Terlambat lapor           | Denda tetap + bunga                   |

### Sanksi Pidana

| Pelanggaran       | Sanksi                    |
| ----------------- | ------------------------- |
| Kealpaan          | Sanksi administratif      |
| Penggelapan pajak | Potensi penuntutan pidana |
| Penipuan          | Penjara + denda           |
| Dokumen palsu     | Sanksi berat              |

## Tips Persiapan Audit

### Praktik Berkelanjutan

| Praktik                        | Manfaat                          |
| ------------------------------ | -------------------------------- |
| Jaga catatan terorganisir      | Tanggapan permintaan lebih cepat |
| Rekonsiliasi rutin             | Temukan masalah lebih awal       |
| Dokumentasikan rasional bisnis | Dukungan untuk pengurang pajak   |
| Jaga catatan kontemporer       | Bukti yang lebih baik            |
| Gunakan penasihat pajak        | Kepatuhan berkelanjutan          |
| Lakukan audit mandiri          | Identifikasi risiko proaktif     |
