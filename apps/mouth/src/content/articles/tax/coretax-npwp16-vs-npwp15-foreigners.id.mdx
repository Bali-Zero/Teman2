## Apa yang Berubah: Dari NPWP 15-Digit ke NPWP 16-Digit

Pada tahun 2022, Kementerian Keuangan Indonesia menerbitkan PMK 112/2022, yang mewajibkan transisi dari NPWP 15-digit lama ke format 16-digit baru. Peraturan ini, yang berlaku sepenuhnya seiring dengan peluncuran sistem CoreTax pada tahun 2025, secara mendasar mengubah cara identifikasi wajib pajak di Indonesia.

Perubahan ini didorong oleh ide sederhana: menyatukan sistem identitas nasional Indonesia. Alih-alih memiliki nomor identitas pajak yang terpisah, pemerintah memutuskan untuk mengintegrasikan sistem pajak dengan database kependudukan (Dukcapil) menggunakan NIK (Nomor Induk Kependudukan), yaitu nomor identitas nasional 16-digit Indonesia.

Bagi orang asing yang tidak memiliki NIK, solusinya berbeda: menambahkan awalan "0" pada NPWP 15-digit yang sudah ada untuk membuat pengenal 16-digit.

## Perbandingan Dua Format NPWP

| Fitur                 | NPWP Lama (15-digit) | NPWP Baru (16-digit)      |
| --------------------- | -------------------- | ------------------------- |
| Panjang               | 15 digit             | 16 digit                  |
| Format (tampilan)     | XX.XXX.XXX.X-XXX.XXX | XXXXXXXXXXXXXXXX          |
| Untuk WNI             | Nomor pajak unik     | NIK (nomor KTP)           |
| Untuk orang asing     | Nomor pajak unik     | "0" + nomor 15-digit lama |
| Untuk badan (PT, CV)  | Nomor pajak unik     | "0" + nomor 15-digit lama |
| Digunakan di CoreTax  | Tidak (sudah usang)  | Ya (wajib)                |
| Digunakan di e-Faktur | Hanya sistem lama    | Wajib untuk faktur baru   |
| Digunakan di e-Bupot  | Hanya sistem lama    | Wajib                     |
| Status per 2026       | Dihapuskan bertahap  | Aktif dan wajib           |

## Bagaimana Struktur NPWP 15-Digit

Memahami format lama membantu Anda memverifikasi nomor baru Anda. NPWP 15-digit lama mengikuti struktur ini:

```
XX.XXX.XXX.X-XXX.XXX
│  │        │  │    │
│  │        │  │    └── Nomor urut (3 digit)
│  │        │  └─────── Kode KPP (3 digit - kantor pajak Anda)
│  │        └────────── Digit pemeriksa (1 digit)
│  └─────────────────── ID wajib pajak unik (6 digit)
└────────────────────── Jenis subjek pajak (2 digit)
```

Dua digit pertama menunjukkan jenis wajib pajak:

- **01-03**: Wajib pajak orang pribadi
- **21-23**: Wajib pajak badan (PT, CV, dll.)
- **31-33**: Kantor cabang

## Bagaimana Cara Kerja NPWP 16-Digit untuk Orang Asing

Bagi warga negara asing (WNA), migrasinya sangat mudah:

**NPWP 16-digit baru Anda = "0" + NPWP 15-digit lama Anda (tanpa titik dan garis strip)**

**Contoh:**

- NPWP Lama: `74.523.891.2-904.000`
- Hapus format: `745238912904000`
- Tambahkan nol di depan: `0745238912904000`
- NPWP 16-digit baru: **0745238912904000**

Ini berlaku untuk:

- Orang asing pribadi (pemegang KITAS/KITAP)
- Badan usaha milik asing (PT PMA)

### Untuk Warga Negara Indonesia (WNI)

Warga negara Indonesia tidak menambahkan angka nol. Sebaliknya, NPWP mereka digantikan sepenuhnya oleh NIK mereka:

- NPWP Lama: `12.345.678.9-012.345`
- NPWP Baru: NIK 16-digit mereka (misalnya, `3174021507920003`)

Inilah sebabnya sistem ini disebut "NPWP berbasis NIK."

## Mengapa Migrasi Ini Penting bagi Bisnis Anda

Perubahan format NPWP bukan sekadar kosmetik. Hal ini memengaruhi hampir setiap interaksi pajak:

### 1. Login CoreTax

Anda tidak bisa login ke CoreTax dengan NPWP 15-digit lama Anda. Sistem memerlukan format 16-digit. Jika Anda mencoba format lama, Anda akan mendapatkan pesan error "kredensial tidak valid."

### 2. Pembuatan Faktur (e-Faktur)

Semua faktur pajak baru harus menggunakan NPWP 16-digit untuk penjual maupun pembeli. Jika klien Anda memberikan NPWP 15-digit lama, sistem e-Faktur akan menolaknya.

### 3. Bukti Potong Pajak (e-Bupot)

Saat menerbitkan bukti potong pajak untuk PPh 21, PPh 23, atau PPh 26, Anda harus menggunakan NPWP 16-digit penerima.

### 4. Transaksi Bank dan Keuangan

Bank dan lembaga keuangan sekarang meminta NPWP 16-digit untuk:

- Pembukaan rekening bank korporat
- Pengajuan pinjaman
- Transfer kawat internasional di atas Rp 100 juta
- Pelaporan pemotongan pajak ke DJP

### 5. Perizinan Pemerintah (OSS)

Sistem OSS (Online Single Submission) untuk izin usaha telah diperbarui untuk menerima NPWP 16-digit. Saat memperbarui NIB atau mengajukan izin baru, gunakan format 16-digit.

## Panduan Migrasi Langkah demi Langkah untuk Orang Asing

### Langkah 1: Tentukan NPWP Baru Anda

Ambil NPWP 15-digit lama Anda dan tambahkan "0" di depannya. Hapus semua titik dan garis strip.

### Langkah 2: Verifikasi di CoreTax

1. Buka [coretaxdjp.pajak.go.id](https://coretaxdjp.pajak.go.id)
2. Masukkan NPWP 16-digit Anda
3. Jika ini pertama kalinya, klik "Lupa Password" untuk mengatur kata sandi baru
4. Masukkan EFIN (Electronic Filing Identification Number) Anda
5. Periksa email terdaftar Anda untuk tautan reset kata sandi
6. Atur kata sandi baru dan login

### Langkah 3: Verifikasi Data Profil Anda

Setelah login ke CoreTax:

1. Navigasi ke "Profil Wajib Pajak"
2. Verifikasi bahwa data pribadi Anda sudah benar:
   - Nama lengkap (sesuai paspor)
   - Nomor paspor
   - Nomor KITAS/KITAP
   - Alamat terdaftar di Indonesia
   - Alamat email
   - Nomor telepon Indonesia
3. Jika ada data yang salah, catat ketidaksesuaian tersebut

### Langkah 4: Perbarui Data yang Salah

Jika data profil Anda perlu diperbaiki:

1. **Perbaikan minor** (email, telepon): Dapat diperbarui langsung di CoreTax di bawah Profil > Edit
2. **Perbaikan mayor** (nama, nomor paspor, alamat): Harus dilakukan di KPP tempat Anda terdaftar
3. **Dokumen yang diperlukan untuk kunjungan ke KPP:**
   - Paspor (asli + fotokopi)
   - KITAS/KITAP (asli + fotokopi)
   - Kartu NPWP lama (jika ada)
   - Surat Keterangan Domisili
   - Akta perusahaan (untuk direktur PT PMA)

### Langkah 5: Perbarui NPWP Anda di Mana Saja

Setelah memverifikasi profil CoreTax Anda, perbarui NPWP 16-digit Anda di:

| Tempat Memperbarui             | Cara Memperbarui                      | Prioritas |
| ------------------------------ | ------------------------------------- | --------- |
| Rekening bank                  | Kunjungi cabang bank dengan NPWP baru | Tinggi    |
| Catatan perusahaan (PT PMA)    | Perbarui melalui AHU/OSS              | Tinggi    |
| Klien/vendor untuk faktur      | Kirim surat pemberitahuan             | Tinggi    |
| Aplikasi e-Faktur              | Perbarui di pengaturan                | Tinggi    |
| Sistem payroll (jika karyawan) | Beritahu departemen HR                | Sedang    |
| Polis asuransi                 | Hubungi penyedia asuransi             | Rendah    |
| Perjanjian sewa                | Ubah dengan pemilik properti          | Rendah    |

## Masalah Umum Selama Migrasi

### Masalah 1: EFIN Tidak Tersedia

Anda memerlukan EFIN untuk mereset kata sandi CoreTax Anda, tetapi banyak wajib pajak yang kehilangan atau tidak pernah menerima EFIN mereka.

**Solusi:**

- Hubungi Kring Pajak di 1500-200 dengan menyiapkan NPWP Anda
- Kunjungi KPP terdaftar Anda dengan membawa dokumen identitas
- EFIN dapat diterbitkan kembali di tempat di KPP

### Masalah 2: Email Terdaftar Sudah Tidak Aktif

Email reset kata sandi dikirim ke alamat email lama yang sudah tidak Anda akses lagi.

**Solusi:**

- Kunjungi KPP Anda dengan membawa dokumen identitas
- Minta pembaruan email
- Setelah email diperbarui, ulangi proses reset kata sandi
- Waktu pengerjaan: pemrosesan di hari yang sama di KPP

### Masalah 3: Ketidakcocokan Pendaftaran KPP

NPWP Anda terdaftar di KPP di Jakarta, tetapi Anda sekarang tinggal di Bali.

**Solusi:**

- Anda dapat mengunjungi KPP mana pun untuk pertanyaan terkait NPWP
- Namun, perubahan resmi (alamat, email) mungkin memerlukan KPP terdaftar Anda
- Pertimbangkan untuk mengajukan mutasi KPP ke lokasi Anda saat ini
- Proses mutasi memakan waktu sekitar 5-10 hari kerja

### Masalah 4: NPWP Ganda (Pribadi dan Perusahaan)

Jika Anda adalah direktur PT PMA, Anda memiliki dua NPWP: pribadi dan perusahaan. Keduanya perlu dimigrasi.

**Solusi:**

- NPWP Pribadi: "0" + NPWP pribadi 15-digit lama
- NPWP Perusahaan: "0" + NPWP perusahaan 15-digit lama
- Keduanya harus diaktifkan secara terpisah di CoreTax
- Masing-masing memiliki EFIN sendiri

## Dampak pada Operasional PT PMA

Bagi perusahaan PT PMA, migrasi NPWP memiliki implikasi operasional khusus:

### Pelaporan Pajak

Semua pelaporan pajak bulanan dan tahunan sekarang menggunakan NPWP perusahaan 16-digit:

| Jenis Pelaporan      | Format yang Dibutuhkan | Tenggat Waktu               |
| -------------------- | ---------------------- | --------------------------- |
| SPT Masa PPh 21      | NPWP 16-digit          | Tanggal 20 bulan berikutnya |
| SPT Masa PPh 23/26   | NPWP 16-digit          | Tanggal 20 bulan berikutnya |
| SPT Masa PPN         | NPWP 16-digit          | Akhir bulan berikutnya      |
| SPT Tahunan Badan    | NPWP 16-digit          | 30 April                    |
| Faktur e-Faktur      | NPWP 16-digit          | Real-time                   |
| Bukti Potong e-Bupot | NPWP 16-digit          | Sama seperti SPT Masa       |

### Pajak Karyawan (PPh 21)

Untuk pelaporan PPh 21, Anda memerlukan NPWP 16-digit (atau NIK) dari setiap karyawan. Ini berarti:

- Karyawan Indonesia: Gunakan NIK mereka
- Karyawan asing: Gunakan "0" + NPWP 15-digit mereka
- Karyawan tanpa NPWP: Gunakan NIK (untuk WNI) atau nomor paspor (untuk WNA) sebagai pengenal sementara, tetapi perhatikan bahwa tarif pemotongan yang lebih tinggi (tambahan 20%) tetap berlaku bagi mereka yang tidak memiliki NPWP valid.

### Komunikasi Vendor dan Klien

PT PMA Anda harus menyampaikan NPWP 16-digit baru kepada semua mitra bisnis. Contoh draf surat pemberitahuan:

> Yth. [Nama Klien/Vendor],
>
> Sehubungan dengan migrasi sistem CoreTax Indonesia, NPWP perusahaan kami telah diperbarui menjadi format 16-digit. Mohon gunakan data berikut untuk semua dokumen pajak dan faktur di masa mendatang:
>
> Nama Perusahaan: [PT Nama Perusahaan Anda]
> NPWP Baru (16-digit): [0XXXXXXXXXXXXXXX]
> NPWP Sebelumnya (15-digit): [XX.XXX.XXX.X-XXX.XXX]
>
> Detail perusahaan lainnya tetap tidak berubah.

## Pertanyaan yang Sering Diajukan

### Bagaimana cara mengubah NPWP 15-digit lama saya menjadi 16 digit?

Untuk orang asing, tambahkan angka 0 di depan NPWP 15-digit lama Anda. Sebagai contoh, jika NPWP lama Anda adalah 12.345.678.9-012.345, maka NPWP 16-digit baru Anda adalah 0123456789012345 (tanpa titik atau garis strip). Warga negara Indonesia menggunakan NIK 16-digit mereka sebagai gantinya.

### Apakah NPWP 15-digit lama masih berlaku?

NPWP 15-digit lama tidak lagi diterima untuk login CoreTax, e-Faktur, atau pelaporan pajak baru. Namun, pendaftaran pajak Anda tetap valid. Anda hanya perlu menggunakan format 16-digit untuk selanjutnya.

### Apakah saya perlu mengunjungi kantor pajak untuk memigrasi NPWP saya?

Tidak selalu. Format 16-digit dibuat secara otomatis (0 + nomor lama). Namun, jika Anda mengalami masalah login atau kesalahan ketidakcocokan NIK di CoreTax, Anda mungkin perlu mengunjungi KPP terdaftar untuk validasi manual.

### Apakah catatan pajak lama saya akan hilang setelah migrasi?

Tidak. Semua pelaporan, pembayaran, dan catatan pajak historis tetap terjaga. Migrasi hanya mengubah format pengenal. Pelaporan SPT sebelumnya dan kredit pajak Anda tetap tertaut ke akun Anda.

### Apa yang terjadi jika klien menggunakan NPWP 15-digit lama saya pada faktur?

Sistem e-Faktur akan menolak faktur dengan NPWP 15-digit. Mintalah klien Anda untuk memperbarui NPWP Anda ke format 16-digit. Jika mereka menerbitkan Faktur Pajak dengan format yang salah, faktur tersebut akan dianggap tidak valid dan kredit pajak masukan PPN tidak dapat diklaim.
