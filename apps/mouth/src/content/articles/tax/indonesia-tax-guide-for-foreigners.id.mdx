<InfoCard variant="important" title="Aturan 183 Hari">
183 hari tersebut tidak harus berurutan. Indonesia menghitung hari dalam **periode 12 bulan apa pun**, yang dapat mencakup tahun kalender yang berbeda. Hari kedatangan dan keberangkatan keduanya dihitung sebagai hari penuh.

Contoh: Jika Anda tiba 1 Oktober 2024, dan menghitung maju 12 bulan hingga 30 September 2025—total hari di Indonesia selama periode ini menentukan residensi.

</InfoCard>

<InfoCard variant="tip" title="Cara Kerja Pajak Progresif">
Anda tidak membayar 35% atas seluruh penghasilan Anda jika berpenghasilan di atas Rp 5 miliar. Setiap braket hanya berlaku untuk penghasilan di dalam rentang tersebut.

**Contoh:** Jika Anda berpenghasilan Rp 300 juta setahun:

- Rp 60 jt pertama kena 5% = Rp 3.000.000
- Rp 190 jt berikutnya (60 jt-250 jt) kena 15% = Rp 28.500.000
- Rp 50 jt berikutnya (250 jt-300 jt) kena 25% = Rp 12.500.000
- **Total pajak: Rp 44.000.000** (tarif efektif: ~14,7%)

## Kalkulator Pajak

<Calculator
  title="Kalkulator Pajak Penghasilan Indonesia"
  description="Estimasi pajak penghasilan tahunan Anda berdasarkan gaji dan tunjangan"
  fields={[
    {
      id: "monthly-salary",
      label: "Gaji Bruto Bulanan",
      type: "number",
      defaultValue: 50000000,
      min: 0,
      step: 1000000,
      suffix: "IDR"
    },
    {
      id: "allowances",
      label: "Tunjangan Bulanan (perumahan, transport, dll.)",
      type: "number",
      defaultValue: 15000000,
      min: 0,
      step: 1000000,
      suffix: "IDR"
    },
    {
      id: "bonus-months",
      label: "Bonus (dalam bulan gaji)",
      type: "select",
      options: [
        { value: "0", label: "Tanpa bonus" },
        { value: "1", label: "1 bulan (THR)" },
        { value: "2", label: "2 bulan" },
        { value: "3", label: "3 bulan" }
      ],
      defaultValue: "1"
    },
    {
      id: "marital-status",
      label: "Status Pernikahan",
      type: "select",
      options: [
        { value: "single", label: "Lajang (TK/0)" },
        { value: "married-0", label: "Menikah, tanpa anak (K/0)" },
        { value: "married-1", label: "Menikah, 1 anak (K/1)" },
        { value: "married-2", label: "Menikah, 2 anak (K/2)" },
        { value: "married-3", label: "Menikah, 3 anak (K/3)" }
      ],
      defaultValue: "single"
    },
    {
      id: "has-npwp",
      label: "Apakah Anda punya NPWP?",
      type: "checkbox",
      defaultValue: true
    }
  ]}
  calculateResult={(values) => {
    const monthly = Number(values['monthly-salary']) + Number(values['allowances']);
    const bonusMonths = Number(values['bonus-months']);
    const annual = (monthly * 12) + (Number(values['monthly-salary']) * bonusMonths);

    // PTKP (non-taxable income)
    const ptkpMap = {
      'single': 54000000,
      'married-0': 58500000,
      'married-1': 63000000,
      'married-2': 67500000,
      'married-3': 72000000
    };
    const ptkp = ptkpMap[values['marital-status']] || 54000000;

    // Calculate taxable income
    let taxableIncome = annual - ptkp;
    if (taxableIncome < 0) taxableIncome = 0;

    // Calculate tax
    let tax = 0;
    let remaining = taxableIncome;

    // Bracket 1: 0-60M at 5%
    if (remaining > 0) {
      const bracket1 = Math.min(remaining, 60000000);
      tax += bracket1 * 0.05;
      remaining -= bracket1;
    }

    // Bracket 2: 60M-250M at 15%
    if (remaining > 0) {
      const bracket2 = Math.min(remaining, 190000000);
      tax += bracket2 * 0.15;
      remaining -= bracket2;
    }

    // Bracket 3: 250M-500M at 25%
    if (remaining > 0) {
      const bracket3 = Math.min(remaining, 250000000);
      tax += bracket3 * 0.25;
      remaining -= bracket3;
    }

    // Bracket 4: 500M-5B at 30%
    if (remaining > 0) {
      const bracket4 = Math.min(remaining, 4500000000);
      tax += bracket4 * 0.30;
      remaining -= bracket4;
    }

    // Bracket 5: >5B at 35%
    if (remaining > 0) {
      tax += remaining * 0.35;
    }

    // Non-NPWP penalty: 20% higher
    if (!values['has-npwp']) {
      tax = tax * 1.2;
    }

    const effectiveRate = annual > 0 ? (tax / annual * 100).toFixed(1) : 0;
    const monthlyTax = tax / 12;
    const takeHome = annual - tax;

    return {
      total: tax,
      breakdown: [
        { label: "Penghasilan Bruto Tahunan", amount: annual },
        { label: `PTKP (${values['marital-status']})`, amount: -ptkp },
        { label: "Penghasilan Kena Pajak", amount: taxableIncome },
        { label: "Pajak Tahunan (PPh 21)", amount: tax },
        { label: "Pemotongan Pajak Bulanan", amount: monthlyTax },
        { label: "Pendapatan Bersih Tahunan", amount: takeHome }
      ],
      currency: "IDR",
      note: `Tarif pajak efektif: ${effectiveRate}%${!values['has-npwp'] ? ' (termasuk penalti 20% tanpa NPWP)' : ''}`
    };

}}
ctaText="Konsultasi dengan Penasihat Pajak"
ctaAction={() => window.open('/contact?service=tax-consultation', '\_blank')}

## PTKP: Penghasilan Tidak Kena Pajak

<GlossaryTerm
  term="PTKP"
  definition="Penghasilan Tidak Kena Pajak - ambang batas penghasilan yang tidak dikenakan pajak yang mengurangi penghasilan kena pajak Anda berdasarkan situasi pribadi."
  indonesian="Penghasilan Tidak Kena Pajak"
  relatedTerms={["PPh 21", "SPT", "NPWP"]}
>
  PTKP
</GlossaryTerm>
adalah jatah bebas pajak Anda. Ini dikurangkan dari penghasilan bruto sebelum
pajak dihitung.

| ------------------------ | ---- | ------------- |
| Lajang, tanpa tanggungan | TK/0 | Rp 54.000.000 |
| Lajang + 1 tanggungan    | TK/1 | Rp 58.500.000 |
| Lajang + 2 tanggungan    | TK/2 | Rp 63.000.000 |
| Lajang + 3 tanggungan    | TK/3 | Rp 67.500.000 |
| Menikah, tanpa anak      | K/0  | Rp 58.500.000 |
| Menikah + 1 anak         | K/1  | Rp 63.000.000 |
| Menikah + 2 anak         | K/2  | Rp 67.500.000 |
| Menikah + 3 anak         | K/3  | Rp 72.000.000 |

<InfoCard variant="note" title="Definisi Tanggungan">

  Maksimal 3 tanggungan yang bisa diklaim

## Tax Treaty: Menghindari Pajak Berganda

Indonesia memiliki <GlossaryTerm term="Tax Treaty" definition="Perjanjian Penghindaran Pajak Berganda (P3B) - kesepakatan antara Indonesia dan negara lain untuk mencegah penghasilan yang sama dikenakan pajak dua kali." indonesian="Perjanjian Penghindaran Pajak Berganda">tax treaty</GlossaryTerm> dengan lebih dari 70 negara untuk mencegah pajak berganda. - **Pengurangan tarif pemotongan** atas dividen, bunga, royalti

- **Aturan tie-breaker** untuk konflik residensi

## Situasi Pajak Khusus

### Pekerja Remote / Digital Nomad

<InfoCard variant="warning" title="Area Abu-Abu Pajak Digital Nomad">
Indonesia tidak memiliki rezim pajak khusus untuk "digital nomad". Secara teknis:

- Pekerjaan yang dilakukan di Indonesia = berpotensi menjadi penghasilan sumber Indonesia
- 183+ hari = residen pajak, penghasilan seluruh dunia kena pajak
- Visa turis tidak mengubah kewajiban pajak Anda

**Realitas**: Banyak digital nomad tidak mendaftar. Ini berisiko. Kantor pajak semakin sadar akan keberadaan pekerja remote.

**Pendekatan paling aman**: Tinggal di bawah 183 hari, atau pertimbangkan pendaftaran sukarela jika tinggal lebih lama.

</InfoCard>

### Pemegang Visa Second Home

Visa **Second Home** yang baru (5-10 tahun) tidak secara otomatis menciptakan residensi pajak, tetapi:

- Tinggal 183+ hari tetap memicu residensi
- Anda mungkin perlu membuktikan penghasilan tidak berasal dari Indonesia
- Pertimbangkan pendaftaran NPWP sukarela untuk keperluan perbankan/properti

### Ekspatriat dalam Penugasan

Jika pemberi kerja di negara asal menugaskan Anda ke Indonesia:

- Biasanya menjadi residen pajak Indonesia
- Mungkin berhak atas **tax equalization** (pemberi kerja menanggung selisih)
- Cek pengaturan **pajak hipotetis** (hypothetical tax)
- Koordinasikan dengan penasihat pajak negara asal dan negara tujuan

## Kesalahan Umum yang Harus Dihindari

<InfoCard variant="error" title="Kesalahan Pajak yang Merugikan">
**1. Tidak Membuat NPWP**
Tambahan pajak 20% tanpa NPWP. Buat segera setelah Anda menjadi residen.

**2. Melewatkan Batas Waktu Lapor**
SPT paling lambat 31 Maret. Terlambat = denda. Pasang pengingat.

**3. Mengabaikan Penghasilan Luar Negeri**
Residen harus melaporkan penghasilan seluruh dunia. Rekening bank luar negeri, investasi, penghasilan sewa—semuanya kena pajak.

**4. Salah Jenis Formulir**
Menggunakan 1770SS padahal punya banyak sumber penghasilan. Gunakan formulir yang benar untuk situasi Anda.

**5. Tidak Mengklaim Manfaat Treaty**
Jika Anda dipotong 20% padahal negara Anda punya treaty untuk 10%, Anda membayar lebih.

**6. Tidak Menyimpan Catatan**
Simpan slip gaji, Bukti Potong, rekening koran selama 10 tahun. Kantor pajak bisa melakukan audit.

</InfoCard>
