<InfoCard variant="important" title="Aturan 183 Hari">
183 hari tidak perlu berurutan. Indonesia menghitung hari dalam periode **12 bulan** apa pun, yang bisa melintasi tahun kalender. Hari masuk dan keluar dihitung sebagai hari penuh.

Contoh: Jika Anda tiba 1 Oktober 2024, dan menghitung mundur 12 bulan ke 30 September 2026—total hari di Indonesia selama periode ini menentukan kependudukan.

</InfoCard>

<InfoCard variant="tip" title="Cara Kerja Pajak Progresif">
Anda tidak membayar 35% pada semua penghasilan Anda jika berpenghasilan di atas IDR 5 miliar. Setiap bracket hanya berlaku untuk penghasilan dalam rentang tersebut.

**Contoh:** Jika Anda berpenghasilan IDR 300 juta per tahun:

- IDR 60M pertama dipajaki 5% = IDR 3.000.000
- IDR 190M berikutnya (60M-250M) dipajaki 15% = IDR 28.500.000
- IDR 50M berikutnya (250M-300M) dipajaki 25% = IDR 12.500.000
- **Total pajak: IDR 44.000.000** (tarif efektif: ~14,7%)

    },
    {

        { value: "married-0", label: "Menikah, tidak punya anak (K/0)" },
        { value: "married-1", label: "Menikah, 1 anak (K/1)" },
        { value: "married-2", label: "Menikah, 2 anak (K/2)" },
        { value: "married-3", label: "Menikah, 3 anak (K/3)" }
      ],

      id: "has-npwp",

      type: "checkbox",

  calculateResult={(values) => {
    const monthly = Number(values['monthly-salary']) + Number(values['allowances']);
    const bonusMonths = Number(values['bonus-months']);
    const annual = (monthly * 12) + (Number(values['monthly-salary']) * bonusMonths);

    // PTKP (penghasilan tidak kena pajak)
    const ptkpMap = {
      'single': 54000000,
      'married-0': 58500000,
      'married-1': 63000000,
      'married-2': 67500000,
      'married-3': 72000000
    };
    const ptkp = ptkpMap[values['marital-status']] || 54000000;

    // Hitung penghasilan kena pajak
    let taxableIncome = annual - ptkp;
    if (taxableIncome < 0) taxableIncome = 0;

    // Hitung pajak
    let tax = 0;
    let remaining = taxableIncome;

    // Bracket 1: 0-60M at 5%
    if (remaining > 0) {
      const bracket1 = Math.min(remaining, 60000000);
      tax += bracket1 * 0.05;
      remaining -= bracket1;
    }

    // Bracket 2: 60M-250M at 15%
    if (remaining > 0) {
      const bracket2 = Math.min(remaining, 190000000);
      tax += bracket2 * 0.15;
      remaining -= bracket2;
    }

    // Bracket 3: 250M-500M at 25%
    if (remaining > 0) {
      const bracket3 = Math.min(remaining, 250000000);
      tax += bracket3 * 0.25;
      remaining -= bracket3;
    }

    // Bracket 4: 500M-5B at 30%
    if (remaining > 0) {
      const bracket4 = Math.min(remaining, 4500000000);
      tax += bracket4 * 0.30;
      remaining -= bracket4;
    }

    // Bracket 5: >5B at 35%
    if (remaining > 0) {
      tax += remaining * 0.35;
    }

    // Sanksi Non-NPWP: 20% lebih tinggi
    if (!values['has-npwp']) {
      tax = tax * 1.2;
    }

    const effectiveRate = annual > 0 ? (tax / annual * 100).toFixed(1) : 0;
    const monthlyTax = tax / 12;
    const takeHome = annual - tax;

    return {
      total: tax,
      breakdown: [
        { label: "Penghasilan Tahunan Kotor", amount: annual },
        { label: `PTKP (${values['marital-status']})`, amount: -ptkp },
        { label: "Penghasilan Kena Pajak", amount: taxableIncome },
        { label: "Pajak Tahunan (PPh 21)", amount: tax },
        { label: "Potongan Pajak Bulanan", amount: monthlyTax },
        { label: "Penghasilan Bersih Tahunan", amount: takeHome }
      ],
      currency: "IDR",
      note: `Tarif pajak efektif: ${effectiveRate}%${!values['has-npwp'] ? ' (termasuk sanksi Non-NPWP 20%)' : ''}`
    };

}}

## PTKP: Penghasilan Tidak Kena Pajak

<GlossaryTerm
  term="PTKP"
  definition="Penghasilan Tidak Kena Pajak - ambang batas penghasilan tidak kena pajak yang mengurangi penghasilan kena pajak Anda berdasarkan kondisi pribadi."

| Lajang + 2 tanggungan | TK/2 | IDR 63.000.000 |

## Situasi Pajak Khusus

### Pekerja Remote / Digital Nomad

<InfoCard variant="warning" title="Area Abu-abu Pajak Digital Nomad">
Indonesia tidak memiliki rezim pajak "digital nomad" khusus. Secara teknis:

- Pekerjaan yang dilakukan di Indonesia = berpotensi penghasilan sumber Indonesia
- 183+ hari = penduduk pajak, penghasilan seluruh dunia kena pajak
- Visa turis tidak mengubah kewajiban pajak

**Realita**: Banyak digital nomad tidak mendaftar. Ini adalah risiko. Kantor pajak semakin sadar tentang pekerja remote.

**Pendekatan paling aman**: Tetap di bawah 183 hari, atau pertimbangkan pendaftaran sukarela jika tinggal lebih lama.

</InfoCard>

### Pemegang Second Home Visa

Visa **Second Home** baru (5 tahun pertama pemberian, dapat diperpanjang hingga maksimal kumulatif 10 tahun) tidak otomatis menciptakan kependudukan pajak, tetapi:

- 183+ hari masih memicu kependudukan
- Anda mungkin perlu membuktikan penghasilan tidak dari Indonesia
- Pertimbangkan pendaftaran NPWP sukarela untuk perbankan/properti

### Ekspatriat dalam Tugas

Jika pemberi kerja negara asal Anda menugaskan Anda ke Indonesia:

- Biasanya menjadi penduduk pajak Indonesia
- Mungkin berhak atas **penyesuaian pajak** (pemberi kerja menutupi perbedaan)
- Cek untuk pengaturan **pajak hipotetis**
- Koordinasikan dengan konsultan pajak negara asal dan negara tuan rumah

## Kesalahan Umum yang Harus Dihindari

<InfoCard variant="error" title="Kesalahan Pajak yang Menghabiskan Uang">
**1. Tidak Mendapatkan NPWP**
Penambahan pajak 20% tanpa NPWP. Dapatkan segera setelah Anda menjadi penduduk.

**2. Melewatkan Jatuh Tempo Pelaporan**
SPT jatuh tempo 31 Maret. Terlambat = sanksi. Atur pengingat.

**3. Mengabaikan Penghasilan Asing**
Penduduk harus melaporkan penghasilan seluruh dunia. Rekening bank asing, investasi, penghasilan sewa—semua kena pajak.

**4. Jenis Formulir Salah**
Menggunakan 1770SS ketika Anda memiliki beberapa sumber penghasilan. Gunakan formulir yang benar untuk situasi Anda.

**5. Tidak Mengeklaim Manfaat Perjanjian**
Jika Anda dipajaki 20% tetapi negara Anda memiliki perjanjian untuk 10%, Anda membayar berlebihan.

**6. Tidak Ada Catatan**
Simpan slip gaji, Bukti Potong, laporan bank selama 10 tahun. Kantor pajak bisa melakukan audit.

</InfoCard>
