## PPh 21: Pajak Penghasilan Karyawan

### Apa itu PPh 21?

<InfoCard variant="note" title="Pemotongan untuk Karyawan">
**PPh 21** adalah pajak penghasilan yang dipotong dari kompensasi karyawan:

- Gaji dan upah
- Bonus dan tunjangan
- Pembayaran pesangon
- Honorarium direksi
- Honorarium konsultan (perorangan)

Pengusaha memotong dan menyetorkan ke kantor pajak.

</InfoCard>

### Tarif PPh 21 (Progresif)

| Penghasilan Kena Pajak (IDR/tahun) | Tarif |
| ------------------------- | ---- |
| 0 - 60 juta               | 5%   |
| 60M - 250 juta            | 15%  |
| 250M - 500 juta           | 25%  |
| 500M - 5 miliar           | 30%  |
| Di atas 5 miliar          | 35%  |

### Kalkulator PPh 21

  title="Estimasi Bulanan PPh 21"
  description="Estimasi pemotongan karyawan bulanan"
  fields={[

  calculateResult={(values) => {
    const monthly = Number(values.gross);
    const annual = monthly * 12;

    // PTKP (Penghasilan Tidak Kena Pajak) untuk 2024
    const ptkp = {
      "tk0": 54000000,
      "k0": 58500000,
      "k1": 63000000,
      "k2": 67500000,
      "k3": 72000000
    };

    // Biaya Jabatan (maksimal 5% atau 6M/tahun)
    const biayaJabatan = Math.min(annual * 0.05, 6000000);

    // Penghasilan kena pajak
    const taxable = Math.max(0, annual - biayaJabatan - ptkp[values.status]);

    // Perhitungan pajak progresif
    let tax = 0;
    let remaining = taxable;

    if (remaining > 0) {
      const bracket1 = Math.min(remaining, 60000000);
      tax += bracket1 * 0.05;
      remaining -= bracket1;
    }
    if (remaining > 0) {
      const bracket2 = Math.min(remaining, 190000000);
      tax += bracket2 * 0.15;
      remaining -= bracket2;
    }
    if (remaining > 0) {
      const bracket3 = Math.min(remaining, 250000000);
      tax += bracket3 * 0.25;
      remaining -= bracket3;
    }
    if (remaining > 0) {
      const bracket4 = Math.min(remaining, 4500000000);
      tax += bracket4 * 0.30;
      remaining -= bracket4;
    }
    if (remaining > 0) {
      tax += remaining * 0.35;
    }

    const monthlyTax = tax / 12;

    return {
      total: Math.round(monthlyTax),
      breakdown: [
        { label: "Gaji Tahunan", amount: annual },
        { label: "Biaya Jabatan", amount: biayaJabatan },
        { label: "PTKP", amount: ptkp[values.status] },
        { label: "Penghasilan Kena Pajak", amount: Math.max(0, taxable) },
        { label: "PPh 21 Tahunan", amount: Math.round(tax) },
        { label: "PPh 21 Bulanan", amount: Math.round(monthlyTax) }
      ],
      currency: "IDR",
      note: "Perhitungan perkiraan"
    };

## PPh 26: Pajak Bukan Penduduk

### Apa itu PPh 26?

<InfoCard variant="warning" title="Pembayaran ke Orang Asing">
**PPh 26** berlaku untuk pembayaran yang dilakukan kepada **bukan penduduk** (orang asing atau entitas):

- Tarif standar: **20%**
- Dapat dikurangi oleh **perjanjian pajak**
- Berlaku untuk: layanan, dividen, bunga, royalti
- Dipotong oleh pembayar Indonesia

</InfoCard>

### Tarif Perjanjian Umum

| Negara     | Layanan  | Dividen   | Bunga      | Royalti    |
| ---------- | -------- | --------- | ---------- | ---------- |
| Singapura  | 15%      | 10/15%    | 10%        | 15%        |
| USA        | 15%      | 10/15%    | 10%        | 10%        |
| Inggris    | 15%      | 10/15%    | 10%        | 15%        |
| Australia  | 15%      | 15%       | 10%        | 15%        |
| Jepang     | 15%      | 10/15%    | 10%        | 10%        |
| Tanpa perjanjian | 20%      | 20%       | 20%        | 20%        |

### Surat Keterangan Domisili (SKD)

Untuk menerapkan tarif perjanjian, penerima asing harus menyediakan:

- **Formulir DGT-1** (Surat Keterangan Domisili)
- Diselesaikan oleh penerima
- Disahkan oleh otoritas pajak
- Berlaku selama 12 bulan

## Sertifikat Potong Pajak

### Diberikan kepada Penerima

Ketika Anda memotong pajak, Anda harus memberikan **Bukti Potong** (sertifikat potong pajak):

| Jenis Pajak | Sertifikat             |
| ----------- | ---------------------- |
| PPh 21      | Bukti Potong 1721-A1/A2 |
| PPh 23      | Bukti Potong PPh 23     |
| PPh 26      | Bukti Potong PPh 26     |
| PPh 4(2)    | Bukti Potong PPh 4(2)   |

Penerima menggunakan ini untuk:

- Mengklaim kredit pajak
- Melaporkan SPT mereka sendiri
- Mendukung pengurangan biaya

## Kesalahan Umum

| Kesalahan                    | Dampak                             |
| ---------------------------- | ---------------------------------- |
| Lupa memotong                | Sanksi keterlambatan + bunga       |

| Prosedur perjanjian hilang   | Tarif 20% berlaku alih-alih tarif perjanjian |
