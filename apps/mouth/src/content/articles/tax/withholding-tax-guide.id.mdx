## PPh 21: Pajak Penghasilan Karyawan

### Apa itu PPh 21?

<InfoCard variant="note" title="Pemotongan Penghasilan Karyawan">
**PPh 21** adalah pajak penghasilan yang dipotong dari kompensasi karyawan:

- Gaji dan upah
- Bonus dan tunjangan
- Pembayaran pesangon
- Biaya direktur
- Biaya konsultan (individu)

Pemberi kerja memotong dan menyetorkan ke kantor pajak.

</InfoCard>

### Tarif PPh 21 (Progresif)

| Pendapatan Kena Pajak (IDR/tahun) | Tarif |
| --------------------------------- | ----- |
| 0 - 60 juta                       | 5%    |
| 60 juta - 250 juta                | 15%   |
| 250 juta - 500 juta               | 25%   |
| 500 juta - 5 miliar               | 30%   |
| Lebih dari 5 miliar               | 35%   |

### Kalkulator PPh 21

<Calculator
  title="Estimasi PPh 21 Bulanan"
  description="Estimasi pemotongan penghasilan karyawan bulanan"
  fields={[
    {
      id: "gross",
      label: "Gaji Kotor Bulanan (IDR)",
      type: "number",
      defaultValue: 25000000,
      min: 0,
      step: 1000000,
      suffix: "IDR"
    },
    {
      id: "status",
      label: "Status Perkawinan",
      type: "select",
      options: [
        { value: "tk0", label: "Lajang, tidak memiliki tanggungan (TK/0)" },
        { value: "k0", label: "Menikah, tidak memiliki anak (K/0)" },
        { value: "k1", label: "Menikah, 1 anak (K/1)" },
        { value: "k2", label: "Menikah, 2 anak (K/2)" },
        { value: "k3", label: "Menikah, 3 anak (K/3)" }
      ],
      defaultValue: "tk0"
    }
  ]}
  calculateResult={(values) => {
    const monthly = Number(values.gross);
    const annual = monthly * 12;

    // PTKP (Penghasilan Tidak Kena Pajak) untuk 2024
    const ptkp = {
      "tk0": 54000000,
      "k0": 58500000,
      "k1": 63000000,
      "k2": 67500000,
      "k3": 72000000
    };

    // Biaya Jabatan (maks 5% 6 juta/tahun)
    const biayaJabatan = Math.min(annual * 0.05, 6000000);

    // Pendapatan Kena Pajak
    const taxable = Math.max(0, annual - biayaJabatan - ptkp[values.status]);

    // Perhitungan pajak progresif
    let tax = 0;
    let remaining = taxable;

    if (remaining > 0) {
      const bracket1 = Math.min(remaining, 60000000);
      tax += bracket1 * 0.05;
      remaining -= bracket1;
    }
    if (remaining > 0) {
      const bracket2 = Math.min(remaining, 190000000);
      tax += bracket2 * 0.15;
      remaining -= bracket2;
    }
    if (remaining > 0) {
      const bracket3 = Math.min(remaining, 250000000);
      tax += bracket3 * 0.25;
      remaining -= bracket3;
    }
    if (remaining > 0) {
      const bracket4 = Math.min(remaining, 4500000000);
      tax += bracket4 * 0.30;
      remaining -= bracket4;
    }
    if (remaining > 0) {
      tax += remaining * 0.35;
    }

    const monthlyTax = tax / 12;

    return {
      total: Math.round(monthlyTax),
      breakdown: [
        { label: "Tahunan Kotor", amount: annual },
        { label: "Biaya Jabatan", amount: biayaJabatan },
        { label: "PTKP", amount: ptkp[values.status] },
        { label: "Pendapatan Kena Pajak", amount: Math.max(0, taxable) },
        { label: "PPh 21 Tahunan", amount: Math.round(tax) },
        { label: "PPh 21 Bulanan", amount: Math.round(monthlyTax) }
      ],
      currency: "IDR",
      note: "Perhitungan perkiraan"
    };

}}

## PPh 26: Pajak Non-Residen

### Apa itu PPh 26?

<InfoCard variant="warning" title="Pembayaran Kepada Orang Asing">
**PPh 26** berlaku untuk pembayaran kepada **non-residen** (orang atau badan hukum asing):

- Tarif standar: **20%**
- Dapat dikurangi oleh **perjanjian pajak**
- Berlaku untuk: jasa, dividen, bunga, royalti
- Dipotong oleh pembayar Indonesia
  </InfoCard>

### Tarif Perjanjian Pajak yang Umum

| Negara           | Jasa | Dividen | Bunga | Royalti |
| ---------------- | ---- | ------- | ----- | ------- |
| Singapura        | 15%  | 10/15%  | 10%   | 15%     |
| AS               | 15%  | 10/15%  | 10%   | 10%     |
| Inggris          | 15%  | 10/15%  | 10%   | 15%     |
| Australia        | 15%  | 15%     | 10%   | 15%     |
| Jepang           | 15%  | 10/15%  | 10%   | 10%     |
| Tanpa perjanjian | 20%  | 20%     | 20%   | 20%     |

### Sertifikat Tempat Tinggal (SKD)

Untuk menerapkan tarif perjanjian, penerima asing harus menyediakan:

- **Formulir DGT-1** (Sertifikat Tempat Tinggal)
- Diisi oleh penerima
- Disertifikasi oleh otoritas pajak
- Berlaku selama 12 bulan

## Bukti Potong

### Memberikan Kepada Penerima

Saat Anda memotong pajak, Anda harus memberikan **Bukti Potong**:

| Jenis Pajak | Bukti Potong            |
| ----------- | ----------------------- |
| PPh 21      | Bukti Potong 1721-A1/A2 |
| PPh 23      | Bukti Potong PPh 23     |
| PPh 26      | Bukti Potong PPh 26     |
| PPh 4(2)    | Bukti Potong PPh 4(2)   |

Penerima menggunakan ini untuk:

- Mengklaim kredit pajak
- Mengajukan pengembalian pajak mereka
- Mendukung pengurangan biaya

## Kesalahan Umum

| Kesalahan                    | Dampak                                   |
| ---------------------------- | ---------------------------------------- |
| Pemotongan kurang            | Denda keterlambatan + bunga              |
| Tarif salah diterapkan       | Kelebihan/kekurangan pembayaran          |
| Tidak memberikan sertifikat  | Masalah bagi penerima                    |
| Formalitas perjanjian kurang | Tarif 20% berlaku bukan tarif perjanjian |
| NPWP salah                   | Masalah sertifikat                       |
