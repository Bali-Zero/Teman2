# PPN di Indonesia 2026: Panduan Bisnis Lengkap

Pajak Pertambahan Nilai (PPN) adalah pajak konsumsi di Indonesia. Memahaminya sangat penting untuk kepatuhan bisnis.

<InfoCard variant="warning" title="Update PPN 2026 (Sumber: pajak.go.id)">
**PPN 12% berlaku mulai 1 Januari 2025:**

PPN Indonesia secara resmi berada di angka **12%** sejak 1 Januari 2025. Namun, berkat mekanisme **DPP Nilai Lain**, tarif efektif untuk sebagian besar barang dan jasa tetap berada di angka **11%**.

- **Barang normal**: 12% × (11/12) = **11% efektif**
- **Barang mewah**: **12% penuh** (tanpa DPP Nilai Lain)
- **Semua faktur pajak** harus diterbitkan melalui **Coretax/e-Faktur**

**Nota Penting**: Struktur ini diterapkan untuk meminimalkan dampak pada konsumen sambil secara formal tetap mempertahankan tarif 12% yang diamanatkan undang-undang.

</InfoCard>

## Pendaftaran PPN

### Siapa yang Wajib Mendaftar?

<InfoCard variant="note" title="Ambang Batas Pendaftaran PKP">
Anda wajib mendaftar sebagai **PKP (Pengusaha Kena Pajak)** jika:

- Omzet bruto melebihi **Rp 4,8 miliar/tahun**
- Atau Anda **mendaftar secara sukarela**

Sebagai PKP, Anda wajib:

- Memungut PPN atas penjualan
- Menerbitkan Faktur Pajak
- Melaporkan SPT Masa PPN setiap bulan
- Dapat mengklaim kredit PPN masukan
  </InfoCard>

## Perhitungan PPN

<Calculator
  title="Kalkulator PPN"
  description="Hitung PPN pada transaksi"
  fields={[
    {
      id: "amount",
      label: "Jumlah Transaksi (IDR)",
      type: "number",
      defaultValue: 100000000,
      min: 0,
      step: 1000000,
      suffix: "IDR"
    },
    {
      id: "type",
      label: "Jenis Transaksi",
      type: "select",
      options: [
        { value: "exclusive", label: "Tambah PPN ke harga" },
        { value: "inclusive", label: "Harga sudah termasuk PPN" }
      ],
      defaultValue: "exclusive"
    }
  ]}
  calculateResult={(values) => {
    const amount = Number(values.amount);
    const rate = 0.11; // 11% efektif

    let baseAmount, vatAmount, totalAmount;

    if (values.type === "exclusive") {
      baseAmount = amount;
      vatAmount = amount * rate;
      totalAmount = amount + vatAmount;
    } else {
      totalAmount = amount;
      baseAmount = amount / (1 + rate);
      vatAmount = totalAmount - baseAmount;
    }

    return {
      total: vatAmount,
      breakdown: [
        { label: "Dasar Pengenaan Pajak (DPP)", amount: Math.round(baseAmount) },
        { label: "PPN (11%)", amount: Math.round(vatAmount) },
        { label: "Total dengan PPN", amount: Math.round(totalAmount) }
      ],
      currency: "IDR",
      note: "Tarif: 11% (standar efektif)"
    };

}}

## Faktur Pajak

### Sistem e-Faktur

<InfoCard variant="warning" title="Wajib e-Faktur">
Semua bisnis yang terdaftar sebagai PKP wajib menggunakan sistem **e-Faktur**:

- Unduh aplikasi e-Faktur
- Daftarkan sertifikat elektronik
- Terbitkan semua faktur secara elektronik
- Unggah ke sistem DJP
- Masukkan kredit PPN masukan secara elektronik
  </InfoCard>

## PPN Masukan vs Keluaran

### Cara Kerja Kredit PPN

| Transaksi              | Jenis PPN    | Perlakuan                     |
| ---------------------- | ------------ | ----------------------------- |
| Penjualan ke pelanggan | PPN Keluaran | Pungut dan setor              |
| Pembelian dari pemasok | PPN Masukan  | Klaim sebagai kredit          |
| Posisi neto            | Selisih      | Bayar jika keluaran > masukan |
| Kredit neto            | Selisih      | Kompensasi atau restitusi     |

### Contoh Perhitungan Bulanan

| Deskripsi            | Jumlah      |
| -------------------- | ----------- |
| PPN Keluaran (jual)  | Rp 110 Juta |
| PPN Masukan (beli)   | Rp 55 Juta  |
| PPN Neto harus bayar | Rp 55 Juta  |

### Barang/Jasa yang Dibebaskan dari PPN

Beberapa barang dan jasa dibebaskan dari PPN:

- Kebutuhan pokok (beras, gabah, jagung, sagu, kedelai, garam, daging, telur, susu, buah, sayur)
- Jasa kesehatan
- Jasa pendidikan
- Jasa keagamaan
- Jasa keuangan (tertentu)
- Bisnis skala kecil (di bawah ambang batas)

## Masalah Umum

### Masalah PPN yang Harus Dihindari

| Masalah       | Konsekuensi             |
| ------------- | ----------------------- |
| Telat lapor   | Denda Rp 500.000        |
| Faktur salah  | Kredit tidak diakui     |
| Faktur hilang | Tidak bisa klaim kredit |
| NPWP salah    | Faktur ditolak          |
| Telat bayar   | Denda bunga             |

### Aturan Kredit PPN Masukan

<InfoCard variant="warning" title="PPN Masukan yang Dapat Dikreditkan">
Tidak semua PPN masukan dapat dikreditkan. Kredit akan **ditolak** untuk:

- Biaya hiburan (entertainment)
- Pembelian non-bisnis
- Pembelian tanpa faktur pajak yang sah
- Pembelian dari pemasok non-PKP
- Barang mewah (mobil pribadi, dll.)
  </InfoCard>

## Restitusi PPN

### Kapan Restitusi Tersedia

- PPN masukan secara konsisten lebih besar dari PPN keluaran
- Bisnis ekspor (penjualan tarif nol)
- Investasi baru dengan PPN masukan besar

### Proses Restitusi

1. Ajukan permohonan restitusi tahunan atau khusus
2. Audit pajak biasanya diwajibkan
3. Waktu pemrosesan: 1-12 bulan
4. Dokumentasi lengkap wajib tersedia
