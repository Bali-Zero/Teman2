## Imposta Finale PMI (PP 55/2022)

<InfoCard variant="tip" title="Semplificato per le Piccole Imprese">
Le aziende con un fatturato lordo inferiore a **4,8 miliardi IDR/anno** possono utilizzare l'imposta finale semplificata:

- **Aliquota**: 0.5% del fatturato lordo
- **Nessun calcolo complesso**
- **Pagamento mensile**
- **Applicabile a**: PT, CV, individui con attività commerciale
- **Durata**: Massimo 7 anni per le PT, 4 anni per CV/individui

Dopo il periodo massimo, si applicano le aliquote regolari.

</InfoCard>

### Esempio Imposta PMI

| Ricavo Mensile | Imposta Dovuta |
| --------------- | -------- |
| IDR 100M        | IDR 500K |
| IDR 200M        | IDR 1M   |
| IDR 400M        | IDR 2M   |

## Pricing di Trasferimento

<InfoCard variant="warning" title="Operazioni tra Parti Correlate">
L'Indonesia ha rigorose regole sul **pricing di trasferimento** per le operazioni tra parti correlate:

- Devono essere a prezzi **arm's length** (a distanza armata)
- **Documentazione richiesta** (Master File, Local File)
- **Reporting Paese per Paese** per grandi gruppi
- **Sanzioni** per non conformità

Collabora con consulenti fiscali qualificati per le operazioni tra parti correlate.

</InfoCard>

### Requisiti Documentali

| Report      | Richiesto Per        | Soglia                |
| ----------- | ------------------- | ------------------------ |
| Master File | Grandi contribuenti     | Ricavo IDR 50B+         |
| Local File  | Affari parti correlate | Qualsiasi transazione materiale |
| CbC Report  | Multinazionali      | Ricavo gruppo €750M+     |

## Problemi Comuni per le Società Esterne

### Considerazioni PT PMA

1. **Thin Capitalization** - Limiti al rapporto debito/capitale proprio (4:1)
2. **Pricing di Trasferimento** - Ispezione delle operazioni tra parti correlate
3. **Imposte di Ritenzione** - Pagamenti a filiali estere
4. **Stabilimento Permanente** - Necessaria strutturazione attenta
5. **Trattati Fiscali** - Verificare l'applicabilità
