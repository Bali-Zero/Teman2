<InfoCard variant="important" title="La Regola dei 183 Giorni">
I 183 giorni non devono essere consecutivi. L'Indonesia conta i giorni in qualsiasi **periodo di 12 mesi**, che può coprire anni fiscali diversi. I giorni di ingresso e uscita contano entrambi come giorni interi.

Esempio: Se arrivi il 1° ottobre 2024 e conti in avanti 12 mesi fino al 30 settembre 2026—il totale dei giorni in Indonesia durante questo periodo determina la residenza.

</InfoCard>

<InfoCard variant="tip" title="Come Funziona la Tassa Progressiva">
Non paghi il 35% su tutto il tuo reddito se guadagni oltre IDR 5 miliardi. Ogni fascia si applica solo al reddito entro quel range.

**Esempio:** Se guadagni IDR 300 milioni all'anno:

- I primi IDR 60M tassati al 5% = IDR 3.000.000
- I successivi IDR 190M (60M-250M) tassati al 15% = IDR 28.500.000
- I successivi IDR 50M (250M-300M) tassati al 25% = IDR 12.500.000
- **Tassa totale: IDR 44.000.000** (aliquota effettiva: ~14,7%)

    // Calcola reddito imponibile

    if (taxableIncome < 0) taxableIncome = 0;

    // Calcola tassa
    let tax = 0;
    let remaining = taxableIncome;

    // Fascia 1: 0-60M al 5%
    if (remaining > 0) {
      const bracket1 = Math.min(remaining, 60000000);
      tax += bracket1 * 0.05;
      remaining -= bracket1;
    }

    // Fascia 2: 60M-250M al 15%
    if (remaining > 0) {
      const bracket2 = Math.min(remaining, 190000000);
      tax += bracket2 * 0.15;
      remaining -= bracket2;
    }

    // Fascia 3: 250M-500M al 25%
    if (remaining > 0) {
      const bracket3 = Math.min(remaining, 250000000);
      tax += bracket3 * 0.25;
      remaining -= bracket3;
    }

    // Fascia 4: 500M-5B al 30%
    if (remaining > 0) {
      const bracket4 = Math.min(remaining, 4500000000);
      tax += bracket4 * 0.30;
      remaining -= bracket4;
    }

    // Fascia 5: >5B al 35%
    if (remaining > 0) {
      tax += remaining * 0.35;
    }

    // Penalità non-NPWP: 20% più alta
    if (!values['has-npwp']) {
      tax = tax * 1.2;
    }

    const effectiveRate = annual > 0 ? (tax / annual * 100).toFixed(1) : 0;
    const monthlyTax = tax / 12;
    const takeHome = annual - tax;

    return {
      total: tax,
      breakdown: [
        { label: "Reddito Annuo Lordo", amount: annual },
        { label: `PTKP (${values['marital-status']})`, amount: -ptkp },
        { label: "Reddito Imponibile", amount: taxableIncome },
        { label: "Tassa Annuale (PPh 21)", amount: tax },
        { label: "Ritenuta Fiscale Mensile", amount: monthlyTax },
        { label: "Reddito Netto Annuo", amount: takeHome }
      ],
      currency: "IDR",
      note: `Aliquota fiscale effettiva: ${effectiveRate}%${!values['has-npwp'] ? ' (include penalità non-NPWP del 20%)' : ''}`
    };

}}
ctaText="Consulta Consulente Fiscale"

<GlossaryTerm

## Situazioni Fiscali Speciali

### Lavoratori Remoti / Digital Nomads

<InfoCard variant="warning" title="Zona Grigia Fiscale Digital Nomad">
L'Indonesia non ha un regime fiscale specifico per "digital nomad". Tecnicamente:

- Lavoro svolto in Indonesia = potenzialmente reddito da fonte indonesiana
- 183+ giorni = residente fiscale, reddito mondiale tassabile
- I visti turistici non cambiano gli obblighi fiscali

**Realtà**: Molti digital nomads non si registrano. Questo è un rischio. L'ufficio delle tasse è sempre più consapevole dei lavoratori remoti.

**Approccio più sicuro**: Rimani sotto i 183 giorni, o valuta la registrazione volontaria se rimani più a lungo.

</InfoCard>

### Detentori del Second Home Visa

Il nuovo **Second Home Visa** (primo rilascio di 5 anni, rinnovabile fino a un massimo cumulativo di 10 anni) non crea automaticamente la residenza fiscale, ma:

- 183+ giorni ancora attiva la residenza
- Potresti dover provare che il reddito non proviene dall'Indonesia
- Valuta la registrazione volontaria NPWP per banche e proprietà

### Espatriati in Assegnazione

Se il tuo datore di lavoro del paese d'origine ti assegna in Indonesia:

- Diventi solitamente residente fiscale indonesiano
- Potresti essere eleggibile per **equalizzazione fiscale** (il datore di lavoro copre la differenza)
- Controlla per gli accordi di **tassa ipotetica**
- Coordina con i consulenti fiscali del paese d'origine e ospitante

## Errori Comuni da Evitare

<InfoCard variant="error" title="Errori Fiscali che Costano Denaro">
**1. Non Ottenere NPWP**
Markup del 20% sulla tassa senza NPWP. Ottienilo non appena diventi residente.

**2. Mancare la Scadenza di Presentazione**
SPT dovuta il 31 marzo. Tardiva = sanzioni. Imposta un promemoria.

**3. Ignorare i Redditi Esteri**
I residenti devono dichiarare il reddito mondiale. Conti bancari esteri, investimenti, reddito da affitto—tutti tassabili.

**4. Modulo Tipo Errato**
Usare 1770SS quando hai più fonti di reddito. Usa il modulo corretto per la tua situazione.

**5. Non Richiedere Benefici del Trattato**
Se sei tassato al 20% ma il tuo paese ha un trattato per il 10%, stai sovrapagando.

**6. Nessun Registro**
Conserva buste paga, Bukti Potong, estratti conto bancari per 10 anni. L'ufficio delle tasse può fare un'audit.

</InfoCard>
