<InfoCard variant="important" title="La Regola dei 183 Giorni">
I 183 giorni non devono essere consecutivi. L'Indonesia conta i giorni in qualsiasi **periodo di 12 mesi**, che può comprendere anni solari diversi. I giorni di entrata e di uscita contano entrambi come giorni interi.

Esempio: Se arrivi il 1° ottobre 2024 e conti in avanti di 12 mesi fino al 30 settembre 2025, il totale dei giorni trascorsi in Indonesia durante questo periodo determina la residenza.

</InfoCard>

<InfoCard variant="tip" title="Come Funziona la Tassazione Progressiva">
Non paghi il 35% su tutto il tuo reddito se guadagni oltre 5 miliardi di IDR. Ogni scaglione si applica solo al reddito all'interno di quella fascia.

**Esempio:** Se guadagni 300 milioni di IDR all'anno:

- Primi 60M tassati al 5% = 3.000.000 IDR
- Successivi 190M (60M-250M) tassati al 15% = 28.500.000 IDR
- Successivi 50M (250M-300M) tassati al 25% = 12.500.000 IDR
- **Tassa totale: 44.000.000 IDR** (aliquota effettiva: ~14,7%)

      defaultValue: "single"
    },
    {
      id: "has-npwp",
      label: "Possiedi l'NPWP?",
      type: "checkbox",
      defaultValue: true
    }
  ]}
  calculateResult={(values) => {
    const monthly = Number(values['monthly-salary']) + Number(values['allowances']);
    const bonusMonths = Number(values['bonus-months']);
    const annual = (monthly * 12) + (Number(values['monthly-salary']) * bonusMonths);

    // PTKP (non-taxable income)
    const ptkpMap = {
      'single': 54000000,
      'married-0': 58500000,
      'married-1': 63000000,
      'married-2': 67500000,
      'married-3': 72000000
    };
    const ptkp = ptkpMap[values['marital-status']] || 54000000;

    // Calculate taxable income
    let taxableIncome = annual - ptkp;
    if (taxableIncome < 0) taxableIncome = 0;

    // Calculate tax
    let tax = 0;
    let remaining = taxableIncome;

    // Bracket 1: 0-60M at 5%
    if (remaining > 0) {
      const bracket1 = Math.min(remaining, 60000000);
      tax += bracket1 * 0.05;
      remaining -= bracket1;
    }

    // Bracket 2: 60M-250M at 15%
    if (remaining > 0) {
      const bracket2 = Math.min(remaining, 190000000);
      tax += bracket2 * 0.15;
      remaining -= bracket2;
    }

    // Bracket 3: 250M-500M at 25%
    if (remaining > 0) {
      const bracket3 = Math.min(remaining, 250000000);
      tax += bracket3 * 0.25;
      remaining -= bracket3;
    }

    // Bracket 4: 500M-5B at 30%
    if (remaining > 0) {
      const bracket4 = Math.min(remaining, 4500000000);
      tax += bracket4 * 0.30;
      remaining -= bracket4;
    }

    // Bracket 5: >5B at 35%
    if (remaining > 0) {
      tax += remaining * 0.35;
    }

    // Non-NPWP penalty: 20% higher
    if (!values['has-npwp']) {
      tax = tax * 1.2;
    }

    const effectiveRate = annual > 0 ? (tax / annual * 100).toFixed(1) : 0;
    const monthlyTax = tax / 12;
    const takeHome = annual - tax;

    return {
      total: tax,
      breakdown: [
        { label: "Reddito Lordo Annuale", amount: annual },
        { label: `PTKP (${values['marital-status']})`, amount: -ptkp },
        { label: "Reddito Imponibile", amount: taxableIncome },
        { label: "Tassa Annuale (PPh 21)", amount: tax },
        { label: "Ritenuta Fiscale Mensile", amount: monthlyTax },
        { label: "Netto Annuale", amount: takeHome }
      ],
      currency: "IDR",
      note: `Aliquota fiscale effettiva: ${effectiveRate}%${!values['has-npwp'] ? ' (include il 20% di penalità per mancanza di NPWP)' : ''}`
    };

}}

## Situazioni Fiscali Speciali

### Lavoratori Remoti / Nomadi Digitali

<InfoCard variant="warning" title="Area Grigia Fiscale per i Nomadi Digitali">
L'Indonesia non ha un regime fiscale specifico per i "nomadi digitali". Tecnicamente:

- Lavoro svolto in Indonesia = potenziale reddito di fonte indonesiana
- 183+ giorni = residente fiscale, reddito mondiale tassabile
- I visti turistici non cambiano gli obblighi fiscali

**Realtà**: Molti nomadi digitali non si registrano. Questo è un rischio. L'ufficio delle tasse è sempre più consapevole dei lavoratori remoti.

**Approccio più sicuro**: Rimanere sotto i 183 giorni, o considerare la registrazione volontaria se si rimane più a lungo.

</InfoCard>

### Titolari di Visa Second Home

Il nuovo **Visa Second Home** (5-10 anni) non crea automaticamente la residenza fiscale, ma:

- 183+ giorni fanno comunque scattare la residenza
- Potrebbe essere necessario dimostrare che il reddito non proviene dall'Indonesia
- Considera la registrazione NPWP volontaria per scopi bancari/immobiliari

### Espatriati in Distacco

Se il datore di lavoro del tuo paese d'origine ti assegna all'Indonesia:

- Di solito diventi residente fiscale indonesiano
- Potresti aver diritto alla **tax equalization** (il datore di lavoro copre la differenza)
- Controlla gli accordi per la **tassa ipotetica** (hypothetical tax)
- Coordinati con i consulenti fiscali del paese d'origine e di quello ospitante

## Errori Comuni da Evitare

<InfoCard variant="error" title="Errori Fiscali che Costano Caro">
**1. Non ottenere l'NPWP**
Maggiorazione fiscale del 20% senza NPWP. Ottienilo non appena diventi residente.

**2. Mancare la scadenza di presentazione**
L'SPT scade il 31 marzo. In ritardo = sanzioni. Imposta un promemoria.

**3. Ignorare il reddito estero**
I residenti devono dichiarare il reddito mondiale. Conti bancari esteri, investimenti, redditi da locazione: tutto è tassabile.

**4. Tipo di modulo errato**
Usare il 1770SS quando si hanno più fonti di reddito. Usa il modulo corretto per la tua situazione.

**5. Non richiedere i benefici del trattato**
Se sei tassato al 20% ma il tuo paese ha un trattato per il 10%, stai pagando troppo.

**6. Nessun registro**
Conserva buste paga, Bukti Potong, estratti conto per 10 anni. L'ufficio delle tasse può effettuare audit.

</InfoCard>
