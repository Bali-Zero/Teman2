<InfoCard variant="tip" title="Pilihan Termudah">

### Pendaftaran IMEI

<InfoCard variant="warning" title="Penting untuk Telepon Asing">
Telepon asing harus mendaftarkan **IMEI** mereka agar berfungsi dengan SIM Indonesia di luar 90 hari.

**Pilihan:**

1. Daftar di kedatangan bandara (gratis untuk telepon pertama)
2. Daftar secara online via Bea Cukai (bea cukai)
3. Bayan pajak untuk perangkat tambahan (~IDR 2,5 juta)

Tanpa pendaftaran, SIM Anda akan berhenti berfungsi setelah 90 hari.

</InfoCard>

## Troubleshooting

### Koneksi Lambat?

| Masalah      | Solusi                      |
| ---------- | ----------------------------- |
| Kemacetan   | Pindah ke penyedia yang lebih sepi  |
| Lokasi       | Dekati jendela/routeer        |
| Throttling   | Cek penggunaan data, beli paket |
| VPN diperlukan | Gunakan layanan VPN berkualitas       |

### VPN di Indonesia

<InfoCard variant="note" title="Penggunaan VPN">
VPN **tidak ilegal** di Indonesia tetapi:
- Beberapa situs diblokir (Reddit, dll.)
- Streaming mungkin memerlukan VPN
- VPN berkualitas direkomendasikan
- VPN gratis sering lambat

Pilihan populer: ExpressVPN, NordVPN, Surfshark

</InfoCard>

## Tips Cepat

1. **Beli SIM di bandara** - Termudah untuk turis
2. **Telkomsel untuk perjalanan** - Jangkauan terbaik di luar kota
3. **XL/Tri untuk kota** - Nilai lebih baik jika tinggal diam
4. **Top up via aplikasi** - GoPay, OVO, Dana bekerja
5. **Cek aplikasi MyTelkomsel** - Manajemen paket mudah
6. **Daftar IMEI awal** - Jangan tunggu sampai diblokir
7. **Bawa cadangan** - Selalu miliki data seluler sebagai cadangan
