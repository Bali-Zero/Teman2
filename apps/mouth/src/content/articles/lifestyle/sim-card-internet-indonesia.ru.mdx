### Регистрация IMEI

<InfoCard variant="warning" title="Важно для иностранных телефонов">
Иностранные телефоны должны зарегистрировать свой **IMEI**, чтобы работать с индонезийскими SIM-картами более 90 дней.

**Варианты:**

1. Зарегистрироваться по прибытии в аэропорт (бесплатно для первого телефона)
2. Зарегистрироваться онлайн через Bea Cukai (таможня)
3. Уплатить налог за дополнительные устройства (около 2,5 млн IDR)

Без регистрации ваша SIM-карта перестанет работать через 90 дней.

</InfoCard>

## Настройка для цифровых кочевников

<InfoCard variant="tip" title="Рекомендуемая настройка">
**Для надежной удаленной работы:**

1. **Основной**: Фиксированный оптоволоконный (IndiHome/Biznet)
2. **Резервный**: SIM-карта Telkomsel с данными
3. **Аварийный**: Карманный Wi-Fi или точка доступа телефона

## Устранение неполадок

### Медленное соединение?

| Проблема     | Решение                                        |
| ------------ | ---------------------------------------------- |
| Перегрузка   | Переключиться на менее загруженного провайдера |
| Расположение | Переместитесь ближе к окну/маршрутизатору      |
| Троттлинг    | Проверьте использование данных, купите пакет   |
| Нужен VPN    | Используйте качественный VPN-сервис            |

### VPN в Indonesia

<InfoCard variant="note" title="Использование VPN">
VPN **не являются незаконными** в Indonesia, но:
- Некоторые сайты заблокированы (Reddit и т.д.)
- Для стриминга может потребоваться VPN
- Рекомендуются качественные VPN
- Бесплатные VPN часто медленные

Популярные варианты: ExpressVPN, NordVPN, Surfshark

</InfoCard>

## Быстрые советы

1. **Купите SIM-карту в аэропорту** - Самый простой вариант для туристов
2. **Telkomsel для путешествий** - Лучшее покрытие за пределами городов
3. **XL/Tri для городов** - Лучшая цена, если остаетесь на месте
4. **Пополнение через приложения** - Работают GoPay, OVO, Dana
5. **Проверьте приложение MyTelkomsel** - Простое управление пакетами
6. **Зарегистрируйте IMEI заранее** - Не ждите, пока заблокируют
7. **Имейте запасной вариант** - Всегда имейте мобильные данные в качестве резерва
