## Международное водительское удостоверение (IDP)

### Что такое IDP?

<InfoCard variant="warning" title="IDP НЕ является водительскими правами">
IDP — это **перевод** Ваших национальных водительских прав, а не отдельное удостоверение.

Вы должны:

- Иметь действующие национальные водительские права
- Носить с собой как IDP, ТАК И оригинал прав
- Соблюдать местные законы
  </InfoCard>

### Получение IDP

Получите Ваше IDP **до** приезда в Индонезию:

| Страна         | Где получить          |
| -------------- | --------------------- |
| США            | Офисы AAA             |
| Великобритания | Почтовое отделение    |
| Австралия      | AAA, RACV             |
| Канада         | Офисы CAA             |
| ЕС             | Местные органы власти |

Стоимость: Обычно $15-50

### Действительность IDP в Индонезии

- **Технически действительно** для краткосрочного пребывания
- Полиция может принять или не принять его
- У страховых компаний могут возникнуть проблемы
- **Категория мотоцикла** должна быть указана
- Лучше использовать как запасной вариант, а не основной

## Реальность на дороге

<InfoCard variant="warning" title="Практические соображения">
**Что происходит на самом деле:**

- Многие туристы ездят на скутерах без соответствующих прав
- Полиция иногда останавливает иностранцев
- Штраф: ~IDR 250K-500K (обсуждаемо)
- Страховые выплаты могут быть отклонены без прав
- Несчастные случаи могут быть сложными

**Рекомендация:** Получите соответствующие права для душевного спокойствия.

</InfoCard>

### Если Вас остановила полиция

1. Оставайтесь спокойным и вежливым
2. Предъявите документы
3. Если нет прав, скорее всего, будет штраф
4. Не спорьте
5. Попросите квитанцию (tilang)

## Аренда скутера без прав

Большинство прокатных контор не проверяют права. Однако:

### Риски

| Риск                    | Последствия                        |
| ----------------------- | ---------------------------------- |
| Остановка полицией      | Штраф IDR 250-500K                 |
| Авария                  | Страховка может не покрыть         |
| Серьезная авария        | Потенциальные юридические проблемы |
| Причинение вреда другим | Ответственность неясна             |

### Примечание о страховке

<InfoCard variant="warning" title="Предупреждение о страховке">
Большинство полисов туристического страхования требуют:
- Действующие права на данный тип транспортного средства
- Соблюдение местных законов

Без соответствующих прав претензии могут быть **отклонены**.

</InfoCard>

## Советы для иностранцев

1. **Получите SIM C, если ездите на скутерах** - Стоит душевного спокойствия
2. **Возьмите национальные права** - Может помочь при сдаче экзамена
3. **Отправляйтесь в Denpasar SAMSAT** - Самое удобное для иностранцев место в Bali
4. **Приезжайте пораньше** - Могут быть длинные очереди
5. **Приведите индонезийскоговорящего спутника** - Полезно, но не обязательно
6. **Потренируйтесь на экзаменационной трассе** - Сначала понаблюдайте за другими
7. **Будьте терпеливы** - Бюрократия требует времени
