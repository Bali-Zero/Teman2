## BPJS Kesehatan

### Что такое BPJS?

<InfoCard variant="note" title="Обязательно для держателей KITAS">
**BPJS Kesehatan** — это национальное медицинское страхование Indonesia. Оно **обязательно** для:
- Граждан Indonesia
- Иностранцев с KITAS, работающих 6+ месяцев

Ваш работодатель должен зарегистрировать вас, или вы регистрируетесь самостоятельно.

</InfoCard>

### Классы BPJS

| Класс   | Ежемесячный взнос | Тип палаты      | Примечания |
| ------- | ----------------- | --------------- | ---------- |
| Класс 1 | IDR 150,000       | VIP одноместная | Лучший     |
| Класс 2 | IDR 100,000       | Полу-приватная  | Хороший    |
| Класс 3 | IDR 42,000        | Общая палата    | Базовый    |

### Покрытие BPJS

- Амбулаторное лечение
- Стационарная госпитализация
- Хирургия
- Лекарства (формуляр)
- Скорая помощь
- Направление к специалистам

### Ограничения BPJS

- Часто встречаются длительные ожидания
- Качество варьируется в зависимости от больницы
- Требуется система направлений
- Некоторые лекарства не покрываются
- Премиальные больницы часто не включены

## Международная страховка

### Почему многие экспаты выбирают международную страховку

1. **Выбор больницы** - Доступ к премиальным частным больницам
2. **Без направлений** - Напрямую к специалисту
3. **Глобальное покрытие** - Покрытие во время путешествий
4. **Поддержка на английском** - Простое общение
5. **Эвакуация** - Медицинская эвакуация при необходимости

### Популярные провайдеры

| Провайдер           | От             | Примечания             |
| ------------------- | -------------- | ---------------------- |
| Cigna Global        | ~USD 200/месяц | Широкая сеть           |
| Allianz             | ~USD 150/месяц | Хорошая репутация      |
| AXA                 | ~USD 150/месяц | Глобальный охват       |
| Pacific Cross       | ~USD 100/месяц | Ориентация на Азию     |
| April International | ~USD 120/месяц | Специалист по экспатам |

<InfoCard variant="tip" title="Получите несколько предложений">

</InfoCard>

  title="Сравнение стоимости страховки"

  fields={[
    {

    },
    {
      id: "age",
      label: "Возрастная группа",
      type: "select",
      options: [
        { value: "young", label: "Младше 35" },
        { value: "middle", label: "35-50" },
        { value: "senior", label: "50-65" },
        { value: "elderly", label: "65+" }
      ],
      defaultValue: "middle"

  calculateResult={(values) => {
    // Base costs by type
    const baseCosts = {
      "bpjs": 1800000, // Class 1 annual
      "local": 12000000,
      "international": 36000000,
      "premium": 72000000
    };

    // Age multipliers
    const ageMultipliers = {
      "young": 0.7,
      "middle": 1.0,
      "senior": 1.5,
      "elderly": 2.0
    };

    const base = baseCosts[values.type];
    const multiplier = ageMultipliers[values.age];
    const annual = base * multiplier;
    const monthly = annual / 12;

    return {
      total: annual,

## Существующие заболевания

<InfoCard variant="warning" title="Раскрытие информации важно">
Большинство международных страховщиков:
- Спросят о существующих заболеваниях
- Могут изначально исключить их
- Предложат покрытие после периода ожидания
- Премия может быть выше

**Никогда не скрывайте заболевания** - в противном случае в претензиях может быть отказано.

</InfoCard>
