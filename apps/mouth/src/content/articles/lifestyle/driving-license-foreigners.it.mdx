## Il Test di Guida

### Test Scritto

<InfoCard variant="note" title="Test su Computer">
Il test scritto è:
- **30 domande** (circa)
- A scelta multipla
- Disponibile in **inglese** (solitamente)
- Devi superare con **70%+**
- Copre regole del traffico, segnali, sicurezza

Studiare le basi - non è difficile!

</InfoCard>

### Test Pratico

| Test  | Veicolo              | Cosa viene testato          |
| ----- | -------------------- | --------------------------- |
| SIM A | La tua auto o fornita | Figure 8, parcheggio, strada |
| SIM C | Scooter fornito      | Figure 8, slalom, equilibrio |

## Permesso di Guida Internazionale (IDP)

### Cos'è un IDP?

<InfoCard variant="warning" title="L'IDP NON è una Patente">
Un IDP è una **traduzione** della tua patente del paese d'origine, non una patente separata.

Devi:

- Avere una patente valida del paese d'origine
- Portare sia l'IDP che la patente originale
- Rispettare le leggi locali
</InfoCard>

### Ottenere un IDP

Ottieni il tuo IDP **prima** di venire in Indonesia:

| Paese     | Dove ottenerlo       |
| --------- | --------------------- |
| USA       | Uffici AAA            |
| UK        | Post Office           |
| Australia | AAA, RACV             |
| Canada    | Uffici CAA            |
| UE        | Autorità locale       |

Costo: Solitamente $15-50

### Validità dell'IDP in Indonesia

- **Tecnicamente valido** per brevi soggiorni
- La polizia potrebbe o non potrebbe accettarlo
- L'assicurazione potrebbe avere problemi
- La **categoria motocicli** deve essere specificata
- Meglio usarlo come backup, non primario

## La Realtà sulla Strada

<InfoCard variant="warning" title="Considerazioni Pratiche">
**Cosa accade realmente:**

- Molti turisti guidano scooter senza patente appropriata
- La polizia a volte ferma gli stranieri
- Multa: ~IDR 250K-500K (negoziabile)
- Le richieste di assicurazione possono essere negate senza patente
- Gli incidenti possono complicarsi

**Raccomandazione:** Ottieni una licenza appropriata per la tranquillità.

</InfoCard>

### Se Fermato dalla Polizia

1. Rimani calmo e cortese
2. Mostra i documenti
3. Senza patente, la multa è probabile
4. Non discutere
5. Chiedi il ricevuta (tilang)

## Noleggio Scooter Senza Patente

La maggior parte dei negozi di noleggio non controlla le patenti. Tuttavia:

### Rischi

| Rischio             | Conseguenza               |
| ----------------    | -------------------------- |
| Ferma dalla polizia | Multa IDR 250-500K         |
| Incidente           | L'assicurazione potrebbe non coprire |
| Grave incidente     | Possibili problemi legali   |
| Lesioni ad altri    | Responsabilità non chiara   |

### Nota Assicurativa

<InfoCard variant="warning" title="Avviso Assicurativo">
La maggior parte delle polizze di viaggio richiede:
- Patente valida per il tipo di veicolo
- Rispetto delle leggi locali

Senza patente appropriata, le richieste potrebbero essere **negate**.

</InfoCard>

## Consigli per gli Stranieri

1. **Ottieni la SIM C se guidi scooter** - Vale la pena per la tranquillità
2. **Porta la patente del paese d'origine** - Può aiutare con il test
3. **Vai al SAMSAT di Denpasar** - Il più accogliente per gli stranieri a Bali
4. **Arriva presto** - Le code possono essere lunghe
5. **Porta un parlante indonesiano** - Utile ma non richiesto
6. **Allena sulla pista del test** - Guarda prima gli altri
7. **Sii paziente** - La burocrazia richiede tempo
