## L'Esame di Guida

### Test Scritto

<InfoCard variant="note" title="Test al Computer">
Il test scritto consiste in:
- Circa **30 domande**
- Risposta multipla
- Disponibile in **Inglese** (solitamente)
- Necessario il **70%+** per superarlo
- Copre regole del traffico, segnali, sicurezza

Studia le basi: non è difficile!

</InfoCard>

### Test Pratico

| Esame | Veicolo            | Cosa viene testato             |
| ----- | ------------------ | ------------------------------ |
| SIM A | Tua auto o fornita | Figura a 8, parcheggio, strada |
| SIM C | Scooter fornito    | Figura a 8, slalom, equilibrio |

## Patente Internazionale (IDP)

### Cos'è una IDP?

<InfoCard variant="warning" title="La IDP NON è una patente">
Una IDP è una **traduzione** della patente del tuo paese, non una patente separata.

Devi:

- Avere una patente valida del tuo paese
- Portare sia la IDP CHE la patente originale
- Rispettare le leggi locali
  </InfoCard>

### Ottenere una IDP

Ottieni la tua IDP **prima** di venire in Indonesia:

| Paese     | Dove ottenerla  |
| --------- | --------------- |
| Italia    | Motorizzazione  |
| USA       | Uffici AAA      |
| UK        | Ufficio Postale |
| Australia | AAA, RACV       |
| Canada    | Uffici CAA      |

Costo: Solitamente 15-50 USD

### Validità IDP in Indonesia

- **Tecnicamente valida** per soggiorni brevi
- La polizia potrebbe accettarla o meno
- L'assicurazione potrebbe fare storie
- La **categoria moto** deve essere specificata
- Meglio usarla come backup, non come principale

## La Realtà sulla Strada

<InfoCard variant="warning" title="Considerazioni Pratiche">
**Cosa succede realmente:**

- Molti turisti guidano scooter senza patente adeguata
- La polizia a volte ferma gli stranieri
- Multa: ~250k-500k IDR (trattabile)
- I rimborsi assicurativi possono essere negati senza patente
- Gli incidenti possono diventare complicati

**Raccomandazione:** Ottieni una patente regolare per la tua tranquillità.

</InfoCard>

### Se Fermati dalla Polizia

1. Mantieni la calma e sii educato
2. Mostra i documenti
3. Se non hai la patente, è probabile una multa
4. Non discutere
5. Chiedi la ricevuta (tilang)

---

## Noleggio Scooter Senza Patente

La maggior parte dei noleggiatori non controlla la patente. Tuttavia:

### Rischi

| Rischio         | Conseguenza                     |
| --------------- | ------------------------------- |
| Fermo polizia   | Multa 250-500k IDR              |
| Incidente       | L'assicurazione può non coprire |
| Incidente grave | Potenziali problemi legali      |
| Lesioni a terzi | Responsabilità incerta          |

### Nota sull'Assicurazione

<InfoCard variant="warning" title="Avviso Assicurazione">
La maggior parte delle polizze di viaggio richiede:
- Patente valida per il tipo di veicolo
- Rispetto delle leggi locali

Senza una patente adeguata, i rimborsi possono essere **negati**.

</InfoCard>

## Consigli per gli Stranieri

1. **Prendi la SIM C se guidi uno scooter** - Ne vale la pena per la tranquillità
2. **Porta la patente originale** - Può aiutare durante i test
3. **Vai al SAMSAT di Denpasar** - Il più abituato agli stranieri a Bali
4. **Arriva presto** - Le code possono essere lunghe
5. **Porta qualcuno che parli indonesiano** - Utile ma non obbligatorio
6. **Esercitati nel percorso d'esame** - Osserva gli altri prima di provare
7. **Sii paziente** - La burocrazia richiede tempo
