## L'Examen de Conduite

### Test Écrit

<InfoCard variant="note" title="Test sur Ordinateur">
Le test écrit est :
- **30 questions** (environ)
- Choix multiples
- Disponible en **anglais** (généralement)
- Doit être réussi avec **70 % et plus**
- Couvre le code de la route, les panneaux, la sécurité

Étudiez les bases - ce n'est pas difficile !

</InfoCard>

### Test Pratique

| Test  | Véhicule                 | Ce qui est testé           |
| ----- | ------------------------ | -------------------------- |
| SIM A | Votre voiture ou fournie | Huit, stationnement, route |
| SIM C | Scooter fourni           | Huit, slalom, équilibre    |

## Permis de Conduire International (IDP)

### Qu'est-ce qu'un IDP ?

<InfoCard variant="warning" title="L'IDP N'EST PAS un Permis">
Un IDP est une **traduction** de votre permis de conduire national, pas un permis distinct.

Vous devez :

- Avoir un permis national valide
- Transporter à la fois l'IDP ET le permis original
- Obéir aux lois locales
  </InfoCard>

### Obtenir un IDP

Obtenez votre IDP **avant** de venir en Indonesia :

| Pays      | Où l'obtenir    |
| --------- | --------------- |
| USA       | Bureaux AAA     |
| UK        | Bureau de Poste |
| Australia | AAA, RACV       |
| Canada    | Bureaux CAA     |
| EU        | Autorité locale |

Coût : Généralement 15-50 $

### Validité de l'IDP en Indonesia

- **Techniquement valide** pour les courts séjours
- La police peut l'accepter ou non
- L'assurance peut avoir des problèmes
- La **catégorie moto** doit être spécifiée
- Mieux utilisé comme support, pas comme permis principal

## La Réalité sur la Route

<InfoCard variant="warning" title="Considérations Pratiques">
**Ce qui se passe réellement :**

- De nombreux touristes conduisent des scooters sans permis approprié
- La police arrête parfois les étrangers
- Amende : ~IDR 250K-500K (négociable)
- Les demandes d'indemnisation d'assurance peuvent être refusées sans permis
- Les accidents peuvent être compliqués

**Recommandation :** Obtenez un permis approprié pour votre tranquillité d'esprit.

</InfoCard>

### Si la Police vous Arrête

1. Restez calme et poli
2. Montrez vos documents
3. Si vous n'avez pas de permis, une amende est probable
4. N'argumentez pas
5. Demandez un reçu (tilang)

## Location de Scooter sans Permis

La plupart des loueurs ne vérifient pas les permis. Cependant :

### Risques

| Risque              | Conséquence                     |
| ------------------- | ------------------------------- |
| Arrêt par la police | Amende IDR 250-500K             |
| Accident            | L'assurance peut ne pas couvrir |
| Accident grave      | Problèmes juridiques potentiels |
| Blessure à autrui   | Responsabilité incertaine       |

### Note sur l'Assurance

<InfoCard variant="warning" title="Avertissement d'Assurance">
La plupart des polices d'assurance voyage exigent :
- Un permis valide pour le type de véhicule
- Le respect des lois locales

Sans permis approprié, les demandes d'indemnisation peuvent être **refusées**.

</InfoCard>

## Conseils pour les Étrangers

1. **Obtenez un SIM C si vous conduisez des scooters** - Ça vaut la tranquillité d'esprit
2. **Apportez votre permis national** - Peut aider avec les tests
3. **Allez au SAMSAT de Denpasar** - Le plus adapté aux étrangers à Bali
4. **Arrivez tôt** - Les files d'attente peuvent être longues
5. **Amenez un locuteur indonésien** - Utile mais non obligatoire
6. **Entraînez-vous sur le parcours de test** - Observez les autres d'abord
7. **Soyez patient** - La bureaucratie prend du temps
