<Calculator
  title="Comparaison des coûts de transfert"
  description="Comparez les coûts pour votre montant de transfert"
  fields={[
    {
      id: "amount",
      label: "Montant à envoyer (USD)",
      type: "number",
      defaultValue: 2000,

    },
    {
      id: "method",

        { value: "bank", label: "Virement bancaire" },
        { value: "western", label: "Western Union" },

      ],
      defaultValue: "wise"
    }
  ]}
  calculateResult={(values) => {
    const amount = Number(values.amount);

    // Fee structures (approximate)
    const fees = {
      "wise": { fixed: 3, percent: 0.006, spread: 0 },
      "bank": { fixed: 35, percent: 0, spread: 0.03 },
      "western": { fixed: 5, percent: 0.035, spread: 0.02 },
      "paypal": { fixed: 0, percent: 0.04, spread: 0.025 }
    };

    const fee = fees[values.method];
    const transferFee = fee.fixed + (amount * fee.percent);
    const spreadCost = amount * fee.spread;
    const totalCost = transferFee + spreadCost;
    const received = amount - totalCost;

    // Approximate IDR conversion (mid-market ~16,000)
    const rate = 16000 * (1 - fee.spread);
    const idrReceived = received * rate;

    return {
      total: totalCost,
      breakdown: [
        { label: "Frais de transfert", amount: transferFee },
        { label: "Marge du taux de change", amount: spreadCost },
        { label: "Coût total", amount: totalCost },
        { label: "Vous recevez", amount: received }
      ],
      currency: "USD",
      note: `Environ ${Math.round(idrReceived).toLocaleString()} IDR reçus`
    };

## Wise (TransferWise)

<InfoCard variant="tip" title="Meilleur choix global">
  **Pourquoi Wise est populaire :** - Utilise le taux de change réel du marché interbancaire - Frais
  bas et transparents - Rapide (généralement 1-2 jours) - Application facile à utiliser - Peut
  recevoir sur un compte bancaire indonesien
</InfoCard>

### Comment utiliser Wise pour Indonesia

1. Créer un compte Wise (gratuit)
2. Vérifier l'identité
3. Ajouter les coordonnées bancaires indonesiennes du destinataire
4. Envoyer depuis votre banque/carte
5. Le destinataire reçoit des IDR sur son compte

### Frais Wise

| Montant | Frais approximatifs | Vous recevez       |
| ------- | ------------------- | ------------------ |
| 500 $   | ~5 $                | ~7,9 millions IDR  |
| 1 000 $ | ~8 $                | ~15,9 millions IDR |
| 2 000 $ | ~14 $               | ~31,8 millions IDR |
| 5 000 $ | ~30 $               | ~79,5 millions IDR |

## Virements bancaires

### Virements SWIFT

Les virements bancaires traditionnels fonctionnent toujours mais sont coûteux :

| Banque          | Frais   | Notes                     |
| --------------- | ------- | ------------------------- |
| Chase           | 40-50 $ | Virement international    |
| Bank of America | 35-45 $ | Varie selon le compte     |
| Wells Fargo     | 35-45 $ | Taux standard             |
| HSBC            | 30-40 $ | Meilleur pour HSBC à HSBC |

### Coûts cachés

<InfoCard variant="warning" title="Attention aux frais cachés">
Les virements bancaires comportent plusieurs coûts :
- **Frais de la banque émettrice** : 25-50 $
- **Frais de la banque réceptrice** : 5-20 $
- **Frais des banques correspondantes** : 10-30 $
- **Marge sur le taux de change** : 2-4 %

Un transfert de 2 000 $ pourrait coûter 100 $ ou plus au total !

</InfoCard>

## Envoyer de l'argent HORS de Indonesia

<InfoCard variant="warning" title="Plus compliqué">
Envoyer de l'argent hors de Indonesia est soumis à des restrictions :
- **Documentation requise** pour les montants importants
- Peut nécessiter de prouver la **source des fonds**
- **Implications fiscales** possibles
- Les banques peuvent poser des questions

Conservez les enregistrements de tous les transferts entrants pour justifier les sorties.

</InfoCard>

## Alternatives de paiement numérique

### Pour les dépenses quotidiennes

Au lieu de tout transférer, envisagez :

1. **Carte multi-devises Wise**
   - Détenez plusieurs devises
   - Dépensez en IDR
   - Retraits aux guichets automatiques

2. **Revolut**
   - Similaire à Wise
   - Limites ATM gratuites

3. **Cartes de crédit internationales**
   - Cartes sans frais de transaction étrangère
   - Bons taux de change

### Retraits aux guichets automatiques

| Type de carte   | Frais             | Taux                 |
| --------------- | ----------------- | -------------------- |
| Wise            | ~1 $              | Taux moyen du marché |
| Revolut         | Gratuit (limites) | Taux moyen du marché |
| Charles Schwab  | Remboursé         | Taux bancaire        |
| Cartes normales | 3-5 $             | +3 % de majoration   |

## Conseils pour les meilleurs taux

1. **Évitez les bureaux de change d'aéroport** - Les pires taux
2. **Utilisez des services au taux moyen du marché** - Wise, Revolut
3. **Transférez des montants plus importants moins souvent** - Réduisez les frais fixes
4. **Comparez avant d'envoyer** - Les taux changent quotidiennement
5. **Configurez des alertes de taux** - Transférez lorsque les taux sont bons
6. **Évitez les week-ends** - Taux gelés, retards possibles
