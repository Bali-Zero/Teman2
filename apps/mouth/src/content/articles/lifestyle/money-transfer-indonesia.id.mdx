    const fees = {
      "wise": { fixed: 3, percent: 0.006, spread: 0 },

      "paypal": { fixed: 0, percent: 0.04, spread: 0.025 }
    };

    const fee = fees[values.method];
    const transferFee = fee.fixed + (amount * fee.percent);
    const spreadCost = amount * fee.spread;
    const totalCost = transferFee + spreadCost;
    const received = amount - totalCost;

    // Approximate IDR conversion (mid-market ~16,000)
    const rate = 16000 * (1 - fee.spread);
    const idrReceived = received * rate;

    return {
      total: totalCost,

      ],
      currency: "USD",
      note: `Sekitar IDR ${Math.round(idrReceived).toLocaleString()} diterima`

## Wise (TransferWise)

<InfoCard variant="tip" title="Pilihan Keseluruhan Terbaik">
  **Mengapa Wise populer:** - Menggunakan nilai tukar pasar menengah yang nyata - Biaya rendah dan
  transparan - Cepat (biasanya 1-2 hari) - Aplikasi yang mudah digunakan - Dapat menerima ke
  rekening bank Indonesia
</InfoCard>

### Cara Menggunakan Wise untuk Indonesia

1. Buat akun Wise (gratis)
2. Verifikasi identitas
3. Tambahkan detail bank Indonesia penerima
4. Kirim dari bank/kartu Anda
5. Penerima mendapatkan IDR di akun mereka

### Biaya Wise

| Jumlah | Perkiraan Biaya | Anda Menerima |
| ------ | --------------- | ------------- |
| $500   | ~$5             | ~IDR 7.9M     |
| $1,000 | ~$8             | ~IDR 15.9M    |
| $2,000 | ~$14            | ~IDR 31.8M    |
| $5,000 | ~$30            | ~IDR 79.5M    |

## Mengirim Uang KELUAR dari Indonesia

<InfoCard variant="warning" title="Lebih Rumit">
Mengirim uang keluar dari Indonesia memiliki batasan:
- **Dokumentasi diperlukan** untuk jumlah besar
- Mungkin perlu menunjukkan **sumber dana**
- **Implikasi pajak** mungkin ada
- Bank mungkin mengajukan pertanyaan

Simpan catatan semua transfer masuk untuk menjustifikasi yang keluar.

</InfoCard>

### Opsi untuk Mengirim Keluar

| Metode          | Batas                            | Catatan           |
| --------------- | -------------------------------- | ----------------- |
| Transfer bank   | Tidak ada batas (dengan dokumen) | Perlu dokumentasi |
| Wise (dari IDR) | Ya, terbatas                     | Nyaman            |
| PayPal          | Terbatas                         | Batasan penarikan |
| Kripto          | Bervariasi                       | Area abu-abu      |

## Alternatif Pembayaran Digital

### Untuk Pengeluaran Harian

Alih-alih mentransfer semuanya, pertimbangkan:

1. **Kartu Multi-Valuta Wise**
   - Simpan beberapa mata uang
   - Belanja dalam IDR
   - Penarikan ATM

2. **Revolut**
   - Mirip dengan Wise
   - Batas ATM gratis

3. **Kartu Kredit Internasional**
   - Kartu tanpa biaya transaksi luar negeri
   - Nilai tukar yang bagus

### Penarikan ATM

| Jenis Kartu    | Biaya          | Kurs           |
| -------------- | -------------- | -------------- |
| Wise           | ~$1            | Pasar menengah |
| Revolut        | Gratis (batas) | Pasar menengah |
| Charles Schwab | Diganti        | Kurs bank      |
| Kartu reguler  | $3-5           | +3% markup     |

## Tips untuk Nilai Tukar Terbaik

1. **Hindari penukaran di bandara** - Kurs terburuk
2. **Gunakan layanan kurs pasar menengah** - Wise, Revolut
3. **Transfer jumlah yang lebih besar lebih jarang** - Kurangi biaya tetap
4. **Bandingkan sebelum mengirim** - Kurs berubah setiap hari
5. **Atur peringatan kurs** - Transfer saat kurs bagus
6. **Hindari akhir pekan** - Kurs beku, kemungkinan penundaan
