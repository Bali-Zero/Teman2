# Noleggio Scooter Indonesia 2026: Guida Completa

Gli scooter sono il modo più pratico per spostarsi a Bali e in molte parti dell'Indonesia. Ecco cosa devi sapere.

## Requisiti per la Patente

<InfoCard variant="warning" title="È Necessaria la Patente">
**Requisito legale:**

Per guidare legalmente uno scooter in Indonesia, ti serve:

- **Permesso Internazionale di Guida (IDP)** con abilitazione moto, OPPURE
- **Patente indonesiana (SIM C)**

Guidare senza una patente adeguata:

- La polizia può multarti (250k-500k IDR)
- L'assicurazione potrebbe non essere valida
- Problemi di responsabilità civile in caso di incidente

Molti turisti guidano senza, ma è un rischio.

</InfoCard>

### Opzioni Patente

| Opzione       | Per                        | Durata   |
| ------------- | -------------------------- | -------- |
| IDP           | Visitatori a breve termine | 1 anno   |
| SIM C         | Titolari di KITAS          | 5 anni   |
| SIM C Turista | Alcune aree lo offrono     | Limitata |

## Consigli per la Sicurezza

### Sicurezza Essenziale

<InfoCard variant="warning" title="Incidenti in Scooter">
**Rischio n. 1 per i turisti a Bali**

Gli incidenti in scooter causano più infortuni ai turisti di qualsiasi altra cosa.

**Resta al sicuro:**

- Indossa sempre il casco (allacciato correttamente)
- Non bere prima di guidare
- Fai attenzione a sabbia, ghiaia e buche
- Presumi che gli altri non si fermino
- Non correre
- Sii extra prudente di notte
- Usa la crema solare (le braccia si scottano!)
  </InfoCard>

### Consigli di Guida

| Situazione      | Cosa fare                 |
| --------------- | ------------------------- |
| Incroci         | Rallenta, sii pronto      |
| Sorpassi        | Usa il clakson, vai piano |
| Di notte        | Evita se possibile        |
| Pioggia         | Accosta e aspetta         |
| Cani            | Rallenta, non sterzare    |
| Zone turistiche | Attenzione ai pedoni      |
| Montagna        | Scala marcia, usa i freni |

## Regole del Traffico

### Regole Chiave

| Regola             | Nota                   |
| ------------------ | ---------------------- |
| Guida a sinistra   | Come in UK, Australia  |

| Violazione     | Range Multa   |

| Senza patente  | IDR 250k-500k |
| Semaforo rosso | IDR 250k      |
| Senza STNK     | IDR 250k      |
| Contromano     | IDR 250k      |

## Assicurazione

<InfoCard variant="warning" title="L'Assicurazione Conta">
**Critico:** L'assicurazione di viaggio potrebbe NON coprirti se:

- Non hai una patente valida
- Guidi senza casco
- Sei sotto l'influenza di alcol/droghe
- Ti trovi su strade non asfaltate

**Controlla attentamente la tua polizza!**

Considera una copertura specifica per moto se guidi regolarmente.

</InfoCard>

### Opzioni Assicurative

| Tipo                   | Copertura                |
| ---------------------- | ------------------------ |
| Assicurazione viaggio  | Può coprire con patente  |
| Assicurazione noleggio | Solitamente solo terzi   |
| Polizza moto separata  | Opzione kasko            |
| Carta di credito       | Controlla bene i termini |

| Pertamax       | ~IDR 14k/L | Premium          |

## Comprare vs Noleggiare

### Considerazioni a Lungo Termine

| Fattore        | Noleggio | Acquisto               |
| -------------- | -------- | ---------------------- |
| Sotto i 3 mesi | Meglio   | Non ne vale la pena    |
| 3-6 mesi       | Calcola  | Considera              |
| Oltre 6 mesi   | Costoso  | Spesso meglio          |
| Rivendita      | N/A      | Puoi recuperare 70-80% |
