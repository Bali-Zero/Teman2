## BPJS Kesehatan

### Cos'è la BPJS?

<InfoCard variant="note" title="Obbligatoria per i titolari di KITAS">
**BPJS Kesehatan** è l'assicurazione sanitaria nazionale indonesiana. È **obbligatoria** per:
- Cittadini indonesiani
- Stranieri con KITAS che lavorano da più di 6 mesi

Il tuo datore di lavoro deve registrarti o puoi farlo tu stesso.

</InfoCard>

### Classi BPJS

| Classe   | Premio Mensile | Tipo di Stanza | Note     |
| -------- | -------------- | -------------- | -------- |
| Classe 1 | 150.000 IDR    | VIP singola    | Migliore |
| Classe 2 | 100.000 IDR    | Semi-privata   | Buona    |
| Classe 3 | 42.000 IDR     | Corsia         | Base     |

### Copertura BPJS

- Cure ambulatoriali
- Ricovero ospedaliero
- Chirurgia
- Farmaci (prontuario)
- Cure d'emergenza
- Rinvio a specialisti

### Limitazioni BPJS

- Tempi di attesa lunghi comuni
- Qualità variabile a seconda dell'ospedale
- Sistema di rinvio richiesto
- Alcuni farmaci non coperti
- Ospedali premium spesso esclusi

## Assicurazione Internazionale

### Perché molti expat scelgono l'internazionale

1. **Scelta dell'ospedale** - Accesso a ospedali privati premium
2. **Nessun rinvio** - Accesso diretto allo specialista
3. **Copertura globale** - Coperti anche in viaggio
4. **Supporto in inglese** - Comunicazione facile
5. **Evacuazione** - Evacuazione medica se necessaria

### Provider Popolari

| Provider            | A partire da  | Note               |
| ------------------- | ------------- | ------------------ |
| Cigna Global        | ~200 USD/mese | Ampia rete         |
| Allianz             | ~150 USD/mese | Ottima reputazione |
| AXA                 | ~150 USD/mese | Portata globale    |
| Pacific Cross       | ~100 USD/mese | Focus Asia         |
| April International | ~120 USD/mese | Spec. per expat    |

## Condizioni Preesistenti

<InfoCard variant="warning" title="La Trasparenza è Fondamentale">

- Chiederà informazioni sulle condizioni preesistenti
- Potrebbe escluderle inizialmente
- Offrirà copertura dopo un periodo di attesa
- Il premio potrebbe essere più alto

**Non nascondere mai le patologie** - le richieste di risarcimento possono essere rifiutate se non dichiarate.
