## Costi Scolastici

### Fasce di Rette Annuali

| Tipo di Scuola           | Costo Annuo       |
| ------------------------ | ----------------- |
| Internazionale (premium) | 20.000-35.000 USD |
| Internazionale (media)   | 10.000-20.000 USD |
| National Plus            | 3.000-10.000 USD  |
| Indonesiana privata      | 500-3.000 USD     |

## Considerazioni Importanti

### Requisiti per il Visto

<InfoCard variant="warning" title="Stato Legale">
I figli devono avere un visto regolare per frequentare la scuola:

**Richiesto:**

- KITAS per familiari a carico (legato al permesso di lavoro del genitore)
- KITAS per studenti (per motivi di studio)
- Second Home Visa (figli inclusi)

**VOA/Visa-Free:** Generalmente non sufficienti per l'iscrizione a scuola

Controlla i requisiti del visto prima dell'iscrizione!

</InfoCard>

### Supporto Linguistico

| Servizio                             | Disponibilità                                |
| ------------------------------------ | -------------------------------------------- |
| EAL (Inglese come lingua aggiuntiva) | La maggior parte delle scuole internazionali |
| Lezioni di indonesiano               | Tutte le scuole                              |
| Bahasa per principianti              | Molte offrono corsi intensivi                |
| Programmi di lingua madre            | Limitati (alcuni per le lingue principali)   |

## Opzione Homeschooling

### È Legale?

<InfoCard variant="note" title="Homeschooling in Indonesia">
L'homeschooling è **legale** in Indonesia con la dovuta registrazione.

**Requisiti:**

- Registrazione presso l'ufficio scolastico locale
- Seguire un curriculum approvato
- Valutazioni periodiche
- Documentazione mantenuta

Molte famiglie expat combinano l'homeschooling con attività locali e tutor.

</InfoCard>

### Approcci Popolari

| Approccio             | Descrizione                       |
| --------------------- | --------------------------------- |
| Scuole online         | Strutturate, accreditate          |
| Pacchetti curricolari | Autodidatta                       |
| Ibrido                | Part-time scuola + casa           |
| Unschooling           | Apprendimento guidato dal bambino |
