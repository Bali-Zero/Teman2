## Suggerimenti per il contratto di affitto

### Termini chiave da includere

| Termine      | Cosa controllare               |
| ------------ | ------------------------------ |
| Durata       | Date inizio/fine chiare        |
| Canone       | Totale e scadenze pagamenti    |
| Deposito     | Importo e condizioni reso      |
| Utenze       | Chi paga cosa                  |
| Manutenzione | Responsabilità per riparazioni |
| Recesso      | Preavviso e penali             |
| Inventario   | Lista degli oggetti inclusi    |

<InfoCard variant="tip" title="Metti tutto per iscritto">
Anche per affitti informali dovresti avere:
- Contratto scritto (può essere semplice)
- Ricevute di pagamento
- Documentazione dello stato dell'immobile
- Contatti del proprietario

I contratti indonesiani sono legalmente validi: pretendi di averne uno!

</InfoCard>
