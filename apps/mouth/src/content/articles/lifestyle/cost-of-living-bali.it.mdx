## Costi dell'alloggio

### Fasce di affitto mensile

| Tipo              | Range mensile (IDR) | Euro (circa)  | Note               |
| ----------------- | ------------------- | ------------- | ------------------ |
| Kos (camera)      | 1,5-4M              | 90-250€       | Essenziale         |
| Monolocale        | 5-10M               | 300-600€      | Con cucina         |
| Appartamento 1 ch | 8-15M               | 500-900€      | In buona zona      |
| Villa 2 camere    | 12-25M              | 750-1.500€    | Piscina e giardino |
| Villa 3+ camere   | 20-50M+             | 1.250-3.000€+ | Famiglia/premium   |

| --------------- | --------------- | ------------------- |

| Pasto in caffè  | 60-100k IDR     | 5-9M IDR            |
| Ristorante      | 100-200k IDR    | 9-18M IDR           |
| Cucinare a casa | 15-30k IDR      | 1,5-3M IDR          |

## Trasporti

| Mezzo            | Costo mensile | Note           |
| ---------------- | ------------- | -------------- |
| Noleggio scooter | 0,8-1,5M IDR  | Il più comune  |
| Acquisto scooter | 15-25M IDR    | Una tantum     |
| Benzina scooter  | 200-400k IDR  | Mensile        |
| Noleggio auto    | 5-8M IDR      | Guida autonoma |
| Auto + autista   | 10-15M IDR    | Tempo pieno    |

## Suggerimenti per risparmiare

1. **Mangia locale** - I warung sono deliziosi ed economici.
2. **Affitto a lungo termine** - Negozia per 6-12 mesi.
3. **Compra uno scooter** - Più conveniente del noleggio a lungo termine.
4. **SIM locale** - Molto più economica del roaming.
