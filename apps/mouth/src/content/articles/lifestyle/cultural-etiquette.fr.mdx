# Étiquette Culturelle Indonésienne 2026 : Guide pour les Expatriés

L'Indonésie possède de riches traditions culturelles. Comprendre les coutumes locales vous aidera à établir de meilleures relations et à éviter les malentendus.

## Valeurs Culturelles Fondamentales

<InfoCard variant="note" title="Valeurs Clés">
**La société indonésienne valorise :**

- **L'Harmonie** - Éviter les conflits, maintenir la paix
- **Le Respect** - Pour les aînés, la hiérarchie, la religion
- **La Communauté** - Le groupe avant l'individu
- **La Face** - Préserver la dignité, éviter l'embarras
- **La Patience** - Le "temps élastique" est une réalité
- **L'Hospitalité** - Accueillant envers les invités

Comprendre ces valeurs explique de nombreuses coutumes.

</InfoCard>

## Étiquette Sociale

### Salutations

| Situation           | Salutation Appropriée                                 |
| ------------------- | ----------------------------------------------------- |
| Formel/Affaires     | Légère inclinaison, poignée de main                   |
| Informel            | Sourire, signe de la main, "Halo"                     |
| Aînés               | Légère inclinaison, ton respectueux                   |
| Musulmans religieux | Poignée de main entre personnes du même sexe préférée |
| Balinais            | "Om Swastiastu" (salutation)                          |

### Contact Physique

| Comportement            | Acceptabilité                         |
| ----------------------- | ------------------------------------- |
| Poignée de main         | Normale (même sexe)                   |
| Tapoter dans le dos     | Entre amis                            |
| Toucher la tête         | Jamais (sacré)                        |
| Pointer du doigt        | Éviter (utiliser le pouce à la place) |
| Main gauche pour donner | Éviter (utiliser la main droite)      |
| Affection publique      | Rester minimal                        |

<InfoCard variant="warning" title="La Tête">
**La tête est sacrée** dans la culture indonésienne.

- Ne jamais toucher la tête de quelqu'un
- Inclut les enfants et les amis
- Même les tapes amicales sont irrespectueuses
- Les services de coiffure sont une exception (contexte professionnel)
  </InfoCard>

### Relations Commerciales

<InfoCard variant="tip" title="La Relation Avant Tout">
**En Indonesia :**

- Les affaires suivent souvent la relation
- Petites discussions avant les sujets d'affaires
- Les déjeuners/dîners d'affaires sont importants
- Établir la confiance prend du temps
- Les relations personnelles comptent

Ne vous précipitez pas sur les affaires - investissez d'abord dans les relations.

</InfoCard>

## Sensibilité Religieuse

### Islam (Religion Majoritaire)

| Considération       | Recommandation                       |
| ------------------- | ------------------------------------ |
| Prières du vendredi | Les réunions peuvent faire une pause |
| Ramadan             | Éviter de manger en public           |
| Porc/alcool         | Ne pas en offrir aux Musulmans       |
| Main droite         | Utiliser pour donner/recevoir        |
| Code vestimentaire  | Conservateur apprécié                |
| Mosquées            | Enlever les chaussures, se couvrir   |

### Hindouisme (Bali)

| Considération | Recommandation              |
| ------------- | --------------------------- |
| Temples       | Tenue appropriée exigée     |
| Offrandes     | Ne pas marcher dessus       |
| Cérémonies    | Faire preuve de respect     |
| Menstruation  | Entrée au temple restreinte |
| Jours saints  | Certaines fermetures        |

<InfoCard variant="warning" title="Code Vestimentaire des Temples">
**Lors de la visite des temples balinais :**

- Sarong exigé (souvent fourni)
- Pas de shorts/jupes courtes
- Épaules couvertes
- Écharpe autour de la taille
- Enlever souvent les chaussures

De nombreux temples proposent des locations.

</InfoCard>
