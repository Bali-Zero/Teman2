## BPJS Kesehatan

### Qu'est-ce que BPJS ?

<InfoCard variant="note" title="Obligatoire pour les Titulaires de KITAS">
**BPJS Kesehatan** est l'assurance santé nationale de l'Indonesia. Elle est **obligatoire** pour :
- Les citoyens indonésiens
- Les étrangers avec KITAS travaillant 6+ mois

Votre employeur doit vous enregistrer ou vous vous enregistrez vous-même.

</InfoCard>

### Classes BPJS

| Classe   | Prime Mensuelle | Type de Chambre  | Notes     |
| -------- | --------------- | ---------------- | --------- |
| Classe 1 | IDR 150,000     | VIP individuelle | Meilleure |
| Classe 2 | IDR 100,000     | Semi-privée      | Bonne     |
| Classe 3 | IDR 42,000      | Salle commune    | Basique   |

### Couverture BPJS

- Soins ambulatoires
- Hospitalisation
- Chirurgie
- Médicaments (formulaire)
- Soins d'urgence
- Références spécialisées

### Limitations de BPJS

- Longs temps d'attente courants
- La qualité varie selon l'hôpital
- Système de référence requis
- Certains médicaments non couverts
- Les hôpitaux premium ne sont souvent pas inclus

## Assurance Internationale

### Pourquoi de nombreux Expatriés choisissent l'International

1.  **Choix de l'hôpital** - Accès aux hôpitaux privés premium
2.  **Pas de références** - Aller directement chez le spécialiste
3.  **Couverture mondiale** - Couvert lors des voyages
4.  **Support en anglais** - Communication facile
5.  **Évacuation** - Évacuation médicale si nécessaire

### Fournisseurs Populaires

| Fournisseur         | À partir de   | Notes                 |
| ------------------- | ------------- | --------------------- |
| Cigna Global        | ~USD 200/mois | Réseau étendu         |
| Allianz             | ~USD 150/mois | Bonne réputation      |
| AXA                 | ~USD 150/mois | Portée mondiale       |
| Pacific Cross       | ~USD 100/mois | Axé sur l'Asie        |
| April International | ~USD 120/mois | Spécialiste expatriés |

<InfoCard variant="tip" title="Obtenez Plusieurs Devis">
  Les coûts d'assurance varient considérablement en fonction de : - L'âge - Le niveau de couverture
  - La franchise - La couverture géographique - Les conditions préexistantes
</InfoCard>

## Conditions Préexistantes

<InfoCard variant="warning" title="La Divulgation est Importante">
La plupart des assureurs internationaux :
- Se renseigneront sur les conditions préexistantes
- Pourront les exclure initialement
- Offriront une couverture après une période d'attente
- La prime pourra être plus élevée

**Ne jamais cacher les conditions** - les demandes peuvent être refusées si non divulguées.
