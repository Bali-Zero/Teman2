<Calculator

## Conseils pour le contrat de location

### Conditions clés à inclure

| Terme             | Ce qu'il faut vérifier               |
| ----------------- | ------------------------------------ |
| Durée             | Dates de début/fin claires           |
| Montant du loyer  | Total et calendrier de paiement      |
| Dépôt de garantie | Montant et conditions de restitution |
| Services publics  | Qui paie quoi                        |
| Entretien         | Responsabilité des réparations       |
| Résiliation       | Délai de préavis, pénalités          |
| Inventaire        | Liste des articles inclus            |

<InfoCard variant="tip" title="Obtenez un écrit">
Même les locations informelles devraient avoir :
- Accord écrit (peut être simple)
- Reçus de paiement
- Documentation de l'état
- Coordonnées du propriétaire

Les contrats indonésiens sont exécutoires - obtenez-en un !

</InfoCard>

## Meublé ou Non Meublé

### Bali/Zones Touristiques

La plupart des locations sont **entièrement meublées** :

- Lit, matelas, linge de maison
- Mobilier de salon
- Cuisine équipée
- Climatisation
- Eau chaude
- Souvent inclut le WiFi

### Jakarta/Villes

Mélange d'options :

- Appartements avec services : entièrement meublés
- Appartements réguliers : ameublement de base
- Maisons : peuvent être non meublées

## Économies à long terme

| Durée   | Remise typique      |
| ------- | ------------------- |
| Mensuel | Prix plein          |
| 3 mois  | 5-10% de réduction  |
| 6 mois  | 15-25% de réduction |
| 12 mois | 25-40% de réduction |

<InfoCard variant="tip" title="Négociez !">
  Conseils pour de meilleurs tarifs : - Demandez directement (n'acceptez pas le
  premier prix) - Offrez une durée plus longue - Payez d'avance si possible -
  Basse saison = meilleures offres - Directement avec le propriétaire = pas de
  frais d'agence
</InfoCard>
