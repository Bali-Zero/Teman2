# Sistem Kesehatan Indonesia 2026: Panduan Ekspatriat

Layanan kesehatan di Indonesia berkisar dari klinik dasar hingga rumah sakit swasta kelas dunia. Inilah yang perlu diketahui oleh para ekspatriat.

## Gambaran Umum Layanan Kesehatan

<InfoCard variant="note" title="Lansekap Layanan Kesehatan">
**Sistem kesehatan Indonesia:**

- **Rumah sakit umum** - Terjangkau tetapi seringkali ramai
- **Rumah sakit swasta** - Pelayanan lebih baik, biaya lebih tinggi
- **Rumah sakit internasional** - Standar Barat, harga premium
- **Klinik** - Untuk masalah ringan, berlimpah di mana-mana

Kebanyakan ekspatriat menggunakan **rumah sakit swasta/internasional** untuk perawatan berkualitas.

</InfoCard>

## Biaya Medis

### Pengeluaran Tipikal

| Layanan                | Umum          | Swasta        | Internasional |
| ---------------------- | ------------- | ------------- | ------------- |
| Konsultasi Dokter Umum | IDR 50-100rb  | IDR 300-500rb | IDR 500rb-1jt |
| Spesialis              | IDR 100-200rb | IDR 500rb-1jt | IDR 1-2jt     |
| Kunjungan Darurat      | IDR 200-500rb | IDR 1-3jt     | IDR 3-10jt    |
| Kamar RS/malam         | IDR 200-500rb | IDR 1-3jt     | IDR 3-8jt     |
| Operasi Kecil          | IDR 2-5jt     | IDR 10-30jt   | IDR 30-100jt  |
| Operasi Besar          | IDR 20-50jt   | IDR 50-200jt  | IDR 200jt+    |

### Metode Pembayaran

| Metode                      | Diterima                            |
| --------------------------- | ----------------------------------- |
| Tunai                       | Selalu                              |
| Kartu kredit/debit          | Rumah sakit Swasta/Internasional    |
| Penagihan langsung asuransi | Rumah sakit besar dengan perjanjian |
| Transfer                    | Biasanya diterima                   |

<InfoCard variant="warning" title="Pembayaran Seringkali Di Muka">
Tidak seperti di beberapa negara, rumah sakit di Indonesia seringkali memerlukan:

- **Deposit** sebelum rawat inap
- **Pembayaran** sebelum pulang
- **Tunai** untuk klinik kecil

Selalu siapkan dana darurat atau asuransi dengan penagihan langsung!

</InfoCard>

## Situasi Darurat

### Apa yang Harus Dilakukan

| Keadaan Darurat | Tindakan                                    |
| --------------- | ------------------------------------------- |
| Mengancam nyawa | Hubungi 118 (ambulans) atau langsung ke UGD |
| Serius          | Pergi ke rumah sakit terdekat dengan UGD    |
| Sedang          | Rawat jalan rumah sakit swasta              |
| Ringan          | Klinik lokal                                |

### Nomor Darurat

| Layanan           | Nomor          |
| ----------------- | -------------- |
| Darurat umum      | 112            |
| Ambulans          | 118            |
| BIMC Bali         | +62 361 761263 |
| SOS Internasional | Cek polis Anda |

<InfoCard variant="warning" title="Realitas Ambulans">
**Penting untuk diketahui:**

- Respon ambulans bisa lambat
- Kemacetan bisa menunda kedatangan
- Seringkali lebih cepat naik taksi/Grab
- Ketahui lokasi rumah sakit terdekat
- Simpan nomor telepon rumah sakit

Dalam keadaan darurat, jangan menunggu - langsung pergi jika memungkinkan.

</InfoCard>
