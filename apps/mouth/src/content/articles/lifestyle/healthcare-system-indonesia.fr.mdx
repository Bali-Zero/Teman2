# Système de santé en Indonesia 2026 : Guide pour les expatriés

Les soins de santé en Indonesia vont des cliniques de base aux hôpitaux privés de classe mondiale. Voici ce que les expatriés doivent savoir.

## Aperçu des soins de santé

<InfoCard variant="note" title="Paysage des soins de santé">
**Le système de santé de l'Indonesia :**

- **Hôpitaux publics** - Abordables mais souvent bondés
- **Hôpitaux privés** - Meilleur service, coûts plus élevés
- **Hôpitaux internationaux** - Normes occidentales, prix premium
- **Cliniques** - Pour les problèmes mineurs, abondantes partout

La plupart des expatriés utilisent les **hôpitaux privés/internationaux** pour des soins de qualité.

</InfoCard>

## Coûts médicaux

### Dépenses typiques

| Service                  | Public       | Privé        | International |
| ------------------------ | ------------ | ------------ | ------------- |
| Consultation généraliste | IDR 50-100K  | IDR 300-500K | IDR 500K-1M   |
| Spécialiste              | IDR 100-200K | IDR 500K-1M  | IDR 1-2M      |
| Visite aux urgences      | IDR 200-500K | IDR 1-3M     | IDR 3-10M     |
| Chambre d'hôpital/nuit   | IDR 200-500K | IDR 1-3M     | IDR 3-8M      |
| Chirurgie mineure        | IDR 2-5M     | IDR 10-30M   | IDR 30-100M   |
| Chirurgie majeure        | IDR 20-50M   | IDR 50-200M  | IDR 200M+     |

### Modes de paiement

| Méthode                             | Acceptée                       |
| ----------------------------------- | ------------------------------ |
| Cash                                | Toujours                       |
| Carte de crédit/débit               | Hôpitaux privés/internationaux |
| Facturation directe par l'assurance | Grands hôpitaux avec accords   |
| Virement                            | Généralement acceptée          |

<InfoCard variant="warning" title="Paiement souvent à l'avance">
Contrairement à certains pays, les hôpitaux indonésiens exigent souvent :

- Un **acompte** avant l'admission
- Un **paiement** avant la sortie
- Du **cash** pour les petites cliniques

Ayez toujours des fonds d'urgence ou une assurance avec facturation directe !

</InfoCard>

## Situations d'urgence

### Que faire

| Urgence       | Action                                                       |
| ------------- | ------------------------------------------------------------ |
| Vie en danger | Appeler le 118 (ambulance) ou aller directement aux urgences |
| Grave         | Aller à l'hôpital le plus proche avec des urgences           |
| Modérée       | Service ambulatoire d'un hôpital privé                       |
| Mineure       | Clinique locale                                              |

### Numéros d'urgence

| Service           | Numéro                |
| ----------------- | --------------------- |
| Urgence générale  | 112                   |
| Ambulance         | 118                   |
| BIMC Bali         | +62 361 761263        |
| International SOS | Vérifier votre police |

<InfoCard variant="warning" title="Réalité des ambulances">
**Important à savoir :**

- La réponse des ambulances peut être lente
- La circulation peut retarder l'arrivée
- Souvent plus rapide de prendre un taxi/Grab
- Connaître l'emplacement de l'hôpital le plus proche
- Avoir les numéros d'hôpital enregistrés

En cas d'urgence, n'attendez pas - allez-y directement si possible.

</InfoCard>

## Pharmacie (Apotek)

### Médicaments

<InfoCard variant="note" title="Conseils pour la pharmacie">
**Bon à savoir :**

- De nombreux médicaments sont disponibles sans ordonnance
- Les médicaments courants sont beaucoup moins chers que dans les pays occidentaux
- Des marques internationales et des génériques locaux sont disponibles
- Le pharmacien peut souvent recommander des solutions pour les problèmes mineurs
- Apportez l'ordonnance du médecin pour les substances réglementées
  </InfoCard>

### Chaînes de pharmacies courantes

| Chaîne      | Notes                                                           |
| ----------- | --------------------------------------------------------------- |
| Guardian    | Emplacements dans les centres commerciaux, sélection plus large |
| Century     | Nombreux emplacements                                           |
| Kimia Farma | Grande chaîne gouvernementale                                   |
| Apotek K-24 | Emplacements ouverts 24h/24                                     |
