# Services Bancaires pour les Étrangers en Indonesia 2026 : Guide Complet

Avoir un compte bancaire indonésien simplifie grandement la vie. Voici comment les étrangers peuvent ouvrir un compte et gérer leur argent.

## Les Étrangers Peuvent-ils Ouvrir des Comptes Bancaires ?

<InfoCard variant="note" title="Oui, avec certaines exigences">
Les étrangers peuvent ouvrir des comptes bancaires indonésiens s'ils possèdent :
- Un passeport valide
- Un **KITAS ou KITAP** (pour les comptes complets)
- Un **NPWP** (numéro fiscal - souvent requis)
- Une preuve d'adresse en Indonesia

Certaines banques autorisent des comptes limités pour les touristes, mais les services complets nécessitent la résidence.

</InfoCard>

## Services Bancaires Sans KITAS

Si vous n'avez pas de KITAS :

### Options

1.  **Comptes d'épargne touristiques** - Limités, certaines banques les proposent
2.  **Banques numériques** - Certaines acceptent uniquement le passeport
3.  **Banques internationales** - HSBC avec une relation globale
4.  **Applications de paiement** - GoPay, OVO (fonctions limitées)

<InfoCard variant="warning" title="Limité Sans KITAS">
  Sans KITAS, les options bancaires sont très limitées. Envisagez : -
  L'utilisation de cartes internationales (Wise, Revolut) - Le retrait aux
  guichets automatiques avec des cartes étrangères - Les applications de
  paiement numérique pour les dépenses quotidiennes
</InfoCard>

## Virements Internationaux

### Recevoir de l'Argent en Indonesia

| Méthode               | Vitesse    | Coût   | Notes              |
| --------------------- | ---------- | ------ | ------------------ |
| **Wise**              | 1-2 jours  | Faible | Meilleurs taux     |
| **Virement bancaire** | 2-5 jours  | Élevé  | Traditionnel       |
| **PayPal**            | Instantané | Moyen  | Retrait limité     |
| **Western Union**     | Instantané | Élevé  | Retrait en espèces |

### Envoyer de l'Argent à l'Étranger

- Soumis à des exigences documentaires
- Peut nécessiter de prouver l'origine des fonds
- Implications fiscales possibles
- Certaines limites sur les montants

## Frais et Coûts

### Frais Courants

| Type de Frais               | Fourchette    | Notes                       |
| --------------------------- | ------------- | --------------------------- |
| Administration mensuelle    | IDR 0-15K     | Certains comptes gratuits   |
| Retrait GAB (propre banque) | Gratuit       | Sur le propre réseau        |
| Retrait GAB (autre banque)  | IDR 7,500-15K | Par transaction             |
| Virement (même banque)      | Gratuit-5K    | Généralement gratuit        |
| Virement (autre banque)     | IDR 6,500-10K | Interbancaire               |
| SWIFT international         | IDR 50-200K   | Plus frais de correspondant |
