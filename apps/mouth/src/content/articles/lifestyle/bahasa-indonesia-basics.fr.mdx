# Bases du Bahasa Indonesia 2026 : Guide Linguistique Essentiel

Même une connaissance basique du Bahasa Indonesia est d'une aide énorme dans la vie quotidienne. Voici ce que vous devez savoir pour commencer.

## Pourquoi Apprendre ?

<InfoCard variant="note" title="Avantages de l'Apprentissage">
**Apprendre le Bahasa Indonesia :**

- Montre le respect de la culture locale
- Permet d'obtenir un meilleur service et de meilleurs prix
- Ouvre des portes et construit des relations
- Rend la vie quotidienne beaucoup plus facile
- Aide en cas d'urgence
- Beaucoup d'Indonésiens ne parlent pas anglais

Même le simple fait d'essayer est apprécié !

</InfoCard>

## Grammaire de Base

### Structure des Phrases

<InfoCard variant="note" title="Structure Simple">
**Schéma de base :** Sujet + Verbe + Objet

Comme en français :

- Saya makan nasi = Je mange du riz
- Dia minum kopi = Il/Elle boit du café
- Kamu tinggal di mana? = Tu habites où ?
  </InfoCard>

### Pas de Changement de Verbe !

| Français           | Indonésien         |
| ------------------ | ------------------ |
| Je mange           | Saya makan         |
| Elle mange         | Dia makan          |
| Ils mangent        | Mereka makan       |
| Hier j'ai mangé    | Kemarin saya makan |
| Demain je mangerai | Besok saya makan   |

Les mots de temps indiquent le temps, pas les changements de verbe !

### Poser des Questions

| Méthode            | Exemple                                        |
| ------------------ | ---------------------------------------------- |
| Ajouter "?"        | Kamu suka? (Tu aimes ?)                        |
| Ajouter "apa"      | Apa kamu suka? (Aimes-tu ?)                    |
| Mots interrogatifs | Siapa, Apa, Di mana, Kapan, Mengapa, Bagaimana |
