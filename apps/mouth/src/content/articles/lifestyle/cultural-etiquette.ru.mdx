# Индонезийский Культурный Этикет 2026: Руководство для Экспатов

Индонезия богата культурными традициями. Понимание местных обычаев поможет вам строить лучшие отношения и избегать недоразумений.

## Основные Культурные Ценности

<InfoCard variant="note" title="Ключевые Ценности">
**Индонезийское общество ценит:**

- **Гармонию** - Избегание конфликтов, поддержание мира
- **Уважение** - К старшим, иерархии, религии
- **Сообщество** - Группа важнее индивидуума
- **Лицо** - Сохранение достоинства, избегание смущения
- **Терпение** - "Резиновое время" реально
- **Гостеприимство** - Радушный прием гостей

Понимание этих ценностей объясняет многие обычаи.

</InfoCard>

## Социальный Этикет

### Приветствия

| Ситуация               | Соответствующее Приветствие              |
| ---------------------- | ---------------------------------------- |
| Формальная/Деловая     | Легкий поклон, рукопожатие               |
| Неформальная           | Улыбка, взмах рукой, "Хало"              |
| Старшие                | Легкий поклон, уважительный тон          |
| Религиозные Мусульмане | Предпочтительно рукопожатие того же пола |
| Балийцы                | "Ом Свастиасту" (приветствие)            |

### Физический Контакт

| Поведение                     | Приемлемость                          |
| ----------------------------- | ------------------------------------- |
| Рукопожатие                   | Нормально (того же пола)              |
| Похлопывание по спине         | Между друзьями                        |
| Прикосновение к голове        | Никогда (священно)                    |
| Указание пальцем              | Избегать (использовать большой палец) |
| Левая рука для передачи       | Избегать (использовать правую руку)   |
| Публичные проявления нежности | Свести к минимуму                     |

<InfoCard variant="warning" title="Голова">
**Голова священна** в индонезийской культуре.

- Никогда не касайтесь чьей-либо головы
- Включая детей и друзей
- Даже шутливые похлопывания неуважительны
- Услуги парикмахера являются исключением (профессиональный контекст)
  </InfoCard>

### Деловые Отношения

<InfoCard variant="tip" title="Отношения Прежде Всего">
**В Индонезии:**

- Бизнес часто следует за отношениями
- Неформальная беседа перед деловыми вопросами
- Обеды/ужины важны
- Построение доверия занимает время
- Личные отношения имеют значение

Не торопитесь с делами – сначала инвестируйте в отношения.

### Индуизм (Bali)

| Соображение | Руководство                      |
| ----------- | -------------------------------- |
| Храмы       | Требуется соответствующая одежда |
| Подношения  | Не переступайте                  |

<InfoCard variant="warning" title="Дресс-код для Храмов">
**Посещение балийских храмов:**

- Саронг обязателен (часто предоставляется)
- Без шорт/коротких юбок
- Плечи должны быть прикрыты
- Пояс на талии
- Часто снимайте обувь

Во многих храмах доступна аренда.
