## Calcolatore dei Costi di Trasferimento

<Calculator
  title="Confronto Costi di Trasferimento"
  description="Confronta i costi per l'importo che desideri inviare"
  fields={[
    {
      id: "amount",
      label: "Importo da Inviare (USD)",
      type: "number",
      defaultValue: 2000,
      min: 100,
      step: 100,
      suffix: "USD"
    },
    {
      id: "method",
      label: "Metodo di Trasferimento",
      type: "select",
      options: [
        { value: "wise", label: "Wise" },
        { value: "bank", label: "Bonifico Bancario" },
        { value: "western", label: "Western Union" },
        { value: "paypal", label: "PayPal" }
      ],
      defaultValue: "wise"
    }
  ]}
  calculateResult={(values) => {
    const amount = Number(values.amount);

    // Struttura commissioni (approssimativa)
    const fees = {
      "wise": { fixed: 3, percent: 0.006, spread: 0 },
      "bank": { fixed: 35, percent: 0, spread: 0.03 },
      "western": { fixed: 5, percent: 0.035, spread: 0.02 },
      "paypal": { fixed: 0, percent: 0.04, spread: 0.025 }
    };

    const fee = fees[values.method];
    const transferFee = fee.fixed + (amount * fee.percent);
    const spreadCost = amount * fee.spread;
    const totalCost = transferFee + spreadCost;
    const received = amount - totalCost;

    // Conversione IDR approssimativa (medio mercato ~16.000)
    const rate = 16000 * (1 - fee.spread);
    const idrReceived = received * rate;

    return {
      total: totalCost,
      breakdown: [
        { label: "Commissione Trasferimento", amount: transferFee },
        { label: "Spread Tasso di Cambio", amount: spreadCost },
        { label: "Costo Totale", amount: totalCost },
        { label: "Riceverai", amount: received }
      ],
      currency: "USD",
      note: `Circa IDR ${Math.round(idrReceived).toLocaleString()} ricevuti`
    };

}}

## Wise (TransferWise)

<InfoCard variant="tip" title="Migliore Scelta Assoluta">
  **Perché Wise è popolare:** - Utilizza il tasso di cambio reale medio di mercato - Commissioni
  basse e trasparenti - Veloce (solitamente 1-2 giorni) - App facile da usare - Possibilità di
  ricevere su conto bancario indonesiano
</InfoCard>

### Come usare Wise per l'Indonesia

1. Crea un account Wise (gratuito)
2. Verifica la tua identità
3. Aggiungi i dati bancari indonesiani del destinatario
4. Invia denaro dalla tua banca o carta
5. Il destinatario riceve IDR sul proprio conto

### Commissioni Wise

| Importo | Commissione Approssimativa | Ricevi     |
| ------- | -------------------------- | ---------- |
| $500    | ~$5                        | ~IDR 7.9M  |
| $1,000  | ~$8                        | ~IDR 15.9M |
| $2,000  | ~$14                       | ~IDR 31.8M |
| $5,000  | ~$30                       | ~IDR 79.5M |

### Costi Nascosti

<InfoCard variant="warning" title="Attenzione ai Costi Nascosti">
I trasferimenti bancari hanno molteplici costi:
- **Commissione banca mittente**: $25-50
- **Commissione banca ricevente**: $5-20
- **Commissioni banche corrispondenti**: $10-30
- **Markup tasso di cambio**: 2-4%

Un trasferimento di $2,000 potrebbe costare oltre $100 in totale!

</InfoCard>

## Inviare Denaro FUORI dall'Indonesia

<InfoCard variant="warning" title="Più Complicato">
L'invio di denaro fuori dall'Indonesia presenta delle restrizioni:
- **Documentazione richiesta** per grandi importi
- Potrebbe essere necessario mostrare la **fonte dei fondi**
- Possibili **implicazioni fiscali**

Conserva i record di tutti i trasferimenti in entrata per giustificare quelli in uscita.

## Alternative di Pagamento Digitale

### Per le Spese Quotidiane

Invece di trasferire tutto, considera:

1. **Carta Multi-Valuta Wise**
   - Gestisci più valute
   - Spendi in IDR
   - Prelievi ATM

2. **Revolut**
   - Simile a Wise
   - Limiti prelievo ATM gratuito

3. **Carte di Credito Internazionali**
   - Carte senza commissioni per transazioni estere
   - Buoni tassi di cambio

### Prelievi ATM

| Tipo di Carta  | Commissione     | Tasso          |
| -------------- | --------------- | -------------- |
| Wise           | ~$1             | Medio mercato  |
| Revolut        | Gratis (limiti) | Medio mercato  |
| Charles Schwab | Rimborsata      | Tasso bancario |
| Carte comuni   | $3-5            | +3% markup     |

## Consigli per i Tassi Migliori

1. **Evita i cambi in aeroporto** - I tassi peggiori
2. **Usa servizi con tasso medio di mercato** - Wise, Revolut
3. **Trasferisci importi maggiori meno spesso** - Riduci le commissioni fisse
4. **Confronta prima di inviare** - I tassi cambiano ogni giorno
5. **Imposta avvisi sul tasso** - Trasferisci quando i tassi sono favorevoli
6. **Evita i fine settimana** - Tassi bloccati, possibili ritardi
