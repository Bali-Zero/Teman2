# Le basi della lingua indonesiana 2026: Guida essenziale

Anche una conoscenza base del Bahasa Indonesia aiuta enormemente nella vita quotidiana. Ecco cosa devi sapere per iniziare.

## Perché imparare?

<InfoCard variant="note" title="Vantaggi dell'apprendimento">
**Imparare il Bahasa Indonesia:**

- Mostra rispetto per la cultura locale
- Aiuta a ottenere servizi e prezzi migliori
- Apre porte e costruisce relazioni
- Rende la vita quotidiana molto più semplice
- Molti indonesiani non parlano inglese

Anche solo provarci viene molto apprezzato!

</InfoCard>

## Buone notizie: è facile!

### Perché il Bahasa è accessibile

| Caratteristica      | Perché è facile                  |
| :------------------ | :------------------------------- |
| Niente toni         | A differenza di Thai o Cinese    |
| Alfabeto latino     | Facile da leggere                |
| Niente coniugazione | I verbi non cambiano             |
| Niente genere       | Nessun maschile/femminile        |
| Fonetico            | Si pronuncia come si scrive      |
| Grammatica semplice | Struttura Soggetto-Verbo-Oggetto |

| Indonesiano   | Italiano        | Pronuncia        |
| :------------ | :-------------- | :--------------- |
| Selamat pagi  | Buongiorno      | se-LA-mat PA-gi  |
| Selamat siang | Buon pomeriggio | se-LA-mat si-ANG |
| Selamat sore  | Buonasera       | se-LA-mat SO-ray |
| Selamat malam | Buonanotte      | se-LA-mat MA-lam |
| Apa kabar?    | Come stai?      | A-pa KA-bar      |
| Baik          | Bene            | BA-ik            |
| Sampai jumpa  | Arrivederci     | SAM-pai JUM-pa   |

### Cortesia

| Indonesiano  | Italiano                                    | Pronuncia       |
| :----------- | :------------------------------------------ | :-------------- |
| Terima kasih | Grazie                                      | te-RI-ma KA-sih |
| Sama-sama    | Prego / Di nulla                            | SA-ma SA-ma     |

| Permisi      | Scusi (per passare o attirare l'attenzione) | per-MI-si       |
