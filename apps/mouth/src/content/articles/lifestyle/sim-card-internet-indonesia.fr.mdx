### Enregistrement IMEI

<InfoCard variant="warning" title="Important pour les téléphones étrangers">
Les téléphones étrangers doivent enregistrer leur **IMEI** pour fonctionner avec les cartes SIM indonésiennes au-delà de 90 jours.

**Options :**

1. Enregistrer à l'arrivée à l'aéroport (gratuit pour le premier téléphone)
2. Enregistrer en ligne via Bea Cukai (douanes)
3. Payer une taxe pour les appareils supplémentaires (~2.5M IDR)

Sans enregistrement, votre carte SIM cessera de fonctionner après 90 jours.

</InfoCard>

## Configuration Nomade Numérique

<InfoCard variant="tip" title="Configuration Recommandée">
**Pour un travail à distance fiable :**

1. **Principal** : Fibre fixe (IndiHome/Biznet)
2. **Sauvegarde** : Carte SIM Telkomsel avec données
3. **Urgence** : WiFi de poche ou point d'accès téléphonique

Ne jamais dépendre d'une seule connexion pour les appels importants !

</InfoCard>

## Dépannage

### Connexion Lente ?

| Problème              | Solution                                               |
| --------------------- | ------------------------------------------------------ |
| Congestion            | Passer à un fournisseur moins chargé                   |
| Emplacement           | Se rapprocher de la fenêtre/du routeur                 |
| Limitation de vitesse | Vérifier l'utilisation des données, acheter un forfait |
| VPN nécessaire        | Utiliser un service VPN de qualité                     |

### VPN en Indonésie

<InfoCard variant="note" title="Utilisation du VPN">
Les VPN ne sont **pas illégaux** en Indonésie mais :
- Certains sites sont bloqués (Reddit, etc.)
- Le streaming peut nécessiter un VPN
- Des VPN de qualité sont recommandés
- Les VPN gratuits sont souvent lents

Options populaires : ExpressVPN, NordVPN, Surfshark

</InfoCard>

## Conseils Rapides

1. **Achetez une carte SIM à l'aéroport** - Le plus simple pour les touristes
2. **Telkomsel pour voyager** - Meilleure couverture en dehors des villes
3. **XL/Tri pour les villes** - Meilleur rapport qualité-prix si vous restez sur place
4. **Rechargez via les applications** - GoPay, OVO, Dana fonctionnent
5. **Vérifiez l'application MyTelkomsel** - Gestion facile des forfaits
6. **Enregistrez l'IMEI tôt** - N'attendez pas d'être bloqué
7. **Ayez une sauvegarde** - Ayez toujours des données mobiles comme sauvegarde
