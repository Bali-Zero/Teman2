<Calculator
  title="Сравнение стоимости перевода"
  description="Сравните стоимость для вашей суммы перевода"
  fields={[
    {
      id: "amount",
      label: "Сумма для отправки (USD)",
      type: "number",
      defaultValue: 2000,
      min: 100,
      step: 100,
      suffix: "USD"
    },
    {
      id: "method",
      label: "Способ перевода",
      type: "select",
      options: [
        { value: "wise", label: "Wise" },
        { value: "bank", label: "Банковский перевод" },
        { value: "western", label: "Western Union" },
        { value: "paypal", label: "PayPal" }
      ],
      defaultValue: "wise"
    }
  ]}
  calculateResult={(values) => {
    const amount = Number(values.amount);

    // Fee structures (approximate)
    const fees = {
      "wise": { fixed: 3, percent: 0.006, spread: 0 },
      "bank": { fixed: 35, percent: 0, spread: 0.03 },
      "western": { fixed: 5, percent: 0.035, spread: 0.02 },
      "paypal": { fixed: 0, percent: 0.04, spread: 0.025 }
    };

    const fee = fees[values.method];
    const transferFee = fee.fixed + (amount * fee.percent);
    const spreadCost = amount * fee.spread;
    const totalCost = transferFee + spreadCost;
    const received = amount - totalCost;

    // Approximate IDR conversion (mid-market ~16,000)
    const rate = 16000 * (1 - fee.spread);
    const idrReceived = received * rate;

    return {
      total: totalCost,
      breakdown: [
        { label: "Комиссия за перевод", amount: transferFee },
        { label: "Спред обменного курса", amount: spreadCost },
        { label: "Общая стоимость", amount: totalCost },
        { label: "Вы получаете", amount: received }
      ],
      currency: "USD",
      note: `Приблизительно ${Math.round(idrReceived).toLocaleString()} IDR получено`
    };

}}

## Wise (TransferWise)

<InfoCard variant="tip" title="Лучший выбор в целом">
  **Почему Wise популярен:** - Использует реальный среднерыночный обменный курс - Низкие, прозрачные
  комиссии - Быстро (обычно 1-2 дня) - Простое в использовании приложение - Можно получать на
  индонезийский банковский счет
</InfoCard>

### Как использовать Wise для Indonesia

1. Создайте аккаунт Wise (бесплатно)
2. Подтвердите личность
3. Добавьте реквизиты индонезийского банковского счета получателя
4. Отправьте со своего банка/карты
5. Получатель получает IDR на свой счет

### Комиссии Wise

| Сумма  | Приблизительная комиссия | Вы получаете  |
| ------ | ------------------------ | ------------- |
| $500   | ~$5                      | ~7,9 млн IDR  |
| $1,000 | ~$8                      | ~15,9 млн IDR |
| $2,000 | ~$14                     | ~31,8 млн IDR |
| $5,000 | ~$30                     | ~79,5 млн IDR |

## Отправка денег ИЗ Indonesia

<InfoCard variant="warning" title="Сложнее">
Отправка денег из Indonesia имеет ограничения:
- **Требуется документация** для крупных сумм
- Возможно, потребуется показать **источник средств**
- Возможны **налоговые последствия**
- Банки могут задавать вопросы

Сохраняйте записи обо всех входящих переводах, чтобы обосновать исходящие.

</InfoCard>

## Альтернативы цифровых платежей

### Для повседневных расходов

Вместо того, чтобы переводить все, рассмотрите:

1. **Мультивалютная карта Wise**
   - Храните несколько валют
   - Тратьте в IDR
   - Снятие наличных в банкоматах

2. **Revolut**
   - Похож на Wise
   - Бесплатные лимиты на снятие наличных в банкоматах

3. **Международные кредитные карты**
   - Карты без комиссии за иностранные транзакции
   - Хорошие обменные курсы

### Снятие наличных в банкоматах

| Тип карты      | Комиссия           | Курс            |
| -------------- | ------------------ | --------------- |
| Wise           | ~$1                | Среднерыночный  |
| Revolut        | Бесплатно (лимиты) | Среднерыночный  |
| Charles Schwab | Возврат            | Банковский курс |
| Обычные карты  | $3-5               | +3% наценка     |

## Советы для получения лучших курсов

1. **Избегайте обменников в аэропортах** - Худшие курсы
2. **Используйте сервисы со среднерыночным курсом** - Wise, Revolut
3. **Переводите более крупные суммы реже** - Уменьшите фиксированные комиссии
4. **Сравнивайте перед отправкой** - Курсы меняются ежедневно
5. **Настройте оповещения о курсах** - Переводите, когда курсы выгодны
6. **Избегайте выходных** - Курсы заморожены, возможны задержки
