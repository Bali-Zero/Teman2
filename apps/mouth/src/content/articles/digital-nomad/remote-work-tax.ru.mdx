## Разъяснение налогового резидентства

<InfoCard variant="warning" title="Правило 183 дней">
**Условия для налогового резидентства в Indonesia:**

1. Присутствие в Indonesia **183+ дня** в течение 12 месяцев ИЛИ
2. Проживание в Indonesia с **намерением остаться**

**Если вы налоговый резидент:**

- Облагаетесь налогом на мировой доход
- Должны иметь NPWP
- Должны подавать ежегодную налоговую декларацию

Это применяется независимо от типа визы!

</InfoCard>

## Работа по туристической визе

<InfoCard variant="warning" title="Серая зона">
**Технически:**
- Туристическая виза = работа запрещена
- Удаленная работа на иностранных клиентов = серая зона
- Indonesia активно не применяла меры в отношении удаленных работников
- Но правила могут быть применены

**Реальность:**

- Многие цифровые кочевники работают по туристическим визам
- Технически нелегально, если это "работа"
- В настоящее время низкий уровень применения мер
- Риск вы оцениваете сами

Для полного соблюдения рассмотрите визу цифрового кочевника E33G (Remote Worker Visa).

</InfoCard>

| Отчитываться об иностранных активах | Если применимо                    |

### Налоговый калькулятор

<Calculator
  title="Оценка подоходного налога"
  description="Налог Indonesia на удаленный доход"
  fields={[
    {
      id: "monthly",
      label: "Ежемесячный доход (IDR)",
      type: "number",
      defaultValue: 30000000,
      min: 0
    },
    {
      id: "resident",
      label: "Статус",
      type: "select",
      options: [
        { value: "resident", label: "Налоговый резидент" },
        { value: "nonresident", label: "Нерезидент" }
      ],
      defaultValue: "resident"
    }
  ]}
  calculateResult={(values) => {
    const annual = values.monthly * 12;
    const ptkp = 54000000; // Standard deduction

    let taxable, tax;

    if (values.resident === "resident") {
      taxable = Math.max(0, annual - ptkp);

      // Progressive rates
      if (taxable <= 60000000) {
        tax = taxable * 0.05;
      } else if (taxable <= 250000000) {
        tax = 3000000 + (taxable - 60000000) * 0.15;
      } else if (taxable <= 500000000) {
        tax = 3000000 + 28500000 + (taxable - 250000000) * 0.25;
      } else if (taxable <= 5000000000) {
        tax = 3000000 + 28500000 + 62500000 + (taxable - 500000000) * 0.30;
      } else {
        tax = 3000000 + 28500000 + 62500000 + 1350000000 + (taxable - 5000000000) * 0.35;
      }
    } else {
      // Non-resident flat rate
      taxable = annual;
      tax = annual * 0.20;
    }

    return {
      total: Math.round(tax),
      breakdown: [
        { label: "Годовой доход", amount: annual },
        { label: values.resident === "resident" ? "После вычета PTKP" : "Налогооблагаемая сумма (фиксированная ставка)", amount: Math.round(taxable) },
        { label: "Приблизительный годовой налог", amount: Math.round(tax) },
        { label: "Эквивалент ежемесячного налога", amount: Math.round(tax / 12) }
      ],
      currency: "IDR",
      note: values.resident === "resident" ? "Прогрессивные ставки 5-35%" : "Фиксированная ставка 20% для нерезидентов"

## Налог в родной стране

### Не забудьте о доме

<InfoCard variant="note" title="Риск двойного налогообложения">
**Вы все еще можете быть должны налог на родине:**

- Граждане США: Облагаются налогом на мировой доход независимо
- Большинство стран: Налоговые резиденты платят налог на родине
- Договоры: Могут уменьшить, но не устранить
- Отчетность: Возможно, потребуется сообщать об иностранных доходах

**Проверьте информацию в своей родной стране!**

- Правила налогового резидентства там
- Отчетность об иностранных доходах
- Преимущества налоговых договоров
- Иностранные налоговые кредиты
  </InfoCard>

### Распространенные родные страны

| Страна         | Если вы уезжаете                             |
| -------------- | -------------------------------------------- |
| США            | По-прежнему облагается налогом как гражданин |
| Великобритания | Может оставаться налоговым резидентом        |
| Австралия      | Применяется правило 183 дней                 |

## Налоговые договоры

### Как помогают договоры

Indonesia имеет налоговые договоры со многими странами, которые:

- Предотвращают двойное налогообложение
- Определяют, какая страна облагает налогом что
- Разрешают иностранные налоговые кредиты
- Могут снижать ставки

### Ключевые преимущества договоров

| Тип дохода            | Преимущество по договору                      |
| --------------------- | --------------------------------------------- |
| Трудовая деятельность | Обычно облагается налогом по месту выполнения |
| Самозанятость         | Зависит от постоянного представительства      |
| Дивиденды             | Сниженные ставки                              |
| Проценты              | Сниженные ставки                              |
| Роялти                | Сниженные ставки                              |
