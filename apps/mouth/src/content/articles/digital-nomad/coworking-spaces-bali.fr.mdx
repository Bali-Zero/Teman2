## Calculateur de coût de coworking

<Calculator
  title="Budget Coworking"
  description="Estimez vos coûts d'espace de travail mensuels"
  fields={[
    {
      id: "frequency",
      label: "À quelle fréquence l'utiliserez-vous ?",
      type: "select",
      options: [
        { value: "daily", label: "Tous les jours (abonnement mensuel)" },
        { value: "parttime", label: "3-4 jours/semaine" },
        { value: "occasional", label: "1-2 jours/semaine" },
        { value: "dropins", label: "Accès occasionnel" }
      ],
      defaultValue: "parttime"
    },
    {
      id: "tier",
      label: "Qualité de l'espace",
      type: "select",
      options: [
        { value: "budget", label: "Économique" },
        { value: "standard", label: "Coworking standard" },
        { value: "premium", label: "Bureau premium/privé" }
      ],
      defaultValue: "standard"
    }
  ]}
  calculateResult={(values) => {
    // Pricing estimates
    const pricing = {
      budget: { monthly: 1500000, day: 100000 },
      standard: { monthly: 2500000, day: 150000 },
      premium: { monthly: 4000000, day: 250000 }
    };

    const tier = pricing[values.tier];
    let monthly;

    switch (values.frequency) {
      case "daily":
        monthly = tier.monthly;
        break;
      case "parttime":
        monthly = Math.min(tier.day * 16, tier.monthly);
        break;
      case "occasional":
        monthly = tier.day * 8;
        break;
      case "dropins":
        monthly = tier.day * 4;
        break;
    }

    return {
      total: monthly,
      breakdown: [
        { label: "Coût de l'espace de travail", amount: monthly },
        { label: "Café/Boissons", amount: 300000 },
        { label: "Déjeuner occasionnel", amount: 500000 }
      ],
      currency: "IDR",
      note: `Environ USD ${Math.round(monthly / 16000)}/mois`
    };

}}

### Villa/Bureau à domicile

De nombreux nomades numériques travaillent à domicile :

**Avantages :**

- Pas de trajet quotidien
- Plus confortable
- Moins cher à long terme
- Votre propre installation

**Inconvénients :**

- Nécessite une bonne connexion internet à domicile
- Peut être isolant
- Moins d'opportunités de réseautage
- Coupures de courant

## Conseils pour les nomades numériques

1. **Essayez avant de vous engager** - Achetez d'abord des pass journaliers
2. **Vérifiez l'internet de secours** - Demandez ce qui se passe lorsque la connexion principale tombe en panne
3. **Visitez pendant vos heures de travail** - Vérifiez si c'est trop occupé
4. **Testez la qualité des appels vidéo** - Essentiel pour la plupart des travaux à distance
5. **Considérez l'emplacement** - Près de votre logement vous fait gagner du temps
6. **Utilisez la communauté** - Le réseautage est précieux
7. **Ayez une connexion mobile de secours** - Carte SIM Telkomsel pour les urgences
8. **Réservez les salles de réunion tôt** - Les espaces populaires se remplissent vite
