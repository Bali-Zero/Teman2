## Penjelasan Penduduk Pajak

<InfoCard variant="warning" title="Aturan 183 Hari">
**Pemicu penduduk pajak Indonesia:**

1. Hadir di Indonesia **183+ hari** dalam 12 bulan, ATAU
2. Tinggal di Indonesia dengan **niat untuk tinggal**

**Jika menjadi penduduk pajak:**

- Dikenai pajak atas penghasilan worldwide
- Harus memiliki NPWP
- Harus mengajukan SPT tahunan

Ini berlaku terlepas dari jenis visa!

</InfoCard>

## Bekerja dengan Visa Wisatawan

<InfoCard variant="warning" title="Area Abu-Abu">
**Secara teknis:**
- Visa wisata = tidak diizinkan bekerja
- Bekerja remote untuk klien asing = area abu-abu
- Indonesia belum secara aktif menegakkan aturan pada pekerja remote
- Namun aturan bisa diterapkan

**Realitasnya:**

- Banyak digital nomad bekerja dengan visa wisata
- Tidak sepenuhnya legal jika "bekerja"
- Penegakan rendah saat ini
- Risiko adalah untuk Anda menilai

Untuk kepatuhan penuh, pertimbangkan E33G Digital Nomad Visa (Visa Pekerja Remote).

</InfoCard>

## Jika Anda Menjadi Penduduk Pajak

### Kewajiban Anda

| Kewajiban              | Detail                     |
| ----------------------- | --------------------------- |
| Dapatkan NPWP          | Nomor ID pajak             |
| Laporkan penghasilan worldwide | Semua sumber secara global        |
| Ajukan SPT tahunan      | Sebelum 31 Maret           |
| Bayar pajak yang harus dibayar | Tarif progresif hingga 35%   |
| Laporkan aset asing     | Jika berlaku               |

### Kalkulator Pajak

<Calculator
  title="Estimasi Pajak Penghasilan"
  description="Pajak Indonesia atas penghasilan remote"
  fields={[
    {
      id: "monthly",
      label: "Penghasilan Bulanan (IDR)",
      type: "number",
      defaultValue: 30000000,
      min: 0
    },
    {
      id: "resident",
      label: "Status",
      type: "select",
      options: [
        { value: "resident", label: "Penduduk Pajak" },
        { value: "nonresident", label: "Non-Penduduk" }
      ],
      defaultValue: "resident"
    }
  ]}
  calculateResult={(values) => {
    const annual = values.monthly * 12;
    const ptkp = 54000000; // Pengurangan standar

    let taxable, tax;

    if (values.resident === "resident") {
      taxable = Math.max(0, annual - ptkp);

      // Tarif progresif
      if (taxable <= 60000000) {
        tax = taxable * 0.05;
      } else if (taxable <= 250000000) {
        tax = 3000000 + (taxable - 60000000) * 0.15;
      } else if (taxable <= 500000000) {
        tax = 3000000 + 28500000 + (taxable - 250000000) * 0.25;
      } else if (taxable <= 5000000000) {
        tax = 3000000 + 28500000 + 62500000 + (taxable - 500000000) * 0.30;
      } else {
        tax = 3000000 + 28500000 + 62500000 + 1350000000 + (taxable - 5000000000) * 0.35;
      }
    } else {
      // Tarif flat non-penduduk
      taxable = annual;
      tax = annual * 0.20;
    }

    return {
      total: Math.round(tax),
      breakdown: [
        { label: "Penghasilan tahunan", amount: annual },
        { label: values.resident === "resident" ? "Setelah pengurangan PTKP" : "Kena pajak (tarif flat)", amount: Math.round(taxable) },

      ],

## Pajak Negara Asal

### Jangan Lupa Negara Asal

<InfoCard variant="note" title="Risiko Pajak Ganda">
**Anda mungkin masih wajib bayar pajak di negara asal:**

- Warga AS: Dikenai pajak atas penghasilan worldwide terlepas dari statusnya
- Sebagian besar negara: Penduduk pajak membayar pajak negara asal
- Perjanjian: Mungkin mengurangi tetapi tidak menghapus
- Pelaporan: Mungkin perlu melaporkan penghasilan asing

**Periksa dengan negara asal Anda!**

- Aturan penduduk pajak di sana
- Pelaporan penghasilan asing
- Manfaat perjanjian pajak
- Kredit pajak asing
</InfoCard>

### Negara Asal Umum

| Negara     | Jika Anda Meninggalkan            |
| ----------- | ----------------------- |
| USA         | Masih dikenai pajak sebagai warga negara  |
| UK          | Mungkin tetap menjadi penduduk pajak   |
| Australia   | Uji coba 183 hari berlaku    |
| Canada      | Bergantung pada ikatan         |
| Netherlands | Harus keluar secara resmi      |
| Germany     | Bergantung pada ikatan         |

## Perjanjian Pajak

### Bagaimana Perjanjian Membantu

Indonesia memiliki perjanjian pajak dengan banyak negara yang:

- Mencegah pemajakan ganda
- Menentukan negara mana yang memajaki apa
- Memungkinkan kredit pajak asing
- Mungkin mengurangi tarif
