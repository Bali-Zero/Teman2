## Penjelasan Penduduk Pajak

<InfoCard variant="warning" title="Aturan 183 Hari">
**Pemicu penduduk pajak Indonesia:**

1. Hadir di Indonesia **183+ hari** dalam 12 bulan, ATAU
2. Tinggal di Indonesia dengan **niat untuk menetap**

**Jika menjadi penduduk pajak:**

- Dikenai pajak atas penghasilan seluruh dunia
- Harus memiliki NPWP
- Harus melapor pajak tahunan

Ini berlaku terlepas dari jenis visa!

</InfoCard>

## Bekerja dengan Visa Wisatawan

<InfoCard variant="warning" title="Area Abu-abu">
**Secara teknis:**
- Visa wisata = tidak diperbolehkan bekerja
- Bekerja jarak jauh untuk klien asing = area abu-abu
- Indonesia belum secara aktif menegakkan aturan pada pekerja jarak jauh
- Namun aturan bisa diterapkan

**Realitanya:**

- Banyak nomad digital bekerja dengan visa wisata
- Tidak secara teknis legal jika "bekerja"
- Penegakan hukum saat ini rendah
- Risiko adalah untuk Anda evaluasi

Untuk kepatuhan penuh, pertimbangkan E33G Digital Nomad Visa (Visa Pekerja Jarak Jauh).

</InfoCard>

### Kewajiban Anda

    const annual = values.monthly * 12;
    const ptkp = 54000000; // Pengurangan standar

    let taxable, tax;

    if (values.resident === "resident") {
      taxable = Math.max(0, annual - ptkp);

      // Tingkat progresif
      if (taxable <= 60000000) {
        tax = taxable * 0.05;
      } else if (taxable <= 250000000) {
        tax = 3000000 + (taxable - 60000000) * 0.15;
      } else if (taxable <= 500000000) {
        tax = 3000000 + 28500000 + (taxable - 250000000) * 0.25;

## Pajak Negara Asal

### Jangan Lupa Rumah

<InfoCard variant="note" title="Risiko Pajak Ganda">
**Anda mungkin masih wajib bayar pajak di rumah:**

- Warga negara AS: Dikenai pajak atas penghasilan seluruh dunia terlepas dari apa pun
- Sebagian besar negara: Penduduk pajak membayar pajak di negara asal
- Perjanjian: Mungkin mengurangi tetapi tidak menghilangkan
- Pelaporan: Mungkin perlu melaporkan penghasilan asing

**Cek dengan negara asal Anda!**

- Aturan penduduk pajak di sana
- Pelaporan penghasilan asing
- Manfaat perjanjian pajak
- Kredit pajak asing
</InfoCard>

### Negara Asal Umum

| Negara     | Jika Anda Meninggalkan            |
| ----------- | ----------------------- |
| USA         | Masih dikenai pajak sebagai warga negara  |
| UK          | Mungkin tetap menjadi penduduk pajak    |
| Australia   | Uji 183 hari berlaku    |
| Canada      | Bergantung pada ikatan         |
| Netherlands | Harus keluar secara resmi      |
| Germany     | Bergantung pada ikatan         |

## Perjanjian Pajak

### Bagaimana Perjanjian Membantu

Indonesia memiliki perjanjian pajak dengan banyak negara yang:

- Mencegah pemajakan ganda
- Menentukan negara mana yang memajak apa
- Memungkinkan kredit pajak asing
- Mungkin mengurangi tarif
