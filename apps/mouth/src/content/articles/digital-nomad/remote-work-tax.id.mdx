## Penjelasan Penduduk Pajak

<InfoCard variant="warning" title="Aturan 183 Hari">
**Pemicu penduduk pajak Indonesia:**

1. Hadir di Indonesia **183+ hari** dalam 12 bulan, ATAU
2. Tinggal di Indonesia dengan **niat untuk tinggal**

**Jika menjadi penduduk pajak:**

- Dikenai pajak atas penghasilan worldwide (seluruh dunia)
- Harus memiliki NPWP
- Harus melaporkan SPT tahunan

Hal ini berlaku tanpa memandang jenis visa!

</InfoCard>

## Bekerja dengan Visa Turis

<InfoCard variant="warning" title="Area Abu-abu">
**Secara teknis:**
- Visa turis = tidak diperbolehkan bekerja
- Bekerja remote untuk klien asing = area abu-abu
- Indonesia belum secara aktif menegakkan aturan pada pekerja remote
- Namun aturan bisa diterapkan

**Realitasnya:**

- Banyak digital nomad bekerja dengan visa turis
- Tidak sepenuhnya legal jika "bekerja"
- Penegakan hukum saat ini rendah
- Risiko adalah tanggung jawab Anda untuk menilai

Untuk kepatuhan penuh, pertimbangkan Visa Digital Nomad E33G (Visa Pekerja Remote).

</InfoCard>

## Jika Anda Menjadi Penduduk Pajak

### Kewajiban Anda

| Kewajiban              | Detail                     |
| ----------------------- | --------------------------- |
| Mendapatkan NPWP       | Nomor ID pajak             |
| Melaporkan penghasilan worldwide | Semua sumber secara global        |
| Mengajukan SPT tahunan  | Sebelum tanggal 31 Maret   |
| Membayar pajak yang harus dibayar | Tarif progresif hingga 35% |
| Melaporkan aset asing   | Jika berlaku               |

### Kalkulator Pajak

      // Tarif progresif
      if (taxable <= 60000000) {
        tax = taxable * 0.05;
      } else if (taxable <= 250000000) {
        tax = 3000000 + (taxable - 60000000) * 0.15;
      } else if (taxable <= 500000000) {

## Pajak Negara Asal

### Jangan Lupa Negara Asal

<InfoCard variant="note" title="Risiko Pajak Ganda">
**Anda mungkin masih wajib bayar pajak di negara asal:**

- Warga AS: Dikenai pajak atas penghasilan worldwide tanpa terkecuali
- Sebagian besar negara: Penduduk pajak membayar pajak di negara asal
- Perjanjian: Mungkin mengurangi tetapi tidak menghilangkan kewajiban
- Pelaporan: Mungkin perlu melaporkan penghasilan asing

**Periksa dengan negara asal Anda!**

- Aturan penduduk pajak di sana
- Pelaporan penghasilan asing
- Manfaat perjanjian pajak
- Kredit pajak asing
</InfoCard>

### Negara Asal Umum

| Negara     | Jika Anda Meninggalkan            |
| ----------- | ----------------------- |
| USA         | Tetap dikenai pajak sebagai warga negara  |
| UK          | Mungkin tetap menjadi penduduk pajak    |
| Australia   | Uji coba 183 hari berlaku    |
| Canada      | Bergantung pada ikatan         |
| Netherlands | Harus keluar secara resmi      |
| Germany     | Bergantung pada ikatan         |

## Perjanjian Pajak

### Bagaimana Perjanjian Membantu

Indonesia memiliki perjanjian pajak dengan banyak negara yang:

- Mencegah pemajakan ganda
- Menentukan negara mana yang memajaki apa
- Memungkinkan kredit pajak asing
- Mungkin mengurangi tarif

### Manfaat Kunci Perjanjian

| Jenis Penghasilan     | Manfaat Perjanjian                |
| --------------- | ----------------------------- |
| Pekerjaan      | Biasanya dipajaki di tempat pelaksanaan |
| Usaha Mandiri | Bergantung pada PE (Permanent Establishment)                 |
| Dividen       | Tarif yang dikurangi                 |
| Bunga          | Tarif yang dikurangi                 |
 Royalti       | Tarif yang dikurangi                 |
