## Penjelasan Warga Pajak

<InfoCard variant="warning" title="Aturan 183 Hari">
**Pemicu warga pajak Indonesia:**

1. Hadir di Indonesia **183+ hari** dalam 12 bulan, ATAU
2. Tinggal di Indonesia dengan **niat untuk tinggal**

**Jika menjadi warga pajak:**

- Dikenai pajak atas penghasilan worldwide (seluruh dunia)
- Harus memiliki NPWP
- Harus melapor SPT tahunan

Hal ini berlaku tanpa memandang jenis visa!

</InfoCard>

## Bekerja dengan Visa Wisatawan

<InfoCard variant="warning" title="Area Abu-abu">
**Secara teknis:**
- Visa wisata = tidak diperbolehkan bekerja
- Bekerja jarak jauh untuk klien asing = area abu-abu
- Indonesia belum secara aktif menegakkan aturan terhadap pekerja jarak jauh
- Namun aturan bisa diterapkan

**Realitanya:**

- Banyak digital nomad bekerja dengan visa wisata
- Tidak sepenuhnya legal jika "bekerja"
- Penegakan hukum saat ini rendah
- Risiko adalah tanggung jawab Anda untuk menilai

Untuk kepatuhan penuh, pertimbangkan E33G Digital Nomad Visa (Visa Pekerja Jarak Jauh).

</InfoCard>

## Jika Anda Menjadi Warga Pajak

### Kewajiban Anda

| Kewajiban              | Detail                     |
| ----------------------- | --------------------------- |
| Dapatkan NPWP          | Nomor ID pajak             |
| Laporkan penghasilan worldwide | Semua sumber secara global        |
| Ajukan SPT tahunan      | Sebelum 31 Maret           |
| Bayar pajak yang terutang | Tarif progresif hingga 35% |
| Laporkan aset asing     | Jika berlaku               |

### Kalkulator Pajak

<Calculator
  title="Estimasi Pajak Penghasilan"
  description="Pajak Indonesia atas penghasilan jarak jauh"
  fields={[

      label: "Penghasilan Bulanan (IDR)",

  calculateResult={(values) => {
    const annual = values.monthly * 12;
    const ptkp = 54000000; // Pengurangan standar

    let taxable, tax;

    if (values.resident === "resident") {
      taxable = Math.max(0, annual - ptkp);

      // Tarif progresif
      if (taxable <= 60000000) {
        tax = taxable * 0.05;
      } else if (taxable <= 250000000) {
        tax = 3000000 + (taxable - 60000000) * 0.15;
      } else if (taxable <= 500000000) {
        tax = 3000000 + 28500000 + (taxable - 250000000) * 0.25;
      } else if (taxable <= 5000000000) {
        tax = 3000000 + 28500000 + 62500000 + (taxable - 500000000) * 0.30;

## Pajak Negara Asal

### Jangan Lupa Negara Asal

<InfoCard variant="note" title="Risiko Pajak Ganda">
**Anda mungkin masih wajib bayar pajak di negara asal:**

- Warga AS: Dikenai pajak atas penghasilan worldwide tanpa terkecuali
- Sebagian besar negara: Warga pajak membayar pajak ke negara asal
- Perjanjian: Mungkin mengurangi tetapi tidak menghapus sepenuhnya
- Pelaporan: Mungkin perlu melaporkan penghasilan asing

**Periksa dengan negara asal Anda!**

- Aturan warga pajak di sana
- Pelaporan penghasilan asing
- Manfaat perjanjian pajak
- Kredit pajak asing
</InfoCard>

### Negara Asal Umum

| Negara     | Jika Anda Meninggalkan            |
| ----------- | --------------------------------- |
| USA         | Masih dikenai pajak sebagai warga negara |
| UK          | Mungkin tetap menjadi warga pajak |
| Australia   | Uji 183 hari berlaku              |
| Kanada      | Bergantung pada ikatan           |
| Belanda     | Harus keluar secara resmi         |
| Jerman      | Bergantung pada ikatan           |

## Perjanjian Pajak

### Bagaimana Perjanjian Membantu

Indonesia memiliki perjanjian pajak dengan banyak negara yang:

- Mencegah pemajakan ganda
- Menentukan negara mana yang memajaki apa
- Memungkinkan kredit pajak asing
- Mungkin mengurangi tarif
