## Penjelasan Domisili Pajak

<InfoCard variant="warning" title="Aturan 183 Hari">
**Pemicu domisili pajak Indonesia:**

1. Berada di Indonesia **183+ hari** dalam 12 bulan, ATAU
2. Bertempat tinggal di Indonesia dengan **niat untuk menetap**

**Jika menjadi subjek pajak dalam negeri:**

- Dipajak atas penghasilan seluruh dunia
- Wajib memiliki NPWP
- Wajib lapor SPT tahunan

Ini berlaku terlepas dari jenis visa Anda!

</InfoCard>

## Bekerja dengan Visa Turis

<InfoCard variant="warning" title="Area Abu-abu">
**Secara teknis:**
- Visa turis = tidak diizinkan bekerja
- Bekerja secara remote untuk klien luar negeri = area abu-abu
- Indonesia belum secara aktif menindak pekerja remote
- Namun aturan bisa saja ditegakkan

**Kenyataannya:**

- Banyak digital nomad bekerja dengan visa turis
- Secara teknis tidak legal jika \"bekerja\"
- Penegakan hukum saat ini masih rendah
- Risiko ada pada penilaian Anda sendiri

Untuk kepatuhan penuh, pertimbangkan Visa Digital Nomad E33G (Visa Pekerja Remote).

</InfoCard>

## Jika Anda Subjek Pajak Dalam Negeri

### Kewajiban Anda

| Kewajiban               | Detail                     |
| ----------------------- | -------------------------- |
| Dapatkan NPWP           | Nomor identitas pajak      |
| Lapor penghasilan dunia | Semua sumber secara global |
| Lapor SPT tahunan       | Paling lambat 31 Maret     |
| Bayar pajak terutang    | Tarif progresif hingga 35% |
| Lapor aset luar negeri  | Jika berlaku               |

### Kalkulator Pajak

<Calculator
  title="Estimasi Pajak Penghasilan"
  description="Pajak Indonesia atas penghasilan remote"
  fields={[
    {
      id: "monthly",
      label: "Penghasilan Bulanan (IDR)",
      type: "number",

    },

  calculateResult={(values) => {
    const annual = values.monthly * 12;
    const ptkp = 54000000; // Pengurang standar

    let taxable, tax;

    if (values.resident === "resident") {
      taxable = Math.max(0, annual - ptkp);

      // Tarif progresif
      if (taxable <= 60000000) {
        tax = taxable * 0.05;
      } else if (taxable <= 250000000) {
        tax = 3000000 + (taxable - 60000000) * 0.15;
      } else if (taxable <= 500000000) {
        tax = 3000000 + 28500000 + (taxable - 250000000) * 0.25;
      } else if (taxable <= 5000000000) {
        tax = 3000000 + 28500000 + 62500000 + (taxable - 500000000) * 0.30;
      } else {
        tax = 3000000 + 28500000 + 62500000 + 1350000000 + (taxable - 5000000000) * 0.35;
      }

      // Tarif flat non-residen
      taxable = annual;

## Pajak Negara Asal

### Jangan Lupakan Negara Asal

<InfoCard variant="note" title="Risiko Pajak Berganda">
**Anda mungkin masih berutang pajak di negara asal:**

- Warga negara AS: Dipajak atas penghasilan seluruh dunia terlepas dari tempat tinggal
- Sebagian besar negara: Subjek pajak dalam negeri membayar pajak di negara asal
- Perjanjian (P3B): Dapat mengurangi tetapi tidak menghilangkan
- Pelaporan: Mungkin perlu melaporkan penghasilan luar negeri

**Cek dengan negara asal Anda!**

- Aturan domisili pajak di sana
- Pelaporan penghasilan luar negeri
- Manfaat perjanjian pajak
- Kredit pajak luar negeri
  </InfoCard>

### Negara Asal Umum

| Negara    | Jika Anda Pergi                    |
| --------- | ---------------------------------- |
| AS        | Tetap dipajak sebagai warga negara |
| Inggris   | Mungkin tetap menjadi subjek pajak |
| Australia | Tes 183 hari berlaku               |
| Kanada    | Tergantung pada ikatan             |

## Perjanjian Pajak (P3B)

### Bagaimana Perjanjian Membantu

Indonesia memiliki perjanjian pajak (P3B) dengan banyak negara yang:

- Mencegah pajak berganda
- Menentukan negara mana yang memajaki apa
- Mengizinkan kredit pajak luar negeri
- Dapat mengurangi tarif

### Manfaat Utama Perjanjian

| Jenis Penghasilan | Manfaat Perjanjian                         |
| ----------------- | ------------------------------------------ |
| Pekerjaan         | Biasanya dipajak di tempat kerja dilakukan |
| Wiraswasta        | Tergantung pada BUT (PE)                   |
| Dividen           | Tarif yang dikurangi                       |
| Bunga             | Tarif yang dikurangi                       |
| Royalti           | Tarif yang dikurangi                       |
