## La résidence fiscale expliquée

<InfoCard variant="warning" title="La règle des 183 jours">
**Déclencheurs de la résidence fiscale indonésienne :**

1. Présence en Indonesia **183 jours ou plus** sur 12 mois, OU
2. Résidence en Indonesia avec **intention de rester**

**Si résident fiscal :**

- Imposition sur le revenu mondial
- Doit avoir un NPWP
- Doit déposer une déclaration fiscale annuelle

Ceci s'applique quel que soit le type de visa !

</InfoCard>

## Travailler avec un visa touristique

<InfoCard variant="warning" title="La zone grise">
**Techniquement :**
- Visa touristique = pas de travail autorisé
- Travailler à distance pour des clients étrangers = zone grise
- L'Indonesia n'a pas activement appliqué la loi aux travailleurs à distance
- Mais les règles pourraient être appliquées

**La réalité :**

- De nombreux nomades numériques travaillent avec des visas touristiques
- Pas techniquement légal si "travail"
- Faible application actuellement
- Le risque est à vous d'évaluer

Pour une conformité totale, envisagez le visa nomade numérique E33G (visa de travailleur à distance).

</InfoCard>

## Si vous êtes résident fiscal

### Vos obligations

| Obligation                      | Détails                         |
| ------------------------------- | ------------------------------- |
| Obtenir un NPWP                 | Numéro d'identification fiscale |
| Déclarer les revenus mondiaux   | Toutes les sources mondiales    |
| Déposer la déclaration annuelle | Avant le 31 mars                |
| Payer l'impôt dû                | Taux progressifs jusqu'à 35 %   |
| Déclarer les actifs étrangers   | Le cas échéant                  |

### Calculateur d'impôt

<Calculator
  title="Estimation de l'impôt sur le revenu"
  description="Impôt indonésien sur les revenus à distance"
  fields={[
    {
      id: "monthly",
      label: "Revenu mensuel (IDR)",
      type: "number",
      defaultValue: 30000000,
      min: 0
    },
    {
      id: "resident",
      label: "Statut",
      type: "select",
      options: [
        { value: "resident", label: "Résident fiscal" },
        { value: "nonresident", label: "Non-résident" }
      ],
      defaultValue: "resident"
    }
  ]}
  calculateResult={(values) => {
    const annual = values.monthly * 12;
    const ptkp = 54000000; // Standard deduction

    let taxable, tax;

    if (values.resident === "resident") {
      taxable = Math.max(0, annual - ptkp);

      // Progressive rates
      if (taxable <= 60000000) {
        tax = taxable * 0.05;
      } else if (taxable <= 250000000) {
        tax = 3000000 + (taxable - 60000000) * 0.15;
      } else if (taxable <= 500000000) {
        tax = 3000000 + 28500000 + (taxable - 250000000) * 0.25;
      } else if (taxable <= 5000000000) {
        tax = 3000000 + 28500000 + 62500000 + (taxable - 500000000) * 0.30;
      } else {
        tax = 3000000 + 28500000 + 62500000 + 1350000000 + (taxable - 5000000000) * 0.35;
      }
    } else {
      // Non-resident flat rate
      taxable = annual;
      tax = annual * 0.20;
    }

    return {
      total: Math.round(tax),
      breakdown: [
        { label: "Revenu annuel", amount: annual },
        { label: values.resident === "resident" ? "Après déduction PTKP" : "Imposable (taux forfaitaire)", amount: Math.round(taxable) },
        { label: "Impôt annuel estimé", amount: Math.round(tax) },
        { label: "Équivalent impôt mensuel", amount: Math.round(tax / 12) }
      ],
      currency: "IDR",
      note: values.resident === "resident" ? "Taux progressifs 5-35%" : "Forfaitaire 20% pour les non-résidents"
    };

}}

## Impôt du pays d'origine

### N'oubliez pas votre pays d'origine

<InfoCard variant="note" title="Risque de double imposition">
**Vous pourriez toujours devoir des impôts dans votre pays d'origine :**

- Citoyens américains : Imposés sur le revenu mondial quoi qu'il arrive
- La plupart des pays : Les résidents fiscaux paient l'impôt dans leur pays
- Conventions : Peuvent réduire mais pas éliminer
- Déclaration : Peut être nécessaire de déclarer les revenus étrangers

**Vérifiez auprès de votre pays d'origine !**

- Règles de résidence fiscale là-bas
- Déclaration des revenus étrangers
- Avantages des conventions fiscales
- Crédits d'impôt étrangers
  </InfoCard>

### Pays d'origine courants

| Pays        | Si vous partez                      |
| ----------- | ----------------------------------- |
| USA         | Toujours imposé en tant que citoyen |
| Royaume-Uni | Peut rester résident fiscal         |
| Australie   | Le test des 183 jours s'applique    |
| Canada      | Dépend des liens                    |
| Pays-Bas    | Doit quitter formellement           |
| Allemagne   | Dépend des liens                    |

## Conventions fiscales

### Comment les conventions aident

L'Indonesia a des conventions fiscales avec de nombreux pays qui :

- Évitent la double imposition
- Déterminent quel pays impose quoi
- Permettent des crédits d'impôt étrangers
- Peuvent réduire les taux

### Principaux avantages des conventions

| Type de revenu      | Avantage de la convention               |
| ------------------- | --------------------------------------- |
| Emploi              | Généralement imposé là où il est exercé |
| Travail indépendant | Dépend de l'EP                          |
| Dividendes          | Taux réduits                            |
| Intérêts            | Taux réduits                            |
| Redevances          | Taux réduits                            |

### Pour un travail à distance conforme

| Option               | Comment ça marche                                   |
| -------------------- | --------------------------------------------------- |
| PT PMA               | Entreprise indonésienne, vous en tant que directeur |
| Entreprise étrangère | Rester employé par une entité étrangère             |

<InfoCard variant="tip" title="Pour les séjours plus longs">
**Si vous restez à long terme :**

Envisagez la structure **PT PMA** :

- Autorisation de travail légale
- Position fiscale claire
- Peut facturer les clients
- Accès au compte bancaire
- Statut professionnel

Oui, il y a des coûts et de la complexité, mais cela apporte de la clarté.

</InfoCard>
