## La Residenza Fiscale Spiegata

<InfoCard variant="warning" title="La Regola dei 183 Giorni">
**Cosa attiva la residenza fiscale indonesiana:**

1. Presenza in Indonesia per **183+ giorni** in 12 mesi, OPPURE
2. Residenza in Indonesia con **intenzione di restare**

**Se sei residente fiscale:**

- Tassato sul reddito mondiale
- Devi possedere un NPWP
- Devi presentare la dichiarazione dei redditi annuale (SPT)

Questo si applica indipendentemente dal tipo di visto!

</InfoCard>

## Lavorare con Visto Turistico

<InfoCard variant="warning" title="L'Area Grigia">
**Tecnicamente:**
- Visto turistico = nessun lavoro permesso
- Lavorare da remoto per clienti esteri = area grigia
- L'Indonesia non ha applicato sanzioni attive sui lavoratori remoti
- Ma le regole potrebbero essere fatte valere

**La realtà:**

- Molti digital nomad lavorano con visti turistici
- Tecnicamente non legale se si "lavora"
- Applicazione delle norme attualmente bassa
- Il rischio è a carico dell'individuo

Per una piena conformità, considera il visto E33G Digital Nomad (Visto per lavoratori remoti).

</InfoCard>

### Calcolatore Fiscale

<Calculator
  title="Stima dell'Imposta sul Reddito"
  description="Tasse indonesiane su reddito remoto"
  fields={[
    {
      id: "monthly",
      label: "Reddito Mensile (IDR)",
      type: "number",
      defaultValue: 30000000,
      min: 0
    },
    {
      id: "resident",
      label: "Stato",
      type: "select",
      options: [
        { value: "resident", label: "Residente Fiscale" },
        { value: "nonresident", label: "Non-Residente" }
      ],
      defaultValue: "resident"
    }
  ]}
  calculateResult={(values) => {
    const annual = values.monthly * 12;
    const ptkp = 54000000; // Deduzione standard

    let taxable, tax;

    if (values.resident === "resident") {
      taxable = Math.max(0, annual - ptkp);

      // Aliquote progressive
      if (taxable <= 60000000) {
        tax = taxable * 0.05;
      } else if (taxable <= 250000000) {
        tax = 3000000 + (taxable - 60000000) * 0.15;
      } else if (taxable <= 500000000) {
        tax = 3000000 + 28500000 + (taxable - 250000000) * 0.25;
      } else if (taxable <= 5000000000) {
        tax = 3000000 + 28500000 + 62500000 + (taxable - 500000000) * 0.30;
      } else {
        tax = 3000000 + 28500000 + 62500000 + 1350000000 + (taxable - 5000000000) * 0.35;
      }
    } else {
      // Aliquota flat non residenti
      taxable = annual;
      tax = annual * 0.20;
    }

    return {
      total: Math.round(tax),
      breakdown: [
        { label: "Reddito annuale", amount: annual },
        { label: values.resident === "resident" ? "Dopo deduzione PTKP" : "Imponibile (aliquota flat)", amount: Math.round(taxable) },
        { label: "Tassa annuale stimata", amount: Math.round(tax) },
        { label: "Equivalente tassa mensile", amount: Math.round(tax / 12) }
      ],
      currency: "IDR",
      note: values.resident === "resident" ? "Aliquote progressive 5-35%" : "Flat 20% per non residenti"

## Tasse nel Paese d'Origine

### Non Dimenticare Casa

<InfoCard variant="note" title="Rischio Doppia Tassazione">
**Potresti ancora dover pagare tasse nel tuo paese:**

- Cittadini USA: Tassati sul reddito mondiale indipendentemente dalla residenza
- Molti paesi: I residenti fiscali pagano le tasse in patria
- Trattati: Possono ridurre ma non eliminare gli obblighi
- Dichiarazioni: Potrebbe essere necessario dichiarare il reddito estero

**Verifica con il tuo paese d'origine!**

- Regole di residenza fiscale locali
- Dichiarazione dei redditi esteri
- Benefici dei trattati fiscali
- Crediti d'imposta per tasse pagate all'estero
  </InfoCard>

### Paesi d'Origine Comuni

| Paese       | Se te ne vai             |
| ----------- | ------------------------ |
| USA         | Tassato come cittadino   |
| UK          | Puoi restare residente   |
| Australia   | Si applica il test 183gg |
| Canada      | Dipende dai legami       |
| Paesi Bassi | Devi uscire formalmente  |
| Germania    | Dipende dai legami       |

## Trattati Fiscali

### Come Aiutano i Trattati

L'Indonesia ha trattati fiscali con molti paesi per:

- Prevenire la doppia tassazione
- Determinare quale paese tassa cosa
- Consentire crediti d'imposta esteri
- Ridurre potenzialmente le aliquote

### Benefici Chiave dei Trattati

| Tipo di Reddito   | Beneficio del Trattato          |
| ----------------- | ------------------------------- |
| Lavoro dipendente | Solitamente tassato dove svolto |
| Lavoro autonomo   | Dipende dalla sede fissa (PE)   |
| Dividendi         | Aliquote ridotte                |
| Interessi         | Aliquote ridotte                |
| Royalties         | Aliquote ridotte                |
