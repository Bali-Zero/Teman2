## Residenza Fiscale Spiegata

<InfoCard variant="warning" title="La Regola dei 183 Giorni">
**Attivatori della residenza fiscale indonesiana:**

1. Presente in Indonesia **183+ giorni** in 12 mesi, OPPURE
2. Residente in Indonesia con **intenzione di rimanere**

**Se residente fiscalmente:**

- Tassato sul reddito mondiale
- Deve avere NPWP
- Deve presentare dichiarazione annuale delle tasse

Ciò si applica indipendentemente dal tipo di visto!

</InfoCard>

## Lavoro con Visto da Turista

<InfoCard variant="warning" title="L'Area Grigia">
**Tecnicamente:**
- Visto da turista = nessun lavoro consentito
- Lavorare remotamente per clienti esteri = area grigia
- L'Indonesia non ha attivamente enforcement sui lavoratori remoti
- Ma le regole potrebbero essere applicate

**La realtà:**

- Molti digital nomad lavorano con visti da turista
- Non tecnicamente legale se "lavorando"
- Enforcement basso attualmente
- Il rischio è tuo da valutare

Per piena conformità, considera il visto E33G Digital Nomad (Visto per Lavoratore Remoto).

</InfoCard>

### I Tuoi Obblighi

| ----------------------- | --------------------------- |

| Comunica attività estere    | Se applicabile               |

### Calcolatore Fiscale

<Calculator
  title="Stima Tasse sul Reddito"
  description="Tassazione indonesiana sul reddito remoto"
  fields={[
    {
      id: "monthly",
      label: "Reddito Mensile (IDR)",
      type: "number",
      defaultValue: 30000000,

  calculateResult={(values) => {
    const annual = values.monthly * 12;
    const ptkp = 54000000; // Detrazione standard

    let taxable, tax;

    if (values.resident === "resident") {
      taxable = Math.max(0, annual - ptkp);

      // Aliquote progressive
      if (taxable <= 60000000) {
        tax = taxable * 0.05;
      } else if (taxable <= 250000000) {
        tax = 3000000 + (taxable - 60000000) * 0.15;
      } else if (taxable <= 500000000) {
        tax = 3000000 + 28500000 + (taxable - 250000000) * 0.25;

## Tasse del Paese d'Origine

### Non Dimenticare Casa

<InfoCard variant="note" title="Rischio Doppia Tassazione">
**Potresti ancora dover pagare tasse a casa:**

- Cittadini USA: Tassati sul reddito mondiale indipendentemente
- La maggior parte dei paesi: I residenti fiscali pagano le tasse locali
- Trattati: Possono ridurre ma non eliminare
- Segnalazione: Potrebbe essere necessario dichiarare redditi esteri

**Controlla con il tuo paese d'origine!**

- Regole di residenza fiscale lì
- Segnalazione redditi esteri
- Benefici del trattato fiscale
- Crediti per imposte estere
</InfoCard>

### Paesi d'Origine Comuni

| Paese     | Se Parti            |
| ----------- | ----------------------- |
| USA         | Sempre tassato come cittadino  |
| UK          | Potresti rimanere residente fiscale |
| Australia   | Si applica il test dei 183 giorni    |
| Canada      | Dipende dai legami         |
| Paesi Bassi | Devi uscire formalmente     |
| Germania    | Dipende dai legami         |

## Trattati Fiscali

### Come i Trattati Aiutano

L'Indonesia ha trattati fiscali con molti paesi che:

- Prevengono la doppia tassazione
- Determinano quale paese tassa cosa
- Consentono crediti per imposte estere
- Possono ridurre le aliquote

### Benefici Chiave dei Trattati

| Tipo di Reddito     | Beneficio del Trattato                |
| --------------- | ----------------------------- |
| Impiego      | Di solito tassato dove svolto |
| Lavoro autonomo | Dipende dalla PE (Stabile Organizzazione)                 |
| Dividendi       | Aliquote ridotte                 |
| Interessi        | Aliquote ridotte                 |
 | Royalties       | Aliquote ridotte                 |
