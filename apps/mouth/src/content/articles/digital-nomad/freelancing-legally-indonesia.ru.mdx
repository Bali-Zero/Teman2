## Разъяснение серой зоны

<InfoCard variant="warning" title="Поймите реальность">
**Что технически незаконно:**
- Работа по туристической/социальной визе
- Предоставление услуг индонезийским клиентам без PT PMA
- Получение дохода из индонезийских источников без надлежащей структуры

**Что широко терпимо:**

- Удаленная работа для иностранных клиентов
- Оплата на иностранные банковские счета
- Отсутствие конкуренции с индонезийскими работниками
- Проживание/расходы в Indonesia как "турист"

**Риск:**

- Иммиграционные проблемы (редко)
- Налоговые последствия, если пребывание составляет 183+ дней
- Отсутствие правовой защиты при трудовых спорах
  </InfoCard>

## PT PMA для фрилансеров

### Когда вам нужна PT PMA

- Работа с индонезийскими клиентами
- Желание полной легальности
- Создание долгосрочного присутствия
- Необходимость в индонезийских контрактах

### Стоимость PT PMA

| Пункт                        | Стоимость              |
| ---------------------------- | ---------------------- |
| Создание                     | IDR 50-100M            |
| Требуемый капитал            | IDR 10B (обязательный) |
| Ежегодное обслуживание       | IDR 30-50M             |
| Разрешение на работу (KITAS) | IDR 20-30M             |

<InfoCard variant="note" title="Стоит ли PT PMA того?">
Для большинства фрилансеров, работающих только с иностранными клиентами, PT PMA является излишней.

**Рассмотрите PT PMA, если:**

- Индонезийские клиенты хотят нанять вас
- Доход оправдывает затраты (IDR 100M+/год)
- Вы хотите полного юридического спокойствия
- Вы строите бизнес, а не просто фриланс
  </InfoCard>

### Подход 2: Правильная индонезийская структура

Для тех, кто хочет полной легальности:

1. **Учредите PT PMA** (~3-6 месяцев)
2. **Получите KITAS директора** (через вашу компанию)
3. **Зарегистрируйтесь для уплаты налогов** (NPWP, PKP при необходимости)
4. **Правильно выставляйте счета** (индонезийские налоговые счета)
5. **Платите индонезийские налоги** (корпоративные и личные)

## Вариант с иностранной компанией

Некоторые фрилансеры используют иностранную компанию:

### Преимущества

- Профессиональное выставление счетов клиентам
- Разделение бизнеса и личного
- Возможности налогового планирования
- Не требуется индонезийская структура

### Популярные юрисдикции

- Сингапур (дорого, но близко)
- Гонконг (благоприятная для бизнеса)
- USA LLC (для резидентов США)
- Эстония e-Residency (доступ к ЕС)

<InfoCard variant="tip" title="Сингапур против других">
Сингапур популярен среди фрилансеров, базирующихся в Indonesia:
- Близкий часовой пояс
- Благоприятная для бизнеса среда
- Хорошее банковское обслуживание
- Профессиональный имидж

Но ежегодные расходы составляют 2-5 тыс. долларов США+.

</InfoCard>

## Распространенные ошибки

1. **Долгосрочная работа по туристической визе** - Получите соответствующую визу
2. **Выставление счетов индонезийским компаниям** - Нужна PT PMA
3. **Игнорирование налогового резидентства** - Отслеживайте свои дни
4. **Отсутствие контрактов** - Всегда имейте соглашения
5. **Неотслеживание доходов** - Ведите учет
6. **Смешивание личного/бизнеса** - Отдельные счета
7. **Предположение, что никому нет дела** - Правила могут меняться

## Когда обращаться за профессиональной помощью

Рассмотрите возможность консультации с профессионалом, если:

- Индонезийские клиенты хотят вас нанять
- Вы остаетесь на 183+ дня
- Вы хотите полного соблюдения законодательства
- Вы получаете значительный доход
- Вы строите бизнес
