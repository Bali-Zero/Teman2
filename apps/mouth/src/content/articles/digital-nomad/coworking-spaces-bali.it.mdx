## Calcolatore dei Costi di Coworking

<Calculator
  title="Budget Coworking"
  description="Stima i tuoi costi mensili per lo spazio di lavoro"
  fields={[
    {
      id: "frequency",
      label: "Quanto spesso lo userai?",
      type: "select",
      options: [
        { value: "daily", label: "Ogni giorno (pass mensile)" },
        { value: "parttime", label: "3-4 giorni/settimana" },
        { value: "occasional", label: "1-2 giorni/settimana" },
        { value: "dropins", label: "Ingressi occasionali" }
      ],
      defaultValue: "parttime"
    },
    {
      id: "tier",
      label: "Qualità dello spazio",
      type: "select",
      options: [
        { value: "budget", label: "Economico" },
        { value: "standard", label: "Coworking standard" },
        { value: "premium", label: "Premium/ufficio privato" }
      ],
      defaultValue: "standard"
    }
  ]}
  calculateResult={(values) => {
    // Stime dei prezzi
    const pricing = {
      budget: { monthly: 1500000, day: 100000 },
      standard: { monthly: 2500000, day: 150000 },
      premium: { monthly: 4000000, day: 250000 }
    };

    const tier = pricing[values.tier];
    let monthly;

    switch (values.frequency) {
      case "daily":
        monthly = tier.monthly;
        break;
      case "parttime":
        monthly = Math.min(tier.day * 16, tier.monthly);
        break;
      case "occasional":
        monthly = tier.day * 8;
        break;
      case "dropins":
        monthly = tier.day * 4;
        break;
    }

    return {
      total: monthly,
      breakdown: [
        { label: "Costo Spazio Lavoro", amount: monthly },
        { label: "Caffè/Bevande", amount: 300000 },
        { label: "Pranzi Occasionali", amount: 500000 }
      ],
      currency: "IDR",
      note: `Circa USD ${Math.round(monthly / 16000)}/mese`
    };

}}
/>

### Villa/Ufficio in Casa

Molti nomadi digitali lavorano da casa:

**Pro:**

- Nessun tragitto giornaliero
- Più confortevole
- Più economico a lungo termine
- La tua configurazione personale

**Contro:**

- Necessità di un buon internet domestico
- Può essere isolante
- Meno opportunità di networking
- Interruzioni di corrente

## Consigli per Nomadi Digitali

1. **Prova prima di impegnarti** - Compra prima i pass giornalieri
2. **Controlla l'internet di backup** - Chiedi cosa succede se fallisce la principale
3. **Visita durante l'orario di lavoro** - Controlla se è troppo affollato
4. **Testa la qualità delle videochiamate** - Essenziale per la maggior parte dei lavori
5. **Considera la posizione** - Vicino al tuo alloggio risparmia tempo
6. **Sfrutta la community** - Il networking è prezioso
7. **Abbi un backup mobile** - SIM Telkomsel per le emergenze
8. **Prenota le sale riunioni in anticipo** - Gli spazi popolari si riempiono subito
