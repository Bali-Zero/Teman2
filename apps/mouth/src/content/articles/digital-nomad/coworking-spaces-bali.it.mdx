    const pricing = {
      budget: { monthly: 1500000, day: 100000 },
      standard: { monthly: 2500000, day: 150000 },
      premium: { monthly: 4000000, day: 250000 }
    };

    const tier = pricing[values.tier];
    let monthly;

    switch (values.frequency) {
      case "daily":
        monthly = tier.monthly;

      case "parttime":

        monthly = tier.day * 4;

### Villa/Ufficio Casa

Molti nomadi digitali lavorano da casa:

**Vantaggi:**

- Nessun pendolarismo quotidiano
- Più confortevole
- Più economico nel lungo termine
- Il tuo setup personale

**Svantaggi:**

- Necessità di buona internet a casa
- Può essere isolante
- Minori opportunità di networking
- Interruzioni di corrente

## Consigli per i Nomadi Digitali

1. **Prova prima di impegnarti** - Compra pass giornalieri prima
2. **Controlla l'Internet di backup** - Chiedi cosa succede quando quello principale fallisce
3. **Visita durante le tue ore di lavoro** - Controlla se è troppo affollato
4. **Testa la qualità della videochiamata** - Essenziale per la maggior parte del lavoro remoto
5. **Considera la posizione** - Vicino al tuo alloggio salva tempo
6. **Usa la comunità** - Il networking è prezioso
7. **Avere un backup mobile** - SIM Telkomsel per emergenze
8. **Prenota sale riunioni in anticipo** - Gli spazi popolari si riempiono
