## Regolamenti sul Franchising

### Requisiti Chiave

<InfoCard variant="note" title="Registrazione Governativa">
**I franchise devono essere registrati:**

- STPW (Surat Tanda Pendaftaran Waralaba)
- Obbligatorio per il franchisor
- Registrare entro 30 giorni dall'inizio
- Richiesta di rinnovo

Operare senza registrazione è illegale.

</InfoCard>

### Quadro Normativo

| Regulation           | Covers                             |
| -------------------- | ---------------------------------- |
| Gov Reg 42/2007      | Definizione del franchise, requisiti |
| Minister Reg 71/2019 | Procedure di registrazione         |
| Trade Minister       | Supervisione continua              |

## Franchising Estero

### Portare un Marchio Estero in Indonesia

<InfoCard variant="warning" title="Regole per i Franchise Esteri">
**Requisiti per i marchi esteri:**

- Contratto di master franchise
- Solitamente richiesta una PT PMA
- Registrare il franchise in Indonesia
- Potrebbe essere necessario un partner locale
- Requisiti di localizzazione
- Regole sull'approvvigionamento locale (80% per alcuni articoli)

I franchisor esteri devono adattarsi alle normative indonesiane.

</InfoCard>

### Requisiti sul Contenuto Locale

| Requirement       | Details                          |
| ----------------- | -------------------------------- |
| Local products    | 80% per certi articoli F&B       |
| Local partnership | Potrebbe essere richiesto per alcuni settori |
| Local management  | Coinvolgimento indonesiano       |
| Registration      | In Indonesia                     |

## Considerazioni per il Franchisee

### Prima di Acquistare

| Factor                  | Check                             |
| ----------------------- | --------------------------------- |
| Track record del franchisor | Anni in attività, tasso di successo   |
| Requisiti finanziari    | Investimento totale, capitale circolante |
| Diritti territoriali    | Esclusivo? Protetto?             |
| Commissioni             | Iniziali, royalty continue        |
| Supporto fornito        | Formazione, marketing, operazioni   |
| Opzioni di uscita       | Puoi vendere? Trasferire?           |

### Tipica Struttura delle Commissioni

| Fee Type          | Typical Range              |
| ----------------- | -------------------------- |
| Franchise fee     | IDR 50M - 500M+            |
| Royalty           | 3-8% del fatturato         |
| Marketing fee     | 1-3% del fatturato         |
| Equipment         | Variabile                  |
| Initial inventory | Variabile                  |
| Working capital   | 3-6 mesi di costi operativi |

## Registrazione STPW

### Processo per i Franchisor

| Step                     | Duration      |
| ------------------------ | ------------- |
| Preparare documenti        | 2-4 settimane     |
| Sottomettere domanda       | 1 settimana        |
| Revisione dal Ministero del Commercio | 2-4 settimane     |
| STPW rilasciata              | All'approvazione |
| Valida per                | 5 anni       |

### Documenti Richiesti

| Document              | Details                |
| --------------------- | ---------------------- |
| Franchise prospectus  | Dettagli dell'azienda   |
| Franchise agreement   | Campione di contratto  |
| Prova di proprietà IP | Certifici dei marchi registrati |
| Documenti aziendali    | Stato legale           |
| Manuali operativi      | Documentazione del sistema   |
