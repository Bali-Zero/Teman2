| --------------------------- | ---------------------------------- | ------------------ |

### Калькулятор затрат

<Calculator
  title="Total Employment Cost"
  description="Estimate employer total cost"
  fields={[
    {
      id: "gross",
      label: "Gross Monthly Salary (IDR)",
      type: "number",
      defaultValue: 15000000,
      min: 0,
      step: 1000000,
      suffix: "IDR"
    },
    {
      id: "thr",
      label: "Include THR Provision",
      type: "select",
      options: [
        { value: "yes", label: "Yes" },
        { value: "no", label: "No" }
      ],
      defaultValue: "yes"
    }
  ]}
  calculateResult={(values) => {
    const gross = Number(values.gross);

    // BPJS employer contributions
    const bpjsKesehatan = gross * 0.04; // 4% health
    const bpjsJKK = gross * 0.0024; // 0.24% min work accident
    const bpjsJKM = gross * 0.003; // 0.3% death
    const bpjsJHT = gross * 0.037; // 3.7% pension fund
    const bpjsJP = gross * 0.02; // 2% pension

    const totalBPJS = bpjsKesehatan + bpjsJKK + bpjsJKM + bpjsJHT + bpjsJP;

    // THR provision (1 month spread over 12)
    const thrProvision = values.thr === "yes" ? gross / 12 : 0;

    const totalMonthly = gross + totalBPJS + thrProvision;

    return {
      total: Math.round(totalMonthly),
      breakdown: [
        { label: "Gross Salary", amount: gross },
        { label: "BPJS Kesehatan (4%)", amount: Math.round(bpjsKesehatan) },
        { label: "BPJS JKK (0.24%)", amount: Math.round(bpjsJKK) },
        { label: "BPJS JKM (0.3%)", amount: Math.round(bpjsJKM) },
        { label: "BPJS JHT (3.7%)", amount: Math.round(bpjsJHT) },
        { label: "BPJS JP (2%)", amount: Math.round(bpjsJP) },
        { label: "THR Provision", amount: Math.round(thrProvision) },
        { label: "Total Monthly Cost", amount: Math.round(totalMonthly) }
      ],
      currency: "IDR",
      note: `Employer BPJS: ~10.24% of salary`
    };

}}

## Регистрация в BPJS

### BPJS Kesehatan (Здоровье)

<InfoCard variant="note" title="Health Insurance">
**Взносы:**
- Всего: 5% от зарплаты
- Работодатель: 4%
- Сотрудник: 1%

**Лимит:** 12 миллионов IDR базовой зарплаты

**Покрытие:**

- Сотрудник
- Супруг(а)
- До 3 детей
- Дополнительные члены семьи: +1% за каждого
  </InfoCard>

### BPJS Ketenagakerjaan (Трудоустройство)

| Программа                               | Работодатель | Сотрудник | Всего       |
| --------------------------------------- | ------------ | --------- | ----------- |
| JKK (Несчастный случай на производстве) | 0.24-1.74%   | 0%        | Варьируется |
| JKM (Смерть)                            | 0.30%        | 0%        | 0.30%       |
| JHT (Пенсионный фонд)                   | 3.70%        | 2%        | 5.70%       |
| JP (Пенсия)                             | 2%           | 1%        | 3%          |

## Испытательный срок

<InfoCard variant="warning" title="Probation Rules">
**Только для PKWTT (Постоянный):**
- Максимум 3 месяца
- Должен быть оформлен письменно
- Полная зарплата во время испытательного срока
- Возможно расторжение с уведомлением во время испытательного срока
- Нет выходного пособия при расторжении во время испытательного срока

**Для PKWT (Срочный):**

- Испытательный срок НЕ допускается
- Любой пункт об испытательном сроке недействителен
  </InfoCard>

## Вопросы расчета заработной платы

### Требования к оплате

| Требование     | Деталь                               |
| -------------- | ------------------------------------ |
| Частота        | Ежемесячно (наиболее распространено) |
| Метод          | Банковский перевод                   |
| Валюта         | IDR                                  |
| Расчетный лист | Требуется                            |
| Удержания      | BPJS, PPh 21, займы                  |

### Удержание налога (PPh 21)

Работодатель обязан:

1.  Рассчитывать ежемесячный PPh 21
2.  Удерживать из зарплаты
3.  Перечислять до 10-го числа следующего месяца
4.  Отчитываться до 20-го числа следующего месяца
5.  Выдавать ежегодную налоговую справку (1721-A1)
