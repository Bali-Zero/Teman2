## PKWT (Contratto a Termine)

<InfoCard variant="warning" title="Limitazioni PKWT">
**Il PKWT può essere utilizzato solo per:**
- Lavori temporanei
- Lavori stagionali
- Progetti una tantum
- Lavori relativi a nuovi prodotti/processi (max 2 anni)

**Non può essere utilizzato per:**

- Posizioni permanenti
- Operazioni principali in corso
- Incarichi a tempo indeterminato

Violazione: Il contratto diventa automaticamente PKWTT (permanente).

</InfoCard>

### Regole sulla Durata del PKWT

| Regola                  | Limite                            |
| ----------------------- | --------------------------------- |
| Durata iniziale         | Max 5 anni (cumulativi)           |
| Rinnovi                 | Entro il limite di 5 anni         |
| Nessun periodo di prova | Periodo di prova nullo se scritto |
| Indennità               | Richiesta al completamento        |

### Regole sul Lavoro Straordinario

<Calculator
  title="Calcolatore del Lavoro Straordinario"
  description="Calcola il pagamento del lavoro straordinario"
  fields={[
    {
      id: "monthly",
      label: "Stipendio Mensile (IDR)",
      type: "number",
      defaultValue: 10000000,
      min: 0,
      step: 500000,
      suffix: "IDR"
    },
    {
      id: "hours",
      label: "Ore di Lavoro Straordinario",
      type: "number",
      defaultValue: 10,
      min: 0,
      max: 14,
      suffix: "ore"
    },
    {
      id: "day",
      label: "Tipo di Giorno",
      type: "select",
      options: [
        { value: "weekday", label: "Giorno feriale normale" },
        { value: "weekend", label: "Fine settimana/festivo" }
      ],
      defaultValue: "weekday"
    }
  ]}
  calculateResult={(values) => {
    const monthly = Number(values.monthly);
    const hours = Number(values.hours);

    // Tariffa oraria = 1/173 dello stipendio mensile
    const hourlyRate = monthly / 173;

    let overtime = 0;

    if (values.day === "weekday") {
      // Prima ora: 1.5x, ore successive: 2x
      if (hours >= 1) {
        overtime += hourlyRate * 1.5;
        if (hours > 1) {
          overtime += (hours - 1) * hourlyRate * 2;
        }
      }
    } else {
      // Fine settimana/festivo: calcolo diverso
      // Prime 8 ore: 2x, 9a ora: 3x, 10a+: 4x
      const first8 = Math.min(hours, 8);
      overtime += first8 * hourlyRate * 2;
      if (hours > 8) {
        overtime += hourlyRate * 3;
        if (hours > 9) {
          overtime += (hours - 9) * hourlyRate * 4;
        }
      }
    }

    return {
      total: Math.round(overtime),
      breakdown: [
        { label: "Stipendio Mensile", amount: monthly },
        { label: "Tariffa Oraria (1/173)", amount: Math.round(hourlyRate) },
        { label: "Ore di Lavoro Straordinario", amount: hours },
        { label: "Pagamento del Lavoro Straordinario", amount: Math.round(overtime) }
      ],
      currency: "IDR",
      note: values.day === "weekday" ? "Giorno feriale: 1.5x la prima ora, 2x dopo" : "Fine settimana: 2x le prime 8, 3x la 9a, 4x la 10a+"
    };

}}

## Diritto al Congedo

### Congedo Annuale

| Tipo                | Diritto                                |
| ------------------- | -------------------------------------- |
| Congedo annuale     | 12 giorni/anno (dopo 12 mesi)          |
| Congedo lungo       | 2 mesi dopo 6 anni (in alcune aziende) |
| Festività religiosa | Come da accordo                        |

### Congedo Speciale (Retribuito)

| Evento                            | Giorni   |
| --------------------------------- | -------- |
| Matrimonio                        | 3 giorni |
| Matrimonio del figlio             | 2 giorni |
| Circoncisione                     | 2 giorni |
| Battesimo                         | 2 giorni |
| Morte del coniuge/figlio/genitore | 2 giorni |
| Morte di un altro familiare       | 1 giorno |

| Tipo di Congedo | Durata                                  | Retribuzione     |

## Regolamenti Aziendali

### Quando Richiesti

<InfoCard variant="note" title="Peraturan Perusahaan">
Le aziende con **10+ dipendenti** devono avere:
- **PP (Peraturan Perusahaan)** - Regolamenti aziendali

O con sindacato:

- **PKB (Perjanjian Kerja Bersama)** - Accordo di contrattazione collettiva

Deve essere registrato presso l'ufficio del lavoro e rinnovato ogni 2 anni.

</InfoCard>
