## PKWT (Contratto a termine)

<InfoCard variant="warning" title="Limitazioni del PKWT">
**Il PKWT può essere utilizzato solo per:**
- Lavoro temporaneo
- Lavoro stagionale
- Progetti unici
- Lavoro legato a nuovi prodotti/processi (massimo 2 anni)

**Non può essere utilizzato per:**

- Posizioni permanenti
- Operazioni core continue
- Assegnazioni indefinite

Violazione: Il contratto diventa automaticamente PKWTT (permanente).

</InfoCard>

### Regole sulla durata del PKWT

| Regola         | Limite                     |
| ------------ | ------------------------- |
| Termine iniziale | Massimo 5 anni (cumulativi)  |
| Proroghe   | Entro il limite di 5 anni       |
| Nessuna prova | La prova è nulla se scritta |
| Compensazione | Richiesta alla fine  |

### Regole per le ore straordinarie

<Calculator
  title="Calcolatore ore straordinarie"
  description="Calcola la paga per le ore straordinarie"
  fields={[
    {
      id: "monthly",
      label: "Stipendio mensile (IDR)",
      type: "number",
      defaultValue: 10000000,
      min: 0,
      step: 500000,
      suffix: "IDR"
    },
    {
      id: "hours",
      label: "Ore straordinarie",
      type: "number",
      defaultValue: 10,
      min: 0,
      max: 14,
      suffix: "ore"
    },
    {
      id: "day",
      label: "Tipo di giorno",
      type: "select",
      options: [
        { value: "weekday", label: "Giorno lavorativo normale" },
        { value: "weekend", label: "Weekend/festivo" }
      ],
      defaultValue: "weekday"
    }
  ]}
  calculateResult={(values) => {
    const monthly = Number(values.monthly);
    const hours = Number(values.hours);

    // Tariffa oraria = 1/173 dello stipendio mensile
    const hourlyRate = monthly / 173;

    let overtime = 0;

    if (values.day === "weekday") {
      // Prima ora: 1.5x, ore successive: 2x
      if (hours >= 1) {
        overtime += hourlyRate * 1.5;
        if (hours > 1) {
          overtime += (hours - 1) * hourlyRate * 2;
        }
      }
    } else {
      // Weekend/festivo: calcolo diverso
      // Prime 8 ore: 2x, 9a ora: 3x, 10a+: 4x
      const first8 = Math.min(hours, 8);
      overtime += first8 * hourlyRate * 2;
      if (hours > 8) {
        overtime += hourlyRate * 3;
        if (hours > 9) {
          overtime += (hours - 9) * hourlyRate * 4;
        }
      }
    }

    return {
      total: Math.round(overtime),
      breakdown: [
        { label: "Stipendio mensile", amount: monthly },
        { label: "Tariffa oraria (1/173)", amount: Math.round(hourlyRate) },
        { label: "Ore straordinarie", amount: hours },
        { label: "Pagamento ore straordinarie", amount: Math.round(overtime) }
      ],
      currency: "IDR",
      note: values.day === "weekday" ? "Giorno lavorativo: 1.5x prima ora, 2x dopo" : "Weekend: 2x prime 8, 3x 9a, 4x 10a+"
    };

}}
/>

## Stipendio minimo

### Stipendio minimo regionale (UMR/UMK)

| Provincia/Città | UMR 2026 (Approssimativo) |
| ------------- | ----------------- |
| DKI Jakarta   | ~IDR 5.1M         |
| Bali          | ~IDR 2.9M         |
| Surabaya      | ~IDR 4.7M         |
| Bandung       | ~IDR 4.0M         |
| Semarang      | ~IDR 3.1M         |

<InfoCard variant="note" title="Note sullo stipendio minimo">

- L'UMR è lo stipendio minimo per i dipendenti permanenti
- Aggiornato annualmente (di solito gennaio)
- Possono applicarsi minimi settoriali
- Componenti: lo stipendio base può essere il 75%, le indennità il 25%
- I lavoratori PKWT hanno diritto agli stessi minimi

</InfoCard>

## Regolamenti aziendali

### Quando richiesti

<InfoCard variant="note" title="Peraturan Perusahaan">
Le aziende con **10+ dipendenti** devono avere:
- **PP (Peraturan Perusahaan)** - Regolamenti aziendali

O con sindacato:

- **PKB (Perjanjian Kerja Bersama)** - Accordo collettivo

Deve essere registrato presso l'ufficio del Lavoro e rinnovato ogni 2 anni.

</InfoCard>

## Violazioni comuni

| Violazione               | Rischio                     |
| ----------------------- | ------------------------ |
