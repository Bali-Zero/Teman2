## PKWT (Contratto a Termine)

<InfoCard variant="warning" title="Limitazioni del PKWT">
**Il PKWT può essere utilizzato solo per:**
- Lavoro temporaneo
- Lavoro stagionale
- Progetti una tantum
- Lavori legati a nuovi prodotti/processi (max 2 anni)

**Non può essere utilizzato per:**

- Posizioni permanenti
- Operazioni continue chiave
- Assegnazioni indefinite

Violazione: Il contratto diventa automaticamente PKWTT (permanente).

</InfoCard>

### Regole sulla Durata del PKWT

| Rule         | Limit                     |
| ------------ | ------------------------- |
| Initial term | Max 5 anni (cumulativo)   |
| Extensions   | Entro il limite dei 5 anni|
| No probation | Il periodo di prova è nullo se scritto |
| Compensation | Richiesto al completamento |

### Regole sul Lavoro Straordinario

<Calculator
  title="Calcolatore Lavoro Straordinario"
  description="Calcola il pagamento per lavoro straordinario"
  fields={[
    {
      id: "monthly",
      label: "Stipendio Mensile (IDR)",
      type: "number",
      defaultValue: 10000000,
      min: 0,
      step: 500000,
      suffix: "IDR"
    },
    {
      id: "hours",
      label: "Ore Straordinarie",
      type: "number",
      defaultValue: 10,
      min: 0,
      max: 14,
      suffix: "ore"
    },
    {
      id: "day",
      label: "Tipo di Giorno",
      type: "select",
      options: [
        { value: "weekday", label: "Giorno feriali normale" },
        { value: "weekend", label: "Fine settimana/festività" }
      ],
      defaultValue: "weekday"
    }
  ]}
  calculateResult={(values) => {
    const monthly = Number(values.monthly);
    const hours = Number(values.hours);

    // Tasso orario = 1/173 dello stipendio mensile
    const hourlyRate = monthly / 173;

    let overtime = 0;

    if (values.day === "weekday") {
      // Prima ora: 1.5x, ore successive: 2x
      if (hours >= 1) {
        overtime += hourlyRate * 1.5;
        if (hours > 1) {
          overtime += (hours - 1) * hourlyRate * 2;
        }
      }
    } else {
      // Fine settimana/festività: calcolo diverso
      // Prime 8 ore: 2x, 9ª ora: 3x, 10ª+: 4x
      const first8 = Math.min(hours, 8);
      overtime += first8 * hourlyRate * 2;
      if (hours > 8) {
        overtime += hourlyRate * 3;
        if (hours > 9) {
          overtime += (hours - 9) * hourlyRate * 4;
        }
      }
    }

    return {
      total: Math.round(overtime),
      breakdown: [
        { label: "Stipendio Mensile", amount: monthly },
        { label: "Tasso Orario (1/173)", amount: Math.round(hourlyRate) },
        { label: "Ore Straordinarie", amount: hours },
        { label: "Pagamento Straordinario", amount: Math.round(overtime) }
      ],
      currency: "IDR",
      note: values.day === "weekday" ? "Feriale: 1.5x prima ora, 2x dopo" : "Fine settimana: 2x prime 8 ore, 3x 9ª, 4x 10ª+"
    };

}}
/>

| Long leave        | 2 mesi dopo 6 anni (alcune aziende)    |
| Religious holiday | Secondo accordo                        |

### Congedo Speciale (Retribuito)

| Event                         | Giorni   |
| ----------------------------- | ------ |

## Regolamenti Aziendali

### Quando Sono Richiesti

<InfoCard variant="note" title="Peraturan Perusahaan">
Le aziende con **10+ dipendenti** devono avere:
- **PP (Peraturan Perusahaan)** - Regolamenti aziendali

Oppure, in presenza di sindacato:

- **PKB (Perjanjian Kerja Bersama)** - Accordo collettivo di lavoro

Devono essere registrati presso l'ufficio del Lavoro e rinnovati ogni 2 anni.

</InfoCard>
