# NIB & OSS System Indonesia 2026 : Guide d'enregistrement complet

Le NIB (Nomor Induk Berusaha) via l'OSS (Online Single Submission) est la porte d'entrée pour opérer légalement une entreprise en Indonesia.

## Qu'est-ce que le NIB ?

<InfoCard variant="note" title="Numéro d'Identification d'Entreprise">
**Le NIB (Nomor Induk Berusaha)** est :

- Votre numéro d'identification d'entreprise
- Un identifiant unique à 13 chiffres
- Remplace plusieurs anciennes licences
- La base de tous les autres permis
- Délivré instantanément via l'OSS

Le NIB fonctionne comme le TDP (Enregistrement de la Société), l'API (ID d'importateur) et l'accès douanier en un seul.

</InfoCard>

## Classification KBLI

<InfoCard variant="warning" title="Choisissez avec soin">
La **KBLI (Klasifikasi Baku Lapangan Usaha Indonesia)** est cruciale :

- Codes d'activité à 5 chiffres
- Détermine la classification des risques
- Affecte les exigences de permis
- Doit correspondre à l'activité réelle
- Les modifications nécessitent des avenants

Un KBLI erroné peut entraîner des permis incorrects ou des violations du DNI.

</InfoCard>

### Trouver les codes KBLI

1. Rechercher dans le système OSS
2. Consulter le guide KBLI (publication BPS)
3. Consulter un notaire/agent
4. Correspondre à votre plan d'affaires

### Exemples courants de KBLI

| Activité               | Code KBLI          |
| ---------------------- | ------------------ |
| Restaurant             | 56101              |
| Développement logiciel | 62012              |
| Commerce (général)     | 46900              |
| Conseil                | 70201              |
| Hôtel                  | 55111              |
| Fabrication            | Divers 10xxx-33xxx |

## Classification des risques

Après la saisie du KBLI, l'OSS détermine le niveau de risque :

### Niveaux de risque

| Niveau       | Exigences                 | Traitement          |
| ------------ | ------------------------- | ------------------- |
| Faible       | NIB uniquement            | Instantané          |
| Moyen-faible | NIB + Certificat Standard | Auto-déclaration    |
| Moyen-élevé  | NIB + Certificat Standard | Vérification        |
| Élevé        | NIB + Permis              | Évaluation complète |

### Ce qui détermine le risque ?

- Secteur d'activité
- Échelle de l'entreprise
- Impact environnemental
- Santé/sécurité publique
- Considérations de sécurité

## Après l'obtention du NIB

### Prochaines étapes immédiates

1. **Télécharger le certificat NIB** - Enregistrer le PDF
2. **Vérifier les engagements** - Examiner toutes les conditions
3. **Demander les permis sectoriels** - Si requis par le KBLI
4. **Finaliser l'environnemental** - Si l'engagement est affiché
5. **Activer les fonctions d'importation** - Si nécessaire

### Obligations continues

- **Rapports LKPM** - Rapports d'investissement trimestriels/semestriels
- **Mises à jour des données** - Lorsque les informations changent
- **Renouvellements de licence** - Avant toute expiration
- **Conformité** - Avec toutes les conditions de permis

## Problèmes courants

### Problèmes OSS

| Problème                | Solution                                   |
| ----------------------- | ------------------------------------------ |
| AHU non synchronisé     | Attendre ou contacter AHU                  |
| KBLI introuvable        | Utiliser les bons termes de recherche      |
| Adresse rejetée         | Vérifier le format/les coordonnées         |
| Erreur système          | Essayer un autre navigateur/moment         |
| Incohérence des données | S'assurer que l'acte correspond à l'entrée |

### Comment corriger les erreurs

<InfoCard variant="tip" title="Modifier le NIB">
Si vous avez fait des erreurs :

1. **Changements mineurs** - Mettre à jour via l'OSS
2. **Changements KBLI** - Peut nécessiter un amendement de l'acte d'abord
3. **Changement d'adresse** - Mettre à jour avec le nouveau domicile
4. **Changement de propriété** - Nécessite un processus juridique d'abord

Toujours mettre à jour l'OSS lorsque les données de l'entreprise changent.

</InfoCard>

## Conseils pour réussir

1. **Préparer les documents en premier** - Avoir tout prêt
2. **Utiliser le navigateur Chrome** - Meilleure compatibilité
3. **Internet stable** - Éviter les problèmes de délai d'attente
4. **Enregistrer la progression** - Le système peut expirer
5. **Capturer des captures d'écran** - Pour les enregistrements
