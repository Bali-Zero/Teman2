# KBLI 2025 Hôtellerie & Hébergement : Villa, Hôtel, Homestay et Gestion à Bali

Le secteur de l'hébergement à Bali est le segment le plus visible internationalement de l'économie d'Indonesia — et le plus complexe sur le plan juridique. Sous KBLI 2025, l'ensemble du secteur est restructuré avec des codes dédiés pour chaque type d'hébergement, formalisant ce qui était auparavant un patchwork d'entreprises mal classées. Pour les investisseurs étrangers, ces changements créent à la fois urgence et opportunité.

Ce guide couvre l'ensemble de l'offre d'hébergement : des hôtels cinq étoiles aux hôtels non classés, l'activité commerciale des villas, les homestay, les aparthotels et les sociétés de gestion professionnelles — ainsi que les facteurs structurels qui définissent la thèse d'investissement pour 2026 et au-delà.

## La transition critique : 55193 → 55203

### Ce qui s'est passé

Pendant des années, les exploitants de villas à Bali ont utilisé le **KBLI 55193 (Pondok Wisata)** — un code conçu pour les maisons d'hôtes traditionnelles indonésiennes — pour classer l'activité commerciale des villas. L'inadéquation était structurelle : pondok wisata implique une petite maison d'hôtes rustique, détenue localement, mais le code est devenu le conteneur par défaut pour des opérations de villas de plusieurs milliards de roupies.

**KBLI 2025 corrige cela avec le 55203 (Aktivitas Vila)** — un code dédié reconnaissant formellement l'activité commerciale des villas comme une catégorie d'entreprise distincte.

### Pourquoi cela est important sur le plan opérationnel

Après le 18 juin 2026 (date limite de migration KBLI 2025 selon la Réglementation BPS 7/2025), le **code 55193 deviendra un code fantôme** — non reconnu par le système OSS-RBA. Toute entreprise fonctionnant encore sous le 55193 verra son NIB pointer vers une classification inexistante, créant des problèmes cumulatifs :

- **Risque de déréférencement OTA** : Airbnb, Booking.com et Agoda exigent progressivement un TDUP valide lié à un code KBLI actuel. Un code fantôme signifie pas de TDUP valide, ce qui peut entraîner la suppression de la plateforme.
- **Complications bancaires** : Les banques indonésiennes exigent de plus en plus la vérification du NIB par rapport aux codes KBLI actifs pour le maintien des comptes professionnels.
- **Exposition aux autorités fiscales** : CoreTax (CTAS) recoupe les codes d'activité commerciale — les incohérences déclenchent des audits algorithmiques.

### Le processus de migration

```
Current State (55193 or misclassified) → Target State (55203)

Step 1: Access OSS portal (oss.go.id)
Step 2: Request "Perubahan NIB" (NIB amendment)
Step 3: Select KBLI 2025 code 55203 — Aktivitas Vila
Step 4: OSS-RDTR validation (GPS coordinates checked against zoning map)
Step 5: TDUP reissuance from Dinas Pariwisata Bali
Step 6: Update tax registration (NPWP) to reflect new KBLI
Deadline: June 18, 2026
```

## Le moratoire sur la construction de Sarbagita

### Ce que c'est

Le **moratoire Sarbagita** est un gel de la construction applicable à quatre régences : **Denpasar, Badung, Gianyar et Tabanan** — le cœur de l'économie touristique de Bali. Le moratoire, lié au plan d'aménagement du territoire régional (RTRW Bali 2009-2029 et ses révisions), bloque effectivement les nouveaux permis de construire pour l'hébergement dans les zones de plus forte demande.

### Comment cela fonctionne en 2026

Le moratoire n'interdit pas toutes les constructions — il cible les nouvelles structures d'hébergement sur des terrains non développés ou zonés résidentiels. En pratique :

- **Nouvelle construction d'hôtel** : Effectivement impossible à Seminyak, Kuta, Sanur, Nusa Dua, Ubud central sans PBG komersial préexistant
- **Construction de villas** : Les nouvelles villas sur terrains vierges à Canggu, Uluwatu, Pecatu nécessitent une vérification RDTR qui bloque souvent l'utilisation commerciale de l'hébergement
- **Rénovation/extension** : Généralement autorisée pour les structures avec un PBG komersial existant
- **En dehors des quatre régences** : Buleleng, Karangasem, Klungkung, Jembrana, Bangli ne sont pas sous le moratoire

### L'implication pour l'investissement

Le moratoire crée une **rareté artificielle** dans les zones privilégiées de Bali. Les actifs d'hébergement sous licence existants — hôtels, villas, maisons d'hôtes avec TDUP et PBG komersial valides — se négocient avec une prime structurelle. Pour les investisseurs PMA, la stratégie d'entrée optimale est passée de la construction sur terrain vierge à :

1.  **L'acquisition d'actifs sous licence existants** avec TDUP + PBG komersial confirmés
2.  **La location-bail** de structures opérationnelles avec un historique de licence propre
3.  **En dehors des zones Sarbagita** : Nouvelle construction à Buleleng (Lovina), Karangasem (Amed, Candidasa), Klungkung (Nusa Penida)

## Intégration OSS-RDTR : Application GPS

### La nouvelle réalité

Depuis 2025, le système OSS-RBA d'Indonesia s'intègre à la base de données GIS **RDTR (Rencana Detail Tata Ruang)** de chaque régence. Lorsqu'une entreprise demande une licence, le système OSS valide les coordonnées GPS de la propriété par rapport à la carte de zonage numérique.

Cela signifie :

- Une adresse écrite sur un terrain résidentiel ne peut pas recevoir de TDUP pour un hébergement commercial
- Le système valide automatiquement — il n'y a pas de discrétion humaine à ce stade
- Les demandes de reclassification de zone existent mais prennent 1 à 3 ans

### Pour les exploitants de villas

Chaque villa à Bali a une zone désignée dans le GIS RDTR :

- **Zona Pariwisata (K-3)** : Hébergement commercial entièrement autorisé
- **Zona Perdagangan dan Jasa (K-1/K-2)** : Hébergement commercial généralement autorisé
- **Zona Perumahan (R-1/R-2/R-3)** : Hébergement commercial bloqué — usage résidentiel uniquement
- **Zona Pertanian (P-2)** : Terre agricole, hébergement généralement bloqué

**Avant toute acquisition ou développement, la validation des coordonnées GPS dans le GIS RDTR est non négociable.**

## Secteur hôtelier : Étoiles et structure

### Le système de certification LSU

Tous les hôtels classés par étoiles nécessitent une certification annuelle d'un **Lembaga Sertifikasi Usaha (LSU)** — un organisme de certification hôtelière accrédité et approuvé par le Ministère du Tourisme.

| Étoile | Critères LSU | Minimums Clés                                              |
| ------ | ------------ | ---------------------------------------------------------- |
| 5★     | 60+ critères | Gastronomie, spa, conciergerie, salles de réunion          |
| 4★     | 35+ critères | Piscine, restaurant, fitness, réception 24h/24             |
| 3★     | 28+ critères | Restaurant, climatisation, wifi, eau chaude                |
| 2★     | 20+ critères | Réception, petit-déjeuner, climatisation, wifi, eau chaude |
| 1★     | 15+ critères | Réception, climatisation, eau chaude                       |

Le non-respect des critères = déclassement ou révocation. La certification est renouvelée annuellement — c'est un engagement opérationnel continu, pas une approbation unique.

### La migration KBLI pour les hôtels

Sous KBLI 2020, **tous les hôtels classés par étoiles partageaient le code 55110 (Hotel Bintang)**. KBLI 2025 introduit des **codes distincts pour chaque niveau d'étoiles** (55101-55105).

Les hôtels dont le NIB affiche 55110 doivent migrer vers leur code d'étoiles correct avant le 18 juin 2026. La migration n'est pas automatique — elle nécessite une application OSS active avec la documentation de certification LSU comme preuve justificative.

## Activité de villa : KBLI 55203 en profondeur

### Le modèle de villa commerciale

Une villa à Bali génère des revenus grâce à la location à court terme (200-2 000 $+/nuit pour le luxe). Sous KBLI 55203, cela est classé comme **activité d'hébergement commercial** — légalement identique en structure à l'exploitation hôtelière.

La pile de licences correcte pour une PT PMA exploitant une villa commerciale :

```
NIB (OSS) with KBLI 55203
  ↓
PBG Komersial (Building Approval for Commercial Use)
  ↓
SLF (Certificate of Occupancy - Commercial)
  ↓
TDUP (Tourism Business License) from Dinas Pariwisata Bali
  ↓
NPWP registered as hospitality business (PBJT 10% applies)
  ↓
OTA accounts linked to TDUP number
```

### Le paradoxe du capital

La **Réglementation BKPM 5/2025** a réduit l'exigence de capital libéré pour les PT PMA de 10 milliards d'IDR à **2,5 milliards d'IDR** — une réduction significative qui a amélioré l'accessibilité. Cependant, l'**exigence d'investissement total reste de 10 milliards d'IDR par code KBLI**, avec une période de blocage de 12 mois.

Pour une seule opération de villa :

- Un capital libéré minimum de 2,5 milliards d'IDR doit apparaître sur le compte bancaire de la PT PMA lors de l'enregistrement
- Un investissement total de 10 milliards d'IDR doit être engagé (peut inclure la valeur de l'actif de la villa, la rénovation, le mobilier, le capital d'exploitation)
- La plupart des villas de luxe à Canggu/Uluwatu ont une valeur d'actif de 8 à 20 milliards d'IDR et plus — atteindre le seuil de 10 milliards d'IDR est réaliste pour les propriétés haut de gamme

### L'architecture à trois voies pour les investisseurs étrangers

**Voie 1 : PT PMA directe**

- La PT PMA détient le bail (HGB/Hak Guna Bangunan) ou le droit de gestion
- La PT PMA détient directement le TDUP
- Idéal pour : villa unique ou petit portefeuille, engagement à long terme
- Exigences : 2,5 milliards d'IDR de capital libéré + 10 milliards d'IDR d'investissement total, directeur indonésien

**Voie 2 : PT PMA + Société de gestion PMDN**

- La PT PMA détient l'actif via un bail
- La PMDN (société indonésienne locale) détient le TDUP et gère les opérations
- La PT PMA et la PMDN ont un accord de gestion avec partage des revenus
- Idéal pour : les investisseurs qui souhaitent la propriété des actifs sans la complexité opérationnelle
- La société de gestion s'occupe du personnel, des OTA, de la conformité TDUP

**Voie 3 : Résidentiel à long terme + Partage des revenus**

- Le propriétaire de la villa (nommé WNI ou structure de fiducie) détient le PBG résidentiel
- Partage des revenus opérationnels avec la société de gestion
- Zone grise légale — risque croissant d'application après 2026
- Non recommandé pour les nouvelles structures ou celles recherchant un investissement/sortie institutionnel

## Homestay vs Villa : La distinction légale

La confusion entre KBLI 55201 (homestay) et 55203 (villa) est commercialement significative :

| Dimension                 | 55201 Homestay                                 | 55203 Villa                                    |
| ------------------------- | ---------------------------------------------- | ---------------------------------------------- |
| Résidence du propriétaire | Requise (le propriétaire vit sur la propriété) | Non requise (propriété commerciale)            |
| Éligible PMA              | De facto non (condition de résidence)          | Oui (100% PMA autorisé)                        |
| TDUP                      | Requis                                         | Requis                                         |
| Traitement fiscal         | PBJT 10% sur les revenus                       | PBJT 10% sur les revenus                       |
| Visibilité OTA            | Airbnb, Booking (avec TDUP)                    | Airbnb, Booking, plateformes de villas de luxe |
| Potentiel d'échelle       | Propriété unique, limitée                      | Possibilité d'échelle de portefeuille          |
| Exigence de capital       | Faible (occupé par le propriétaire)            | Élevée (2,5 milliards d'IDR+ pour PT PMA)      |

**Règle clé** : Si un investisseur étranger souhaite générer des revenus locatifs commerciaux à partir d'une villa à Bali, la structure correcte est **PT PMA + KBLI 55203**, jamais la voie du homestay qui exige que le propriétaire réside physiquement sur la propriété.

## Aparthotel (55204) : L'opportunité des nomades numériques

Le format aparthotel est apparu comme l'intersection de l'appartement avec services et de l'hôtel — tarifs journaliers ou hebdomadaires, services hôteliers (ménage, réception), mais unités de taille appartement (40-80 m²) avec cuisines et espaces de travail dédiés.

### Pourquoi Bali, pourquoi maintenant

- **Population nomade** : Canggu accueille à lui seul une estimation de plus
