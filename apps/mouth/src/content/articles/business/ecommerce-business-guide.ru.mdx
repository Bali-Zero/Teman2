Цифровая экономика Индонезии:

## PT PMA для электронной коммерции

### Коды KBLI для электронной коммерции

| KBLI Code | Деятельность                                   | Примечания                                |
| --------- | ---------------------------------------------- | ----------------------------------------- |
| 47911     | Интернет-розница (общая)                       | Наиболее распространен для онлайн-розницы |
| 47912     | Оптовая интернет-торговля                      | B2B электронная коммерция                 |
| 62011     | Разработка программного обеспечения/приложений | Для платформ                              |
| 63122     | Деятельность веб-порталов                      | Операции маркетплейса                     |

### Иностранное владение

Большинство видов деятельности в сфере электронной коммерции допускают **100% иностранное владение** через PT PMA. Исключения:

- Некоторые розничные категории
- Деятельность из негативного списка
- Платформы с элементами социальных сетей

<InfoCard variant="warning" title="Check KBLI Restrictions">
  Некоторые коды KBLI имеют ограничения или требования к иностранному владению.
  Проверьте вашу конкретную деятельность перед созданием компании.
</InfoCard>

## Регистрация PSE

Регистрация **PSE (Penyelenggara Sistem Elektronik)** обязательна для электронной коммерции:

### Кому нужна PSE?

- Любой веб-сайт/приложение, работающее в Индонезии
- Платформы электронной коммерции
- Поставщики онлайн-услуг
- Приложения, обрабатывающие данные индонезийских пользователей

### Типы PSE

| Тип         | Для                    | Пример                        |
| ----------- | ---------------------- | ----------------------------- |
| PSE Private | Частные компании       | Магазин электронной коммерции |
| PSE Public  | Государственные услуги | Не применимо для бизнеса      |

### Как зарегистрироваться

1. Доступ к системе OSS
2. Подать заявку на регистрацию PSE
3. Предоставить учредительные документы компании
4. Подробно описать вашу электронную систему
5. Получить сертификат PSE

## Продажи на маркетплейсах

Без PT PMA иностранцы все еще могут продавать через:

### Индонезийские маркетплейсы

- **Tokopedia** - Крупнейший маркетплейс
- **Shopee** - Популярный, ориентированный на мобильные устройства
- **Lazada** - Поддерживается Alibaba
- **Blibli** - Ориентированный на качество
- **Bukalapak** - Ориентированный на малый и средний бизнес

### Требования

- Индивидуальный или бизнес-аккаунт
- Индонезийский банковский счет (обычно)
- Действительное удостоверение личности
- Соответствие продукта правилам платформы

<InfoCard variant="tip" title="Start Small on Marketplaces">
  Протестируйте свои продукты на маркетплейсах, прежде чем инвестировать в PT
  PMA. Используйте данные маркетплейсов для проверки спроса перед более крупными
  инвестициями.
</InfoCard>

## Платежные решения

### Популярные способы оплаты

- **Банковский перевод** - Все еще распространен
- **Электронные кошельки** - OVO, GoPay, DANA, ShopeePay
- **QRIS** - Универсальный QR-код
- **COD** - Наложенный платеж (важно для доверия)
- **Кредитные карты** - Ограниченное распространение

### Варианты платежных шлюзов

- Midtrans (альтернатива Stripe)
- Xendit
- DOKU
- Faspay

## Налоговые соображения

### Налогообложение электронной коммерции

| Вид налога             | Ставка            | Применяется к           |
| ---------------------- | ----------------- | ----------------------- |
| НДС (PPN)              | 11%               | Продажи товаров         |
| Налог на прибыль (PPh) | 22% корпоративный | Прибыль компании        |
| Удержание              | Варьируется       | Определенные транзакции |

### Трансграничные соображения

- Импортные пошлины на товары стоимостью более 3 долларов США
- НДС на цифровые услуги
- Правила трансфертного ценообразования для связанных сторон
