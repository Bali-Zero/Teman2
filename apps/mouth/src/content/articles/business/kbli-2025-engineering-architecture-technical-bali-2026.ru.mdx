Сектор инженерии и архитектуры на Bali вступает в период одновременных ограничений и возможностей. Мораторий Sarbagita ограничивает новое строительство в самой активной зоне Южного Bali, в то время как North Bali Airport (Perpres 12/2025) и платная дорога Gilimanuk-Mengwi создают новый инфраструктурный коридор стоимостью миллиарды USD. На это накладывается критический переход IMB→PBG, создающий огромный рынок модернизации и инспекции, а также геопространственная система валидации OSS-RDTR GPS, которая теперь контролирует каждый строительный проект.

## Нормативно-правовая база 2026

### Структурные изменения KBLI 2025 для Группы 71

KBLI 2025 (BPS Reg 7/2025, на основе ISIC Rev.5) представил наиболее значительную реструктуризацию subgolongan 7120 в истории KBLI:

| Старый KBLI 2020                             | Новый KBLI 2025                  | Изменение                                                                        |
| :------------------------------------------- | :------------------------------- | :------------------------------------------------------------------------------- |
| 71200 (Тестирование и анализ — агрегировано) | 71201 (Сертификация)             | **Разделено на 5 конкретных кодов**                                              |
| 71200                                        | 71202 (Инспекция)                |                                                                                  |
| 71200                                        | 71203 (Верификация и валидация)  |                                                                                  |
| 71200                                        | 71204 (Техническое тестирование) |                                                                                  |
| 71200                                        | 71209 (Прочее тестирование)      |                                                                                  |
| 71101 (Архитектура)                          | 71101 (Архитектура)              | Сохранено, описание расширено (добавлена ссылка на IBC)                          |
| 71109 (Инженерия)                            | 71109 (Инженерия)                | Сохранено, расширено для включения управления проектами и инженерии безопасности |

**Требуемые действия**: Все компании с KBLI 71200 должны перераспределить свою деятельность по новым конкретным кодам и обновить свой NIB в OSS до **18 июня 2026 года**.

### Структура PMA: UU Jasa Konstruksi (UU 2/2017 + PP 14/2021)

Для PT PMA, связанных со строительством (BUJK PMA):

| Требование                                       | Деталь                                              |
| :----------------------------------------------- | :-------------------------------------------------- |
| Требуется SBU                                    | Через аккредитованный LPJK орган                    |
| Максимальная иностранная собственность           | **67%** (минимум 33% местного партнера)             |
| Минимальный чистый капитал (консалтинг)          | IDR 250 billion (perencana dan pengawas konstruksi) |
| SKK (Сертификат профессиональной компетентности) | Обязательно для каждого технического сотрудника     |
| Передача знаний                                  | Обязательно для всех иностранных TKA                |

### OSS-RDTR GPS: Новый привратник строительства

PP 28/2025 поднял RDTR (Rencana Detail Tata Ruang) со статуса инструмента планирования до **основного юридического определяющего фактора для лицензирования OSS**. Проверка происходит автоматически:

1. Предприниматель вводит GPS-координаты проекта в OSS
2. Система сверяет координаты с цифровыми картами зонирования RDTR (более 800 RDTR интегрированы по всей стране к концу 2025 года)
3. Если деятельность по KBLI несовместима с зоной → **NIB автоматически блокируется**. Без административного усмотрения.

Для инженерных и архитектурных проектов это означает:

- Проверка соответствия RDTR должна проводиться **до** любой аренды, покупки земли или регистрации в OSS
- Одно и то же местоположение может быть разрешено для одного вида деятельности и запрещено для другого
- Несоблюдение может аннулировать все последующие разрешения (PBG, экологические разрешения, операционные лицензии)
- Интерактивный инструмент RDTR: https://oss.go.id/rdtr-interaktif

### IMB → PBG + SLF: Критический переход наследия 2026 года

Старая система IMB (Izin Mendirikan Bangunan) была полностью заменена:

- **PBG** (Persetujuan Bangunan Gedung): Разрешение на проектирование здания до начала строительства — подтверждает соответствие RTRW, структурную безопасность и воздействие на окружающую среду
- **SLF** (Sertifikat Laik Fungsi): Сертификат функциональной пригодности, выдаваемый после завершения строительства, проверяемый лицензированным pengkaji teknis с IPTB
- Управляется онлайн через SIMBG (simbg.pu.go.id)

**Все существующие сооружения с IMB должны перейти на PBG+SLF.** Это создает огромный рынок по всем кодам 71xxx: архитектурные аудиты, технические инспекции, испытания материалов и инженерные оценки для тысяч отелей, вилл и коммерческих структур Bali.

## KBLI 71101 — Архитектурные услуги

**Парадокс эстетики Bali**

Наиболее ценное отличие на архитектурном рынке Bali — это способность разрешать фундаментальный конфликт дизайна: клиенты требуют местную балийскую архитектуру — бамбук, утрамбованную землю, крыши из alang-alang, интеграцию рисовых террас и философскую основу **Tri Hita Karana** — при этом требуя международных клинических и гостиничных характеристик: скрытые HVAC, санитарные стандарты, сейсмическая устойчивость для условий Ring of Fire.

**Ограничение по высоте в 15 метров** («не выше кокосовой пальмы») — установленное SK Gubernur 1971 и подтвержденное в Perda 16/2009 Art. 95 — вынуждает к творческим решениям: проектирование зданий вниз по склону обрыва, полуподземные пространства и каскадные террасы. Редкие исключения (больницы, аэропорты, передающие вышки) не распространяются на отели или курорты.

**Операционные требования**: Сертификация SBU через LPJK по подклассификациям AR001/AR002. Требуется минимум 33% местного партнера. SKK обязателен для каждого архитектора. Иностранные архитекторы должны пройти программу передачи знаний (alih teknologi).

**Зоны возможностей 2026 года**:

| Зона                   | Статус                     | Обоснование                                                            |
| :--------------------- | :------------------------- | :--------------------------------------------------------------------- |
| Uluwatu                | Быстро растет              | Прибывает международный аэропорт; пока на ранней стадии                |
| North Bali (Buleleng)  | Лучшая возможность         | Вне моратория Sarbagita; ожидается аэропорт                            |
| Sanur                  | Недостаточно обслуживается | Расширение медицинского туризма KEK                                    |
| Tabanan/West Bali      | Развивается                | Коридор платной дороги Gilimanuk-Mengwi                                |
| South Bali (Sarbagita) | Ограничено                 | Мораторий ограничивает новое строительство; сильный рынок модернизации |

## KBLI 71109 — Инженерный консалтинг (Общий)

**Самый универсальный и востребованный код в группе 71xxx**

KBLI 2025 расширяет сферу действия 71109, явно включая управление проектами и инженерию безопасности, что делает его оптимальной основной лицензией для инженерной фирмы PT PMA. Охватывает гражданское, гидравлическое, транспортное, MEP, геотехническое, акустическое проектирование и многое другое.

### Инфраструктурный трубопровод 2025–2030

**North Bali Airport** (Perpres 12/2025):

- Местоположение: Kubutambahan, Buleleng Regency (северное побережье)
- Масштаб: 2 800 гектаров, значительный компонент морской рекультивации
- Целевая пропускная способность: до 50 миллионов пассажиров
- Начало строительства: ориентировочно ~2027 год (в настоящее время на подготовительной/финансовой стадии)
- Инженерный спрос: геотехнический, прибрежный, морской, структурный, транспортный

**Платная дорога Gilimanuk-Mengwi**:

- Длина: 97 км по трем участкам
- Стоимость: IDR 5 trillion (строительство) + IDR 4 trillion (приобретение земли), схема ГЧП
- Целевое завершение: 2027–2029
- Влияние: сокращает время в пути Gilimanuk-Mengwi с 3–4 часов до 1–1,5 часов

**Спрос после наводнения** (наводнения на Bali в сентябре 2025 года): взрывной рост гидрологических исследований, дренажной инженерии и снижения рисков — особенно в соответствии с требованиями Pergub 24/2020 по защите озер/источников/рек/морей.

## KBLI 71201 — Техническая сертификация

**Новая детализация в KBLI 2025** — охватывает сертификацию продукции, процессов, услуг и систем: ISO, HACCP, ISPO, SMK3, халяльную сертификацию, легальность древесины (SVLK) и строительную сертификацию SBU.

**Основной фактор спроса на Bali**: экомаркировка и сертификация устойчивого туризма. KBLI 2025 явно включает _sertifikasi kegiatan pariwisata_ в сферу действия этого кода. Сертификация «зеленых» зданий (EDGE, Greenship) растет на эко-курортах.

**Входной барьер**: Требуется аккредитация KAN (Национальный аккредитационный комитет). Рынок доминируется SGS, Bureau Veritas, TÜV. Лучше позиционируется как дополнительная услуга для PMA, уже работающей в 71101/71109, чем как самостоятельный бизнес.

## KBLI 71202 — Техническая инспекция

**Немедленная рыночная возможность 2026–2028 годов**

Отделен от старого 71200 в KBLI 2025. Охватывает инспекцию трубопроводов и конструкций, не связанную с ремонтом/установкой. Переход IMB→PBG создает **огромное количество требований к инспекции**:

- Тысячи отелей, вилл и коммерческих структур Bali требуют технической инспекции для миграции PBG/SLF
- После наводнений в сентябре 2025 года: структурные инспекции поврежденных зданий в Sarbagita и Buleleng
- Периодический водный кризис стимулирует спрос на инспекцию трубопроводных сетей

Требуется IPTB (Лицензия технического специалиста по зданиям) для инспекторов. Высокая юридическая ответственность — ошибки инспекции создают риск судебных разбирательств. **Отлично подходит в качестве дополнения к 71101 или 71109** для полного пакета проектирования + инспекции.

## KBLI 71203 — Техническая верификация и валидация

**Полностью новый в KBLI 2025** (не было в KBLI 2020). Охватывает верификацию и валидацию технических процессов, систем и документов без выдачи окончательной сертификации.

Особенно актуально для консалтинга по предварительной валидации OSS-RDTR — помощь клиентам в проверке соответствия GPS-координат перед официальной подачей. В сложных проектах эко-курортов одновременное соблюдение сейсмических стандартов, экологических норм, ограничения по высоте в 15 м и международных стандартов (WELL, LEED, FGI 2026) создает специализированную нишу валидации.

Лучше всего позиционируется как **дополнительный код** в рамках предложения с несколькими KBLI.

## KBLI 71204 — Техническое тестирование

**Высокий потенциал, высокий барьер**

Физическое, химическое и аналитическое тестирование материалов, продуктов и условий окружающей среды. Спрос, специфичный для Bali:

| Тип тестирования               | Применение на Bali                                                                |
| :----------------------------- | :-------------------------------------------------------------------------------- |
| Тестирование качества воды     | Загрязнение от чрезмерного туризма; медицинские требования KEK Sanur              |
| Местные строительные материалы | Конструкционный бамбук, камень Paras Bali, утрамбованная земля по стандартам SNI  |
| Сейсмическое тестирование      | Соответствие существующих конструкций после землетрясения                         |
| Акустическое тестирование      | Парадокс дизайна курортов под открытым небом против требований конфиденциальности |
| Тестирование внутренней среды  | FGI 2026 Доказательный дизайн для оздоровительных центров и клиник                |

**Рыночный пробел**: Большинство образцов с Bali в настоящее время отправляются в Surabaya или Jakarta для тестирования. Аккредитованная KAN лаборатория на Bali устранила бы этот пробел. Партнерство с Udayana University может значительно сократить CAPEX.

## KBLI 71209 — Прочее техническое тестирование

Остаточный код, охватывающий все. Включает судебную экспертизу, физическое моделирование (аэропорты, плотины) и анализ качества продукции. Актуальные применения на Bali: судебный анализ структурных разрушений после наводнений, моделирование морского воздействия для рекультивации North Bali Airport, тестирование качества ремесленных балийских продуктов для
