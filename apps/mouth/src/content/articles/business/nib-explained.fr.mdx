# Explication du NIB : Votre numéro d'identification d'entreprise indonésien 2026

Le NIB (Nomor Induk Berusaha) est la pierre angulaire de l'enregistrement des entreprises en Indonesia. Considérez-le comme la carte d'identité nationale de votre entreprise, requise pour pratiquement tout.

## Ce que le NIB remplace

Le NIB a consolidé plusieurs licences auparavant distinctes :

| Ancienne Licence         | Fonction                     | Désormais partie du NIB |
| :----------------------- | :--------------------------- | :---------------------- |
| **TDP**                  | Enregistrement d'entreprise  | ✓ Remplacé              |
| **API-U**                | ID d'importateur général     | ✓ Remplacé              |
| **Angka Pengenal Impor** | Numéro d'importation         | ✓ Remplacé              |
| **Access to customs**    | Dédouanement à l'importation | ✓ Inclus                |

<InfoCard variant="tip" title="Un numéro, plusieurs fonctions">
  Le NIB simplifie l'enregistrement des entreprises. Au lieu d'obtenir plusieurs
  licences distinctes, vous obtenez un seul NIB qui sert à plusieurs fins. Ce
  fut une amélioration majeure par rapport au système d'avant 2018.
</InfoCard>

## NIB et classification des risques

Dans le cadre de l'OSS RBA (approche basée sur le risque), votre NIB détermine les permis supplémentaires dont vous avez besoin :

| Niveau de risque        | NIB + Quoi d'autre ?                    |
| :---------------------- | :-------------------------------------- |
| **Faible risque**       | NIB uniquement                          |
| **Risque moyen-faible** | NIB + Sertifikat Standar                |
| **Risque moyen-élevé**  | NIB + Sertifikat Standar + Vérification |
| **Risque élevé**        | NIB + Izin complète (licence)           |

<InfoCard variant="note" title="Risque déterminé par KBLI">
  Vos codes d'activité commerciale (KBLI) déterminent le niveau de risque. Le
  conseil en technologie est généralement à risque faible à moyen. La production
  alimentaire est à risque plus élevé. Le système OSS classe automatiquement en
  fonction de votre sélection KBLI.
</InfoCard>
