## Why Accounting Software Matters for PT PMA

Choosing the right accounting software is one of the most impactful decisions for a PT PMA's financial management. Indonesia's complex tax environment -- with monthly PPh 21, PPh 25, PPh 23/26, VAT (PPN), and the new CoreTax system -- means manual bookkeeping on spreadsheets is no longer practical for most businesses.

The right software automates tax calculations, generates compliant reports, integrates with government systems, and gives you real-time visibility into your company's financial health.

Before comparing options, understand what your PT PMA actually needs:

### Must-Have Features

## e-Faktur Integration: Why It Matters

### What Is e-Faktur?

e-Faktur (electronic VAT invoice) is DJP's mandatory system for creating, approving, and reporting VAT invoices. If your PT PMA is registered as PKP (VAT collector), every taxable transaction must have an e-Faktur.

### How Integration Works

**Without integration (manual process):**

1. Create sales invoice in accounting software
2. Log into DJP e-Faktur application
3. Manually enter the same invoice data
4. Upload for DJP approval
5. Download approved e-Faktur
6. Manually record approval number in accounting software

**With integration (Jurnal.id or Accurate):**

1. Create sales invoice in accounting software
2. Click "Generate e-Faktur"
3. System automatically submits to DJP
4. Approved e-Faktur is recorded in accounting software
5. Monthly VAT report is generated automatically

The time savings are significant -- from 15-30 minutes per invoice (manual) to 30 seconds (integrated).

## CoreTax: The New DJP System

### What Is CoreTax?

CoreTax (Sistem Inti Administrasi Perpajakan) is DJP's next-generation tax administration platform. It aims to consolidate all tax services:

| Old System | CoreTax Replacement    |
| ---------- | ---------------------- |
| e-Filing   | CoreTax filing module  |
| e-Billing  | CoreTax payment module |
| e-Faktur   | CoreTax invoice module |
| e-SPT      | CoreTax returns module |

### Impact on Accounting Software

CoreTax introduces an API-based approach, meaning accounting software can potentially:

- Submit tax returns directly to DJP
- Retrieve taxpayer data automatically
- Validate e-Faktur in real-time
- Receive notifications about tax obligations

**Current status (2026):** CoreTax is being rolled out in phases. Jurnal.id and Accurate have announced API integration, but full functionality is still being finalized. Most PT PMA companies still use the legacy e-Faktur and e-Filing systems alongside CoreTax.

## Implementation Best Practices

### Phase 1: Setup (Week 1-2)

1. Input company information and tax details
2. Set up chart of accounts (follow SAK structure)
3. Configure tax rates (PPh 21, 23, PPN)
4. Connect bank accounts (where supported)
5. Set up users and permissions

### Phase 2: Opening Balances (Week 2-3)

1. Enter opening balance sheet from previous accounting records
2. Import customer and supplier lists
3. Enter outstanding invoices (AR and AP)
4. Set up fixed asset register

### Phase 3: Parallel Run (Month 1-2)

1. Run the new software alongside the old system
2. Compare monthly results
3. Resolve discrepancies
4. Train staff on new workflows

### Phase 4: Go Live

1. Switch fully to the new system
2. Continue reconciling monthly
3. Ensure tax filings match software reports
4. Set up regular backups

## Frequently Asked Questions

### Does the accounting software need to integrate with e-Faktur?

If your PT PMA is registered as PKP (VAT collector), e-Faktur integration is essential. Jurnal.id and Accurate both have direct e-Faktur integration that allows you to generate, manage, and report VAT invoices within the software. Without integration, you must manually export data to the DJP e-Faktur application, which is time-consuming and error-prone.

### Can I use international software like Xero or QuickBooks for a PT PMA?

Yes, but with limitations. Xero and QuickBooks can handle general bookkeeping in IDR but do not natively integrate with Indonesian tax systems (e-Faktur, CoreTax, PPh 21 calculator). You will need a separate process for tax compliance. Many PT PMA use Xero for management reporting and a local tool for tax filings.

### What is CoreTax and does my software need to support it?

CoreTax is DJP's new integrated tax administration system launched in phases from 2024-2026. It replaces the previous e-Filing, e-Billing, and e-Faktur systems with a single platform. Accounting software with CoreTax API integration can automatically submit tax returns and retrieve tax data. Jurnal.id and Accurate have announced CoreTax integration for 2026.
