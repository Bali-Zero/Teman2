### Calculateur de coûts

<Calculator
  title="Total Employment Cost"
  description="Estimate employer total cost"
  fields={[
    {
      id: "gross",
      label: "Gross Monthly Salary (IDR)",
      type: "number",
      defaultValue: 15000000,
      min: 0,
      step: 1000000,
      suffix: "IDR"
    },
    {
      id: "thr",
      label: "Include THR Provision",
      type: "select",
      options: [
        { value: "yes", label: "Yes" },
        { value: "no", label: "No" }
      ],
      defaultValue: "yes"
    }
  ]}
  calculateResult={(values) => {
    const gross = Number(values.gross);

    // BPJS employer contributions
    const bpjsKesehatan = gross * 0.04; // 4% health
    const bpjsJKK = gross * 0.0024; // 0.24% min work accident
    const bpjsJKM = gross * 0.003; // 0.3% death
    const bpjsJHT = gross * 0.037; // 3.7% pension fund
    const bpjsJP = gross * 0.02; // 2% pension

    const totalBPJS = bpjsKesehatan + bpjsJKK + bpjsJKM + bpjsJHT + bpjsJP;

    // THR provision (1 month spread over 12)
    const thrProvision = values.thr === "yes" ? gross / 12 : 0;

    const totalMonthly = gross + totalBPJS + thrProvision;

    return {
      total: Math.round(totalMonthly),
      breakdown: [
        { label: "Gross Salary", amount: gross },
        { label: "BPJS Kesehatan (4%)", amount: Math.round(bpjsKesehatan) },
        { label: "BPJS JKK (0.24%)", amount: Math.round(bpjsJKK) },
        { label: "BPJS JKM (0.3%)", amount: Math.round(bpjsJKM) },
        { label: "BPJS JHT (3.7%)", amount: Math.round(bpjsJHT) },
        { label: "BPJS JP (2%)", amount: Math.round(bpjsJP) },
        { label: "THR Provision", amount: Math.round(thrProvision) },
        { label: "Total Monthly Cost", amount: Math.round(totalMonthly) }
      ],
      currency: "IDR",
      note: `Employer BPJS: ~10.24% of salary`
    };

}}
/>

## Enregistrement BPJS

### BPJS Kesehatan (Santé)

<InfoCard variant="note" title="Health Insurance">
**Contributions :**
- Total : 5% du salaire
- Employeur : 4%
- Employé : 1%

**Plafond :** 12 millions IDR de salaire de base

**Couverture :**

- Employé
- Conjoint
- Jusqu'à 3 enfants
- Membres de la famille supplémentaires : +1% chacun
  </InfoCard>

### BPJS Ketenagakerjaan (Emploi)

| Programme                 | Employeur  | Employé | Total    |
| ------------------------- | ---------- | ------- | -------- |
| JKK (Accident du travail) | 0.24-1.74% | 0%      | Variable |
| JKM (Décès)               | 0.30%      | 0%      | 0.30%    |
| JHT (Fonds de pension)    | 3.70%      | 2%      | 5.70%    |
| JP (Pension)              | 2%         | 1%      | 3%       |

### Liste de contrôle du contrat

- Détails de l'employé et de l'employeur
- Titre et description du poste
- Lieu de travail
- Heures de travail
- Salaire et composantes
- Avantages
- Date de début (et date de fin pour PKWT)
- Conditions de probation (PKWTT uniquement)
- Dispositions de résiliation
- Signé par les deux parties

## Période d'essai

<InfoCard variant="warning" title="Probation Rules">
**Pour PKWTT (Permanent) uniquement :**
- Maximum 3 mois
- Doit être par écrit
- Salaire complet pendant la probation
- Peut résilier avec préavis pendant la probation
- Pas d'indemnité de départ si résilié pendant la probation

**Pour PKWT (Fixed-term) :**

- Probation NON autorisée
- Toute clause de probation est nulle
  </InfoCard>

## Considérations relatives à la paie

### Exigences de paiement

| Exigence      | Détail                       |
| ------------- | ---------------------------- |
| Fréquence     | Mensuelle (la plus courante) |
| Méthode       | Virement bancaire            |
| Devise        | IDR                          |
| Fiche de paie | Obligatoire                  |
| Déductions    | BPJS, PPh 21, prêts          |

### Retenue d'impôt (PPh 21)

L'employeur doit :

1. Calculer le PPh 21 mensuel
2. Retenir sur le salaire
3. Verser avant le 10 du mois suivant
4. Déclarer avant le 20 du mois suivant
5. Émettre un relevé fiscal annuel (1721-A1)

## Erreurs courantes

| Erreur                                        | Impact                           |
| --------------------------------------------- | -------------------------------- |
| Pas de contrat écrit                          | Par défaut, PKWTT                |
| Enregistrement BPJS tardif                    | Amendes et pénalités             |
| Utilisation de PKWT pour des rôles permanents | Le contrat devient PKWTT         |
| Probation en PKWT                             | La clause est nulle              |
| Ne pas collecter le NPWP                      | Problèmes de déclaration fiscale |
| Absence de retenue d'impôt                    | Responsabilité de l'employeur    |
