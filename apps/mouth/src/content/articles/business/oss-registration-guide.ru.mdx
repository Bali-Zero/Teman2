# Система OSS: Простая онлайн-регистрация бизнеса 2026

OSS (Online Single Submission) — это интегрированная онлайн-платформа Индонезии для всех регистраций и разрешений на ведение бизнеса. Это ваше универсальное решение для получения NIB, бизнес-лицензий и разрешений на эксплуатацию.

<InfoCard variant="warning" title="Обновление 2026 (Источник: oss.go.id)">
**PP 28/2025 - Новые правила лицензирования:**

Постановление правительства 28/2025 полностью внедрено в систему OSS-RBA с 2025 года:

1. **Расширенный риск-ориентированный подход** - Более детальная классификация рисков для KBLI codes
2. **Межведомственная интеграция** - Прямая связь с BKPM, Kemenkumham, DJP
3. **Сокращение сроков** - Цель более быстрой обработки для низкорисковых видов деятельности
4. **Цифровой LKPM** - Полностью онлайн-отчетность об инвестициях

**Важное примечание**: PP 28/2025 обновляет, но не полностью заменяет предыдущие правила. Некоторые специфические отраслевые процедуры все еще могут требовать отдельных согласований.

</InfoCard>

## Что такое OSS?

OSS заменила старую систему посещения нескольких государственных учреждений. Теперь практически все разрешения на ведение бизнеса проходят через эту единую платформу на **oss.go.id**.

### Эволюция OSS

| Версия      | Период               | Ключевые особенности                         |
| ----------- | -------------------- | -------------------------------------------- |
| OSS 1.0     | 2018-2020            | Первоначальный запуск                        |
| OSS 1.1     | 2020-2021            | Улучшения                                    |
| **OSS RBA** | 2021-Настоящее время | Риск-ориентированный подход, текущая система |

## Риск-ориентированный подход (RBA)

OSS использует риск-ориентированную систему для определения того, какие разрешения вам нужны:

<InfoCard variant="note" title="Как определяется риск">
Ваши **KBLI коды** определяют уровень риска:

- **Низкий риск**: Базовые виды деятельности (консалтинг, IT-услуги) - только NIB
- **Средне-низкий**: Требуется некоторое соответствие - NIB + Sertifikat Standar
- **Средне-высокий**: Требуется проверка - NIB + Sertifikat Standar + Инспекция
- **Высокий риск**: Полное лицензирование - NIB + Izin + Регулярные аудиты

Система автоматически классифицирует, когда вы выбираете свои KBLI коды.

</InfoCard>

1. **OSS 3.0** - Обсуждается возможная новая версия системы OSS с улучшенным интерфейсом и более быстрыми сроками обработки. Некоторые эксперты прогнозируют запуск в 2026-2027 годах. _Официальных объявлений нет._

2. **Международная интеграция** - Ведутся дискуссии о возможной интеграции с международными системами проверки личности для упрощения регистрации иностранных компаний. _Только спекуляции._

3. **Автоматический KBLI** - Обсуждается система автоматического подбора KBLI кодов на основе описания деятельности. _Находится на стадии изучения._

4. **Мобильное приложение OSS** - Некоторые считают, что будет запущено официальное мобильное приложение для управления разрешениями и отчетностью со смартфона. _Не подтверждено._
