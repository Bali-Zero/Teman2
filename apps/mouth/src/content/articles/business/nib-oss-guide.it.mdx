# Guida Completa al Sistema NIB & OSS dell'Indonesia 2026

NIB (Nomor Induk Berusaha) tramite OSS (Online Single Submission) è il portale per operare legalmente un'attività commerciale in Indonesia.

## Cos'è il NIB?

<InfoCard variant="note" title="Numero di Identificazione Aziendale">
**NIB (Nomor Induk Berusaha)** è:

- Il tuo numero di identificazione aziendale
- Identificatore unico a 13 cifre
- Sostituisce le vecchie licenze multiple
- Fondamento per tutti gli altri permessi
- Erogato istantaneamente tramite OSS

Il NIB funge da TDP (Registro Aziendale), API (ID Importatore) e accesso doganale in uno.

</InfoCard>

## Classificazione KBLI

<InfoCard variant="warning" title="Scegli con Cura">
**KBLI (Klasifikasi Baku Lapangan Usaha Indonesia)** è cruciale:

- Codici attività a 5 cifre
- Determina la classificazione del rischio
- Influenza i requisiti dei permessi
- Deve corrispondere all'attività reale
- Le modifiche richiedono integrazioni

Un KBLI errato può significare permessi sbagliati o violazioni DNI.

</InfoCard>

### Trovare i Codici KBLI

1. Cerca nel sistema OSS
2. Controlla la guida KBLI (pubblicazione del BPS)
3. Consulta con notaio/agente
4. Corrispondi al tuo piano aziendale

### Esempi Comuni di KBLI

| Attività             | Codice KBLI          |
| -------------------- | ------------------- |
| Ristorante           | 56101               |
| Sviluppo software    | 62012               |
| Commercio (generale) | 46900               |
| Consulenza           | 70201               |
| Hotel                | 55111               |
| Manifattura          | Varii 10xxx-33xxx  |

## Classificazione del Rischio

Dopo aver inserito i codici KBLI, l'OSS determina il livello di rischio:

### Livelli di Rischio

| Livello       | Requisiti                  | Elaborazione      |
| ----------- | -------------------------- | --------------- |
| Basso         | Solo NIB                   | Istantaneo         |
| Medio-Basso  | NIB + Certificato Standard | Auto-dichiarazione    |
| Medio-Alto   | NIB + Certificato Standard | Verifica          |
| Alto         | NIB + Permesso             | Valutazione completa |

### Cosa Determina il Rischio?

- Settore industriale
- Scala dell'attività
- Impatto ambientale
- Salute pubblica/sicurezza
- Considerazioni di sicurezza

## Dopo Aver Ottenuto il NIB

### Prossimi Passi Immediati

1. **Scarica il certificato NIB** - Salva PDF
2. **Controlla gli impegni** - Rivedi eventuali condizioni
3. **Richiedi permessi settoriali** - Se richiesti dal KBLI
4. **Completa l'impatto ambientale** - Se indicato nell'impegno
5. **Attiva funzioni di importazione** - Se necessario

### Obblighi Continuativi

- **Segnalazioni LKPM** - Rapporti sull'investimento trimestrali/semestrali
- **Aggiornamenti dati** - Quando cambiano le informazioni
- **Rinnovi licenze** - Prima della scadenza
- **Conformità** - Con tutte le condizioni dei permessi

---

## Problemi Comuni

### Problemi OSS

| Problema            | Soluzione                   |
| ---------------- | -------------------------- |
| AHU non sincronizzato   | Aspetta o contatta AHU        |
| KBLI non trovato   | Usa termini di ricerca corretti   |
| Indirizzo rifiutato | Controlla formato/coordinate   |
| Errore del sistema     | Prova un altro browser/orario |
| Dati non corrispondenti    | Assicurati che l'atto corrisponda all'inserimento  |

### Come Correggere gli Errori

<InfoCard variant="tip" title="Modifica del NIB">
Se hai commesso errori:

1. **Modifiche minori** - Aggiorna tramite OSS
2. **Modifiche KBLI** - Potrebbe essere necessaria prima la modifica dell'atto
3. **Cambio indirizzo** - Aggiorna con nuovo domicilio
4. **Cambio proprietà** - Richiede processo legale prima

Aggiorna sempre l'OSS quando cambiano i dati aziendali.

</InfoCard>
