## Правила франчайзинга

### Ключевые требования

<InfoCard variant="note" title="Государственная регистрация">
**Франшизы должны быть зарегистрированы:**

- STPW (Surat Tanda Pendaftaran Waralaba)
- Обязательно для франчайзера
- Зарегистрировать в течение 30 дней с момента начала работы
- Требуется продление

Работа без регистрации является незаконной.

</InfoCard>

### Нормативно-правовая база

| Регулирование        | Охватывает                       |
| :------------------- | :------------------------------- |
| Gov Reg 42/2007      | Определение франшизы, требования |
| Minister Reg 71/2019 | Процедуры регистрации            |
| Министр торговли     | Постоянный надзор                |

## Иностранные франшизы

### Привлечение иностранного бренда в Индонезию

<InfoCard variant="warning" title="Правила для иностранных франшиз">
**Требования к иностранным брендам:**

- Соглашение о мастер-франшизе
- Обычно требуется PT PMA
- Регистрация франшизы в Индонезии
- Может потребоваться местный партнер
- Требования к локализации
- Правила местного снабжения (80% для определенных товаров)

Иностранные франчайзеры должны адаптироваться к индонезийским правилам.

</InfoCard>

### Требования к местному содержанию

| Требование          | Детали                                     |
| :------------------ | :----------------------------------------- |
| Местные продукты    | 80% для определенных товаров F&B           |
| Местное партнерство | Может потребоваться для некоторых секторов |
| Местное управление  | Участие индонезийцев                       |
| Регистрация         | В Индонезии                                |
