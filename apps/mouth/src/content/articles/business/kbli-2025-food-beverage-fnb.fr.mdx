## L'essentiel, d'abord

Si vous ouvrez un restaurant, un café, un bar ou une entreprise de traiteur à Bali en tant qu'étranger, votre code KBLI détermine tout : votre niveau de risque, vos obligations en matière de licence, la possibilité de détenir 100 % de propriété étrangère, et le montant que le bureau des impôts s'attend à ce que vous gagniez. Selon le KBLI 2025, le secteur de l'alimentation et des boissons (F&B) couvre 10 codes distincts à cinq chiffres, chacun avec des exigences de conformité différentes. Choisissez le mauvais et vous ferez face à une classification de risque erronée, aux mauvaises licences et potentiellement à un audit raté. La date limite de conformité est le **18 juin 2026**.

Ce guide couvre chaque code F&B du KBLI 2025, les licences exactes requises pour chacun, les règles PMA (propriété étrangère), l'autorisation d'alcool, la certification d'hygiène et les règles de calcul des investissements qui prennent la plupart des opérateurs au dépourvu.

## Comprendre les codes : ce que chacun couvre réellement

### 56101 — Restoran (Restaurant)

C'est le code principal pour la plupart des établissements F&B à capitaux étrangers à Bali. Il couvre les restaurants formels avec service à table, places assises et un menu fixe. La classification de risque est **Rendah (Faible)**, ce qui signifie que l'obtention de la licence est la voie la plus simple disponible. La propriété étrangère via PT PMA est autorisée à 100 %.

Si vous ouvrez un restaurant avec service à table — qu'il s'agisse d'un grill de fruits de mer en bord de mer à Jimbaran, d'un établissement de haute cuisine à Seminyak ou d'un restaurant décontracté à Canggu — c'est presque certainement votre code.

### 56103 — Kedai Makanan (Étal de nourriture)

C'est là que de nombreux opérateurs commettent leur première erreur. Un kedai makanan est un établissement de restauration de plus petit format — pensez aux étals de style colporteur, aux petits restaurants de type "shop-house" ou aux comptoirs de service. Bien que de plus petite envergure, ce code est classé comme risque **Sedang (Moyen)**. Cela implique une conformité supplémentaire : vous aurez besoin de la certification LSPr en plus des exigences d'hygiène standard.

Pour les investisseurs étrangers, le 56103 permet toujours une propriété PMA à 100 %, mais la classification de risque moyen fait du 56101 un meilleur choix pour la plupart des concepts de restaurants formels. Si votre établissement dispose de places assises appropriées, d'une cuisine et d'un service à table, utilisez plutôt le 56101.

### 56109 — Autres restaurants et services de restauration mobile

C'est le code fourre-tout pour les concepts F&B qui ne rentrent pas parfaitement dans les codes 56101 ou 56103. Il couvre :

- **Aires de restauration** — Salles à manger multi-vendeurs
- **Food trucks** — Opérations de restauration mobile
- **Boulangeries avec service de restauration sur place** — Hybrides boulangerie-café
- **Autres formats de restaurants** — Restaurants éphémères, cuisines fantômes avec service de ramassage

La classification de risque est **Rendah (Faible)** et 100 % PMA est autorisé. Si vous lancez une opération de food truck ou un concept d'aire de restauration à Bali, c'est votre code.

### 56210 — Event Catering (Jasa Boga Untuk Suatu Event Tertentu)

Le service de traiteur événementiel — mariages, fonctions d'entreprise, fêtes privées — relève du code 56210. Le niveau de risque est **Sedang (Moyen)**, ce qui déclenche des exigences de licence supplémentaires, y compris la certification LSPr.

**Restriction PMA critique :** Les opérations de traiteur événementiel à petite échelle ne sont **pas ouvertes à l'investissement étranger**. Cela signifie que votre PT PMA doit atteindre le seuil d'investissement complet. Si vous prévoyez une entreprise de traiteur boutique avec un faible capital, ce code pourrait bloquer votre structure de propriété étrangère. Consultez un spécialiste des licences avant de vous enregistrer.

### 56290 — Traiteur basé sur une période

Ce code couvre les contrats de traiteur continus — fourniture de repas pour des bureaux, des usines, des internats ou des clients institutionnels sur une période définie. Contrairement au traiteur événementiel (56210), le traiteur basé sur une période est classé comme risque **Rendah (Faible)** et est ouvert à 100 % PMA.

Si votre modèle commercial est la fourniture de repas B2B plutôt que le traiteur événementiel, le 56290 est la classification correcte et offre un chemin de conformité nettement plus facile.

### 56301 — Bar

Le code 56301 couvre les bars en tant qu'établissements autonomes. Cependant, ce code comporte une note de classification : vérifiez le niveau de risque exact et le statut PMA dans le système OSS actuel, car les sources de données montrent des incohérences dans la façon dont le 56301 est catégorisé par rapport au 56302. Si vous ouvrez un bar, recoupez les informations des codes 56301 et 56302 avec votre consultant en licences avant de choisir.

### 56302 — Nightclub / Disco (Servant principalement des boissons)

Les boîtes de nuit et discothèques qui servent principalement des boissons plutôt que de la nourriture relèvent du code 56302. Malgré la nature très axée sur le divertissement de l'entreprise, ce code est classé comme risque **Rendah (Faible)** et autorise 100 % de propriété étrangère.

Le problème n'est pas le code KBLI lui-même — c'est la **licence d'alcool**. Opérer sous le code 56302 sans NPBBKC (Nomer Pokok Pengusaha Barang Kena Cukai) est illégal. Plus d'informations à ce sujet dans la section sur les licences d'alcool ci-dessous.

### 56303 — Rumah Minum/Kafe (Café / Salon de thé)

Le code des cafés et salons de thé. Il couvre tout, des cafés spécialisés aux bars à jus en passant par les salons de thé. La classification de risque est **Rendah (Faible)** avec 100 % PMA autorisé.

Pour les nombreux cafés à capitaux étrangers à Canggu, Ubud et Seminyak, c'est le code correct. N'enregistrez pas un café sous le code 56101 (Restaurant) — les codes comportent des références fiscales différentes, et le système Coretax de la DGT compare vos marges déclarées aux normes de l'industrie pour votre code KBLI spécifique.

### 56305 — Rumah/Kedai Obat Tradisional (Boutique de médecine traditionnelle)

Un code de niche mais pertinent pour l'économie du bien-être de Bali. Il couvre les magasins vendant des médicaments à base de plantes traditionnelles (jamu) et des produits similaires. Le risque est **Rendah (Faible)** et 100 % PMA est autorisé, bien que des permis supplémentaires liés à la santé et aux produits spécifiques s'appliquent au-delà des exigences F&B standard.

### 56702 — Warung (Restaurant local)

Le warung — le restaurant local omniprésent en Indonésie — a son propre code dédié. Le risque est **Rendah (Faible)** et, peut-être étonnamment, 100 % PMA est techniquement autorisé. En pratique, le seuil d'investissement minimum de 10 milliards IDR pour les PT PMA rend les warungs à capitaux étrangers rares. La plupart des opérateurs étrangers qui souhaitent un concept de restauration décontractée utilisent plutôt le 56101 et construisent un établissement plus formel.

## Licence d'alcool : l'exigence NPBBKC

Si votre entreprise sert de l'alcool — qu'il s'agisse d'un bar (56301/56302), d'une boîte de nuit (56302), d'un restaurant avec un menu de cocktails (56101), ou même d'un café avec de la bière pression (56303) — vous devez comprendre le cadre de licence NPBBKC.

### Qu'est-ce que le NPBBKC ?

NPBBKC signifie **Nomer Pokok Pengusaha Barang Kena Cukai** — le numéro d'enregistrement commercial des produits soumis à accise. C'est la licence légale requise pour distribuer et vendre des boissons alcoolisées en Indonésie. Sans elle, la vente d'alcool est une infraction pénale, pas seulement une violation administrative.

### Catégories d'alcool

La loi indonésienne classe les boissons alcoolisées en trois catégories :

- **Catégorie A** — Jusqu'à 5 % d'alcool (bière, cidre, cocktails légers)
- **Catégorie B** — 5 % à 20 % d'alcool (vin, saké, liqueurs)
- **Catégorie C** — Au-dessus de 20 % d'alcool (spiritueux, vodka, whisky, rhum)

La plupart des bars et boîtes de nuit ont besoin des trois catégories. Un restaurant qui ne sert que de la bière et du vin pourrait s'en sortir avec les catégories A et B, mais cela limite la flexibilité de votre menu.

### NPBBKC via Bali Zero

L'obtention d'un NPBBKC de manière indépendante implique de naviguer entre les douanes et accises (Bea Cukai), les approbations du gouvernement local et la documentation de conformité. Bali Zero fournit une licence NPBBKC complète couvrant les **catégories A, B et C** pour **15 000 000 IDR**.

Cela couvre le processus complet de demande, la documentation et la liaison avec Bea Cukai. Le délai est généralement de 4 à 8 semaines selon la charge de travail du bureau local.

### Qui a besoin du NPBBKC ?

| Type d'entreprise                      | NPBBKC requis ?       | Notes                                                    |

| Bar (56301/56302)                      | **Oui — obligatoire** | Ne peut pas fonctionner légalement sans                  |
| Boîte de nuit (56302)                  | **Oui — obligatoire** | Les trois catégories sont généralement nécessaires       |
| Restaurant avec alcool (56101)         | **Oui**               | Même si l'alcool représente une part mineure des revenus |

| Traiteur avec service d'alcool (56210) | **Oui**               | Licence par événement ou permanente                      |
| Warung (56702)                         | Rarement              | La plupart des warungs ne servent pas d'alcool           |

## Licences d'hygiène et de santé : HSP, SLHS et Halal

Toute entreprise F&B en Indonésie — quel que soit le code KBLI — doit respecter les normes d'hygiène et de santé. Le KBLI 2025 ne modifie pas les exigences d'hygiène en elles-mêmes, mais le niveau de risque de votre code détermine la manière dont les exigences sont appliquées.

### Label Higiene Sanitasi Pangan (HSP)

Le HSP est le label d'hygiène sanitaire de base requis pour toutes les entreprises de services alimentaires. Il certifie que vos locaux, vos processus de manipulation des aliments et l'hygiène de votre personnel respectent les normes minimales établies par le ministère de la Santé.

**Qui en a besoin :** Toute entreprise F&B relevant de la Division 56.

### Sertifikat Laik Sehat (SLHS)

Le SLHS — Certificat d'aptitude sanitaire — est la certification formelle attestant que votre établissement a réussi une inspection sanitaire. Il est délivré par le bureau de santé local (Dinas Kesehatan) après une inspection sur place couvrant :

- Les zones de cuisine et de préparation des aliments
- L'approvisionnement en eau et l'élimination des déchets
- Les certificats de santé du personnel (Surat Keterangan Sehat)
- Le stockage des aliments et la conformité de la chaîne du froid
- Les mesures de lutte antiparasitaire

Bali Zero offre une assistance pour la certification SLHS pour **9 000 000 IDR**, ce qui comprend la préparation avant l'inspection, la documentation et la coordination avec Dinas Kesehatan.

### Dokumen Penilaian Mandiri (Document d'auto-évaluation)

Les entreprises F&B à risque moyen (56103 et 56210) sont tenues de soumettre un document d'auto-évaluation via OSS dans le cadre de leur processus de licence. Ce document détaille vos protocoles d'hygiène, la formation du personnel et le système de gestion de la sécurité alimentaire. Les entreprises à faible risque (56101, 56109, 56290, 56302, 56303, 56305, 56702) sont exemptées de l'auto-évaluation mais ont toujours besoin du HSP et du SLHS.

### Certification Halal

Depuis octobre 2024, la loi indonésienne sur la certification halal (UU JPH) exige que tous les produits alimentaires — y compris les repas de restaurant — portent une déclaration Halal ou Non-Halal. Pour les restaurants de Bali servant du porc ou de l'alcool, l'enregistrement en tant que **Non-Halal** est la voie conforme.

Les coûts de certification Halal varient de **5 000 000 IDR à 8 000 000 IDR** selon la complexité du menu et l'organisme de certification utilisé. Pour la plupart des entreprises F&B basées à Bali servant une cuisine internationale, la déclaration Non-Halal est plus simple et plus rapide.

### PIRT (Enregistrement des aliments de l'industrie artisanale)

Si vous produisez des produits alimentaires emballés (sauces, snacks, produits de boulangerie) pour la vente au détail plutôt que de servir des repas préparés, vous pourriez avoir besoin d'un enregistrement PIRT. Cela couvre la production alimentaire artisanale à petite échelle et coûte **500 000 IDR à 1 000 000 IDR**. Notez que le PIRT est distinct de la licence de restaurant — il s'applique aux produits alimentaires, pas aux services de restauration.

## Règles d'investissement : le calcul par Kabupaten

C'est la règle qui déroute la plupart des opérateurs de chaînes F&B à Bali. Selon le KBLI 2025, l'investissement minimum pour une PT PMA est calculé **par Kabupaten/Kota (régence/ville)**, et non par point de vente ni à l'échelle de l'île.

### Comment ça marche

Une PT PMA exploitant des entreprises F&B doit maintenir un investissement minimum de **10 milliards IDR** (environ 625 000 USD) par Kabupaten/Kota où elle opère. Voici comment cela se déroule en pratique :

**Scénario 1 : Une seule régence, plusieurs points de vente**
Vous ouvrez trois cafés dans la régence de Badung (Seminyak, Canggu, Kuta). Votre investissement global pour ces trois points de vente doit dépasser 10 milliards IDR. Vous n'avez pas besoin de 10 milliards IDR par magasin — seulement 10 milliards IDR au total pour Badung.

**Scénario 2 : Expansion vers une nouvelle régence**
Les affaires vont bien, et vous souhaitez ouvrir un quatrième emplacement dans la ville de Denpasar (un Kabupaten/Kota distinct de Badung). Cela déclenche un **nouveau seuil de 10 milliards IDR** pour Denpasar. Votre engagement d'investissement total est désormais de 20 milliards IDR sur deux juridictions.

**Scénario 3 : Chaîne à l'échelle de Bali**
Bali compte 9 Kabupaten/Kota. Une chaîne présente dans les neuf aurait théoriquement besoin d'un engagement d'investissement total de 90 milliards IDR. En pratique, la plupart des chaînes se développent progressivement, saturant une régence avant de passer à la suivante.

### Implications stratégiques

Cette règle encourage la **densité plutôt que la dispersion**. Pour une chaîne de cafés à capitaux étrangers, il est plus efficace en termes de capital d'ouvrir cinq emplacements à Badung (un seul seuil) que d'ouvrir un emplacement dans cinq régences différentes (cinq seuils). Planifiez votre géographie d'expansion avant d'enregistrer votre NIB, car la régence que vous sélectionnez dans OSS verrouille votre juridiction d'investissement initiale.

## Erreurs courantes : Mauvais code, mauvaises conséquences

### Erreur 1 : Enregistrer un café comme un restaurant (56101 au lieu de 56303)

Un café et un restaurant sont des codes KBLI différents avec des références fiscales différentes. Le système Coretax de la DGT compare vos marges bénéficiaires déclarées à la fourchette attendue pour votre code KBLI. Un café déclarant des coûts alimentaires de niveau restaurant (plus élevés) ou un restaurant déclarant des marges de niveau café (plus faibles) déclenche des alertes d'audit automatisées. Utilisez le code qui correspond à votre modèle commercial réel.

### Erreur 2 : Utiliser le code 56103 (Étal de nourriture) alors que le code 56101 (Restaurant) s'applique

Si votre établissement dispose de places assises formelles, d'une cuisine complète et d'un service à table, il s'agit d'un restaurant (56101, faible risque), et non d'un étal de nourriture (56103, risque moyen). Choisir le 56103 vous soumet inutilement à des exigences de conformité de risque moyen, y compris la certification LSPr et la documentation d'auto-évaluation. Il n'y a aucun avantage à s'enregistrer sous une classification de risque plus élevée.

### Erreur 3 : Ignorer la licence d'alcool

De nombreux restaurants ajoutent des cocktails ou du vin à leur menu après l'ouverture, oubliant que tout service d'alcool nécessite un NPBBKC. Opérer sans cette licence n'est pas une zone grise — c'est une violation de la loi sur les accises. Demandez le NPBBKC avant que votre première boisson ne soit servie, pas après.

### Erreur 4 : Choisir le traiteur événementiel (56210) pour une entreprise de préparation de repas

Si vous fournissez des boîtes repas quotidiennes à des bureaux ou des espaces de coworking, vous gérez un service de traiteur basé sur une période (56290, faible risque), et non un traiteur événementiel (56210, risque moyen, PMA restreint pour les petites entreprises). Une classification erronée pourrait bloquer entièrement votre structure de propriété étrangère.

### Erreur 5 : Oublier la déclaration Halal/Non-Halal

Depuis octobre 2024, ce n'est plus facultatif. Toute entreprise de services alimentaires doit faire une déclaration. Pour les entreprises basées à Bali servant du porc, de l'alcool ou une cuisine non halal, enregistrez-vous comme Non-Halal. Ne pas déclarer l'un ou l'autre est une lacune de conformité que les régulateurs appliquent de plus en plus.

## Niveaux de risque et ce qu'ils signifient pour les licences

Le KBLI 2025 attribue à chaque code d'entreprise un niveau de risque qui détermine directement votre parcours de licence via OSS :

**Rendah (Faible risque) :** Vous recevez votre NIB et pouvez opérer immédiatement. Aucune certification ou inspection supplémentaire n'est requise avant l'ouverture, bien que vous deviez maintenir la conformité HSP et SLHS. Codes : 56101, 56109, 56290, 56302, 56303, 56305, 56702.

**Sedang (Risque moyen) :** Vous recevez votre NIB mais devez également remplir un document d'auto-évaluation (Dokumen Penilaian Mandiri) et obtenir la certification LSPr avant d'opérer. Le délai d'obtention de la licence est plus long, et des inspections peuvent avoir lieu avant votre ouverture. Codes : 56103, 56210.

La différence pratique est de 2 à 4 semaines de temps de traitement supplémentaire et de 3 à 5 millions IDR de coûts de certification supplémentaires pour les codes à risque moyen. C'est pourquoi le choix du code est important — une classification erronée vous coûte du temps et de l'argent avant de servir votre premier client.

## La date limite de juin 2026 : ce que vous devez faire

Le règlement n° 7 de 2025 du BPS exige que toutes les entreprises migrent vers la classification KBLI 2025 d'ici le **18 juin 2026**. Pour les entreprises F&B, cela signifie :

1.  **Auditer votre NIB actuel** — Vérifiez quel code KBLI est enregistré sur votre licence commerciale
2.  **Mapper vers le KBLI 2025** — Identifiez si votre code a changé, a été divisé ou reclassifié
3.  **Vérifier le niveau de risque** — Confirmez si votre nouveau code porte la même classification de risque
4.  **Vérifier le statut PMA** — Assurez-vous que votre code autorise toujours votre structure de propriété
5.  **Mettre à jour via OSS** — Soumettez le changement de code via le système Online Single Submission
6.  **Préparer Coretax** — Votre nouveau code détermine les références de marge bénéficiaire que la DGT utilisera

N'attendez pas juin. Le système OSS connaîtra probablement un trafic élevé à l'approche de la date limite, et les délais de traitement pour les codes à risque moyen peuvent s'étendre à 4-6 semaines.

## Points clés à retenir

- **La plupart des restaurants à capitaux étrangers devraient utiliser le code 56101** (Restoran) — faible risque, 100 % PMA, chemin de licence le plus simple
- **Les cafés sont 56303, pas 56101** — code différent, références fiscales différentes, même classification à faible risque
- **Les bars et boîtes de nuit ont besoin du NPBBKC** — pas d'exceptions, pas de période de grâce
- **Le traiteur événementiel (56210) restreint le PMA à petite échelle** — envisagez le 56290 (basé sur une période) si votre modèle le permet
- **L'investissement est par Kabupaten/Kota** — planifiez votre géographie d'expansion avant de vous enregistrer
- **La date limite est le 18 juin 2026** — auditez votre code KBLI maintenant, pas en mai
- **Toute entreprise F&B a besoin de HSP et SLHS** — la conformité en matière d'hygiène est non négociable quel que soit le niveau de risque
