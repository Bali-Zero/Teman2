## Пять обязательных финансовых отчетов

Индонезийские стандарты бухгалтерского учета требуют от компаний PT PMA подготавливать полный комплект из пяти финансовых отчетов в конце каждого финансового года. Эти отчеты рассказывают о финансовом состоянии вашей компании и используются налоговыми органами, банками, инвесторами и регулирующими органами.

| Отчет                             | Название на индонезийском                           | Назначение                                   |
| :-------------------------------- | :-------------------------------------------------- | :------------------------------------------- |
| Бухгалтерский баланс              | Laporan Posisi Keuangan                             | Снимок активов, обязательств и капитала      |
| Отчет о прибылях и убытках        | Laporan Laba Rugi dan Penghasilan Komprehensif Lain | Доходы, расходы и чистая прибыль             |
| Отчет о движении денежных средств | Laporan Arus Kas                                    | Притоки и оттоки денежных средств            |
| Отчет об изменениях в капитале    | Laporan Perubahan Ekuitas                           | Движение капитала и нераспределенной прибыли |
| Примечания                        | Catatan Atas Laporan Keuangan                       | Пояснения и учетная политика                 |

## Отчет 1: Бухгалтерский баланс (Laporan Posisi Keuangan)

Бухгалтерский баланс показывает, чем владеет ваша компания, что она должна и какова ее стоимость на определенный момент времени (обычно 31 декабря).

### Структура

**Активы (Aset)**

| Категория                               | Подкатегории                    | Примеры                                                               |
| :-------------------------------------- | :------------------------------ | :-------------------------------------------------------------------- |
| Оборотные активы (Aset Lancar)          | Денежные средства и эквиваленты | Банковские счета, мелкие наличные                                     |
|                                         | Дебиторская задолженность       | Неоплаченные счета клиентов                                           |
|                                         | Запасы                          | Сырье, готовая продукция                                              |
|                                         | Предоплаченные расходы          | Аренда, оплаченная авансом, страховка                                 |
|                                         | Налоговые авансы                | Платежи PPh 25, входящий НДС                                          |
| Внеоборотные активы (Aset Tidak Lancar) | Основные средства (нетто)       | Оборудование, транспортные средства, улучшения арендованных помещений |
|                                         | Нематериальные активы           | Лицензии на программное обеспечение, товарные знаки                   |
|                                         | Инвестиционная недвижимость     | Сдаваемая в аренду недвижимость                                       |
|                                         | Долгосрочные депозиты           | Депозиты обеспечения                                                  |

**Обязательства (Kewajiban)**

| Категория                                      | Подкатегории                       | Примеры                                          |
| :--------------------------------------------- | :--------------------------------- | :----------------------------------------------- |
| Краткосрочные обязательства (Kewajiban Lancar) | Кредиторская задолженность         | Неоплаченные счета поставщиков                   |
|                                                | Налоговые обязательства            | Подлежащие уплате PPh 21, 23, 25, PPN            |
|                                                | Подлежащие уплате BPJS             | Kesehatan и Ketenagakerjaan                      |
|                                                | Начисленные расходы                | Зарплата, коммунальные услуги, проценты          |
|                                                | Краткосрочные займы                | Банковский овердрафт, кредитные линии            |
| Долгосрочные обязательства                     | Долгосрочные займы                 | Банковские кредиты, займы акционеров             |
|                                                | Отложенные налоговые обязательства | Временные разницы                                |
|                                                | Выплаты сотрудникам                | Обязательства по выплатам после выхода на пенсию |

**Капитал (Ekuitas)**

| Компонент                         | Описание                                            |
| :-------------------------------- | :-------------------------------------------------- |
| Уставный капитал                  | Общий капитал согласно учредительному акту компании |
| Оплаченный капитал                | Фактически внесенный капитал                        |
| Дополнительный оплаченный капитал | Премия сверх номинальной стоимости                  |
| Нераспределенная прибыль          | Накопленная нераспределенная прибыль                |
| Прибыль/убыток текущего года      | Чистая прибыль за год                               |

**Уравнение бухгалтерского баланса всегда должно выполняться:** Активы = Обязательства + Капитал

## Отчет 2: Отчет о прибылях и убытках (Laporan Laba Rugi)

Отчет о прибылях и убытках показывает доходы, расходы и чистую прибыль вашей компании за финансовый год.

```
  Direct Costs                              (IDR xxx)
  Gross Profit (Laba Kotor)                  IDR xxx

Operating Expenses (Beban Operasional)
  Salaries & Benefits                       (IDR xxx)
  Rent                                      (IDR xxx)
  Utilities                                 (IDR xxx)
  Depreciation & Amortization              (IDR xxx)
  Marketing & Advertising                   (IDR xxx)
  Professional Fees                         (IDR xxx)
  Office Supplies                           (IDR xxx)
  Insurance                                 (IDR xxx)
  Travel & Transportation                   (IDR xxx)
  Other Operating Expenses                  (IDR xxx)
  Total Operating Expenses                  (IDR xxx)

  Interest Income                            IDR xxx

  Income Tax Expense                        (IDR xxx)

```

### Основные соображения

**Признание выручки:** Выручка признается, когда услуга оказана или товары переданы клиенту, а не когда получена оплата (метод начисления).

**Вычитаемость расходов:** Не все расходы в коммерческом отчете о прибылях и убытках подлежат вычету для целей налогообложения. Фискальная сверка корректирует следующие пункты:

- Представительские расходы (требуется подробный список/nominatif)
- Пожертвования (ограниченная вычитаемость)
- Различия в амортизации (коммерческие против фискальных ставок)
- Штрафы и пени (не вычитаются)
- Выплаты сотрудникам, не соответствующие налоговым критериям

## Отчет 3: Отчет о движении денежных средств (Laporan Arus Kas)

Отчет о движении денежных средств показывает фактическое движение денежных средств, разделенное на три вида деятельности:

### Операционная деятельность

Денежные потоки от обычной хозяйственной деятельности:

- Денежные средства, полученные от клиентов
- Денежные средства, выплаченные поставщикам и сотрудникам
- Налоговые платежи
- Уплаченные и полученные проценты

### Инвестиционная деятельность

Денежные потоки от покупки/продажи долгосрочных активов:

- Покупка оборудования или недвижимости
- Поступления от продажи активов
- Инвестиции в дочерние компании или ценные бумаги

### Финансовая деятельность

Денежные потоки от операций с капиталом и долгом:

- Вливание капитала от акционеров
- Поступления и погашения займов
- Выплата дивидендов

### Методы

PT PMA может использовать любой из следующих методов:

- **Прямой метод:** Перечисляет фактические поступления и выплаты денежных средств (предпочтительно DJP)
- **Косвенный метод:** Начинается с чистой прибыли и корректируется на неденежные статьи

## Отчет 5: Примечания к финансовой отчетности

Примечания предоставляют важный контекст и фактически являются самой большой частью финансовой отчетности. Они должны включать:

### Обязательные раскрытия

1.  **Обзор компании:** Название, организационно-правовая форма, дата учреждения, виды деятельности
2.  **Учетная политика:** Краткое изложение основных используемых методов бухгалтерского учета
3.  **Политика признания выручки:** Как признается выручка
4.  **Политика в отношении основных средств:** Методы амортизации и сроки полезного использования
5.  **Политика в отношении иностранной валюты:** Порядок учета обменного курса
6.  **Налоговая сверка:** Сверка коммерческой и фискальной прибыли
7.  **Операции со связанными сторонами:** Операции с акционерами, директорами, аффилированными лицами
8.  **Условные обязательства:** Незавершенные судебные процессы, налоговые споры, гарантии
9.  **События после отчетной даты:** Значительные события после окончания года
10. **Оценка непрерывности деятельности:** Если применимо

## Коммерческая против фискальной финансовой отчетности

### Почему два комплекта?

Налоговое законодательство Индонезии отличается от стандартов бухгалтерского учета SAK в нескольких областях. PT PMA должна подготовить:

1.  **Коммерческая финансовая отчетность:** Следует стандартам SAK/PSAK для бизнес-отчетности
2.  **Фискальная финансовая отчетность:** Скорректирована для соответствия налоговому законодательству

### Ключевые различия

| Пункт                                       | Коммерческий (SAK)                            | Фискальный (Налоговый)                      |
| :------------------------------------------ | :-------------------------------------------- | :------------------------------------------ |
| Амортизация – Здания                        | Гибкая (оценка срока полезного использования) | 5% в год (20 лет)                           |
| Амортизация – Транспортные средства         | Гибкая                                        | 12,5% в год (8 лет)                         |
| Амортизация – Оборудование                  | Гибкая                                        | 25% в год (4 года)                          |
| Представительские расходы                   | Полностью отнесены на расходы                 | Необходимо предоставить nominatif список    |
| Выплаты сотрудникам                         | Начисляются при возникновении обязательства   | Вычитаются при оплате                       |
| Резервы по сомнительным долгам              | На основе оценки                              | Требуются конкретные критерии               |
| Пожертвования                               | Отнесены на расходы                           | Ограниченная вычитаемость                   |
| Штрафы и пени                               | Отнесены на расходы                           | Не вычитаются                               |
| Служебный автомобиль (личное использование) | Полная амортизация                            | 50% амортизации + 50% операционных расходов |

### Пример фискальной сверки

```
Commercial Profit Before Tax           IDR 500,000,000

Positive Adjustments (add back):
  Entertainment without nominative list  IDR  20,000,000
  Depreciation difference                IDR  15,000,000
  Employee benefits (not yet paid)       IDR  10,000,000
  Penalties and fines                    IDR   5,000,000
  Subtotal                               IDR  50,000,000

Negative Adjustments (deduct):
  Tax depreciation excess               (IDR   8,000,000)
  Subtotal                              (IDR   8,000,000)

Fiscal Profit Before Tax                IDR 542,000,000
Corporate Tax (22%)                     IDR 119,240,000
```

| :------------------------------ | :---------------------------------------------------------------- |
| Срок подачи                     | 30 апреля следующего года                                         |

### Отчетность LKPM

Финансовые данные также должны ежеквартально сообщаться через LKPM:

- Показатели выручки и производства
- Реализация капитала
- Данные о занятости
- Статус инвестиций

### RUPS (Ежегодное собрание акционеров)

Финансовая отчетность должна быть представлена и утверждена акционерами на ежегодном RUPS в течение 6 месяцев после окончания финансового года (к 30 июня для компаний с календарным годом).

## Распространенные ошибки при подготовке финансовой отчетности

### Ошибка 1: Непоследовательная учетная политика

Изменение методов амортизации или политики признания выручки между годами без раскрытия информации создает проблемы для аудита и налоговые вопросы.

### Ошибка 2: Отсутствие раскрытия информации о сделках со связанными сторонами

Операции с акционерами, директорами или аффилированными компаниями должны быть раскрыты в примечаниях. DJP уделяет особое внимание трансфертному ценообразованию между связанными сторонами.

### Ошибка 3: Неправильный учет иностранной валюты

Все остатки в иностранной валюте должны быть пересчитаны по среднему курсу BI на 31 декабря. Нереализованные курсовые прибыли/убытки должны быть признаны. Многие компании забывают пересчитать дебиторскую/кредиторскую задолженность в USD на конец года.

### Ошибка 4: Несогласованность налоговых счетов

Остатки налоговых обязательств в бухгалтерском балансе должны соответствовать фактическим налоговым обязательствам. Распространенной ошибкой является наличие предоплаченных сумм PPh 25, которые не согласуются с фактическими платежами.

### Ошибка 5: Пропуск обязательств по выплатам сотрудникам

В соответствии с PSAK 24 (выплаты сотрудникам) компании должны рассчитывать и раскрывать обязательства по выплатам после выхода на пенсию. Даже если расчет несущественен, раскрытие информации требуется.

## Часто задаваемые вопросы

### Когда сдается финансовая отчетность PT PMA?

Годовая финансовая отчетность должна быть подготовлена к концу первого квартала (31 марта) за предыдущий финансовый год. Она подается в DJP в составе SPT Tahunan PPh Badan (корпоративной налоговой декларации) до 30 апреля. Компании, подлежащие аудиту, должны иметь аудированную отчетность к сроку RUPS (в течение 6 месяцев после окончания финансового года, т.е. к 30 июня).

### Должна ли PT PMA использовать полные PSAK или может применять упрощенные стандарты?

Большинство частных компаний PT PMA могут использовать SAK ETAP (упрощенные стандарты для организаций, не имеющих публичной ответственности). Полные PSAK требуются только для публично торгуемых компаний, финансовых учреждений и компаний, планирующих выйти на биржу. SAK EMKM доступен для микро/малых предприятий, но редко применяется к PT PMA из-за их минимальных требований к капиталу.

### В чем разница между коммерческой и фискальной финансовой отчетностью?

Коммерческая финансовая отчетность соответствует стандартам бухгалтерского учета SAK/PSAK для точной бизнес-отчетности. Фискальная финансовая отчетность — это скорректированные версии, соответствующие налоговому законодательству Индонезии, которое имеет различные правила для ставок амортизации, допустимых вычетов и признания выручки. PT PMA должна подготовить обе версии и включить фискальную сверку в налоговую декларацию.
