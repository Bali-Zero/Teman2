# NIB Spiegato: Il Tuo Numero di Identificazione Aziendale Indonesiano 2026

Il NIB (Nomor Induk Berusaha) è la pietra angolare della registrazione aziendale in Indonesia. Pensalo come la carta d'identità della tua azienda, richiesta per praticamente tutto.

## Cosa Sostituisce il NIB

Il NIB ha consolidato diverse licenze precedentemente separate:

| Vecchia Licenza          | Funzione                | Ora Parte del NIB |
| ------------------------ | ----------------------- | ----------------- |
| **TDP**                  | Registrazione aziendale | ✓ Sostituita      |
| **API-U**                | ID importatore generale | ✓ Sostituita      |
| **Angka Pengenal Impor** | Numero di importazione  | ✓ Sostituita      |
| **Accesso alle dogane**  | Sdoganamento            | ✓ Incluso         |

<InfoCard variant="tip" title="Un Numero, Molte Funzioni">
  Il NIB semplifica la registrazione aziendale. Invece di ottenere licenze separate, ottieni un NIB
  che serve a molteplici scopi. Questo è stato un miglioramento significativo rispetto al sistema
  precedente al 2018.
</InfoCard>

## NIB e Classificazione del Rischio

Nell’ambito di OSS RBA (Risk-Based Approach), il tuo NIB determina quali permessi aggiuntivi ti servono:

| Livello di Rischio | NIB + Cosa Altro?                   |
| ------------------ | ----------------------------------- |
| **Basso Rischio**  | NIB solo                            |
| **Basso-Medio**    | NIB + Sertifikat Standar            |
| **Alto-Medio**     | NIB + Sertifikat Standar + Verifica |
| **Alto Rischio**   | NIB + Full Izin (Licenza)           |

<InfoCard variant="note" title="Rischio Determinato dai KBLI">
  Il livello di rischio è determinato dai codici di attività commerciale (KBLI). La consulenza
  tecnologica è solitamente a basso-medio rischio. La produzione alimentare è a rischio più elevato.
  Il sistema OSS classifica automaticamente in base alla selezione dei tuoi codici KBLI.
</InfoCard>
