# NIB Spiegato: Il Tuo Numero di Identificazione Aziendale Indonesiano 2026

Il NIB (Nomor Induk Berusaha) è il pilastro della registrazione aziendale in Indonesia. Pensalo come la carta d'identità nazionale della tua azienda—necessario per quasi tutto.

## Cosa Sostituisce il NIB

Il NIB ha consolidato diverse licenze precedentemente separate:

| Licenza Precedente          | Funzione                  | Ora Parte di NIB |
| --------------------------- | ------------------------- | ----------------- |
| **TDP**                     | Registrazione aziendale   | ✓ Sostituito      |
| **API-U**                   | ID importatore generale   | ✓ Sostituito      |
| **Angka Pengenal Impor**    | Numero di importazione    | ✓ Sostituito      |
| **Accesso al dogana**       | Doganale per l'import     | ✓ Incluso         |

<InfoCard variant="tip" title="Un Numero, Molte Funzioni">

Il NIB semplifica la registrazione aziendale. Invece di ottenere più licenze separate, ottieni un unico NIB che serve a molteplici scopi. Questo è stato un grande miglioramento rispetto al sistema pre-2018.

</InfoCard>

## NIB e Classificazione dei Rischi

Secondo l'OSS RBA (Approccio Basato sul Rischio), il tuo NIB determina quali permessi aggiuntivi sono necessari:

| Livello di Rischio      | NIB + Cosa Altro?                        |
| ----------------------- | ---------------------------------------- |
| **Basso Rischio**       | Solo NIB                                 |
| **Medio-Basso**         | NIB + Sertifikat Standar                 |
| **Medio-Alto**          | NIB + Sertifikat Standar + Verifica      |
| **Alto Rischio**        | NIB + Licenza Completa (Izin)            |

<InfoCard variant="note" title="Rischio Determinato dai Codici KBLI">

I codici delle tue attività commerciali (KBLI) determinano il livello di rischio. Il consulente tecnologico è solitamente a basso-medio rischio. La produzione alimentare ha un rischio più elevato. Il sistema OSS classifica automaticamente in base alla tua selezione dei codici KBLI.

</InfoCard>
