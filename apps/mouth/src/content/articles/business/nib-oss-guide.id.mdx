# Sistem NIB & OSS Indonesia 2026: Panduan Pendaftaran Lengkap

NIB (Nomor Induk Berusaha) melalui OSS (Online Single Submission) adalah gerbang untuk menjalankan bisnis secara legal di Indonesia.

## Apa itu NIB?

<InfoCard variant="note" title="Nomor Identitas Bisnis">
**NIB (Nomor Induk Berusaha)** adalah:

- Nomor identifikasi bisnis Anda
- Pengenal unik 13 digit
- Menggantikan berbagai izin lama
- Fondasi untuk semua perizinan lainnya
- Diterbitkan seketika melalui OSS

NIB berfungsi sebagai TDP (Pendaftaran Perusahaan), API (ID Importir), dan akses bea cukai dalam satu.

</InfoCard>

## Klasifikasi KBLI

<InfoCard variant="warning" title="Pilih dengan Hati-hati">
**KBLI (Klasifikasi Baku Lapangan Usaha Indonesia)** sangat penting:

- Kode kegiatan 5 digit
- Menentukan klasifikasi risiko
- Mempengaruhi persyaratan izin
- Harus sesuai dengan bisnis aktual
- Perubahan memerlukan amandemen

KBLI yang salah dapat berarti izin yang salah atau pelanggaran DNI.

</InfoCard>

### Mencari Kode KBLI

1. Cari di sistem OSS
2. Periksa panduan KBLI (publikasi BPS)
3. Konsultasikan dengan notaris/agen
4. Sesuaikan dengan rencana bisnis Anda

### Contoh Umum KBLI

| Kegiatan             | Kode KBLI           |
| -------------------- | ------------------- |
| Restoran             | 56101               |
| Pengembangan software | 62012               |
| Perdagangan (umum)   | 46900               |
| Konsultasi           | 70201               |
| Hotel                | 55111               |
| Manufaktur           | Berbagai 10xxx-33xxx |

## Klasifikasi Risiko

Setelah memasukkan KBLI, OSS menentukan tingkat risiko:

### Tingkat Risiko

| Level       | Persyaratan                     | Pemrosesan        |
| ----------- | -------------------------------- | ------------------ |
| Rendah      | NIB saja                        | Seketika          |
| Sedang-Rendah | NIB + Sertifikat Standar         | Deklarasi sendiri |
| Sedang-Tinggi | NIB + Sertifikat Standar         | Verifikasi        |
| Tinggi      | NIB + Izin                      | Penilaian penuh   |

### Apa yang Menentukan Risiko?

- Sektor industri
- Skala bisnis
- Dampak lingkungan
- Kesehatan dan keselamatan publik
- Pertimbangan keamanan

## Setelah Mendapatkan NIB

### Langkah Selanjutnya Segera

1. **Unduh sertifikat NIB** - Simpan PDF
2. **Periksa komitmen** - Tinjau kondisi apa pun
3. **Ajukan izin sektoral** - Jika diperlukan oleh KBLI
4. **Selesaikan lingkungan** - Jika komitmen ditunjukkan
5. **Aktifkan fungsi impor** - Jika diperlukan

### Kewajiban Berkelanjutan

- **Pelaporan LKPM** - Laporan investasi kuartalan/semesteran
- **Pembaruan data** - Ketika informasi berubah
- **Perpanjangan izin** - Sebelum ada yang kedaluwarsa
- **Kepatuhan** - Dengan semua kondisi izin

---

## Masalah Umum

### Masalah OSS

| Masalah            | Solusi                   |
| ------------------ | ------------------------ |
| AHU tidak sinkron  | Tunggu atau hubungi AHU  |
| KBLI tidak ditemukan | Gunakan kata kunci pencarian yang benar |
| Alamat ditolak     | Periksa format/koordinat |
| Kesalahan sistem   | Coba browser/waktu lain  |
| Data tidak cocok   | Pastikan akta sesuai dengan input |

### Cara Memperbaiki Kesalahan

<InfoCard variant="tip" title="Mengubah NIB">
Jika Anda membuat kesalahan:

1. **Perubahan kecil** - Perbarui melalui OSS
2. **Perubahan KBLI** - Mungkin perlu amandemen akta terlebih dahulu
3. **Perubahan alamat** - Perbarui dengan domisili baru
4. **Perubahan kepemilikan** - Membutuhkan proses hukum terlebih dahulu

Selalu perbarui OSS ketika data perusahaan berubah.

</InfoCard>
