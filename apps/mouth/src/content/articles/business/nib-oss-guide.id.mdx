# NIB & OSS Sistem Indonesia 2026: Panduan Pendaftaran Lengkap

NIB (Nomor Induk Berusaha) melalui OSS (Online Single Submission) adalah gerbang untuk mengoperasikan bisnis secara legal di Indonesia.

## Apa itu NIB?

<InfoCard variant="note" title="Nomor Identitas Usaha">
**NIB (Nomor Induk Berusaha)** adalah:

- Nomor identifikasi usaha Anda
- Identifikasi unik 13 digit
- Menggantikan beberapa lisensi lama
- Dasar untuk semua izin lainnya
- Diterbitkan secara instan melalui OSS

NIB berfungsi sebagai TDP (Tanda Daftar Perusahaan), API (Izin Impor), dan akses kepabeanan dalam satu.

</InfoCard>

## Klasifikasi KBLI

<InfoCard variant="warning" title="Pilih dengan Hati-hati">
**KBLI (Klasifikasi Baku Lapangan Usaha Indonesia)** sangat penting:

- Kode kegiatan 5 digit
- Menentukan klasifikasi risiko
- Mempengaruhi persyaratan izin
- Harus sesuai dengan bisnis sebenarnya
- Perubahan memerlukan amandemen

KBLI yang salah dapat menyebabkan izin yang salah atau pelanggaran DNI.

</InfoCard>

### Menemukan Kode KBLI

1. Cari di sistem OSS
2. Periksa panduan KBLI (publikasi BPS)
3. Konsultasikan dengan Notaris/agen
4. Sesuaikan dengan rencana bisnis Anda

### Contoh KBLI Umum

| Kegiatan                     | Kode KBLI            |
| ---------------------------- | -------------------- |
| Restoran                     | 56101                |
| Pengembangan perangkat lunak | 62012                |
| Perdagangan (umum)           | 46900                |
| Konsultasi                   | 70201                |
| Hotel                        | 55111                |
| Manufaktur                   | Berbagai 10xxx-33xxx |

---

## Klasifikasi Risiko

Setelah memasukkan KBLI, OSS menentukan tingkat risiko:

### Tingkat Risiko

| Level         | Persyaratan              | Prosesing       |
| ------------- | ------------------------ | --------------- |
| Rendah        | NIB saja                 | Instan          |
| Sedang-Rendah | NIB + Sertifikat Standar | Swasaya         |
| Sedang-Tinggi | NIB + Sertifikat Standar | Verifikasi      |
| Tinggi        | NIB + Izin               | Penilaian penuh |

### Apa yang Menentukan Risiko?

- Sektor industri
- Skala bisnis
- Dampak lingkungan
- Kesehatan/keselamatan publik
- Pertimbangan keamanan

## Setelah Mendapatkan NIB

### Langkah Berikutnya Segera

1. **Unduh sertifikat NIB** - Simpan PDF
2. **Periksa komitmen** - Tinjau persyaratan apa pun
3. **Ajukan izin sektoral** - Jika diperlukan oleh KBLI
4. **Lengkapi lingkungan** - Jika komitmen ditunjukkan
5. **Aktifkan fungsi impor** - Jika diperlukan

### Kewajiban Berkelanjutan

- **Pelaporan LKPM** - Laporan investasi triwulanan/semesteran
- **Pembaruan data** - Saat informasi berubah
- **Perpanjangan lisensi** - Sebelum kedaluwarsa
- **Kepatuhan** - Dengan semua persyaratan izin

---

## Masalah Umum

### Masalah OSS

| Masalah                   | Solusi                               |
| ------------------------- | ------------------------------------ |
| AHU tidak tersinkronisasi | Tunggu atau hubungi AHU              |
| KBLI tidak ditemukan      | Gunakan istilah pencarian yang benar |
| Alamat ditolak            | Periksa format/koordinat             |
| Kesalahan sistem          | Coba browser/waktu yang berbeda      |
| Ketidaksesuaian data      | Pastikan akta sesuai input           |

### Cara Memperbaiki Kesalahan

<InfoCard variant="tip" title="Mengamandemen NIB">
Jika Anda membuat kesalahan:

1. **Perubahan kecil** - Perbarui melalui OSS
2. **Perubahan KBLI** - Mungkin memerlukan amandemen akta terlebih dahulu
3. **Perubahan alamat** - Perbarui dengan domisili baru
4. **Perubahan kepemilikan** - Memerlukan proses hukum terlebih dahulu

Selalu perbarui OSS saat data perusahaan berubah.

</InfoCard>
