## PKWT (Kontrak Jangka Waktu)

<InfoCard variant="warning" title="Keterbatasan PKWT">
**PKWT hanya dapat digunakan untuk:**
- Pekerjaan sementara
- Pekerjaan musiman
- Proyek satu kali
- Pekerjaan terkait produk/proses baru (maks 2 tahun)

**Tidak dapat digunakan untuk:**

- Posisi permanen
- Operasi inti yang berkelanjutan
- Penugasan tanpa batas waktu

Pelanggaran: Kontrak otomatis menjadi PKWTT (permanen).

</InfoCard>

### Aturan Durasi PKWT

| Aturan                   | Batas                              |
| ------------------------ | ---------------------------------- |
| Durasi awal              | Maks 5 tahun (kumulatif)           |
| Perpanjangan             | Dalam batas 5 tahun                |
| Tidak ada masa percobaan | Masa percobaan batal jika tertulis |
| Kompensasi               | Diperlukan pada saat selesai       |

### Aturan Lembur

<Calculator
  title="Kalkulator Lembur"
  description="Hitung upah lembur"
  fields={[
    {
      id: "monthly",
      label: "Gaji Bulanan (IDR)",
      type: "number",
      defaultValue: 10000000,
      min: 0,
      step: 500000,
      suffix: "IDR"
    },
    {
      id: "hours",
      label: "Jam Lembur",
      type: "number",
      defaultValue: 10,
      min: 0,
      max: 14,
      suffix: "jam"
    },
    {
      id: "day",
      label: "Jenis Hari",
      type: "select",
      options: [
        { value: "weekday", label: "Hari kerja biasa" },
        { value: "weekend", label: "Akhir pekan/hari libur" }
      ],
      defaultValue: "weekday"
    }
  ]}
  calculateResult={(values) => {
    const monthly = Number(values.monthly);
    const hours = Number(values.hours);

    // Tarif per jam = 1/173 dari gaji bulanan
    const hourlyRate = monthly / 173;

    let overtime = 0;

    if (values.day === "weekday") {
      // Jam pertama: 1.5x, jam berikutnya: 2x
      if (hours >= 1) {
        overtime += hourlyRate * 1.5;
        if (hours > 1) {
          overtime += (hours - 1) * hourlyRate * 2;
        }
      }
    } else {
      // Akhir pekan/hari libur: perhitungan berbeda
      // 8 jam pertama: 2x, jam ke-9: 3x, 10+: 4x
      const first8 = Math.min(hours, 8);
      overtime += first8 * hourlyRate * 2;
      if (hours > 8) {
        overtime += hourlyRate * 3;
        if (hours > 9) {
          overtime += (hours - 9) * hourlyRate * 4;
        }
      }
    }

    return {
      total: Math.round(overtime),
      breakdown: [
        { label: "Gaji Bulanan", amount: monthly },
        { label: "Tarif Per Jam (1/173)", amount: Math.round(hourlyRate) },
        { label: "Jam Lembur", amount: hours },
        { label: "Upah Lembur", amount: Math.round(overtime) }
      ],
      currency: "IDR",
      note: values.day === "weekday" ? "Hari kerja: 1.5x jam pertama, 2x setelahnya" : "Akhir pekan: 2x 8 jam pertama, 3x jam ke-9, 4x jam ke-10+"
    };

}}

## Peraturan Perusahaan

### Kapan Diperlukan

<InfoCard variant="note" title="Peraturan Perusahaan">
Perusahaan dengan **10+ karyawan** harus memiliki:
- **PP (Peraturan Perusahaan)** - Peraturan perusahaan

Atau dengan serikat pekerja:

- **PKB (Perjanjian Kerja Bersama)** - Perjanjian kerja bersama

Harus didaftarkan ke kantor Tenaga Kerja dan diperbarui setiap 2 tahun.

</InfoCard>
