## PKWT (Kontrak Berjangka Waktu)

<InfoCard variant="warning" title="Keterbatasan PKWT">
**PKWT hanya dapat digunakan untuk:**
- Pekerjaan sementara
- Pekerjaan musiman
- Proyek sekali pakai
- Pekerjaan terkait produk/proses baru (maks 2 tahun)

**Tidak dapat digunakan untuk:**

- Posisi tetap
- Operasi berkelanjutan inti
- Penugasan tidak terbatas

Pelanggaran: Kontrak otomatis menjadi PKWTT (tetap).

</InfoCard>

### Aturan Durasi PKWT

| Aturan         | Batas                     |
| -------------- | ------------------------- |
| Periode awal   | Maksimal 5 tahun (akumulatif) |
| Perpanjangan    | Dalam batas 5 tahun       |
| Tanpa masa percobaan | Masa percobaan batal jika tertulis |
| Kompensasi     | Diperlukan saat penyelesaian |

### Aturan Lembur

<Calculator
  title="Kalkulator Lembur"
  description="Hitung gaji lembur"
  fields={[
    {
      id: "monthly",
      label: "Gaji Bulanan (IDR)",
      type: "number",
      defaultValue: 10000000,
      min: 0,
      step: 500000,
      suffix: "IDR"
    },
    {
      id: "hours",
      label: "Jam Lembur",
      type: "number",
      defaultValue: 10,
      min: 0,
      max: 14,
      suffix: "jam"
    },
    {
      id: "day",
      label: "Tipe Hari",
      type: "select",
      options: [
        { value: "weekday", label: "Hari kerja biasa" },
        { value: "weekend", label: "Weekend/libur" }
      ],
      defaultValue: "weekday"
    }
  ]}
  calculateResult={(values) => {
    const monthly = Number(values.monthly);
    const hours = Number(values.hours);

    // Tarif per jam = 1/173 dari gaji bulanan
    const hourlyRate = monthly / 173;

    let overtime = 0;

    if (values.day === "weekday") {
      // Jam pertama: 1.5x, jam selanjutnya: 2x
      if (hours >= 1) {
        overtime += hourlyRate * 1.5;
        if (hours > 1) {
          overtime += (hours - 1) * hourlyRate * 2;
        }
      }
    } else {
      // Weekend/libur: perhitungan berbeda
      // 8 jam pertama: 2x, jam ke-9: 3x, jam ke-10+: 4x
      const first8 = Math.min(hours, 8);
      overtime += first8 * hourlyRate * 2;
      if (hours > 8) {
        overtime += hourlyRate * 3;
        if (hours > 9) {
          overtime += (hours - 9) * hourlyRate * 4;
        }
      }
    }

    return {
      total: Math.round(overtime),
      breakdown: [
        { label: "Gaji Bulanan", amount: monthly },
        { label: "Tarif per Jam (1/173)", amount: Math.round(hourlyRate) },
        { label: "Jam Lembur", amount: hours },
        { label: "Gaji Lembur", amount: Math.round(overtime) }
      ],
      currency: "IDR",
      note: values.day === "weekday" ? "Hari kerja: 1.5x jam pertama, 2x setelahnya" : "Weekend: 2x 8 jam pertama, 3x jam ke-9, 4x jam ke-10+"
    };

}}

## Upah Minimum

### Upah Minimum Regional (UMR/UMK)

| Provinsi/Kota   | UMR 2026 (Perkiraan) |
| --------------- | -------------------- |
| DKI Jakarta     | ~IDR 5.1 Juta        |
| Bali            | ~IDR 2.9 Juta        |
| Surabaya        | ~IDR 4.7 Juta        |
| Bandung         | ~IDR 4.0 Juta        |
| Semarang        | ~IDR 3.1 Juta        |

<InfoCard variant="note" title="Catatan Upah Minimum">

- UMR adalah minimum untuk karyawan tetap
- Diperbarui setiap tahun (biasanya Januari)
- Upah minimum sektoral dapat berlaku
- Komponen: gaji pokok bisa 75%, tunjangan 25%
- Pekerja PKWT berhak atas upah minimum yang sama

</InfoCard>

## Hak Cuti Khusus

### Cuti Tahunan

| Tipe              | Hak                          |
| ----------------- | ---------------------------- |
| Cuti tahunan      | 12 hari/tahun (setelah 12 bulan) |
| Cuti panjang      | 2 bulan setelah 6 tahun (beberapa perusahaan) |
| Libur agama       | Sesuai kesepakatan           |

### Cuti Khusus (Bergaji)

| Peristiwa                         | Hari   |
| --------------------------------- | ------ |
| Pernikahan                        | 3 hari |
| Pernikahan anak                  | 2 hari |
| Sunat                            | 2 hari |
| Pembaptisan                      | 2 hari |
| Meninggalnya pasangan/anak/orang tua | 2 hari |
| Meninggalnya anggota keluarga lain | 1 hari |
| Istri melahirkan/aborsi          | 2 hari |

### Cuti Melahirkan/Cuti Ayah

| Tipe Cuti   | Durasi                                   | Gaji      |
| ----------- | ---------------------------------------- | --------- |
| Melahirkan  | 1.5 bulan sebelum + 1.5 bulan setelah lahir | Gaji penuh |
| Aborsi       | 1.5 bulan                                | Gaji penuh |
| Ayah         | 2 hari                                   | Gaji penuh |

## Peraturan Perusahaan

### Kapan Diperlukan

<InfoCard variant="note" title="Peraturan Perusahaan">
Perusahaan dengan **10+ karyawan** harus memiliki:
- **PP (Peraturan Perusahaan)** - Peraturan perusahaan

Atau dengan serikat pekerja:

- **PKB (Perjanjian Kerja Bersama)** - Perjanjian kerja bersama

Harus didaftarkan di kantor Ketenagakerjaan dan diperbarui setiap 2 tahun.

</InfoCard>
