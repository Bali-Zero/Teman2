## Le lien caché entre le code de votre entreprise et votre visa

La plupart des entrepreneurs étrangers en Indonesia considèrent la création d'entreprise et les demandes de visa comme des processus distincts. Créer d'abord la PT PMA, demander ensuite le KITAS. Deux systèmes gouvernementaux différents, deux agences différentes, deux calendriers différents.

Ils ont tort. Les deux processus sont **profondément liés**, et le point de connexion est votre code KBLI.

Lorsque vous demandez un KITAS — que ce soit en tant qu'investisseur, directeur, employé ou travailleur à distance — l'immigration ne se contente pas de regarder votre passeport et votre entreprise sponsor. Ils récupèrent le NIB (Nomor Induk Berusaha) de votre entreprise et vérifient quels codes KBLI sont enregistrés. Ensuite, ils posent une question simple : **le type de visa de cette personne correspond-il à ce que fait réellement cette entreprise ?**

Si la réponse est non, votre demande de KITAS est rejetée. Si la non-conformité est découverte après l'émission, votre KITAS peut être révoqué. Avec la reclassification KBLI 2025 (Règlement BPS n° 7 de 2025) modifiant les structures de codes dans presque tous les secteurs, les risques de désalignement se sont multipliés. Des codes qui existaient sous KBLI 2020 peuvent avoir été scindés, fusionnés ou renumérotés. Si votre NIB contient encore d'anciens codes alors que votre KITAS fait référence à de nouvelles descriptions d'activité, la non-concordance devient un signal d'alarme.

Ce guide explique précisément comment chaque type de KITAS interagit avec vos codes KBLI — et comment les maintenir synchronisés.

## La matrice d'alignement KITAS-KBLI

Le tableau suivant présente les principaux types de KITAS, leurs exigences KBLI, les pièges courants et les codes recommandés. C'est la référence dont vous avez besoin avant de déposer toute demande de KITAS.

| Type de KITAS              | Index     | Objectif                                          | Exigence KBLI                       | RPTKA nécessaire | Codes KBLI recommandés     | Risque clé                                |
| -------------------------- | --------- | ------------------------------------------------- | ----------------------------------- | ---------------- | -------------------------- | ----------------------------------------- |
| **Investisseur**           | E28A      | Actionnaire étranger avec investissement 10B+ IDR | Doit être éligible PMA (TERBUKA)    | Non              | 70209, 62019, 55110, 68xxx | Code non-PMA = rejet immédiat             |
| **Directeur**              | E25B      | Directeur/commissaire étranger                    | KBLI doit justifier le rôle         | Oui              | 70209, 62019, 55110, 79111 | Inadéquation activité/fonctions directeur |
| **Employé**                | E23       | Travailleur étranger (TKA)                        | KBLI détermine le quota TKA secteur | Oui              | Spécifique au secteur      | Quota TKA dépassé pour le secteur         |
| **Travailleur à distance** | E33G      | Travaille pour employeur étranger                 | KBLI de l'entité sponsor compte     | Non              | 70209, 62019               | KBLI sponsor incohérent avec activité     |
| **Retraite**               | E33F/E33E | Permis de séjour de retraité                      | Aucune exigence KBLI directe        | Non              | S/O                        | Le titulaire ne peut pas travailler       |

La compréhension critique : **chaque type de KITAS, à l'exception de la retraite, a une dépendance directe ou indirecte aux codes KBLI.** La dépendance n'est pas théorique. Les agents d'immigration à Bali, Jakarta et Surabaya recoupent activement les données NIB pendant le traitement des KITAS.

## KITAS investisseur E28A : votre KBLI doit être éligible PMA

Le KITAS investisseur E28A est le permis de séjour standard pour les actionnaires étrangers qui détiennent au moins 10 milliards d'IDR de capital libéré dans une [PT PMA](/insights/business/pt-pma-registration-guide). La logique est simple : vous avez investi substantiellement dans une entreprise indonésienne et vous devez être physiquement présent pour superviser votre investissement.

### La porte KBLI

Les codes KBLI de votre PT PMA doivent être classés comme **TERBUKA** (totalement ouverts à la propriété étrangère) ou **TERBUKA BERSYARAT** avec un plafond de propriété étrangère qui correspond à votre pourcentage d'actionnariat. Si votre entreprise opère sous un code KBLI qui restreint ou interdit la propriété étrangère, vous ne pouvez pas détenir d'actions — et sans actionnariat valide, la demande E28A n'a aucune base légale.

Sous KBLI 2025, les secteurs les plus couramment utilisés par les titulaires de E28A incluent :

- **Conseil** (70201–70209) : 100 % PMA, faible risque. Le choix le plus sûr pour les KITAS d'investisseurs.
- **Services informatiques** (62012, 62019, 62024) : 100 % PMA. Forte justification pour les investisseurs axés sur la technologie.
- **Hôtellerie** (55110–55199) : 100 % PMA. Hôtels, villas, maisons d'hôtes — tous ouverts.
- **Immobilier** (68xxx — les 14 codes) : 100 % PMA. [Expansion majeure sous KBLI 2025](/insights/business/kbli-2025-foreign-ownership-pma-guide).
- **Tourisme** (79111–79120) : 100 % PMA. Agences de voyage, voyagistes.

### Piège courant E28A

Un investisseur crée une PT PMA avec des codes KBLI de l'ère KBLI 2020. Selon l'ancienne classification, les codes étaient éligibles PMA. Sous KBLI 2025, la même activité pourrait correspondre à un code différent — potentiellement un code avec de nouvelles conditions. Si le NIB n'a pas été mis à jour pour refléter les codes KBLI 2025, l'immigration peut signaler l'incohérence lors de la demande E28A.

**Action requise :** Vérifiez que les codes KBLI de votre PT PMA sont à jour selon la classification 2025 avant votre prochain renouvellement E28A ou votre demande initiale. La date limite de conformité est le **18 juin 2026** (Règlement BPS n° 7 de 2025).

## KITAS directeur E25B : votre rôle doit correspondre à l'activité de l'entreprise

Le KITAS directeur E25B est destiné aux ressortissants étrangers nommés directeurs ou commissaires d'entreprises indonésiennes. Il nécessite un RPTKA (Rencana Penggunaan Tenaga Kerja Asing) — le plan d'utilisation de la main-d'œuvre étrangère qui justifie pourquoi un étranger est nécessaire pour ce rôle.

### Comment l'immigration examine les demandes E25B

L'immigration ne se contente pas de confirmer que vous êtes listé comme directeur dans l'akta (acte de constitution) de l'entreprise. Elle examine si un directeur étranger est **justifié** pour l'activité commerciale déclarée de l'entreprise. Cette justification provient directement du code KBLI.

**Scénarios de justification solides :**

- **70209** (Conseil en gestion) : Un directeur étranger gérant une pratique de conseil international. Ajustement naturel. Questions minimales.
- **62019** (Services informatiques) : Un directeur étranger supervisant les opérations de développement logiciel. L'expertise technologique justifie un leadership étranger.
- **55110** (Hôtels/Hébergement) : Un directeur étranger dirigeant une opération hôtelière. Antécédent établi à Bali.
- **79111** (Agence de voyage) : Un directeur étranger gérant une opération de tourisme entrant ciblant une clientèle internationale.

**Scénarios de justification plus faibles :**

- Une PT PMA enregistrée sous un code KBLI de vente au détail de base (47xxx) avec un directeur étranger. L'immigration peut se demander pourquoi un directeur local ne peut pas gérer les opérations de vente au détail.
- Une PT PMA de construction (41017) avec un directeur étranger sans expérience en construction. L'inadéquation KBLI-rôle soulève des doutes.

### La chaîne RPTKA-KBLI

Le document RPTKA indique explicitement l'activité commerciale de l'entreprise et le rôle du travailleur étranger en son sein. Cette description doit correspondre aux codes KBLI de votre NIB. Si votre NIB indique du conseil (70209) mais que votre RPTKA décrit la gestion de la construction, les documents se contredisent. L'immigration rejettera la demande.

La chaîne est : **KBLI sur NIB → description d'activité RPTKA → demande KITAS → examen par l'immigration.** Chaque maillon doit être cohérent.

## KITAS employé E23 : les quotas TKA sont spécifiques au secteur

Le KITAS employé E23 couvre les travailleurs étrangers (Tenaga Kerja Asing / TKA) employés par des entreprises indonésiennes. Contrairement au E25B, l'employé n'est pas un directeur — c'est un membre du personnel embauché. Le RPTKA est obligatoire, et le processus d'approbation inclut une variable critique : **les quotas TKA par secteur.**

### Comment le KBLI détermine votre quota TKA
