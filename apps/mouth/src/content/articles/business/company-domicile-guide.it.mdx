## Ufficio Virtuale Spiegato

L'ufficio virtuale è la scelta più comune per le PT PMA:

### Cosa Ottieni

- **Indirizzo commerciale registrato** per scopi ufficiali
- **Surat Keterangan Domisili** (lettera di domicilio)
- **Ricezione** e inoltro **posta**
- **Risposta telefonica** (opzionale)
- **Accesso a sale riunioni** (tariffe orarie/giornaliere)

### Cosa Non Ottieni

- Scrivania fisica o spazio permanente
- Posto di lavoro quotidiano

<InfoCard variant="tip" title="L'Ufficio Virtuale È Legittimo">
Gli uffici virtuali sono legali al 100% e accettati da:
- Ministero della Legge (Kemenkumham)
- Ufficio delle imposte (DJP)
- sistema OSS
- Banche (per l'apertura del conto)

Molte PT PMA operano in questo modo, specialmente le attività basate sui servizi.

</InfoCard>

      options: [
        { value: "jakarta-prime", label: "Jakarta Prime (SCBD, Sudirman)" },
        { value: "jakarta-other", label: "Altre Aree di Jakarta" },
        { value: "bali", label: "Bali" },

    },
    {

      type: "select",
      options: [
        { value: "1", label: "1 anno" },

      defaultValue: "1"

    let yearlyBase = 0;

    const rates = {
      virtual: { 'jakarta-prime': 18000000, 'jakarta-other': 12000000, bali: 12000000, other: 8000000 },
