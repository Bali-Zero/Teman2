## AMDAL (Оценка воздействия на окружающую среду)

<InfoCard variant="warning" title="Только для крупных проектов">
**AMDAL требуется для:**
- Крупные производственные предприятия
- Горнодобывающие операции
- Крупные инфраструктурные проекты
- Крупномасштабное сельское хозяйство
- Значительное освоение земель
- Химические/опасные объекты

AMDAL включает общественные консультации и экспертную оценку.

</InfoCard>

### Процесс AMDAL

| Этап                      | Описание                                     | Продолжительность |
| ------------------------- | -------------------------------------------- | ----------------- |
| Скрининг                  | Определение необходимости AMDAL              | 1-2 недели        |
| Определение объема        | Определение объема исследования              | 2-4 недели        |
| Исследование ОВОС         | Исследование воздействия на окружающую среду | 3-6 месяцев       |
| Общественные консультации | Вклад сообщества                             | 1-2 месяца        |
| Рассмотрение              | Оценка комитетом                             | 1-2 месяца        |
| Утверждение               | Выдача экологического разрешения             | 2-4 недели        |

### Компоненты AMDAL

| Документ | Назначение                        |
| -------- | --------------------------------- |
| KA-ANDAL | Техническое задание               |
| ANDAL    | Анализ воздействия                |
| RKL      | План управления окружающей средой |
| RPL      | План мониторинга окружающей среды |

## UKL-UPL (Управление и мониторинг)

### Когда требуется UKL-UPL

Большинству средних предприятий требуется UKL-UPL:

- Рестораны и кафе
- Малое и среднее производство
- Мастерские и гаражи
- Среднее строительство
- Отели (определенных размеров)

## SPPL (Письмо-заявление)

<InfoCard variant="tip" title="Простейший вариант">
**SPPL** предназначен для предприятий с низким уровнем воздействия:
- Небольшие розничные магазины
- Базовые услуги
- Офисная деятельность
- Операции с низким риском

Часто генерируется автоматически через систему OSS на основе вашего кода KBLI.

</InfoCard>

### Процесс SPPL

1. Зарегистрируйтесь в системе OSS
2. Введите данные о бизнесе
3. SPPL генерируется, если риск низкий
4. Распечатайте и храните в записи
5. Соблюдайте заявленные обязательства

---

## Подход, основанный на оценке рисков

### Классификация рисков OSS

Система OSS теперь использует **подход, основанный на оценке рисков**:

| Уровень риска  | Экологическое требование    |
| -------------- | --------------------------- |
| Низкий         | SPPL (автоматически в OSS)  |
| Средне-низкий  | SPPL или упрощенный UKL-UPL |
| Средне-высокий | Стандартный UKL-UPL         |
| Высокий        | Полная оценка AMDAL         |

Риск определяется:

- Классификация бизнеса по KBLI
- Масштаб операций
- Чувствительность местоположения
- Потенциальное воздействие на окружающую среду

## Управление отходами

### Категории отходов

| Категория           | Примеры                  | Требования                 |
| ------------------- | ------------------------ | -------------------------- |
| B3 (Опасные)        | Химикаты, батареи, масло | Лицензированная утилизация |
| Не-B3               | Общие отходы             | Правильная утилизация      |
| Сточные воды        | Технологическая вода     | Очистка перед сбросом      |
| Выбросы в атмосферу | Дым, газы                | Мониторинг, фильтры        |

<InfoCard variant="warning" title="Отходы B3">
**Опасные отходы (B3)** требуют:
- Раздельное хранение
- Лицензированный перевозчик
- Лицензированное утилизационное сооружение
- Документация манифеста
- Регулярная отчетность

Нарушения могут привести к серьезным штрафам.

</InfoCard>

---

## Штрафы за несоблюдение

| Нарушение                       | Штраф                                   |
| ------------------------------- | --------------------------------------- |
| Деятельность без разрешения     | Закрытие + штрафы                       |
| Превышение стандартов           | Предупреждения → штрафы → закрытие      |
| Неправильная утилизация отходов | Возможны уголовные обвинения            |
| Ложная отчетность               | Отзыв разрешения                        |
| Нарушения, связанные с B3       | Уголовная + гражданская ответственность |
