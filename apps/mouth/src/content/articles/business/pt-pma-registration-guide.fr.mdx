# Comment enregistrer une PT PMA en Indonesia : Étape par étape 2026

L'enregistrement d'une PT PMA (Perseroan Terbatas Penanaman Modal Asing) est le moyen standard pour les étrangers d'établir une entité commerciale légale en Indonesia. Voici exactement comment procéder.

<InfoCard variant="danger" title="Mise à jour de conformité 2026 : Rapports annuels obligatoires">
  **Nouvelle Réglementation 49/2025 :** À partir de 2026, toutes les PT PMA sont désormais tenues de
  soumettre des rapports annuels notariés (approbation GMS) via le système SABH. Le non-respect de
  cette exigence entraîne la suspension immédiate du NIB. De plus, une vérification plus stricte de
  l'UBO (Ultimate Beneficial Owner) est désormais obligatoire pour toutes les modifications
  d'entreprise. [Lire le mandat de conformité complet des PT PMA
  →](/business/indonesia-corporate-reporting-mandate-regulation-49-2025)
</InfoCard>

## Aperçu rapide

| Aspect                 | Détails                       |
| ---------------------- | ----------------------------- |
| **Délai**              | 4-8 semaines                  |
| **Investissement Min** | IDR 10 milliards (~625 000 $) |

| **Directeurs Min**     | 1 (peut être étranger)        |
| **Commissaires Min**   | 1 (peut être étranger)        |

### Possibles développements PT PMA (OPINION)

1. **Capitale réduit pour le secteur technologique** - Une discussion est en cours concernant une éventuelle réduction de l'exigence de capital minimum (actuellement 10 milliards IDR) pour les startups technologiques et les services numériques. Certains estiment qu'elle pourrait descendre à 2,5-5 milliards IDR. _Discussion seulement, aucune confirmation._

2. **Liste d'investissement négative simplifiée** - Il y a une discussion sur des ouvertures sectorielles supplémentaires pour les investisseurs étrangers, notamment dans l'éducation, la santé et la logistique. _Aucune annonce officielle._

3. **Enregistrement en un seul point** - Il est question d'un processus encore plus intégré qui combinerait le notaire, Kemenkumham, NPWP et OSS en un seul flux. _Spéculation seulement._

4. **Entreprise virtuelle pour les freelances** - Certains experts discutent d'une possible structure d'entreprise simplifiée pour les freelances étrangers, sans les exigences complètes d'une PT PMA. _Non confirmé._

5. **Incitatifs pour les zones économiques spéciales** - Des incitatifs supplémentaires possibles (congé fiscal, capital réduit) sont discutés pour les PT PMA qui s'établissent dans les Zones Économiques Spéciales (KEK). _En cours d'évaluation._

**Rappel** : Pour les décisions d'investissement, attendez les confirmations officielles de oss.go.id ou bkpm.go.id.
