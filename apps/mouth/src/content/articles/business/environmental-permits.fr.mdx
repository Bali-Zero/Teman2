## AMDAL (Évaluation de l'impact environnemental)

<InfoCard variant="warning" title="Projets majeurs uniquement">
**AMDAL est requis pour :**
- Grandes installations de fabrication
- Opérations minières
- Projets d'infrastructure majeurs
- Agriculture à grande échelle
- Développement foncier significatif
- Installations chimiques/dangereuses

AMDAL implique une consultation publique et une évaluation par des experts.

</InfoCard>

### Processus AMDAL

| Étape                             | Description                        | Durée        |
| --------------------------------- | ---------------------------------- | ------------ |
| Sélection                         | Déterminer si AMDAL est nécessaire | 1-2 semaines |
| Définition du champ d'application | Définir le périmètre de l'étude    | 2-4 semaines |
| Étude d'impact environnemental    | Étude d'impact environnemental     | 3-6 mois     |
| Consultation publique             | Contribution de la communauté      | 1-2 mois     |
| Examen                            | Évaluation par le comité           | 1-2 mois     |
| Approbation                       | Permis environnemental délivré     | 2-4 semaines |

### Composantes AMDAL

| Document | Objectif                              |
| -------- | ------------------------------------- |
| KA-ANDAL | Termes de référence                   |
| ANDAL    | Analyse d'impact                      |
| RKL      | Plan de gestion environnementale      |
| RPL      | Plan de surveillance environnementale |

## UKL-UPL (Gestion et surveillance)

### Quand UKL-UPL est requis

La plupart des entreprises de taille moyenne ont besoin de UKL-UPL :

- Restaurants et cafés
- Fabrication de petite à moyenne taille
- Ateliers et garages
- Construction moyenne
- Hôtels (certaines tailles)

## SPPL (Lettre de déclaration)

<InfoCard variant="tip" title="Option la plus simple">
**SPPL** est destiné aux entreprises à faible impact :
- Petits commerces de détail
- Services de base
- Activités de bureau
- Opérations à faible risque

Souvent généré automatiquement via le système OSS en fonction de votre code KBLI.

</InfoCard>

### Processus SPPL

1. S'inscrire sur le système OSS
2. Saisir les détails de l'entreprise
3. SPPL généré si le risque est faible
4. Imprimer et conserver dans les dossiers
5. Se conformer aux engagements déclarés

---

## Approche basée sur les risques

### Classification des risques OSS

Le système OSS utilise désormais une **approche basée sur les risques** :

| Niveau de risque | Exigence environnementale   |
| ---------------- | --------------------------- |
| Faible           | SPPL (automatique dans OSS) |
| Moyen-faible     | SPPL ou UKL-UPL simplifié   |
| Moyen-élevé      | UKL-UPL standard            |
| Élevé            | AMDAL évaluation complète   |

Risque déterminé par :

- Classification commerciale KBLI
- Échelle des opérations
- Sensibilité de l'emplacement
- Impact environnemental potentiel

## Gestion des déchets

### Catégories de déchets

| Catégorie                | Exemples                             | Exigences              |
| ------------------------ | ------------------------------------ | ---------------------- |
| B3 (Dangereux)           | Produits chimiques, batteries, huile | Élimination autorisée  |
| Non-B3                   | Déchets généraux                     | Élimination appropriée |
| Eaux usées               | Eaux de processus                    | Traitement avant rejet |
| Émissions atmosphériques | Fumée, gaz                           | Surveillance, filtres  |

<InfoCard variant="warning" title="Déchets B3">
Les **déchets dangereux (B3)** nécessitent :
- Stockage séparé
- Transporteur agréé
- Installation d'élimination agréée
- Documentation du manifeste
- Rapports réguliers

Les violations peuvent entraîner de graves sanctions.

</InfoCard>

---

## Sanctions en cas de non-conformité

| Violation                            | Sanction                             |
| ------------------------------------ | ------------------------------------ |
| Opération sans permis                | Fermeture + amendes                  |
| Dépassement des normes               | Avertissements → amendes → fermeture |
| Élimination inappropriée des déchets | Poursuites pénales possibles         |
| Faux rapports                        | Révocation du permis                 |
| Violations B3                        | Responsabilité pénale + civile       |
