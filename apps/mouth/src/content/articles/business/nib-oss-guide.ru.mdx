# Система NIB и OSS в Indonesia 2026: Полное руководство по регистрации

NIB (Nomor Induk Berusaha) через OSS (Online Single Submission) — это шлюз для легального ведения бизнеса в Indonesia.

## Что такое NIB?

<InfoCard variant="note" title="Идентификационный номер предприятия">
**NIB (Nomor Induk Berusaha)** это:

- Ваш идентификационный номер предприятия
- Уникальный 13-значный идентификатор
- Заменяет несколько старых лицензий
- Основа для всех других разрешений
- Выдается мгновенно через OSS

NIB функционирует как TDP (Регистрация компании), API (Идентификатор импортера) и таможенный доступ в одном.

</InfoCard>

## Классификация KBLI

<InfoCard variant="warning" title="Выбирайте внимательно">
**KBLI (Klasifikasi Baku Lapangan Usaha Indonesia)** имеет решающее значение:

- 5-значные коды деятельности
- Определяет классификацию риска
- Влияет на требования к разрешениям
- Должен соответствовать фактическому бизнесу
- Изменения требуют поправок

Неправильный KBLI может означать неправильные разрешения или нарушения DNI.

</InfoCard>

### Поиск кодов KBLI

1. Поиск в системе OSS
2. Проверить руководство KBLI (публикация BPS)
3. Проконсультироваться с нотариусом/агентом
4. Соответствие вашему бизнес-плану

### Примеры распространенных KBLI

| Деятельность     | Код KBLI              |
| ---------------- | --------------------- |
| Ресторан         | 56101                 |
| Разработка ПО    | 62012                 |
| Торговля (общая) | 46900                 |
| Консалтинг       | 70201                 |
| Отель            | 55111                 |
| Производство     | Различные 10xxx-33xxx |

---

## Классификация рисков

После ввода KBLI, OSS определяет уровень риска:

### Уровни риска

| Уровень        | Требования                   | Обработка                      |
| -------------- | ---------------------------- | ------------------------------ |
| Низкий         | Только NIB                   | Мгновенно                      |
| Средне-низкий  | NIB + Стандартный сертификат | Самостоятельное декларирование |
| Средне-высокий | NIB + Стандартный сертификат | Проверка                       |
| Высокий        | NIB + Разрешение             | Полная оценка                  |

### Что определяет риск?

- Сектор промышленности
- Масштаб бизнеса
- Воздействие на окружающую среду
- Общественное здоровье/безопасность
- Соображения безопасности

## После получения NIB

### Немедленные следующие шаги

1. **Скачать сертификат NIB** - Сохранить PDF
2. **Проверить обязательства** - Просмотреть любые условия
3. **Подать заявку на секторальные разрешения** - Если требуется KBLI
4. **Завершить экологические** - Если показано обязательство
5. **Активировать функции импорта** - Если необходимо

### Текущие обязательства

- **Отчетность LKPM** - Ежеквартальные/полугодовые инвестиционные отчеты
- **Обновления данных** - При изменении информации
- **Продление лицензий** - До истечения срока действия
- **Соблюдение** - Всех условий разрешения

## Общие проблемы

### Проблемы OSS

| Проблема               | Решение                                           |
| ---------------------- | ------------------------------------------------- |
| AHU не синхронизирован | Подождать или связаться с AHU                     |
| KBLI не найден         | Использовать правильные термины поиска            |
| Адрес отклонен         | Проверить формат/координаты                       |
| Системная ошибка       | Попробовать другой браузер/время                  |
| Несоответствие данных  | Убедиться, что акт соответствует введенным данным |

### Как исправить ошибки

<InfoCard variant="tip" title="Внесение изменений в NIB">
Если вы допустили ошибки:

1. **Незначительные изменения** - Обновить через OSS
2. **Изменения KBLI** - Возможно, сначала потребуется внести изменения в акт
3. **Изменение адреса** - Обновить с новым домицилем
4. **Изменение собственности** - Сначала требуется юридическая процедура

Всегда обновляйте OSS при изменении данных компании.

</InfoCard>
