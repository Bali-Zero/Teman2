# Exigences de capital pour PT PMA : Ce que vous devez investir en 2026

L'investissement minimum de **10 milliards IDR** (environ 625 000 $ USD) pour une PT PMA est l'une des exigences les plus mal comprises. Examinons ce que cela signifie réellement.

## Les deux chiffres clés

| Exigence | Montant | Ce que cela signifie |
| -------------------- | ------------------ | Investissement total prévu sur la durée de vie de l'entreprise |
| **Investissement total** | 10 milliards IDR min | Investissement total prévu sur la durée de vie de l'entreprise |
| **Capital versé** | 10 milliards IDR min | Espèces déposées sur le compte bancaire de l'entreprise |

<InfoCard variant="important" title="Les deux doivent être respectés">
  Conformément à la réglementation en vigueur, **à la fois** le plan d'investissement total ET le
  capital versé doivent être d'au moins 10 milliards IDR. Cela a changé par rapport aux règles
  précédentes où le capital versé pouvait être inférieur.
</InfoCard>

## Calculateur d'investissement

<Calculator
  title="Planificateur de structure d'investissement"
  description="Planifiez comment atteindre 10 milliards IDR d'investissement"
  fields={[

  calculateResult={(values) => {
    const cash = Number(values.cash);
    const equipment = Number(values.equipment);
    const working = Number(values.working);
    const property = Number(values.property);

    const total = cash + equipment + working + property;
    const required = 10000000000;
    const shortage = Math.max(0, required - total);
    const paidUpShortage = Math.max(0, required - cash);

    const breakdown = [
      { label: "Capital social (Espèces)", amount: cash },
      { label: "Équipement et machinerie", amount: equipment },

      { label: "Plan d'investissement total", amount: total }
    ];

    let note = "";
    if (total >= required && cash >= required) {
      note = "Exigences respectées !";
    } else if (cash < required) {
      note = `Le capital versé est insuffisant de IDR ${(paidUpShortage/1000000000).toFixed(1)}B. Doit déposer au minimum 10 milliards IDR.`;
    } else if (total < required) {
      note = `L'investissement total est insuffisant de IDR ${(shortage/1000000000).toFixed(1)}B`;
    }

    return {
      total,
      breakdown,
      currency: "IDR",
      note

## Questions courantes sur le capital

<InfoCard variant="note" title="FAQ">
**Q: Ai-je besoin de 10 milliards IDR sur mon compte bancaire dès le premier jour ?**
R: Oui, un capital versé de 10 milliards IDR doit être déposé pour ouvrir le compte bancaire de l'entreprise et finaliser l'enregistrement.

**Q: Puis-je l'utiliser après le dépôt ?**
R: Oui, une fois déposés en tant que capital social, vous utilisez ces fonds pour les opérations commerciales.

**Q: Que faire si je ne peux pas atteindre 10 milliards IDR ?**
R: Les options incluent :

- Joint venture avec un partenaire local
- Structure d'entreprise différente (bureau de représentation, etc.)
- Attendre d'avoir un capital suffisant

**Q: Existe-t-il un moyen de contourner le minimum ?**
R: Il n'y a aucun moyen légitime. La réglementation est claire sur le minimum de 10 milliards IDR pour une PT PMA.

</InfoCard>
