## PKWT (Contrat à durée déterminée)

<InfoCard variant="warning" title="Limitations PKWT">
**Le PKWT ne peut être utilisé que pour :**
- Travail temporaire
- Travail saisonnier
- Projets uniques
- Travail lié à de nouveaux produits/processus (max 2 ans)

**Ne peut pas être utilisé pour :**

- Postes permanents
- Opérations continues essentielles
- Missions à durée indéterminée

Violation : Le contrat devient automatiquement un PKWTT (permanent).

</InfoCard>

### Règles de durée PKWT

| Règle                  | Limite                          |
| ---------------------- | ------------------------------- |
| Durée initiale         | Max 5 ans (cumulatif)           |
| Prolongations          | Dans la limite de 5 ans         |
| Pas de période d'essai | Période d'essai nulle si écrite |
| Compensation           | Obligatoire à l'achèvement      |

### Règles sur les heures supplémentaires

<Calculator
  title="Calculateur d'heures supplémentaires"
  description="Calculer le salaire des heures supplémentaires"
  fields={[
    {
      id: "monthly",
      label: "Salaire mensuel (IDR)",
      type: "number",
      defaultValue: 10000000,
      min: 0,

      suffix: "IDR"
    },
    {
      id: "hours",
      label: "Heures supplémentaires",
      type: "number",
      defaultValue: 10,
      min: 0,
      max: 14,
      suffix: "heures"
    },
    {
      id: "day",
      label: "Type de jour",
      type: "select",
      options: [
        { value: "weekday", label: "Jour de semaine normal" },
        { value: "weekend", label: "Week-end/jour férié" }
      ],
      defaultValue: "weekday"
    }
  ]}
  calculateResult={(values) => {
    const monthly = Number(values.monthly);
    const hours = Number(values.hours);

    // Hourly rate = 1/173 of monthly salary
    const hourlyRate = monthly / 173;

    let overtime = 0;

    if (values.day === "weekday") {
      // First hour: 1.5x, subsequent hours: 2x
      if (hours >= 1) {
        overtime += hourlyRate * 1.5;
        if (hours > 1) {
          overtime += (hours - 1) * hourlyRate * 2;
        }
      }
    } else {
      // Weekend/holiday: different calculation
      // First 8 hours: 2x, 9th hour: 3x, 10th+: 4x
      const first8 = Math.min(hours, 8);
      overtime += first8 * hourlyRate * 2;
      if (hours > 8) {
        overtime += hourlyRate * 3;
        if (hours > 9) {
          overtime += (hours - 9) * hourlyRate * 4;
        }
      }
    }

    return {
      total: Math.round(overtime),
      breakdown: [
        { label: "Salaire mensuel", amount: monthly },
        { label: "Taux horaire (1/173)", amount: Math.round(hourlyRate) },
        { label: "Heures supplémentaires", amount: hours },
        { label: "Rémunération des heures supplémentaires", amount: Math.round(overtime) }
      ],
      currency: "IDR",
      note: values.day === "weekday" ? "Jour de semaine : 1,5x première heure, 2x ensuite" : "Week-end : 2x les 8 premières, 3x la 9ème, 4x la 10ème et plus"
    };

}}

## Salaire minimum

### Salaire minimum régional (UMR/UMK)

| Province/Ville | UMR 2026 (Approx) |
| -------------- | ----------------- |
| DKI Jakarta    | ~IDR 5.1M         |
| Bali           | ~IDR 2.9M         |
| Surabaya       | ~IDR 4.7M         |
| Bandung        | ~IDR 4.0M         |
| Semarang       | ~IDR 3.1M         |

<InfoCard variant="note" title="Notes sur le salaire minimum">
  - L'UMR est le minimum pour les employés permanents - Mis à jour annuellement (généralement en
  janvier) - Des minimums sectoriels peuvent s'appliquer - Composantes : le salaire de base peut

## Droits à congés

### Congés annuels

| Type                  | Droit                                      |
| --------------------- | ------------------------------------------ |
| Congé annuel          | 12 jours/an (après 12 mois)                |
| Congé de longue durée | 2 mois après 6 ans (certaines entreprises) |
| Fête religieuse       | Selon l'accord                             |

### Congé spécial (Payé)

| Événement                              | Jours   |
| -------------------------------------- | ------- |
| Mariage                                | 3 jours |
| Mariage d'un enfant                    | 2 jours |
| Circoncision                           | 2 jours |
| Baptême                                | 2 jours |
| Décès du conjoint/enfant/parent        | 2 jours |
| Décès d'un autre membre de la famille  | 1 jour  |
| Accouchement/fausse couche de l'épouse | 2 jours |

### Maternité/Paternité

| Type de congé | Durée                                        | Paie        |
| ------------- | -------------------------------------------- | ----------- |
| Maternité     | 1,5 mois avant + 1,5 mois après la naissance | Pleine paie |
| Fausse couche | 1,5 mois                                     | Pleine paie |
| Paternité     | 2 jours                                      | Pleine paie |

## Règlement intérieur de l'entreprise

### Quand est-il requis

<InfoCard variant="note" title="Peraturan Perusahaan">
Les entreprises de **10 employés et plus** doivent avoir :
- **PP (Peraturan Perusahaan)** - Règlement intérieur de l'entreprise

Ou avec un syndicat :

- **PKB (Perjanjian Kerja Bersama)** - Convention collective de travail

Doit être enregistré auprès du bureau du travail et renouvelé tous les 2 ans.

</InfoCard>
