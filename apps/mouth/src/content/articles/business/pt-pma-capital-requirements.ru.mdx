# Требования к капиталу PT PMA: Что нужно инвестировать в 2026 году

Минимальный объем инвестиций для PT PMA в размере **10 миллиардов индонезийских рупий** (приблизительно $625,000 долларов США) является одним из самых неправильно понимаемых требований. Давайте разберем, что это на самом деле означает.

## Две ключевые цифры

| Требование                 | Сумма                     | Что это означает                                                      |
| :------------------------- | :------------------------ | :-------------------------------------------------------------------- |
| **Общий объем инвестиций** | минимум 10 миллиардов IDR | Общий запланированный объем инвестиций на срок существования компании |
| **Оплаченный капитал**     | минимум 10 миллиардов IDR | Наличные, внесенные на банковский счет компании                       |

<InfoCard variant="important" title="Должны быть выполнены оба условия">
  Согласно действующим правилам, **как** общий план инвестиций, ТАК И оплаченный капитал должны
  составлять не менее 10 миллиардов IDR. Это изменилось по сравнению с предыдущими правилами, когда
  оплаченный капитал мог быть ниже.
</InfoCard>

## Калькулятор инвестиций

<Calculator
  title="Планировщик структуры инвестиций"
  description="Спланируйте, как достичь 10 миллиардов IDR инвестиций"
  fields={[
    {
      id: "cash",
      label: "Наличные для внесения (акционерный капитал)",
      type: "number",
      defaultValue: 10000000000,
      min: 0,
      step: 500000000,
      suffix: "IDR"
    },
    {
      id: "equipment",
      label: "Оборудование и машины",
      type: "number",
      defaultValue: 0,
      min: 0,
      step: 100000000,
      suffix: "IDR"
    },
    {
      id: "working",
      label: "Оборотный капитал (Год 1)",
      type: "number",
      defaultValue: 0,
      min: 0,
      step: 100000000,
      suffix: "IDR"
    },
    {
      id: "property",
      label: "Недвижимость/Земля",
      type: "number",
      defaultValue: 0,
      min: 0,
      step: 500000000,
      suffix: "IDR"
    }
  ]}
  calculateResult={(values) => {
    const cash = Number(values.cash);
    const equipment = Number(values.equipment);
    const working = Number(values.working);
    const property = Number(values.property);

    const total = cash + equipment + working + property;
    const required = 10000000000;
    const shortage = Math.max(0, required - total);
    const paidUpShortage = Math.max(0, required - cash);

    const breakdown = [
      { label: "Акционерный капитал (наличные)", amount: cash },
      { label: "Оборудование и машины", amount: equipment },
      { label: "Оборотный капитал", amount: working },
      { label: "Недвижимость/Земля", amount: property },
      { label: "Общий план инвестиций", amount: total }
    ];

    let note = "";
    if (total >= required && cash >= required) {
      note = "Требования выполнены!";
    } else if (cash < required) {
      note = `Оплаченный капитал недоступен на ${ (paidUpShortage/1000000000).toFixed(1)}B IDR. Необходимо внести минимум 10B IDR.`;
    } else if (total < required) {
      note = `Общий объем инвестиций недоступен на ${ (shortage/1000000000).toFixed(1)}B IDR`;
    }

    return {
      total,
      breakdown,
      currency: "IDR",
      note
    };

}}

## Общие вопросы о капитале

<InfoCard variant="note" title="Часто задаваемые вопросы">
**В: Нужны ли мне 10 миллиардов IDR на моем банковском счете в первый день?**
О: Да, оплаченный капитал в размере 10 миллиардов IDR должен быть внесен для открытия банковского счета компании и завершения регистрации.

**В: Могу ли я использовать его после внесения?**
О: Да, после внесения в качестве акционерного капитала, вы используете эти средства для ведения бизнеса.

**В: Что, если я не смогу собрать 10 миллиардов IDR?**
О: Варианты включают:

- Совместное предприятие с местным партнером
- Другая структура бизнеса (представительство и т. д.)
- Подождать, пока у вас не будет достаточного капитала

**В: Есть ли какой-либо способ обойти минимум?**
О: Легального способа нет. Правила четко устанавливают минимум в 10 миллиардов IDR для PT PMA.

</InfoCard>
