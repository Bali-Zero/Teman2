# NIB Dijelaskan: Nomor Identifikasi Bisnis Indonesia Anda 2026

NIB (Nomor Induk Berusaha) adalah fondasi pendaftaran bisnis di Indonesia. Anggap saja ini sebagai kartu identitas nasional perusahaan Anda—dibutuhkan untuk hampir segala sesuatu.

## Apa yang Digantikan oleh NIB

NIB mengkonsolidasikan beberapa lisensi yang sebelumnya terpisah:

| Lisensi Lama             | Fungsi                 | Sekarang Bagian dari NIB |
| ------------------------ | ---------------------- | ------------------------ |
| **TDP**                  | Pendaftaran perusahaan | ✓ Diganti                |
| **API-U**                | ID importir umum       | ✓ Diganti                |
| **Angka Pengenal Impor** | Nomor impor            | ✓ Diganti                |
| **Akses ke bea cukai**   | Pelunasan impor        | ✓ Termasuk               |

<InfoCard variant="tip" title="Satu Nomor, Banyak Fungsi">
  NIB menyederhanakan pendaftaran bisnis. Alih-alih mendapatkan beberapa lisensi terpisah, Anda
  mendapatkan satu NIB yang berfungsi untuk berbagai tujuan. Ini merupakan peningkatan besar dari
  sistem sebelum tahun 2018.
</InfoCard>

## NIB dan Klasifikasi Risiko

Di bawah OSS RBA (Pendekatan Berbasis Risiko), NIB Anda menentukan izin tambahan apa yang Anda butuhkan:

| Tingkat Risiko    | NIB + Apa Lagi?                       |
| ----------------- | ------------------------------------- |
| **Rendah**        | NIB saja                              |
| **Rendah-Sedang** | NIB + Sertifikat Standar              |
| **Sedang-Tinggi** | NIB + Sertifikat Standar + Verifikasi |
| **Tinggi**        | NIB + Izin Lengkap (Lisensi)          |

<InfoCard variant="note" title="Risiko Ditentukan oleh KBLI">
  Kode kegiatan bisnis Anda (KBLI) menentukan tingkat risiko. Konsultasi teknologi biasanya berisiko
  rendah-sedang. Produksi makanan berisiko lebih tinggi. Sistem OSS secara otomatis
  mengklasifikasikan berdasarkan pemilihan kode KBLI Anda.
</InfoCard>
