# NIB Dijelaskan: Nomor Identitas Bisnis Anda di Indonesia 2026

NIB (Nomor Induk Berusaha) adalah fondasi utama pendaftaran bisnis di Indonesia. Bayangkan ini sebagai kartu ID nasional perusahaan Anda—diperlukan untuk hampir segala sesuatu.

## Apa yang Digantikan oleh NIB

NIB telah menggabungkan beberapa izin terpisah sebelumnya:

| Izin Lama              | Fungsi                  | Sekarang Bagian dari NIB |
| ---------------------- | ----------------------- | ------------------------- |
| **TDP**                | Pendaftaran perusahaan  | ✓ Digantikan              |
| **API-U**              | ID Importir Umum        | ✓ Digantikan              |
| **Angka Pengenal Impor** | Nomor impor            | ✓ Digantikan              |
| **Akses ke bea cukai** | Pembersihan impor       | ✓ Termasuk                |

<InfoCard variant="tip" title="Satu Nomor, Banyak Fungsi">

NIB menyederhanakan pendaftaran bisnis. Alih-alih mendapatkan berbagai izin terpisah, Anda hanya mendapatkan satu NIB yang melayani banyak tujuan. Ini adalah peningkatan besar dari sistem pra-2018.

</InfoCard>

## NIB dan Klasifikasi Risiko

Di bawah OSS RBA (Risk-Based Approach), NIB Anda menentukan izin tambahan apa yang diperlukan:

| Tingkat Risiko      | NIB + Apa Lagi?                        |
| -------------------- | -------------------------------------- |
| **Risiko Rendah**    | NIB saja                               |
| **Risiko Sedang-Rendah**  | NIB + Sertifikat Standar               |
| **Risiko Sedang-Tinggi**  | NIB + Sertifikat Standar + Verifikasi  |
| **Risiko Tinggi**     | NIB + Izin Lengkap                     |

<InfoCard variant="note" title="Risiko Ditentukan oleh KBLI">

Kode kegiatan bisnis Anda (KBLI) menentukan tingkat risiko. Konsultasi teknologi biasanya berisiko rendah-sedang. Produksi pangan memiliki risiko lebih tinggi. Sistem OSS secara otomatis mengklasifikasikan berdasarkan pilihan KBLI Anda.

</InfoCard>
