## Юридические требования

### Для иностранных инвесторов

<InfoCard variant="warning" title="PT PMA Required">
**Иностранные инвестиции в электронную коммерцию:**

- PT PMA необходима для значительных операций
- Требования к минимальным инвестициям
- Коды KBLI для деятельности в сфере электронной коммерции
- NIB через OSS
- Может потребоваться регистрация PPMSE

Нельзя просто работать неофициально как иностранец.

</InfoCard>

## Способы оплаты

### Популярные варианты

| Метод                                   | Использование                 |
| --------------------------------------- | ----------------------------- |
| Банковский перевод                      | Очень распространен           |
| Электронные кошельки (OVO, GoPay, Dana) | Быстро растет                 |
| Кредитные карты                         | Ограниченное проникновение    |
| COD (Наложенный платеж)                 | Все еще значителен            |
| Рассрочка                               | Популярна для крупных покупок |

<InfoCard variant="tip" title="Payment Strategy">
**Предложите несколько вариантов:**

- Банковский перевод (обязательно)
- Электронные кошельки (обязательно)
- Кредитные карты (для более дорогих покупок)
- COD (если вы можете управлять логистикой)

Индонезийцы предпочитают привычные способы оплаты.

</InfoCard>

## Налоговые обязательства

### Налог на электронную коммерцию

| Налог                    | Ставка           | Когда                    |
| ------------------------ | ---------------- | ------------------------ |
| Корпоративный подоходный | 22%              | Годовая прибыль          |
| НДС (PPN)                | 11%              | Если PKP, с продаж       |
| Удержание                | Различные        | С произведенных платежей |
| Комиссия платформы       | НДС не взимается | Комиссия платформе       |

<InfoCard variant="note" title="VAT on E-Commerce">
**Особенности НДС:**

- Порог: доход 4,8 млрд индонезийских рупий
- Необходимо зарегистрироваться как PKP
- Выдавать e-Faktur
- Платформа может обрабатывать для продаж на маркетплейсе
- Трансграничная торговля имеет другие правила
  </InfoCard>
