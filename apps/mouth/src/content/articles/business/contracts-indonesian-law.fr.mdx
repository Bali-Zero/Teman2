# Contrats Commerciaux en Droit Indonésien 2026

Les contrats sont essentiels pour les affaires, mais ils doivent être conformes au droit indonésien pour être exécutoires. Voici ce que vous devez savoir.

## Exigences Contractuelles

<InfoCard variant="note" title="Éléments d'un Contrat Valide">
Selon le Code Civil Indonésien (Article 1320), un contrat valide requiert :

1.  **Consentement** - Accord mutuel, donné librement
2.  **Capacité** - Parties légalement aptes à contracter
3.  **Objet spécifique** - Objet clair
4.  **Cause licite** - But légal

L'absence de l'un de ces éléments peut rendre le contrat nul ou annulable.

</InfoCard>

## Exigences Linguistiques

<InfoCard variant="warning" title="Loi sur la Langue Indonésienne">
En vertu de la **Loi 24/2009**, les contrats impliquant des parties indonésiennes **doivent être en indonésien**.

**Approche pratique :**

- Contrats bilingues (indonésien + anglais)
- La version indonésienne prévaut en cas de conflit
- Inclure une clause précisant quelle version régit

Ignorer cela peut créer des problèmes d'exécution.

</InfoCard>

### Meilleure Pratique

| Situation                      | Recommandation                      |
| :----------------------------- | :---------------------------------- |
| Les deux parties indonésiennes | Indonésien uniquement               |
| Une partie étrangère           | Bilingue                            |
| Les deux parties étrangères    | Anglais OK (mais l'indonésien aide) |
| Contrat de travail             | Doit inclure l'indonésien           |

## Droit de Timbre (Materai)

<InfoCard variant="note" title="Droit de Timbre Requis">
Le **Materai (droit de timbre)** est requis sur :
-   Contrats
-   Documents juridiques
-   Documents utilisés comme preuve devant les tribunaux

**Taux actuel :** 10 000 IDR par document

Sans un droit de timbre approprié, le document pourrait ne pas être recevable comme preuve.

</InfoCard>

### Comment Appliquer le Droit de Timbre

| Méthode         | Notes                                       |
| :-------------- | :------------------------------------------ |
| Timbre physique | Apposé et signé en travers                  |
| E-Materai       | Droit de timbre électronique                |
| Post-timbrage   | Peut être fait ultérieurement si nécessaire |

## Résolution des Litiges

### Options

| Méthode                | Avantages                      | Inconvénients             |
| :--------------------- | :----------------------------- | :------------------------ |
| Négociation            | Rapide, peu coûteux            | Pas d'exécution forcée    |
| Médiation              | Tiers neutre                   | Toujours non contraignant |
| Arbitrage (BANI)       | Contraignant, arbitres experts | Coûteux                   |
| Contentieux judiciaire | Exécution par l'État           | Lent, public              |

### Clause d'Arbitrage

<InfoCard variant="tip" title="Choisir l'Arbitrage">
Pour les contrats commerciaux importants :
-   Inclure une clause d'arbitrage
-   BANI (Indonésien) ou SIAC (Singapour)
-   Plus rapide que les tribunaux
-   Exécutoire à l'échelle internationale

Une clause type devrait spécifier :

- Institution (BANI, SIAC)
- Lieu
- Nombre d'arbitres
- Langue
  </InfoCard>

## Contrats Électroniques

<InfoCard variant="note" title="Contrats Électroniques Valides">
En vertu de la **Loi 11/2008** (Loi ITE) :
-   Les contrats électroniques sont valides
-   Les signatures électroniques sont reconnues
-   Doivent satisfaire à certaines exigences
-   Quelques exceptions (terres, héritage)

Les plateformes de signature numérique peuvent être utilisées pour la plupart des contrats commerciaux.

</InfoCard>

## Force Majeure

Le droit indonésien reconnaît la force majeure (keadaan kahar) :

- Événements échappant au contrôle
- Rendent l'exécution impossible
- Doivent être spécifiquement définis dans le contrat

Inclure des clauses de force majeure claires définissant :

- Quels événements sont éligibles
- Exigences de notification
- Effet sur les obligations
- Limites de durée
