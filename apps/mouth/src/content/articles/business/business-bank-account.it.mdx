## Banche Locali vs Internazionali

<InfoCard variant="note" title="Quale Scegliere?">
**Banche Locali (BCA, Mandiri):**
- Più filiali/bancomat
- Migliore integrazione locale
- Commissioni generalmente più basse
- Ideali per attività interna

**Banche Internazionali (HSBC, SCB):**

- Trasferimenti internazionali più facili
- Migliori per operazioni globali
- Minimi e commissioni più alti
- Servizio in inglese eccellente

**La maggior parte delle PT PMAs utilizza:** BCA o CIMB Niaga per le operazioni quotidiane, a volte una banca internazionale per i transfrontalieri.

</InfoCard>

## Processo di Apertura

### Passo dopo Passo

| Step                    | Cosa Accade              |
| ----------------------- | ------------------------- |
| 1. Scegliere banca      | Confrontare opzioni, posizione |
| 2. Incontro iniziale    | Discutere i requisiti     |
| 3. Invio documenti      | Pacchetto completo        |
| 4. Due diligence        | La banca verifica i documenti   |
| 5. Approvazione         | Di solito 1-3 settimane   |
| 6. Attivazione conto    | Firmare documenti, versamento   |
| 7. Configurazione home banking | Token, credenziali        |

### Tempistiche

| Fase                | Durata      |
| -------------------- | ------------- |
| Preparazione documenti | 1-2 settimane     |
| Revisione banca          | 1-3 settimane     |
| Approvazione             | 1-2 settimane     |
| **Totale**            | **3-6 settimane** |

<InfoCard variant="warning" title="Ritardi Comuni">
**Cosa rallenta il processo:**

- Documenti incompleti
- Direttore senza KITAS ancora
- Domande di conformità della banca
- Problemi di verifica dell'indirizzo
- Lacune nella documentazione degli azionisti

Preparati a fondo per evitare ritardi!

</InfoCard>

## Trasferimenti Internazionali

### Invio di Denaro all'Estero

<InfoCard variant="note" title="Controllo Valuta">
**L'Indonesia ha alcuni controlli:**

- Transazioni sopra USD 25K richiedono documenti sottostanti
- Potrebbe essere richiesta autorizzazione fiscale
- La banca riferisce alla banca centrale
- Documentazione corretta essenziale

Conserva tutte le fatture, contratti per i trasferimenti!

</InfoCard>

### Documenti Richiesti per Trasferimento in Uscita

| Per             | Documenti                  |
| --------------- | -------------------------- |
| Pagamento import  | Fattura, LC, documenti doganali  |
| Pagamento servizi | Contratto, fattura          |
| Dividendo        | Delibera del Consiglio, documenti fiscali |
| Restituzione prestito | Accordo di prestito             |

## Ricezione di Denaro

### Rimessa Inbound

| Requisito      | Dettagli                    |
| --------------- | -------------------------- |
| Fattura/contratto | Documento di supporto        |
| NPWP             | Numero fiscale aziendale    |
| Segnalazione     | Auto-segnalato sopra USD 10K |

### Consigli per una Ricezione Fluida

- Informa la banca dei grandi trasferimenti attesi
- Tieni pronti i documenti di supporto
- Allinea il riferimento del trasferimento alla fattura
- Assicurati che l'invia utilizzi i dettagli corretti

## Consigli per il Successo

<InfoCard variant="tip" title="Consigli per l'Apertura del Conto">
**Per un processo fluido:**

1. **Documenti completi prima** - Non inviare parziali
2. **Usa un segretario aziendale** - Conoscono i requisiti bancari
3. **Costruisci relazioni** - Il relationship manager aiuta
4. **Inizia presto** - Prima di averne urgente bisogno
5. **Considera una banca di backup** - Due conti è comune
6. **Mantieni documenti aggiornati** - Modifiche annuali all'atto

</InfoCard>

### Errori Comuni

| Errore                | Conseguenza         |
| --------------------- | -------------------- |
| Documenti incompleti  | Rifiuto/ritardi      |
| Direttore senza KITAS | Impossibile aprire   |
| Nome azienda sbagliato | Deve corrispondere esattamente |
| Versione atto vecchia | Deve essere attuale  |
| NPWP mancante         | Rifiuto immediato    |
