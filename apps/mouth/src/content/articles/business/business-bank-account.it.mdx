## Banche Locali vs Internazionali

<InfoCard variant="note" title="Quale Scegliere?">
**Banche Locali (BCA, Mandiri):**
- Più filiali/ATM
- Migliore integrazione locale
- Tariffe solitamente più basse
- Buone per affari domestici

**Banche Internazionali (HSBC, SCB):**

- Trasferimenti internazionali più facili
- Migliori per operazioni globali
- Minimi/tariffe più elevate
- Servizio in inglese eccellente

**La maggior parte delle PT PMA usa:** BCA o CIMB Niaga per operazioni quotidiane, a volte banca internazionale per cross-border.

</InfoCard>

## Processo di Apertura

### Passo dopo Passo

| Passo                            | Cosa Succede                  |
| -------------------------------- | ----------------------------- |
| 1. Scegli la banca               | Confronta opzioni, posizione  |
| 2. Incontro iniziale             | Discuti i requisiti           |
| 3. Presentazione documenti       | Pacchetto completo            |
| 4. Due diligence                 | La banca verifica i documenti |
| 5. Approvazione                  | Solitamente 1-3 settimane     |
| 6. Attivazione conto             | Firma documenti, deposito     |
| 7. Configurazione online banking | Token, credenziali            |

### Cronologia

| Fase                   | Durata            |
| ---------------------- | ----------------- |
| Preparazione documenti | 1-2 settimane     |
| Revisione banca        | 1-3 settimane     |
| Approvazione           | 1-2 settimane     |
| **Totale**             | **3-6 settimane** |

<InfoCard variant="warning" title="Ritardi Comuni">
**Cosa rallenta le cose:**

- Documenti incompleti
- Direttore senza KITAS ancora
- Domande compliance della banca
- Problemi verifica indirizzo
- Lacune documentazione azionisti

Prepara accuratamente per evitare ritardi!

</InfoCard>

## Trasferimenti Internazionali

### Invio Denaro all'Estero

<InfoCard variant="note" title="Controlli Valutari">
**L'Indonesia ha alcuni controlli:**

- Transazioni oltre USD 25K richiedono documenti sottostanti
- Potrebbe essere richiesta liquidazione fiscale
- La banca segnala alla banca centrale
- Documentazione corretta essenziale

Conserva tutte le fatture, contratti per i trasferimenti!

</InfoCard>

### Documenti Richiesti per Trasferimento in Uscita

| Per                    | Documenti                             |
| ---------------------- | ------------------------------------- |
| Pagamento importazione | Fattura, LC, documenti doganali       |
| Pagamento servizi      | Contratto, fattura                    |
| Dividendo              | Delibera consiglio, documenti fiscali |
| Rimborso prestito      | Contratto di prestito                 |

## Ricezione Denaro

### Rimessa in Entrata

| Requisito         | Dettagli                     |
| ----------------- | ---------------------------- |
| Fattura/contratto | Documento di supporto        |
| NPWP              | Numero fiscale aziendale     |
| Reporting         | Oltre USD 10K auto-segnalato |

### Suggerimenti per Ricezione Senza Intoppi

- Informa la banca di trasferimenti elevati previsti
- Abbi documenti di supporto pronti
- Fai corrispondere il riferimento di trasferimento alla fattura
- Assicurati che il mittente usi i dati corretti

## Suggerimenti per il Successo

<InfoCard variant="tip" title="Suggerimenti Apertura Conto">
**Per un processo fluido:**

1. **Documenti completi prima** — Non presentare parziali
2. **Usa segretaria societaria** — Conoscono i requisiti bancari
3. **Costruisci relazione** — Il relationship manager aiuta
