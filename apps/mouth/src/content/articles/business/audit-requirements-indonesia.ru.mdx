## Когда аудит обязателен?

Не каждой PT PMA в Индонезии требуется финансовый аудит. Требование зависит от размера компании, сектора и специфических характеристик. Понимание того, когда аудит обязателен, поможет вам соответствующим образом планировать и составлять бюджет.

### Критерии обязательного аудита согласно UU 40/2007

Статья 68 Закона о компаниях (UU 40/2007) требует аудита публичным бухгалтером для компаний, которые соответствуют любому из следующих критериев:

| Критерий                               | Порог                                 |
| :------------------------------------- | :------------------------------------ |
| Управление государственными средствами | Любая сумма (банки, пенсионные фонды) |
| Выпуск долговых инструментов           | Любая сумма (облигации, сукук)        |
| Годовой доход                          | Превышает 50 миллиардов IDR           |
| Общие активы                           | Превышают 100 миллиардов IDR          |
| Публично котируемые (IDX)              | Все котируемые компании               |
| Требуется законом/регулированием       | Требования, специфичные для сектора   |

### Обязательный аудит для конкретных секторов

| Сектор                                         | Регулятор   | Требование к аудиту                                 |
| :--------------------------------------------- | :---------- | :-------------------------------------------------- |
| Банковское дело                                | OJK         | Ежегодный аудит обязателен для всех банков          |
| Страхование                                    | OJK         | Ежегодный аудит обязателен                          |
| Компании по ценным бумагам                     | OJK         | Ежегодный аудит обязателен                          |
| Пенсионные фонды                               | OJK         | Ежегодный аудит обязателен                          |
| Финансовые компании                            | OJK         | Ежегодный аудит обязателен                          |
| Горнодобывающая промышленность (держатели IUP) | ESDM        | Ежегодный аудит для компаний на стадии производства |
| Публичные компании (Tbk)                       | OJK/IDX     | Ежегодный и полугодовой аудит                       |
| Компании, получающие государственные гранты    | Различные   | Согласно грантовому соглашению                      |
| НПО/фонды                                      | Kemenkumham | При управлении публичными пожертвованиями           |

### Практическая оценка для PT PMA на Бали

Для большинства малых и средних компаний PT PMA на Бали (гостиничный бизнес, F&B, консалтинг, технологии, туризм) честная оценка такова:

**Вероятно, не требуется**, если:

- Годовой доход ниже 50 миллиардов IDR (приблизительно 3 миллиона долларов США)
- Общие активы ниже 100 миллиардов IDR
- Не относится к регулируемому сектору
- Не является публичной компанией

**Определенно требуется**, если:

- Доход превышает 50 миллиардов IDR
- В банковской, страховой или финансовой сфере
- Подготовка к IPO
- По решению суда (например, споры акционеров)

## Виды аудита

### Обязательный аудит (Audit Wajib)

Обязательный ежегодный аудит, требуемый законом. Это аудит полного объема, результатом которого является заключение о финансовой отчетности.

### Добровольный аудит (Audit Sukarela)

Аудит, проводимый по выбору, а не по требованию закона. Причины включают:

- Требования банка к кредиту
- Комплексная проверка инвесторов
- Внутреннее управление
- Доверие деловых партнеров
- Подготовка к будущим регуляторным требованиям

### Налоговый аудит (Pemeriksaan Pajak)

Проводится DJP, а не внешними аудиторами. Это государственная налоговая проверка, а не аудит финансовой отчетности. Однако наличие аудированной финансовой отчетности значительно помогает во время налоговых аудитов.

### Аудит специального назначения

Аудиты для конкретных целей, таких как:

- Комплексная проверка для сделок M&A
- Аудиты соответствия конкретным нормативным актам
- Судебно-бухгалтерские аудиты для расследования мошенничества
- Согласованные процедуры для конкретных областей

## Процесс аудита

### Фаза 1: Планирование и заключение договора (2-4 недели)

| Шаг                 | Детали                                                                    |
| :------------------ | :------------------------------------------------------------------------ |
| Письмо о соглашении | Аудитор и компания договариваются об объеме, сроках, гонорарах            |
| Оценка рисков       | Аудитор выявляет области наибольшего риска                                |
| Существенность      | Устанавливает порог для значительных ошибок                               |
| План аудита         | Подробные процедуры тестирования для каждой области финансовой отчетности |

### Фаза 2: Полевые работы (4-8 недель)

Команда аудитора посещает ваш офис и выполняет:

**Существенное тестирование:**

- Выборочная проверка операций по продажам и признания выручки
- Проверка банковских остатков (банковские подтверждения)
- Подтверждения дебиторской задолженности (непосредственно с клиентами)
- Физический пересчет запасов (если применимо)
- Проверка основных средств
- Проверка документации по расходам
- Тестирование налогового соответствия
- Проверка операций со связанными сторонами
- Проверка контрактов и обязательств

**Тестирование контроля:**

- Оценка внутренних контролей над финансовой отчетностью
- Тестирование процедур авторизации и утверждения
- Проверка разделения обязанностей
- Оценка контролей ИТ-систем

### Фаза 3: Обзор и отчетность (2-4 недели)

| Шаг                                 | Детали                                                      |
| :---------------------------------- | :---------------------------------------------------------- |
| Проект выводов                      | Аудитор представляет предварительные выводы руководству     |
| Ответы руководства                  | Компания отвечает на выводы и корректировки                 |
| Корректирующие записи               | Согласование корректировок финансовой отчетности            |
| Окончательная финансовая отчетность | Подготовка пересмотренной отчетности с учетом корректировок |
| Аудиторское заключение              | Аудитор выдает официальное заключение                       |
| Письмо руководству                  | Отдельное письмо с рекомендациями по улучшению              |

### Фаза 4: Доставка

Окончательные результаты включают:

- Аудированная финансовая отчетность с аудиторским заключением
- Письмо руководству с выводами и рекомендациями
- Список корректирующих бухгалтерских записей
- Сводка нескорректированных расхождений (если таковые имеются)

## Аудиторские заключения

Заключение аудитора указывает на уровень доверия к финансовой отчетности:

| Заключение                                                | Значение                                               | Следствие                                 |
| :-------------------------------------------------------- | :----------------------------------------------------- | :---------------------------------------- |
| Безусловно-положительное (Wajar Tanpa Pengecualian / WTP) | Финансовая отчетность достоверно представлена          | Наилучший возможный результат             |
| Условно-положительное (Wajar Dengan Pengecualian / WDP)   | В целом достоверна, за исключением конкретных вопросов | Приемлемо, но проблемы должны быть решены |
| Отрицательное (Tidak Wajar)                               | Финансовая отчетность существенно искажена             | Серьезная проблема; отчетность ненадежна  |
| Отказ от выражения мнения (Tidak Memberikan Pendapat)     | Аудитор не может сформировать мнение                   | Обычно из-за ограничений объема           |

**Цель:** Каждая PT PMA должна стремиться к безусловно-положительному (WTP) заключению. Условно-положительное или отрицательное заключение может повлиять на банковское финансирование, доверие инвесторов и регуляторный статус.

## Типичные аудиторские выводы для PT PMA

### Вывод 1: Недостаточная документация по трансфертному ценообразованию

**Проблема:** Операции со связанными сторонами (материнская компания, аффилированные лица) без надлежащей документации по принципу "вытянутой руки".
**Решение:** Ежегодно готовить местный файл по трансфертному ценообразованию.

### Вывод 2: Несогласованные налоговые счета

**Проблема:** Остатки авансовых платежей по налогам и кредиторской задолженности по налогам в книгах не соответствуют фактическим налоговым декларациям и платежам.
**Решение:** Ежемесячная сверка налогов (см. наше [руководство по бухгалтерскому учету](/insights/monthly-bookkeeping-indonesia)).

### Вывод 3: Отсутствие отсечения выручки

**Проблема:** Выручка признана в неправильном периоде (услуги за декабрь выставлены в январе или наоборот).
**Решение:** Внедрить надлежащие процедуры признания выручки и анализ отсечения.

### Вывод 4: Необоснованные требования по расходам

**Проблема:** Расходы без надлежащей подтверждающей документации (квитанции, счета-фактуры, контракты).
**Решение:** Внедрить политику "нет квитанции – нет возмещения" и поддерживать организованные архивы документов.

### Вывод 5: Расхождения в основных средствах

**Проблема:** Физические активы не соответствуют реестру основных средств (отсутствующие позиции, выбывшие, но не удаленные из книг).
**Решение:** Ежегодная физическая проверка активов и обновление реестра.

## Часто задаваемые вопросы

### Сколько стоит аудит PT PMA в Индонезии?

Стоимость аудита значительно варьируется в зависимости от размера фирмы и сложности компании. Местные KAP (аудиторские фирмы): 30-100 миллионов IDR для малых и средних PT PMA. Международные аффилированные компании среднего уровня (BDO, Grant Thornton, RSM): 80-200 миллионов IDR. Фирмы "Большой четверки" (Deloitte, EY, KPMG, PwC): 200-500+ миллионов IDR. Стоимость зависит от размера выручки, объема транзакций, количества сотрудников и сложности отрасли.

### Может ли PT PMA выбрать аудит, даже если он не требуется?

Да. Добровольные аудиты распространены для компаний PT PMA, которые хотят: обеспечить банковское финансирование (многие банки требуют аудированную отчетность для кредитов свыше 1 миллиарда IDR), привлечь инвесторов, продемонстрировать доверие деловым партнерам или подготовиться к будущим регуляторным требованиям. Добровольный аудит соответствует тем же профессиональным стандартам, что и обязательный.

### Что произойдет, если PT PMA, которой требуется аудит, не получит его?

Несоблюдение обязательных требований к аудиту может привести к: отклонению DJP корпоративной налоговой декларации (SPT Badan), штрафам от OJK для регулируемых организаций, судебным искам акционеров (миноритарные акционеры могут оспаривать неаудированную финансовую отчетность), трудностям с получением банковских кредитов и потенциальным проблемам с продлением бизнес-лицензий.
