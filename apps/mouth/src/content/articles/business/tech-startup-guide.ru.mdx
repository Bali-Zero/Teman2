# Технологический стартап в Indonesia 2026: Руководство для иностранных основателей

Indonesia является крупнейшей стартап-экосистемой Юго-Восточной Азии с такими единорогами, как Gojek, Tokopedia и Traveloka. Вот как иностранные основатели могут построить здесь бизнес.

## Почему Indonesia для технологий?

- Население **270 миллионов**
- **200+ миллионов** интернет-пользователей
- **Средний возраст 29** - молодые, технически подкованные
- **Растущий средний класс**
- **Mobile-first рынок**
- **Активная венчурная экосистема**

## KBLI коды для технологий

| Код   | Деятельность                        | Примечания            |
| ----- | ----------------------------------- | --------------------- |
| 62011 | Разработка программного обеспечения | Приложения, платформы |
| 62012 | Системная интеграция                | Предприятия           |
| 62021 | ИТ-консалтинг                       | Консультации          |
| 63111 | Обработка данных                    | Аналитика             |
| 63112 | Веб-хостинг                         | Инфраструктура        |
| 63122 | Веб-портал                          | Торговые площадки     |

<InfoCard variant="tip" title="Меньше инвестиций для технологий">
  Некоторые KBLI коды для технологий (особенно 62011, 62012) могут иметь более
  низкие требования к инвестициям, чем стандартные 10 миллиардов IDR. Проверьте
  текущие требования OSS для вашей конкретной деятельности.
</InfoCard>

## Найм в Indonesia

### Местные таланты

- Сильные инженерные таланты, особенно в Jakarta
- Более низкие затраты, чем в Singapore
- Растущий пул опытных сотрудников стартапов
- Знание английского языка варьируется

### Основы трудоустройства

| Требование                   | Примечания                               |
| ---------------------------- | ---------------------------------------- |
| BPJS Kesehatan               | Медицинское страхование (обязательное)   |
| BPJS Ketenagakerjaan         | Страхование занятости (обязательное)     |
| Минимальная заработная плата | По провинциям (Jakarta ~5 млн IDR/месяц) |
| Контракты                    | Срочные или постоянные                   |
| Выходное пособие             | Значительное при увольнениях             |

### Иностранные сотрудники

Найм иностранных технических специалистов:

- RPTKA требуется для каждой должности
- Ежемесячная плата DKP-TKA 100 долларов США
- Должны обучать индонезийского коллегу
- Обычно ограничивается руководящими/специализированными должностями

## Технические регламенты

### PSE (Оператор электронной системы)

Все технологические платформы должны зарегистрироваться:

- Обязательно для работы в Indonesia
- Требования к локализации данных
- Обязательства по модерации контента
- Положения о доступе правительства

### Защита данных

- В Indonesia действует закон о защите персональных данных
- Требования к обработке данных
- Обязательства по согласию и безопасности
- Штрафы за несоблюдение

### Специально для финтеха

Если вы создаете финтех:

- Требуется лицензирование OJK
- Доступны песочницы
- Требования к капиталу
- Регулярная отчетность
