## I cinque rendiconti finanziari obbligatori

Gli standard contabili indonesiani richiedono alle società PT PMA di preparare un set completo di cinque rendiconti finanziari alla fine di ogni anno fiscale. Questi documenti raccontano lo stato di salute finanziaria della vostra azienda e sono utilizzati dalle autorità fiscali, dalle banche, dagli investitori e dalle autorità di regolamentazione.

| Prospetto                       | Nome Indonesiano                                    | Scopo                                                |
| ------------------------------- | --------------------------------------------------- | ---------------------------------------------------- |
| Stato Patrimoniale              | Laporan Posisi Keuangan                             | Istantanea di attività, passività e patrimonio netto |
| Conto Economico                 | Laporan Laba Rugi dan Penghasilan Komprehensif Lain | Ricavi, costi e utile netto                          |
| Rendiconto Finanziario          | Laporan Arus Kas                                    | Entrate e uscite di cassa                            |
| Variazioni del Patrimonio Netto | Laporan Perubahan Ekuitas                           | Movimenti di capitale e utili portati a nuovo        |
| Note                            | Catatan Atas Laporan Keuangan                       | Spiegazioni e principi contabili                     |

## Prospetto 1: Stato Patrimoniale (Laporan Posisi Keuangan)

Lo stato patrimoniale mostra ciò che l'azienda possiede, i suoi debiti e il suo valore in un momento specifico (solitamente il 31 dicembre).

### Struttura

**Attività (Aset)**

| Categoria                                 | Sottocategorie                     | Esempi                                            |
| ----------------------------------------- | ---------------------------------- | ------------------------------------------------- |
| Attività Correnti (Aset Lancar)           | Cassa e disponibilità              | Conti bancari, piccola cassa                      |
|                                           | Crediti verso clienti              | Fatture clienti in sospeso                        |
|                                           | Rimanenze                          | Materie prime, prodotti finiti                    |
|                                           | Risconti attivi                    | Affitto pagato in anticipo, assicurazione         |
|                                           | Acconti d'imposta                  | Rate PPh 25, IVA a credito (VAT input)            |
| Attività Non Correnti (Aset Tidak Lancar) | Immobilizzazioni materiali (nette) | Attrezzature, veicoli, migliorie su beni di terzi |
|                                           | Immobilizzazioni immateriali       | Licenze software, marchi                          |
|                                           | Investimenti immobiliari           | Immobili locati                                   |
|                                           | Depositi a lungo termine           | Depositi cauzionali                               |

**Passività (Kewajiban)**

| Categoria                             | Sottocategorie                  | Esempi                               |
| ------------------------------------- | ------------------------------- | ------------------------------------ |
| Passività Correnti (Kewajiban Lancar) | Debiti verso fornitori          | Fatture fornitori non pagate         |
|                                       | Debiti tributari                | PPh 21, 23, 25, PPN dovuta           |
|                                       | BPJS Payable                    | Kesehatan e Ketenagakerjaan          |
|                                       | Ratei passivi                   | Salari, utenze, interessi            |
|                                       | Prestiti a breve termine        | Scoperti bancari, linee di credito   |
| Passività Non Correnti                | Prestiti a lungo termine        | Prestiti bancari, finanziamenti soci |
|                                       | Passività per imposte differite | Differenze temporali                 |
|                                       | Benefici per i dipendenti       | Obbligazioni post-impiego            |

**Patrimonio Netto (Ekuitas)**

| Componente                  | Descrizione                              |
| --------------------------- | ---------------------------------------- |
| Capitale autorizzato        | Totale capitale per atto costitutivo     |
| Capitale versato            | Capitale effettivamente depositato       |
| Riserva sovrapprezzo azioni | Sovrapprezzo rispetto al valore nominale |
| Utili portati a nuovo       | Utili accumulati non distribuiti         |
| Utile/perdita d'esercizio   | Utile netto dell'anno                    |

**L'equazione di bilancio deve sempre quadrare:** Attività = Passività + Patrimonio Netto

## Prospetto 2: Conto Economico (Laporan Laba Rugi)

Il conto economico mostra i ricavi, i costi e l'utile netto dell'azienda durante l'anno fiscale.

### Formato Standard

```
Ricavi (Pendapatan Usaha)
  Ricavi da vendite / servizi                 IDR xxx
  Meno: Resi e sconti sulle vendite          (IDR xxx)
  Ricavi netti                                IDR xxx

Costo del venduto (Beban Pokok Pendapatan)
  Costi diretti                              (IDR xxx)
  Utile lordo (Laba Kotor)                    IDR xxx

Spese operative (Beban Operasional)
  Salari e benefici                          (IDR xxx)
  Affitto                                    (IDR xxx)
  Utenze                                     (IDR xxx)
  Ammortamento e svalutazione                (IDR xxx)
  Marketing e pubblicità                     (IDR xxx)
  Compensi professionali                     (IDR xxx)
  Materiale d'ufficio                        (IDR xxx)
  Assicurazione                              (IDR xxx)
  Viaggi e trasporti                         (IDR xxx)
  Altre spese operative                      (IDR xxx)
  Totale spese operative                     (IDR xxx)

Utile operativo (Laba Operasional)             IDR xxx

Altri proventi/(oneri)
  Interessi attivi                            IDR xxx
  Interessi passivi                          (IDR xxx)
  Utili/(perdite) su cambi                    IDR xxx
  Altri proventi/(oneri)                      IDR xxx
  Totale altri proventi/(oneri)              (IDR xxx)

Utile ante imposte (Laba Sebelum Pajak)        IDR xxx
  Imposta sul reddito                        (IDR xxx)
Utile netto (Laba Bersih)                      IDR xxx
```

### Considerazioni Chiave

**Riconoscimento dei ricavi:** I ricavi vengono rilevati quando il servizio viene prestato o i beni vengono trasferiti al cliente, non quando viene ricevuto il pagamento (principio di competenza).

**Deducibilità dei costi:** Non tutti i costi nel conto economico civilistico sono deducibili ai fini fiscali. La riconciliazione fiscale rettifica per:

- Spese di rappresentanza (necessitano di una lista dettagliata/nominatif)
- Donazioni (deducibilità limitata)
- Differenze di ammortamento (aliquote civilistiche vs fiscali)
- Multe e sanzioni (non deducibili)
- Benefici per i dipendenti che non soddisfano i criteri fiscali

## Prospetto 3: Rendiconto Finanziario (Laporan Arus Kas)

Il rendiconto finanziario mostra i movimenti effettivi di cassa, suddivisi in tre attività:

### Attività Operative

Flussi di cassa derivanti dalle normali operazioni aziendali:

- Incassi da clienti
- Pagamenti a fornitori e dipendenti
- Pagamenti fiscali
- Interessi pagati e ricevuti

### Attività di Investimento

Flussi di cassa derivanti dall'acquisto/vendita di attività a lungo termine:

- Acquisto di attrezzature o immobili
- Proventi da vendite di beni
- Investimenti in sussidiarie o titoli

### Attività di Finanziamento

Flussi di cassa derivanti da operazioni sul capitale e sul debito:

- Iniezione di capitale dai soci
- Proventi e rimborsi di prestiti
- Pagamento di dividendi

### Metodi

Le PT PMA possono utilizzare:

- **Metodo diretto:** Elenca gli incassi e i pagamenti effettivi (preferito dal DJP)
- **Metodo indiretto:** Parte dall'utile netto e rettifica per le voci non monetarie

## Prospetto 5: Note al Bilancio

Le note forniscono il contesto essenziale e rappresentano in realtà la parte più consistente del bilancio. Devono includere:

### Informative obbligatorie

1. **Panoramica aziendale:** Nome, forma legale, data di costituzione, attività aziendali
2. **Principi contabili:** Sintesi dei metodi contabili significativi utilizzati
3. **Politica di riconoscimento dei ricavi:** Come vengono rilevati i ricavi
4. **Politica sui cespiti fissi:** Metodi di ammortamento e vite utili
5. **Politica sulle valute estere:** Trattamento dei tassi di cambio
6. **Riconosciliazione fiscale:** Riconosciliazione tra utile civilistico e fiscale
7. **Operazioni con parti correlate:** Operazioni con soci, amministratori, affiliate
8. **Passività potenziali:** Cause legali pendenti, controversie fiscali, garanzie
9. **Fatti intervenuti dopo la chiusura dell'esercizio:** Eventi significativi dopo la fine dell'anno
10. **Valutazione della continuità aziendale:** Se applicabile

## Bilancio Civilistico vs. Fiscale

### Perché due versioni?

La legge fiscale indonesiana differisce dagli standard contabili SAK in diverse aree. Le PT PMA devono preparare:

1. **Bilancio civilistico:** Secondo SAK/PSAK per la rendicontazione aziendale
2. **Bilancio fiscale:** Rettificato per la conformità alla legge fiscale

### Differenze Chiave

| Voce                        | Civilistico (SAK)             | Fiscale (Tasse)                        |
| --------------------------- | ----------------------------- | -------------------------------------- |
| Ammortamento - Edifici      | Flessibile (stima vita utile) | 5% annuo (20 anni)                     |
| Ammortamento - Veicoli      | Flessibile                    | 12,5% annuo (8 anni)                   |
| Ammortamento - Attrezzature | Flessibile                    | 25% annuo (4 anni)                     |
| Spese di rappresentanza     | Interamente spesate           | Obbligo di lista nominatif             |
| Benefici per i dipendenti   | Accantonati per competenza    | Deducibili se pagati                   |
| Svalutazione crediti        | In base a valutazione         | Criteri specifici richiesti            |
| Donazioni                   | Spesate                       | Deducibilità limitata                  |
| Multe e sanzioni            | Spesate                       | Non deducibili                         |
| Auto aziendale (uso pers.)  | Ammortamento totale           | 50% ammortamento + 50% costi operativi |

### Esempio di Riconosciliazione Fiscale

```
Utile civilistico ante imposte            IDR 500.000.000

Variazioni in aumento:
  Rappresentanza senza lista nominatif    IDR  20.000.000
  Differenza di ammortamento              IDR  15.000.000
  Benefici dipendenti (non ancora pagati) IDR  10.000.000
  Sanzioni e multe                        IDR   5.000.000
  Subtotale                               IDR  50.000.000

Variazioni in diminuzione:
  Eccedenza ammortamento fiscale         (IDR   8.000.000)
  Subtotale                              (IDR   8.000.000)

Utile fiscale ante imposte                IDR 542.000.000
Imposta sul reddito delle società (22%)   IDR 119.240.000
```

## Requisiti di Deposito e Scadenze

### Dichiarazione dei Redditi Societaria Annuale (SPT Tahunan PPh Badan)

| Requisito            | Dettaglio                                                |
| -------------------- | -------------------------------------------------------- |
| Scadenza deposito    | 30 aprile dell'anno successivo                           |
| Proroga possibile    | Fino a 2 mesi (richiesta entro il 30 aprile)             |
| Allegati richiesti   | Bilancio, riconciliazione fiscale, prospetti di supporto |
| Metodo di deposito   | DJP Online (e-Filing) o applicazione e-SPT               |
| Sanzione per ritardo | 1.000.000 IDR                                            |

### Report LKPM

I dati finanziari devono essere riportati trimestralmente anche tramite LKPM:

- Dati su ricavi e produzione
- Realizzazione del capitale
- Dati sull'occupazione
- Stato dell'investimento

### RUPS (Assemblea Annuale dei Soci)

Il bilancio deve essere presentato e approvato dai soci durante il RUPS annuale entro 6 mesi dalla fine dell'anno fiscale (entro il 30 giugno per le società con anno solare).

## Cronoprogramma di Preparazione

| Mese     | Attività                                                      |
| -------- | ------------------------------------------------------------- |
| Gennaio  | Chiusura libri di dicembre, preparazione bilancio di verifica |
| Febbraio | Bozza del bilancio, controlli preliminari                     |
| Marzo    | Finalizzazione del bilancio civilistico                       |
| Marzo    | Preparazione della riconciliazione fiscale                    |
| Marzo    | Incarico al revisore (se richiesto)                           |
| Aprile   | Invio SPT Tahunan PPh Badan con bilancio                      |
| Giugno   | RUPS con bilancio approvato                                   |

## Errori Comuni nella Preparazione del Bilancio

### Errore 1: Principi contabili incoerenti

Cambiare i metodi di ammortamento o le politiche di riconoscimento dei ricavi tra un anno e l'altro senza informativa crea segnali di allarme per gli audit e problemi fiscali.

### Errore 2: Mancata informativa sulle parti correlate

Le operazioni con soci, amministratori o società affiliate devono essere indicate nelle note. Il DJP presta particolare attenzione ai prezzi di trasferimento (transfer pricing) tra parti correlate.

### Errore 3: Trattamento errato dei cambi esteri

Tutti i saldi in valuta estera devono essere rideterminati al tasso medio BI al 31 dicembre. Gli utili/perdite su cambi non realizzati devono essere rilevati. Molte aziende dimenticano di rideterminare i crediti/debiti in USD a fine anno.

### Errore 4: Mancata riconciliazione dei conti fiscali

I saldi delle imposte da pagare nello stato patrimoniale devono corrispondere alle effettive obbligazioni fiscali. Un errore comune è avere acconti PPh 25 che non si riconciliano con i pagamenti effettivi.

### Errore 5: Omissione delle obbligazioni per benefici ai dipendenti

Secondo il PSAK 24 (benefici per i dipendenti), le società devono calcolare e indicare le obbligazioni per benefici post-impiego. Anche se il calcolo è irrilevante, l'informativa è richiesta.

## Domande Frequenti

### Quali sono le scadenze per il bilancio della PT PMA?

Il bilancio annuale deve essere preparato entro la fine del primo trimestre (31 marzo) per l'anno fiscale precedente. Viene presentato al DJP come parte dell'SPT Tahunan PPh Badan (dichiarazione dei redditi societaria) entro il 30 aprile. Le società soggette a revisione contabile devono avere il bilancio certificato pronto entro la scadenza del RUPS (entro 6 mesi dalla fine dell'esercizio, ovvero il 30 giugno).

### Una PT PMA deve usare il PSAK completo o può usare standard semplificati?

La maggior parte delle società PT PMA private può utilizzare il SAK ETAP (standard semplificati per entità senza responsabilità pubblica). Il PSAK completo è richiesto solo per le società quotate in borsa, le istituzioni finanziarie e le società che intendono quotarsi. Il SAK EMKM è disponibile per le micro e piccole entità, ma raramente si applica alle PT PMA a causa dei loro requisiti minimi di capitale.

### Qual è la differenza tra bilancio civilistico e fiscale?

Il bilancio civilistico (commerciale) segue gli standard contabili SAK/PSAK per una rendicontazione aziendale accurata. Il bilancio fiscale è una versione rettificata conforme alla legge fiscale indonesiana, che prevede regole diverse per le aliquote di ammortamento, le deduzioni ammesse e il riconoscimento dei ricavi. Le PT PMA devono preparare entrambi e includere una riconciliazione fiscale nella dichiarazione dei redditi.
