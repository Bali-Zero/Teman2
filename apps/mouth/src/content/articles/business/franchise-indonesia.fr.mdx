## Réglementations sur les Franchises

### Exigences Clés

<InfoCard variant="note" title="Enregistrement Gouvernemental">
**Les franchises doivent être enregistrées :**

- STPW (Surat Tanda Pendaftaran Waralaba)
- Requis pour le franchiseur
- Enregistrer dans les 30 jours suivant le début des activités
- Renouvellement requis

Opérer sans enregistrement est illégal.

</InfoCard>

### Cadre Réglementaire

| Réglementation                         | Couvre                                |
| -------------------------------------- | ------------------------------------- |
| Réglementation gouvernementale 42/2007 | Définition de la franchise, exigences |
| Réglementation ministérielle 71/2019   | Procédures d'enregistrement           |
| Ministre du Commerce                   | Surveillance continue                 |

## Franchises Étrangères

### Introduire une Marque Étrangère en Indonésie

<InfoCard variant="warning" title="Règles pour les Franchises Étrangères">
**Exigences pour les marques étrangères :**

- Contrat de master franchise
- Une PT PMA est généralement requise
- Enregistrer la franchise en Indonésie
- Un partenaire local peut être nécessaire
- Exigences de localisation
- Règles d'approvisionnement local (80% pour certains articles)

Les franchiseurs étrangers doivent s'adapter aux réglementations indonésiennes.

</InfoCard>

### Exigences de Contenu Local

| Exigence          | Détails                                          |
| ----------------- | ------------------------------------------------ |
| Produits locaux   | 80% pour certains articles de restauration (F&B) |
| Partenariat local | Peut être requis pour certains secteurs          |
| Gestion locale    | Implication indonésienne                         |
| Enregistrement    | En Indonésie                                     |

## Enregistrement STPW

### Processus pour les Franchiseurs

| Étape                               | Durée             |
| ----------------------------------- | ----------------- |
| Préparer les documents              | 2-4 semaines      |
| Soumettre la demande                | 1 semaine         |
| Examen par le Ministère du Commerce | 2-4 semaines      |
| STPW délivré                        | Après approbation |
| Valide pour                         | 5 ans             |

### Documents Requis

| Document                           | Détails                  |
