## L'avantage du multi-code

La plupart des entrepreneurs étrangers à Bali créent une PT PMA avec un seul code KBLI. Cela fonctionne pour les entreprises simples. Mais dès que vos opérations couvrent plus d'une activité — construire des villas _et_ les louer, gérer un restaurant _et_ vendre des produits en ligne, écrire des logiciels _et_ concevoir des marques — vous avez besoin d'une stratégie multi-code.

La loi indonésienne permet à une PT PMA d'enregistrer plusieurs codes KBLI sur un seul NIB (Nomor Induk Berusaha). Ce n'est pas une échappatoire. C'est le mécanisme prévu pour les entreprises ayant des opérations intégrées verticalement ou horizontalement. La question n'est pas de savoir si vous _pouvez_ enregistrer plusieurs codes, mais si vous _devriez_ — et quelles combinaisons créent une protection juridique ou des maux de tête en matière de conformité.

## Comment fonctionne l'enregistrement multi-KBLI

Lorsque vous enregistrez une PT PMA via OSS (Online Single Submission), vous sélectionnez un ou plusieurs codes KBLI à cinq chiffres qui décrivent vos activités commerciales. Chaque code correspond à une classification de risque spécifique (faible, moyen-faible, moyen-élevé ou élevé) et détermine les licences, permis et obligations de conformité applicables.

Mécanismes clés :

- **Un NIB, plusieurs codes.** Tous les codes KBLI sont enregistrés sous un seul NIB. Vous n'avez pas besoin d'entités commerciales distinctes pour des activités distinctes.
- **Le seuil d'investissement est agrégé.** L'exigence d'investissement minimum de 10 milliards IDR pour une PT PMA couvre _tous_ les codes enregistrés combinés — et non par code. Une entreprise avec trois codes KBLI n'a toujours besoin que de 10 milliards IDR au total.
- **Le niveau de risque suit le code le plus élevé.** Si vous enregistrez trois codes à faible risque et un code à risque élevé, l'ensemble de votre NIB est classé comme à risque élevé. Cela déclenche des exigences de conformité supplémentaires à tous les niveaux.
- **Chaque code doit être réel.** Enregistrer un code KBLI que vous n'exécutez pas réellement est une violation réglementaire. OSS et l'autorité fiscale (DJP) peuvent recouper vos codes enregistrés avec vos flux de revenus réels.

## Comprendre les implications du niveau de risque

La classification des risques est le facteur le plus important dans une stratégie multi-code. Elle détermine votre parcours de licence, la fréquence des inspections et la charge de déclaration.

### La règle du "le risque le plus élevé l'emporte"

Le niveau de risque global de votre NIB est défini par le **code à risque le plus élevé** que vous enregistrez. Ce n'est pas une moyenne — c'est une fonction plafond. Voici comment les niveaux de risque se traduisent en obligations de conformité :

**Faible risque** — NIB uniquement. Aucune licence supplémentaire requise. Auto-certification suffisante. Rapports minimaux.

**Risque moyen-faible** — NIB + Certificat standard (Sertifikat Standar). Conformité auto-déclarée aux normes sectorielles. Auto-déclaration périodique.

**Risque moyen-élevé** — NIB + Certificat standard avec vérification. Vérification gouvernementale requise avant le début des opérations. Inspections régulières.

**Risque élevé** — NIB + licence complète (Izin). Approbation gouvernementale pré-opérationnelle. Inspections fréquentes. Permis sectoriels supplémentaires (par exemple, évaluation de l'impact environnemental pour la construction, approbation du ministère de la Santé pour le bien-être).

### Exemple pratique

Considérez une agence numérique qui écrit du code (62019, faible risque) et conçoit des graphiques (74130, faible risque). Leur NIB est à faible risque. La conformité est minimale.

Supposons maintenant que la même agence décide d'ajouter le conseil en gestion (70209, risque moyen-faible) pour formaliser les services de conseil qu'elle fournit déjà. L'ensemble du NIB passe à moyen-faible. Ils ont maintenant besoin d'un Certificat standard.

S'ils ajoutent ensuite la production cinématographique (59111, moyen-élevé dans certaines classifications), le NIB change à nouveau. Chaque étape ajoute de la paperasse, des exigences de vérification et une exposition potentielle aux inspections.

La leçon : n'ajoutez jamais un code "au cas où". Chaque code que vous enregistrez a un coût de conformité, et ce coût est déterminé par le code le plus risqué de votre NIB.

## Le seuil d'investissement : un seul pool, tous les codes

L'un des aspects les plus mal compris de l'enregistrement multi-KBLI est l'exigence d'investissement. En vertu du PP 5/2021 sur les licences commerciales basées sur les risques, le minimum d'investissement de 10 milliards IDR s'applique à **l'entité PT PMA dans son ensemble**, et non par code KBLI.

Cela signifie :

- Une PT PMA avec un code KBLI a besoin de 10 milliards IDR d'investissement engagé.
- Une PT PMA avec cinq codes KBLI a _également_ besoin de 10 milliards IDR d'investissement engagé.
- L'investissement peut être déployé sur n'importe quelle combinaison de vos activités enregistrées.
- Il n'y a aucune exigence d'allouer une portion spécifique de l'investissement à chaque code.

Cela crée un avantage structurel significatif pour l'enregistrement multi-code. Au lieu de créer trois PT PMA distinctes (chacune nécessitant 10 milliards IDR, totalisant 30 milliards IDR de capital engagé), vous pouvez exploiter les trois activités sous une seule entité avec un engagement unique de 10 milliards IDR.

Cependant, l'investissement doit être crédible. OSS et BKPM examinent les plans d'investissement, et les 10 milliards IDR doivent être réalistement déployables sur vos activités déclarées. L'enregistrement de dix codes avec un plan qui ne finance que deux soulèvera des questions lors de la vérification.

## Synergies de codes : quand le multi-code crée de la valeur

Les meilleures stratégies multi-codes suivent la logique de l'intégration verticale ou de l'adjacence commerciale naturelle. Ce sont des combinaisons où les activités se nourrissent réellement les unes des autres :

### Intégration verticale

Un promoteur de villas (41017) qui exploite également les villas achevées (55193) et gère le portefeuille immobilier (68111) a une chaîne verticale claire : construire, exploiter, gérer. Chaque code représente une phase distincte du même modèle commercial. Les régulateurs comprennent immédiatement cette logique.

### Adjacence horizontale

Une entreprise de tourisme (79111) qui gère également des hébergements (55199) et des restaurants (56101) opère sur toute la chaîne de valeur de l'hôtellerie. Les clients qui réservent des voyages ont également besoin d'endroits où séjourner et manger. Les codes sont des activités adjacentes servant la même clientèle.

### Convergence numérique

Une agence numérique (62019) qui fait également de la conception graphique (74130) et du conseil (70209) reflète la réalité des entreprises de services modernes. Les clients qui vous engagent pour développer des logiciels ont également besoin de travail de conception et de conseils stratégiques. Ces activités sont inséparables sur le plan opérationnel dans la pratique.

### Ce qui fait une mauvaise combinaison

Les codes qui n'ont aucune relation logique signalent un risque réglementaire. Un restaurant (56101) qui s'enregistre également comme une opération minière (07100) fera l'objet d'un examen minutieux. Même si les deux activités sont techniquement autorisées pour une PMA, le manque de logique commerciale les reliant suggère soit un enregistrement spéculatif, soit une intention future de vendre l'entité — ce qui attire l'attention.

## Implications fiscales : mappage KBLI-vers-KLU

Chaque code KBLI correspond à un code KLU (Klasifikasi Lapangan Usaha) dans le système fiscal. Le KLU détermine vos références fiscales — les ratios attendus par le DJP pour la marge brute, la marge nette et les taux d'imposition effectifs pour les entreprises de cette classification.

Lorsque vous enregistrez plusieurs codes KBLI, vos revenus sont segmentés par KLU. Le DJP peut comparer chaque flux de revenus à sa référence sectorielle indépendamment. Cela signifie :

- Les **revenus de votre restaurant** (56101/KLU 56101) sont comparés aux normes de l'industrie de la restauration.
- Les **revenus de votre e-commerce** (47911/KLU 47911) sont comparés aux normes du commerce de détail.
- **Si votre restaurant affiche une marge de 5 %** alors que la référence KLU est de 15 %, le DJP peut le signaler pour examen — _même si votre marge e-commerce est supérieure à la référence_.

L'enregistrement multi-code ne crée pas de référence mixte. Chaque activité est évaluée selon ses propres termes. C'est à la fois un risque et une protection : votre activité à forte marge ne tire pas vers le bas la performance attendue de votre activité à faible marge, mais une mauvaise performance dans un seul code attire l'attention.

## Comment enregistrer plusieurs codes KBLI

### Étape 1 : Auditez vos activités réelles

Listez chaque activité génératrice de revenus que votre entreprise exerce ou exercera au cours des 12 prochains mois. Soyez précis. "Services numériques" n'est pas une activité — "développement de logiciels personnalisés", "conception graphique pour les clients" et "conseil en gestion" le sont.

### Étape 2 : Mappez les activités aux codes KBLI à cinq chiffres

Chaque activité correspond exactement à un code KBLI 2025 à cinq chiffres. Utilisez la classification officielle BPS KBLI 2025 ou notre KBLI Navigator pour trouver les codes corrects. N'utilisez pas de codes à quatre ou trois chiffres — OSS exige cinq chiffres.

### Étape 3 : Évaluez le profil de risque

Identifiez la classification de risque de chaque code. Si l'ajout d'un code fait passer votre NIB à un niveau de risque plus élevé, évaluez si l'avantage commercial justifie la charge de conformité supplémentaire. Si l'activité génère moins de 10 % de vos revenus, elle peut ne pas valoir le coût réglementaire.

### Étape 4 : Enregistrez via OSS

Lors de l'enregistrement (ou de la modification) de la PT PMA, sélectionnez tous les codes KBLI applicables dans le système OSS. Le système calculera automatiquement votre niveau de risque agrégé et générera les exigences de licence appropriées.

### Étape 5 : Maintenez la conformité par code

Chaque code enregistré a ses propres obligations de conformité. Suivez les renouvellements de licences, les délais de déclaration et les exigences sectorielles spécifiques pour chaque code. Le non-respect d'une exigence de conformité sur un code peut affecter le statut de l'ensemble de votre NIB.

## Erreurs courantes à éviter

**Enregistrer des codes "pour l'avenir".** Chaque code de votre NIB doit représenter une activité commerciale actuelle ou imminente. L'enregistrement de codes pour des activités que vous _pourriez_ faire dans deux ans crée des obligations de conformité aujourd'hui sans revenus pour les justifier. Vous pouvez toujours ajouter des codes plus tard via un amendement OSS.

**Ignorer la cascade de risques.** L'ajout d'un code à risque élevé à un NIB autrement à faible risque transforme l'ensemble de votre profil de conformité. Avant d'ajouter un code de construction ou de santé, calculez le coût total du niveau de conformité supérieur — non seulement les frais de licence, mais aussi la préparation aux inspections, la charge de déclaration et les retards opérationnels potentiels.

**Supposer des références fiscales mixtes.** Votre comptable doit segmenter les revenus par code KBLI/KLU. Regrouper tous les revenus sous un seul code déforme votre entreprise aux yeux du DJP et déclenchera éventuellement un examen fiscal. Une segmentation appropriée dès le premier jour prévient les problèmes lors de l'audit.

**Copier les codes d'une autre entreprise.** L'entreprise de villas de votre ami a cinq codes KBLI, alors vous enregistrez les mêmes cinq. Mais votre modèle commercial est différent — vous ne faites pas de construction, seulement des opérations. L'enregistrement du 41017 (construction) alors que vous ne construisez jamais rien ajoute une classification à risque élevé sans aucun avantage.

**Ne pas mettre à jour les codes après KBLI 2025.** Si votre PT PMA a été enregistrée sous l'ancienne classification KBLI, vos codes peuvent avoir changé, été divisés ou reclassifiés. La date limite pour la migration KBLI 2025 est le **18 juin 2026**. Auditez vos codes existants par rapport à la nouvelle classification avant cette date.

## Le cadre de décision

Avant d'enregistrer plusieurs codes KBLI, passez chaque code candidat à travers cette liste de contrôle :

1.  **Ce code représente-t-il une activité que j'exerce ou que j'exercerai dans les 12 mois ?** Si non, ne l'enregistrez pas.
2.  **L'ajout de ce code augmente-t-il le niveau de risque de mon NIB ?** Si oui, les revenus de cette activité sont-ils suffisamment importants pour justifier le coût de la conformité ?
3.  **Existe-t-il une relation commerciale logique entre ce code et mes codes existants ?** Si non, déterminez si une entité distincte est plus judicieuse.
4.  **Mon système comptable peut-il segmenter les revenus par code KBLI/KLU ?** Si non, configurez-le avant d'ajouter des codes.
5.  **Suis-je prêt à maintenir la conformité pour ce code de manière indépendante ?** Chaque code a ses propres cycles de renouvellement et exigences de déclaration.

Si un code passe les cinq questions, enregistrez-le. S'il échoue à l'une d'entre elles, reconsidérez.

## En résumé

L'enregistrement multi-KBLI est un outil puissant pour les entreprises PT PMA à Bali. Il vous permet d'opérer sur des activités intégrées verticalement ou adjacentes sous une seule entité avec un engagement d'investissement unique de 10 milliards IDR. Mais chaque code que vous ajoutez a un poids en termes de conformité. La stratégie optimale est chirurgicale : enregistrez exactement les codes dont vous avez besoin, comprenez la cascade de risques, segmentez correctement vos impôts et laissez les codes spéculatifs pour un amendement futur.

Vos codes KBLI ne sont pas une liste de souhaits. Ils sont un contrat de conformité avec le gouvernement indonésien. Choisissez-les en conséquence.
