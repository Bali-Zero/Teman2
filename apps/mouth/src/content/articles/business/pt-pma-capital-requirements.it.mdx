# Requisiti di Capitale per PT PMA: Cosa Devi Investire nel 2026

L’**investimento minimo di 10 miliardi di IDR** (~625.000 USD) per PT PMA è uno dei requisiti più fraintesi. Analizziamo cosa significa realmente.

## I Due Numeri Chiave

| Requisito               | Importo                | Cosa Significa                                                |
| ----------------------- | ---------------------- | ------------------------------------------------------------- |
| **Investimento Totale** | 10 miliardi di IDR min | Investimento pianificato totale durante la vita della società |
| **Capitale Versato**    | 10 miliardi di IDR min | Denaro depositato sul conto bancario della società            |

<InfoCard variant="important" title="Entrambi Devono Essere Rispettati">
  Secondo le normative attuali, **sia** il piano di investimento totale che il capitale versato
  devono essere di almeno 10 miliardi di IDR. Questo è cambiato rispetto alle regole precedenti in
  cui il capitale versato poteva essere inferiore.
</InfoCard>

## Calcolatore di Investimento

<Calculator
  title="Pianificatore della Struttura dell'Investimento"
  description="Pianifica come raggiungere un investimento di 10 miliardi di IDR"
  fields={[
    {
      id: "cash",
      label: "Denaro da Depositare (Capitale Azionario)",
      type: "number",
      defaultValue: 10000000000,
      min: 0,
      step: 500000000,

    },
    {
      id: "equipment",

      type: "number",
      defaultValue: 0,
      min: 0,
      step: 100000000,
      suffix: "IDR"
    },
    {
      id: "working",
      label: "Capitale Circolante (Anno 1)",
      type: "number",
      defaultValue: 0,
      min: 0,
      step: 100000000,
      suffix: "IDR"
    },
    {
      id: "property",
      label: "Proprietà/Terreno",
      type: "number",
      defaultValue: 0,
      min: 0,
      step: 500000000,
      suffix: "IDR"
    }
  ]}
  calculateResult={(values) => {
    const cash = Number(values.cash);
    const equipment = Number(values.equipment);
    const working = Number(values.working);
    const property = Number(values.property);

    const total = cash + equipment + working + property;
    const required = 10000000000;
    const shortage = Math.max(0, required - total);
    const paidUpShortage = Math.max(0, required - cash);

    const breakdown = [
      { label: "Capitale Azionario (Denaro)", amount: cash },
      { label: "Attrezzature e Macchinari", amount: equipment },
      { label: "Capitale Circolante", amount: working },
      { label: "Proprietà/Terreno", amount: property },
      { label: "Piano di Investimento Totale", amount: total }
    ];

    let note = "";
    if (total >= required && cash >= required) {
      note = "Requisiti soddisfatti!";
    } else if (cash < required) {
      note = `Capitale versato inferiore di IDR ${(paidUpShortage/1000000000).toFixed(1)}B. È necessario depositare un minimo di 10 miliardi di IDR.`;
    } else if (total < required) {
      note = `Investimento totale inferiore di IDR ${(shortage/1000000000).toFixed(1)}B`;
    }

    return {
      total,
      breakdown,
      currency: "IDR",
      note
    };

}}

## Domande Frequenti sui Capitali

<InfoCard variant="note" title="FAQ">
**D: Ho bisogno di 10 miliardi di IDR sul mio conto bancario il primo giorno?**
R: Sì, il capitale versato di 10 miliardi di IDR deve essere depositato per aprire il conto bancario della società e completare la registrazione.

**D: Posso usarlo dopo averlo depositato?**
R: Sì, una volta depositato come capitale azionario, puoi utilizzare questi fondi per le operazioni aziendali.

**D: Cosa succede se non posso raggiungere i 10 miliardi di IDR?**
R: Le opzioni includono:

- Joint venture con un partner locale
- Struttura aziendale diversa (ufficio di rappresentanza, ecc.)
- Aspettare di avere capitale sufficiente

**D: C'è un modo per aggirare il minimo?**
R: Non esiste un modo legittimo. Le normative sono chiare sul minimo di 10 miliardi di IDR per PT PMA.

</InfoCard>
