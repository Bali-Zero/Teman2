## Местные против международных банков

<InfoCard variant="note" title="Какой выбрать?">
**Местные банки (BCA, Mandiri):**
- Больше отделений/банкоматов
- Лучшая местная интеграция
- Обычно более низкие комиссии
- Хорошо подходят для внутреннего бизнеса

**Международные банки (HSBC, SCB):**

- Более простые международные переводы
- Лучше подходят для глобальных операций
- Более высокие минимальные остатки/комиссии
- Отличное обслуживание на английском языке

**Большинство PT PMA используют:** BCA или CIMB Niaga для ежедневных операций, иногда международный банк для трансграничных операций.

</InfoCard>

## Процесс открытия

### Пошагово

| Шаг                          | Что происходит                           |
| ---------------------------- | ---------------------------------------- |
| 1. Выбор банка               | Сравнение вариантов, местоположение      |
| 2. Первоначальная встреча    | Обсуждение требований                    |
| 3. Подача документов         | Полный пакет                             |
| 4. Проверка благонадежности  | Банк проверяет документы                 |
| 5. Одобрение                 | Обычно 1-3 недели                        |
| 6. Активация счета           | Подписание документов, внесение депозита |
| 7. Настройка онлайн-банкинга | Токен, учетные данные                    |

### Сроки

| Этап                  | Продолжительность |
| --------------------- | ----------------- |
| Подготовка документов | 1-2 недели        |
| Проверка банком       | 1-3 недели        |
| Одобрение             | 1-2 недели        |
| **Итого**             | **3-6 недель**    |

<InfoCard variant="warning" title="Частые задержки">
**Что замедляет процесс:**

- Неполные документы
- Директор еще без KITAS
- Вопросы банка по соблюдению требований
- Проблемы с подтверждением адреса
- Пробелы в документации акционеров

Тщательно подготовьтесь, чтобы избежать задержек!

</InfoCard>

## Международные переводы

### Отправка денег за границу

<InfoCard variant="note" title="Валютный контроль">
**В Индонезии существуют некоторые ограничения:**

- Для транзакций свыше 25 тыс. долларов США требуются подтверждающие документы
- Может потребоваться налоговое разрешение
- Банк отчитывается перед центральным банком
- Надлежащая документация крайне важна

Сохраняйте все счета-фактуры, контракты для переводов!

</InfoCard>

### Необходимые документы для исходящего перевода

| Для               | Документы                                      |
| ----------------- | ---------------------------------------------- |
| Оплата импорта    | Счет-фактура, аккредитив, таможенные документы |
| Оплата услуг      | Контракт, счет-фактура                         |
| Дивиденды         | Решение совета директоров, налоговые документы |
| Погашение кредита | Кредитный договор                              |

## Получение денег

### Входящий перевод

| Требование            | Детали                                              |
| --------------------- | --------------------------------------------------- |
| Счет-фактура/контракт | Подтверждающий документ                             |
| NPWP                  | Налоговый номер компании                            |
| Отчетность            | Свыше 10 тыс. долларов США автоматически сообщается |

### Советы для беспрепятственного получения

- Информируйте банк об ожидаемых крупных переводах
- Подготовьте подтверждающие документы
- Сопоставьте ссылку на перевод со счетом-фактурой
- Убедитесь, что отправитель использует правильные реквизиты

## Советы для успеха

<InfoCard variant="tip" title="Советы по открытию счета">
**Для бесперебойного процесса:**

1.  **Сначала подготовьте все документы** - Не подавайте неполные
2.  **Используйте корпоративного секретаря** - Они знают требования банка
3.  **Выстраивайте отношения** - Менеджер по работе с клиентами поможет
4.  **Начните процесс заранее** - До того, как счет понадобится срочно
5.  **Рассмотрите запасной банк** - Два счета — это обычная практика
6.  **Обновляйте документы** - Ежегодные изменения в учредительном акте
