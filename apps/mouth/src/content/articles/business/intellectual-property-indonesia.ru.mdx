## Регистрация товарного знака

### Зачем регистрировать в Индонезии?

<InfoCard variant="warning" title="Система «первый подавший заявку»">
Индонезия использует систему **«первый подавший заявку»**:
- Первый зарегистрировавший владеет товарным знаком
- Ваш товарный знак, зарегистрированный в другом месте, не защищает вас здесь
- "Сквоттеры" могут зарегистрировать ваш бренд первыми
- Без регистрации возможности принудительного исполнения ограничены

**Зарегистрируйте свой товарный знак до выхода на рынок Индонезии!**

</InfoCard>

## Защита авторских прав

### Автоматическая защита

Защита авторских прав **автоматически** действует в Индонезии для:

- Литературных произведений
- Музыки и песен
- Произведений искусства и фотографий
- Фильмов и видео
- Программного обеспечения и баз данных
- Архитектуры

### Зачем все-таки регистрировать?

| Преимущество     | Объяснение                 |
| ---------------- | -------------------------- |
| Доказательство   | Подтверждает дату владения |
| Принуждение      | Упрощает судебные действия |
| Лицензирование   | Более четкое владение      |
| Стоимость актива | Для оценки бизнеса         |

### Процесс регистрации

| Шаг                   | Срок       |
| --------------------- | ---------- |
| Подготовка документов | 1 неделя   |
| Онлайн-заявка         | 1 день     |
| Рассмотрение DGIP     | 1-3 месяца |
| Выдача свидетельства  | 1-2 недели |

## Коммерческие тайны

### Требования к защите

<InfoCard variant="tip" title="Защитите свои секреты">
Для сохранения защиты коммерческой тайны:

1.  **Определите**, что является конфиденциальным
2.  **Пометьте** документы как конфиденциальные
3.  **Ограничьте** доступ по принципу необходимости знать
4.  **Соглашения о неразглашении (NDA)** с сотрудниками и партнерами
5.  **Меры безопасности** (физические и цифровые)
6.  **Обучение** персонала конфиденциальности

После обнародования защита теряется навсегда.

</InfoCard>

### Основные положения NDA

| Элемент                  | Назначение                    |
| ------------------------ | ----------------------------- |
| Определение              | Что является конфиденциальным |

| Срок действия            | Как долго действует           |
| Исключения               | Разрешенные раскрытия         |
| Средства правовой защиты | Последствия нарушения         |
