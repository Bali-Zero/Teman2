## Banques Locales vs Internationales

<InfoCard variant="note" title="Laquelle Choisir ?">
**Banques Locales (BCA, Mandiri) :**
- Plus de succursales/guichets automatiques
- Meilleure intégration locale
- Frais généralement plus bas
- Bonnes pour les affaires nationales

**Banques Internationales (HSBC, SCB) :**

- Virements internationaux plus faciles
- Meilleures pour les opérations mondiales
- Minimums/frais plus élevés
- Excellent service en anglais

**La plupart des PT PMA utilisent :** BCA ou CIMB Niaga pour les opérations quotidiennes, parfois une banque internationale pour les transactions transfrontalières.

</InfoCard>

## Processus d'Ouverture

### Étape par Étape

| Étape                                  | Ce qui se passe                     |
| -------------------------------------- | ----------------------------------- |
| 1. Choisir la banque                   | Comparer les options, l'emplacement |
| 2. Première réunion                    | Discuter des exigences              |
| 3. Soumission des documents            | Dossier complet                     |
| 4. Due diligence                       | La banque vérifie les documents     |
| 5. Approbation                         | Généralement 1-3 semaines           |
| 6. Activation du compte                | Signer les documents, dépôt         |
| 7. Configuration de la banque en ligne | Jeton, identifiants                 |

### Calendrier

| Phase                     | Durée            |
| ------------------------- | ---------------- |
| Préparation des documents | 1-2 semaines     |
| Examen par la banque      | 1-3 semaines     |
| Approbation               | 1-2 semaines     |
| **Total**                 | **3-6 semaines** |

<InfoCard variant="warning" title="Retards Courants">
**Ce qui ralentit le processus :**

- Documents incomplets
- Directeur sans KITAS encore
- Questions de conformité bancaire
- Problèmes de vérification d'adresse
- Lacunes dans la documentation des actionnaires

Préparez-vous minutieusement pour éviter les retards !

</InfoCard>

## Virements Internationaux

### Envoi d'Argent à l'Étranger

<InfoCard variant="note" title="Contrôles de Devises">
**L'Indonésie a certains contrôles :**

- Les transactions de plus de 25 000 USD nécessitent des documents justificatifs
- Une attestation fiscale peut être requise
- La banque fait rapport à la banque centrale
- Une documentation appropriée est essentielle

Conservez toutes les factures et contrats pour les virements !

</InfoCard>

### Documents Requis pour les Virements Sortants

| Pour                   | Documents                                |
| ---------------------- | ---------------------------------------- |
| Paiement d'importation | Facture, LC, documents douaniers         |
| Paiement de service    | Contrat, facture                         |
| Dividende              | Résolution du conseil, documents fiscaux |
| Remboursement de prêt  | Contrat de prêt                          |

## Réception d'Argent

### Virement Entrant

| Exigence        | Détails                                     |
| --------------- | ------------------------------------------- |
| Facture/contrat | Document justificatif                       |
| NPWP            | Numéro fiscal de l'entreprise               |
| Déclaration     | Plus de 10 000 USD signalés automatiquement |

### Conseils pour une Réception Fluide

- Informer la banque des virements importants attendus
- Avoir les documents justificatifs prêts
- Faire correspondre la référence du virement à la facture
- S'assurer que l'expéditeur utilise les bonnes coordonnées

## Conseils pour Réussir

<InfoCard variant="tip" title="Conseils pour l'Ouverture de Compte">
**Pour un processus fluide :**

1. **Complétez d'abord les documents** - Ne soumettez pas de dossier incomplet
2. **Utilisez un secrétaire d'entreprise** - Il connaît les exigences bancaires
3. **Établissez une relation** - Un gestionnaire de relation aide
4. **Commencez le processus tôt** - Avant d'avoir un besoin urgent du compte
5. **Envisagez une banque de secours** - Deux comptes sont courants
6. **Gardez les documents à jour** - Modifications annuelles de l'acte
   </InfoCard>

### Erreurs Courantes

| Erreur                        | Conséquence                   |
| ----------------------------- | ----------------------------- |
| Documents incomplets          | Rejet/retards                 |
| Directeur sans KITAS          | Impossible d'ouvrir           |
| Nom de l'entreprise incorrect | Doit correspondre exactement  |
| Ancienne version de l'acte    | Doit être la version actuelle |
| NPWP manquant                 | Rejet immédiat                |
