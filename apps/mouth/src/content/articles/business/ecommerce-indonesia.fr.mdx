# E-commerce en Indonésie 2026 : Guide complet

L'Indonésie est le plus grand marché de commerce électronique d'Asie du Sud-Est. Voici comment exploiter cette opportunité.

## Aperçu du marché

<InfoCard variant="note" title="Indonesia E-Commerce">
**Taille du marché (2026) :**

- Marché de ~80+ milliards de dollars
- Population de 280+ millions
- 200+ millions d'utilisateurs d'internet
- Classe moyenne en croissance
- Forte pénétration du mobile
- Le commerce social en hausse

L'un des marchés de commerce électronique à la croissance la plus rapide au monde.

</InfoCard>

## Exigences légales

### Pour les investisseurs étrangers

<InfoCard variant="warning" title="PT PMA Required">
**Investissement étranger dans l'e-commerce :**

- PT PMA nécessaire pour les opérations significatives
- Exigences d'investissement minimum
- Codes KBLI pour les activités d'e-commerce
- NIB via OSS
- Peut nécessiter l'enregistrement PPMSE

Ne peut pas simplement opérer de manière informelle en tant qu'étranger.

</InfoCard>

### Catégories avec des exigences spéciales

| Catégorie              | Exigence                      |
| ---------------------- | ----------------------------- |
| Aliments et boissons   | Enregistrement BPOM           |
| Cosmétiques            | BPOM + halal (le cas échéant) |
| Électronique           | Certification SNI             |
| Médicaments            | Contrôles stricts             |
| Marchandises importées | Douanes, droits               |
| Produits halal         | Certification MUI             |

**Offrez plusieurs options :**

- Virement bancaire (essentiel)
- Portefeuilles électroniques (essentiel)
- Cartes de crédit (pour une valeur plus élevée)
- COD (si vous pouvez gérer la logistique)

Les Indonésiens préfèrent les méthodes de paiement familières.

## Obligations fiscales

### Impôt sur l'e-commerce

| Impôt                  | Taux                | Quand                       |
| ---------------------- | ------------------- | --------------------------- |
| Impôt sur les sociétés | 22%                 | Bénéfice annuel             |
| TVA (PPN)              | 11%                 | Si PKP, sur les ventes      |
| Retenue à la source    | Divers              | Sur les paiements effectués |
| Frais de plateforme    | Pas de TVA facturée | Commission à la plateforme  |

<InfoCard variant="note" title="VAT on E-Commerce">
**Considérations sur la TVA :**

- Seuil : 4,8 milliards IDR de revenus
- Doit s'enregistrer en tant que PKP
- Émettre des e-Faktur
- La plateforme peut gérer pour les ventes sur marketplace
- Le transfrontalier a des règles différentes
  </InfoCard>
