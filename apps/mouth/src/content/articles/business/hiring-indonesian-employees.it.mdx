### Calcolatore di costi

<Calculator
  title="Costo totale del lavoro"
  description="Stima il costo totale per il datore di lavoro"
  fields={[
    {
      id: "gross",
      label: "Stipendio mensile lordo (IDR)",
      type: "number",
      defaultValue: 15000000,
      min: 0,
      step: 1000000,
      suffix: "IDR"
    },
    {
      id: "thr",
      label: "Includi la provvista THR",
      type: "select",

        { value: "yes", label: "Sì" },
        { value: "no", label: "No" }
      ],
      defaultValue: "yes"
    }
  ]}
  calculateResult={(values) => {
    const gross = Number(values.gross);

    // Contributi BPJS del datore di lavoro
    const bpjsKesehatan = gross * 0.04; // 4% salute
    const bpjsJKK = gross * 0.0024; // 0.24% min infortunio sul lavoro
    const bpjsJKM = gross * 0.003; // 0.3% decesso
    const bpjsJHT = gross * 0.037; // 3.7% fondo pensione
    const bpjsJP = gross * 0.02; // 2% pensione

    const totalBPJS = bpjsKesehatan + bpjsJKK + bpjsJKM + bpjsJHT + bpjsJP;

    // Provvista THR (1 mese dilazionato in 12)
    const thrProvision = values.thr === "yes" ? gross / 12 : 0;

    const totalMonthly = gross + totalBPJS + thrProvision;

    return {
      total: Math.round(totalMonthly),
      breakdown: [
        { label: "Stipendio lordo", amount: gross },
        { label: "BPJS Kesehatan (4%)", amount: Math.round(bpjsKesehatan) },
        { label: "BPJS JKK (0.24%)", amount: Math.round(bpjsJKK) },
        { label: "BPJS JKM (0.3%)", amount: Math.round(bpjsJKM) },
        { label: "BPJS JHT (3.7%)", amount: Math.round(bpjsJHT) },
        { label: "BPJS JP (2%)", amount: Math.round(bpjsJP) },
        { label: "Provvista THR", amount: Math.round(thrProvision) },

## Registrazione BPJS

### BPJS Kesehatan (Salute)

<InfoCard variant="note" title="Assicurazione sanitaria">
**Contributi:**
- Totale: 5% dello stipendio
- Datore di lavoro: 4%
- Dipendente: 1%

**Limite:** Stipendio base di IDR 12 milioni

**Copertura:**

- Dipendente
- Coniuge
- Fino a 3 figli
- Membri familiari aggiuntivi: +1% ciascuno

</InfoCard>

### BPJS Ketenagakerjaan (Lavoro)

| Programma             | Datore di lavoro   | Dipendente | Totale  |
| ------------------- | ---------- | -------- | ------ |
| JKK (Infortunio sul lavoro) | 0.24-1.74% | 0%       | Varies |
| JKM (Decesso)         | 0.30%      | 0%       | 0.30%  |
| JHT (Fondo pensione)  | 3.70%      | 2%       | 5.70%  |
| JP (Pensione)        | 2%         | 1%       | 3%     |

### Checklist del contratto

- Dettagli del datore di lavoro e del dipendente
- Titolo del lavoro e descrizione
- Luogo di lavoro
- Orari di lavoro
- Stipendio e componenti
- Benefici
- Data di inizio (e data di fine per PKWT)
- Termini di prova (solo PKWTT)
- Disposizioni per la terminazione
- Firma da entrambe le parti

## Periodo di prova

<InfoCard variant="warning" title="Regole di prova">
**Per PKWTT (Permanente) solo:**
- Massimo 3 mesi
- Deve essere scritto
- Stipendio pieno durante il periodo di prova
- Può essere terminato con preavviso durante il periodo di prova
- Nessuna indennità se terminato durante il periodo di prova

**Per PKWT (A termine):**

- Periodo di prova NON consentito
- Qualsiasi clausola di prova è nulla

</InfoCard>

## Considerazioni sulle buste paga

### Requisiti di pagamento

| Requisito | Dettaglio                |
| ----------- | --------------------- |
| Frequenza   | Mensile (più comune) |
| Metodo      | Trasferimento bancario         |
| Valuta    | IDR                   |
| Busta paga    | Obbligatoria              |
| Trattenute  | BPJS, PPh 21, prestiti   |

### Ritenuta d'acconto (PPh 21)

Il datore di lavoro deve:

1. Calcolare il PPh 21 mensile
2. Trattenere dallo stipendio
3. Versare entro il 10 del mese successivo
4. Dichiarare entro il 20 del mese successivo
5. Emettere la busta paga annuale (1721-A1)

## Errori comuni

| Errore                        | Impatto                 |
| ------------------------------ | ---------------------- |
| Nessun contratto scritto            | Default a PKWTT      |
| Registrazione BPJS ritardata         | Multe e sanzioni    |
| Utilizzo di PKWT per ruoli permanenti | Contratto diventa PKWTT |
| Periodo di prova in PKWT              | Clausola è nulla         |
| Non raccogliere l'NPWP            | Problemi nella dichiarazione delle tasse   |
| Manca la ritenuta d'acconto        | Responsabilità del datore di lavoro     |
