### Calcolatore dei Costi

<Calculator
  title="Costo Totale dell'Assunzione"
  description="Stima del costo totale per il datore di lavoro"
  fields={[
    {
      id: "gross",
      label: "Stipendio Mensile Lordo (IDR)",
      type: "number",
      defaultValue: 15000000,
      min: 0,
      step: 1000000,
      suffix: "IDR"
    },
    {
      id: "thr",
      label: "Includere Provvedimento THR",
      type: "select",
      options: [
        { value: "yes", label: "Sì" },
        { value: "no", label: "No" }
      ],
      defaultValue: "yes"
    }
  ]}
  calculateResult={(values) => {
    const gross = Number(values.gross);

    // Contributi datori di lavoro BPJS
    const bpjsKesehatan = gross * 0.04; // 4% sanità
    const bpjsJKK = gross * 0.0024; // 0,24% infortuni sul lavoro min
    const bpjsJKM = gross * 0.003; // 0,3% decesso
    const bpjsJHT = gross * 0.037; // 3,7% fondo pensione
    const bpjsJP = gross * 0.02; // 2% pensione

    const totalBPJS = bpjsKesehatan + bpjsJKK + bpjsJKM + bpjsJHT + bpjsJP;

    // Provvedimento THR (1 mese distribuito su 12)
    const thrProvision = values.thr === "yes" ? gross / 12 : 0;

    const totalMonthly = gross + totalBPJS + thrProvision;

    return {
      total: Math.round(totalMonthly),
      breakdown: [
        { label: "Stipendio Lordo", amount: gross },
        { label: "BPJS Kesehatan (4%)", amount: Math.round(bpjsKesehatan) },
        { label: "BPJS JKK (0,24%)", amount: Math.round(bpjsJKK) },
        { label: "BPJS JKM (0,3%)", amount: Math.round(bpjsJKM) },
        { label: "BPJS JHT (3,7%)", amount: Math.round(bpjsJHT) },
        { label: "BPJS JP (2%)", amount: Math.round(bpjsJP) },
        { label: "Provvedimento THR", amount: Math.round(thrProvision) },
        { label: "Costo Mensile Totale", amount: Math.round(totalMonthly) }

      currency: "IDR",

## Iscrizione BPJS

### BPJS Kesehatan (Sanità)

<InfoCard variant="note" title="Assicurazione Sanitaria">
**Contributi:**
- Totale: 5% dello stipendio
- Datore di lavoro: 4%
- Dipendente: 1%

**Limite:** Stipendio base IDR 12 milioni

**Copertura:**

- Dipendente
- Coniuge
- Fino a 3 figli
- Familiari aggiuntivi: +1% ciascuno

</InfoCard>

### BPJS Ketenagakerjaan (Lavoro)

| Programma             | Datore di Lavoro   | Dipendente | Totale  |
| ------------------- | ---------- | -------- | ------ |
| JKK (Infortunio sul lavoro) | 0,24-1,74% | 0%       | Variabile |
| JKM (Decesso)         | 0,30%      | 0%       | 0,30%  |
| JHT (Fondo Pensione)  | 3,70%      | 2%       | 5,70%  |
| JP (Pensione)        | 2%         | 1%       | 3%     |

### Checklist Contratto

- Dettagli del dipendente e del datore di lavoro
- Titolo e descrizione del ruolo
- Luogo di lavoro
- Orari di lavoro
- Stipendio e componenti
- Benefit
- Data di inizio (e data di fine per PKWT)
- Termini del periodo di prova (solo PKWTT)
- Clausole di recesso
- Firmato da entrambe le parti

## Periodo di Prova

<InfoCard variant="warning" title="Regole sulla Prova">
**Solo per PKWTT (Indefinito):**
- Massimo 3 mesi
- Deve essere scritto
- Stipendio pieno durante la prova
- Possibilità di recesso con preavviso durante la prova
- Nessun indennità in caso di recesso durante la prova

**Per PKWT (A tempo determinato):**

- Prova NON consentita
- Qualsiasi clausola sulla prova è nulla

</InfoCard>

## Considerazioni sul Payroll

### Requisiti di Pagamento

| Requisito | Dettaglio                |
| ----------- | --------------------- |
| Frequenza   | Mensile (più comune) |
| Metodo      | Bonifico bancario         |
| Valuta    | IDR                   |
| Busta paga    | Obbligatoria              |
| Trattenute  | BPJS, PPh 21, prestiti   |

### Trattenuta Fiscale (PPh 21)

Il datore di lavoro deve:

1. Calcolare il PPh 21 mensile
2. Trattenere dallo stipendio
3. Versare entro il 10 del mese successivo
4. Dichiarare entro il 20 del mese successivo
5. Emettere cedolare annua (1721-A1)

## Errori Comuni

| Errore                        | Impatto                 |
| ------------------------------ | ---------------------- |
| Nessun contratto scritto            | Si applica PKWTT      |
| Iscrizione BPJS tardiva         | Multe e sanzioni    |
| Uso di PKWT per ruoli permanenti | Contratto diventa PKWTT |
| Prova in PKWT              | Clausola è nulla         |
| Mancata raccolta NPWP            | Problemi report fiscali   |
| Mancata trattenuta fiscale        | Responsabilità datore di lavoro     |
