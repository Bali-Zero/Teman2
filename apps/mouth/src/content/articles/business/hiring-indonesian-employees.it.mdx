### Calcolatore Costi

<Calculator
  title="Costo Totale del Lavoro"
  description="Stima il costo totale per il datore di lavoro"
  fields={[
    {
      id: "gross",
      label: "Stipendio Lordo Mensile (IDR)",
      type: "number",
      defaultValue: 15000000,
      min: 0,
      step: 1000000,
      suffix: "IDR"
    },
    {
      id: "thr",
      label: "Includi Provvista THR",
      type: "select",
      options: [
        { value: "yes", label: "Sì" },
        { value: "no", label: "No" }
      ],
      defaultValue: "yes"
    }
  ]}
  calculateResult={(values) => {
    const gross = Number(values.gross);

    // BPJS employer contributions
    const bpjsKesehatan = gross * 0.04; // 4% health
    const bpjsJKK = gross * 0.0024; // 0.24% min work accident
    const bpjsJKM = gross * 0.003; // 0.3% death
    const bpjsJHT = gross * 0.037; // 3.7% pension fund
    const bpjsJP = gross * 0.02; // 2% pension

    const totalBPJS = bpjsKesehatan + bpjsJKK + bpjsJKM + bpjsJHT + bpjsJP;

    // THR provision (1 month spread over 12)
    const thrProvision = values.thr === "yes" ? gross / 12 : 0;

    const totalMonthly = gross + totalBPJS + thrProvision;

    return {
      total: Math.round(totalMonthly),
      breakdown: [
        { label: "Stipendio Lordo", amount: gross },
        { label: "BPJS Kesehatan (4%)", amount: Math.round(bpjsKesehatan) },
        { label: "BPJS JKK (0.24%)", amount: Math.round(bpjsJKK) },
        { label: "BPJS JKM (0.3%)", amount: Math.round(bpjsJKM) },
        { label: "BPJS JHT (3.7%)", amount: Math.round(bpjsJHT) },
        { label: "BPJS JP (2%)", amount: Math.round(bpjsJP) },
        { label: "Provvista THR", amount: Math.round(thrProvision) },
        { label: "Costo Mensile Totale", amount: Math.round(totalMonthly) }
      ],
      currency: "IDR",
      note: `BPJS datore di lavoro: ~10.24% dello stipendio`
    };

## Registrazione BPJS

### BPJS Kesehatan (Salute)

<InfoCard variant="note" title="Assicurazione Sanitaria">
**Contributi:**
- Totale: 5% dello stipendio
- Datore di lavoro: 4%
- Dipendente: 1%

**Limite:** Stipendio base IDR 12 milioni

**Copertura:**

- Dipendente
- Coniuge
- Fino a 3 figli
- Familiari aggiuntivi: +1% ciascuno
  </InfoCard>

### BPJS Ketenagakerjaan (Lavoro)

| Programma            | Datore di Lavoro | Dipendente | Totale    |
| -------------------- | ---------------- | ---------- | --------- |
| JKK (Infortunio)     | 0.24-1.74%       | 0%         | Variabile |
| JKM (Decesso)        | 0.30%            | 0%         | 0.30%     |
| JHT (Fondo Pensione) | 3.70%            | 2%         | 5.70%     |
| JP (Pensione)        | 2%               | 1%         | 3%        |

## Periodo di Prova

<InfoCard variant="warning" title="Regole di Prova">
**Solo per PKWTT (Permanente):**
- Massimo 3 mesi
- Deve essere per iscritto
- Stipendio pieno durante la prova
- Si può terminare con preavviso durante la prova
- Nessuna indennità se terminato durante la prova

**Per PKWT (A termine):**

- Prova NON consentita
- Qualsiasi clausola di prova è nulla
  </InfoCard>

## Considerazioni sulla Busta Paga

### Requisiti di Pagamento

| Requisito  | Dettaglio              |
| ---------- | ---------------------- |
| Frequenza  | Mensile (più comune)   |
| Metodo     | Bonifico bancario      |
| Valuta     | IDR                    |
| Busta paga | Obbligatoria           |
| Detrazioni | BPJS, PPh 21, prestiti |

### Ritenuta Fiscale (PPh 21)

Il datore di lavoro deve:

1. Calcolare il PPh 21 mensile
2. Trattenere dallo stipendio
3. Versare entro il 10 del mese successivo
4. Dichiarare entro il 20 del mese successivo
5. Rilasciare la certificazione fiscale annuale (1721-A1)

## Errori Comuni

| Errore                          | Impatto                               |
| ------------------------------- | ------------------------------------- |
| Nessun contratto scritto        | Diventa PKWTT di default              |
| Registrazione BPJS tardiva      | Multe e sanzioni                      |
| Usare PKWT per ruoli permanenti | Il contratto diventa PKWTT            |
| Prova in PKWT                   | La clausola è nulla                   |
| Non raccogliere NPWP            | Problemi con la dichiarazione fiscale |
| Mancata ritenuta fiscale        | Responsabilità del datore di lavoro   |
