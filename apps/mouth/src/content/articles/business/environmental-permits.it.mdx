## AMDAL (Valutazione di Impatto Ambientale)

<InfoCard variant="warning" title="Solo Grandi Progetti">
**AMDAL è richiesto per:**
- Grandi impianti manifatturieri
- Attività minerarie
- Grandi progetti infrastrutturali
- Agricoltura su larga scala
- Sviluppo significativo del terreno
- Impianti chimici/pericolosi

L'AMDAL coinvolge la consultazione pubblica e la valutazione da parte di esperti.

</InfoCard>

### Processo AMDAL

| Fase               | Descrizione                 | Durata   |
| ------------------- | --------------------------- | ---------- |
| Screening           | Determinare se serve AMDAL  | 1-2 settimane  |
| Scoping             | Definire lo studio          | 2-4 settimane  |
| Studio EIA          | Studio di impatto ambientale | 3-6 mesi |
| Consultazione pubblica | Input della comunità       | 1-2 mesi |
| Revisione           | Valutazione da parte del comitato     | 1-2 mesi |
| Approvazione        | Permesso ambientale emesso  | 2-4 settimane  |

### Componenti AMDAL

| Documento | Scopo                       |
| -------- | ----------------------------- |
| KA-ANDAL | Termini di riferimento       |
| ANDAL    | Analisi d'impatto            |
| RKL      | Piano di gestione ambientale |
| RPL      | Piano di monitoraggio ambientale |

## UKL-UPL (Gestione e Monitoraggio)

### Quando è Richiesto UKL-UPL

La maggior parte delle imprese medie necessita di UKL-UPL:

- Ristoranti e caffè
- Manifattura piccola/media
- Officine e garage
- Costruzione media
- Hotel (alcune dimensioni)

## SPPL (Lettera di Dichiarazione)

<InfoCard variant="tip" title="Opzione più Semplice">
**SPPL** è per imprese a basso impatto:
- Piccoli negozi al dettaglio
- Servizi di base
- Attività d'ufficio
- Operazioni a basso rischio

Spesso generato automaticamente tramite il sistema OSS basato sul tuo codice KBLI.

</InfoCard>

### Processo SPPL

1. Registrati sul sistema OSS
2. Inserisci i dettagli dell'impresa
3. SPPL generato se il rischio è basso
4. Stampa e conserva in archivio
5. Rispetta gli impegni dichiarati

---

## Approccio Basato sul Rischio

### Classificazione del Rischio OSS

Il sistema OSS ora utilizza un **approccio basato sul rischio**:

| Livello di Rischio  | Requisito Ambientale         |
| ----------- | -------------------------- |
| Basso        | SPPL (automatico in OSS)    |
| Medio-Basso  | SPPL o UKL-UPL semplificato |
| Medio-Alto   | UKL-UPL standard            |
| Alto         | AMDAL valutazione completa   |

Il rischio è determinato da:

- Classificazione commerciale KBLI
- Scala delle operazioni
- Sensibilità della posizione
- Impatto ambientale potenziale

## Gestione Rifiuti

### Categorie di Rifiuti

| Categoria       | Esempi                  | Requisiti               |
| -------------- | ------------------------- | -------------------------- |
| B3 (Pericoloso) | Sostanze chimiche, batterie, olio | Smaltimento autorizzato          |
| Non-B3         | Rifiuti generali             | Smaltimento appropriato            |
| Acque reflue     | Acqua di processo             | Trattamento prima scarico           |
| Emissioni aria  | Fumo, gas                   | Monitoraggio, filtri              |

<InfoCard variant="warning" title="Rifiuti B3">
**I rifiuti pericolosi (B3)** richiedono:
- Stoccaggio separato
- Trasportatore autorizzato
- Impianto di smaltimento autorizzato
- Documentazione manifest
- Segnalazione regolare

Le violazioni possono comportare sanzioni gravi.

</InfoCard>

---

## Sanzioni per Non Conformità

| Violazione                | Sanzione                    |
| ------------------------ | -------------------------- |
| Operare senza permesso   | Chiusura + multe           |
| Superamento standard      | Avvisi → multe → chiusura  |
| Smaltimento improprio rifiuti  | Possibili reati penali    |
| Segnalazione falsa       | Revoca del permesso        |
| Violazioni B3            | Responsabilità penale + civile |
