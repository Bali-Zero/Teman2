## AMDAL (Valutazione di Impatto Ambientale)

<InfoCard variant="warning" title="Solo per Grandi Progetti">
**L'AMDAL è richiesto per:**
- Grandi impianti di produzione
- Operazioni minerarie
- Grandi progetti infrastrutturali
- Agricoltura su larga scala
- Sviluppo fondiario significativo
- Impianti chimici/pericolosi

L'AMDAL comporta consultazioni pubbliche e valutazioni di esperti.

</InfoCard>

### Processo AMDAL

| Fase                   | Descrizione                         | Durata        |
| ---------------------- | ----------------------------------- | ------------- |
| Screening              | Determinare se l'AMDAL è necessario | 1-2 settimane |
| Definizione Scopo      | Definire l'ambito dello studio      | 2-4 settimane |
| Studio VIA             | Studio di impatto ambientale        | 3-6 mesi      |
| Consultazione Pubblica | Input della comunità                | 1-2 mesi      |
| Revisione              | Valutazione da parte del comitato   | 1-2 mesi      |
| Approvazione           | Rilascio del permesso ambientale    | 2-4 settimane |

### Componenti AMDAL

| Documento | Scopo                            |
| --------- | -------------------------------- |
| KA-ANDAL  | Termini di riferimento           |
| ANDAL     | Analisi dell'impatto             |
| RKL       | Piano di gestione ambientale     |
| RPL       | Piano di monitoraggio ambientale |

## UKL-UPL (Gestione e Monitoraggio)

### Quando è richiesto l'UKL-UPL

La maggior parte delle medie imprese necessita di UKL-UPL:

- Ristoranti e caffè
- Produzione medio-piccola
- Officine e garage
- Costruzioni medie
- Hotel (di determinate dimensioni)

## SPPL (Lettera di Dichiarazione)

<InfoCard variant="tip" title="Opzione più Semplice">
**L'SPPL** è per imprese a basso impatto:
- Piccoli negozi al dettaglio
- Servizi di base
- Attività d'ufficio
- Operazioni a basso rischio

Spesso generato automaticamente tramite il sistema OSS in base al tuo codice KBLI.

</InfoCard>

### Processo SPPL

1. Registrati sul sistema OSS
2. Inserisci i dettagli dell'attività
3. L'SPPL viene generato se il rischio è basso
4. Stampa e conserva nei registri
5. Rispetta gli impegni dichiarati

---

## Approccio Basato sul Rischio

### Classificazione del Rischio OSS

Il sistema OSS utilizza ora un **approccio basato sul rischio**:

| Livello di Rischio | Requisito Ambientale        |
| ------------------ | --------------------------- |
| Basso              | SPPL (automatico in OSS)    |
| Medio-Basso        | SPPL o UKL-UPL semplificato |
| Medio-Alto         | UKL-UPL standard            |
| Alto               | AMDAL valutazione completa  |

Rischio determinato da:

- Classificazione aziendale KBLI
- Scala delle operazioni
- Sensibilità della posizione
- Potenziale impatto ambientale

## Gestione dei Rifiuti

### Categorie di Rifiuti

| Categoria       | Esempi                  | Requisiti                       |
| --------------- | ----------------------- | ------------------------------- |
| B3 (Pericolosi) | Chimici, batterie, olio | Smaltimento autorizzato         |
| Non-B3          | Rifiuti generici        | Smaltimento corretto            |
| Acque reflue    | Acqua di processo       | Trattamento prima dello scarico |
| Emissioni aria  | Fumo, gas               | Monitoraggio, filtri            |

<InfoCard variant="warning" title="Rifiuti B3">
**I rifiuti pericolosi (B3)** richiedono:
- Stoccaggio separato
- Trasportatore autorizzato
- Impianto di smaltimento autorizzato
- Documentazione del manifesto
- Rapporti regolari

Le violazioni possono comportare gravi sanzioni.

</InfoCard>

---

## Sanzioni per Inosservanza

| Violazione                 | Sanzione                       |
| -------------------------- | ------------------------------ |
| Operare senza permesso     | Chiusura + multe               |
| Superamento degli standard | Avvisi → multe → chiusura      |
| Smaltimento improprio      | Possibili accuse penali        |
| Rapporti falsi             | Revoca del permesso            |
| Violazioni B3              | Responsabilità penale + civile |
