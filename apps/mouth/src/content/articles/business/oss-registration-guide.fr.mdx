# Système OSS : Enregistrement Commercial En Ligne Simplifié 2026

OSS (Online Single Submission) est la plateforme en ligne intégrée de l'Indonesia pour toutes les enregistrements et permis commerciaux. C'est votre guichet unique pour le NIB, les licences commerciales et les permis opérationnels.

<InfoCard variant="warning" title="Aggiornamento 2026 (Fonte: oss.go.id)">
**PP 28/2025 - Nuove Regole di Licensing:**

Il Regolamento Governativo 28/2025 è pienamente implementato nel sistema OSS-RBA dal 2025:

1. **Risk-Based Approach potenziato** - Classificazione del rischio più granulare per KBLI codes
2. **Integrazione inter-ministeriale** - Connessione diretta con BKPM, Kemenkumham, DJP
3. **Tempi ridotti** - Obiettivo di elaborazione più rapida per attività a basso rischio
4. **LKPM digitale** - Reporting investimenti completamente online

**Nota Importante**: PP 28/2025 aggiorna ma non sostituisce completamente le regole precedenti. Alcune procedure specifiche del settore possono ancora richiedere approvazioni separate.

</InfoCard>

## Qu'est-ce que l'OSS ?

L'OSS a remplacé l'ancien système de visite de plusieurs bureaux gouvernementaux. Désormais, pratiquement tous les permis commerciaux transitent par cette plateforme unique à **oss.go.id**.

### Évolution de l'OSS

| Version     | Période      | Fonctionnalités Clés                           |
| ----------- | ------------ | ---------------------------------------------- |
| OSS 1.0     | 2018-2020    | Lancement initial                              |
| OSS 1.1     | 2020-2021    | Améliorations                                  |
| **OSS RBA** | 2021-Présent | Approche Basée sur les Risques, système actuel |

## Approche Basée sur les Risques (RBA)

L'OSS utilise un système basé sur les risques pour déterminer les permis dont vous avez besoin :

<InfoCard variant="note" title="Comment le Risque est Déterminé">
Vos **KBLI codes** déterminent le niveau de risque :

- **Faible Risque**: Activités de base (conseil, services informatiques) - NIB seulement
- **Moyen-Faible**: Une certaine conformité nécessaire - NIB + Sertifikat Standar
- **Moyen-Élevé**: Vérification requise - NIB + Sertifikat Standar + Inspection
- **Élevé Risque**: Licence complète - NIB + Izin + Audits réguliers

Le système classe automatiquement lorsque vous sélectionnez vos codes KBLI.

</InfoCard>

### Développements possibles de l'OSS (OPINION)

1. **OSS 3.0** - Il est question d'une possible nouvelle version du système OSS avec une interface améliorée et des temps de traitement plus rapides. Certains experts prévoient un lancement en 2026-2027. _Aucune annonce officielle._

2. **Intégration internationale** - Il y a des discussions sur une possible intégration avec des systèmes de vérification d'identité internationaux pour simplifier l'enregistrement des entreprises étrangères. _Pure spéculation._

3. **KBLI automatique** - Il est question d'un système de recommandation automatique des codes KBLI basé sur la description de l'activité. _En phase d'étude._

4. **Application mobile OSS** - Certains estiment qu'une application mobile officielle sera lancée pour gérer les permis et les rapports depuis un smartphone. _Non confirmé._

5. **Blockchain pour les documents** - Il y a des discussions sur l'utilisation de la blockchain pour la vérification et l'authentification des documents d'entreprise dans le système OSS. _Discussion académique._

**Rappel**: Pour des informations officielles, consultez toujours oss.go.id.
