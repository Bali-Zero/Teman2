## Perché il Software di Contabilità è Importante per PT PMA

Scegliere il software di contabilità giusto è una delle decisioni più impattanti per la gestione finanziaria di un PT PMA. L'ambiente fiscale complesso dell'Indonesia -- con PPh 21, PPh 25, PPh 23/26, IVA (PPN) mensili e il nuovo sistema CoreTax -- significa che la contabilità manuale su fogli di calcolo non è più praticabile per la maggior parte delle aziende.

Il software giusto automatizza i calcoli fiscali, genera report conformi, si integra con i sistemi governativi e ti dà visibilità in tempo reale sulla salute finanziaria della tua azienda.

## Integrazione e-Faktur: Perché è Importante

### Cos'è e-Faktur?

e-Faktur (fattura IVA elettronica) è il sistema obbligatorio del DJP per creare, approvare e riportare fatture IVA. Se il tuo PT PMA è registrato come PKP (soggetto riscossione IVA), ogni transazione tassabile deve avere un e-Faktur.

### Come Funziona l'Integrazione

**Senza integrazione (processo manuale):**

1. Crea fattura di vendita nel software di contabilità
2. Accedi all'applicazione DJP e-Faktur
3. Inserisci manualmente gli stessi dati della fattura
4. Carica per l'approvazione del DJP
5. Scarica l'e-Faktur approvato
6. Registra manualmente il numero di approvazione nel software di contabilità

**Con integrazione (Jurnal.id o Accurate):**

1. Crea fattura di vendita nel software di contabilità
2. Clicca "Genera e-Faktur"
3. Il sistema invia automaticamente al DJP
4. L'e-Faktur approvato viene registrato nel software di contabilità
5. Il report IVA mensile viene generato automaticamente

I risparmi di tempo sono significativi -- da 15-30 minuti per fattura (manuale) a 30 secondi (integrato).

## CoreTax: Il Nuovo Sistema del DJP

### Cos'è CoreTax?

CoreTax (Sistem Inti Administrasi Perpajakan) è la piattaforma di amministrazione fiscale di nuova generazione del DJP. Mira a consolidare tutti i servizi fiscali:

| Sistema Vecchio | Sostituzione CoreTax         |
| --------------- | ---------------------------- |
| e-Filing        | Modulo filing CoreTax        |
| e-Billing       | Modulo pagamento CoreTax     |
| e-Faktur        | Modulo fatture CoreTax       |
| e-SPT           | Modulo dichiarazioni CoreTax |

### Impatto sul Software di Contabilità

CoreTax introduce un approccio basato su API, significa che il software di contabilità potenzialmente può:

- Inviare dichiarazioni fiscali direttamente al DJP
- Recuperare automaticamente i dati del contribuente
- Validare e-Faktur in tempo reale
- Ricevere notifiche sugli obblighi fiscali

**Stato attuale (2026):** CoreTax è in fase di rollout graduale. Jurnal.id e Accurate hanno annunciato l'integrazione API, ma la piena funzionalità è ancora in fase di finalizzazione. La maggior parte delle aziende PT PMA usa ancora i sistemi legacy e-Faktur ed e-Filing insieme a CoreTax.

2. Continua la riconciliazione mensile
3. Assicurati che le dichiarazioni fiscali corrispondano ai report del software
4. Configura backup regolari

## Domande Frequenti

### Il software di contabilità deve integrarsi con e-Faktur?

Se il tuo PT PMA è registrato come PKP (soggetto riscossione IVA), l'integrazione e-Faktur è essenziale. Jurnal.id e Accurate hanno entrambi integrazione diretta e-Faktur che permette di generare, gestire e riportare fatture IVA all'interno del software. Senza integrazione, devi esportare manualmente i dati all'applicazione DJP e-Faktur, il che richiede tempo ed è soggetto a errori.

### Posso usare software internazionali come Xero o QuickBooks per un PT PMA?

Sì, ma con limitazioni. Xero e QuickBooks possono gestire la contabilità generale in IDR ma non si integrano nativamente con i sistemi fiscali indonesiani (e-Faktur, CoreTax, calcolatore PPh 21). Avrai bisogno di un processo separato per la conformità fiscale. Molti PT PMA usano Xero per la reportistica di gestione e uno strumento locale per le dichiarazioni fiscali.

### Cos'è CoreTax e il mio software deve supportarlo?

CoreTax è il nuovo sistema integrato di amministrazione fiscale del DJP lanciato a fasi dal 2024-2026. Sostituisce i precedenti sistemi e-Filing, e-Billing ed e-Faktur con una piattaforma unica. Il software di contabilità con integrazione API CoreTax può inviare automaticamente dichiarazioni fiscali e recuperare dati fiscali. Jurnal.id e Accurate hanno annunciato l'integrazione CoreTax per il 2026.
