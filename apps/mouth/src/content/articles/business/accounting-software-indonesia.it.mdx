## Perché il software contabile è importante per una PT PMA

Scegliere il software contabile giusto è una delle decisioni più influenti per la gestione finanziaria di una PT PMA. L'ambiente fiscale complesso dell'Indonesia -- con il PPh 21 mensile, PPh 25, PPh 23/26, IVA (PPN) e il nuovo sistema CoreTax -- significa che la contabilità manuale su fogli di calcolo non è più praticabile per la maggior parte delle aziende.

Il software giusto automatizza i calcoli fiscali, genera report conformi, si integra con i sistemi governativi e ti dà una visibilità in tempo reale sulla salute finanziaria della tua azienda.

## Requisiti principali per il software contabile indonesiano

Prima di confrontare le opzioni, capisci cosa serve realmente alla tua PT PMA:

### Funzionalità obbligatorie

| Funzionalità                    | Perché è importante                                                    |
| -------------------------- | ----------------------------------------------------------------- |
| Supporto multi-valuta IDR     | Tutti i libri devono essere in Rupiah; le transazioni straniere richiedono la conversione |
| Integrazione e-Faktur         | Genera e gestisci fatture IVA per le aziende PKP                |
| Calcolatore PPh 21            | Calcola automaticamente l'imposta sul reddito dei dipendenti                       |

| Cloud-based                   | Accesso da qualsiasi luogo, backup automatici                           |

## Integrazione e-Faktur: Perché è importante

### Cos'è l'e-Faktur?

L'e-Faktur (fattura IVA elettronica) è il sistema obbligatorio del DJP per creare, approvare e reportare le fatture IVA. Se la tua PT PMA è registrata come PKP (raccoglitore IVA), ogni transazione imponibile deve avere un e-Faktur.

### Come funziona l'integrazione

**Senza integrazione (processo manuale):**

1. Crea la fattura di vendita nel software contabile
2. Accedi all'applicazione e-Faktur del DJP
3. Inserisci manualmente gli stessi dati della fattura
4. Carica per l'approvazione del DJP
5. Scarica l'e-Faktur approvato
6. Registra manualmente il numero di approvazione nel software contabile

**Con integrazione (Jurnal.id o Accurate):**

1. Crea la fattura di vendita nel software contabile
2. Clicca su "Genera e-Faktur"
3. Il sistema invia automaticamente al DJP
4. L'e-Faktur approvato viene registrato nel software contabile
5. Il report IVA mensile viene generato automaticamente

Il risparmio di tempo è significativo -- da 15-30 minuti per fattura (manuale) a 30 secondi (integrato).

## CoreTax: Il nuovo sistema del DJP

### Cos'è CoreTax?

CoreTax (Sistem Inti Administrasi Perpajakan) è la piattaforma di amministrazione fiscale di prossima generazione del DJP. L'obiettivo è unificare tutti i servizi fiscali:

| Vecchio Sistema | Sostituzione CoreTax    |
| ---------- | ---------------------- |
| e-Filing   | Modulo di presentazione CoreTax  |
| e-Billing  | Modulo di pagamento CoreTax |
| e-Faktur   | Modulo di fattura CoreTax |
| e-SPT      | Modulo di dichiarazioni CoreTax |

### Impatto sul software contabile

CoreTax introduce un approccio basato su API, il che significa che il software contabile può potenzialmente:

- Presentare le dichiarazioni fiscali direttamente al DJP
- Recuperare automaticamente i dati del contribuente
- Validare l'e-Faktur in tempo reale
- Ricevere notifiche sugli obblighi fiscali

**Stato attuale (2026):** CoreTax sta venendo implementato in fasi. Jurnal.id e Accurate hanno annunciato l'integrazione API, ma la funzionalità completa è ancora in fase di definizione. La maggior parte delle aziende PT PMA utilizza ancora i sistemi legacy e-Faktur e e-Filing insieme a CoreTax.

### Fase 4: Go Live

1. Passa completamente al nuovo sistema
2. Continua a conciliare mensilmente
3. Assicurati che le dichiarazioni fiscali corrispondano ai report del software
4. Configura i backup regolari

## Domande frequenti

### Il software contabile deve integrarsi con e-Faktur?

Se la tua PT PMA è registrata come PKP (raccoglitore IVA), l'integrazione e-Faktur è essenziale. Jurnal.id e Accurate hanno entrambi un'integrazione diretta e-Faktur che ti permette di generare, gestire e reportare le fatture IVA all'interno del software. Senza integrazione, devi esportare manualmente i dati nell'applicazione e-Faktur del DJP, il che è tempo consumante e soggetto a errori.

### Posso utilizzare software internazionale come Xero o QuickBooks per una PT PMA?

Sì, ma con limitazioni. Xero e QuickBooks possono gestire la contabilità generale in IDR ma non integrano nativamente i sistemi fiscali indonesiani (e-Faktur, CoreTax, calcolatore PPh 21). Avrai bisogno di un processo separato per la conformità fiscale. Molte PT PMA utilizzano Xero per la reportistica gestionale e uno strumento locale per le dichiarazioni fiscali.

### Cos'è CoreTax e il mio software deve supportarlo?

CoreTax è il nuovo sistema di amministrazione fiscale integrato del DJP lanciato in fasi dal 2024-2026. Sostituisce i sistemi precedenti e-Filing, e-Billing e e-Faktur con una singola piattaforma. Il software contabile con integrazione API CoreTax può inviare automaticamente le dichiarazioni fiscali e recuperare i dati fiscali. Jurnal.id e Accurate hanno annunciato l'integrazione CoreTax per il 2026.
