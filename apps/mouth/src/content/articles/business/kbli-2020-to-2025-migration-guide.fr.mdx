## La réinitialisation de la classification

Sur le papier, la migration du KBLI 2020 vers le KBLI 2025 semble simple : trouver votre ancien code, rechercher le nouveau, mettre à jour vos dossiers. En pratique, c'est tout sauf cela. Le **Règlement BPS n° 7 de 2025** n'a pas simplement renuméroté les codes existants. Il a restructuré l'ensemble de la hiérarchie de classification, l'a alignée sur la norme internationale CITI Révision 5 et a fondamentalement modifié la façon dont l'Indonesia catégorise l'activité économique.

Le résultat : les quelque 1 790 codes à cinq chiffres du KBLI 2020 ont été réorganisés en environ 1 562 codes à cinq chiffres répartis en 22 catégories (contre 21 auparavant). Certains codes sont restés intacts. Beaucoup ont été divisés en activités plus spécifiques. D'autres ont été fusionnés, consolidés ou entièrement éliminés. La date limite de conformité obligatoire est le **18 juin 2026**.

Ce guide vous explique précisément ce qui a changé, comment trouver votre nouveau code et quoi faire lorsqu'il n'y a pas de correspondance directe. Si vous êtes entièrement nouveau au KBLI, commencez par notre [Guide du débutant pour le KBLI 2025](/insights/beginners-guide-kbli-2025) d'abord, puis revenez ici pour les spécificités de la migration.

## Les quatre types de modifications de code

Chaque code KBLI 2020 relève de l'un des quatre scénarios de migration. Comprendre quel scénario s'applique à votre entreprise détermine votre stratégie de migration.

### 1. Correspondance directe (1:1)

Le cas le plus simple. Votre ancien code KBLI 2020 a un équivalent unique et direct dans le KBLI 2025. Le numéro de code a peut-être changé, mais la description de l'activité reste substantiellement la même.

**Action requise :** Mettez à jour le code dans vos dossiers. Aucune analyse supplémentaire n'est nécessaire.

**Exemple :** Les activités de vente au détail de base, les catégories de fabrication standard et les codes agricoles simples ont souvent des correspondances directes. Le tableau de concordance du BPS affichera une seule flèche de l'ancien au nouveau.

### 2. Codes divisés (1:Plusieurs)

C'est le changement le plus courant et le plus important du KBLI 2025. Un code KBLI 2020 général a été divisé en plusieurs codes KBLI 2025 plus spécifiques. Vous devez choisir le code qui décrit le plus précisément votre activité commerciale réelle.

**Action requise :** Examinez tous les nouveaux codes dérivés de votre ancien code. Sélectionnez la correspondance la plus spécifique en fonction de ce que votre entreprise fait réellement — et non de ce que votre ancien code couvrait de manière générique.

**Exemple immobilier :** Sous le KBLI 2020, le secteur immobilier était couvert par environ 5 codes. Le KBLI 2025 étend cela à **14 codes** — une augmentation de 180 %. Une entreprise précédemment classée sous un code général "activités immobilières" doit maintenant déterminer si elle est engagée dans le développement de propriétés résidentielles, la gestion de propriétés commerciales, la subdivision de terrains, le courtage immobilier ou les services d'évaluation immobilière. Chacun a son propre code, son propre niveau de risque et ses propres exigences en matière de licence.

**Exemple informatique et télécommunications :** La catégorie I (Information et Communication) du KBLI 2020 a été divisée en deux catégories entièrement nouvelles :

| KBLI 2020  | KBLI 2025      | Portée                                                                   |
| ---------- | -------------- | ------------------------------------------------------------------------ |
| Category I | **Category J** | Production de contenu, édition, médias et diffusion                      |
| Category I | **Category K** | Télécommunications, services informatiques et développement de logiciels |

Si votre entreprise était classée sous la Catégorie I, vous devez maintenant déterminer si votre activité principale relève du contenu/édition (J) ou de la technologie/services informatiques (K). Une agence numérique qui produit à la fois du contenu et développe des logiciels pourrait avoir besoin de codes des deux catégories.

### 3. Codes fusionnés (Plusieurs:1)

L'inverse de la division. Plusieurs codes KBLI 2020 ont été consolidés en un seul code KBLI 2025. Cela se produit généralement lorsque le BPS a déterminé que les distinctions précédentes étaient inutilement granulaires ou n'avaient plus de signification économique.

**Action requise :** Confirmez que le nouveau code unifié couvre votre activité. Si votre entreprise détenait plusieurs anciens codes qui fusionnent maintenant en un seul, vous pourriez simplifier votre NIB en listant moins de codes.

### 4. Codes obsolètes (1:0)

Certains codes KBLI 2020 n'ont pas d'équivalent direct dans le KBLI 2025. L'activité a été soit absorbée dans une catégorie plus large, reclassée sous une section entièrement différente, soit jugée obsolète.

**Action requise :** C'est le scénario le plus complexe. Vous devez analyser vos opérations commerciales réelles et trouver le code KBLI 2025 le plus proche. Dans certains cas, vous pourriez avoir besoin de conseils professionnels pour déterminer la classification correcte, surtout si le code obsolète chevauche plusieurs nouvelles catégories.

## Comment trouver votre nouveau code KBLI

Suivez ce processus systématique pour mapper chaque code KBLI 2020 de votre NIB à son équivalent KBLI 2025.

### Étape 1 : Inventoriez vos codes actuels

Extrayez votre NIB actuel du [système OSS](https://oss.go.id). Listez chaque code KBLI 2020 enregistré pour votre entreprise. Pour chaque code, notez :

- Le numéro de code à cinq chiffres
- La description de l'activité (en Bahasa Indonesia)
- Si l'activité est réellement exercée

Ce dernier point est important. De nombreuses entreprises ont enregistré des codes "ambitieux" lors de la configuration initiale qu'elles n'ont jamais réellement utilisés. La migration est l'occasion de nettoyer votre NIB.

### Étape 2 : Consultez le tableau de concordance du BPS

Le BPS publie un tableau de concordance officiel (_tabel korespondensi_) mappant les codes KBLI 2020 aux codes KBLI 2025. C'est votre document de référence principal. Pour chacun de vos codes, le tableau indiquera l'un des quatre scénarios décrits ci-dessus.

### Étape 3 : Validez par rapport à vos opérations réelles

Pour les codes divisés et les codes obsolètes, ne choisissez pas simplement la première option du tableau de concordance. Faites correspondre le code à ce que votre entreprise fait réellement sur le terrain. Un mauvais code peut entraîner :

- **Classification de risque incorrecte** — déclenchant des permis ou des inspections inutiles
- **Restrictions sur la propriété étrangère** — certains nouveaux codes ont des seuils PMA différents
- **Désalignement fiscal** — votre KLU (classification fiscale) découle de votre KBLI, affectant les références fiscales et les obligations de déclaration
- **Problèmes de licence d'importation** — l'éligibilité API-U vs API-P dépend de votre catégorie KBLI

Pour une analyse approfondie de l'interaction entre KBLI et KLU avec la politique fiscale, consultez notre [analyse du contrôle fiscal KBLI-KLU](/insights/kbli-klu-fiscal-control-2025).

### Étape 4 : Documentez vos décisions de mappage

Pour chaque code où le mappage n'est pas un simple 1:1, créez une justification écrite expliquant pourquoi vous avez sélectionné un code KBLI 2025 particulier. Incluez :

- L'ancien code et sa description
- Le nouveau code et sa description
- Une brève explication de la raison pour laquelle ce code correspond à vos opérations
- Preuves à l'appui (profil d'entreprise, SIUP, permis d'exploitation)

Cette documentation a deux objectifs : elle vous protège lors de tout audit réglementaire, et elle fournit un enregistrement clair pour votre comptable et votre équipe juridique.

### Étape 5 : Préparez le dossier de mise à jour

Compilez votre mappage de codes complet dans un seul document. Cela deviendra l'ensemble d'instructions pour la personne qui exécutera la mise à jour dans OSS une fois le système prêt. Incluez :

- Tableau de mappage Ancien code → Nouveau code
- Justifications à l'appui pour les mappages non évidents
- Tous les codes à supprimer (activités non plus exercées)
- Tous les nouveaux codes à ajouter (nouvelles activités permises par le KBLI 2025)

## La transition OSS : Préparez maintenant, exécutez plus tard

Voici la réalité opérationnelle critique en février 2026 : **le système OSS n'a pas encore entièrement intégré les codes KBLI 2025**. Vous ne pouvez pas actuellement exécuter une migration KBLI via OSS.

Cela crée une fenêtre stratégique. Le gouvernement a imposé la conformité d'ici le 18 juin 2026, ce qui signifie que l'OSS sera mis à jour avant cette date limite. L'approche intelligente :

| Phase            | Calendrier                       | Action                                                                                                  |
| ---------------- | -------------------------------- | ------------------------------------------------------------------------------------------------------- |
| **Préparation**  | De maintenant jusqu'à avril 2026 | Complétez votre mappage de codes, documentez les justifications, préparez le dossier de mise à jour     |
| **Suivi**        | De mars à mai 2026               | Surveillez les mises à jour du système OSS, les circulaires ministérielles et les directives techniques |
| **Exécution**    | Lorsque l'OSS est prêt           | Soumettez vos mises à jour de code via le système immédiatement                                         |
| **Vérification** | Après la soumission              | Confirmez que votre NIB mis à jour reflète les codes KBLI 2025 corrects                                 |

Les entreprises qui attendent la dernière minute feront face à un goulot d'étranglement. Lorsque l'OSS ouvrira pour les mises à jour KBLI 2025, toutes les entreprises en Indonesia se précipiteront pour se conformer avant la date limite. Avoir votre mappage prêt à l'avance signifie que vous pouvez exécuter en quelques heures, et non en quelques semaines.

## Que se passe-t-il si vous manquez la date limite

La date limite du 18 juin 2026 n'est pas symbolique. Après cette date, les codes KBLI 2020 ne seront plus reconnus pour :

- **Nouvelles demandes de permis** — toute nouvelle licence ou permis nécessitera des codes KBLI 2025
- **Rapports LKPM** — votre rapport trimestriel d'activité d'investissement doit utiliser la nouvelle classification
- **Approbations d'importation** — les systèmes des douanes et du ministère du commerce feront référence au KBLI 2025
- **Renouvellements de licences** — lorsque vos permis existants arriveront à échéance, les anciens codes ne seront pas traités
- **Administration fiscale** — l'alignement du DJP avec le KBLI 2025 affecte votre KLU et vos références fiscales

Vos permis existants ne s'évaporeront pas du jour au lendemain. Mais toute nouvelle interaction réglementaire — déposer un rapport, renouveler une licence, demander un quota d'importation — nécessitera les codes mis à jour. L'effet pratique est qu'une entreprise bloquée sur les codes KBLI 2020 après la date limite ne pourra pas mener ses opérations commerciales normales.

## Considérations spéciales pour les entreprises à capitaux étrangers (PT PMA)

La migration a des implications supplémentaires pour les entités PT PMA :

**Les seuils de propriété étrangère peuvent changer.** Lorsqu'un code se divise, les nouveaux codes résultants peuvent avoir des entrées différentes dans le _Daftar Negatif Investasi_ (DNI) ou la nouvelle Liste d'Investissement Positive. Une PT PMA qui était détenue à 100 % par des étrangers sous un code KBLI 2020 large doit vérifier que le code KBLI 2025 spécifique vers lequel elle migre permet toujours une propriété étrangère à 100 %.

**Alignement du plan d'investissement.** Votre plan d'investissement approuvé par le BKPM fait référence à des codes KBLI spécifiques. Un changement de code peut déclencher la nécessité de mettre à jour votre _Rencana Penanaman Modal_ (plan d'investissement) via le BKPM, en particulier si le nouveau code relève d'une classification sectorielle différente.

**Implications RPTKA.** Votre quota de travailleurs étrangers (RPTKA) est lié à vos codes KBLI. Une migration vers une catégorie sectorielle différente pourrait affecter vos postes et ratios approuvés.

## Liste de contrôle de migration étape par étape

Utilisez ceci comme votre liste de contrôle opérationnelle :

1.  **Exportez votre NIB actuel** depuis OSS — capturez tous les codes KBLI 2020 enregistrés
2.  **Obtenez le tableau de concordance du BPS** — le document officiel de mappage KBLI 2020 vers 2025
3.  **Classifiez chaque code** dans l'un des quatre scénarios : correspondance directe, divisé, fusionné ou obsolète
4.  **Pour les codes divisés** — analysez vos opérations réelles et sélectionnez le nouveau code le plus spécifique
5.  **Pour les codes obsolètes** — recherchez l'équivalent KBLI 2025 le plus proche ; envisagez une consultation professionnelle
6.  **Pour les codes fusionnés** — confirmez le code unifié et identifiez toute opportunité de simplification du NIB
7.  **Documentez toutes les décisions de mappage** avec des justifications écrites
8.  **Examinez les implications PMA** — vérifiez la propriété étrangère, le plan d'investissement et l'alignement RPTKA
9.  **Préparez votre dossier de mise à jour** — un document unique prêt pour la soumission à OSS
10. **Surveillez la préparation d'OSS** — abonnez-vous aux circulaires gouvernementales et aux associations industrielles pour les annonces de mise à jour
11. **Exécutez immédiatement** lorsque l'OSS ouvre pour le KBLI 2025 — n'attendez pas la ruée de dernière minute
12. **Vérifiez votre NIB mis à jour** — confirmez que tous les codes sont correctement enregistrés après la soumission

## En résumé

La migration KBLI n'est pas une simple case à cocher bureaucratique. La reclassification du KBLI 2020 au KBLI 2025 modifie les niveaux de risque, les règles de propriété, les références fiscales et les exigences en matière de licence. Un code choisi avec négligence peut coûter à votre entreprise l'accès à des incitations, déclencher des charges de conformité inutiles ou créer des complications de propriété étrangère qui prennent des mois à résoudre.

Les entreprises qui navigueront en douceur cette transition sont celles qui se préparent dès maintenant — en mappant les codes, en documentant les décisions et en préparant leurs dossiers de mise à jour — afin de pouvoir exécuter dès que l'OSS sera prêt.
