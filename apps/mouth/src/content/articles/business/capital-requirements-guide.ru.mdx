# PT PMA Требования к капиталу Индонезия 2026: Руководство для инвесторов

Понимание требований к капиталу имеет решающее значение для иностранных инвесторов в Индонезии. Вот что вам нужно знать.

## Обзор структуры капитала

<InfoCard variant="note" title="Two Types of Capital">
**PT PMA имеет два вида капитала:**

1.  **Уставный капитал** (Modal Dasar) - Максимальный капитал, который может иметь компания
2.  **Оплаченный капитал** (Modal Disetor) - Фактически инвестированный капитал

Оба имеют минимальные требования для иностранных инвестиций.

</InfoCard>

---

## Текущие требования

### Стандартные минимумы для PT PMA

| Тип капитала               | Минимальная сумма                                                          |
| :------------------------- | :------------------------------------------------------------------------- |
| **Общий объем инвестиций** | 10 миллиардов IDR (~625 000 долларов США)                                  |
| **Оплаченный капитал**     | 10 миллиардов IDR (должен соответствовать общему объему инвестиций сейчас) |
| **На акционера**           | Минимум 10 миллионов IDR                                                   |

<InfoCard variant="warning" title="2021 Changes">
**Важное изменение:**

Согласно действующим правилам, оплаченный капитал должен быть равен общему объему инвестиционных обязательств. Это означает, что вам необходимо фактически иметь и инвестировать минимум 10 миллиардов IDR.

Это значительное увеличение по сравнению с предыдущими требованиями.

</InfoCard>

---

## Инвестиции против оплаченного капитала

### В чем разница?

| Понятие                | Значение                                                        |
| :--------------------- | :-------------------------------------------------------------- |
| Общий объем инвестиций | Все ресурсы для бизнеса (капитал + займы + оборудование)        |
| Оплаченный капитал     | Фактические денежные средства/активы, внесенные акционерами     |
| Уставный капитал       | Максимальное количество акций, которое может выпустить компания |

## Секторные требования

### Некоторые секторы имеют более высокие минимумы

| Сектор                         | Дополнительные требования                 |
| :----------------------------- | :---------------------------------------- |
| Банковское дело                | Значительно выше (миллиарды долларов США) |
| Страхование                    | Особые требования к капиталу              |
| Горнодобывающая промышленность | Более высокие инвестиционные пороги       |
| Телекоммуникации               | Особые требования                         |
| Образование                    | Применяется минимум 10 миллиардов IDR     |
| Здравоохранение                | Могут быть дополнительные требования      |

<InfoCard variant="note" title="Check Your KBLI">
**Требования к секторам различаются:**

Некоторые классификации видов деятельности (коды KBLI) имеют особые требования к капиталу, превышающие стандартный минимум. Всегда проверяйте требования для вашей конкретной деятельности.

</InfoCard>

## Расчет капитала

### Что учитывается при инвестировании?

| Учитывается                    | Не учитывается                    |
| :----------------------------- | :-------------------------------- |
| Денежные вклады                | Будущие доходы                    |
| Оборудование (оцененное)       | Деловая репутация                 |
| Земля/здания                   | Прогнозируемый доход              |
| Интеллектуальная собственность | Неоцененные нематериальные активы |
| Первоначальный запас           | Операционные расходы              |

## Взнос активов

### Неденежный капитал

<InfoCard variant="tip" title="Contributing Assets">
**Вы можете вносить активы вместо всех наличных средств:**

- Оборудование (машины, транспортные средства)
- Интеллектуальная собственность (патенты, товарные знаки)
- Недвижимость (земля, здания)

**Требования:**

- Должны быть оценены сертифицированным оценщиком
- Отчет об оценке представляется Notaris
- Активы должны быть переданы компании
- Документированы в учредительном договоре компании
  </InfoCard>

### Процесс оценки

| Шаг | Действие                                        |
| :-- | :---------------------------------------------- |
| 1   | Привлечь сертифицированного оценщика            |
| 2   | Предоставить документацию по активам            |
| 3   | Оценщик осматривает/оценивает                   |
| 4   | Получить отчет об оценке                        |
| 5   | Представить Notaris                             |
| 6   | Зафиксировать в учредительном договоре компании |

## Частые вопросы

### Часто задаваемые вопросы

<InfoCard variant="note" title="Can I Start Smaller?">
**Частый вопрос:** Могу ли я начать с меньшего капитала?

**Ответ:**

- Для стандартной PT PMA требуется минимум 10 миллиардов IDR
- Некоторые особые зоны могут иметь другие правила
