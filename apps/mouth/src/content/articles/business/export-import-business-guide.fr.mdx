# Activités d'Export-Import en Indonésie 2026 : Guide Complet

La position stratégique de l'Indonésie et son vaste marché en font un lieu idéal pour le commerce international. Voici comment les étrangers peuvent établir des opérations d'import-export.

## Aperçu des Activités Commerciales

L'Indonésie offre :

- Un marché de consommation de **270 millions**
- Une position stratégique au sein de l'ASEAN
- Une base manufacturière en croissance
- De riches ressources naturelles pour l'exportation
- Des accords de libre-échange avec les principaux marchés

### Licence d'Exportation

Pour les exportations, vous avez besoin :

- **ET (Eksportir Terdaftar)** - Exportateur Enregistré pour certaines marchandises
- Certains produits nécessitent des permis d'exportation spécifiques
- La plupart des produits peuvent être exportés avec juste un NIB

## Structure Commerciale

### PT PMA pour le Négoce

Les sociétés de négoce à capitaux étrangers peuvent :

- Importer des marchandises pour la revente
- Exporter des produits indonésiens
- Agir en tant que distributeur
- Vendre en gros aux détaillants

<InfoCard variant="note" title="Exigence d'Investissement">
  Une PT PMA de négoce requiert : - Un investissement minimum de **10 milliards IDR** - Un capital
  libéré de **2,5 milliards IDR** - Des installations d'entrepôt appropriées (pour certaines
  marchandises) - Des codes d'import-export enregistrés
</InfoCard>

## Douanes et Droits

### Droits d'Importation

| Catégorie          | Taux de Droit | Remarques                  |
| ------------------ | ------------- | -------------------------- |
| Matières premières | 0-5%          | Souvent plus bas           |
| Semi-finis         | 5-15%         | Varie selon le produit     |
| Produits finis     | 10-40%        | Protection plus élevée     |
| Articles de luxe   | 20-200%       | Taxe de luxe additionnelle |

### Autres Frais d'Importation

- **TVA (PPN)** : 11% sur CIF + droit
- **Impôt sur le Revenu (PPh 22)** : 2,5% avec API, 7,5% sans
- **Taxe de Luxe (PPnBM)** : Sur certaines marchandises

<InfoCard variant="tip" title="Recherche de Code HS">
Recherchez le **Code HS** (Système Harmonisé) de votre produit pour comprendre :
- Le taux de droit applicable
- Les restrictions d'importation
- Les permis requis
- Les besoins en documentation

Utilisez le portail INSW de l'Indonésie pour la recherche de codes HS.

</InfoCard>

## Restrictions sur les Produits

### Restrictions à l'Importation

Certains produits nécessitent des permis supplémentaires :

- **Aliments/Boissons** : Enregistrement BPOM
- **Électronique** : Certification SNI
- **Cosmétiques** : BPOM + Halal
- **Produits Pharmaceutiques** : Licences strictes
- **Textiles** : Des systèmes de quotas peuvent s'appliquer

### Articles Prohibés

- Drogues/stupéfiants
- Armes (sans licence)
- Certains produits agricoles
- Produits violant les droits de propriété intellectuelle
- Articles contraires à la moralité publique

## Opportunités d'Exportation

### Principales Exportations Indonésiennes

1. Produits à base d'huile de palme
2. Charbon et minéraux
3. Textiles et vêtements
4. Produits en caoutchouc
5. Électronique
6. Aliments transformés
7. Meubles et artisanat

### Exigences d'Exportation

- ET (Exportateur Enregistré) pour certaines marchandises
- Documentation d'exportation (facture, liste de colisage, etc.)
- Inspection avant expédition (certains produits)
- Certificat d'origine (pour les taux préférentiels)

- Reporter les droits d'importation jusqu'à ce que les marchandises entrent sur le marché intérieur
- Facilités en matière de TVA et d'impôt sur le revenu
- Procédures douanières simplifiées
- Idéal pour la fabrication destinée à l'exportation

## Erreurs Courantes

<InfoCard variant="error" title="Évitez Ces Erreurs">
  1. **Mauvais type d'API** - API-U vs API-P doit correspondre à l'activité 2. **Ignorer les
  réglementations sur les produits** - Certaines marchandises nécessitent des permis spéciaux 3.
  **Sous-évaluer les marchandises** - Les pénalités douanières sont sévères 4. **Absence de
  documentation appropriée** - Retards et coûts supplémentaires 5. **Mauvais code HS** - Droits
  différents, pénalités potentielles 6. **Ignorer les quotas/restrictions** - Certains produits sont
  limités
</InfoCard>
