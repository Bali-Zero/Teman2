# NIB Explained: Ваш индонезийский идентификационный номер предприятия 2026

NIB (Nomor Induk Berusaha) является краеугольным камнем регистрации бизнеса в Indonesia. Думайте о нем как о национальном удостоверении личности вашей компании — оно требуется практически для всего.

## Что заменяет NIB

NIB объединил несколько ранее отдельных лицензий:

| Старая лицензия          | Функция                        | Теперь часть NIB |
| :----------------------- | :----------------------------- | :--------------- |
| **TDP**                  | Регистрация компании           | ✓ Заменено       |
| **API-U**                | Идентификатор общего импортера | ✓ Заменено       |
| **Angka Pengenal Impor** | Номер импорта                  | ✓ Заменено       |
| **Доступ к таможне**     | Таможенное оформление          | ✓ Включено       |

<InfoCard variant="tip" title="Один номер, много функций">
  NIB упрощает регистрацию бизнеса. Вместо получения нескольких отдельных
  лицензий, вы получаете один NIB, который служит множеству целей. Это стало
  значительным улучшением по сравнению с системой, существовавшей до 2018 года.
</InfoCard>

## NIB и классификация рисков

В соответствии с OSS RBA (подходом, основанным на рисках), ваш NIB определяет, какие дополнительные разрешения вам потребуются:

| Уровень риска      | NIB + что еще?                         |
| :----------------- | :------------------------------------- |
| **Низкий риск**    | Только NIB                             |
| **Средне-низкий**  | NIB + Sertifikat Standar               |
| **Средне-высокий** | NIB + Sertifikat Standar + Верификация |
| **Высокий риск**   | NIB + Полный Izin (лицензия)           |

<InfoCard variant="note" title="Риск определяется KBLI">
  Коды вашей деловой активности (KBLI) определяют уровень риска. Консалтинг в
  сфере технологий обычно имеет средне-низкий риск. Производство продуктов
  питания имеет более высокий риск. Система OSS автоматически классифицирует на
  основе вашего выбора KBLI.
</InfoCard>
