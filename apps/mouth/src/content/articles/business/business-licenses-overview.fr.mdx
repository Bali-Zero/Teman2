# Licences Commerciales en Indonésie 2026 : Aperçu Complet

L'Indonésie a rationalisé l'octroi des licences commerciales grâce au système OSS (Online Single Submission), mais comprendre ce dont vous avez besoin peut encore être complexe.

## Cadre de Licences

<InfoCard variant="note" title="OSS System">
Depuis la **Loi sur la Création d'Emplois (Omnibus Law)**, l'Indonésie utilise le système **OSS RBA** (Risk-Based Approach) :

- Toutes les entreprises s'enregistrent via OSS
- Reçoivent le **NIB** (Nomor Induk Berusaha)
- Le niveau de risque détermine les exigences supplémentaires
- Les licences sectorielles sont intégrées dans l'OSS
  </InfoCard>

## Licences Basées sur le Risque

### Classification des Risques

| Niveau de risque | Exigences                 | Exemples                                   |
| ---------------- | ------------------------- | ------------------------------------------ |
| Faible           | NIB uniquement            | Petit commerce de détail, services de base |
| Moyen-faible     | NIB + Certificat standard | Certains commerces, conseil                |
| Moyen-élevé      | NIB + Certificat standard | Services alimentaires, fabrication         |
| Élevé            | NIB + Permis + Inspection | Grande industrie, dangereux                |

### Comment le Risque est Déterminé

Les facteurs incluent :

- Secteur d'activité (code KBLI)
- Échelle des opérations
- Impact environnemental
- Risque pour la santé/sécurité publique
- Valeur de l'investissement

## Licences Environnementales

<InfoCard variant="warning" title="Environmental Compliance">
La plupart des entreprises ont besoin d'une approbation environnementale :

**Faible Impact (SPPL)**

- Petit commerce de détail/bureau
- Déclaration simple

**Impact Moyen (UKL-UPL)**

- Entreprises de taille moyenne
- Plan de gestion environnementale

**Impact Élevé (AMDAL)**

- Grands projets
- Étude d'impact environnemental complète
- Consultation publique requise
  </InfoCard>

## Erreurs Courantes

1.  **Opérer sans NIB** - Requis même pour les petites entreprises
2.  **Codes KBLI erronés** - Doivent correspondre aux activités réelles
3.  **Permis sectoriels manquants** - Vérifier les exigences de l'industrie
4.  **Ignorer l'environnemental** - Ne peut pas fonctionner sans approbation
5.  **Ne pas rapporter le LKPM** - Le rapport d'investissement est obligatoire
6.  **Permis expirés** - Surveiller les dates d'expiration
