# Audit préalable (Due Diligence) en Indonésie 2026 : Liste de contrôle complète

Que ce soit pour investir, acquérir une entreprise ou conclure un partenariat en Indonésie, un audit préalable approfondi est essentiel. Voici votre guide complet.

## Pourquoi l'audit préalable est important

<InfoCard variant="warning" title="Indonesian Business Risks">
**Problèmes courants découverts lors de l'audit préalable :**

- Passifs non divulgués
- Irrégularités fiscales
- Déficiences de licences
- Violations du droit du travail
- Non-conformité environnementale
- Transactions entre parties liées
- Problèmes de titres fonciers
- Actionnaires cachés

**Ne sautez jamais l'audit préalable** - les problèmes sont courants et coûteux.

</InfoCard>

## Audit préalable opérationnel

### Domaines clés

| Domaine       | Ce qu'il faut vérifier                               |
| ------------- | ---------------------------------------------------- |
| Gestion       | Dépendance vis-à-vis des personnes clés, compétences |
| Employés      | Compétences, rotation du personnel, litiges          |
| Systèmes      | TI, processus, évolutivité                           |
| Installations | État, capacité, conformité                           |
| Fournisseurs  | Dépendance, alternatives, contrats                   |
| Clients       | Satisfaction, fidélité, concentration                |

### Signaux d'alerte

| Signal d'alerte                              | Préoccupation                   |
| -------------------------------------------- | ------------------------------- |
| Dépendance vis-à-vis des personnes clés      | Risque en cas de départ         |
| Rotation élevée du personnel                 | Problèmes de culture/gestion    |
| Technologie vieillissante                    | Investissement futur nécessaire |
| Dépendance vis-à-vis d'un fournisseur unique | Risque d'approvisionnement      |
| Concentration de la clientèle                | Risque de revenus               |
| Documentation insuffisante                   | Faiblesses de contrôle          |

## Constatations courantes de l'audit préalable

<InfoCard variant="note" title="Typical Issues Found">
**Dans les entreprises indonésiennes :**

1.  **Lacunes en matière de licences** - Permis manquants ou expirés
2.  **Violations du droit du travail** - BPJS, heures supplémentaires, contrats
3.  **Sous-paiement d'impôts** - Surtout la retenue à la source
4.  **Problèmes de parties liées** - Non divulgués, conditions défavorables
5.  **Problèmes de titres fonciers** - Propriété incertaine, litiges
6.  **Non-conformité environnementale** - Pas de permis, violations
7.  **Passifs non divulgués** - Dettes cachées, garanties
8.  **PI non enregistrée** - Lacunes en matière de marques, brevets
    </InfoCard>

## Processus d'audit préalable

### Calendrier

| Phase                 | Durée        | Activités                      |
| --------------------- | ------------ | ------------------------------ |
| Planification         | 1 semaine    | Portée, équipe, accès          |
| Collecte de documents | 1-2 semaines | Demande et réception           |
| Analyse               | 2-4 semaines | Examen, vérification           |
| Visites sur site      | 1 semaine    | Inspection physique            |
| Rapport               | 1 semaine    | Constatations, recommandations |
| Questions-réponses    | 1-2 semaines | Clarifications                 |

### Structure de l'équipe

| Rôle                          | Responsabilité           |
| ----------------------------- | ------------------------ |
| Responsable de la transaction | Coordination générale    |
| Conseil juridique             | Audit juridique          |
| Comptable                     | Audit financier          |
| Conseiller fiscal             | Audit fiscal             |
| Expert sectoriel              | Audit opérationnel       |
| Consultant local              | Spécifique à l'Indonésie |

## Gestion des constatations

### Options de réponse

| Constatation           | Options                              |
| ---------------------- | ------------------------------------ |
| Rupture de transaction | Se retirer                           |
| Problème matériel      | Ajustement de prix                   |
| Problème réparable     | Exiger une solution avant la clôture |
| Allocation des risques | Indemnisation dans le SPA            |
| Problème mineur        | Accepter le risque                   |

### Indemnisation

<InfoCard variant="tip" title="Protect Yourself">
**Pour les risques identifiés :**

- Indemnités spécifiques dans le contrat de vente
- Montants bloqués en séquestre
- Complément de prix lié aux déclarations
- Assurance (déclarations et garanties)
- Conditions de clôture exigeant une solution

N'acceptez pas simplement les risques, allouez-les correctement !

</InfoCard>
