# Izin Usaha di Indonesia 2026: Panduan Lengkap

Indonesia telah menyederhanakan penerbitan izin usaha melalui sistem OSS (Online Single Submission), tetapi memahami kebutuhan Anda tetap bisa rumit. Jika Anda berencana mendirikan bisnis di Bali khususnya, panduan kami tentang [iklim bisnis di Bali 2026](/business/bali-business-climate-2026-what-foreigners-actually-face) mencakup lapisan regulasi unik yang berlaku di atas kerangka nasional.

## Kerangka Izin

<InfoCard variant="note" title="Sistem OSS">
Sejak **Undang-Undang Cipta Kerja (Omnibus Law)**, Indonesia menggunakan sistem **OSS RBA** (Pendekatan Berbasis Risiko):

- Semua bisnis mendaftar melalui OSS
- Mendapatkan **NIB** (Nomor Induk Berusaha)
- Tingkat risiko menentukan persyaratan lebih lanjut
- Izin sektoral terintegrasi ke dalam OSS

</InfoCard>

## Sistem Izin Berbasis Risiko

### Klasifikasi Risiko

| Tingkat Risiko  | Persyaratan               | Contoh                     |
| ----------- | -------------------------- | ---------------------------- |
| Rendah         | Hanya NIB                   | Ritel kecil, jasa dasar |
| Menengah-Rendah  | NIB + Sertifikat Standar | Beberapa perdagangan, konsultasi    |
| Menengah-Tinggi | NIB + Sertifikat Standar | Jasa makanan, manufaktur  |
| Tinggi        | NIB + Izin + Pemeriksaan  | Industri besar, berbahaya    |

### Cara Menentukan Risiko

Faktor-faktor meliputi:

- Sektor bisnis (kode KBLI)
- Skala operasi
- Dampak lingkungan
- Risiko kesehatan/masyarakat
- Nilai investasi

## Izin Berdasarkan Jenis Bisnis

### Bisnis Perdagangan/Impor

| Izin              | Tujuan                   |
| -------------------- | ------------------------- |
| NIB                  | Pendaftaran dasar         |
| API-U                | Importir umum          |
| API-P                | Importir produsen         |
| IT (Persetujuan Impor) | Persetujuan produk spesifik |
| LS (Verifikasi)    | Komoditas tertentu       |

### Restoran/Kafe

| Izin                                                                        | Tujuan                  |
| ------------------------------------------------------------------------------ | ------------------------ |
| NIB                                                                            | Pendaftaran dasar        |
| [TDUP](/business/bali-tourism-business-license-what-you-need-to-start-legally) | Izin bisnis pariwisata |

| BPOM (jika memproses)                                                           | Makanan kemasan            |
| Halal (disarankan)                                                            | Pelanggan Muslim         |

### Manufaktur

| Izin              | Tujuan            |
| -------------------- | ------------------ |
| NIB                  | Pendaftaran dasar  |
| IUI                  | Izin industri |
| Izin lingkungan | AMDAL/UKL-UPL      |
| Izin lokasi      | Persetujuan penggunaan lahan  |
| Izin bangunan      | IMB/PBG            |
| Izin operasional   | Persetujuan akhir     |

## Izin Lingkungan

<InfoCard variant="warning" title="Kepatuhan Lingkungan">
Sebagian besar bisnis membutuhkan persetujuan lingkungan:

**Dampak Rendah (SPPL)**

- Ritel kecil/kantor
- Deklarasi sederhana

**Dampak Menengah (UKL-UPL)**

- Bisnis menengah
- Rencana pengelolaan lingkungan

**Dampak Tinggi (AMDAL)**

- Proyek besar
- Studi dampak lingkungan lengkap
- Konsultasi publik diperlukan

</InfoCard>

## Kesalahan Umum

1. **Beroperasi tanpa NIB** - Diperlukan bahkan untuk bisnis kecil
2. **Kode KBLI salah** - Harus sesuai dengan aktivitas sebenarnya
3. **Izin sektoral hilang** - Periksa persyaratan industri
4. **Mengabaikan lingkungan** - Tidak bisa beroperasi tanpa persetujuan
5. **Tidak melaporkan LKPM** - Pelaporan investasi wajib
6. **Izin kedaluwarsa** - Pantau tanggal kedaluwarsa
