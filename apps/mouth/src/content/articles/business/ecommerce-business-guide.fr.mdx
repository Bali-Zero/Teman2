Le marché du commerce électronique en Indonésie est immense – plus de 200 millions d'internautes et en croissance. Voici comment les étrangers peuvent y participer.

## Aperçu du marché du commerce électronique

L'économie numérique de l'Indonésie :

- Plus de **170 millions** d'utilisateurs de commerce électronique
- Taille du marché de plus de **50 milliards de dollars**
- Croissance de plus de **20 % par an**
- Marché axé sur le mobile

## PT PMA pour le commerce électronique

### Codes KBLI pour le commerce électronique

| KBLI Code | Activité                                  | Notes                                               |
| --------- | ----------------------------------------- | --------------------------------------------------- |
| 47911     | Commerce de détail par internet (général) | Le plus courant pour le commerce de détail en ligne |
| 47912     | Commerce de gros par internet             | Commerce électronique B2B                           |
| 62011     | Développement de logiciels/applications   | Pour les plateformes                                |
| 63122     | Activités de portail web                  | Opérations de marketplace                           |

### Propriété étrangère

La plupart des activités de commerce électronique autorisent une **propriété étrangère à 100 %** via une PT PMA. Exceptions :

- Certaines catégories de commerce de détail
- Activités sur liste négative
- Plateforme avec des éléments de médias sociaux

<InfoCard variant="warning" title="Vérifier les restrictions KBLI">
  Certains codes KBLI ont des limites ou des exigences en matière de propriété étrangère. Vérifiez
  votre activité spécifique avant de créer votre entreprise.
</InfoCard>

## Enregistrement PSE

L'enregistrement **PSE (Penyelenggara Sistem Elektronik)** est obligatoire pour le commerce électronique :

### Qui a besoin du PSE ?

- Tout site web/application opérant en Indonésie
- Plateformes de commerce électronique
- Fournisseurs de services en ligne
- Applications traitant les données des utilisateurs indonésiens

### Types de PSE

| Type        | Pour                     | Exemple                          |
| ----------- | ------------------------ | -------------------------------- |
| PSE Private | Entreprises privées      | Magasin de commerce électronique |
| PSE Public  | Services gouvernementaux | N/A pour les entreprises         |

### Comment s'enregistrer

1. Accéder au système OSS
2. Demander l'enregistrement PSE
3. Fournir les documents de l'entreprise
4. Détailler votre système électronique
5. Recevoir le certificat PSE

## Vendre sur les marketplaces

Sans PT PMA, les étrangers peuvent toujours vendre via :

### Marketplaces indonésiennes

- **Tokopedia** - La plus grande marketplace
- **Shopee** - Populaire, axée sur le mobile
- **Lazada** - Soutenue par Alibaba
- **Blibli** - Axée sur la qualité
- **Bukalapak** - Axée sur les PME

### Exigences

- Compte individuel ou professionnel
- Compte bancaire indonésien (généralement)
- Pièce d'identité valide
- Conformité des produits aux règles de la plateforme

<InfoCard variant="tip" title="Commencez petit sur les marketplaces">
  Testez vos produits sur les marketplaces avant d'investir dans une PT PMA. Utilisez les données
  des marketplaces pour valider la demande avant un investissement plus important.
</InfoCard>

## Solutions de paiement

### Méthodes de paiement populaires

- **Virement bancaire** - Toujours courant
- **Portefeuilles électroniques** - OVO, GoPay, DANA, ShopeePay
- **QRIS** - Code QR universel
- **COD** - Paiement à la livraison (important pour la confiance)
- **Cartes de crédit** - Adoption limitée

### Options de passerelle de paiement

- Midtrans (alternative à Stripe)
- Xendit
- DOKU
- Faspay

## Considérations fiscales

### Fiscalité du commerce électronique

| Type de taxe              | Taux             | S'applique à              |
| ------------------------- | ---------------- | ------------------------- |
| TVA (PPN)                 | 11%              | Ventes de biens           |
| Impôt sur le revenu (PPh) | 22% des sociétés | Bénéfices de l'entreprise |
| Retenue à la source       | Varie            | Certaines transactions    |

### Considérations transfrontalières

- Droits d'importation sur les marchandises de plus de 3 USD
- TVA sur les services numériques
- Règles de prix de transfert pour les parties liées
