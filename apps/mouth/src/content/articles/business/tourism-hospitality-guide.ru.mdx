## Приключенческий туризм

Особые соображения для приключенческих видов деятельности:

### Дайвинг-операции

- **PADI/SSI аффилиация** - Требуется сертификация
- **Сотрудник по безопасности дайвинга** - Обученный персонал
- **Стандарты оборудования** - Регулярное обслуживание
- **Страховка** - Специальное покрытие для дайвинга
- **Готовность к спасению** - Протоколы действий в чрезвычайных ситуациях

### Водные виды спорта

- **Школы серфинга** - Сертификаты инструкторов
- **Операторы рафтинга** - Разрешения на реку, снаряжение для безопасности
- **Туры с маской и трубкой** - Обучение гидов, оборудование

<InfoCard variant="warning" title="Безопасность прежде всего">
  Приключенческий туризм несет риски ответственности. Надлежащее страхование,
  сертифицированные гиды и протоколы безопасности имеют важное значение — не
  только для соблюдения требований, но и для вашей защиты.
</InfoCard>

## Проблемы с арендой вилл

<InfoCard variant="error" title="Ограничения на аренду вилл">
  Маломасштабная аренда вилл является одной из наиболее ограниченных областей
  для иностранцев: - Во многих районах запрещены Pondok Wisata, принадлежащие
  иностранцам - На Bali действуют особые правила, ограничивающие деятельность
  иностранных вилл - «Номинальные» соглашения являются незаконными и
  рискованными - Аренда земли + строительство виллы имеют сложности с владением
</InfoCard>

### Варианты вилл для иностранцев

1. **Классификация отелей** (15+ единиц) - Возможно с PT PMA
2. **Управление недвижимостью** - Управление чужими виллами
3. **Совместное предприятие** - С индонезийским партнером (рискованно)
4. **Инвестиции в аренду (leasehold)** - Ограниченный контроль

## Турагентство (BPW)

Полноценные турагентства могут:

- Бронировать авиабилеты
- Организовывать бронирование отелей
- Создавать пакетные туры
- Обрабатывать продажу билетов

### Требования BPW

- PT PMA с KBLI турагентства
- TDUP для турагентства
- Подтверждение финансовой состоятельности
- Лицензированный персонал
