# Tech Startup in Indonesia 2026: Guida per Fondatori Stranieri

L'Indonesia è l'ecosistema di startup più grande del Sud-est asiatico con unicorni come Gojek, Tokopedia e Traveloka. Ecco come i fondatori stranieri possono costruire qui.

## Perché l'Indonesia per la Tecnologia?

- **270 milioni** di abitanti
- **200+ milioni** di utenti internet
- **Età media 29** - giovani, esperti di tecnologia
- **Crescente classe media**
- **Mercato mobile-first**
- **Ecosistema VC attivo**

## Codici KBLI per la Tecnologia

| Codice | Attività             | Note             |
| ------ | -------------------- | ---------------- |
| 62011  | Sviluppo software    | App, piattaforme |
| 62012  | Integrazione sistemi | Enterprise       |
| 62021  | Consulenza IT        | Consulenza       |
| 63111  | Elaborazione dati    | Analisi          |
| 63112  | Hosting web          | Infrastruttura   |
| 63122  | Portale web          | Marketplace      |

<InfoCard variant="tip" title="Investimento Inferiore per la Tecnologia">
  Alcuni codici KBLI tecnologici (soprattutto 62011, 62012) potrebbero avere
  requisiti di investimento inferiori rispetto agli standard di IDR 10 miliardi.
  Controlla i requisiti OSS attuali per la tua attività specifica.
</InfoCard>

## Assunzioni in Indonesia

### Talento Locale

- Forte talento ingegneristico, soprattutto a Jakarta
- Costi inferiori rispetto a Singapore
- Pool crescente di dipendenti esperti di startup
- La competenza in inglese varia

### Principi Fondamentali del Lavoro

| Requisito            | Note                                       |
| -------------------- | ------------------------------------------ |
| BPJS Kesehatan       | Assicurazione sanitaria (obbligatoria)     |
| BPJS Ketenagakerjaan | Assicurazione per l'impiego (obbligatoria) |
| Salario minimo       | Per provincia (Jakarta ~IDR 5M/mese)       |
| Contratti            | A tempo determinato o indeterminato        |
| Indennità            | Significativa per i licenziamenti          |

### Dipendenti Stranieri

Assumere talenti tecnologici stranieri:

- RPTKA richiesto per posizione
- Tariffa DKP-TKA di 100 USD/mese
- Deve formare un collega indonesiano
- Generalmente limitato a ruoli senior/specialisti

## Regolamenti Specifici per la Tecnologia

### PSE (Operatore di Sistema Elettronico)

Tutte le piattaforme tecnologiche devono registrarsi:

- Obbligatorio per operare in Indonesia
- Requisiti di localizzazione dei dati
- Obblighi di moderazione dei contenuti
- Disposizioni di accesso governativo

### Protezione dei Dati

- L'Indonesia ha una legge sulla protezione dei dati personali
- Requisiti per la gestione dei dati
- Consenso e obblighi di sicurezza
- Sanzioni per la non conformità

### Specifico per Fintech

Se si costruisce fintech:

- Licenza OJK richiesta
- Programmi sandbox disponibili
- Requisiti di capitale
- Rendicontazione regolare
