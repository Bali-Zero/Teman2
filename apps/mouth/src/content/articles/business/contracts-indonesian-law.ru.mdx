# Деловые контракты по индонезийскому законодательству 2026

Контракты необходимы для ведения бизнеса, но они должны соответствовать индонезийскому законодательству, чтобы быть подлежащими исполнению. Вот что вам нужно знать.

## Требования к контракту

<InfoCard variant="note" title="Элементы действительного контракта">
Согласно Гражданскому кодексу Индонезии (статья 1320), действительный контракт требует:

1.  **Согласие** – Взаимное согласие, данное добровольно
2.  **Дееспособность** – Стороны, юридически способные заключать контракт
3.  **Определенный предмет** – Четкий предмет договора
4.  **Законное основание** – Законная цель

Отсутствие любого элемента может сделать контракт ничтожным или оспоримым.

</InfoCard>

## Языковые требования

<InfoCard variant="warning" title="Закон об индонезийском языке">
Согласно **Закону 24/2009**, контракты с участием индонезийских сторон **должны быть на индонезийском языке**.

**Практический подход:**

- Двуязычные контракты (индонезийский + английский)
- Индонезийская версия имеет преимущественную силу в случае конфликта
- Включить пункт, указывающий, какая версия является регулирующей

Игнорирование этого может создать проблемы с принудительным исполнением.

</InfoCard>

### Лучшая практика

| Ситуация                  | Рекомендация                                    |
| :------------------------ | :---------------------------------------------- |
| Обе стороны индонезийские | Только индонезийский                            |
| Одна сторона иностранная  | Двуязычный                                      |
| Обе стороны иностранные   | Английский подходит (но индонезийский помогает) |
| Трудовой договор          | Должен включать индонезийский язык              |

## Гербовый сбор (Materai)

<InfoCard variant="note" title="Требуется гербовый сбор">
**Materai (гербовый сбор)** требуется для:
-   Контрактов
-   Юридических документов
-   Документов, используемых в качестве доказательств в суде

**Текущая ставка:** 10 000 индонезийских рупий за документ

Без надлежащего гербового сбора документ может быть неприемлем в качестве доказательства.

</InfoCard>

### Как применять гербовый сбор

| Метод            | Примечания                                |
| :--------------- | :---------------------------------------- |
| Физическая марка | Наклеивается и подписывается поверх       |
| E-Meterai        | Электронный гербовый сбор                 |
| Пост-штампование | Может быть сделано позже, если необходимо |

## Разрешение споров

### Варианты

| Метод                    | Плюсы                            | Минусы                             |
| :----------------------- | :------------------------------- | :--------------------------------- |
| Переговоры               | Быстро, дешево                   | Нет принудительного исполнения     |
| Медиация                 | Нейтральная третья сторона       | Все еще не имеет обязательной силы |
| Арбитраж (BANI)          | Обязательный, экспертные арбитры | Дорогостоящий                      |
| Судебное разбирательство | Государственное принуждение      | Медленно, публично                 |

### Арбитражная оговорка

<InfoCard variant="tip" title="Выбирайте арбитраж">
Для значимых коммерческих контрактов:
-   Включите арбитражную оговорку
-   BANI (индонезийский) или SIAC (Сингапур)
-   Быстрее, чем суды
-   Подлежит исполнению на международном уровне

Пример оговорки должен указывать:

- Учреждение (BANI, SIAC)
- Местонахождение
- Количество арбитров
- Язык
  </InfoCard>

## Требования к нотариальному заверению

### Когда требуется Notaris

| Документ                 | Нотариальное заверение |
| :----------------------- | :--------------------- |
| Устав компании           | Требуется              |
| Передача акций           | Требуется              |
| Передача собственности   | Требуется              |
| Доверенность             | Рекомендуется          |
| Стандартный коммерческий | Не требуется           |

Индонезийские нотариусы (PPAT/Notaris) имеют особые полномочия для определенных документов.

## Электронные контракты

<InfoCard variant="note" title="Электронные контракты действительны">
Согласно **Закону 11/2008** (Закон об ИТЭ):
-   Электронные контракты действительны
-   Электронные подписи признаются
-   Должны соответствовать определенным требованиям
-   Некоторые исключения (земля, наследство)

Платформы для цифровой подписи могут использоваться для большинства коммерческих контрактов.

</InfoCard>

## Форс-мажор

Индонезийское законодательство признает force majeure (keadaan kahar):

- События вне контроля
- Делают исполнение невозможным
- Должны быть специально определены в контракте

Включите четкие положения о force majeure, определяющие:

- Какие события квалифицируются
- Требования к уведомлению
- Влияние на обязательства
- Ограничения по срокам
