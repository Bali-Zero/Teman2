## Pendaftaran Merek

### Mengapa Mendaftar di Indonesia?

<InfoCard variant="warning" title="Sistem First-to-File">
Indonesia menggunakan sistem **first-to-file**:
- Yang pertama mendaftar memiliki merek
- Merek Anda di tempat lain tidak melindungi Anda di sini
- "Penyerobot" mungkin mendaftarkan merek Anda lebih dulu
- Tanpa pendaftaran, penegakan terbatas

**Daftarkan merek Anda sebelum memasuki pasar Indonesia!**

</InfoCard>

## Perlindungan Hak Cipta

### Perlindungan Otomatis

Perlindungan hak cipta **otomatis** di Indonesia untuk:

- Karya sastra
- Musik dan lagu
- Seni dan fotografi
- Film dan video
- Perangkat lunak dan basis data
- Arsitektur

### Mengapa Tetap Mendaftar?

| Manfaat    | Penjelasan                      |
| ---------- | ------------------------------- |
| Bukti      | Membuktikan tanggal kepemilikan |
| Penegakan  | Tindakan hukum lebih mudah      |
| Lisensi    | Kepemilikan lebih jelas         |
| Nilai aset | Untuk valuasi bisnis            |

### Proses Pendaftaran

| Langkah                | Durasi     |
| ---------------------- | ---------- |
| Siapkan dokumen        | 1 minggu   |
| Aplikasi online        | 1 hari     |
| Tinjauan DGIP          | 1-3 bulan  |
| Sertifikat diterbitkan | 1-2 minggu |

## Rahasia Dagang

### Persyaratan Perlindungan

<InfoCard variant="tip" title="Lindungi Rahasia Anda">
Untuk mempertahankan perlindungan rahasia dagang:

1. **Identifikasi** apa yang rahasia
2. **Tandai** dokumen sebagai rahasia
3. **Batasi** akses sesuai kebutuhan
4. **NDA** dengan karyawan dan mitra
5. **Tindakan keamanan** (fisik dan digital)
6. **Latih** staf tentang kerahasiaan

Setelah dipublikasikan, perlindungan hilang selamanya.

</InfoCard>

### Elemen NDA

| Elemen       | Tujuan                      |
| ------------ | --------------------------- |
| Definisi     | Apa yang rahasia            |
| Kewajiban    | Cara melindungi             |
| Durasi       | Berapa lama mengikat        |
| Pengecualian | Pengungkapan yang diizinkan |
| Remedi       | Konsekuensi pelanggaran     |
| Yurisdiksi   | Biasanya hukum Indonesia    |

## Perlindungan Internasional

### Perjanjian yang Diikuti Indonesia

| Perjanjian      | Manfaat                       |
| --------------- | ----------------------------- |
| Konvensi Paris  | Klaim prioritas (12 bulan)    |
| TRIPS           | Standar minimum               |
| Protokol Madrid | Sistem merek internasional    |
| PCT             | Pengajuan paten internasional |
| Konvensi Bern   | Pengakuan hak cipta           |

<InfoCard variant="note" title="Klaim Prioritas">
Jika Anda memiliki pendaftaran KI yang ada di luar negeri, Anda dapat mengklaim **prioritas** di Indonesia:
- Merek: 6 bulan dari pengajuan pertama
- Paten: 12 bulan dari pengajuan pertama

Ini mengundur tanggal pengajuan Indonesia Anda.

</InfoCard>
