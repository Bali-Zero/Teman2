## AMDAL (Penilaian Dampak Lingkungan)

<InfoCard variant="warning" title="Proyek Utama Saja">
**AMDAL diperlukan untuk:**
- Fasilitas manufaktur besar
- Operasi pertambangan
- Proyek infrastruktur utama
- Pertanian skala besar
- Pengembangan lahan signifikan
- Fasilitas kimia/berbahaya

AMDAL melibatkan konsultasi publik dan penilaian ahli.

</InfoCard>

### Proses AMDAL

| Tahap               | Deskripsi                 | Durasi   |
| ------------------- | --------------------------- | ---------- |
| Screening           | Menentukan apakah AMDAL diperlukan | 1-2 minggu  |
| Scoping             | Mendefinisikan cakupan studi          | 2-4 minggu  |
| Studi EIA           | Studi dampak lingkungan               | 3-6 bulan |
| Konsultasi publik   | Masukan masyarakat                   | 1-2 bulan |
| Tinjauan            | Penilaian oleh komite                | 1-2 bulan |
| Persetujuan         | Izin lingkungan diterbitkan          | 2-4 minggu  |

### Komponen AMDAL

| Dokumen | Tujuan                       |
| -------- | ----------------------------- |
| KA-ANDAL | Kerangka acuan               |
| ANDAL    | Analisis dampak              |
| RKL      | Rencana pengelolaan lingkungan |
| RPL      | Rencana pemantauan lingkungan |

## UKL-UPL (Pengelolaan & Pemantauan)

### Kapan UKL-UPL Diperlukan

Sebagian besar bisnis menengah memerlukan UKL-UPL:

- Restoran dan kafe
- Manufaktur kecil hingga menengah
- Bengkel dan garasi
- Konstruksi menengah
- Hotel (ukuran tertentu)

## SPPL (Surat Pernyataan)

<InfoCard variant="tip" title="Pilihan Paling Sederhana">
**SPPL** untuk bisnis berisiko rendah:
- Toko ritel kecil
- Layanan dasar
- Kegiatan kantor
- Operasi berisiko rendah

Seringkali dihasilkan secara otomatis melalui sistem OSS berdasarkan kode KBLI Anda.

</InfoCard>

### Proses SPPL

1. Daftar pada sistem OSS
2. Masukkan detail bisnis
3. SPPL dihasilkan jika risikonya rendah
4. Cetak dan simpan sebagai arsip
5. Patuhi komitmen yang dinyatakan

---

## Pendekatan Berbasis Risiko

### Klasifikasi Risiko OSS

Sistem OSS sekarang menggunakan **pendekatan berbasis risiko**:

| Tingkat Risiko  | Persyaratan Lingkungan       |
| ----------- | -------------------------- |
| Rendah         | SPPL (otomatis di OSS)    |
| Rendah-Sedang  | SPPL atau UKL-UPL disederhanakan |
| Sedang-Tinggi | UKL-UPL standar           |
| Tinggi        | AMDAL penilaian lengkap      |

Risiko ditentukan oleh:

- Klasifikasi bisnis KBLI
- Skala operasi
- Sensitivitas lokasi
- Potensi dampak lingkungan

## Pengelolaan Limbah

### Kategori Limbah

| Kategori       | Contoh                  | Persyaratan               |
| -------------- | ------------------------- | -------------------------- |
| B3 (Berbahaya) | Kimia, baterai, minyak   | Pembuangan berlisensi      |
| Non-B3         | Limbah umum              | Pembuangan yang tepat      |
| Air limbah     | Air proses               | Pengolahan sebelum dibuang |
| Emisi udara    | Asap, gas                | Pemantauan, filter        |

<InfoCard variant="warning" title="Limbah B3">
**Limbah berbahaya (B3)** memerlukan:
- Penyimpanan terpisah
- Pengangkut berlisensi
- Fasilitas pembuangan berlisensi
- Dokumentasi manifest
- Pelaporan rutin

Pelanggaran dapat mengakibatkan sanksi serius.

</InfoCard>

---

## Sanksi untuk Ketidakpatuhan

| Pelanggaran                | Sanksi                    |
| ------------------------ | -------------------------- |
| Operasi tanpa izin        | Penutupan + denda          |
| Melampaui standar         | Peringatan → denda → penutupan |
| Pembuangan limbah tidak tepat | Tuntutan pidana mungkin   |
| Pelaporan palsu           | Pencabutan izin           |
| Pelanggaran B3            | Pidana + tanggung jawab perdata |
