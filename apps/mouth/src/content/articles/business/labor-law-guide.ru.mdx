## PKWT (Срочный трудовой договор)

<InfoCard variant="warning" title="Ограничения PKWT">
**PKWT может использоваться только для:**
- Временной работы
- Сезонной работы
- Единовременных проектов
- Работы, связанной с новыми продуктами/процессами (макс. 2 года)

**Не может использоваться для:**

- Постоянных должностей
- Основных текущих операций
- Бессрочных назначений

Нарушение: Договор автоматически становится PKWTT (постоянным).

</InfoCard>

### Правила продолжительности PKWT

| Правило                  | Ограничение                                    |
| ------------------------ | ---------------------------------------------- |
| Начальный срок           | Макс. 5 лет (совокупно)                        |
| Продления                | В пределах 5-летнего лимита                    |
| Без испытательного срока | Испытательный срок недействителен, если указан |
| Компенсация              | Обязательна по завершении                      |

### Правила сверхурочной работы

<Calculator
  title="Калькулятор сверхурочных"
  description="Рассчитайте оплату сверхурочных"
  fields={[
    {
      id: "monthly",
      label: "Месячная зарплата (IDR)",
      type: "number",
      defaultValue: 10000000,
      min: 0,
      step: 500000,
      suffix: "IDR"
    },
    {
      id: "hours",
      label: "Сверхурочные часы",
      type: "number",
      defaultValue: 10,
      min: 0,
      max: 14,
      suffix: "часов"
    },
    {
      id: "day",
      label: "Тип дня",
      type: "select",
      options: [
        { value: "weekday", label: "Обычный будний день" },
        { value: "weekend", label: "Выходной/праздничный день" }
      ],
      defaultValue: "weekday"
    }
  ]}
  calculateResult={(values) => {
    const monthly = Number(values.monthly);
    const hours = Number(values.hours);

    // Hourly rate = 1/173 of monthly salary
    const hourlyRate = monthly / 173;

    let overtime = 0;

    if (values.day === "weekday") {
      // First hour: 1.5x, subsequent hours: 2x
      if (hours >= 1) {
        overtime += hourlyRate * 1.5;
        if (hours > 1) {
          overtime += (hours - 1) * hourlyRate * 2;
        }
      }
    } else {
      // Weekend/holiday: different calculation
      // First 8 hours: 2x, 9th hour: 3x, 10th+: 4x
      const first8 = Math.min(hours, 8);
      overtime += first8 * hourlyRate * 2;
      if (hours > 8) {
        overtime += hourlyRate * 3;
        if (hours > 9) {
          overtime += (hours - 9) * hourlyRate * 4;
        }
      }
    }

    return {
      total: Math.round(overtime),
      breakdown: [
        { label: "Месячная зарплата", amount: monthly },
        { label: "Почасовая ставка (1/173)", amount: Math.round(hourlyRate) },
        { label: "Сверхурочные часы", amount: hours },
        { label: "Оплата сверхурочных", amount: Math.round(overtime) }
      ],
      currency: "IDR",
      note: values.day === "weekday" ? "Будний день: 1.5x первый час, 2x далее" : "Выходные: 2x первые 8 часов, 3x 9-й час, 4x 10-й и далее"
    };

}}

## Право на отпуск

### Ежегодный отпуск

| Тип                  | Право                                     |
| -------------------- | ----------------------------------------- |
| Ежегодный отпуск     | 12 дней/год (после 12 месяцев)            |
| Длительный отпуск    | 2 месяца после 6 лет (некоторые компании) |
| Религиозный праздник | Согласно договору                         |

### Специальный оплачиваемый отпуск

| Событие                         | Дней   |
| ------------------------------- | ------ |
| Брак                            | 3 дня  |
| Брак ребенка                    | 2 дня  |
| Обрезание                       | 2 дня  |
| Крещение                        | 2 дня  |
| Смерть супруга/ребенка/родителя | 2 дня  |
| Смерть другого члена семьи      | 1 день |
| Роды/выкидыш жены               | 2 дня  |

### Отпуск по беременности и родам / Отпуск по уходу за ребенком

| Тип отпуска                    | Продолжительность                      | Оплата        |
| ------------------------------ | -------------------------------------- | ------------- |
| Отпуск по беременности и родам | 1.5 месяца до + 1.5 месяца после родов | Полная оплата |
| Выкидыш                        | 1.5 месяца                             | Полная оплата |
| Отпуск по уходу за ребенком    | 2 дня                                  | Полная оплата |

## Правила компании

### Когда требуется

<InfoCard variant="note" title="Peraturan Perusahaan">
Компании с **10+ сотрудниками** должны иметь:
- **PP (Peraturan Perusahaan)** - Правила компании

Или с профсоюзом:

- **PKB (Perjanjian Kerja Bersama)** - Коллективный договор

Должны быть зарегистрированы в Министерстве трудовых ресурсов и продлеваться каждые 2 года.

</InfoCard>
