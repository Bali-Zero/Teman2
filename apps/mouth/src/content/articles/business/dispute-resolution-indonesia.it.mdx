## Arbitrato

### Perché l'Arbitrato?

<InfoCard variant="tip" title="Vantaggi dell'Arbitrato">
**Per controversie commerciali:**

- **Arbitratori esperti** - Conoscenza del settore
- **Confidenziale** - Nessun registro pubblico
- **Più veloce** - Rispetto ai tribunali di solito
- **Esecutibile** - Trattati internazionali
- **Flessibile** - Le parti scelgono il processo
- **Definitivo** - Limitate basi per appello

La maggior parte dei contratti commerciali significativi include clausole arbitrali.

</InfoCard>

### BANI (Arbitrato Indonesiano)

| Aspetto    | Dettagli                            |
| --------- | ---------------------------------- |
| Nome completo | Badan Arbitrase Nasional Indonesia |
| Sede       | Jakarta, Surabaya                  |
| Regole     | Regole BANI                        |
| Lingua     | Indonesiano o Inglese              |
| Costi      | Tassa di deposito + onorari arbitri |
| Tempistiche | 6-12 mesi tipici                   |

### Opzioni Internazionali

| Istituto      | Quando Utilizzato                 |
| ---------------- | ------------------------- |
| SIAC (Singapore) | Contratti internazionali   |
| ICC              | Grandi affari internazionali |
| HKIAC            | Focus Asia-Pacifico          |
| LCIA             | Questioni relative al Regno Unito        |

<InfoCard variant="note" title="Clausola Arbitrale">
**Clausola arbitrale standard:**

"Qualsiasi controversia derivante o connessa a questo accordo sarà risolta definitivamente tramite arbitrato secondo le Regole BANI. La sede dell'arbitrato sarà Jakarta. La lingua dell'arbitrato sarà l'Inglese."

Includi questa nei tuoi contratti!

</InfoCard>

## Esecuzione

### Esecuzione di Premi Arbitrali

<InfoCard variant="note" title="Esecuzione Internazionale">
**L'Indonesia è parte di:**
- Convenzione di New York (1958)
- Convenzione ICSID

I premi arbitrali stranieri sono esecutibili in Indonesia tramite il processo di registrazione presso i tribunali (tipicamente 2-4 mesi).

I premi BANI indonesiani sono direttamente esecutibili.

</InfoCard>

### Esecuzione di Sentenze dei Tribunali

| Situazione           | Processo                       |
| ------------------- | ----------------------------- |
| Sentenza indonesiana | Esecuzione diretta              |
| Sentenza straniera    | Deve essere riesaminata in Indonesia |

Le sentenze dei tribunali stranieri **non sono direttamente esecutibili** - è necessario citare nuovamente in giudizio nei tribunali indonesiani.

## Consigli per la Prevenzione

<InfoCard variant="tip" title="Evita Controversie">
**Migliori pratiche:**

1. **Contratti chiari** - Termini dettagliati e non ambigui
2. **Clausola controversia** - Includi meccanismo di risoluzione
3. **Comunicazione** - Affronta le questioni presto
4. **Documentazione** - Tieni registri
5. **Diligenza dovuta** - Prima di entrare in accordi
6. **Consulenza professionale** - Quando hai dubbi

La prevenzione costa meno della risoluzione!

</InfoCard>
