## Registrazione del Marchio

### Perché Registrarsi in Indonesia?

<InfoCard variant="warning" title="Sistema First-to-File">
Indonesia utilizza il sistema **first-to-file**:
- Chi per primo registra possiede il marchio
- Il tuo marchio all'estero non ti protegge qui
- I "squatter" possono registrare il tuo marchio in anticipo
- Senza registrazione, enforcement limitato

**Registra il tuo marchio prima di entrare nel mercato indonesiano!**

</InfoCard>

## Protezione del Diritto d'Autore

### Protezione Automatica

La protezione del diritto d'autore è **automatica** in Indonesia per:

- Opere letterarie
- Musica e canzoni
- Arte e fotografie
- Film e video
- Software e database
- Architettura

### Perché Registrarsi Comunque?

| Beneficio     | Spiegazione            |
| ----------- | ---------------------- |
| Prova        | Dimostra la data di proprietà |
| Enforcement   | Azione legale più facile    |
| Licenziamento   | Proprietà più chiara      |
| Valore asset  | Per valutazione aziendale |

### Processo di Registrazione

| Passo               | Durata   |
| ------------------ | ---------- |
| Prepara i documenti  | 1 settimana     |
| Domanda online       | 1 giorno      |
| Revisione DGIP        | 1-3 mesi |
| Certificato erogat    | 1-2 settimane  |

## Segreti Commerciali

### Requisiti di Protezione

<InfoCard variant="tip" title="Proteggi i Tuoi Segreti">
Per mantenere la protezione del segreto commerciale:

1. **Identifica** cosa è riservato
2. **Segna** i documenti come riservati
3. **Limita** l'accesso a chi ne ha bisogno
4. **NDA** con dipendenti e partner
5. **Sicurezza** (fisica e digitale)
6. **Formazione** del personale sulla riservatezza

Una volta reso pubblico, la protezione è persa per sempre.

</InfoCard>

### Fondamentali dell'NDA

| Elemento      | Scopo                  |
| ------------ | ------------------------ |
| Definizione   | Cosa è riservato      |
| Obblighi  | Come proteggere           |
| Durata     | Per quanto tempo vincolante         |
| Eccezioni   | Divulgazioni consentite    |
| Rimedi     | Conseguenze della violazione      |
| Giurisdizione | Tipicamente legge indonesiana |

## Protezione Internazionale

### Trattati Seguiti da Indonesia

| Trattato           | Beneficio                     |
| ---------------- | --------------------------- |
| Convenzione di Parigi | Priorità (12 mesi)          |
| TRIPS            | Standard minimi             |
| Protocollo di Madrid  | Sistema internazionale marchi     |
| PCT              | Presentazione brevetti internazionali |
| Convenzione di Berna | Riconoscimento diritto d'autore       |

<InfoCard variant="note" title="Rivendicazioni di Priorità">
Se hai una registrazione della PI esistente all'estero, puoi rivendicare **priorità** in Indonesia:
- Marchi: 6 mesi dalla prima presentazione
- Brevetti: 12 mesi dalla prima presentazione

Questo fa risale la tua domanda indonesiana.

</InfoCard>
