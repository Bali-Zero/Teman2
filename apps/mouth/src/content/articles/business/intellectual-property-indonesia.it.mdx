## Registrazione Marchio

### Perché Registrare in Indonesia?

<InfoCard variant="warning" title="Sistema First-to-File">
L'Indonesia usa il sistema **first-to-file**:
- Chi si registra per primo possiede il marchio
- Il tuo marchio altrove non ti protegge qui
- Gli "squatter" possono registrare il tuo brand per primi
- Senza registrazione, enforcement limitato

**Registra il tuo marchio prima di entrare nel mercato Indonesia!**

</InfoCard>

## Protezione Diritto d'Autore

### Protezione Automatica

La protezione del diritto d'autore è **automatica** in Indonesia per:

- Opere letterarie
- Musica e canzoni
- Arte e fotografie
- Film e video
- Software e database
- Architettura

### Perché Registrare Comunque?

| Beneficio    | Spiegazione               |
| ------------ | ------------------------- |
| Prova        | Dimostra data proprietà   |
| Enforcement  | Azione legale più facile  |
| Licenze      | Proprietà più chiara      |
| Valore asset | Per valutazione aziendale |

### Processo di Registrazione

| Passo                  | Durata        |
| ---------------------- | ------------- |
| Prepara documenti      | 1 settimana   |
| Domanda online         | 1 giorno      |
| Revisione DGIP         | 1-3 mesi      |
| Certificato rilasciato | 1-2 settimane |

## Segreti Commerciali

### Requisiti Protezione

<InfoCard variant="tip" title="Proteggi i Tuoi Segreti">
Per mantenere la protezione dei segreti commerciali:

1. **Identifica** cosa è confidenziale
2. **Marca** i documenti come confidenziali
3. **Limita** l'accesso al bisogno
4. **NDA** con dipendenti e partner
5. **Misure di sicurezza** (fisiche e digitali)
6. **Formazione** del personale sulla confidenzialità

Una volta pubblici, la protezione è persa per sempre.

</InfoCard>

### Elementi NDA

| Elemento      | Scopo                         |
| ------------- | ----------------------------- |
| Definizione   | Cosa è confidenziale          |
| Obblighi      | Come proteggere               |
| Durata        | Per quanto tempo vincolante   |
| Eccezioni     | Divulgazioni permesse         |
| Rimedi        | Conseguenze violazione        |
| Giurisdizione | Tipicamente legge indonesiana |

## Protezione Internazionale

### Trattati Seguiti dall'Indonesia

| Trattato              | Beneficio                         |
| --------------------- | --------------------------------- |
| Convenzione di Parigi | Rivendicazioni priorità (12 mesi) |
| TRIPS                 | Standard minimi                   |
| Protocollo di Madrid  | Sistema marchi internazionale     |
| PCT                   | Deposito brevetto internazionale  |
| Convenzione di Berna  | Riconoscimento diritto d'autore   |

<InfoCard variant="note" title="Rivendicazioni Priorità">
Se hai una registrazione PI esistente all'estero, puoi rivendicare **priorità** in Indonesia:
- Marchi: 6 mesi dal primo deposito
- Brevetti: 12 mesi dal primo deposito

Questo retrodata il tuo deposito indonesiano.

</InfoCard>
