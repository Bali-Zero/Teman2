┌──────────────────────────────────────────────────────────────────────────────┐
│ 🛠️ TROUBLESHOOTING                                                           │
└──────────────────────────────────────────────────────────────────────────────┘

  Problem: Errors not appearing in Sentry
  Solution:
    1. Check Vercel env vars: vercel env ls
    2. Verify all 5 SENTRY_* variables are set
    3. Check deployment logs: vercel logs --follow
    4. Look for "Sentry webpack plugin" in logs
    5. Force redeploy: vercel --prod --force

  Problem: Stack traces are minified (no source maps)
  Solution:
    1. Verify SENTRY_AUTH_TOKEN is set on Vercel
    2. Check token permissions: Project: Read & Write + Release: Admin
    3. Regenerate token if needed
    4. Redeploy after updating token

  Problem: Too many events (quota exceeded)
  Solution:
    1. Reduce sample rates in sentry.client.config.ts:
       tracesSampleRate: 0.05 (instead of 0.1)
       replaysSessionSampleRate: 0.05 (instead of 0.1)
    2. Add ignoreErrors for known issues
    3. Upgrade to paid plan if necessary
