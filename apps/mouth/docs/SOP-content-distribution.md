# SOP — Content Distribution (Bali Zero)

**Owner:** Subhi (Growth / SEO / CRO)
**Version:** 1.0 — 27 Jul 2026
**Scope:** Distribusi ulang artikel `kita.balizero.com` ke 5 channel sosial untuk memperluas audiens tanpa merusak SEO canonical.
**Golden rule:** Canonical selalu menunjuk balik ke `kita.balizero.com`. Setiap link keluar wajib pakai UTM. Tidak ada klaim yang belum diverifikasi tim (Surya/Angel untuk tax, Antonello untuk angka bisnis).

---

## 0. Prinsip umum (berlaku semua channel)

| Aturan               | Detail                                                                                                                |
| -------------------- | --------------------------------------------------------------------------------------------------------------------- |
| Canonical-first      | Republish penuh hanya di channel yang mendukung canonical tag (Medium). Channel lain: teaser + link, bukan full-copy. |
| UTM wajib            | Semua link keluar `?utm_source=[channel]&utm_medium=social&utm_campaign=[batch]-distribution`.                        |
| Cadence aman         | Maks sesuai tabel per channel. Jangan burst — hindari flag spam.                                                      |
| Tidak ada klaim liar | Angka klien/review, regulasi pajak, klaim hukum → hanya yang sudah diverifikasi.                                      |
| 1 CTA per post       | Satu ajakan jelas (WhatsApp / baca full). Jangan tumpuk banyak link.                                                  |
| Bahasa               | Ikuti bahasa artikel: ID untuk audiens Indonesia, EN untuk expat/investor.                                            |

**Placeholder yang dipakai di seluruh template:**
`[JUDUL]` `[SLUG]` `[RINGKASAN_150]` `[POIN_1]` `[POIN_2]` `[POIN_3]` `[HERO_IMAGE]` `[UTM_LINK]` `[WA_LINK]`

## 1. Medium

**Tujuan:** Backlink + audiens baru, aman untuk SEO karena canonical.
**Cadence:** 3 artikel/minggu. Prioritas immigration dulu (volume pencarian tertinggi).

**Langkah:**

1. Medium → _Stories_ → _Import a story_ → paste URL `[UTM_LINK]`. Ini **otomatis set canonical** ke `kita.balizero.com` (wajib, jangan copy-paste manual).
2. Cek canonical sudah benar: Medium tampil "originally published at kita.balizero.com".
3. Tag (maks 5): `Indonesia`, `Bali`, `Expat`, + 2 topik spesifik (`Business` / `Tax` / `Visa` / `Property`).
4. Kategori: Indonesia Business · Bali Expat Life · Tax & Legal.
5. Footer artikel — tambah blok CTA:

```
---
Butuh bantuan [topik]? Tim Bali Zero (licensed notary & tax agent) siap bantu.
👉 Baca panduan lengkap: [UTM_LINK]
💬 Konsultasi langsung: [WA_LINK]
```

**Checklist:** ☐ Import (bukan paste) ☐ Canonical verified ☐ 5 tag ☐ CTA footer ☐ UTM aktif

---

## 2. LinkedIn

**Tujuan:** Audiens investor/profesional. Prioritas artikel business + property.
**Cadence:** 3–4 native post/minggu.
**Kunci algoritma:** LinkedIn menekan link eksternal di body → **link taruh di komentar pertama**, bukan di post.

**Struktur post (200–300 kata):**

```
[HOOK — 1 kalimat provokatif / statistik]

[RINGKASAN_150 — reframe jadi insight, bukan ringkasan artikel]

3 hal yang perlu kamu tahu:
• [POIN_1]
• [POIN_2]
• [POIN_3]

Panduan lengkap ada di komentar pertama 👇
```

**Komentar pertama (segera setelah post):** `Full breakdown: [UTM_LINK]`

**Checklist:** ☐ Native text (bukan link-only) ☐ Hook di baris 1 ☐ Link di komentar-1 ☐ UTM aktif ☐ Maks 3 hashtag

---

## 3. Twitter / X

**Tujuan:** Reach cepat, engagement tinggi. Bisa harian.
**Cadence:** 1 thread/hari.
**Formula: 7-tweet thread.**

```
Tweet 1 (HOOK):   [statistik / pernyataan mengejutkan]. Thread 🧵
Tweet 2:          Konteks masalah — kenapa ini penting sekarang.
Tweet 3:          [POIN_1] + data pendukung.
Tweet 4:          [POIN_2] + contoh konkret.
Tweet 5:          [POIN_3] + implikasi praktis.
Tweet 6:          Ringkasan / kesalahan umum yang harus dihindari.
Tweet 7 (CTA):    Panduan lengkap: [UTM_LINK]
                  Butuh bantuan? [WA_LINK]
```

**Aturan:** 1 gambar/diagram di Tweet 1 (naikkan reach). Link hanya di Tweet 7 (link awal turunkan reach).

**Checklist:** ☐ Hook kuat T1 ☐ Gambar T1 ☐ Link hanya T7 ☐ UTM aktif ☐ Maks 2 hashtag

---

## 4. Facebook Group (expat Bali)

**Tujuan:** Reach komunitas high-intent.
**Cadence:** 2–3 post/minggu, sebar merata antar grup (jangan post sama di banyak grup di hari yang sama).
**Kunci:** Banyak grup **ban promosi langsung** → format **percakapan**, bukan link-dump. Cek rules tiap grup dulu.

**Template conversational:**

```
Lagi baca soal [topik] dan ternyata banyak yang belum tahu soal [insight singkat dari POIN_1].

[2–3 kalimat nilai nyata — kasih dulu, jangan jualan]

Aku tulis breakdown lengkapnya di sini kalau ada yang butuh: [UTM_LINK]
(happy to answer pertanyaan di kolom komentar 🙌)
```

**Aturan:** Balas komentar dalam 1 jam pertama (boost reach). Jangan copy-paste identik antar grup — variasikan pembuka.

**Checklist:** ☐ Cek rules grup ☐ Format percakapan ☐ Value dulu ☐ 1 link ☐ UTM aktif ☐ Balas komentar

---

## 5. Pinterest

**Tujuan:** Traffic evergreen jangka panjang. Prioritas visual-friendly: property, lifestyle, business dulu.
**Cadence:** Batch create. Immigration/tax pakai infografik data sederhana.

**Spec pin:**

- Ukuran: **1000×1500px** (rasio 2:3).
- Judul overlay besar + branding Bali Zero (pojok).
- Pakai Canva template reusable (koordinasi Damar).

**Description pin (100–200 kata):**

```
[JUDUL] — [1 kalimat manfaat]. [POIN_1]. [POIN_2].
Baca panduan lengkap → [UTM_LINK]
#BaliBusiness #ExpatIndonesia #[topik]
```

**Checklist:** ☐ 1000×1500 ☐ Branding ☐ Judul overlay ☐ Link di description ☐ UTM aktif ☐ 3–5 hashtag

## 7. Definition of Done (per artikel)

Sebuah artikel dianggap "terdistribusi" jika:
☐ Medium republished + canonical verified
☐ LinkedIn posted + link di komentar-1
☐ X thread posted
☐ Facebook posted di min. 1 grup (sesuai rules)
☐ Pinterest pin live (jika visual-friendly)
☐ Semua link UTM terverifikasi muncul di GA4 (utm_source terekam)

**Review:** 2 minggu setelah batch selesai → GA4 → Traffic Acquisition → filter `utm_source` → bandingkan sessions & lead_whatsapp_cta per channel. Channel pemenang jadi prioritas SOP versi berikutnya.
