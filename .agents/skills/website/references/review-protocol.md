# Website review protocol

## Evidence packet

Provide the current route/component inventory, approved owner decisions, desktop
and mobile screenshots with decoded images, actual CTA destinations, and the
production comparison. Identify which inputs show the old versus new Team.
Do not transmit client data or credentials. Give reviewers an explicit read-only
scope and a bounded output folder for their reports.

## Independent stages

1. Advanced critique: evaluate hierarchy, conversion, trust, accessibility,
   visual quality, page length, mobile usage, and ecosystem omissions. Require
   precise observations, counterarguments, and questions needing research.
2. Gemini research: investigate those questions using current primary sources
   and credible UX research. Record URLs, actual tool use, uncertainty, and what
   is transferable to Bali Zero. Do not convert a competitor pattern into fact
   about our users. A sourced response without browsing evidence is not a
   verified deep-research pass.
3. Visual reassessment: review the real screenshots, not only JSX/CSS. Correct
   claims caused by lazy-loading, preview-only safeguards, or stale assets.
4. Synthesis: separate immediate defects, plausible experiments, product/owner
   decisions, and production integration blockers. Explain disagreements rather
   than averaging arbitrary scores.

## Provenance and constraints

Record vendor, requested model, served model when observable, date, input scope,
tool access, execution status, and limitations. Use sanctioned subscription
routes; no new paid keys. Keep processes bounded and stop them when complete.
Skill availability across five vendors does not mean all five reviewed the page.

## Useful final output

Rank a small number of changes by expected visitor impact and evidence strength.
For each proposed addition ask: which visitor need, which current destination,
what verified capability, where it fits, and what existing element it replaces.
Avoid expanding a nearly finished homepage into an internal product catalogue.
No unmeasured conversion uplift or fabricated user-test results.
