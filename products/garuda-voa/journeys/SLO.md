# GARUDA VOA service levels

## Measurement contract

| ID   | Rule                                                                                                                                                                                                                                                          |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| M-01 | All interval boundaries use server-side UTC timestamps from the authoritative ingress and commit records. Client clocks and provider `occurred_at` values are diagnostic only.                                                                                |
| M-02 | One logical request, upload, order, provider event, or transition contributes at most one sample. Retries and inbox duplicates do not increase numerator or denominator.                                                                                      |
| M-03 | An operation that starts but does not complete remains in the population. Once its age crosses the objective, it counts as a violation; it is never dropped as missing data.                                                                                  |
| M-04 | Production and synthetic traffic are labeled only by environment and test class. Synthetic traffic is excluded from business conversion counts and reported separately for liveness.                                                                          |
| M-05 | Metrics contain only bounded low-cardinality labels. No personal data, answers, nationality value, document value, opaque result identifier, account identifier, order identifier, payment reference, URL, IP address, or user agent is a label or log field. |
| M-06 | A missing metric stream or unavailable denominator is `unknown`, never `healthy`, and raises the measurement-data alert.                                                                                                                                      |

## Service-level objectives

| ID      | Signal                     | Start                                                                                         | Stop                                                                                                                                                   | Population                                                                                                                                                                       | Objective           | Evaluation                                                                  |
| ------- | -------------------------- | --------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------- | --------------------------------------------------------------------------- |
| SLO-V01 | Public verdict latency     | Complete eligibility request accepted at public ingress after body-size and schema validation | Terminal `ACCEPT` or `DECLINE` response committed and available to the requesting browser                                                              | All production verdict requests that pass transport/schema validation, including eligibility declines and freshness declines; policy-unavailable failures are tracked separately | p95 ≤ 10 seconds    | Rolling 30 days; publish 5-minute and 1-hour burn views                     |
| SLO-O01 | Upload-to-OCR feedback     | Last upload byte accepted and the upload receipt committed                                    | First terminal customer-visible OCR feedback committed: verified review fields, `LOW_CONFIDENCE`, or `UNREADABLE_DOCUMENT`                             | Every accepted production upload attempt, including corrupt and low-confidence images; retries with the same idempotency identity count once                                     | median < 60 seconds | Rolling 60 minutes for paging and rolling 30 days for objective reporting   |
| SLO-W01 | Webhook reconciliation lag | Provider webhook bytes accepted at ingress, before signature verification                     | One atomic terminal outcome commits: authenticated rejection, inbox dedup no-op, business-state transition plus journal/outbox, or governed quarantine | Every webhook delivered to production ingress; valid signed events are reported separately from invalid-signature traffic                                                        | p99 ≤ 60 seconds    | Rolling 60 minutes for alerting and rolling 30 days for objective reporting |

## Exact observations

| Signal  | Required timestamps and outcome                                                                                                                                                                                                                                                                                                                                                     |
| ------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Verdict | `request_accepted_at`, `verdict_committed_at`, terminal outcome class. Latency is `verdict_committed_at - request_accepted_at`. Network time before ingress and browser rendering after response commit are excluded.                                                                                                                                                               |
| OCR     | `upload_committed_at`, `ocr_feedback_committed_at`, terminal feedback class. Latency is `ocr_feedback_committed_at - upload_committed_at`. Queue wait, local OCR, validation, and feedback persistence are included. An unresolved upload aged 60 seconds or more contributes a censored duration of at least its current age and therefore cannot make the median falsely healthy. |
| Webhook | `webhook_received_at`, `reconciliation_committed_at`, signature class, terminal reconciliation class. Lag is `reconciliation_committed_at - webhook_received_at`. Provider transit time is excluded because the provider clock is not authoritative. Out-of-order and quarantined valid events remain in the population.                                                            |

## Paged business invariants

| ID    | Invariant                                         | Activation                                                                                                                                               | Measurement                                                                                                                                                                                                                                                                        | Page condition                                                                                                                                                                                               | Recovery                                                                                                          |
| ----- | ------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------- |
| BI-01 | Paid orders in rolling 24 hours > 0 once launched | Begin evaluation 24 hours after the explicit production `launch_activated_at`, provided the public funnel has remained enabled                           | Every 5 minutes, count distinct production, non-synthetic orders whose first OP-02 `payment.paid` journal event committed in `(now - 24h, now]` from a signature-verified, reconciled webhook. A later refund does not erase the historical paid event; it is reported separately. | Page when the count is 0. Page the measurement-data alert instead if the count cannot be proven from journal evidence. Sandbox, staff test, replay, browser redirect, and manually edited state never count. | Resolve only after the rolling count is > 0 from qualifying evidence and the underlying incident is acknowledged. |
| BI-02 | Median upload-to-OCR feedback < 60 seconds        | Evaluate whenever the rolling 60-minute SLO-O01 population is non-empty; the scheduled synthetic upload monitors liveness when production volume is zero | Recompute SLO-O01 every 5 minutes from committed start/stop evidence, including overdue unresolved uploads as violations                                                                                                                                                           | Page when the median is ≥ 60 seconds. Page the measurement-data alert if starts exist but timestamps or outcomes are missing.                                                                                | Resolve only after the rolling median is < 60 seconds and no unaccounted upload starts remain.                    |

## Synthetic dead-man

| ID     | Cadence                | Required path                                                                                                                   | Success evidence                                                                                                                                                         | Dead-man action                                                                                                                                                           |
| ------ | ---------------------- | ------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| SYN-01 | Start every 15 minutes | Synthetic eligibility → local OCR feedback → sandbox checkout → valid signed sandbox webhook → `paid` → one `Received` practice | One signed probe result binds all stage outcomes to the scheduled probe class; no personal data is used; its order is excluded from BI-01 and paid-order product metrics | If no complete signed result is recorded within 15 minutes of its scheduled start, set the public flag off and alert the owner. A late probe cannot auto-enable the flag. |

## Alert ownership

| Signal          | Primary owner       | Required evidence in page                                                                                                             |
| --------------- | ------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| SLO-V01 burn    | Public funnel lane  | Window, percentile, sample count, open overdue count, release version; no request identifiers                                         |
| SLO-O01 / BI-02 | OCR and upload lane | Window, median, sample count, queue-age buckets, feedback-class counts; no document or customer identifiers                           |
| SLO-W01         | Payment lane        | Window, p99, signed/invalid/quarantined counts, inbox backlog count; no provider or order references                                  |
| BI-01           | Product operations  | Launch timestamp, rolling qualifying count, last qualifying paid-event age, sandbox-exclusion count; no order or customer identifiers |
